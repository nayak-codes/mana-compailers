Example 2: Pointer Arithmetic & Memory Addresses

#include <stdio.h>

int main() {
    int num = 42;
    int *ptr = &num;
    
    printf("Value of num: %d\n", num);
    printf("Address of num: %p\n", (void*)&num);
    printf("Value via ptr: %d\n", *ptr);
    return 0;
}
Expected Output: 
Value of num: 42
Address of num: 0x7ffe...
Value via ptr: 42

Code Explanation: & operator retrieves variable memory address, while * dereferences the pointer to read stored value.

Example 3: Dynamic Memory Allocation (malloc)

#include <stdio.h>
#include <stdlib.h>

int main() {
    int n = 5;
    int *arr = (int*)malloc(n * sizeof(int));
    
    if (arr == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }
    
    for (int i = 0; i < n; i++) {
        arr[i] = (i + 1) * 10;
        printf("arr[%d] = %d\n", i, arr[i]);
    }
    
    free(arr);
    return 0;
}
Expected Output: 
arr[0] = 10
arr[1] = 20
arr[2] = 30
arr[3] = 40
arr[4] = 50

Code Explanation: malloc() allocates dynamic heap memory, checked against NULL. free() deallocates memory post-usage.

🛠️ Common C Language Compiler Errors & Fixes

⚠️ implicit declaration of function

Cause: Calling a function before declaring it or missing required header (e.g. <stdio.h>).

How to Fix: Include appropriate #include <header.h> directives at top of file.

⚠️ segmentation fault (core dumped)

Cause: Dereferencing NULL or invalid pointer, accessing array out of bounds.

How to Fix: Check pointer initialization and array bounds before accessing memory.

⚠️ expected ; before token

Cause: Missing semicolon at end of statement.

How to Fix: Add semicolon ; at end of preceding line statement.

⚠️ conflicting types for function

Cause: Function implementation signature differs from prototype declaration.

How to Fix: Ensure parameter types and return type match prototype exactly.
