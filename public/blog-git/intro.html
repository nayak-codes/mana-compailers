Git & GitHub — Introduction to Git

🔀 Git & GitHub 🟢 Lesson 1 📅 2026
Every developer eventually runs into the same problem: multiple versions of a project, unclear which file is the "latest," and no easy way to undo a bad change. Git solves this by tracking every change to your code over time, letting you go back to any earlier version instantly. This lesson explains what Git actually is and why almost every software team on Earth uses it.
1What is Version Control?

Version control is a system that records changes to files over time so you can recall specific versions later. Before tools like Git existed, developers often kept folders named project_final, project_final_v2, project_ACTUALLY_final — a chaotic and error-prone way to work. Git replaces all of that with a single, organized history.

2Git vs GitHub — They Are Not the Same Thing

This confuses almost every beginner. Git is the version control software itself — it runs on your computer and tracks your project's history locally, even with zero internet connection. GitHub is a website that hosts Git repositories online, adding collaboration features like pull requests, issues, and code review on top of Git. You can use Git without ever touching GitHub, but GitHub cannot exist without Git.

3Why Git Is Distributed

Git is a distributed version control system, meaning every developer's local copy contains the entire project history, not just the current files. This is different from older centralized systems where only one central server held the full history. Because of this, you can commit changes, view history, and create branches entirely offline — you only need internet access when you want to sync with a remote repository like GitHub.

⚠️ Common Mistake: Thinking Git and GitHub Are Interchangeable

New developers often say "push it to Git" when they mean GitHub, or assume installing GitHub Desktop means they have Git. Keep the distinction clear: Git is the tool, GitHub (or GitLab, Bitbucket, etc.) is one of many places you can host a Git repository online.
