Git & GitHub — Installing & Configuring Git

🔀 Git & GitHub 🟢 Lesson 2 📅 2026
Before you can use any Git commands, you need Git installed on your computer and configured with your identity. This one-time setup takes less than five minutes and every commit you ever make will use these details.
1Installing Git

Git is available for every major operating system:

  • Windows — download the installer from git-scm.com and run it; Git Bash is included, giving you a Unix-style terminal
  • Mac — install via Homebrew with brew install git, or install Xcode Command Line Tools
  • Linux — use your package manager, e.g. sudo apt install git on Ubuntu/Debian

Verify the installation worked by checking the version:

git --version
2Setting Your Identity

Git attaches a name and email address to every single commit you make, so your team knows who changed what. Set this globally once, and it applies to every repository on your machine:

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
3Checking Your Configuration

You can view all your current settings at any time:

git config --list

If you ever need project-specific settings that differ from your global defaults, drop the --global flag while inside that project's folder — Git will apply the setting only to that one repository.

⚠️ Common Mistake: Skipping the --global Flag by Accident

Forgetting --global sets your name and email for only the current repository, not your whole system. If you then create a new project elsewhere and commit without configuring it again, Git may use a blank or incorrect identity, or refuse to commit at all.

💻 Try It Yourself

Open your terminal and run these three commands to check your Git is properly installed and identified.

git --version
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
