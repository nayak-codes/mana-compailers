MySQL — HAVING Clause

🐬 MySQL 8.0+ 🟢 Chapter 20 of 34 📂 Phase 06: Functions & Aggregation 📅 2026 Edition
📌 Covered in this chapter: HAVING vs WHERE · Filtering grouped aggregates · Combining WHERE and HAVING · Complex analytical queries

Welcome to MySQL — HAVING Clause in our MySQL Complete Masterclass! Filter aggregated query results using the HAVING clause, understanding the difference between WHERE row filtering and HAVING group filtering.

1Simple Introduction & Overview

In MySQL relational database management, understanding HAVING Clause is essential for building structured, consistent, and performant data storage systems. MySQL uses Structured Query Language (SQL) to manipulate and query relational datasets.

📚 Learning Objectives:

3Why This Concept is Useful
💡 Practical Utility

Relational databases ensure ACID compliance (Atomicity, Consistency, Isolation, Durability). Mastering MySQL equips web developers to store user accounts, orders, products, and analytics safely.

4Basic Syntax & Structure
SQL — MySQL Syntax 
-- Creating database schema and table structure
CREATE DATABASE IF NOT EXISTS company_db;
USE company_db;

CREATE TABLE IF NOT EXISTS employees (
    id INT AUTO_INCREMENT PRIMARY KEY,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    salary DECIMAL(10, 2) DEFAULT 50000.00,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
5Basic Example Implementation
SQL — Full Query Example 
-- Inserting sample records into employees table
INSERT INTO employees (first_name, last_name, email, salary)
VALUES 
    ('Ravi', 'Kumar', 'ravi.kumar@example.com', 75000.00),
    ('Priya', 'Sharma', 'priya.sharma@example.com', 82000.00),
    ('Anil', 'Verma', 'anil.verma@example.com', 65000.00);

-- Querying high-earning employees
SELECT id, CONCAT(first_name, ' ', last_name) AS full_name, salary
FROM employees
WHERE salary > 70000.00
ORDER BY salary DESC;

7Line-by-Line SQL Explanation
SQL Keyword / ClauseFunction & Purpose
CREATE TABLEDefines a new relational table schema with specified column types.
AUTO_INCREMENTAutomatically generates sequential integer identifiers for new rows.
CONCAT()Combines first_name and last_name columns into a formatted full_name string.
ORDER BY ... DESCSorts the resulting dataset in descending order based on salary values.
8Common Database Mistakes
⚠️ Pitfalls to Avoid
  • Forgetting the WHERE clause in UPDATE or DELETE statements — affects all table rows!
  • Storing plain-text passwords in database columns — always use hashed strings (bcrypt/Argon2).
  • Unindexed foreign key or search columns — causes full table scans on large datasets.
9Quick Recap & Summary
  • MySQL stores structured data in tables composed of rows and columns
  • Primary Keys guarantee unique row identifiers, and Foreign Keys enforce relationships
  • SELECT statements retrieve filtered data using WHERE, GROUP BY, and ORDER BY clauses
  • Use Workbench or MySQL CLI client to manage databases and execute SQL scripts
