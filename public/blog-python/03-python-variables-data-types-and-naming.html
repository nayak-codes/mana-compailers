ఏ కంప్యూటర్ ప్రోగ్రామ్ అయినా చివరికి చేసేది డేటాను నిర్వహించడమే. C, C++ లేదా Java వంటి భాషల్లో ఒక వేరియబుల్‌ను సృష్టించాలంటే ముందుగానే int x = 10; అని మెమరీ బాక్స్ సైజును రిజర్వ్ చేయాలి. కానీ పైథాన్ మెమరీ ఆర్కిటెక్చర్ పూర్తిగా భిన్నమైనది మరియు అద్భుతమైనది! పైథాన్‌లో వేరియబుల్స్ అనేవి మెమరీ బాక్స్‌లు కావు; అవి హీప్ మెమరీలో సృష్టించబడిన ఆబ్జెక్టులకు తగిలించే లేబుల్స్ (Name Tags / Object References) మాత్రమే! ఈ మూడవ అధ్యాయంలో — పైథాన్ డైనమిక్ టైపింగ్ ఎలా పనిచేస్తుంది, id() ద్వారా మెమరీ అడ్రస్‌లను తనిఖీ చేయడం, స్మాల్ ఇంటిజర్ క్యాషింగ్, నంబర్స్, బూలియన్లు, స్ట్రింగ్స్, మ్యూటబిలిటీ vs ఇమ్మ్యుటబిలిటీ, మరియు ఒక పూర్తి స్థాయి E-Commerce Dynamic Billing & SKU Engine ప్రాజెక్ట్ ద్వారా డేటా టైప్స్‌పై సంపూర్ణ పట్టు సాధిద్దాం!

1 పైథాన్‌లో వేరియబుల్స్ అంటే ఏమిటి? (Variables as Memory Labels)

సాంప్రదాయ ప్రోగ్రామింగ్ భాషల్లో ఒక వేరియబుల్ అంటే మెమరీలో నిర్దిష్ట సైజు కలిగిన ఒక డబ్బా (Storage Box). కానీ పైథాన్‌లో ప్రతిదీ ఒక ఆబ్జెక్ట్ (Everything is an Object)!

మీరు age = 25 అని రాసినప్పుడు తెరవెనుక మూడు పనులు జరుగుతాయి:

  1. పైథాన్ హీప్ మెమరీలో 25 అనే విలువతో ఒక int ఆబ్జెక్ట్‌ను సృష్టిస్తుంది.
  2. ఆ ఆబ్జెక్ట్‌కు ఒక ప్రత్యేకమైన మెమరీ చిరునామా (Memory Address) కేటాయిస్తుంది.
  3. age అనే పేరును ఆ మెమరీ ఆబ్జెక్ట్‌కు ఒక లేబుల్ లేదా పాయింటర్‌లా బంధిస్తుంది (Name Binding).
[పైథాన్ నేమ్ బైండింగ్ vs సాంప్రదాయ మెమరీ బాక్స్] 1. C/C++ శైలి (వేరియబుల్ అంటే ఫిక్స్‌డ్ మెమరీ బాక్స్): [ వేరియబుల్ x (4 Bytes) ] ===> లోపల 100 అనే విలువ నిల్వ ఉంటుంది. 2. Python శైలి (వేరియబుల్స్ అంటే హీప్ ఆబ్జెక్టులకు టాగ్స్): ┌───────────────┐ │ వేరియబుల్: a │─────┐ └───────────────┘ │ ▼ ┌───────────────┐ ┌─────────────────────────────────────────┐ │ వేరియబుల్: b │──>│ Heap Object: 100 (Type: int) │ └───────────────┘ │ Address: id() = 140723849201 │ │ Ref Count: 2 (రెండు వేరియబుల్స్ లింక్)│ └─────────────────────────────────────────┘ • 'b = a' అని రాసినప్పుడు కొత్త ఆబ్జెక్ట్ తయారుకాదు! • 'b' కూడా అదే పాత 100 ఆబ్జెక్ట్‌ను పాయింట్ చేస్తుంది (Memory Efficiency!).

2 డైనమిక్ టైపింగ్ & స్ట్రాంగ్ టైపింగ్ ఫిలాసఫీ (Dynamic & Strongly Typed)

పైథాన్ గురించి ఇంటర్వ్యూలలో తరచుగా అడిగే ప్రశ్న: "పైథాన్ Dynamically Typed ఆ లేక Statically Typed ఆ? మరియు Strongly Typed ఆ లేక Weakly Typed ఆ?"

  • పైథాన్ Dynamically Typed: వేరియబుల్ డిక్లేర్ చేసేటప్పుడు టైప్ చెప్పనవసరం లేదు. రన్‌టైమ్‌లో అది పాయింట్ చేసే ఆబ్జెక్ట్ ఆధారంగా టైప్ నిర్ణయించబడుతుంది. ఒకే వేరియబుల్‌కు మొదట నంబర్, తర్వాత స్ట్రింగ్ అసైన్ చేయవచ్చు:
    data = 100 (ఇప్పుడు int), ఆపై data = "స్వాగతం" (ఇప్పుడు str).
  • పైథాన్ Strongly Typed: జావాస్క్రిప్ట్ లాగా ఆటోమేటిక్‌గా డేటా టైపులను మార్చి పిచ్చి లెక్కలు చేయదు! ఉదాహరణకు జావాస్క్రిప్ట్‌లో "5" + 5 అంటే "55" అవుతుంది. కానీ పైథాన్‌లో "5" + 5 అని రాస్తే తక్షణమే TypeError: can only concatenate str (not "int") to str అని స్పష్టమైన ఎర్రర్ ఇస్తుంది!

3 ఆబ్జెక్ట్ ఐడెంటిటీ, మెమరీ అడ్రస్: id(), type() & is ఆపరేటర్

పైథాన్‌లో ఏదైనా ఆబ్జెక్ట్ అంతర్గత స్వభావాన్ని శోధించడానికి రెండు అత్యంత కీలకమైన బిల్ట్-ఇన్ ఫంక్షన్లు ఉన్నాయి:

  • type(obj): ఆబ్జెక్ట్ యొక్క క్లాస్ లేదా డేటా టైప్‌ను రిటర్న్ చేస్తుంది (ఉదా: <class 'int'>).
  • id(obj): ఆ ఆబ్జెక్ట్ RAM లో నిల్వ చేయబడిన ప్రత్యేకమైన మెమరీ చిరునామాను (Integer Memory Address) రిటర్న్ చేస్తుంది.
  • is ఆపరేటర్: రెండు వేరియబుల్స్ మెమరీలో ఒకే ఆబ్జెక్ట్‌ను పాయింట్ చేస్తున్నాయా లేదా (id(a) == id(b)) అని చెక్ చేస్తుంది. విలువలను పోల్చడానికి == వాడతాం, మెమరీ ఐడెంటిటీని పోల్చడానికి is వాడతాం!

# ఆబ్జెక్ట్ ఐడెంటిటీ & id() మెమరీ శోధన

num1 = 250
num2 = 250

print("num1 విలువ:", num1, "| టైప్:", type(num1), "| ID:", id(num1))
print("num2 విలువ:", num2, "| టైప్:", type(num2), "| ID:", id(num2))

# == (విలువ సమానత్వమా?) vs is (ఒకే మెమరీ ఆబ్జెక్టా?)
print("విలువలు సమానమా (num1 == num2)?", num1 == num2)
print("ఒకే మెమరీ ఆబ్జెక్టా (num1 is num2)?", num1 is num2)

# స్మాల్ ఇంటిజర్ క్యాషింగ్ (-5 నుండి 256 వరకు పైథాన్ మెమరీలో ముందుగానే ఉంచుతుంది!)
a = 100
b = 100
print("\nస్మాల్ ఇంటిజర్ క్యాషింగ్ (a is b):", a is b) # True! ఒకే మెమరీ అడ్రస్

4 ప్రిమిటివ్ డేటా టైప్స్ 1: సంఖ్యలు (Numeric Types — int, float, complex)

పైథాన్‌లో గణిత లెక్కల కోసం మూడు ప్రధాన న్యూమరిక్ డేటా టైప్స్ ఉన్నాయి:

డేటా టైప్ వివరణ ఉదాహరణ ప్రత్యేకత (Unique Feature)
int (పూర్ణాంకాలు) ధనాత్మక లేదా రణాత్మక సంపూర్ణ సంఖ్యలు. 42, -105, 1_000_000 అపరిమిత పరిమాణం (Arbitrary Precision)! 32-bit లేదా 64-bit ఓవర్‌ఫ్లో ఉండదు; ఎంత పెద్ద సంఖ్యనైనా మెమరీ ఉన్నంతవరకు నిల్వ చేస్తుంది.
float (దశాంశాలు) పాయింట్ ఉన్న దశాంశ సంఖ్యలు (Double precision). 3.14159, -0.005, 1.5e-4 సైంటిఫిక్ నోటేషన్ సపోర్ట్ చేస్తుంది (IEEE 754 64-bit standard). 53 బిట్స్ సిగ్నిఫికెంట్ ప్రిసిషన్ లభిస్తుంది.
complex (మిశ్రమ సంఖ్యలు) వాస్తవ మరియు ఊహాత్మక భాగాలు (Real & Imaginary). 3 + 4j, z = 2 - 5j ఇంజనీరింగ్ & క్వాంటం ఫిజిక్స్ కోసం ఇన్-బిల్ట్ j సపోర్ట్. z.real, z.imag లభిస్తాయి.
Decimal (ఖచ్చితమైన దశాంశాలు) బ్యాంకింగ్ & ఫైనాన్స్ కరెన్సీ లెక్కల కోసం. Decimal('19.99') decimal మాడ్యూల్ నుండి లభిస్తుంది. ఫ్లోటింగ్ పాయింట్ రౌండింగ్ ఎర్రర్స్ లేకుండా పూర్తి ఖచ్చితత్వాన్ని ఇస్తుంది.
🔬 డీప్ డైవ్: Python 3 లో int మెమరీ ఎలా నిర్వహించబడుతుంది?

సాధారణ C లాంగ్వేజ్‌లో ఇంటీజర్ అంటే 4 బైట్స్ (32-బిట్: -2,147,483,648 నుండి 2,147,483,647 వరకు మాత్రమే). కానీ Python 3 లో ప్రతి int ఒక C-లెవల్ PyLongObject స్ట్రక్చర్! చిన్న సంఖ్య అయితే 28 బైట్స్ మెమరీ తీసుకుంటుంది; సంఖ్య పెరుగుతున్న కొద్దీ డైనమిక్‌గా 30-బిట్ డిజిట్స్ (digits array) రూపంలో మెమరీని పెంచుకుంటూ పోతుంది. అందుకే పైథాన్‌లో ఇంటీజర్ ఓవర్‌ఫ్లో అనేది అసాధ్యం!

# పైథాన్ 3 ఆర్బిట్రరీ ప్రెసిషన్ ఇంటీజర్స్ & కాంప్లెక్స్ నంబర్స్ డెమో

# 1. భారీ సంఖ్యలు (C/C++ లో ఇవి ఓవర్‌ఫ్లో అయి క్రాష్ అవుతాయి!)
astronomical_number = 2 ** 100
print("2 పవర్ 100 విలువ:")
print(astronomical_number)

# 2. అండర్‌స్కోర్స్ ద్వారా రీడబిలిటీ (PEP 515)
annual_revenue = 10_000_000_000 # 1000 కోట్లు
print("\nవార్షిక ఆదాయం:", annual_revenue, "రూపాయలు")

# 3. కాంప్లెక్స్ నంబర్స్
z = 5 + 12j
print("\nకాంప్లెక్స్ సంఖ్య:", z)
print("రియల్ పార్ట్ (వాస్తవ భాగం):", z.real)
print("ఇమాజినరీ పార్ట్ (ఊహాత్మక భాగం):", z.imag)

5 ప్రిమిటివ్ డేటా టైప్స్ 2: బూలియన్లు & Truthiness (bool)

పైథాన్‌లో నిజం లేదా అబద్ధాన్ని సూచించడానికి bool క్లాస్ ఉంది, ఇందులో కేవలం రెండే విలువలు ఉంటాయి: True మరియు False (గమనిక: మొదటి అక్షరం పెద్ద అక్షరం క్యాపిటల్ T, క్యాపిటల్ F ఉండాలి).

పైథాన్‌లో bool అనేది నిజానికి int క్లాస్ యొక్క సబ్-క్లాస్! అందుకే True == 1 మరియు False == 0 అవుతుంది.

💡 Truthy vs Falsy విలువల నియమాలు:

ఏదైనా వేరియబుల్‌ను if కండిషన్‌లో పెట్టినప్పుడు పైథాన్ దాన్ని ఆటోమేటిక్‌గా బూలియన్‌గా మారుస్తుంది.

  • Falsy విలువలు (ఎల్లప్పుడూ False): False, None, సంఖ్య సున్నా (0, 0.0), ఖాళీ కలెక్షన్స్ ("", [], (), {}, set()).
  • Truthy విలువలు (ఎల్లప్పుడూ True): సున్నా కాని ఏ సంఖ్య అయినా (ఉదా: -5, 42), ఖాళీ లేని స్ట్రింగ్స్ (ఉదా: " ", "hello"), అంశాలు ఉన్న ఏ లిస్ట్ లేదా డిక్షనరీ అయినా.

6 ప్రిమిటివ్ డేటా టైప్స్ 3: స్ట్రింగ్స్ & NoneType (str & None)

  • స్ట్రింగ్స్ (str): అక్షరాలు, పదాలు లేదా టెక్స్ట్‌ను సూచించే ఇమ్మ్యుటబుల్ సీక్వెన్స్. సింగిల్ కోట్స్ ('...'), డబుల్ కోట్స్ ("..."), లేదా మల్టీ-లైన్ ట్రిపుల్ కోట్స్ ("""...""") లో రాస్తారు. తెలుగు మరియు ప్రపంచ భాషలన్నింటినీ UTF-8 ద్వారా నేరుగా సపోర్ట్ చేస్తుంది.
  • NoneType (None): ఇతర భాషల్లో null లేదా nil లాగా, పైథాన్‌లో "విలువ ఏమీ లేదు" (Absence of value) అని చెప్పడానికి ఒకే ఒక సింగిల్టన్ ఆబ్జెక్ట్ None ఉంటుంది. ఒక ఫంక్షన్ ఏమీ రిటర్న్ చేయకపోతే అది బై-డిఫాల్ట్ None ను రిటర్న్ చేస్తుంది.

7 మ్యూటబుల్ vs ఇమ్మ్యుటబుల్ కాన్సెప్ట్ (Mutability vs Immutability)

పైథాన్ ఆర్కిటెక్చర్‌లో ఇది అత్యంత కీలకమైన అంశం. ఒక ఆబ్జెక్ట్ మెమరీలో సృష్టించబడిన తర్వాత దానిలోని విలువలను అక్కడికక్కడే మార్చవచ్చా లేదా అనే దానిని బట్టి డేటా టైపులను రెండుగా విభజిస్తారు:

కేటగిరీ డేటా టైప్స్ అర్థం & ప్రవర్తన
ఇమ్మ్యుటబుల్ (Immutable - మార్చలేనివి) int, float, bool, str, tuple, frozenset ఒకసారి మెమరీలో తయారైన తర్వాత దాని విలువను మార్చలేము. మీరు విలువను మారిస్తే, పాత ఆబ్జెక్ట్ మారదు; కొత్త మెమరీలో కొత్త ఆబ్జెక్ట్ సృష్టించబడుతుంది!
మ్యూటబుల్ (Mutable - మార్చదగినవి) list, dict, set, bytearray మెమరీ అడ్రస్ (ID) మారకుండానే ఆబ్జెక్ట్ లోపలి విలువలను ఇన్-ప్లేస్ గా జోడించవచ్చు, సవరించవచ్చు లేదా తొలగించవచ్చు.

8 వేరియబుల్ నేమింగ్ రూల్స్ & PEP 8 స్టాండర్డ్స్ (Naming Conventions)

పైథాన్‌లో వేరియబుల్స్ పేర్లు పెట్టేటప్పుడు తప్పనిసరిగా పాటించాల్సిన అధికారిక నియమాలు:

  • అనుమతించబడిన అక్షరాలు: ఇంగ్లీష్ అక్షరాలు (a-z, A-Z), అంకెలు (0-9), మరియు అండర్‌స్కోర్ (_).
  • అంకెతో ప్రారంభం కాకూడదు: 1st_user అనేది తప్పు ❌; user_1 అనేది సరైనది ✅.
  • కేస్-సెన్సిటివ్ (Case-sensitive): score, Score, SCORE అనేవి మూడు వేర్వేరు వేరియబుల్స్!
  • రిజర్వ్డ్ కీవర్డ్స్ వాడకూడదు: పైథాన్‌లో 35 రిజర్వ్డ్ కీవర్డ్స్ (if, for, while, def, class...) ఉన్నాయి. వీటిని వేరియబుల్ పేర్లుగా పెట్టకూడదు.
  • PEP 8 శైలి: వేరియబుల్స్ మరియు ఫంక్షన్ల కోసం ఎల్లప్పుడూ snake_case వాడాలి (ఉదా: customer_name, total_amount). స్థిర విలువల (Constants) కోసం UPPER_CASE వాడాలి (ఉదా: PI = 3.14, MAX_USERS = 100).

9 మల్టిపుల్ అసైన్‌మెంట్ & వేరియబుల్ స్వాప్పింగ్ (Multiple Assignment & Swapping)

పైథాన్ ఇచ్చే అద్భుతమైన ఫీచర్లలో మల్టిపుల్ అసైన్‌మెంట్ ఒకటి. ఒకే లైన్‌లో బహుళ వేరియబుల్స్‌కు విలువలని కేటాయించవచ్చు:

03_multiple_assignment_and_swap.py 
# 1. ఒకే లైన్‌లో వేర్వేరు విలువలను కేటాయించడం (Tuple Unpacking)
item_id, item_title, unit_price = 101, "లాప్‌టాప్ బ్యాగ్", 1499.50
print(f"ID: {item_id} | ఐటెమ్: {item_title} | ధర: ₹ {unit_price}")

# 2. ఒకే విలువను చాలా వేరియబుల్స్‌కు ఇవ్వడం (Chained Assignment)
count_a = count_b = count_c = 0
print("కౌంటర్లు:", count_a, count_b, count_c)

# 3. వేరియబుల్స్ మార్పిడి (Swapping values)
# C/C++ లో temp వేరియబుల్ వాడాలి. పైథాన్‌లో కేవలం ఒక్క లైన్!
x = "రైలు"
y = "విమానం"
print(f"స్వాప్ ముందు: x = {x}, y = {y}")

x, y = y, x  # పైథాన్ మ్యాజిక్ స్వాప్!
print(f"స్వాప్ తర్వాత: x = {x}, y = {y}")

10 టైప్ కాస్టింగ్: ఇంప్లిసిట్ vs ఎక్స్‌ప్లిసిట్ (Type Conversion)

ఒక డేటా టైప్‌లో ఉన్న విలువను మరొక డేటా టైప్‌లోకి మార్చడాన్ని టైప్ కాస్టింగ్ (Type Conversion) అంటారు:

  • 1. ఇంప్లిసిట్ కాస్టింగ్ (Automatic Type Coercion): డేటా లాస్ లేకుండా పైథాన్ స్వయంగా మార్చే విధానం. ఉదాహరణకు int + float చేసినప్పుడు ఫలితం ఆటోమేటిక్‌గా float అవుతుంది:
    res = 10 + 5.5 => 15.5 (float).
  • 2. ఎక్స్‌ప్లిసిట్ కాస్టింగ్ (Manual Type Casting): మనమే ఫంక్షన్లను పిలిచి మార్చడం:
    • int(x): పూర్ణాంకంగా మార్చడం (దశాంశాలు కట్ అవుతాయి: int(9.99) -> 9).
    • float(x): దశాంశ సంఖ్యగా మార్చడం (float("45.5") -> 45.5).
    • str(x): స్ట్రింగ్‌గా మార్చడం (str(100) -> "100").
    • bool(x): బూలియన్‌గా మార్చడం (bool(0) -> False, bool("hi") -> True).

11 మోడరన్ పైథాన్ 3.10+ టైప్ హింటింగ్ (Type Hints & Annotations)

పైథాన్ డైనమిక్ భాష అయినప్పటికీ, పెద్ద ఎంటర్‌ప్రైజ్ ప్రాజెక్ట్‌లలో కోడ్ చదివేటప్పుడు గందరగోళం రాకుండా ఆధునిక పైథాన్ Type Hints (PEP 484 & PEP 604) ఫీచర్‌ను ప్రవేశపెట్టింది:

# బేసిక్ టైప్ అనోటేషన్స్
product_name: str = "గేమింగ్ మౌస్"
product_price: float = 2499.00
stock_quantity: int = 50
is_available: bool = True

# Python 3.10+ పైప్ సింటాక్స్ (Union types):
user_id: int | str = "UID_90812" # int లేదా str రెండూ అనుమతించబడతాయి
discount_coupon: str | None = None # ఐచ్ఛిక విలువ (Optional string)

గమనిక: టైప్ హింట్స్ రన్‌టైమ్‌లో పైథాన్ ఎగ్జిక్యూషన్ వేగాన్ని నెమ్మదించవు; పైథాన్ ఇంటర్‌ప్రిటర్ వీటిని కేవలం మెటాడేటాగా భావించి వేరియబుల్స్‌లాగే నడుపుతుంది. కానీ VS Code / PyCharm వంటి IDEలు మరియు mypy వంటి స్టాటిక్ టైప్ చెకర్లు కోడ్ రన్ అవ్వకముందే బగ్స్‌ను పసిగట్టడానికి ఇవి ఎంతగానో ఉపయోగపడతాయి.

12 కామన్ బిగినర్స్ మిస్టేక్స్ & ప్రొడక్షన్ బెస్ట్ ప్రాక్టీసెస్

  • Mistake 1: బిల్ట్-ఇన్ ఫంక్షన్ల పేర్లను వేరియబుల్స్‌గా వాడటం: మీరు పొరపాటున str = "హలో" లేదా type = "admin" అని రాస్తే, పైథాన్ యొక్క బిల్ట్-ఇన్ str() లేదా type() ఫంక్షన్ ఓవర్‌రైట్ అయిపోతుంది! ఆ తర్వాత str(123) అని పిలిస్తే TypeError: 'str' object is not callable అని క్రాష్ అవుతుంది!
  • Mistake 2: 0.1 + 0.2 != 0.3 ఫ్లోటింగ్ పాయింట్ సమస్య: కంప్యూటర్లు బైనరీలో ఫ్లోటింగ్ పాయింట్ లెక్కలు చేయడం వల్ల 0.1 + 0.2 చేసినప్పుడు 0.30000000000000004 వస్తుంది. ఖచ్చితమైన బ్యాంకింగ్ లెక్కల కోసం పైథాన్ యొక్క decimal మాడ్యూల్ వాడాలి.
  • Mistake 3: ValueError నివారించకపోవడం: యూజర్ నుండి వచ్చే డేటా "abc" అయినప్పుడు నేరుగా int("abc") చేస్తే క్రాష్ అవుతుంది. ఎల్లప్పుడూ try...except బ్లాక్ లేదా str.isdigit() ద్వారా ఇన్‌పుట్ వాలిడేషన్ చేయాలి.
  • Best Practice: మెమరీ క్లీనప్ & రిఫరెన్స్ కౌంటింగ్: పైథాన్‌లో ఏదైనా వేరియబుల్‌కు కేటాయించిన ఆబ్జెక్ట్ రిఫరెన్స్ కౌంట్ సున్నా అయితే (Garbage Collection ద్వారా) ఆ మెమరీ ఆటోమేటిక్‌గా రీక్లెయిమ్ అవుతుంది. పెద్ద డేటా ఆబ్జెక్టులను వెంటనే క్లియర్ చేయడానికి del var_name ఉపయోగించవచ్చు.

13 రియల్-వరల్డ్ ప్రాజెక్ట్: "Enterprise E-Commerce Product SKU & Dynamic Billing Engine"

ఈ మూడవ అధ్యాయంలో నేర్చుకున్న అన్ని అంశాలను (డేటా టైప్స్, డైనమిక్ టైపింగ్, id() మెమరీ ట్రాకింగ్, టైప్ కాస్టింగ్, Truthiness, మల్టిపుల్ అసైన్‌మెంట్) కలగలిపి — ఒక పూర్తి స్థాయి E-Commerce SKU & Dynamic Billing Engine ను నిర్మిద్దాం!

04_ecommerce_sku_billing_engine.py 
# =====================================================================
# చాప్టర్ 03 ప్రాజెక్ట్: Enterprise E-Commerce Product SKU & Dynamic Billing
# కాన్సెప్ట్స్: All Primitive Types, Dynamic Typing, id() Memory Check,
#             Explicit Type Casting, Swapping, Formatted Receipt Output
# =====================================================================

def generate_invoice(sku_code: str, title: str, raw_price: str, raw_qty: str, is_prime_member: bool):
    """
    ఉత్పత్తి డేటాను వాలిడేట్ చేసి, టైప్ కాస్టింగ్ ద్వారా బిల్లును గణిస్తుంది.
    """
    print("=" * 65)
    print("        🛒 QUICK-MART E-COMMERCE BILLING ENGINE (2026)")
    print("=" * 65)

    # 1. ఎక్స్‌ప్లిసిట్ టైప్ కాస్టింగ్ (యూజర్ స్ట్రింగ్స్ నుండి న్యూమరిక్ డేటా టైప్స్)
    unit_price: float = float(raw_price)
    quantity: int = int(raw_qty)

    # 2. మల్టిపుల్ అసైన్‌మెంట్ & గణనలు
    subtotal: float = unit_price * quantity
    gst_tax_rate: float = 0.18 # 18% GST టాక్స్
    tax_amount: float = subtotal * gst_tax_rate

    # 3. బూలియన్ Truthiness ద్వారా ప్రైమ్ డిస్కౌంట్
    discount: float = 0.0
    if is_prime_member:
        discount = subtotal * 0.10 # 10% VIP ప్రైమ్ డిస్కౌంట్

    final_total: float = subtotal + tax_amount - discount

    # 4. ఆబ్జెక్ట్ మెమరీ అడ్రస్ ఆడిట్ (id() మరియు type() తనిఖీ)
    print(f"  • SKU కోడ్     : {sku_code} [Type: {type(sku_code).__name__}]")
    print(f"  • ఐటెమ్ పేరు     : {title} [Memory ID: {id(title)}]")
    print(f"  • యూనిట్ ధర     : ₹ {unit_price:.2f} [Type: {type(unit_price).__name__}]")
    print(f"  • పరిమాణం (Qty) : {quantity} [Type: {type(quantity).__name__}]")
    print(f"  • ప్రైమ్ మెంబర్ : {'అవును (VIP)' if is_prime_member else 'కాదు'}")
    print("-" * 65)
    print(f"  సబ్‌టోటల్ (Subtotal)          : ₹ {subtotal:>10.2f}")
    print(f"  GST పన్ను (18%)              : ₹ {tax_amount:>10.2f}")
    print(f"  ప్రైమ్ లాయల్టీ తగ్గింపు (10%) : -₹ {discount:>9.2f}")
    print("=" * 65)
    print(f"  💰 చెల్లించాల్సిన తుది మొత్తం : ₹ {final_total:>10.2f}")
    print("=" * 65)

if __name__ == "__main__":
    # యూజర్ వెబ్ ఫారమ్ నుండి స్ట్రింగ్స్ రూపంలో వచ్చిన డేటా సిమ్యులేషన్
    input_sku = "SKU-ELE-9081"
    input_title = "సోనీ వైర్‌లెస్ హెడ్‌ఫోన్స్ (Noise Cancelling)"
    input_price_str = "12499.50"  # స్ట్రింగ్ డేటా
    input_qty_str = "2"           # స్ట్రింగ్ డేటా
    is_vip = True                 # బూలియన్ డేటా

    generate_invoice(
        sku_code=input_sku,
        title=input_title,
        raw_price=input_price_str,
        raw_qty=input_qty_str,
        is_prime_member=is_vip
    )

    print("\n✅ బిల్లింగ్ ఇంజిన్ విజయవంతంగా ఎగ్జిక్యూట్ అయ్యింది!\n")

★ ఈ అధ్యాయంపై ప్రాక్టీస్ క్విజ్ (Knowledge Check)

1. పైథాన్‌లో వేరియబుల్స్ అనేవి మెమరీ బాక్స్‌లు కావు అని ఎందుకు అంటారు?
సమాధానం: C++/Java లో వేరియబుల్ అనేది మెమరీలో డేటాను నిల్వ చేసే నిర్దిష్ట బాక్స్. కానీ పైథాన్‌లో ప్రతిదీ ఒక ఆబ్జెక్ట్! డేటా ఎల్లప్పుడూ హీప్ మెమరీలో ఆబ్జెక్ట్‌గా ఉంటుంది; వేరియబుల్స్ కేవలం ఆ ఆబ్జెక్టుల మెమరీ అడ్రస్‌లను పాయింట్ చేసే లేబుల్స్ లేదా రిఫరెన్సెస్ (Name Bindings) మాత్రమే.
2. '==' ఆపరేటర్‌కు మరియు 'is' ఆపరేటర్‌కు మధ్య ప్రాథమిక తేడా ఏమిటి?
సమాధానం: == ఆపరేటర్ రెండు వేరియబుల్స్‌లోని విలువలను (Values) పోల్చి సమానమైతే True ఇస్తుంది. కానీ is ఆపరేటర్ రెండు వేరియబుల్స్ మెమరీలో ఒకే ఆబ్జెక్ట్‌ను (Same Memory Address via id()) పాయింట్ చేస్తున్నాయా లేదా అని పోల్చుతుంది.
3. C++ తో పోలిస్తే Python 3 లో 'int' డేటా టైప్‌కు ఉన్న అసాధారణ సూపర్-పవర్ ఏమిటి?
సమాధానం: ఆర్బిట్రరీ ప్రెసిషన్ (Arbitrary Precision)! C++ లేదా Java లో 64-bit లాంగ్ ఇంటీజర్ గరిష్ట పరిమితి దాటితే ఓవర్‌ఫ్లో ఎర్రర్ వస్తుంది. కానీ Python 3 లో ఇంటీజర్ పరిమాణానికి ఎటువంటి పరిమితి లేదు; కంప్యూటర్ RAM లో స్థలం ఉన్నంతవరకు 2 ** 1000 లాంటి వందల అంకెల సంఖ్యలను కూడా ఎటువంటి ఓవర్‌ఫ్లో లేకుండా ఖచ్చితంగా గణిస్తుంది.
4. పైథాన్‌లో Falsy విలువలు ఏవి? కనీసం 4 ఉదాహరణలు ఇవ్వండి.
సమాధానం: బూలియన్ సందర్భంలో False గా పరిగణించబడే విలువలను Falsy అంటారు. ఉదాహరణలు: 1) None, 2) False, 3) సంఖ్య సున్నా (0, 0.0), 4) ఖాళీ స్ట్రింగ్ (""), 5) ఖాళీ లిస్ట్ ([]) లేదా ఖాళీ డిక్షనరీ ({}). ఇవి తప్ప మిగిలినవన్నీ Truthy విలువలే.
5. పైథాన్‌లో స్ట్రింగ్స్ (str) మరియు ఇంటీజర్స్ (int) ఇమ్మ్యుటబుల్ అని ఎందుకు అంటారు?
సమాధానం: ఇమ్మ్యుటబుల్ అంటే మెమరీలో ఒకసారి సృష్టించబడిన తర్వాత ఆ ఆబ్జెక్ట్ లోపలి డేటాను మార్చలేము. ఉదాహరణకు x = 10 తర్వాత x = x + 5 అని రాస్తే, పాత 10 ఆబ్జెక్ట్ 15 గా మారదు; మెమరీలో సరికొత్త 15 ఆబ్జెక్ట్ తయారై x అనే లేబుల్ దాని వైపు తిరుగుతుంది. పాత 10 ఆబ్జెక్ట్ మెమరీ అడ్రస్ అలాగే ఉంటుంది.
