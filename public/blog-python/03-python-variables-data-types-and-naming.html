Python Variables & Data Types (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 3 of 65 📂 Phase 1: Python Basics 📅 2026 Edition
📌 Covered in this chapter: Variables as References · Dynamic Typing · Memory Identity (id, is vs ==) · Swapping · Type Checking
Python లో వేరియబుల్స్ మెమరీ పాయింటర్స్ లాగా ఎలా పనిచేస్తాయి, Dynamic typing అంటే ఏంటి, id() వాడి మెమరీ చెక్ చేయడం, మరియు సింగిల్ లైన్ లో వేరియబుల్స్ ని మార్చడం (Swapping) గురించి తెలుసుకుందాం.
1Variables అంటే మెమరీ కి పాయింటర్లు

C లేదా Java లో వేరియబుల్ అంటే ఒక డబ్బా లాంటిది. కానీ Python లో వేరియబుల్స్ అంటే మెమరీలో ఉన్న డేటాని పాయింట్ చేసే ఒక పేరు లేదా లేబుల్ (reference pointer) లాంటివి.

CPython లో ప్రతీ ఆబ్జెక్ట్ లోపల 3 విషయాలు సేవ్ అయ్యి ఉంటాయి:

  1. Type: ఇది నెంబరా, టెక్స్టా? అని చెప్తుంది.
  2. Reference Count: ఈ డేటాని ఎన్ని వేరియబుల్స్ పాయింట్ చేస్తున్నాయి? అనేది కౌంట్ చేస్తుంది. (ఇది 0 ఐతే Garbage Collector దాన్ని డిలీట్ చేస్తుంది).
  3. Value: అసలైన డేటా.
💻 Example 1: Variables of Different Data Types
Python 3 ▶ Run in Compiler 
# 4 రకాల ముఖ్యమైన డేటా టైప్స్:
student_name = "Alex"      # str (Text string)
age = 20                   # int (Whole integer number)
account_balance = 1450.75  # float (Decimal number)
is_enrolled = True         # bool (Boolean True or False)

# వీటిని ప్రింట్ చేసి వాటి Type ఏంటో చూద్దాం:
print("Student Name:", student_name, "| Data Type:", type(student_name).__name__)
print("Age:", age, "| Data Type:", type(age).__name__)
print("Balance: Rs.", account_balance, "| Data Type:", type(account_balance).__name__)
print("Is Enrolled:", is_enrolled, "| Data Type:", type(is_enrolled).__name__)
🔍 Type బ్రేక్ డౌన్:
  • str: కోట్స్ లో ఉండే టెక్స్ట్ (స్ట్రింగ్).
  • int: పాయింట్స్ లేని మామూలు నెంబర్స్.
  • float: దశాంశ స్థానాలు (డెసిమల్స్) ఉండే నెంబర్స్.
  • bool: అవును లేదా కాదు (True or False).
2Dynamic Typing అంటే ఏంటి?

Python అనేది dynamically typed లాంగ్వేజ్. అంటే ఒక వేరియబుల్ లో ముందు నెంబర్ పెట్టి, ఆ తర్వాత అదే వేరియబుల్ లో టెక్స్ట్ పెట్టినా ఎర్రర్ రాదు:

💻 Example 2: Dynamic Rebinding in Python
Python 3 ▶ Run in Compiler 
# ఒకే వేరియబుల్ కి వేరే వేరే డేటా ఇద్దాం:
data = 42
print("1. Value:", data, "| Type:", type(data))

data = "Now I am a text string!"
print("2. Value:", data, "| Type:", type(data))

data = [10, 20, 30]
print("3. Value:", data, "| Type:", type(data))
🔍 ముఖ్య గమనిక:

Python లో డేటా కి టైప్ ఉంటుంది కానీ, వేరియబుల్ కి టైప్ ఉండదు! వేరియబుల్ అనేది డేటా కి తగిలించిన ఒక ట్యాగ్ మాత్రమే.

3మెమరీ లో ఏముంది? id() మరియు "is" vs "=="

Python లో ప్రతీ ఆబ్జెక్ట్ కి ఒక మెమరీ అడ్రస్ ఉంటుంది. దాన్ని id() వాడి చూడొచ్చు:

  • == (Value Equality): రెండు వేరియబుల్స్ లోపల ఉన్న డేటా ఒకటేనా? అని చెక్ చేస్తుంది.
  • is (Identity Equality): రెండు వేరియబుల్స్ మెమరీ లో ఒకే చోట (ఒకే అడ్రస్) ఉన్నాయా? అని చెక్ చేస్తుంది.
💻 Example 3: Memory Inspection with id()
Python 3 ▶ Run in Compiler 
# ఒకే రకమైన డేటా ఉన్న రెండు లిస్ట్ లు:
list1 = [1, 2, 3]
list2 = [1, 2, 3]
list3 = list1  # list3 కి list1 నే అసైన్ చేసాం!

print("list1 == list2 (డేటా సేమ్ ఆ?):", list1 == list2) # True
print("list1 is list2 (అడ్రస్ సేమ్ ఆ?):", list1 is list2)   # False (రెండు వేరు వేరు లిస్ట్ లు!)
print("list1 is list3 (అడ్రస్ సేమ్ ఆ?):", list1 is list3)  # True

print("\nMemory Address list1:", id(list1))
print("Memory Address list2:", id(list2))
print("Memory Address list3:", id(list3))
🔍 Pro Tip:

నెంబర్స్, స్ట్రింగ్స్, లిస్ట్స్ ని పోల్చడానికి ఎప్పుడూ == వాడాలి. is ని కేవలం None, True, లేదా False లాంటి వాటికి మాత్రమే వాడాలి.

4సింగిల్ లైన్ లో Variables ని స్వ్యాప్ (Swap) చేయడం

C/Java లాంటి భాషల్లో a మరియు b ని మార్చాలంటే మూడో వేరియబుల్ (temp) వాడాలి. కానీ Python లో ఒకే లైన్ లో ఈజీగా చేయవచ్చు:

💻 Example 4: Swapping Variables in One Line
Python 3 ▶ Run in Compiler 
x = 10
y = 20
print(f"Before swap: x = {x}, y = {y}")

# ఒకే లైన్ లో x ని y కి, y ని x కి మారుద్దాం:
x, y = y, x

print(f"After swap:  x = {x}, y = {y}")
🔍 ఇదెలా పనిచేస్తుంది:

కుడి వైపు ఉన్న y, x ముందే ఒక ట్యూపుల్ (20, 10) ని క్రియేట్ చేసి, ఆ తర్వాత వాటిని ఎడమ వైపు ఉన్న x మరియు y లోపలికి ఒకేసారి సేవ్ చేస్తుంది.

⚠️ Common Developer Pitfall: Keywords ని పేర్లుగా వాడటం

వేరియబుల్స్ కి ఎప్పుడూ list, str, int లాంటి పేర్లు పెట్టకూడదు. అలా పెడితే Python ఆ built-in ఫంక్షన్స్ ని మర్చిపోయి క్రాష్ అవుతుంది. (TypeError వస్తుంది).

❓ Frequently Asked Questions (FAQ)

Q Dynamic Typing కి Static Typing కి తేడా ఏంటి?

Static typing (C, Java) లో మనం ముందుగానే డేటా టైప్ చెప్పాలి, తర్వాత దాన్ని మార్చలేము. Dynamic typing (Python) లో అలా చెప్పక్కర్లేదు, ప్రోగ్రామ్ రన్ అవుతున్నప్పుడు దానంతట అదే టైప్ మార్చుకుంటుంది.

Q id(256) == id(256) ట్రూ అవుతుంది, కానీ పెద్ద నెంబర్స్ కి ఫాల్స్ ఎందుకు వస్తుంది?

CPython లో -5 నుంచి 256 వరకు ఉన్న నెంబర్స్ ని ముందుగానే సేవ్ చేసి ఉంచుతారు. అవే నెంబర్స్ వస్తే మళ్ళీ కొత్త అడ్రస్ ఇవ్వకుండా పాత అడ్రస్ నే ఇస్తుంది. దీన్ని ఇంటర్నింగ్ అంటారు.
