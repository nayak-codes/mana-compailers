1Machine Learning అంటే ఏంటి? (Supervised vs Unsupervised)

మామూలు ప్రోగ్రామింగ్ లో మనం రూల్స్ రాసి కంప్యూటర్ కి ఇస్తాం, అది ఆన్సర్స్ చెప్తుంది. కానీ Machine Learning (ML) లో మనం డేటా, ఆన్సర్స్ ఇస్తాం.. కంప్యూటరే వాటి మధ్య ఉన్న రూల్స్ ని (ప్యాట్రన్స్ ని) నేర్చుకుని ఒక మోడల్ ని తయారు చేస్తుంది!

దీనిలో 3 రకాలు:

  1. Supervised Learning: ఇది టీచర్ పాఠం చెప్పినట్టు. డేటా (X) తో పాటు కరెక్ట్ ఆన్సర్స్ (y) కూడా ఇస్తాం.
    • Regression: నెంబర్స్ ని ప్రిడిక్ట్ చేయడం (ఉదా: ఈ ఇల్లు ఎంత ధరకు పోతుంది?).
    • Classification: కేటగిరీలని కనుక్కోవడం (ఉదా: ఇది స్పామ్ ఈమెయిలా కాదా?).
  2. Unsupervised Learning: దీనిలో ఆన్సర్స్ ఇవ్వం (యూట్యూబ్ రికమండేషన్స్ లాగా). అది డేటాని చూసి ఏది ఏ గ్రూప్ కి చెందుతుందో అదే డిసైడ్ అవుతుంది (ఉదా: కస్టమర్లని డిఫరెంట్ గ్రూప్స్ గా విడదీయడం).
  3. Reinforcement Learning: రోబోట్స్ నడవడం నేర్చుకోవడం, గేమ్స్ ఆడటం (తప్పు చేస్తే మైనస్ మార్కులు, కరెక్ట్ చేస్తే ప్లస్ మార్కులు).

💻 Example 1: End-to-End Linear Regression Architecture Implementation
Python 3 ▶ Run in Compiler 
# Linear Regression (y = mx + c) ఎలా పనిచేస్తుందో సింపుల్ లాజిక్:
class SimpleLinearRegression:
    def __init__(self):
        self.m = 0 # స్లోప్ (ఎంత పెరుగుతుంది)
        self.c = 0 # స్టార్టింగ్ పాయింట్

    def fit(self, X_train, y_train):
        # ఇక్కడే అది ఆ ఫార్ములా కి తగ్గ నెంబర్స్ ని నేర్చుకుంటుంది (M అండ్ C)
        n = len(X_train)
        mean_x = sum(X_train) / n
        mean_y = sum(y_train) / n
        
        num = sum((x - mean_x) * (y - mean_y) for x, y in zip(X_train, y_train))
        den = sum((x - mean_x) ** 2 for x in X_train)
        self.m = num / den
        self.c = mean_y - (self.m * mean_x)
        print(f"🤖 మోడల్ నేర్చుకుంది: y = {self.m:.2f}x + {self.c:.2f}")

    def predict(self, X_test):
        return [self.m * x + self.c for x in X_test]

# 1. డేటా: ఎన్ని ఏళ్ళ ఎక్స్పీరియన్స్ ఉంటే ఎంత శాలరీ వస్తుంది?
X_experience = [1, 2, 3, 4, 5]
y_salary =     [40, 50, 65, 75, 90] # వేలలో

# 2. మోడల్ కి నేర్పించడం:
model = SimpleLinearRegression()
model.fit(X_experience, y_salary)

# 3. కొత్త వాళ్లకి శాలరీ చెప్పడం (6, 8 ఏళ్ళ ఎక్స్పీరియన్స్ ఉంటే?):
unseen = [6, 8]
predictions = model.predict(unseen)

print("\n--- 📈 కొత్త డేటాకి ప్రిడిక్షన్స్ ---")
for exp, pred in zip(unseen, predictions):
    print(f"• ఎక్స్పీరియన్స్: {exp} yrs -> వస్తుందని అంచనా శాలరీ: ₹{pred:,.2f}k")
🔍 Scikit-Learn సింప్లిసిటీ:

నిజమైన లైబ్రరీ వాడినప్పుడు ఇంత కోడ్ రాయక్కర్లేదు. ఏ అల్గారిథమ్ కైనా model.fit() అని ఇస్తే నేర్చుకుంటుంది, model.predict() అని ఇస్తే ఆన్సర్ చెప్తుంది. అంతే సింపుల్!

2మోడల్ ఎంత బాగా పనిచేస్తుందో టెస్ట్ చేయడం (Accuracy, Precision)

మోడల్ కి 99% Accuracy వచ్చింది అని గుడ్డిగా నమ్మకూడదు. (ఒక హాస్పిటల్ డేటాలో 100 మందిలో 1కి క్యాన్సర్ ఉంటే, "ఎవరికీ లేదు" అని చెప్పినా 99% అక్యూరసీ వస్తుంది, కానీ అది పెద్ద తప్పు కదా!). అందుకే ఇవి వాడతారు:

పేరుఎందుకు?
Accuracyఅన్నిటిలో ఎన్ని కరెక్ట్ గా చెప్పింది? (డేటా బ్యాలెన్స్ గా ఉన్నప్పుడు).
Precision"తప్పుగా ఎవరినీ పనిష్ చేయకూడదు" అనుకున్నప్పుడు (స్పామ్ ఫిల్టర్స్ కి).
Recall"ఏ ఒక్క అసలైన కేసు కూడా మిస్ అవ్వకూడదు" అనుకున్నప్పుడు (క్యాన్సర్ టెస్టింగ్ లాంటివి).
💻 Example 2: Classification Performance Metrics & Confusion Matrix
Python 3 ▶ Run in Compiler 
# కన్ఫ్యూజన్ మ్యాట్రిక్స్ సిమ్యులేషన్ (హాస్పిటల్ రిపోర్ట్):
TP = 85  # క్యాన్సర్ ఉంది అని కరెక్ట్ గా చెప్పినవి
FP = 10  # హెల్తీ గా ఉన్నా క్యాన్సర్ ఉందని తప్పుగా చెప్పినవి
FN = 5   # క్యాన్సర్ ఉన్నా "హెల్తీ" అని డేంజర్ తప్పు చేసినవి!
TN = 900 # హెల్తీ అని కరెక్ట్ గా చెప్పినవి

accuracy = (TP + TN) / (TP + FP + FN + TN)
precision = TP / (TP + FP)
recall = TP / (TP + FN)
f1 = 2 * (precision * recall) / (precision + recall)

print("--- 🩺 మెడికల్ మోడల్ రిపోర్ట్ ---")
print(f"• Accuracy:  {accuracy * 100:.2f}%")
print(f"• Precision: {precision * 100:.2f}% (క్యాన్సర్ అని చెప్పిన వాటిలో నిజంగా ఉన్నవాళ్ళు)")
print(f"• Recall:    {recall * 100:.2f}% (అసలు కేసుల్లో ఎన్ని పట్టుకుంది)")
🔍 Model Save చేయడం (joblib):

ఒక మోడల్ కి నేర్పించడానికి గంటల టైమ్ పడుతుంది. ప్రతిసారీ నేర్పించలేం కాబట్టి దాన్ని joblib.dump() వాడి ఒక ఫైల్ లా సేవ్ చేసి యాప్స్ లో వాడుకుంటాం.

⚠️ Common Developer Pitfall: నేర్పించిన డేటా తోనే టెస్ట్ చేయడం

స్టూడెంట్ కి ఒక బుక్ ఇచ్చి చదవమని, ఎగ్జామ్ లో అవే క్వశ్చన్స్ ఇస్తే 100 మార్కులు వస్తాయి. కానీ బయటనుంచి ఇస్తే ఫెయిల్ అవుతాడు (దీన్నే Overfitting అంటారు). అందుకే మనం ఎప్పుడూ `train_test_split` వాడి 20% డేటాని దాచిపెట్టి (టెస్ట్ సెట్), దాని మీద మాత్రమే మార్కులు వేయాలి.

MSE (Mean Squared Error) ఎంత ఉందో క్యాలిక్యులేట్ చేయండి: అసలు ప్రైసెస్ [50, 80], మనం గెస్ చేసినవి [48, 85].

predicted = [48, 85]

rmse = mse ** 0.5

print(f"ఆవరేజ్ ఎర్రర్ (RMSE): ₹{rmse:.2f} తేడాతో తప్పు చెప్తుంది")

❓ Frequently Asked Questions (FAQ)

Q StandardScaler ఎందుకు వాడాలి?

శాలరీ అనేది 1,00,000 లాగా పెద్ద నెంబర్, ఏజ్ అనేది 25 లాగా చిన్న నెంబర్. మోడల్ కి శాలరీ ఏమో పెద్ద విషయం అనుకుని కన్ఫ్యూజ్ అవుతుంది. దాన్ని ఆపడానికే అన్ని నెంబర్స్ ని 0, 1 ల మధ్యలోకి తీసుకువస్తాం (స్కేలింగ్).

Q Bagging, Boosting అంటే ఏంటి?

Random Forest (Bagging) అంటే ఒకేసారి 100 చెట్ల (మోడల్స్) కి నేర్పించి ఓటింగ్ వేయడం. XGBoost (Boosting) అంటే ఒక మోడల్ చేసిన తప్పుని రెండో మోడల్, అది చేసిన తప్పుని మూడో మోడల్.. ఇలా వరుసగా నేర్చుకుంటూ పర్ఫెక్ట్ గా అవ్వడం.
