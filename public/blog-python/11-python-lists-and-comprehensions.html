Python Lists & Comprehensions (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 11 of 65 📂 Phase 3: Strings and Collections 📅 2026 Edition
📌 Covered in this chapter: Creation · Indexing · CRUD · Sorting · Copying (Shallow vs Deep) · Nested Lists · List Comprehensions
Python లో Lists ఎలా పనిచేస్తాయి? అందులో డేటా యాడ్ చేయడం, డిలీట్ చేయడం, సార్ట్ (sort) చేయడం, షాలో vs డీప్ కాపీ, మరియు సింగిల్ లైన్ List Comprehensions గురించి తెలుసుకుందాం.
1List అంటే ఏంటి? (Dynamic Array Architecture)

Python లో list (list) అంటే స్క్వేర్ బ్రాకెట్స్ ([...]) లోపల పెట్టుకునే ఒక ఆర్డర్ ఉన్న, మార్చగలిగే (mutable), అన్ని రకాల డేటాని కలిపి ఉంచుకోగల కలెక్షన్.

  • Ordered: మనం ఏ ఆర్డర్ లో యాడ్ చేసామో అదే ఆర్డర్ లో సేవ్ అవుతాయి.
  • Mutable: కొత్త లిస్ట్ క్రియేట్ చేయకుండానే, ఉన్న లిస్ట్ లోకే యాడ్ చేయడం, డిలీట్ చేయడం చేయొచ్చు.
  • Heterogeneous: ఒకే లిస్ట్ లో నెంబర్స్, స్ట్రింగ్స్, బూలియన్స్ లాంటివి ఏవైనా కలిపి పెట్టుకోవచ్చు.
💻 Example 1: Creating Lists with Mixed Data Types
Python 3 ▶ Run in Compiler 
# 1. ఒక ఖాళీ లిస్ట్ మరియు కొన్ని డేటా ఉన్న లిస్ట్స్
empty_list = []
numbers = [10, 20, 30, 40, 50]
mixed_list = ["Balaji", 25, 99.5, True, ["Python", "JS"]]

# 2. లిస్ట్ ని, దాని పొడవు (లెంత్) ని చూద్దాం
print("Numbers list:", numbers)
print("Total elements:", len(numbers))
print("Mixed list:", mixed_list)
🔍 లోపల ఏం జరుగుతుంది? (CPython):

CPython లో లిస్ట్ అనేది ఒక డైనమిక్ అర్రే (Dynamic Array). లిస్ట్ లో ప్లేస్ అయిపోతే, దానంతట అదే ఆటోమాటిక్ గా ఇంకొంచెం పెద్ద సైజు ఉన్న మెమరీని తీసుకుని పాత డేటాని అందులోకి షిఫ్ట్ చేస్తుంది.

2లిస్ట్ లోకి డేటా యాడ్ చేయడం: append(), insert(), extend()

ఒక లిస్ట్ లోకి కొత్త ఐటమ్స్ యాడ్ చేయడానికి మనకు 3 పద్ధతులు ఉన్నాయి:

  • list.append(x): లిస్ట్ కి చిట్టచివర్లో యాడ్ చేస్తుంది (చాలా ఫాస్ట్).
  • list.insert(index, x): మనకు కావాల్సిన పొజిషన్ లో యాడ్ చేస్తుంది, మిగతా వాటిని పక్కకి జరుపుతుంది.
  • list.extend(iterable): ఇంకొక లిస్ట్ లోని ఐటమ్స్ అన్నిటినీ విడగొట్టి చివర్లో కలుపుతుంది.
💻 Example 2: Adding Elements with append, insert, extend
Python 3 ▶ Run in Compiler 
fruits = ["Apple", "Banana"]
print("Initial list:", fruits)

# 1. append() - చివర్లో యాడ్ చేయడం
fruits.append("Mango")
print("After append('Mango'):", fruits)

# 2. insert() - 1వ ఇండెక్స్ లో యాడ్ చేయడం
fruits.insert(1, "Orange")
print("After insert(1, 'Orange'):", fruits)

# 3. extend() - వేరే లిస్ట్ ని కలపడం
more_fruits = ["Grapes", "Pineapple"]
fruits.extend(more_fruits)
print("After extend():", fruits)
🔍 append() vs extend() Trap:

ఒకవేళ మీరు fruits.append(["Grapes", "Pineapple"]) అని రాస్తే, ఆ లిస్ట్ మొత్తం ఒకే ఐటెం లాగా లిస్ట్ లోపల లిస్ట్ గా పడిపోతుంది! విడివిడిగా కలవాలంటే extend() వాడాలి.

3అప్డేట్ మరియు డిలీట్ చేయడం: pop(), remove(), del, clear()

లిస్ట్ లోని డేటాని తీసేయడానికి ఈ మెథడ్స్ వాడతారు:

  • list[index] = new_val: ఒక పొజిషన్ లో ఉన్న వాల్యూ ని రీప్లేస్ చేస్తుంది.
  • list.remove(val): మనం వెతుకుతున్న వాల్యూ ఎక్కడున్నా (మొదటిది) వెతికి డిలీట్ చేస్తుంది.
  • list.pop(index): ఆ ఇండెక్స్ లో ఉన్న దాన్ని డిలీట్ చేయడమే కాకుండా, దాన్ని బయటికి ఇస్తుంది.
  • del list[index]: డైరెక్ట్ గా మెమరీ లోనుంచే లేపేస్తుంది.
  • list.clear(): లిస్ట్ మొత్తాన్ని ఖాళీ చేస్తుంది.
💻 Example 3: Updating and Removing Elements
Python 3 ▶ Run in Compiler 
tasks = ["Email client", "Write code", "Bug fix", "Deploy app"]
print("Initial tasks:", tasks)

# 1. 0 వ ఇండెక్స్ ని అప్డేట్ చేద్దాం
tasks[0] = "Check Slack messages"
print("After update tasks[0]:", tasks)

# 2. remove() పేరుతో డిలీట్
tasks.remove("Bug fix")
print("After remove('Bug fix'):", tasks)

# 3. pop() చివర్లో ఉన్నదాన్ని పీకేసి మనకు ఇస్తుంది
completed_task = tasks.pop()
print(f"Popped task: '{completed_task}' | Remaining: {tasks}")

# 4. del కీవర్డ్ తో డిలీట్
del tasks[0]
print("After del tasks[0]:", tasks)
🔍 ఏ డిలీట్ మెథడ్ ఎప్పుడు వాడాలి?
  • మీకు పేరు తెలిస్తే .remove(val) వాడండి.
  • మీకు నెంబర్ తెలిసి ఆ డిలీట్ అయిన వాల్యూ కూడా కావాలంటే .pop(i) వాడండి.
  • ఒక రేంజ్ మొత్తాన్ని లేపేయాలంటే del list[0:2] వాడండి.
4సార్ట్ (Sort) చేయడం: sort() vs sorted()

పైథాన్ లో నెంబర్స్ లేదా అక్షరాల్ని ఒక ఆర్డర్ లో పెట్టడానికి రెండు పద్ధతులు ఉన్నాయి (వీటి వెనుక Timsort అల్గారిథం ఉంది):

  • list.sort(): ఒరిజినల్ లిస్ట్ నే డైరెక్ట్ గా మారుస్తుంది (దీని రిజల్ట్ None).
  • sorted(iterable): ఇది ఒరిజినల్ దాన్ని మార్చకుండా, కొత్త సార్ట్ అయిన లిస్ట్ ని ఇస్తుంది!
💻 Example 4: Sorting In-Place (sort) vs Non-Destructive (sorted)
Python 3 ▶ Run in Compiler 
scores = [45, 99, 12, 78, 63, 85]

# 1. sorted() కొత్త లిస్ట్ ని ఇస్తుంది:
ascending_scores = sorted(scores)
descending_scores = sorted(scores, reverse=True)

print("Original scores list:", scores)
print("New sorted list (ascending):", ascending_scores)
print("New sorted list (descending):", descending_scores)

# 2. .sort() ఒరిజినల్ దాన్నే మార్చేస్తుంది:
scores.sort()
print("\nOriginal scores after .sort():", scores)
🔍 కామన్ బిగినర్ తప్పు:

ఎప్పుడూ scores = scores.sort() అని రాయకండి! ఎందుకంటే .sort() ఏం రిటర్న్ చేయదు (None), అలా రాస్తే మీ లిస్ట్ మొత్తం పోయి None సేవ్ అవుతుంది.

5లిస్ట్ ని కాపీ చేయడం: Shallow Copy కాన్సెప్ట్

list_b = list_a అని రాసినప్పుడు, పైథాన్ లిస్ట్ ని కాపీ చేయదు. రెండు పేర్లకి ఒకే మెమరీ అడ్రస్ ని ఇస్తుంది. అంటే list_b లో డేటా మారిస్తే list_a లో కూడా మారిపోతుంది!

ఒక నిజమైన విడిగా ఉండే కాపీ కావాలంటే .copy() లేదా [:] వాడాలి:

💻 Example 5: List Copying and Reference Isolation
Python 3 ▶ Run in Compiler 
# ❌ ఇదొక బగ్ (Reference Alias):
original = [1, 2, 3]
alias = original
alias.append(99)
print("Reference Alias Demo:")
print("Original:", original)  # ఇక్కడ కూడా 99 యాడ్ అయిపోయింది!
print("Alias:   ", alias)

# ✅ సేఫ్ అయిన SHALLOW COPY:
source = [10, 20, 30]
cloned = source.copy()  # లేదా source[:] అని రాయొచ్చు
cloned.append(999)

print("\nIndependent Copy Demo:")
print("Source:", source)  # [10, 20, 30] (ఇది సేఫ్!)
print("Cloned:", cloned)  # [10, 20, 30, 999]
🔍 Deep Copy గురించి:

మీ లిస్ట్ లోపల ఇంకో లిస్ట్ ఉంటే (ఉదా: [[1, 2], [3, 4]]), అప్పుడు .copy() పనిచేయదు. import copy; copy.deepcopy(matrix) వాడాలి.

6Python List Comprehensions ([expr for x in list if cond])

List comprehensions వాడి పాత లిస్ట్ నుండి కొత్త లిస్ట్ ని ఒకే ఒక లైన్ లో అద్భుతంగా, ఫాస్ట్ గా క్రియేట్ చేయొచ్చు.

సింటాక్స్: [ లాజిక్ for ఐటెం in లిస్ట్ if కండిషన్ ]
💻 Example 6: List Comprehensions Filtering & Transformation
Python 3 ▶ Run in Compiler 
# పాత పద్ధతి (5 లైన్స్ ఫర్ లూప్):
squares_traditional = []
for x in range(1, 11):
    if x % 2 == 0:
        squares_traditional.append(x ** 2)

# ✅ కొత్త పద్ధతి (List Comprehension ఒకే లైన్ లో):
squares_comprehension = [x ** 2 for x in range(1, 11) if x % 2 == 0]

print("Traditional Loop Result:", squares_traditional)
print("Comprehension Result:   ", squares_comprehension)

# ఇంకో ఉదాహరణ (పొడవాటి పేర్లను క్యాపిటల్ చేయడం):
names = ["Alex", "Balaji", "Chloe", "David", "Elizabeth"]
long_names = [n.upper() for n in names if len(n) >= 6]
print("Uppercase Long Names (len >= 6):", long_names)
🔍 పెర్ఫార్మన్స్ లాభం:

List comprehensions వాడటం వల్ల పైథాన్ PVM లో C లాంగ్వేజ్ స్పీడ్ తో ఇవి రన్ అవుతాయి. మాటిమాటికి .append() కాల్ చేయడం తప్పుతుంది.

⚠️ Common Developer Pitfall: లూప్ రన్ అవుతున్న లిస్ట్ లోంచే ఐటమ్స్ డిలీట్ చేయడం

ఎప్పుడూ (for x in lst:) రన్ అవుతున్న లిస్ట్ లోంచి డేటాని (lst.remove(x)) తీయకూడదు. తీస్తే ఇండెక్స్ జరిగిపోయి ఐటమ్స్ స్కిప్ అవుతాయి. డిలీట్ చేయాలంటే దాని కాపీ మీద రన్ చేయాలి: (for x in lst.copy():) లేదా List Comprehension వాడాలి.

❓ Frequently Asked Questions (FAQ)

Q append() కి insert(0, x) కి స్పీడ్ తేడా ఉందా?

చాలా ఉంది! append() అనేది O(1) టైమ్ (చాలా ఫాస్ట్). insert(0, x) అంటే ఫస్ట్ పొజిషన్ లోకి నెట్టడం కాబట్టి, మిగతా నెంబర్స్ అన్నీ కుడిపక్కకి జరగాలి (O(N) టైమ్).

Q ఒకే నెంబర్ లిస్ట్ లో పదిసార్లు ఉంటే అన్నిటినీ తీసేయడం ఎలా?

List comprehension వాడటమే బెస్ట్: cleaned = [x for x in my_list if x != target_val]

Q లిస్ట్ లోపల లిస్ట్ పెట్టొచ్చా?

కచ్చితంగా! దీన్నే 2D matrices (grid = [[1, 2], [3, 4]]) అంటారు. ఇలా ఎంత లోపలికైనా పెట్టుకుంటూ వెళ్లొచ్చు.
