Web Scraping & Browser Automation (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 60 of 65 📂 Phase 12: Automation and Professional Skills 📅 2026 Edition
📌 Covered in this chapter: HTML DOM Structure · BeautifulSoup4 Parsing · CSS Selectors · Browser Automation (Selenium/Playwright) · Headless Chrome · Rate Limiting & Ethical Scraping
ఇంటర్నెట్ లో ఉన్న డేటాని ఆటోమాటిక్ గా కాపీ చేసుకోవడం (Web Scraping) ఎలా? బ్రౌజర్ ని మనమే ఓపెన్ చేయకుండా కోడ్ ద్వారా ఎలా ఆపరేట్ చేయాలో (Selenium / Playwright) నేర్చుకుందాం.
1Web Scraping అంటే ఏంటి? (BeautifulSoup4 వాడకం)

Web Scraping అంటే ఒక వెబ్ సైట్ కి వెళ్లి, అక్కడున్న ఇన్ఫర్మేషన్ ని కాపీ చేసుకుని మన ఎక్సెల్ షీట్ లోకి సేవ్ చేయడాన్ని ఆటోమేట్ చేయడం.

ఎక్కడ వాడతారు?

  • ప్రైస్ మానిటరింగ్: అమెజాన్, ఫ్లిప్కార్ట్ లో మనకు కావాల్సిన ప్రోడక్ట్ ధర ఎప్పుడు తగ్గుతుందో ఎప్పటికప్పుడు చెక్ చేయడానికి.
  • న్యూస్ లేదా స్టాక్స్: స్టాక్ మార్కెట్ సైట్స్ నుంచి ఎప్పటికప్పుడు లేటెస్ట్ డేటాని లాగడానికి.

దీని ప్రాసెస్ ఏంటి?:

ఏ వెబ్ సైట్ అయినా HTML తోనే తయారవుతుంది. మనం ఆ HTML కోడ్ ని తెచ్చుకుని, అందులో మనకు కావాల్సిన పదాన్ని వెతుక్కుంటాం. ఇందుకు BeautifulSoup4 అనే ప్యాకేజీ వాడతాం.

💻 Example 1: HTML DOM Parsing and Text Extraction
Python 3 ▶ Run in Compiler 
# Web Scraping సిమ్యులేషన్ (యాక్చువల్ వెబ్ సైట్ HTML డేటా):
from html.parser import HTMLParser

raw_html_mock = """


    

        
Mechanical Keyboard

        ₹2,499.00
        In Stock
    

    

        
4K Monitor 27-inch

        ₹28,999.00
        Out of Stock
    



"""

# ఈ కోడ్ HTML ని చదివి డేటాని బయటకు లాగుతుంది:
class SimpleScraper(HTMLParser):
    def __init__(self):
        super().__init__()
        self.products = []
        self.item = {}
        self.tag = None

    def handle_starttag(self, tag, attrs):
        self.tag = tag
        attr_dict = dict(attrs)
        if attr_dict.get("class") == "product-card":
            self.item = {"id": attr_dict.get("data-id")}

    def handle_data(self, data):
        text = data.strip()
        if text:
            if self.tag == "h2":
                self.item["title"] = text
            elif self.tag == "span" and "₹" in text:
                self.item["price"] = text
            elif self.tag == "span" and "Stock" in text:
                self.item["status"] = text
                if "title" in self.item:
                    self.products.append(self.item.copy())

scraper = SimpleScraper()
scraper.feed(raw_html_mock)

print("--- 🛒 వెబ్ సైట్ నుంచి కాపీ చేసిన డేటా ---")
for p in scraper.products:
    print(f"• ID #{p['id']}: {p['title']:22} | Price: {p['price']:>10} | Status: {p['status']}")
🔍 BeautifulSoup లాజిక్:

రియల్ ప్రాజెక్ట్స్ లో మనం soup.select('div.product-card h2') అని ఇస్తే ఆ ట్యాగ్ లో ఉన్న టెక్స్ట్ ని లాగేస్తుంది.

2Browser Automation (Selenium / Playwright)

కొన్ని వెబ్ సైట్స్ (React, Angular తో చేసినవి) డైరెక్ట్ గా HTML లో డేటా ఇవ్వవు. సైట్ ఓపెన్ అయ్యాక లోపల జావాస్క్రిప్ట్ రన్ అయ్యి అప్పుడు డేటా వస్తుంది. వాటికి BeautifulSoup పనిచేయదు.

పరిష్కారం ఏంటి?:

Selenium లేదా Playwright వాడతాం. ఇవి స్క్రీన్ మీద కనబడకుండానే (Headless Mode) క్రోమ్ బ్రౌజర్ ని ఓపెన్ చేసి, జావాస్క్రిప్ట్ అంతా రన్ అయ్యేదాకా వెయిట్ చేసి, ఆ తర్వాత డేటాని లాగుతాయి. బటన్స్ ని క్లిక్ చేయడం, లాగిన్ ఫారమ్స్ నింపడం అన్నీ చేయగలవు.

💻 Reference: Selenium Headless Browser Automation Architecture

# Playwright & Selenium కోడ్ బ్లూప్రింట్ (ఎలా రాస్తారో చూపించడానికి):
"""
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.chrome.options import Options
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

# 1. బ్రౌజర్ ని స్క్రీన్ మీద కనబడకుండా (Background) ఓపెన్ చేయడం:
options = Options()
options.add_argument("--headless=new") 

driver = webdriver.Chrome(options=options)

try:
    # 2. లాగిన్ పేజీకి వెళ్లడం:
    driver.get("https://example.com/login")

    # 3. పేజీ లోడ్ అయ్యేదాకా (గరిష్టంగా 10 సెకన్లు) వెయిట్ చేయడం:
    user_input = WebDriverWait(driver, 10).until(
        EC.presence_of_element_located((By.NAME, "username"))
    )

    # 4. యూజర్ నేమ్, పాస్ వర్డ్ నింపి బటన్ క్లిక్ చేయడం:
    user_input.send_keys("balaji_dev")
    driver.find_element(By.NAME, "password").send_keys("Secret123")
    driver.find_element(By.CSS_SELECTOR, "button[type='submit']").click()

    # 5. ప్రూఫ్ కోసం స్క్రీన్ షాట్ తీసుకోవడం:
    driver.save_screenshot("login_success.png")
    print("✅ లాగిన్ అయ్యి స్క్రీన్ షాట్ తీసుకుంది!")

finally:
    driver.quit() # పనైపోగానే కచ్చితంగా బ్రౌజర్ క్లోజ్ చేయాలి!
"""
print("Browser Automation బ్లూప్రింట్ లోడ్ అయ్యింది.")
🔍 time.sleep() వాడకండి:

10 సెకన్లు ఆగు అని ఫిక్స్డ్ టైమ్ ఇవ్వకూడదు (నెట్ ఫాస్ట్ ఉంటే టైమ్ వేస్ట్). పై కోడ్ లో లాగా Explicit Waits వాడితే, పేజీ లోడ్ అవ్వగానే నెక్స్ట్ లైన్ కి వెళ్ళిపోతుంది.

⚠️ Common Developer Pitfall: గ్యాప్ లేకుండా రిక్వెస్ట్స్ పంపడం (IP బ్లాక్ అవుతుంది)

కోడ్ రాశాం కదా అని సెకనుకి 100 సార్లు వెబ్ సైట్ ని హిట్ చేస్తే వాళ్ల సర్వర్ డౌన్ అవుతుంది (లేదా వాళ్లు మనల్ని బాట్ అనుకుని బ్లాక్ చేస్తారు). ఎప్పుడూ లూప్ లో `time.sleep(3)` లాంటివి పెట్టి గ్యాప్ ఇచ్చి డేటాని లాగాలి.

💻 Hands-on Interactive Practice Challenge

ఒక HTML టెక్స్ట్ లో నుంచి లింక్స్ (href="") ని బయటకు తీసే కోడ్ రాయండి.

Python 3 Practice Challenge ▶ Run in Compiler 
import re

sample_html = '''


  Home
  Courses
  GitHub


'''

# లింక్స్ ఫైండ్ చేయడానికి రెగ్యులర్ ఎక్స్ప్రెషన్ (Regex):
links = re.findall(r'href="([^"]+)"', sample_html)

print("బయటకు తీసిన లింక్స్:")
for link in links:
    print("•", link)

❓ Frequently Asked Questions (FAQ)

Q robots.txt అంటే ఏంటి?

ఏ వెబ్ సైట్ కైనా చివర /robots.txt అని ఇస్తే (ఉదా: google.com/robots.txt), మనం ఏ పేజీలని స్క్రాప్ చేయొచ్చు, ఏవి చేయకూడదు అని వాళ్లు ముందే చెప్తారు. దాన్ని గౌరవించాలి.

Q Cloudflare లాంటివి ఎలా బైపాస్ చేయాలి?

అది కొంచెం అడ్వాన్స్డ్. అప్పుడు నార్మల్ Selenium కాకుండా undetected-chromedriver లాంటివి వాడతాం, అలాగే మనుషుల్లాగా టైమ్ గ్యాప్స్ ఇస్తుంటాం.
