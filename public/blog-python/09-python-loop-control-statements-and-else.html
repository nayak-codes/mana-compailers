Python Loop Controls (break, continue, else) (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 9 of 65 📂 Phase 2: Operators & Control Flow 📅 2026 Edition
📌 Covered in this chapter: break · continue · pass · Loop else Clause · Prime Checker
లూప్స్ ని కంట్రోల్ చేయడానికి break, iteration ని స్కిప్ చేయడానికి continue, మరియు పైథాన్ లో స్పెషల్ ఫీచర్ అయిన Loop else గురించి నేర్చుకుందాం.
1The break Statement (లూప్ ని ముందే ఆపేయడం)

break statement ఎప్పుడైతే ఎక్జిక్యూట్ అవుతుందో, వెంటనే లూప్ అక్కడికక్కడే ఆగిపోయి, లూప్ బయట ఉన్న నెక్స్ట్ లైన్ కి జంప్ అవుతుంది:

💻 Example 1: Terminating Loop Early with break
Python 3 ▶ Run in Compiler 
# మనకు కావాల్సిన నెంబర్ 3 దొరకగానే ఆపేద్దాం:
print("Starting loop:")

for i in range(1, 6):
    if i == 3:
        print("🎯 Target number 3 found! Stopping loop immediately.")
        break  # లూప్ ఇక్కడే ఆగిపోతుంది!
        
    print("Processing number:", i)

print("Program continued after break. ✅")
🔍 ఎక్జిక్యూషన్ ఫ్లో:
  • ముందు Processing number: 1, 2 ప్రింట్ అవుతాయి.
  • ఎప్పుడైతే i == 3 అయిందో, break ఆ లూప్ ని బద్దలుకొట్టి బయటికి వచ్చేస్తుంది. అందుకే 4, 5 అసలు ప్రింటే అవ్వవు!
2The continue Statement (మిగతాది వదిలేసి నెక్స్ట్ సైకిల్ కి వెళ్లడం)

continue statement రన్ అయితే, లూప్ ఆగిపోదు, కానీ ఆ సైకిల్ లో కింద ఉన్న కోడ్ ని వదిలేసి, వెంటనే నెక్స్ట్ సైకిల్ కి వెళ్ళిపోతుంది:

💻 Example 2: Skipping Current Iteration with continue
Python 3 ▶ Run in Compiler 
# 3 ని స్కిప్ చేసి మిగతావి ప్రింట్ చేద్దాం:
print("Starting loop with continue:")

for i in range(1, 6):
    if i == 3:
        print("⏭️ Skipping number 3...")
        continue  # ఈ సైకిల్ లోని కింది కోడ్ ని స్కిప్ చేసి, మళ్లీ పైకి వెళ్తుంది!
        
    print("Processing number:", i)

print("Loop finished! ✅")
🔍 break మరియు continue మధ్య తేడా:
  • break అయితే మొత్తం లూప్ నే డిలీట్ చేసి బయటికి వచ్చేస్తుంది.
  • continue అయితే కేవలం ఆ ఒక్క సైకిల్ ని మాత్రమే ఆపేసి, మిగతా వాటి కోసం లూప్ ని రన్ చేస్తుంది.
3Python కు మాత్రమే ఉన్న స్పెషల్ ఫీచర్: Loop else Clause

Python లో మనం for లేదా while లూప్ కి డైరెక్ట్ గా ఒక else బ్లాక్ ని కలపొచ్చు. లూప్ ఎప్పుడూ break కాకుండా మొత్తం కంప్లీట్ గా రన్ అయితేనే ఈ else బ్లాక్ ఎక్జిక్యూట్ అవుతుంది. ఒకవేళ break అయితే else బ్లాక్ కూడా స్కిప్ అవుతుంది:

💻 Example 3: Loop else Clause when Target is Found
Python 3 ▶ Run in Compiler 
numbers = [10, 20, 30, 40]
target = 30

for num in numbers:
    if num == target:
        print(f"✅ Target {target} found in list!")
        break  # break అయింది కాబట్టి -> కింది else బ్లాక్ ఎక్జిక్యూట్ అవ్వదు!
else:
    print(f"❌ Target {target} not found.")
🔍 else ఎందుకు రన్ అవ్వలేదు?:

ఎందుకంటే num == 30 అవ్వగానే, break ఎక్జిక్యూట్ అయింది. అలా break అయినప్పుడు లూప్ దానికి అతుక్కుని ఉన్న else: ని కూడా ఆపేస్తుంది.

4టార్గెట్ దొరకనప్పుడు Loop else ఏమవుతుంది?

టార్గెట్ గనుక లిస్ట్ లో లేకపోతే, లూప్ break అవ్వకుండా మొత్తం అన్నీ వెతికి సహజంగానే ఆగిపోతుంది. అప్పుడు వెంటనే else రన్ అయి, "నాకు దొరకలేదు" అని చెప్తుంది!

💻 Example 4: Loop else Clause when Target is Missing
Python 3 ▶ Run in Compiler 
numbers = [10, 20, 30, 40]
target = 99  # ఈ నెంబర్ లిస్ట్ లో లేదు

for num in numbers:
    if num == target:
        print(f"✅ Target {target} found!")
        break
else:
    # బ్రేక్ అవ్వలేదు కాబట్టి ఆటోమాటిక్ గా రన్ అవుతుంది!
    print(f"❌ Target {target} was NOT found in the list! (Handled by loop else)")
🔍 Loop else రూల్:

లూప్ కి ఉన్న else ని "if nobreak:" అని చదువుకోవచ్చు. లూప్ మధ్యలో ఆగిపోకుండా పూర్తి అయితేనే ఇది రన్ అవుతుంది.

5రియల్ వరల్డ్ అప్లికేషన్: ప్రైమ్ నెంబర్ ప్రోగ్రామ్

ఒక నెంబర్ ప్రైమ్ నెంబరా కాదా అని తెలుసుకోవడానికి Loop else ని చాలా బాగా వాడొచ్చు:

💻 Example 5: Prime Number Checker with Loop else
Python 3 ▶ Run in Compiler 
num = 17

# 2 నుండి దానికి ముందున్న నెంబర్ వరకు ఏది భాగిస్తుందో చూద్దాం:
for i in range(2, num):
    if num % i == 0:
        print(f"{num} is NOT prime (divisible by {i})")
        break
else:
    # ఏ నెంబర్ భాగించక బ్రేక్ అవ్వలేదు కాబట్టి ఇది రన్ అవుతుంది:
    print(f"🌟 {num} is a PRIME NUMBER! (No divisors found)")
🔍 ఇదెలా పనిచేసింది?:

2 నుండి 16 వరకు ఏ నెంబర్ కూడా 17 ని భాగించలేదు కాబట్టి break జరగలేదు. లూప్ ప్రశాంతంగా పూర్తవ్వడంతో else: రన్ అయి 17 ప్రైమ్ నెంబర్ అని ప్రింట్ చేసింది!

⚠️ Common Developer Pitfall: break తర్వాత కూడా else రన్ అవుతుంది అనుకోవడం

గుర్తుంచుకోండి: లూప్ గనక break స్టేట్మెంట్ వాడితే, కింది else బ్లాక్ మొత్తానికే స్కిప్ అయిపోతుంది. లూప్ లోని అన్నీ ఐటమ్స్ కంప్లీట్ అయితే మాత్రమే else పని చేస్తుంది.

💻 Hands-on Interactive Practice Challenge

"Balaji" అనే పేరు కోసం వెతకండి. దొరికితే బ్రేక్ చేయండి, లేదంటే else లో "Student not found" అని ప్రింట్ చేయండి.

Python 3 Practice Challenge ▶ Run in Compiler 
students = ["Alex", "Balaji", "Chloe", "David"]
search_name = "Balaji"

for name in students:
    if name == search_name:
        print(f"👋 Found {search_name}! Welcome to class.")
        break
else:
    print(f"❌ {search_name} is not enrolled in this class.")

❓ Frequently Asked Questions (FAQ)

Q while లూప్ కి కూడా else పని చేస్తుందా?

అవును. while-else లో కూడా కండిషన్ False అయ్యి లూప్ ఆగినప్పుడు else రన్ అవుతుంది. కానీ break వాడితే మాత్రం else రన్ అవ్వదు.

Q nested లూప్స్ (లూప్ లోపల లూప్) లోపలినుంచి ఒకేసారి బయటికి రావడం ఎలా?

పైథాన్ లో ఇలా చేయడానికి బెస్ట్ వే: ఆ కోడ్ ని ఒక ఫంక్షన్ లో పెట్టి డైరెక్ట్ గా return చేయడం. లేదా ఒక వేరియబుల్ ని ఫ్లాగ్ (True/False) గా పెట్టుకుని బ్రేక్ చేయాలి.
