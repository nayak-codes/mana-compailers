Python OS, Sys & Pathlib Guide (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 22 of 65 📂 Phase 5: Modules and Packages 📅 2026 Edition
📌 Covered in this chapter: os Module · sys System Hooks · Modern pathlib Object Paths · Directory Traversal · Environment Variables
Python తో ఆపరేటింగ్ సిస్టం తో మాట్లాడటం ఎలా? ఫైల్స్, ఫోల్డర్స్ తో పనిచేయడానికి os, sys మరియు సరికొత్త మోడ్రన్ pathlib మాడ్యూల్స్ గురించి నేర్చుకుందాం.
1OS తో ఇంటరాక్ట్ అవ్వడం: The os Module

os మాడ్యూల్ మీ ఆపరేటింగ్ సిస్టం (Windows, Mac, Linux) తో సంబంధం లేకుండా పని చేయగలిగే ఫంక్షన్స్ ఇస్తుంది:

  • Environment Variables: os.environ (కంప్యూటర్ లో దాచిన API కీస్, పాస్వర్డ్స్ కి). ఎప్పుడైనా os.getenv("KEY") వాడితే ఎర్రర్ రాకుండా సేఫ్ గా ఉంటుంది.
  • ఫోల్డర్స్ చూడటం: os.getcwd() (మనం ఏ ఫోల్డర్ లో ఉన్నాం), os.chdir(path) (వేరే ఫోల్డర్ కి జంప్ అవ్వడం).
  • ఫోల్డర్స్ క్రియేట్ చేయడం: os.mkdir() (ఒకటి క్రియేట్ చేస్తుంది), os.makedirs(path, exist_ok=True) (లోపల లోపల ఫోల్డర్స్ ఉంటే అన్నీ ఒకేసారి క్రియేట్ చేస్తుంది).
  • ఫైల్స్ చూడటం & డిలీట్: os.listdir() (ఫైల్స్ లిస్ట్ ఇస్తుంది), os.remove() (ఫైల్ డిలీట్ చేస్తుంది).
💻 Example 1: Operating System Interface with os Module
Python 3 ▶ Run in Compiler 
# మీ OS డీటెయిల్స్ మరియు ఫోల్డర్స్ చూద్దాం:
import os

print("Operating System Name:", os.name) # Windows అయితే 'nt', Mac/Linux అయితే 'posix'
print("Current Working Directory:", os.getcwd())

# ఎన్విరాన్మెంట్ వేరియబుల్స్ తీసుకుందాం:
db_user = os.getenv("DB_USER", "default_admin")
print("Database User:", db_user)

# ఈ ఫోల్డర్ లో ఉన్న ఫైల్స్ చూద్దాం (హిడెన్ ఫైల్స్ వదిలేసి):
dir_files = [f for f in os.listdir(".") if not f.startswith(".")]
print(f"Top 5 files in current directory: {dir_files[:5]}")
🔍 సెక్యూరిటీ రూల్:

API Keys, డేటాబేస్ పాస్వర్డ్స్ లాంటివి డైరెక్ట్ గా కోడ్ లో అస్సలు రాయకూడదు. వాటిని మీ కంప్యూటర్ లో వేరియబుల్ గా సెట్ చేసి os.getenv() ద్వారానే తెచ్చుకోవాలి.

2పైథాన్ లోపల ఏం జరుగుతోంది?: The sys Module

sys మాడ్యూల్ పైథాన్ ఇంటర్ప్రెటర్ తో డైరెక్ట్ గా మాట్లాడటానికి వాడతారు:

  • sys.argv: మీరు టెర్మినల్ లో ఫైల్ రన్ చేసేటప్పుడు పక్కన ఇచ్చే టెక్స్ట్ (కమాండ్ లైన్ ఆర్గ్యుమెంట్స్) అన్నీ ఈ లిస్ట్ లో ఉంటాయి.
  • sys.exit(0): పైథాన్ ప్రోగ్రాం ని మధ్యలోనే ఆపేసి బయటికి వచ్చేయడం (0 అంటే ఎర్రర్ లేకుండా అని అర్థం).
  • sys.version: మీ పైథాన్ వెర్షన్ ఏంటి అని చెప్తుంది.
  • sys.getsizeof(obj): ఒక వేరియబుల్ ఎంత RAM (మెమరీ) తీసుకుంటుందో బైట్స్ లో చెప్తుంది.
💻 Example 2: Python Interpreter Inspection via sys Module
Python 3 ▶ Run in Compiler 
import sys

print(f"🐍 Python Runtime Version: {sys.version.split()[0]}")
print(f"💻 OS Platform Identifier: {sys.platform}")
print(f"📥 Command-line Arguments (sys.argv): {sys.argv}")

# వేర్వేరు ఆబ్జెక్ట్స్ ఎంత మెమరీ తీసుకుంటున్నాయో చూద్దాం (bytes లో):
int_size = sys.getsizeof(100)
str_size = sys.getsizeof("Hello, World!")
list_size = sys.getsizeof([1, 2, 3, 4, 5])

print(f"\nMemory Footprint:")
print(f"• Integer (100):      {int_size} bytes")
print(f"• String ('Hello..'): {str_size} bytes")
print(f"• List ([1..5]):      {list_size} bytes")
🔍 sys.argv ఎలా పనిచేస్తుంది?:

ఒకవేళ మీరు టెర్మినల్ లో python app.py report.pdf అని కొడితే, sys.argv లో ['app.py', 'report.pdf'] అని రెండు వస్తాయి.

3మోడ్రన్ ఫైల్ పాత్స్ (The new pathlib)

పాత రోజుల్లో ఫైల్ పాత్ కోసం స్ట్రింగ్స్ (os.path.join) వాడేవాళ్ళు. కానీ పైథాన్ 3 లో తీసుకొచ్చిన pathlib.Path అనేది చాలా స్మార్ట్. ఇది ఒక / వాడి ఫోల్డర్స్ ని కలుపుతుంది.

పాత స్ట్రింగ్ పద్ధతి: os.path.join("data", "users", "report.csv") మోడ్రన్ pathlib పద్ధతి: Path("data") / "users" / "report.csv" (సూపర్ క్లీన్)

దీని వల్ల విండోస్ లో (\), లైనక్స్ లో (/) వచ్చే క్రాష్ ఇష్యూస్ అన్నీ అదే సాల్వ్ చేసేసుకుంటుంది.

💻 Example 3: Object-Oriented File Paths with pathlib.Path
Python 3 ▶ Run in Compiler 
from pathlib import Path

# 1. / వాడి పాత్ ని క్రియేట్ చేయడం:
data_folder = Path("my_project") / "data"
config_file = data_folder / "app_config.json"

print("Path Object:", config_file)
print("Filename (name):", config_file.name)      # app_config.json
print("Filename stem:  ", config_file.stem)      # app_config (పేరు)
print("Extension:      ", config_file.suffix)    # .json
print("Parent Folder:  ", config_file.parent)    # my_project/data

# 2. ఒకే లైన్ లో ఫైల్ రైట్ చేసి రీడ్ చేయడం (Open/Close రాయక్కర్లేదు!):
test_file = Path("demo_note.txt")
test_file.write_text("Hello from Python pathlib! 🚀", encoding="utf-8")

file_content = test_file.read_text(encoding="utf-8")
print(f"\nRead file content: '{file_content}'")

# క్లీన్ అప్ (Delete):
if test_file.exists():
    test_file.unlink() # ఫైల్ డిలీట్ అయిపోతుంది
    print("Cleaned up demo_note.txt ✅")
🔍 ఎంత ఈజీ అంటే:

ఫైల్ ఉందా అని చెక్ చేయడానికి test_file.exists() అంటే చాలు. ఓపెన్, క్లోజ్ లతో పని లేకుండా ఒకే లైన్ లో .read_text() అని డేటా మొత్తం తెచ్చేసుకోవచ్చు.

4ఫైల్స్ వెతకడం (Pattern Globbing with Path.glob)

మీకు ఒక ఫోల్డర్ లో ఉన్న .py ఫైల్స్ అన్నీ కావాలనుకుంటే Globbing వాడతారు:

  • path.glob("*.py"): ఆ ఫోల్డర్ లో ఉన్న పైథాన్ ఫైల్స్ అన్నింటినీ ఇస్తుంది.
  • path.rglob("*.py"): Recursive - ఆ ఫోల్డర్ తో పాటు దాని లోపల ఉన్న వందల ఫోల్డర్స్ లో కూడా వెతుకుతుంది!
💻 Example 4: Pattern Searching with Path.glob
Python 3 ▶ Run in Compiler 
from pathlib import Path

current_dir = Path(".")

# ఈ ఫోల్డర్ లో ఉన్న HTML ఫైల్స్ అన్నీ వెతుకుదాం:
html_files = list(current_dir.glob("*.html"))
print(f"Found {len(html_files)} HTML files in current root.")

# మొదటి 3 ఫైల్స్ సైజు (bytes లో) చూద్దాం:
for f in html_files[:3]:
    print(f"• File: {f.name:25} | Size: {f.stat().st_size} bytes")
🔍 Performance Advantage:

Path.glob() వాడితే లక్ష ఫైల్స్ ఉన్నా సిస్టమ్ స్లో అవ్వదు (Generator వాడటం వల్ల RAM బతికిపోతుంది).

⚠️ Common Developer Pitfall: ఫైల్ పాత్స్ ని ప్లస్ (+) తో కలపడం

f = "folder" + "\\" + "file.txt" అని హార్డ్ కోడ్ చేస్తే, ఆ కోడ్ రేపు Linux సర్వర్ లో రన్ చేస్తే క్రాష్ అవుతుంది (లైనక్స్ లో క్రాస్ స్లాష్ / ఉంటుంది). అందుకే ఎప్పుడూ Path("folder") / "file.txt" అనే వాడాలి.

❓ Frequently Asked Questions (FAQ)

Q sys.exit(0) కి sys.exit(1) కి తేడా ఏంటి?

0 తో ఎగ్జిట్ అయితే, కంప్యూటర్ కి "కోడ్ సక్సెస్ ఫుల్ గా అయిపోయింది" అని సిగ్నల్ వెళ్తుంది. 1 వాడితే "ఏదో ఎర్రర్ వచ్చింది" అని సిగ్నల్ వెళ్తుంది.

Q లోపల లోపల ఉన్న ఫోల్డర్స్ క్రియేట్ చేసేటప్పుడు ఎర్రర్ రాకుండా ఎలా?

os.makedirs("my/deep/folder", exist_ok=True) అని రాస్తే, అప్పటికే ఆ ఫోల్డర్ ఉంటే క్రాష్ అవ్వకుండా సైలెంట్ గా వదిలేస్తుంది.
