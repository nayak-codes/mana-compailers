Python JSON Serialization Guide (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 23 of 65 📂 Phase 5: Modules and Packages 📅 2026 Edition
📌 Covered in this chapter: JSON Specification · json.dumps() vs dump() · json.loads() vs load() · Type Mappings · Custom Encoders
వెబ్ టెక్నాలజీస్ లో కింగ్ అయిన JSON తో పైథాన్ లో ఎలా డీల్ చేయాలి? డిక్షనరీస్ ని JSON గా మార్చడం (dumps, loads), ఫైల్స్ లోకి పంపడం, డేట్ (datetime) ని మార్చే కస్టమ్ ఎన్కోడర్స్ (Custom Encoders) గురించి నేర్చుకుందాం.
1JSON ఫార్మాట్ & పైథాన్ డేటా టైప్స్ మ్యాపింగ్

JSON (JavaScript Object Notation) అనేది ఇంటర్నెట్ లో డేటాని పంచుకోవడానికి (APIs, Web) వాడే ఒక యూనివర్సల్ టెక్స్ట్ ఫార్మాట్.

పైథాన్ లోని json మాడ్యూల్ మన డిక్షనరీస్ ని JSON గాను, JSON ని డిక్షనరీ గాను మార్చగలదు (దీన్నే Serialization అంటారు). కింది టేబుల్ లో ఏది ఏలా మారుతుందో చూడండి:

Python ObjectJSON EquivalentNotes
dictobject ({...})డిక్షనరీ లాగే ఉంటుంది
list, tuplearray ([...])ట్యూపుల్స్ కూడా అర్రే గా మారిపోతాయి
strstringటెక్స్ట్ (డబుల్ కోట్స్)
int, floatnumberనెంబర్స్
True / Falsetrue / falseస్మాల్ లెటర్స్ లోకి మారుతుంది
Nonenullనల్ రిఫరెన్స్
💻 Example 1: Translating Python Data Types to JSON
Python 3 ▶ Run in Compiler 
# పైథాన్ డేటాని JSON లోకి మారుద్దాం:
import json

python_payload = {
    "user_id": 101,
    "username": "balaji_dev",
    "is_admin": True,
    "roles": ("Backend", "DevOps"), # ఇది Array (List) గా మారుతుంది
    "profile": None,                # ఇది null అవుతుంది
    "rating": 4.95
}

# 1. డిక్షనరీ ని టెక్స్ట్ (స్ట్రింగ్) గా మారుద్దాం (dumps):
json_string = json.dumps(python_payload)
print("JSON Output String:")
print(json_string)
🔍 గమనించారా?:

True కాస్తా true (స్మాల్ లెటర్) అయింది. None కాస్తా null అయింది. ఇది JSON ఇంటర్నేషనల్ రూల్!

2మెమరీలో మార్చడం: json.dumps() మరియు json.loads()

"s" (string) తో ఎండ్ అయ్యే ఈ రెండు ఫంక్షన్స్ డేటాని ఫైల్ లో కాకుండా డైరెక్ట్ మెమరీలో టెక్స్ట్ లాగా (స్ట్రింగ్ గా) మారుస్తాయి:

  • json.dumps(obj): ఒక పైథాన్ ఆబ్జెక్ట్ ని JSON టెక్స్ట్ (స్ట్రింగ్) గా మారుస్తుంది (Dump String).
  • json.loads(str): JSON టెక్స్ట్ ని చదివి, దాన్ని మనకు పైథాన్ డిక్షనరీ లాగా ఇస్తుంది (Load String).
💻 Example 2: In-Memory Serialization with json.dumps and json.loads
Python 3 ▶ Run in Compiler 
import json

# 1. అందంగా కనిపించడానికి indent (స్పేస్) వాడి మార్చుదాం:
server_config = {
    "host": "127.0.0.1",
    "port": 8000,
    "debug": False,
    "allowed_hosts": ["localhost", "ourcompiler.com"]
}

pretty_json = json.dumps(server_config, indent=4, sort_keys=True)
print("--- 💅 Pretty Formatted JSON ---")
print(pretty_json)

# 2. బయట ఎక్కడో API నుంచి వచ్చిన టెక్స్ట్ ని పైథాన్ లోకి మారుద్దాం:
raw_api_response = '{"status": 200, "message": "Success", "data": [10, 20, 30]}'
parsed_dict = json.loads(raw_api_response)

print("\n--- 🔄 Parsed Python Dictionary ---")
print("Status Code:", parsed_dict["status"])
print("Data items: ", parsed_dict["data"])
print("Python Type:", type(parsed_dict).__name__)
🔍 ఎక్కడ వాడతారు?:

వెబ్ API (ఉదా: requests.get()) నుంచి రిజల్ట్ వస్తే అది టెక్స్ట్ లానే ఉంటుంది. దాన్ని json.loads() ద్వారా లోపలికి లాగితేనే మనం డిక్షనరీ లాగా data['status'] అని వాడుకోగలం.

3ఫైల్స్ లోకి చదవడం/రాయడం: json.dump() మరియు json.load()

ఒకవేళ మీరు టెక్స్ట్ తో కాకుండా, డైరెక్ట్ గా ఒక ఫైల్ (.json) లో రాయాలన్నా లేదా అక్కడినుంచి చదవాలన్నా s లేని ఫంక్షన్స్ వాడాలి:

  • json.dump(obj, file): ఆబ్జెక్ట్ ని ఫైల్ లోపల సేవ్ చేస్తుంది.
  • json.load(file): ఫైల్ ని చదివి డిక్షనరీ గా ఇస్తుంది.
💻 Example 3: File Stream Serialization with json.dump and json.load
Python 3 ▶ Run in Compiler 
import json
from pathlib import Path

settings_file = Path("user_settings.json")

# సేవ్ చేయాల్సిన డేటా:
user_preferences = {
    "theme": "dark",
    "font_size": 14,
    "auto_save": True,
    "recent_files": ["main.py", "models.py", "utils.py"]
}

# 1. ఫైల్ ఓపెన్ చేసి డైరెక్ట్ గా అందులోకి డంప్ (dump) చేద్దాం:
with open(settings_file, "w", encoding="utf-8") as f:
    json.dump(user_preferences, f, indent=4)
print(f"✅ Saved settings to {settings_file}")

# 2. ఆ ఫైల్ ని ఓపెన్ చేసి డేటాని లోడ్ (load) చేసుకుందాం:
with open(settings_file, "r", encoding="utf-8") as f:
    loaded_settings = json.load(f)

print(f"📖 Loaded Theme: {loaded_settings['theme']} | Font: {loaded_settings['font_size']}px")

# మన డెమో ఫైల్ డిలీట్ చేసేద్దాం:
settings_file.unlink()
🔍 బెస్ట్ ప్రాక్టీస్:

JSON ఫైల్స్ ని ఓపెన్ చేసేటప్పుడు కచ్చితంగా encoding="utf-8" రాయాలి. లేకపోతే ఎమోజీలు లేదా తెలుగు అక్షరాలు సరిగ్గా సేవ్ అవ్వవు (విండోస్ లో).

4డేట్/టైం ని JSON లోకి మార్చడం (Custom Encoders)

ఒకవేళ మీరు పైథాన్ datetime ని లేదా set ని JSON లాగా మార్చమని అడిగితే TypeError: Object is not JSON serializable వస్తుంది. ఎందుకంటే JSON కి డేట్స్, సెట్స్ అర్థం కావు.

దీన్ని సాల్వ్ చేయడానికి మనం ఒక చిన్న కస్టమ్ ఎన్కోడర్ (Custom Handler) రాసి default కి ఇవ్వాలి:

💻 Example 4: Custom JSON Serializer for Datetime and Sets
Python 3 ▶ Run in Compiler 
import json
import datetime as dt

def custom_json_serializer(obj):
    """అర్థంకాని టైప్స్ ని JSON కి అర్థమయ్యే టెక్స్ట్ గా మారుస్తుంది."""
    if isinstance(obj, (dt.datetime, dt.date)):
        return obj.isoformat() # Date ని ఇంటర్నేషనల్ టెక్స్ట్ గా మారుస్తుంది
    if isinstance(obj, set):
        return list(obj)       # Set ని లిస్ట్ గా మార్చి ఇస్తుంది
    raise TypeError(f"Type {type(obj)} is not serializable!")

# Date మరియు Set తో కూడిన ఒక డిక్షనరీ:
transaction = {
    "invoice_id": "INV-2026-894",
    "timestamp": dt.datetime.now(),                      # Datetime ఆబ్జెక్ట్
    "unique_categories": {"Electronics", "Accessories"}, # Set కలెక్షన్
    "amount": 499.99
}

# మన ఫంక్షన్ ని default=custom_json_serializer గా పంపుదాం
serialized_json = json.dumps(transaction, default=custom_json_serializer, indent=2)
print("--- 🛡️ Custom Serialized JSON ---")
print(serialized_json)
🔍 ఇండస్ట్రీ స్టాండర్డ్:

తేదీలని ఎప్పుడూ ISO 8601 స్ట్రింగ్ గా (ఉదా: 2026-08-14T15:30:00) సేవ్ చేయడం వరల్డ్ వైడ్ రూల్.

⚠️ Common Developer Pitfall: json.loads() కి json.load() కి మధ్య కన్ఫ్యూజన్

loads(str) అంటే టెక్స్ట్ (స్ట్రింగ్) తీసుకుంటుంది. load(file) అంటే ఓపెన్ చేసిన ఫైల్ తీసుకుంటుంది. మీరు json.load(టెక్స్ట్) అని ఇస్తే AttributeError వస్తుంది.

❓ Frequently Asked Questions (FAQ)

Q json.dumps({"a": 1}) పనిచేసింది కానీ json.dumps({(1, 2): "val"}) ఎందుకు ఫెయిల్ అవుతుంది?

JSON రూల్స్ ప్రకారం డిక్షనరీ Keys ఎప్పుడూ టెక్స్ట్ (స్ట్రింగ్స్) లోనే ఉండాలి. పైథాన్ లో లాగా ట్యూపుల్స్ ని Keys గా పెడితే JSON కి అర్థం కాదు.

Q నెట్వర్క్ లో డేటా పంపేటప్పుడు సైజ్ తగ్గించడం ఎలా (Compact JSON)?

json.dumps(obj, separators=(",", ":")) వాడితే మధ్యలో ఉన్న స్పేసెస్ అన్నీ మాయమైపోయి మొత్తం ఒకే లైన్ లోకి కుదించుకుపోయి వస్తుంది. దీనివల్ల ఇంటర్నెట్ బ్యాండ్విడ్త్ కలిసివస్తుంది.
