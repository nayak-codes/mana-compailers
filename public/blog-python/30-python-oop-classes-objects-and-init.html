Python Classes, Objects & __init__ (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 30 of 65 📂 Phase 7: Object-Oriented Programming 📅 2026 Edition
📌 Covered in this chapter: OOP Concepts · Class Blueprint vs Object Instance · __init__() Constructor · self Parameter · Instance vs Class Variables
పైథాన్ లో Object-Oriented Programming (OOP) అంటే ఏమిటి? Classes, Objects, __init__ కన్స్ట్రక్టర్, మరియు self పారామీటర్ గురించి పూర్తి వివరాలు తెలుసుకుందాం.
1OOP అంటే ఏమిటి? Procedural vs Object-Oriented

Object-Oriented Programming (OOP) అనేది కోడ్ రాసే ఒక స్టైల్. ఇందులో మనం డేటాని మరియు ఆ డేటా పైన పనిచేసే ఫంక్షన్స్ ని కలిపి ఒకే "Object" లాగా తయారుచేస్తాం.

మామూలు కోడింగ్ కి, OOP కి తేడా:

FeatureProcedural ProgrammingObject-Oriented (OOP)
ఫోకస్స్టెప్-బై-స్టెప్ లాజిక్ మరియు ఫంక్షన్స్ పైన ఉంటుంది.రియల్ వరల్డ్ ఆబ్జెక్ట్స్ (కార్, యూజర్, అకౌంట్) పైన ఉంటుంది.
డేటావేరియబుల్స్ ఒక దగ్గర, ఫంక్షన్స్ ఒక దగ్గర ఉంటాయి. విడివిడిగా.డేటా మరియు మెథడ్స్ కలిసి ఒకే చోట ప్యాక్ అయి ఉంటాయి.
సెక్యూరిటీగ్లోబల్ వేరియబుల్స్ వాడటం వల్ల ఎవరు ఏ డేటాని మారుస్తున్నారో కనుక్కోవడం కష్టం.ఎవరి డేటా వారిదే (Encapsulation ద్వారా లాక్ చేయొచ్చు).

Blueprint లాజిక్: ఒక Class అనేది ఇల్లు కట్టడానికి వాడే బ్లూప్రింట్ (ప్లాన్) లాంటిది. ఇల్లు కట్టకముందు దానికంటూ ఒక షేప్ ఉండదు. ఆ ప్లాన్ ని చూసి మనం రియల్ గా ఒక ఇల్లు కడితే, ఆ కట్టిన ఇంటిని Object (లేదా Instance) అంటారు!

┌────────────────────────────────────────────────────────┐ │ Class Blueprint (ప్లాన్): BankAccount │ │ ├── ఏముంటాయి?: owner, balance │ │ └── ఏం చేయగలవు?: deposit(), withdraw() │ └───────────────────────────┬────────────────────────────┘ │ [అకౌంట్ క్రియేట్ చేద్దాం: Account("Ravi", 5000)] ▼ ┌────────────────────────────────────────────────────────┐ │ రియల్ Object (కంప్యూటర్ మెమరీలో): │ │ ├── owner = "Ravi" │ │ └── balance = 5000 │ └────────────────────────────────────────────────────────┘
💻 Example 1: Defining a Class and Instantiating Objects
Python 3 ▶ Run in Compiler 
# మన ఫస్ట్ Class క్రియేట్ చేసి దానినుంచి Objects తయారుచేద్దాం:
class Car:
    """కార్ కి సంబంధించిన బ్లూప్రింట్."""
    
    # ఎప్పుడైతే కొత్త కార్ క్రియేట్ చేస్తామో, అప్పుడు ఈ __init__ ఆటోమాటిక్ గా రన్ అవుతుంది:
    def __init__(self, brand, model, year):
        self.brand = brand  # ఇవన్నీ ఏ కార్ కి ఆ కార్ కే ఉంటాయి
        self.model = model  
        self.year = year    
        self.is_running = False

    # కార్ స్టార్ట్ చేయడానికి ఒక మెథడ్ (ఫంక్షన్):
    def start_engine(self):
        self.is_running = True
        return f"🚗 {self.brand} {self.model} ఇంజిన్ స్టార్ట్ అయింది! వ్రూమ్!"

# ఈ బ్లూప్రింట్ నుంచి రెండు రియల్ కార్స్ (Objects) క్రియేట్ చేద్దాం:
car1 = Car("Tesla", "Model 3", 2024)
car2 = Car("Toyota", "Supra", 2023)

print("Car 1 Brand:", car1.brand, "| Model:", car1.model)
print("Car 2 Brand:", car2.brand, "| Model:", car2.model)
print(car1.start_engine())
🔍 గమనించారా?:
  • class Car: అనేది బ్లూప్రింట్ ని క్రియేట్ చేసింది.
  • Car("Tesla", ...) అని పిలవగానే __init__ రన్ అయ్యి, దానికి మెమరీ ఇచ్చింది.
  • car1 కి, car2 కి సంబంధం లేదు. ఎవరి బ్రాండ్ వాళ్లదే!
2__init__() Constructor & self ఎందుకు వాడాలి?

పైథాన్ లో __init__() అనేది ఒక స్పెషల్ మెథడ్ (దీన్నే కన్స్ట్రక్టర్ అంటారు). మీరు క్లాస్ పేరుతో ఎప్పుడైతే పిలుస్తారో, వెంటనే పైథాన్ ఈ ఫంక్షన్ ని రన్ చేసి మీరు ఇచ్చిన వాల్యూస్ ని వేరియబుల్స్ కి అటాచ్ చేస్తుంది.

self అంటే ఏంటి?

self అంటే "ఇప్పుడు ఏ ఆబ్జెక్ట్ నన్ను పిలుస్తోంది?" అని అర్థం. ఉదాహరణకి మీరు account1.deposit(500) అని రాస్తే, పైథాన్ లోపల దాన్ని BankAccount.deposit(account1, 500) లాగా మార్చుకుంటుంది!

మనం రాసేది: account1.show_balance() పైథాన్ చేసేది: BankAccount.show_balance(account1) <-- ఇక్కడ 'account1' యే self అన్నమాట!

పైథాన్ బై-డిఫాల్ట్ గా ఆ ఆబ్జెక్ట్ ని ఫస్ట్ పారామీటర్ గా పంపిస్తుంది కాబట్టి, మనం క్లాస్ లోపల రాసే ప్రతి ఫంక్షన్ కీ ఫస్ట్ self కచ్చితంగా రాయాలి.

💻 Example 2: BankAccount Class with __init__ and self
Python 3 ▶ Run in Compiler 
# BankAccount క్లాస్ డెమో:
class BankAccount:
    def __init__(self, owner, balance):
        # self ద్వారా ఇవి పర్మనెంట్ గా ఆబ్జెక్ట్ కి అతుక్కుపోతాయి:
        self.owner = owner
        self.balance = float(balance)

    def deposit(self, amount):
        if amount <= 0:
            print("❌ పాజిటివ్ అమౌంట్ ఇవ్వండి!")
            return
        self.balance += amount
        print(f"✅ {self.owner} అకౌంట్ లోకి ₹{amount:,.2f} వేశారు.")

    def show_balance(self):
        print(f"💳 Account: {self.owner} | Balance: ₹{self.balance:,.2f}")

# అకౌంట్ క్రియేట్ చేసి వాడటం:
account = BankAccount("Ravi", 5000)
account.show_balance()
account.deposit(1000)
account.show_balance()
🔍 self లేకపోతే ఏమవుతుంది?:

ఒకవేళ మీరు balance = amount అని ఊరికే రాస్తే, అది ఒక టెంపరరీ వేరియబుల్ అవుతుంది, ఫంక్షన్ అవ్వగానే డిలీట్ అవుతుంది. self.balance అని రాస్తేనే అది అకౌంట్ తో పాటు ఎప్పటికీ సేవ్ అయి ఉంటుంది.

3Instance Variables vs Class Variables

OOP లో వేరియబుల్స్ రెండు రకాలుగా ఉంటాయి, ఇది తెలియకపోతే చాలా బగ్స్ వస్తాయి:

  • Instance Variables (self.name): __init__ లోపల self వాడి రాసేవి. ఇవి ఎవరివి వాళ్ళకే ఉంటాయి. (ఉదా: ఒక ఎంప్లాయీ జీతం, ఇంకో ఎంప్లాయీ జీతం వేరుగా ఉంటాయి).
  • Class Variables: క్లాస్ లోపల (ఫంక్షన్స్ కి బయట) డైరెక్ట్ గా రాసేవి. వీటికి కంప్యూటర్ లో ఒకే ఒక్క మెమరీ ఉంటుంది, ఆ క్లాస్ కి సంబంధించిన ఆబ్జెక్ట్స్ అన్నీ ఆ ఒక్క దన్నే షేర్ చేసుకుంటాయి.
💻 Example 3: Instance Variables vs Shared Class Variables
Python 3 ▶ Run in Compiler 
class Employee:
    # 1. Class Variable (అందరికీ కలిపి ఒకటే ఉంటుంది):
    company_name = "Tech Innovations Ltd"
    total_employees_count = 0

    def __init__(self, name, department, salary):
        # 2. Instance Variables (ఎవరికి వారు సెపరేట్):
        self.name = name
        self.department = department
        self.salary = salary
        
        # కౌంట్ ని పెంచుదాం (ఇది క్లాస్ వేరియబుల్):
        Employee.total_employees_count += 1

    def get_details(self):
        return f"• {self.name:8} ({self.department}) | Salary: ₹{self.salary:,} | Company: {self.company_name}"

# ఎంప్లాయీస్ ని క్రియేట్ చేద్దాం:
emp1 = Employee("Balaji", "Backend", 95000)
emp2 = Employee("Alex", "DevOps", 82000)
emp3 = Employee("Chloe", "AI/ML", 105000)

print(emp1.get_details())
print(emp2.get_details())
print(emp3.get_details())
print(f"\n🏢 మొత్తం ఎంప్లాయీస్: {Employee.total_employees_count}")
🔍 లాజిక్:

మీరు emp1.company_name అని అడిగితే, ఫస్ట్ అది emp1 లోపల వెతుకుతుంది. అక్కడ లేకపోతే, అప్పుడు వెళ్లి క్లాస్ వేరియబుల్స్ లో వెతుకుతుంది.

⚠️ Common Developer Pitfall: Class Variable ని ఒక Object ద్వారా మార్చడం

మీరు emp1.company_name = "NewCorp" అని రాస్తే, కంపెనీ పేరు అందరికీ మారదు! emp1 కి మాత్రమే ఒక కొత్త టెంపరరీ వేరియబుల్ యాడ్ అవుతుంది. అందరికీ మారాలంటే క్లాస్ పేరుతోనే మార్చాలి: Employee.company_name = "NewCorp".

💻 Hands-on Interactive Practice Challenge

ఒక Book క్లాస్ రాయండి. అందులో title, author, price ఉండాలి. apply_discount(percent) అనే మెథడ్ వాడి, ఎంత పర్సెంట్ ఇస్తే అంత రేటు తగ్గించాలి.

Python 3 Practice Challenge ▶ Run in Compiler 
class Book:
    def __init__(self, title, author, price):
        self.title = title
        self.author = author
        self.price = price

    def apply_discount(self, percent):
        discount_amt = self.price * (percent / 100)
        self.price -= discount_amt
        print(f"Discount {percent}% applied on '{self.title}'! New Price: ₹{self.price:.2f}")

book1 = Book("Python Mastery 2026", "Guido", 799.00)
book1.apply_discount(15)

❓ Frequently Asked Questions (FAQ)

Q ఫంక్షన్స్ లో self ఖచ్చితంగా రాయాలా? దాన్ని వేరే పేరుతో రాయొచ్చా?

self అనేది పైథాన్ రూల్. వేరే పేరుతో (ఉదా: obj) రాసినా పనిచేస్తుంది, కానీ ఎవ్వరూ అలా రాయరు, చదివే వాళ్ళకి కన్ఫ్యూజన్ వస్తుంది.

Q ఒక క్లాస్ లో రెండు __init__ లు రాయొచ్చా (Java లాగా)?

లేదు. పైథాన్ లో రెండు రాస్తే రెండోది మాత్రమే వర్కవుట్ అవుతుంది. అలాంటప్పుడు డీఫాల్ట్ పారామీటర్స్ లేదా *args వాడాలి.
