Python Menu-Driven Applications (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 19 of 65 📂 Phase 4: Functions & Reusable Code 📅 2026 Edition
📌 Covered in this chapter: CLI Menu Loops · Function Dispatch Tables · State Management · Banking System Project · Capstone Architecture
యూజర్ ని అడిగి పని చేయించుకునే (Interactive) కన్సోల్ అప్లికేషన్స్ ఎలా తయారు చేయాలో చూద్దాం: Menu loops, function dispatchers, మరియు ఒక పూర్తి బ్యాంకింగ్ అప్లికేషన్ ప్రాజెక్ట్.
1Menu-Driven Architecture అంటే ఏంటి?

Menu-Driven Application అంటే మనం యూజర్ కి ఆప్షన్స్ చూపించి (1 నొక్కితే ఇది, 2 నొక్కితే అది), వాడు నంబర్ ఇవ్వగానే ఆ పని చేసి, మళ్ళీ ఆప్షన్స్ చూపిస్తూ వాడు Exit అయ్యేదాకా రన్ అయ్యే ప్రోగ్రామ్.

┌────────────────────────────────────────────────────────┐ │ 1. మెనూ ఆప్షన్స్ ని డిస్ప్లే చేయాలి │ │ 2. యూజర్ ఇచ్చే నెంబర్ చదివి చెక్ చేయాలి │ │ 3. ఆ నెంబర్ కు సంబంధించిన ఫంక్షన్ ని రన్ చేయాలి │ │ 4. మళ్ళీ మెనూ చూపించాలి (ఎగ్జిట్ అయ్యేవరకు) │ └────────────────────────────────────────────────────────┘
💻 Example 1: Interactive Menu Loop Blueprint
Python 3 ▶ Run in Compiler 
# సింపుల్ మెనూ లూప్ బ్లూప్రింట్:
def show_menu():
    print("\n--- 📱 Quick Actions Menu ---")
    print("1. View Profile")
    print("2. Update Settings")
    print("3. Exit")

def app_controller():
    # ఇక్కడ కన్సోల్ (CLI) ఇన్పుట్ బదులు మనం డెమో కోసం లిస్ట్ వాడాం:
    simulated_inputs = ["1", "2", "3"]
    
    for choice in simulated_inputs:
        show_menu()
        print("Selected Choice:", choice)
        
        if choice == "1":
            print("👉 Action: Displaying User Profile...")
        elif choice == "2":
            print("👉 Action: Updating User Settings...")
        elif choice == "3":
            print("👋 Exiting program. Goodbye!")
            break

app_controller()
🔍 కంట్రోల్ ఫ్లో:

లూప్ పదే పదే మెనూ చూపిస్తూ ఉంటుంది. బ్రేక్ (Exit) కండిషన్ రన్ అయినప్పుడు మాత్రమే కోడ్ ఆగిపోయి బయటికి వస్తుంది.

2100 if-else లకి బదులు: Dictionary Function Dispatchers

సాధారణంగా ఆప్షన్స్ పెరిగే కొద్దీ if-elif-elif-else లతో పెద్ద నిచ్చెన కడితే కోడ్ అంతా చెత్తగా తయారవుతుంది. ప్రొఫెషనల్ పైథాన్ డెవలపర్స్ ఇలా Dictionary Dispatch Tables వాడి క్షణంలో ఫంక్షన్ కి రౌట్ (route) చేస్తారు:

💻 Example 2: Dictionary Function Dispatch Tables
Python 3 ▶ Run in Compiler 
# మనకు కావాల్సిన ఫంక్షన్స్:
def handle_view(): return "📋 Showing all database records..."
def handle_create(): return "➕ Creating new database record..."
def handle_delete(): return "🗑️ Deleting specified record..."
def handle_exit(): return "👋 Application closed."

# ఈ డిక్షనరీ లో కీ కి ఫంక్షన్ ని లింక్ చేస్తాం:
COMMANDS_DISPATCH = {
    "1": handle_view,
    "2": handle_create,
    "3": handle_delete,
    "4": handle_exit
}

def execute_command(user_choice):
    action = COMMANDS_DISPATCH.get(user_choice)
    if action:
        return action() # ఇక్కడ () పెట్టి ఫంక్షన్ ని పిలుస్తున్నాం!
    return "❌ Invalid selection! Please enter a valid number."

# టెస్ట్ చేద్దాం:
for choice in ["1", "2", "3", "99", "4"]:
    print(f"Command '{choice}' -> {execute_command(choice)}")
🔍 క్లీన్ కోడ్ పవర్:

రేపు మీరు 10 కొత్త ఫీచర్లు యాడ్ చేసినా పెద్ద if-else లు ఏమీ మారవు. జస్ట్ ఫంక్షన్ రాసి ఈ డిక్షనరీ లో కలుపుకోవడమే!

3Capstone Project: స్టూడెంట్ / బ్యాంకింగ్ సిస్టం

బ్యాంకింగ్ యాప్ ఎలా ఉంటుందో తెలుసుకోవడానికి అకౌంట్ బ్యాలెన్స్ చూడటం, డబ్బులు డిపాజిట్, విత్డ్రా చేయడం మరియు ట్రాన్సాక్షన్ హిస్టరీ అన్నీ చూసుకునే ఒక ప్రాజెక్ట్:

💻 Example 3: Comprehensive Banking Management System Project
Python 3 ▶ Run in Compiler 
# =========================================================================
# CAPSTONE PROJECT: MODULAR BANKING & ACCOUNT MANAGEMENT
# =========================================================================

accounts_database = {
    "ACC101": {"holder": "Balaji", "balance": 5000.0, "history": []},
    "ACC102": {"holder": "Alex", "balance": 2500.0, "history": []}
}

def check_balance(acc_id):
    acc = accounts_database.get(acc_id)
    if not acc: return f"❌ Account {acc_id} not found."
    return f"💳 Account: {acc['holder']} | Balance: Rs.{acc['balance']:.2f}"

def deposit_funds(acc_id, amount):
    acc = accounts_database.get(acc_id)
    if not acc: return f"❌ Account {acc_id} not found."
    if amount <= 0: return "❌ Deposit amount must be positive!"
    
    acc["balance"] += amount
    acc["history"].append(f"Deposited +Rs.{amount:.2f}")
    return f"✅ Deposited Rs.{amount:.2f} successfully! New Balance: Rs.{acc['balance']:.2f}"

def withdraw_funds(acc_id, amount):
    acc = accounts_database.get(acc_id)
    if not acc: return f"❌ Account {acc_id} not found."
    if amount > acc["balance"]:
        return f"❌ Insufficient funds! Current Balance: Rs.{acc['balance']:.2f}"
        
    acc["balance"] -= amount
    acc["history"].append(f"Withdrawn -Rs.{amount:.2f}")
    return f"✅ Withdrew Rs.{amount:.2f} successfully! Remaining: Rs.{acc['balance']:.2f}"

# బ్యాంకింగ్ సిమ్యులేషన్ చూద్దాం:
print("--- 🏦 Online Banking Simulation ---")
print(check_balance("ACC101"))
print(deposit_funds("ACC101", 1500.0))
print(withdraw_funds("ACC101", 2000.0))
print(withdraw_funds("ACC101", 10000.0)) # డబ్బులు లేవని చెప్తుంది
print("\nFinal State ACC101:", accounts_database["ACC101"])
🔍 సాఫ్ట్వేర్ ఇంజనీరింగ్ సూత్రాలు:
  • Single Responsibility: ప్రతి ఫంక్షన్ ఒకే పని చేస్తుంది (డిపాజిట్ కి ఒక ఫంక్షన్, విత్డ్రా కి ఒక ఫంక్షన్).
  • Defensive Validation: ముందే అకౌంట్ ఉందా లేదా? వాడిదగ్గర డబ్బులున్నాయా అని చెక్ చేసి సేఫ్ గా ఉంచుతుంది.
⚠️ Common Developer Pitfall: డిక్షనరీ లోపలే ఫంక్షన్ ని రన్ చేసేయడం (తప్పు)

డిక్షనరీ లో "1": my_func అని రాసి పేరు మాత్రమే ఇవ్వాలి. ఒకవేళ "1": my_func() అని బ్రాకెట్స్ పెడితే, మీరు బటన్ నొక్కకముందే అప్లికేషన్ స్టార్ట్ అవ్వగానే అవన్నీ రన్ అయిపోతాయి!

💻 Hands-on Interactive Practice Challenge

ఒక మినీ ఇన్వెంటరీ (స్టాక్) మేనేజ్మెంట్ తయారుచేసి, స్టాక్ యాడ్ చేయడం, సెల్ చేయడం ట్రై చేయండి.

Python 3 Practice Challenge ▶ Run in Compiler 
inventory = {"Laptops": 10, "Mice": 25, "Keyboards": 15}

def add_stock(item, qty):
    inventory[item] = inventory.get(item, 0) + qty
    return f"Added {qty} {item}. Current Stock: {inventory[item]}"

def sell_stock(item, qty):
    if inventory.get(item, 0) < qty:
        return f"Insufficient stock for {item}!"
    inventory[item] -= qty
    return f"Sold {qty} {item}. Remaining: {inventory[item]}"

print("Initial Inventory:", inventory)
print(add_stock("Laptops", 5))
print(sell_stock("Mice", 10))
print("Updated Inventory:", inventory)

Q Function Dispatch Table అంటే ఏంటి?

యూజర్ 1 ఇస్తే ఈ ఫంక్షన్ రన్ అవ్వాలి, 2 ఇస్తే ఇంకో ఫంక్షన్ రన్ అవ్వాలి అని ఒక డిక్షనరీ లో మ్యాపింగ్ చేయడాన్నే డిస్పాచ్ టేబుల్ అంటారు. ఇది if-else లకంటే చాలా ఫాస్ట్.

Q ప్రోగ్రామ్ ని క్లోజ్ చేసి ఓపెన్ చేస్తే నా డేటా ఎందుకు మాయం అవుతుంది?

మనం క్రియేట్ చేసే వేరియబుల్స్ అన్నీ RAM లో సేవ్ అవుతాయి కాబట్టి ప్రోగ్రామ్ క్లోజ్ చేస్తే పోతాయి. అవి అలానే ఉండాలంటే మనం దాన్ని json మాడ్యూల్ లేదా sqlite డేటాబేస్ వాడి ఫైల్స్ లో సేవ్ చేయాలి.
