Python Standard Library Core (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 21 of 65 📂 Phase 5: Modules and Packages 📅 2026 Edition
📌 Covered in this chapter: math · random · datetime · statistics · High-Performance Utilities · Reproducible Seeds
Python తో పాటే వచ్చే పవర్ ఫుల్ "Standard Library" మాడ్యూల్స్: math (మ్యాథ్స్ లాజిక్), random (రాండమ్ నెంబర్స్), datetime (టైం అండ్ డేట్), మరియు statistics (స్టాటిస్టిక్స్) గురించి నేర్చుకుందాం.
1"Batteries Included" & math మాడ్యూల్

పైథాన్ ఫిలాసఫీ ఏంటంటే "Batteries Included". అంటే మీరు బయటినుంచి ఏమీ డౌన్లోడ్ చేసుకోకపోయినా, పైథాన్ తో పాటే వందలాది పవర్ ఫుల్ C-optimized మాడ్యూల్స్ ఆటోమాటిక్ గా వచ్చేస్తాయి.

math మాడ్యూల్ అనేది మ్యాథ్స్ కాలిక్యులేషన్స్ చేయడానికి వాడతారు:

  • Constants: math.pi (3.14159...), math.e (2.71828...).
  • Rounding: math.floor() (కిందికి రౌండ్ చేస్తుంది), math.ceil() (పైకి రౌండ్ చేస్తుంది), math.trunc() (చుక్క తర్వాతవి తీసేస్తుంది).
  • పవర్ & లాగ్: math.sqrt() (రూట్), math.pow() (పవర్), math.log().
  • కాంప్లెక్స్: math.factorial(n) (ఫ్యాక్టోరియల్), math.gcd(a, b) (గరిష్ట సామాన్య భాజకం).
💻 Example 1: Advanced Mathematical Computations with math
Python 3 ▶ Run in Compiler 
import math

# 1. Rounding ఆపరేషన్స్
print("Ceil of 4.2: ", math.ceil(4.2))   # 5 (పైకి)
print("Floor of 4.8:", math.floor(4.8))  # 4 (కిందికి)

# 2. ఫ్యాక్టోరియల్ మరియు కాంబినేషన్స్
print("\n5! (Factorial):", math.factorial(5)) # 120
print("Combinations of 5 choose 2:", math.comb(5, 2)) # 10

# 3. ట్రైగోనోమెట్రీ (Trigonometry) - యాంగిల్స్ Radians లో ఉండాలి
angle_rad = math.radians(90) # 90 డిగ్రీలని radians లోకి మార్చడం
print("sin(90 degrees):", math.sin(angle_rad))
print("Hypotenuse of 6 and 8:", math.hypot(6, 8)) # 10.0 (పైథాగరస్ థియరమ్)
🔍 Precision Tip:

డెసిమల్స్ (0.1 + 0.2) ని ఎప్పుడూ == వాడి చెక్ చేయకండి, రిజల్ట్ తప్పు వస్తుంది (IEEE 754 ఇష్యూ). ఎప్పుడూ math.isclose(a, b) వాడాలి.

2The random మాడ్యూల్: పర్ఫెక్ట్ గా రాండమ్ నెంబర్స్

random మాడ్యూల్ అనేది గెస్ చేయలేని (Mersenne Twister అల్గారిథం వాడి) నెంబర్స్ ని క్రియేట్ చేయడానికి వాడతారు.

  • random.randint(a, b): a మరియు b మధ్యలో ఒక నెంబర్ ని ఇస్తుంది (రెండూ కలుపుకుని).
  • random.random(): 0.0 నుండి 1.0 లోపు ఒక ఫ్లోట్ ని ఇస్తుంది.
  • random.choice(sequence): లిస్ట్ లోంచి ఏదైనా ఒకదాన్ని రాండమ్ గా సెలెక్ట్ చేస్తుంది.
  • random.sample(seq, k=n): లిస్ట్ లోంచి n ఐటమ్స్ ని డూప్లికేట్ లేకుండా సెలెక్ట్ చేస్తుంది.
  • random.shuffle(list): లిస్ట్ లోని ఐటమ్స్ ఆర్డర్ ని జిగ్-జాగ్ (shuffle) చేస్తుంది.
  • random.seed(x): దీన్ని వాడితే, ఎన్నిసార్లు రన్ చేసినా ఒకటే రాండమ్ రిజల్ట్ వస్తుంది (టెస్టింగ్ కి వాడతారు).
💻 Example 2: Random Number Generation, Selection and Shuffling
Python 3 ▶ Run in Compiler 
import random

# 1. రాండమ్ నెంబర్స్
dice_roll = random.randint(1, 6)
random_prob = random.random()
print(f"🎲 Rolled a dice: {dice_roll} | Probability: {random_prob:.4f}")

# 2. లిస్ట్ లోంచి లాటరీ తీయడం
participants = ["Alex", "Balaji", "Chloe", "David", "Elena", "Faisal"]
winner = random.choice(participants)
print(f"🏆 Lucky Winner (choice): {winner}")

# 3. ముగ్గురిని సెలెక్ట్ చేయడం (ఒకరు మళ్ళీ రాకుండా)
team = random.sample(participants, k=3)
print(f"👥 Selected Team (3 unique members): {team}")

# 4. పేకముక్కలు (Cards) కలపడం లాంటిది
cards = ["A♠", "K♥", "Q♦", "J♣", "10♠"]
random.shuffle(cards)
print(f"🃏 Shuffled Cards: {cards}")
🔍 సెక్యూరిటీ వార్నింగ్:

random మాడ్యూల్ ని కేవలం గేమ్స్ కి, సిమ్యులేషన్స్ కి మాత్రమే వాడాలి. బ్యాంకింగ్ పాస్వర్డ్స్, OTP లకి ఎప్పుడూ పైథాన్ secrets మాడ్యూల్ వాడాలి!

3The datetime మాడ్యూల్: టైమ్ మరియు డేట్ లాజిక్

datetime మాడ్యూల్ అనేది తేదీలు (dates), సమయం (times) తో ఆడుకోవడానికి బెస్ట్.

  • datetime.date(year, month, day): కేవలం తేదీ (Date) కోసం.
  • datetime.datetime.now(): ప్రస్తుత కచ్చితమైన టైం.
  • datetime.timedelta(...): ఇంకో 30 రోజులు కలపడం, లేదా టైం తీసేయడం లాంటి మ్యాథ్స్ కోసం.
  • Formatting:
    • strftime(format): టైం ని ఒక స్ట్రింగ్ (టెక్స్ట్) లాగా మార్చడం.
    • strptime(string, format): టెక్స్ట్ రూపంలో ఉన్న టైం ని మళ్ళీ పైథాన్ ఆబ్జెక్ట్ గా మార్చడం.
💻 Example 3: Working with datetime, timedeltas and formatting
Python 3 ▶ Run in Compiler 
import datetime as dt

# 1. ఇప్పటి టైం తీసుకుందాం
now = dt.datetime.now()
print("Current Timestamp:", now)

# 2. మనకు నచ్చినట్లు టెక్స్ట్ (స్ట్రింగ్) గా ఫార్మాట్ చేద్దాం
formatted_date = now.strftime("%A, %d %B %Y | %I:%M:%S %p")
print("Formatted Date:   ", formatted_date)

# 3. డేట్ మ్యాథ్స్ (ఇంకో 30 రోజులు కలుపుదాం)
today = dt.date.today()
expiry_date = today + dt.timedelta(days=30)
days_remaining = (expiry_date - today).days

print(f"\nSubscription Start: {today}")
print(f"Subscription Expiry: {expiry_date} ({days_remaining} days left)")

# 4. యూజర్ ఇచ్చిన టెక్స్ట్ ని డేట్ గా మారుద్దాం (Parsing)
user_input_str = "2026-12-25"
parsed_date = dt.datetime.strptime(user_input_str, "%Y-%m-%d").date()
print("Parsed Holiday Date:", parsed_date)
🔍 ఫార్మాట్ కోడ్స్ గుర్తుంచుకోండి:
  • %Y: సంవత్సరం (2026), %m: నెల (01-12), %d: రోజు (01-31).
  • %H: 24-గంటల టైం, %I: 12-గంటల టైం, %p: AM లేదా PM.
4The statistics మాడ్యూల్: డేటా అనాలిసిస్

statistics మాడ్యూల్ అనేది NumPy లాంటి పెద్ద లైబ్రరీల అవసరం లేకుండానే బేసిక్ స్టాటిస్టిక్స్ (సగటు, మధ్యగతం) చూసుకోవడానికి వాడతారు:

  • mean(data): యావరేజ్ కనుక్కుంటుంది.
  • median(data): ఆర్డర్ లో పెట్టి మధ్యలో ఉన్న వాల్యూ ఇస్తుంది.
  • mode(data): ఎక్కువసార్లు రిపీట్ అయినదాన్ని ఇస్తుంది.
  • stdev(data): స్టాండర్డ్ డీవియేషన్ (వాల్యూస్ ఎంత దూరం లో ఉన్నాయో) చెప్తుంది.
💻 Example 4: Statistical Metrics with statistics Module
Python 3 ▶ Run in Compiler 
import statistics as stats

exam_scores = [78, 85, 92, 85, 99, 64, 85, 90, 72, 88]

avg_score = stats.mean(exam_scores)
median_score = stats.median(exam_scores)
most_common = stats.mode(exam_scores)
spread = stats.stdev(exam_scores)

print("Dataset:", exam_scores)
print("=" * 40)
print(f"• Mean (Average):     {avg_score:.2f}")
print(f"• Median (Midpoint):  {median_score}")
print(f"• Mode (Most Common): {most_common}")
print(f"• Standard Deviation: {spread:.2f}")
🔍 ఇంటర్వ్యూ పాయింట్:

శాలరీలు లాంటి డేటాని చూసేటప్పుడు ఒకరి జీతం కోటి రూపాయలు ఉన్నా mean() (యావరేజ్) తప్పు చూపిస్తుంది. అలాంటి టైమ్ లో median() వాడటమే చాలా కరెక్ట్.

⚠️ Common Developer Pitfall: సెక్యూరిటీ కోసం random మాడ్యూల్ వాడటం

random మాడ్యూల్ లో నెంబర్స్ పక్కా రాండమ్ కాదు (Pseudo-random). ఒక హ్యాకర్ 624 అవుట్పుట్స్ చూసి నెక్స్ట్ ఏమొస్తుందో చెప్పేయగలడు. కాబట్టి పాస్వర్డ్స్ కి ఎప్పుడూ "secrets" మాడ్యూల్ వాడాలి.

💻 Hands-on Interactive Practice Challenge

ఒక ప్రోగ్రామ్ రాసి, ఒక 6-డిజిట్ రాండమ్ OTP జనరేట్ చేయండి. దానికి datetime వాడి ఇంకో 5 నిమిషాల్లో టైం అయిపోతుంది అని ప్రింట్ చేయండి.

Python 3 Practice Challenge ▶ Run in Compiler 
import random
import datetime as dt

otp = random.randint(100000, 999999)
now = dt.datetime.now()
expiry = now + dt.timedelta(minutes=5)

print(f"🔑 Your One-Time Password (OTP): {otp}")
print(f"⏳ Generated At: {now.strftime('%H:%M:%S')}")
print(f"⌛ Valid Until:  {expiry.strftime('%H:%M:%S')} (5 mins expiry)")

❓ Frequently Asked Questions (FAQ)

Q random.choice() కి random.choices() కి తేడా ఏంటి?

choice() ఒక్కటే ఇస్తుంది. choices() అనేది మీకు కావాల్సినన్ని (k=3) ఇస్తుంది, కానీ ఒకటే మళ్ళీ మళ్ళీ వచ్చే ఛాన్స్ ఉంది (with replacement).

Q random.seed() ఎందుకు వాడతారు?

ఒకవేళ మీరు random.seed(42) అని పైన రాస్తే, మీరు ఈ కోడ్ ఎప్పుడు రన్ చేసినా అవే రాండమ్ నెంబర్స్ వస్తాయి. టెస్టింగ్ లో కరెక్ట్ గా చెక్ చేసుకోవడానికి ఇది వాడతారు.
