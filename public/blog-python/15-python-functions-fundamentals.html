Python Functions Fundamentals (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 15 of 65 📂 Phase 4: Functions & Reusable Code 📅 2026 Edition
📌 Covered in this chapter: def · Parameters vs Arguments · return · Default Arguments · Keyword vs Positional · Calculator Project
Python లో మాడ్యులర్ ప్రోగ్రామింగ్ (Modular Programming): ఫంక్షన్స్ ఎలా రాయాలి, Parameters కి Arguments కి తేడా ఏంటి, multiple return values, మరియు రియల్-లైఫ్ క్యాలిక్యులేటర్ ప్రాజెక్ట్.
1Function అంటే ఏంటి? (Modular Architecture)

Function అనేది ఒక పేరుతో సేవ్ చేసుకునే కోడ్ బ్లాక్ (code block). దీని ముఖ్య ఉద్దేశ్యం DRY Principle (Don't Repeat Yourself) — అంటే ఒకే కోడ్ ని మళ్లీ మళ్లీ రాయకుండా, ఒక్కసారి రాసి ఎన్నిసార్లైనా వాడుకోవచ్చు.

మెమరీలో ఫంక్షన్స్ ఎలా రన్ అవుతాయి (The Call Stack):

┌────────────────────────────────────────────────────────┐ │ Call Stack Frame (calculate_tax) │ [Local variables allocated] ├────────────────────────────────────────────────────────┤ │ Call Stack Frame (main / module scope) │ [Pauses until function returns] └────────────────────────────────────────────────────────┘

మనం ఒక ఫంక్షన్ ని కాల్ చేయగానే, పైథాన్ మెమరీలో ఒక Stack Frame ని క్రియేట్ చేసి అందులో ఆ ఫంక్షన్ కి సంబంధించిన వేరియబుల్స్ ని పెట్టుకుంటుంది. return అవ్వగానే ఆ మెమరీ క్లీన్ అయిపోతుంది.

💻 Example 1: Defining, Calling and Returning Values from a Function
Python 3 ▶ Run in Compiler 
# 1. ఒక పునర్వినియోగ (reusable) ఫంక్షన్ ని డిఫైన్ చేద్దాం:
def calculate_total(price, tax_rate=0.18):
    """టాక్స్ తో కలిపి ఫైనల్ బిల్లు లెక్కించే ఫంక్షన్."""
    final_amount = price + (price * tax_rate)
    return round(final_amount, 2)

# 2. వివిధ వాల్యూస్ తో ఆ ఫంక్షన్ ని పిలుద్దాం (calling):
bill1 = calculate_total(100)        # tax ఇవ్వలేదు కాబట్టి డీఫాల్ట్ 18% వాడింది -> 118.0
bill2 = calculate_total(500, 0.05)  # ఇక్కడ 5% tax వాడింది -> 525.0

print("Order 1 Total: Rs.", bill1)
print("Order 2 Total: Rs.", bill2)
🔍 ఎక్జిక్యూషన్ బ్రేక్ డౌన్:
  • def calculate_total(...) అనేది ఫంక్షన్ ఆబ్జెక్ట్ ని క్రియేట్ చేసింది.
  • calculate_total(100) అనగానే price కి 100 వెళ్లింది. tax_rate ఆటోమేటిక్ గా 0.18 తీసుకుంది.
  • return స్టేట్మెంట్ ఫైనల్ రిజల్ట్ ని మనకు వెనక్కి ఇచ్చేసి తన పని ముగించుకుంది.
2Parameters కి Arguments కి తేడా & Multiple Return Values

చాలా మందికి ఇవి కన్ఫ్యూజన్ గా ఉంటాయి, క్లారిటీ తెచ్చుకోండి:

  • Parameters: ఫంక్షన్ ని డిఫైన్ చేసేటప్పుడు మనం ఇచ్చే పేర్లు (ఉదా: def add(x, y): లో x, y లు).
  • Arguments: ఫంక్షన్ ని కాల్ చేసేటప్పుడు మనం ఇచ్చే అసలు వాల్యూస్ (ఉదా: add(10, 20) లో 10, 20 లు).

ఒకేసారి చాలా వాల్యూస్ రిటర్న్ చేయడం: పైథాన్ లో ఒక ఫంక్షన్ కామాతో సెపరేట్ చేసి ఎన్ని వాల్యూస్ నైనా ఒకేసారి రిటర్న్ చేయొచ్చు. పైథాన్ దాన్ని ఆటోమాటిక్ గా ఒక tuple లో ప్యాక్ చేసి మనకు ఇస్తుంది:

💻 Example 2: Returning and Unpacking Multiple Values
Python 3 ▶ Run in Compiler 
# ఒకే ఫంక్షన్ నుంచి మూడింటిని (min, max, avg) రిటర్న్ చేద్దాం:
def get_min_max_avg(numbers_list):
    lowest = min(numbers_list)
    highest = max(numbers_list)
    average = sum(numbers_list) / len(numbers_list)
    
    # 3 ఐటమ్స్ రిటర్న్ చేస్తున్నాం (ఇది ట్యూపుల్ లాగా ప్యాక్ అవుతుంది):
    return lowest, highest, round(average, 2)

# వచ్చిన 3 రిజల్ట్స్ ని ఒకే లైన్ లో Unpack చేసుకుందాం:
test_scores = [78, 92, 64, 88, 95, 82]
min_val, max_val, avg_val = get_min_max_avg(test_scores)

print("Scores:", test_scores)
print(f"Lowest: {min_val} | Highest: {max_val} | Class Average: {avg_val}")
🔍 రిటర్న్ కాని ఫంక్షన్స్:

ఏదైనా ఫంక్షన్ లో మీరు అసలు return రాయకపోతే, పైథాన్ ఆటోమాటిక్ గా దానినుంచి None ని రిటర్న్ చేస్తుంది.

3Default Arguments & అస్సలు చేయకూడని తప్పు (Mutable Bug)

యూజర్ ఒక వాల్యూ ఇవ్వకపోతే తీసుకునేందుకు Default arguments వాడతాం. కానీ ఎప్పుడూ లిస్ట్ లేదా డిక్షనరీ లాంటివి (mutable) డిఫాల్ట్ గా ఇవ్వకూడదు!

ఎందుకంటే పైథాన్ ఈ డిఫాల్ట్ వాల్యూస్ ని ఫంక్షన్ క్రియేట్ అయినప్పుడు ఒక్కసారే కాలిక్యులేట్ చేసి పెట్టుకుంటుంది. ఒక లిస్ట్ ని ఇస్తే, మీరు ఎన్నిసార్లు ఫంక్షన్ పిలిచినా అదే పాత లిస్ట్ కంటిన్యూ అవుతూ డేటా కలుషితం అవుతుంది (Shared List Bug)!

💻 Example 3: Default Mutable Argument Bug vs None Sentinel Pattern
Python 3 ▶ Run in Compiler 
# ❌ ఇదొక ప్రమాదకరమైన బగ్ (Mutable Default):
def add_item_bad(item, target_list=[]):
    target_list.append(item)
    return target_list

print("Bad Call 1:", add_item_bad("Apple"))  # ['Apple']
print("Bad Call 2:", add_item_bad("Banana")) # ['Apple', 'Banana'] (అనుకోకుండా రెండు కలిసిపోయాయి!)

# ✅ సరైన పద్ధతి (None వాడటం):
def add_item_safe(item, target_list=None):
    if target_list is None:
        target_list = []  # ప్రతిసారి ఇక్కడ ఒక కొత్త ఫ్రెష్ లిస్ట్ క్రియేట్ అవుతుంది!
    target_list.append(item)
    return target_list

print("\nSafe Call 1:", add_item_safe("Apple"))  # ['Apple']
print("Safe Call 2:", add_item_safe("Banana")) # ['Banana'] (క్లీన్ గా సపరేట్ గా వచ్చాయి!)
🔍 గోల్డెన్ రూల్:

ఎప్పుడైనా డిఫాల్ట్ గా ఒక లిస్ట్ ని సెట్ చేయాలనుకుంటే, దానికి None ఇచ్చి లోపల కోడ్ లో [] ని అసైన్ చేసుకోవాలి.

4Positional vs Keyword Arguments (PEP 570)

ఫంక్షన్ కి వాల్యూస్ పంపేటప్పుడు డైరెక్ట్ గా ఆర్డర్ లో పంపొచ్చు (Positional), లేదా పేరు చెప్పి పంపొచ్చు (Keyword). పైథాన్ లో ఈ ఆర్డర్ ని కంట్రోల్ చేయడానికి రెండు సింబల్స్ వాడతారు:

  • /: దీనికి ముందున్నవి Positional-Only (వాటికి పేర్లు చెప్పి పంపకూడదు).
  • *: దీని తర్వాతివి Keyword-Only (కచ్చితంగా పేరు చెప్పే పంపాలి).
💻 Example 4: Positional-Only and Keyword-Only Arguments
Python 3 ▶ Run in Compiler 
# / కి ముందు Positional, * కి తర్వాత Keyword-Only:
def create_user(username, email, /, *, is_admin=False, send_email=True):
    return {
        "username": username,
        "email": email,
        "is_admin": is_admin,
        "send_email": send_email
    }

# కరెక్ట్ గా కాల్ చేయడం:
user1 = create_user("balaji", "balaji@test.com", is_admin=True)
print("Created User:", user1)
🔍 API డిజైన్:

చివర్లో Keyword-Only వాడటం వల్ల, ఎవరైనా ఫంక్షన్ వాడేటప్పుడు True అని వదిలేయకుండా is_admin=True అని క్లియర్ గా రాస్తారు. ఇది చదవడానికి బాగుంటుంది.

5Practical Project 1: క్యాలిక్యులేటర్ ఇంజిన్ (Calculator Engine)

ఎలాంటి కన్ఫ్యూజన్ లేకుండా సింపుల్ ఫంక్షన్స్ తో ఒక క్యాలిక్యులేటర్ లాజిక్ డిజైన్ చేయడం:

💻 Example 5: Modular Calculator Engine Project
Python 3 ▶ Run in Compiler 
# Modular Calculator Functions
def add(a, b): return a + b
def subtract(a, b): return a - b
def multiply(a, b): return a * b
def divide(a, b):
    if b == 0:
        return "❌ Error: Cannot divide by zero!"
    return a / b

# మెయిన్ ఫంక్షన్
def calculate(num1, num2, operation):
    operations_map = {
        "+": add,
        "-": subtract,
        "*": multiply,
        "/": divide
    }
    func = operations_map.get(operation)
    if func:
        return func(num1, num2)
    return "❌ Invalid Operator!"

# టెస్ట్ చేద్దాం:
print("10 + 5 =", calculate(10, 5, "+"))
print("10 - 4 =", calculate(10, 4, "-"))
print("10 * 3 =", calculate(10, 3, "*"))
print("10 / 2 =", calculate(10, 2, "/"))
print("10 / 0 =", calculate(10, 0, "/"))
🔍 ఆర్కిటెక్చర్ గమనించండి:

ఫంక్షన్స్ ని డైరెక్ట్ గా ఒక డిక్షనరీ (operations_map) లో పెట్టి పిలవడం వల్ల పెద్ద పెద్ద if-else కండిషన్స్ రాసే పని తప్పింది! దీన్నే Dispatch Pattern అంటారు.

⚠️ Common Developer Pitfall: డిఫాల్ట్ ఉన్నవాటి తర్వాత డిఫాల్ట్ లేనివి పెట్టడం

def func(a=10, b): అని రాస్తే SyntaxError: non-default argument follows default argument వస్తుంది. ఎందుకంటే, డిఫాల్ట్ లేనివి అన్నీ ముందు రాయాలి, డిఫాల్ట్ వాల్యూస్ ఉన్నవేమో ఫంక్షన్ చివర్లో మాత్రమే రాయాలి.

💻 Hands-on Interactive Practice Challenge

ఒక ఫంక్షన్ convert_temperature(celsius) రాసి దాన్ని Fahrenheit లోకి మరియు Kelvin లోకి మార్చి రెంటినీ ఒకేసారి ట్యూపుల్ ద్వారా రిటర్న్ చేయండి.

Python 3 Practice Challenge ▶ Run in Compiler 
def convert_temperature(celsius):
    fahrenheit = (celsius * 9/5) + 32
    kelvin = celsius + 273.15
    return fahrenheit, kelvin

f, k = convert_temperature(25)
print("25°C in Fahrenheit:", f, "°F")
print("25°C in Kelvin:    ", k, "K")

❓ Frequently Asked Questions (FAQ)

Q Parameter కి Argument కి తేడా మళ్లీ చెప్తారా?

ఫంక్షన్ ని క్రియేట్ చేస్తున్నప్పుడు బ్రాకెట్స్ లో ఇచ్చే వేరియబుల్స్ పేరు Parameter (అది ఒక ఖాళీ డబ్బా లాంటిది). ఫంక్షన్ ని వాడుకునేటప్పుడు అందులోకి పంపించే అసలు డేటాని Argument అంటారు.

Q నేను ఒక లిస్ట్ ని డిఫాల్ట్ ఆర్గ్యుమెంట్ గా ఇస్తే ఏమవుతుంది?

డిఫాల్ట్ వాల్యూ ఒకేసారి క్రియేట్ అవుతుంది కాబట్టి, మీరు ఎన్నిసార్లు ఫంక్షన్ ని పిలిచినా అదే పాత లిస్ట్ లోకే మీ ఐటమ్స్ వెళ్తాయి. అందుకే ఎప్పుడూ None ని డిఫాల్ట్ గా వాడి, లోపల కొత్త లిస్ట్ అసైన్ చేయాలి.
