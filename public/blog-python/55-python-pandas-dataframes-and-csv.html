Pandas Series, DataFrames & CSV (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 55 of 65 📂 Phase 11: Data Science and AI 📅 2026 Edition
📌 Covered in this chapter: Series vs DataFrame Architecture · Loading CSV/JSON · head() & info() Exploration · loc (Label) vs iloc (Integer) · Boolean Query Filtering · Multi-Column Sorting
డేటా సైన్స్ లో ఎక్కువగా వాడే టూల్ Pandas. ఎక్సెల్ ఫైల్స్ ని, CSV ఫైల్స్ ని చదవడం, అందులో పనికిరాని డేటాని క్లీన్ చేయడం, మనకు కావాల్సిన డేటాని వెతకడం (Filtering) ఎలాగో చూద్దాం.
1Pandas అంటే ఏంటి? (Series మరియు DataFrame)

Pandas అంటే పైథాన్ వాళ్ళ ఎక్సెల్ లాంటిది. లక్షల కొద్దీ రోస్ ఉన్న డేటాని క్షణాల్లో ప్రాసెస్ చేయగలదు.

Pandas లో ఉండే 2 మెయిన్ ఆబ్జెక్ట్స్:

  • Series (1D): ఇది ఒకే ఒక్క నిలువు వరుస (Column). (ఉదా: వయసుల లిస్ట్).
  • DataFrame (2D): ఇది అచ్చం స్ప్రెడ్ షీట్ లాంటిది. అడ్డు వరుసలు (Rows), నిలువు వరుసలు (Columns) కలిపి ఒక టేబుల్ లాగా ఉంటుంది.
┌────────────────────────────────────────────────────────────────────────┐ │ PANDAS DATAFRAME స్ట్రక్చర్ │ ├────────────────────────────────────────────────────────────────────────┤ │ Columns (Series పేర్లు) │ │ ┌──────────────┬──────────────┬──────────────┐ │ │ Index (Row పేర్లు) │ "name" (str) │ "age" (int) │"salary"(flt) │ │ │ ┌─────────────────────┼──────────────┼──────────────┼──────────────┤ │ │ │ 0 │ Balaji Dev │ 28 │ 95000.00 │ │ │ │ 1 │ Alex Smith │ 34 │ 82000.00 │ │ │ │ 2 │ Chloe Davis │ 25 │ 78000.00 │ │ │ └─────────────────────┴──────────────┴──────────────┴──────────────┘ │ │ ├── df.shape -> (3, 3) [3 rows, 3 columns] │ │ ├── df['salary'] -> ఒక్క కాలమ్ (Series) బయటకు వస్తుంది │ └────────────────────────────────────────────────────────────────────────┘
💻 Example 1: Tabular Dataset Representation in Memory
Python 3 ▶ Run in Compiler 
# డేటాఫ్రేమ్ ఎలా ఉంటుందో చూద్దాం (పైథాన్ డిక్షనరీలతో పోల్చి):
tabular_dataset = [
    {"emp_id": 101, "name": "Balaji", "dept": "AI", "salary": 95000},
    {"emp_id": 102, "name": "Alex",   "dept": "Cloud", "salary": 82000},
    {"emp_id": 103, "name": "Chloe",  "dept": "Data", "salary": 88000}
]

print("--- 📊 డేటాసెట్ (3 రోస్ x 4 కాలమ్స్) ---")
header = f"{'ID':<6} {'Name':<10} {'Dept':<10} {'Salary':<10}"
print(header)
print("-" * len(header))
for row in tabular_dataset:
    print(f"{row['emp_id']:<6} {row['name']:<10} {row['dept']:<10} ₹{row['salary']:<10,}")
🔍 Pandas ఫంక్షన్స్:
  • df.head(5): మొదటి 5 రోస్ చూపిస్తుంది (లక్షల డేటా ఉన్నప్పుడు వాడతాం).
  • df.info(): ఏ కాలమ్ లో ఏ డేటా ఉంది, ఫైల్ సైజ్ ఎంత అని చెప్తుంది.
  • df.describe(): నెంబర్స్ ఉన్న కాలమ్స్ కి ఆవరేజ్, మినిమమ్, మ్యాక్సిమమ్ లెక్కేస్తుంది.
2డేటాని వెతకడం: .loc (లేబుల్స్) vs .iloc (నెంబర్స్)

Pandas లో టేబుల్ లోపలికి వెళ్లి డేటాని తీసుకోవాలంటే రెండు ఆప్షన్స్ ఉంటాయి. ఇవి చాలా ఇంపార్టెంట్ కన్ఫ్యూజ్ కాకుండా గుర్తుపెట్టుకోవాలి.

విధానంఎలా రాయాలి?ఏంటి డిఫరెన్స్?
.loc[]df.loc['row_name', 'col_name']పేర్లు/లేబుల్స్ (Names) వాడి వెతుకుతుంది.
.iloc[]df.iloc[0, 1]సొన్న (0, 1, 2) లాంటి ఇండెక్స్ నెంబర్స్ వాడి వెతుకుతుంది.
💻 Example 2: loc vs iloc Indexing & Boolean Filtering
Python 3 ▶ Run in Compiler 
# .loc, .iloc లాజిక్ ని సిమ్యులేట్ చేద్దాం:
employees = {
    101: {"name": "Balaji", "role": "Lead", "salary": 95000},
    102: {"name": "Alex",   "role": "DevOps", "salary": 82000},
    103: {"name": "Chloe",  "role": "Data", "salary": 88000}
}

# 1. .loc (పేరును బట్టి వెతకడం):
# "101" అనే ఐడీతో ఉన్న వాళ్ళ శాలరీ కావాలి:
loc_sample = employees[101]["salary"]
print(f"loc రిజల్ట్ (ఐడీ 101): ₹{loc_sample:,}")

# 2. .iloc (వరుస సంఖ్యను బట్టి వెతకడం):
# లిస్ట్ లో ఫస్ట్ ఉన్న (index 0) ఎంప్లాయ్ పేరు కావాలి:
row_keys = list(employees.keys())
iloc_sample = employees[row_keys[0]]["name"]
print(f"iloc రిజల్ట్ (1st లైన్): {iloc_sample}")

# 3. ఫిల్టరింగ్ (85,000 కంటే ఎక్కువ శాలరీ ఉన్నవాళ్లు ఎవరు?):
high_earners = [e for e in employees.values() if e["salary"] >= 85000]
print(f"\n85k కంటే ఎక్కువ శాలరీ ఉన్నవాళ్లు: {len(high_earners)} మంది.")
🔍 Pandas లో ఫిల్టరింగ్:

నిజంగా పాండాస్ లో రాయాలంటే ఇలా రాస్తాం: df[(df['salary'] >= 85000) & (df['dept'] == 'AI')] (రెండింటికీ బ్రాకెట్స్ పెట్టడం మర్చిపోకూడదు!).

⚠️ Common Developer Pitfall: Pandas లో "and" / "or" వాడటం

నార్మల్ పైథాన్ లో `and`, `or` వాడినట్టు Pandas లో వాడితే "ValueError" వస్తుంది. Pandas లో డేటాని ఫిల్టర్ చేసేటప్పుడు కచ్చితంగా `&` (AND కోసం), `|` (OR కోసం) వాడాలి.

ఒక ప్రోడక్ట్స్ లిస్ట్ ని ఫస్ట్ కేటగిరీ (A to Z), ఆ తర్వాత ప్రైస్ (హై టు లో) ని బట్టి సార్ట్ చేయండి.

Python 3 Practice Challenge ▶ Run in Compiler 
products = [
    {"name": "Mouse", "cat": "Tech", "price": 800},
    {"name": "Desk", "cat": "Furniture", "price": 4500},
    {"name": "Laptop", "cat": "Tech", "price": 55000},
    {"name": "Chair", "cat": "Furniture", "price": 3200}
]

# Pandas లో: df.sort_values(by=["cat", "price"], ascending=[True, False])
sorted_prods = sorted(products, key=lambda x: (x["cat"], -x["price"]))
print("సార్ట్ చేసిన ప్రోడక్ట్స్:")
for p in sorted_prods:
    print(f"• [{p['cat']:9}] {p['name']:10} - ₹{p['price']:,}")
