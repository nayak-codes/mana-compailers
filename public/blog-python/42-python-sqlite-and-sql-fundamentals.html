Python SQLite & SQL Fundamentals (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 42 of 65 📂 Phase 9: Databases and APIs 📅 2026 Edition
📌 Covered in this chapter: Relational DB Theory · SQLite Embedded Architecture · SQLite vs Client-Server · sqlite3 Module · CREATE TABLE DDL · INSERT & SELECT · executemany() · sqlite3.Row Mapping
డేటాని ఫైల్స్ లో కాకుండా డేటాబేస్ లో ఎందుకు స్టోర్ చేయాలి? టేబుల్స్, Primary Keys అంటే ఏంటి? పైథాన్ లో డీఫాల్ట్ గా వచ్చే `sqlite3` ని వాడి డేటాని ఎలా సేవ్ చేయాలి, ఎలా వెతకాలో నేర్చుకుందాం.
1డేటాబేస్ అంటే ఏంటి? ఫైల్స్ (TXT, CSV) ఎందుకు పనికిరావు?

కోడ్ రాయడానికి ముందు అసలు డేటాబేస్ ఎందుకు అవసరం అని తెలుసుకోవడం చాలా ముఖ్యం. మామూలుగా మనం డేటాని .txt లేదా .csv ఫైల్స్ లో స్టోర్ చేస్తే 4 పెద్ద ప్రాబ్లమ్స్ వస్తాయి:

  1. ఒకేసారి ఇద్దరు ఓపెన్ చేస్తే (Concurrency): అమెజాన్ లో ఒకే ఫోన్ మిగిలింది అనుకోండి. ఇద్దరు ఒకేసారి కొంటే, ఫైల్ అయితే ఇద్దరికీ ఫోన్ ఉందని చెప్పి 2 ఆర్డర్స్ తీసుకుంటుంది. డేటాబేస్ అయితే ఒకరిని ఆపి కరెక్ట్ గా మేనేజ్ చేస్తుంది.
  2. చాలా స్లో (No Indexing): 10 లక్షల రికార్డ్స్ ఉన్న ఫైల్ లో ఐడీ 98421 కోసం వెతకాలంటే ఫైల్ మొత్తం మొదటినుంచి స్కాన్ చేయాలి (చాలా స్లో). డేటాబేస్ లో అయితే B-Trees అనే టెక్నిక్ వల్ల మైక్రో-సెకండ్స్ లో దొరుకుతుంది.
  3. రూల్స్ ఉండవు: వయసు (age) అనే చోట ఎవరైనా 'ABC' అని రాస్తే ఫైల్ ఏమీ అనదు. డేటాబేస్ అయితే ఎర్రర్ ఇచ్చి ఆపేస్తుంది (Data Integrity).
  4. క్రాష్ అయితే గోవిందా: ఫైల్ లో సేవ్ అవుతున్నప్పుడు పవర్ పోతే ఫైల్ మొత్తం కరప్ట్ అయిపోయి డేటా పోతుంది. డేటాబేస్ అయితే సేఫ్ గా ఉంటుంది.

రిలేషనల్ డేటాబేస్ (Tables, Rows, Columns, Keys):

RDBMS (Relational Database) లో డేటా అంతా ఎక్సెల్ షీట్ లాగా టేబుల్స్ లో ఉంటుంది:

  • Columns: ఏ డేటా వస్తుందో ముందే చెప్తాయి (ఉదా: id: INTEGER, name: TEXT).
  • Rows: డేటా రికార్డ్స్ (ఒక పర్సన్ డీటెయిల్స్).
  • Primary Key (PK): ప్రతి రో కి ఇచ్చే ఒక యూనిక్ నెంబర్ (ఆధార్ కార్డ్ లాగా). ఒకే నెంబర్ ఇద్దరికీ ఉండదు.
  • Foreign Key (FK): ఒక టేబుల్ లోని డేటాని, ఇంకో టేబుల్ లోని డేటాకి లింక్ చేయడానికి వాడే నెంబర్. (ఉదా: ఆర్డర్స్ టేబుల్ లో యూజర్ ఐడీ).
💻 Concept Blueprint: Relational Database Architecture Overview
Python 3 ▶ Run in Compiler 
# కాన్సెప్ట్ అర్థం చేసుకోవడానికి:
schema_explanation = {
    "Table": "ఒక ఎక్సెల్ షీట్ లాంటిది (ఉదా: Users టేబుల్)",
    "Column": "ఏ టైప్ డేటా వస్తుందో చెప్తుంది (ఉదా: email: TEXT)",
    "Row": "ఒక మనిషి/వస్తువు మొత్తం డీటెయిల్స్ (ఒక రికార్డ్)",
    "Primary Key": "ఎవరో గుర్తుపట్టడానికి వాడే యూనిక్ ఐడీ (ఉదా: user_id = 101)",
    "Foreign Key": "రెండు టేబుల్స్ ని కలపడానికి వాడే లింక్"
}

for concept, definition in schema_explanation.items():
    print(f"📌 {concept:15}: {definition}")
💡 రియల్ లైఫ్ ఎగ్జాంపుల్:

Primary Key అంటే మీ ఆధార్ నెంబర్ లాంటిది. ఇద్దరు వ్యక్తులకు ఒకే పేరు ఉండొచ్చు కానీ ఆధార్ ఒకటే ఉండదు కదా. Foreign Key అంటే మీ పాస్పోర్ట్ అప్లికేషన్ లో మీ ఆధార్ నెంబర్ రాయడం లాంటిది (పాస్పోర్ట్ ని ఆధార్ కి లింక్ చేయడం).

2SQLite స్పెషాలిటీ ఏంటి? (Serverless)

పెద్ద డేటాబేస్ లు (PostgreSQL, MySQL లాంటివి) ఒక సపరేట్ సర్వర్ లాగా రన్ అవుతాయి. మన పైథాన్ కోడ్ వాటికి నెట్వర్క్ ద్వారా కనెక్ట్ అవ్వాలి (పోర్ట్స్, పాస్వర్డ్స్ ఇచ్చి).

కానీ SQLite స్పెషాలిటీ ఏంటంటే, దీనికి సర్వర్ అవసరం లేదు (Serverless). డేటాబేస్ ఇంజిన్ మొత్తం మన పైథాన్ లోనే ఉంటుంది. డేటా అంతా మన ఫోల్డర్ లో ఒక చిన్న ఫైల్ (.db) లో సేవ్ అవుతుంది.

SQLite ఎప్పుడు వాడాలి?

  • ఆండ్రాయిడ్ యాప్స్, గూగుల్ క్రోమ్, డెస్క్ టాప్ యాప్స్ లోకల్ గా డేటాని సేవ్ చేయడానికి వాడతాయి.
  • టెస్టింగ్ అప్పుడు ర్యామ్ (":memory:") లో ఫాస్ట్ గా రన్ చేయడానికి.
  • రోజుకి లక్ష మంది వచ్చే చిన్న/మీడియం వెబ్సైట్స్ కి కూడా ఇది సూపర్ గా పనిచేస్తుంది.
💻 Example 1: Establishing SQLite Connection and Creating Relational Tables
Python 3 ▶ Run in Compiler 
import sqlite3

# 1. డేటాబేస్ కి కనెక్ట్ అవుదాం (ఒకవేళ ఫైల్ లేకపోతే అదే క్రియేట్ చేస్తుంది):
conn = sqlite3.connect("company.db")

# 2. ఒక Cursor (పాయింటర్) ని క్రియేట్ చేద్దాం:
# దీని ద్వారానే మనం SQL కమాండ్స్ పంపిస్తాం.
cursor = conn.cursor()

# 3. 'departments' (డిపార్ట్మెంట్స్) టేబుల్ క్రియేట్ చేద్దాం:
cursor.execute("""
CREATE TABLE IF NOT EXISTS departments (
    dept_id INTEGER PRIMARY KEY AUTOINCREMENT,
    dept_name TEXT NOT NULL UNIQUE,
    budget REAL NOT NULL
)
""")

# 4. 'employees' (ఎంప్లాయిస్) టేబుల్ క్రియేట్ చేద్దాం (Foreign Key తో):
cursor.execute("""
CREATE TABLE IF NOT EXISTS employees (
    emp_id INTEGER PRIMARY KEY AUTOINCREMENT,
    full_name TEXT NOT NULL,
    email TEXT NOT NULL UNIQUE,
    salary REAL NOT NULL,
    dept_id INTEGER,
    joined_date DATE DEFAULT CURRENT_DATE,
    FOREIGN KEY (dept_id) REFERENCES departments(dept_id)
)
""")

conn.commit() # మనం చేసిన మార్పులని ఫైల్ లోకి పర్మినెంట్ గా సేవ్ చేయాలి
print("✅ డేటాబేస్ టేబుల్స్ సక్సెస్ ఫుల్ గా క్రియేట్ అయ్యాయి!")
conn.close() # పని అయ్యాక కనెక్షన్ క్లోజ్ చేయాలి
🔍 SQL రూల్స్ (Constraints):

NOT NULL అంటే ఆ కాలమ్ ఖాళీగా వదలకూడదు. UNIQUE అంటే ఆ ఈమెయిల్ తో ఇద్దరు ఎంప్లాయిస్ ఉండకూడదు.

3డేటాని మేనేజ్ చేయడం (CRUD ఆపరేషన్స్)

CRUD అంటే Create (డేటా పెట్టడం), Read (చదవడం), Update (మార్చడం), Delete (తీసేయడం).

1. ఒకేసారి చాలా డేటా ఎక్కించడం (executemany):

ఒక్కో రికార్డ్ ని ఎక్కిస్తే చాలా స్లో అవుతుంది. cursor.executemany() వాడితే 1000 రికార్డ్స్ ని కూడా 5 మిల్లీ-సెకండ్స్ లోపల ఎక్కించేయొచ్చు!

2. డేటాని డిక్షనరీ లాగా తెచ్చుకోవడం (sqlite3.Row):

మామూలుగా అయితే డేటా (1, 'Balaji', 95000) లాగా టపుల్స్ లో వస్తుంది. అలా కాకుండా conn.row_factory = sqlite3.Row అని పెడితే, మనం కాలమ్ పేరుతో (ఉదా: row['full_name']) డేటాని చాలా క్లీన్ గా చదువుకోవచ్చు.

💻 Example 2: Complete Relational CRUD & JOIN Queries with sqlite3.Row
Python 3 ▶ Run in Compiler 
import sqlite3

conn = sqlite3.connect("company.db")
conn.row_factory = sqlite3.Row  # డేటాని డిక్షనరీ లాగా తెచ్చుకోవడానికి
cursor = conn.cursor()

# Foreign Keys పనిచేయడానికి ఆన్ చేయాలి:
cursor.execute("PRAGMA foreign_keys = ON")

# 1. CREATE: డిపార్ట్మెంట్స్ డేటాని ఎక్కిద్దాం:
departments_data = [
    ("Engineering", 5000000.0),
    ("Product Design", 2000000.0),
    ("Human Resources", 1200000.0)
]
cursor.executemany("INSERT OR IGNORE INTO departments (dept_name, budget) VALUES (?, ?)", departments_data)

# ఎంప్లాయిస్ డేటాని ఎక్కిద్దాం:
employees_data = [
    ("Balaji Dev", "balaji.dev@company.com", 95000.0, 1),
    ("Alex Smith", "alex.smith@company.com", 82000.0, 1),
    ("Chloe Davis", "chloe.d@company.com", 78000.0, 2)
]
cursor.executemany("INSERT OR IGNORE INTO employees (full_name, email, salary, dept_id) VALUES (?, ?, ?, ?)", employees_data)
conn.commit()

# 2. READ: ఎంప్లాయిస్ వివరాలు (JOIN వాడి డిపార్ట్మెంట్ పేరు కూడా తెద్దాం):
print("--- 📋 ఎంప్లాయిస్ రిపోర్ట్ ---")
cursor.execute("""
SELECT e.emp_id, e.full_name, e.salary, d.dept_name
FROM employees e
JOIN departments d ON e.dept_id = d.dept_id
WHERE e.salary >= ?
ORDER BY e.salary DESC
""", (70000.0,))

high_earners = cursor.fetchall()
for emp in high_earners:
    # డిక్షనరీ లాగా కాలమ్ పేరుతో డేటా తీయొచ్చు:
    print(f"• ID #{emp['emp_id']}: {emp['full_name']:18} | Dept: {emp['dept_name']:15} | Salary: ₹{emp['salary']:,.2f}")

# 3. UPDATE: ఇంజనీరింగ్ వాళ్ళకి 10% శాలరీ పెంచుదాం:
cursor.execute("""
UPDATE employees
SET salary = salary * 1.10
WHERE dept_id = 1
""")
print(f"\n📈 {cursor.rowcount} మంది శాలరీ 10% పెంచాం!")

conn.commit()
conn.close()
🔍 ముఖ్యమైన పాయింట్స్:
  • JOIN ... ON అంటే రెండు టేబుల్స్ లోని డేటాని లింక్ చేసి (డిపార్ట్మెంట్ ఐడీ మ్యాచ్ చేసి) కంబైన్డ్ రిపోర్ట్ ఇవ్వడం.
  • cursor.rowcount వాడితే మనం ఎన్ని రోస్ ని మార్చామో లేదా డిలీట్ చేసామో తెలుస్తుంది.
⚠️ Common Developer Pitfall: SQLite లో PRAGMA ఆన్ చేయకపోవడం

SQLite లో డీఫాల్ట్ గా Foreign Keys పని చేయవు (పాత వెర్షన్స్ కోసం అలా ఉంచారు). కాబట్టి కనెక్షన్ ఓపెన్ చేసిన ప్రతిసారీ "PRAGMA foreign_keys = ON" అని రన్ చేయాలి. లేకపోతే తప్పుడు ఐడీలు ఇచ్చినా తీసుకుంటుంది!

💻 Hands-on Interactive Practice Challenge

మెమరీలో ఒక inventory టేబుల్ (item_id, name, quantity) క్రియేట్ చేసి, 3 ఐటమ్స్ వేసి, ఒకదాని క్వాంటిటీ అప్డేట్ చేసి, 10 కంటే ఎక్కువ ఉన్నవి ప్రింట్ చేయండి.

Python 3 Practice Challenge ▶ Run in Compiler 
import sqlite3

conn = sqlite3.connect(":memory:")
conn.row_factory = sqlite3.Row
cur = conn.cursor()

cur.execute("CREATE TABLE inventory (item_id INTEGER PRIMARY KEY, name TEXT, quantity INTEGER)")
cur.executemany("INSERT INTO inventory VALUES (?, ?, ?)", [
    (1, "SSD 1TB", 25),
    (2, "RAM 16GB", 8),
    (3, "Monitor", 14)
])
cur.execute("UPDATE inventory SET quantity = 30 WHERE item_id = 1")
conn.commit()

cur.execute("SELECT * FROM inventory WHERE quantity > 10")
for row in cur.fetchall():
    print(f"Item #{row['item_id']}: {row['name']} (Stock: {row['quantity']})")
conn.close()

Q నేను డెస్క్ టాప్ యాప్స్ కి SQLite బదులు ఫైల్స్ ఎందుకు వాడకూడదు?

SQLite అయితే పవర్ పోయినా డేటా కరప్ట్ అవ్వకుండా సేఫ్ గా ఉంటుంది. ఎంత డేటా ఉన్నా సెర్చ్ చేయడం చాలా ఫాస్ట్ గా ఉంటుంది.

Q Write-Ahead Logging (WAL) అంటే ఏంటి?

ఇది ఒక స్పెషల్ మోడ్. ఇది ఆన్ చేస్తే (PRAGMA journal_mode=WAL;), డేటాని ముందు ఒక లాగ్ ఫైల్ లో రాసుకుంటుంది. దీనివల్ల ఒకరు డేటా రాస్తున్నప్పుడు వేరేవాళ్ళు వెయిట్ చేయకుండా చదువుకోవచ్చు (స్పీడ్ పెరుగుతుంది).
