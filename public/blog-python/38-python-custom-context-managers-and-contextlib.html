Context Managers & contextlib (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 38 of 65 📂 Phase 8: Advanced Python 📅 2026 Edition
📌 Covered in this chapter: __enter__() and __exit__() Protocol · Suppressing Exceptions · @contextmanager Generator · Database Transaction & Timer Contexts
ఫైల్స్ ని, డేటాబేస్ కనెక్షన్స్ ని మర్చిపోకుండా ఎలా క్లోజ్ చేయాలి? Context Managers (__enter__, __exit__) మరియు contextlib వాడి `with` స్టేట్మెంట్ ని మనకు నచ్చినట్టు ఎలా వాడుకోవాలో చూద్దాం.
1Context Manager Protocol (__enter__ మరియు __exit__)

పైథాన్ లో మనం with open("file.txt") as f: అని రాస్తాం కదా? ఇందులో ఫైల్ ఓపెన్ అయ్యాక, ఆటోమాటిక్ గా ఎలా క్లోజ్ అవుతుంది? దీనికోసం Context Manager Protocol వాడతారు.

ఒక క్లాస్ లో రెండు మెథడ్స్ రాస్తే అది కాంటెక్స్ట్ మేనేజర్ అవుతుంది:

  1. __enter__(self): ఇది with బ్లాక్ స్టార్ట్ అవ్వగానే రన్ అవుతుంది.
  2. __exit__(self, exc_type, exc_val, exc_tb): ఇది with బ్లాక్ అవ్వగానే రన్ అవుతుంది. లోపల ఏమైనా ఎర్రర్ వస్తే ఆ డీటెయిల్స్ ఇందులో ఉంటాయి. ఒకవేళ ఇక్కడ True రిటర్న్ చేస్తే, ఆ ఎర్రర్ బయటకి రాకుండా ఆగిపోతుంది!
💻 Example 1: Class-based Context Manager with __enter__ and __exit__
Python 3 ▶ Run in Compiler 
# మన ఓన్ ఫైల్ మేనేజర్ క్లాస్ ని రాద్దాం:
class ManagedFile:
    def __init__(self, filename, mode):
        self.filename = filename
        self.mode = mode
        self.file = None

    def __enter__(self):
        print(f"🔓 [__enter__] ఫైల్ ఓపెన్ చేస్తున్నాను: {self.filename}")
        self.file = open(self.filename, self.mode, encoding="utf-8")
        return self.file # ఇది 'as f' లోకి వెళ్తుంది

    def __exit__(self, exc_type, exc_val, exc_tb):
        print(f"🔒 [__exit__] ఫైల్ క్లోజ్ చేస్తున్నాను: {self.filename}")
        if self.file:
            self.file.close()
        # False రిటర్న్ చేస్తే ఎర్రర్స్ బయటకి మామూలుగానే వస్తాయి
        return False

# మన క్లాస్ ని 'with' వాడి టెస్ట్ చేద్దాం:
with ManagedFile("demo_context.txt", "w") as f:
    f.write("హలో! మన సొంత కాంటెక్స్ట్ మేనేజర్ నుండి రాస్తున్నాను! 🚀\n")

print("ఫైల్ క్లోజ్ అయ్యిందా?", f.closed) # True!
🔍 లాభం ఏంటి?:

ఒకవేళ మీరు ఫైల్ లో రాసేటప్పుడు పవర్ కట్ అయ్యి ఎర్రర్ (ఉదా: 0 తో డివైడ్ చేయడం) వచ్చినా సరే, __exit__ ఖచ్చితంగా రన్ అయ్యి ఫైల్ ని సేఫ్ గా క్లోజ్ చేస్తుంది.

2contextlib.contextmanager (చిన్న షార్ట్ కట్)

ప్రతి చిన్నదానికీ ఇంత పెద్ద క్లాస్ రాయాలంటే చిరాకు కదా? అందుకే పైథాన్ లో @contextmanager అని ఒక డెకరేటర్ ఇచ్చారు. దీన్ని ఒక చిన్న జనరేటర్ ఫంక్షన్ (yield) పైన పెడితే, అదే కాంటెక్స్ట్ మేనేజర్ అయిపోతుంది!

1. yield పైన ఉన్న కోడ్ ==> __enter__ లో రన్ అవుతుంది 2. yield లో ఇచ్చే వాల్యూ ==> 'as x' లోకి వెళ్తుంది 3. yield కింద ఉన్న కోడ్ ==> __exit__ (finally లోపల) రన్ అవుతుంది
💻 Example 2: Elegant Generator Context Manager with contextlib
Python 3 ▶ Run in Compiler 
import time
from contextlib import contextmanager

# 1. 8 లైన్స్ లో టైమర్ కాంటెక్స్ట్ మేనేజర్:
@contextmanager
def code_timer(label="పని"):
    start = time.perf_counter()
    print(f"⏳ [{label}] స్టార్ట్ అయ్యింది...")
    try:
        yield # with బ్లాక్ లోపల ఉన్న కోడ్ అంతా ఇక్కడ రన్ అవుతుంది!
    finally:
        end = time.perf_counter()
        duration_ms = (end - start) * 1000
        print(f"⌛ [{label}] కంప్లీట్ అయ్యింది! ({duration_ms:.3f} ms పట్టింది)")

# మన టైమర్ ని వాడదాం:
with code_timer("డేటా ప్రాసెసింగ్"):
    # ఇక్కడ పెద్ద ప్రాసెస్ ఏదైనా రన్ చేయొచ్చు
    results = [x ** 2 for x in range(300_000)]
    time.sleep(0.05)
🔍 try-finally రూల్:

yield కింద రాసే క్లీన్-అప్ కోడ్ ఖచ్చితంగా finally: బ్లాక్ లోపలే రాయాలి. లేకపోతే లోపల ఎర్రర్ వస్తే క్లీన్-అప్ కోడ్ రన్ అవ్వదు.

⚠️ Common Developer Pitfall: Generator లో try-finally వాడకపోవడం

మీరు yield రాసి దాని కింద డైరెక్ట్ గా కోడ్ రాస్తే, with బ్లాక్ లో ఏమైనా ఎర్రర్ వస్తే ఆ కింద ఉన్న కోడ్ (క్లీన్-అప్) రన్ అవ్వకుండానే ఆగిపోతుంది. అందుకే ఎప్పుడూ yield ని try లో పెట్టి, క్లీన్-అప్ కోడ్ finally లో రాయాలి.

💻 Hands-on Interactive Practice Challenge

ఒక కాంటెక్స్ట్ మేనేజర్ temporary_setting రాయండి. ఒక డిక్షనరీ లో ఒక కీ కి టెంపరరీగా ఒక వాల్యూ ఇచ్చి, with బ్లాక్ అవ్వగానే పాత వాల్యూ మళ్ళీ సెట్ అవ్వాలి.

Python 3 Practice Challenge ▶ Run in Compiler 
from contextlib import contextmanager

@contextmanager
def temporary_setting(config_dict, key, temp_val):
    original_val = config_dict.get(key)
    config_dict[key] = temp_val
    try:
        yield
    finally:
        config_dict[key] = original_val

settings = {"debug": False, "env": "production"}
print("స్టార్టింగ్ లో:", settings)

with temporary_setting(settings, "debug", True):
    print("విత్ బ్లాక్ లోపల:", settings)

print("విత్ బ్లాక్ అయ్యాక:", settings)
