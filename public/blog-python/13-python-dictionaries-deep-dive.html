Python Dictionaries Deep Dive (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 13 of 65 📂 Phase 3: Strings and Collections 📅 2026 Edition
📌 Covered in this chapter: Key-Value Pairs · Hash Table Internals · CRUD · get() Fallback · Looping · Dict Comprehensions
Python Dictionaries గురించి పూర్తిగా నేర్చుకుందాం: hash table టెక్నాలజీ, key-value mappings, ఎర్రర్ రాకుండా get() వాడటం, looping (.items()), మరియు dictionary comprehensions.
1Dictionary అంటే ఏంటి? (Key-Value Pair)

Dictionary (dict) అనేది కర్లీ బ్రాకెట్స్ ({key: value}) లో ఉండే ముఖ్యమైన కలెక్షన్. (Python 3.7+ నుండి ఇవి ఆర్డర్ ని ఫాలో అవుతాయి).

  • Keys ఎప్పుడూ యూనిక్ గా ఉండాలి: మరియు కీస్ మార్చలేనివి (strings, numbers, tuples) అయి ఉండాలి.
  • Values ఏవైనా అవ్వొచ్చు: లిస్ట్స్, నెంబర్స్, లేదా డిక్షనరీ లోపల ఇంకో డిక్షనరీ కూడా పెట్టుకోవచ్చు.
  • క్షణాలు లో $O(1)$ లూకప్: CPython లో ఇది సూపర్ ఫాస్ట్ గా పనిచేసే "Hash Table" అల్గారిథం తో తయారైంది.
💻 Example 1: Creating and Accessing Dictionaries
Python 3 ▶ Run in Compiler 
# ఒక డెవలపర్ ప్రొఫైల్ ని డిక్షనరీ లో రాద్దాం:
developer = {
    "name": "Balaji",
    "role": "Python Backend Engineer",
    "experience_years": 4,
    "skills": ["Python", "FastAPI", "PostgreSQL", "Docker"],
    "is_active": True
}

# వాల్యూస్ ని బయటికి తీద్దాం:
print("Developer Name:", developer["name"])
print("Role:", developer["role"])
print("Primary Skills:", developer["skills"])
🔍 Hash Table మ్యాజిక్:

మీరు developer["name"] అని అడిగినప్పుడు, పైథాన్ hash("name") కాలిక్యులేట్ చేసి ఆ మెమరీ స్లాట్ కి డైరెక్ట్ గా జంప్ అవుతుంది. అందుకే డిక్షనరీ చాలా ఫాస్ట్.

2సేఫ్ గా డేటాని తీయడం: [] vs .get()

డిక్షనరీ లో లేని కీ ని dict["salary"] అని స్క్వేర్ బ్రాకెట్స్ లో అడిగితే ప్రోగ్రామ్ క్రాష్ అయ్యి KeyError వస్తుంది. అదే .get() వాడితే సేఫ్ గా None లేదా మనం ఇచ్చిన ఫాల్-బ్యాక్ (fallback) వాల్యూ వస్తుంది:

💻 Example 2: Safe Key Access with .get()
Python 3 ▶ Run in Compiler 
user = {"id": 101, "username": "balaji_dev"}

# 1. ఉన్న దాన్ని సేఫ్ గా అడగటం
print("User ID:", user.get("id"))

# 2. లేని దాన్ని అడిగినా ఎర్రర్ రాకుండా డీఫాల్ట్ (default) సెట్ చేయడం
role = user.get("role", "Standard Member")
salary = user.get("salary", 0.0)

print("User Role:", role)      # "Standard Member" అని వచ్చింది
print("User Salary: Rs.", salary) # 0.0 అని వచ్చింది
🔍 ప్రొఫెషనల్ కోడింగ్:

ఏదైనా API నుంచి JSON డేటా తీసుకుంటున్నప్పుడు ఎప్పుడూ .get(key, fallback) వాడాలి. అప్పుడు కొన్ని ఫీల్డ్స్ మిస్ అయినా కోడ్ క్రాష్ అవ్వదు.

3డిక్షనరీ ని మార్చడం (Add, Update, Delete)

డిక్షనరీ లోకి డేటాని డైనమిక్ గా మార్చడానికి ఇలా చేయాలి:

  • dict[key] = new_value: ఉంటే అప్డేట్ చేస్తుంది, లేకపోతే కొత్తగా యాడ్ చేస్తుంది.
  • dict.update({...}): చాలా కీస్ ని ఒకేసారి కలుపుతుంది.
  • dict.pop(key): డిలీట్ చేసి, ఆ వాల్యూ ని మనకు ఇస్తుంది.
  • del dict[key]: డైరెక్ట్ గా మెమరీ లోంచి డిలీట్ చేస్తుంది.
💻 Example 3: Adding, Updating, and Removing Dictionary Keys
Python 3 ▶ Run in Compiler 
product = {"id": 501, "title": "Wireless Mouse", "price": 499}
print("Initial Product:", product)

# 1. కొత్తది యాడ్ చేద్దాం
product["brand"] = "Logitech"

# 2. పాతదాన్ని అప్డేట్ చేద్దాం
product["price"] = 449

# 3. రెండు మూడు ఒకేసారి కలుపుదాం
product.update({"rating": 4.8, "in_stock": True})
print("After update:", product)

# 4. పాప్ (pop) చేసి డిలీట్ చేద్దాం
removed_rating = product.pop("rating")
print(f"Popped rating: {removed_rating} | Remaining keys: {list(product.keys())}")
🔍 ఒక చిన్న నోట్:

డిక్షనరీ లో కేస్ సెన్సిటివ్ (Case-sensitive) పనిచేస్తుంది: "Price" మరియు "price" అనేవి రెండు వేరు వేరు కీస్!

4డిక్షనరీ మీద లూప్ చేయడం (.keys(), .values(), .items())

డిక్షనరీ లోని డేటా మొత్తాన్ని లూప్ చేయడానికి ఈ మెథడ్స్ వాడతారు:

  • dict.keys(): కేవలం కీస్ మాత్రమే ఇస్తుంది.
  • dict.values(): కేవలం వాల్యూస్ మాత్రమే ఇస్తుంది.
  • dict.items(): కీ, వాల్యూ రెండింటినీ జంటగా ((key, value)) ఇస్తుంది.
💻 Example 4: Looping Through Dictionaries with .items()
Python 3 ▶ Run in Compiler 
student_marks = {"Math": 95, "Physics": 88, "Chemistry": 92, "English": 85}

print("--- Subject & Marks Report ---")
for subject, marks in student_marks.items():
    print(f"• {subject:10}: {marks}/100")

# టోటల్ క్యాలిక్యులేట్ చేయడానికి values వాడదాం:
total = sum(student_marks.values())
average = total / len(student_marks)
print(f"\nTotal Marks: {total} | Average: {average:.1f}%")
🔍 బెస్ట్ ప్రాక్టీస్:

ఎప్పుడైనా లూప్ చేసేటప్పుడు for key, val in d.items(): వాడటమే మంచిది. లూప్ లోపల మళ్లీ d[key] అని పిలవడం కరెక్ట్ కాదు.

5Dictionary Comprehensions ({k: v for ... in ...})

List comprehension లాగే డిక్షనరీస్ ని కూడా ఒకే లైన్ లో క్రియేట్ చేయొచ్చు:

💻 Example 5: Dictionary Comprehensions
Python 3 ▶ Run in Compiler 
# 1. 1 నుండి 5 వరకు వాటి స్క్వేర్స్ ని చేద్దాం:
squares_dict = {x: x ** 2 for x in range(1, 6)}
print("Squares Dict:", squares_dict)

# 2. 50 కంటే ఎక్కువ మార్కులు వచ్చినవాళ్లనే ఫిల్టర్ చేద్దాం:
raw_marks = {"Alex": 45, "Balaji": 95, "Chloe": 78, "David": 35}
passed_students = {name: score for name, score in raw_marks.items() if score >= 50}
print("Passed Students (marks >= 50):", passed_students)
🔍 ఈ టెక్నిక్ పవర్:

పెద్ద పెద్ద కోడ్ రాయకుండా, ఫిల్టర్ చేయడం మరియు కొత్త డేటా తయారుచేయడం సింగిల్ లైన్ లో అయిపోతుంది.

⚠️ Common Developer Pitfall: మార్చగలిగే (Mutable) ఆబ్జెక్ట్స్ ని Key గా వాడటం

డిక్షనరీ Key కి ఎప్పుడూ స్ట్రింగ్ గాని, నెంబర్ గాని వాడాలి. లిస్ట్ ని కీ గా వాడితే ({[1, 2]: "data"}) TypeError: unhashable type: 'list' అని వస్తుంది. దాని బదులు ట్యూపుల్ {(1, 2): "data"} వాడాలి.

❓ Frequently Asked Questions (FAQ)

Q Python డిక్షనరీస్ ఆర్డర్ లో ఉంటాయా?

అవును. Python 3.7 నుండి మనం ఏ ఆర్డర్ లో క్రియేట్ చేసామో అదే ఆర్డర్ ని ఇవి గుర్తుపెట్టుకుంటాయి.

Q డిక్షనరీ లో ఒక ఐటెం ని వెతకడం ఎంత ఫాస్ట్?

ఇది Hash table ద్వారా పనిచేస్తుంది కాబట్టి O(1) టైమ్ (చాలా అంటే చాలా ఫాస్ట్) తీసుకుంటుంది.

Q ఒక డిక్షనరీ లోపల ఇంకో డిక్షనరీ పెట్టొచ్చా?

పెట్టొచ్చు! దాన్నే Nested Dictionary అంటారు. బయటనుంచి వచ్చే JSON డేటా అంతా ఇలాగే ఉంటుంది.
