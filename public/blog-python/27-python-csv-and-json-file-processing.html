Python CSV & JSON File Processing (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 27 of 65 📂 Phase 6: Exception and File Handling 📅 2026 Edition
📌 Covered in this chapter: csv.reader · csv.writer · csv.DictReader · csv.DictWriter · json.dump() & load() · Structured Storage
టేబుల్స్ రూపంలో ఉండే CSV ఫైల్స్ ని, మరియు వెబ్ లో వాడే JSON ఫైల్స్ ని పైథాన్ లో ప్రొఫెషనల్ గా ఎలా ప్రాసెస్ చేయాలో నేర్చుకుందాం.
1CSV (ఎక్సెల్) ఫైల్స్: csv.reader మరియు csv.writer

CSV (Comma-Separated Values) అనేది ఒక ఎక్సెల్ షీట్ లాంటి టేబుల్ డేటా. దీనికోసం పైథాన్ లో csv మాడ్యూల్ ఉంది.

💡 విండోస్ లో చాలా ముఖ్యం:
విండోస్ లో CSV ఫైల్ రాసేటప్పుడు ఎప్పుడూ newline="" అని రాయాలి (open("data.csv", "w", newline="")). లేకపోతే ఎక్సెల్ లో ప్రతి రెండు లైన్ల మధ్యలో ఒక ఖాళీ (ఎంప్టీ) లైన్ వచ్చేస్తుంది!
💻 Example 1: Reading and Writing CSV Files with csv.reader and writer
Python 3 ▶ Run in Compiler 
import csv

# 1. లిస్ట్స్ తో ఉన్న డేటాని CSV లోకి రాయడం (writerows):
student_data = [
    ["Roll No", "Student Name", "Grade", "Percentage"],
    [101, "Balaji", "A+", 94.5],
    [102, "Alex Smith", "A", 88.0],
    [103, "Chloe Davis", "A+", 96.2]
]

with open("students.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(student_data)
print("✅ students.csv written successfully!")

# 2. ఆ ఫైల్ ని మళ్ళీ చదవడం (csv.reader):
print("\n--- Reading students.csv ---")
with open("students.csv", "r", encoding="utf-8") as f:
    reader = csv.reader(f)
    header = next(reader) # ఫస్ట్ లైన్ (హెడర్స్) తీసుకుని పక్కన పెడుతుంది
    print("Columns Header:", header)
    
    for row in reader:
        # row లో మనకి డేటా లిస్ట్ లాగా వస్తుంది
        print(f"Roll: {row[0]:4} | Name: {row[1]:12} | Grade: {row[2]} ({row[3]}%)")
🔍 next() ఎందుకు?:

next(reader) వాడటం వల్ల హెడింగ్స్ (Column names) విడిగా వచ్చేస్తాయి, అప్పుడు లూప్ లో ఓన్లీ డేటా మాత్రమే రన్ అవుతుంది.

2ప్రొఫెషనల్ అప్రోచ్: csv.DictReader & csv.DictWriter

పైన row[1], row[2] లాగా నెంబర్స్ వాడటం మంచిది కాదు (ఒకవేళ కాలమ్స్ మారితే కోడ్ క్రాష్ అవుతుంది). అందుకే DictReader వాడతారు. ఇది ఫైల్ హెడర్స్ ని చూసుకుని ప్రతి లైన్ ని ఒక డిక్షనరీ (row['Name']) లాగా ఇస్తుంది:

💻 Example 2: Robust Column Mapping with csv.DictReader and csv.DictWriter
Python 3 ▶ Run in Compiler 
import csv

# 1. డిక్షనరీస్ తో ఉన్న డేటాని CSV లో రాయడం (DictWriter):
fieldnames = ["product_id", "product_name", "category", "price"]

products = [
    {"product_id": "P01", "product_name": "Keyboard", "category": "Hardware", "price": 2499.00},
    {"product_id": "P02", "product_name": "Mouse", "category": "Hardware", "price": 799.00}
]

with open("inventory.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader() # హెడ్డింగ్స్ అదే రాస్తుంది!
    writer.writerows(products)

# 2. డిక్షనరీ లాగా చదవడం (DictReader) - ఇది సూపర్ సేఫ్!:
print("--- Inventory Catalog (DictReader) ---")
with open("inventory.csv", "r", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        # ఇక్కడ మనం నెంబర్ కాకుండా పేరుతో పిలుస్తున్నాం!
        print(f"[{row['product_id']}] {row['product_name']:10} | Rs.{float(row['price']):.2f}")
🔍 DictReader పవర్:

ఎక్సెల్ లో ఒకవేళ price కాలమ్ ఫస్ట్ కి వచ్చినా, లాస్ట్ కి వెళ్ళినా మీ కోడ్ అస్సలు క్రాష్ అవ్వదు. ఎందుకంటే మనం పేరుతో పిలుస్తున్నాం కాబట్టి!

3JSON తో ఫైల్స్ సేవ్ చేయడం (dump & load)

టేబుల్ డేటా అయితే CSV బెస్ట్. కానీ ఒక యూజర్ ప్రొఫైల్, సెట్టింగ్స్ లాంటి డేటా టేబుల్స్ లో పట్టదు, దానికి JSON బెస్ట్.

  • json.dump(obj, file): డిక్షనరీని డైరెక్ట్ గా ఫైల్ లోకి సేవ్ చేస్తుంది.
  • json.load(file): ఫైల్ లోంచి డైరెక్ట్ గా డిక్షనరీలోకి లోడ్ చేస్తుంది.
💻 Example 3: Serializing and Deserializing JSON Data to Disk
Python 3 ▶ Run in Compiler 
import json

# మన యాప్ సెట్టింగ్స్ (ఇలాంటివి CSV లో రాయలేము):
app_settings = {
    "app_name": "ManaCompiler Pro",
    "version": "3.5.0",
    "server": {
        "host": "0.0.0.0",
        "port": 8080,
        "ssl_enabled": True
    },
    "features": ["code_editor", "realtime_compiler", "ai_code_review"]
}

# 1. ఫైల్ లో సేవ్ చేద్దాం (dump):
with open("app_config.json", "w", encoding="utf-8") as f:
    json.dump(app_settings, f, indent=4) # అందంగా రాయడానికి indent
print("✅ app_config.json saved to disk!")

# 2. ఫైల్ లోంచి మళ్ళీ చదువుదాం (load):
with open("app_config.json", "r", encoding="utf-8") as f:
    loaded_config = json.load(f)

print("\n--- Loaded JSON Config ---")
print("App Name: ", loaded_config["app_name"])
print("Host URL: ", f"http://{loaded_config['server']['host']}:{loaded_config['server']['port']}")
🔍 ఏది వాడాలి?:
  • సెన్సార్ డేటా, బ్యాంక్ స్టేట్మెంట్స్ లాంటి టేబుల్ ఫార్మాట్ కి CSV వాడాలి.
  • ఆప్ సెట్టింగ్స్, API రెస్పాన్స్ లాంటి లోపల లోపల ఉండే (Nested) డేటాకి JSON వాడాలి.
⚠️ Common Developer Pitfall: CSV లో newline="" మర్చిపోవడం (విండోస్ లో)

విండోస్ యూజర్లు ఖచ్చితంగా open("file.csv", "w", newline="") ఇవ్వాలి. లేకపోతే పైథాన్ ఎక్సెల్ ఫైల్ లో ఒక లైన్ రాసి, ఒక లైన్ గ్యాప్ (ఎంప్టీ) ఇచ్చి, మళ్ళీ రాస్తుంది.

💻 Hands-on Interactive Practice Challenge

3 పుస్తకాల వివరాలతో (title, author, price) ఒక డిక్షనరీస్ లిస్ట్ క్రియేట్ చేసి DictWriter తో "books.csv" లో సేవ్ చేసి చూపించండి.

Python 3 Practice Challenge ▶ Run in Compiler 
import csv

books = [
    {"title": "Clean Code", "author": "Robert C. Martin", "price": 450},
    {"title": "Fluent Python", "author": "Luciano Ramalho", "price": 890},
    {"title": "The Pragmatic Programmer", "author": "Andrew Hunt", "price": 550}
]

with open("books.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["title", "author", "price"])
    writer.writeheader()
    writer.writerows(books)

print("Saved books.csv successfully! Reading back:")
with open("books.csv", "r", encoding="utf-8") as f:
    print(f.read().strip())

❓ Frequently Asked Questions (FAQ)

Q CSV ఫైల్స్ లో కామా (,) కాకుండా సెమికోలన్ (;) వాడొచ్చా?

వాడొచ్చు! csv.reader(f, delimiter=";") అని ఇస్తే, కామా బదులు సెమికోలన్ తో డేటాని విడగొడుతుంది.

Q JSON ఫైల్స్ లో కామెంట్స్ రాసుకోవచ్చా?

లేదు, ఒరిజినల్ JSON రూల్స్ ప్రకారం అందులో హాష్ (#) గానీ, స్లాష్ (//) గానీ పెట్టి కామెంట్స్ రాయలేము. రాస్తే ఎర్రర్ వస్తుంది.
