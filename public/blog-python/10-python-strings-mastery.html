Python Strings Mastery (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 10 of 65 📂 Phase 3: Strings and Collections 📅 2026 Edition
📌 Covered in this chapter: Quotes · Indexing · Slicing · Escape Characters · String Methods · F-Strings · Palindrome
Python లో స్ట్రింగ్స్ తో ఆడుకోవడం ఎలా? సింగిల్/డబుల్ కోట్స్, ఎస్కేప్ క్యారెక్టర్స్, ఇండెక్సింగ్, స్లైసింగ్, స్ట్రింగ్ మెథడ్స్, F-Strings మరియు పాలిండ్రోమ్ లాజిక్ గురించి నేర్చుకుందాం.
1స్ట్రింగ్స్ ని క్రియేట్ చేయడం, Quotes & Escape Characters

Python లో string (str) అంటే అక్షరాల సముదాయం (sequence). ఇది immutable, అంటే ఒకసారి క్రియేట్ చేసాక దాన్ని మార్చలేము. Python 3 లో అన్నీ UTF-8 ఎన్కోడింగ్ లో ఉంటాయి కాబట్టి ఎమోజీలు (emojis) కూడా వాడుకోవచ్చు.

స్ట్రింగ్స్ రాయడానికి రకాలు:

  • సింగిల్ కోట్స్ ('...'): లోపల డబుల్ కోట్స్ ఉన్నప్పుడు దీన్ని వాడాలి (ఉదా: 'She said "Hello"').
  • డబుల్ కోట్స్ ("..."): లోపల సింగిల్ కోట్ ఉన్నప్పుడు వాడాలి (ఉదా: "It's a sunny day").
  • ట్రిపుల్ కోట్స్ ("""...""" లేదా '''...'''): ఒకే స్ట్రింగ్ ని మల్టిపుల్ లైన్స్ లో రాయాలంటే ఇది వాడాలి.
  • Raw Strings (r"..."): ముందు r పెడితే లోపల ఉన్న స్పెషల్ క్యారెక్టర్స్ నార్మల్ టెక్స్ట్ లాగా మారిపోతాయి (ఫైల్ పాత్స్ కి వాడతారు).

Escape Characters: స్ట్రింగ్ మధ్యలో కొత్త లైన్ కావాలన్నా లేదా స్పెషల్ క్యారెక్టర్స్ ని ప్రింట్ చేయాలన్నా \ ని వాడతాం:

Escape CodeMeaning (అర్థం)Example
\nకొత్త లైన్ (Newline)"Line 1\nLine 2"
\tటాబ్ స్పేస్ (Tab space)"Col 1\tCol 2"
\'సింగిల్ కోట్ ప్రింట్ అవ్వడానికి'It\'s Python'
\"డబుల్ కోట్ ప్రింట్ అవ్వడానికి"She said \"Hi\""
💻 Example 1: String Creation and Escape Sequences
Python 3 ▶ Run in Compiler 
# 1. సింగిల్, డబుల్, మరియు ట్రిపుల్ కోట్స్ వాడటం
msg1 = 'Hello with single quotes'
msg2 = "Hello with double quotes (It's easy!)"
msg3 = """This is a
multi-line string
preserving newlines!"""

# 2. Escape characters ని వాడటం
escaped_text = "Name:\tBalaji\nRole:\tPython Backend Engineer\nQuote:\t\"Keep Building!\""

print(msg1)
print(msg2)
print("\n--- Escape Characters Demo ---")
print(escaped_text)
🔍 కోడ్ బ్రేక్ డౌన్:
  • \t వాడటం వల్ల Name కి, వాల్యూ కి మధ్యలో ఒక టాబ్ స్పేస్ వచ్చింది.
  • \n వల్ల కింది లైన్ కి జంప్ అయింది.
  • \" వాడటం వల్ల డబుల్ కోట్స్ లోపల ఇంకో డబుల్ కోట్స్ ఎర్రర్ లేకుండా ప్రింట్ అయ్యాయి.
2String Indexing & Slicing ([start:stop:step])

స్ట్రింగ్ లోని ప్రతి అక్షరానికి ఒక నెంబర్ (ఇండెక్స్) ఉంటుంది. పైథాన్ లో రెండు రకాల ఇండెక్సింగ్ ఉంటుంది:

Positive Indices: 0 1 2 3 4 5 String Characters: P y t h o n Negative Indices: -6 -5 -4 -3 -2 -1

Slicing ఫార్ములా: string[start : stop : step]

  • start: ఎక్కడినుంచి మొదలవ్వాలి (inclusive).
  • stop: ఎక్కడికి ఎండ్ అవ్వాలి (కానీ ఒక అక్షరం ముందుకే ఆగిపోతుంది!).
  • step: ఎన్ని అడుగులు వేయాలి (-1 ఇస్తే వెనక్కి వస్తుంది).
💻 Example 2: Indexing, Slicing and Reversing Strings
Python 3 ▶ Run in Compiler 
text = "Python Programming"

# 1. Indexing (ఒక్కో అక్షరం)
print("First character [0]:", text[0])    # P
print("Last character [-1]:", text[-1])   # g

# 2. Slicing (కొంత భాగం కట్ చేయడం)
print("First 6 chars [0:6]:", text[0:6])  # Python
print("From index 7 to end [7:]:", text[7:]) # Programming
print("Every 2nd character [::2]:", text[::2]) # Pto rgamn

# 3. String ని రివర్స్ చేయడం (step=-1)
print("Reversed string [::-1]:", text[::-1])
🔍 కాన్సెప్ట్ గుర్తుంచుకోండి:

పైథాన్ లో స్ట్రింగ్స్ ని డైరెక్ట్ గా మార్చలేము (IMMUTABLE). స్లైసింగ్ చేసినప్పుడు అది ఒరిజినల్ దాన్ని మార్చదు, కొత్త స్ట్రింగ్ ని ఇస్తుంది.

3ముఖ్యమైన String Methods (Case, Strip, Replace)

టెక్స్ట్ ని క్లీన్ చేయడానికి పైథాన్ లో కొన్ని బెస్ట్ built-in మెథడ్స్ ఉన్నాయి:

  • len(s): స్ట్రింగ్ పొడవు ఎంత ఉందో కౌంట్ చేస్తుంది.
  • s.upper() / s.lower(): మొత్తం పెద్ద అక్షరాలు (Caps) లేదా చిన్న అక్షరాలుగా మారుస్తుంది.
  • s.title() / s.capitalize(): ఫస్ట్ లెటర్ ని మాత్రమే క్యాపిటల్ చేస్తుంది.
  • s.strip(): టెక్స్ట్ కి ముందు, వెనక ఉన్న పనికిరాని స్పేసెస్ ని తీసేస్తుంది.
  • s.replace(old, new): పాత పదం స్థానంలో కొత్త పదాన్ని పెడుతుంది.
💻 Example 3: String Cleaning and Transformation Methods
Python 3 ▶ Run in Compiler 
raw_input = "   learn python programming today   "

# 1. Length
print("Original Length:", len(raw_input))

# 2. స్పేసెస్ ని strip చేయండి
cleaned = raw_input.strip()
print("Cleaned text:", repr(cleaned))
print("Cleaned Length:", len(cleaned))

# 3. Case మార్చడం
print("Uppercase:", cleaned.upper())
print("Title Case:", cleaned.title())

# 4. ఒక పదాన్ని Replace చేయడం
updated = cleaned.replace("python", "FastAPI & Python")
print("Replaced text:", updated)
🔍 రియల్ వరల్డ్ యూజ్:

యూజర్ ఈమెయిల్ పాస్వర్డ్ ఎంటర్ చేసినప్పుడు ఎప్పుడూ .strip().lower() వాడితే ఎర్రర్స్ రాకుండా సేఫ్ గా ఉంటుంది.

4టెక్స్ట్ లో వెతకడం (find, count, startswith, endswith)

ఒక స్ట్రింగ్ లో మనం వెతుకుతున్న పదం ఉందా లేదా తెలుసుకోవడానికి:

  • s.find(sub): ఆ పదం ఉంటే ఇండెక్స్ నెంబర్ ఇస్తుంది (లేకపోతే -1 ఇస్తుంది).
  • s.count(sub): ఆ పదం ఎన్నిసార్లు వచ్చిందో కౌంట్ చేస్తుంది.
  • s.startswith(prefix): ఫలానా పదంతో స్టార్ట్ అయిందా అని చెక్ చేసి True/False ఇస్తుంది.
  • s.endswith(suffix): ఫలానా పదంతో ఎండ్ అయిందా అని చెక్ చేస్తుంది.
💻 Example 4: String Searching and Validation
Python 3 ▶ Run in Compiler 
filename = "data_report_2026.pdf"

# 1. స్ట్రింగ్ చివర చెక్ చేద్దాం
print("Is PDF file?", filename.endswith(".pdf"))         # True
print("Is data file?", filename.startswith("data_"))     # True

# 2. ఏ పొజిషన్ లో ఉందో వెతుకుదాం
pos = filename.find("report")
print("Position of 'report': index", pos)                # index 5

# 3. ఎన్ని సార్లు వచ్చిందో కౌంట్ చేద్దాం
text_sample = "banana"
print("Count of letter 'a' in 'banana':", text_sample.count("a")) # 3
🔍 Pro Tip (find vs index):

పదం దొరకకపోతే .find() అనేది -1 ఇస్తుంది, కానీ .index() వాడితే కోడ్ క్రాష్ (ValueError) అవుతుంది. కాబట్టి find() వాడటమే సేఫ్.

5Splitting, Joining & Modern F-Strings

ఒక స్ట్రింగ్ ని ముక్కలు చేయాలన్నా లేదా ముక్కల్ని కలపాలన్నా ఈ మెథడ్స్ వాడతాం:

  • s.split(delimiter): కామా లేదా స్పేస్ బేస్ చేసుకుని టెక్స్ట్ ని లిస్ట్ గా ముక్కలు చేస్తుంది.
  • delimiter.join(list): లిస్ట్ లో ఉన్న ఐటమ్స్ ని కలిపి మళ్లీ ఒకే స్ట్రింగ్ గా చేస్తుంది.
  • F-Strings (f"..."): వేరియబుల్స్ ని నేరుగా స్ట్రింగ్ మధ్యలో ఇరికించడానికి బెస్ట్ సింటాక్స్.
💻 Example 5: split(), join(), and F-String Formatting
Python 3 ▶ Run in Compiler 
# 1. కామా ఉన్న చోట ముక్కలు (split) చేద్దాం
csv_line = "Apple,Banana,Mango,Orange"
fruits_list = csv_line.split(",")
print("Splitted List:", fruits_list)

# 2. మళ్లీ వాటిని " | " తో కలుపుదాం (join)
joined_str = " | ".join(fruits_list)
print("Joined String:", joined_str)

# 3. F-string వాడి ఫార్మాట్ చేద్దాం
user = "Balaji"
score = 98.75
message = f"Student {user} scored {score:.1f}% on the Python Exam!"
print("F-String Message:", message)
🔍 ".join()" ఎందుకు డిఫరెంట్?:

పైథాన్ లో my_list.join(", ") అని కాకుండా ", ".join(my_list) అని రాస్తారు. ఎందుకంటే join అనేది లిస్ట్ మెథడ్ కాదు, స్ట్రింగ్ మెథడ్!

6Real-World లాజిక్: Palindrome Checker

Palindrome అంటే ఒక పదాన్ని ముందు నుంచి చదివినా, వెనక నుంచి చదివినా ఒకేలా ఉండటం (ఉదా: "radar", "madam").

పైథాన్ లో స్ట్రింగ్ స్లైసింగ్ వల్ల పాలిండ్రోమ్ లాజిక్ రాయడం చాలా ఈజీ:

💻 Example 6: Reusable Palindrome Checker Function
Python 3 ▶ Run in Compiler 
def is_palindrome(word):
    # Step 1: స్పేసెస్ తీసేసి స్మాల్ లెటర్స్ లోకి మార్చాలి
    cleaned = word.strip().lower()
    
    # Step 2: ఒరిజినల్ పదం, దాని రివర్స్ [::-1] ఒకేలా ఉన్నాయా?
    return cleaned == cleaned[::-1]

# కొన్ని పదాలతో టెస్ట్ చేద్దాం:
test_words = ["Radar", "Python", "madam", "Racecar", "Compiler"]

for w in test_words:
    result = "✅ Palindrome" if is_palindrome(w) else "❌ Not Palindrome"
    print(f"{w:10} -> {result}")
🔍 లాజిక్ ఎలా పనిచేస్తుంది:
  • Radar అనేది స్మాల్ లెటర్స్ తో radar అయింది.
  • దాన్ని radar[::-1] తో రివర్స్ చేస్తే మళ్లీ radar వచ్చింది.
  • అందుకే అది పాలిండ్రోమ్ (True) అని తేలింది!
⚠️ Common Developer Pitfall: స్ట్రింగ్ మధ్యలో అక్షరాన్ని మార్చడానికి ట్రై చేయడం

word[0] = "H" అని రాస్తే పైథాన్ TypeError ఇస్తుంది. ఎందుకంటే స్ట్రింగ్స్ immutable (మారనివి). ఒకవేళ మార్చాలంటే కొత్త స్ట్రింగ్ క్రియేట్ చేయాలి: word = "H" + word[1:].

❓ Frequently Asked Questions (FAQ)

Q Python లో స్ట్రింగ్స్ ని ఎందుకు మార్చలేము (Immutable)?

మార్చకుండా ఉండటం వల్లే మెమరీలో ఒకటే పదాన్ని మల్టిపుల్ వేరియబుల్స్ కి ఫాస్ట్ గా ఇవ్వగలుగుతాము, మరియు సెక్యూరిటీ పరంగా సేఫ్.

Q F-strings లో క్యాలిక్యులేషన్స్ చేయొచ్చా?
