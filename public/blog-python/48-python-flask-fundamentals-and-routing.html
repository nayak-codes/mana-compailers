Flask Fundamentals & Routing (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 48 of 65 📂 Phase 10: Web Development 📅 2026 Edition
📌 Covered in this chapter: Microframeworks vs Full-Stack · Flask(__name__) · WSGI Request Lifecycle · Dynamic Routing () · HTTP Methods · Request Parsing (args vs form)
పైథాన్ తో వెబ్సైట్స్ ఎలా తయారు చేస్తారు? Flask అనే లైట్ వెయిట్ ఫ్రేమ్ వర్క్ తో ఫస్ట్ వెబ్ సర్వర్ ని స్టార్ట్ చేద్దాం. బ్రౌజర్ నుంచి వచ్చే లింక్స్ ని (Routing) మన పైథాన్ కోడ్ ఎలా అర్థం చేసుకుంటుందో చూద్దాం.
1Flask అంటే ఏంటి? (Microframework vs Full-Stack)

పైథాన్ లో వెబ్ బ్యాకెండ్ రాయడానికి మెయిన్ గా రెండు రకాల ఫ్రేమ్ వర్క్స్ ఉంటాయి:

ఫీచర్Microframework (Flask / FastAPI)Full-Stack (Django)
ఫిలాసఫీచాలా సింపుల్: ఇది కేవలం బేసిక్ కనెక్షన్ (Routing) మాత్రమే ఇస్తుంది. డేటాబేస్, లాగిన్స్ అన్నీ మనమే సెట్ చేసుకోవాలి.అన్నీ వాళ్లే ఇస్తారు (Batteries-Included): డేటాబేస్ లింక్, అడ్మిన్ ప్యానెల్, లాగిన్స్ అన్నీ డీఫాల్ట్ గా వచ్చేస్తాయి.
నేర్చుకోవడంచాలా ఈజీ; ఒకే ఒక చిన్న ఫైల్ తో స్టార్ట్ చేయొచ్చు.కొంచెం కష్టం; ఫోల్డర్స్ ఎక్కడున్నాయి, సెట్టింగ్స్ ఎలా అని తెలుసుకోవాలి.
ఎక్కడ వాడతారు?చిన్న చిన్న API లు, మైక్రో సర్వీసెస్, సింపుల్ వెబ్ యాప్స్ చేయడానికి.పెద్ద పెద్ద ప్రాజెక్ట్స్ (కంపెనీ పోర్టల్స్, E-Commerce యాప్స్) చేయడానికి.

WSGI అంటే ఏంటి?

WSGI (Web Server Gateway Interface) అంటే... మన పైథాన్ కోడ్ కి, ఇంటర్నెట్ లోని బ్రౌజర్ కి మధ్యలో ఉండే ఒక ట్రాన్స్లేటర్ లాంటిది. ఇది బ్రౌజర్ నుంచి వచ్చే రిక్వెస్ట్ ని పైథాన్ కి అర్థమయ్యేలా చెప్తుంది.

@app.route("/", methods=["GET"])
def home():

"

@app.route("/users/", methods=["GET"])

    return jsonify({

        "status": "Active"
    })

if __name__ == "__main__":

🔍 ఈ కోడ్ ఏం చేస్తుంది?:
  • @app.route("/"): ఎవరైనా మన లింక్ ని ఓపెన్ చేయగానే, ఈ ఫంక్షన్ ఆటోమాటిక్ గా రన్ అవ్వాలని చెప్తుంది.
  • <int:user_id>: ఎవరైనా /users/abc అని టైప్ చేస్తే ముందే ఆపేస్తుంది, నెంబర్స్ ఇస్తేనే లోపలికి పంపుతుంది.
2బ్రౌజర్ పంపే డేటాని పైథాన్ లో ఎలా చదవాలి? (Query Params & JSON)

బ్రౌజర్ నుంచి మనకి డేటా వస్తున్నప్పుడు, Flask లో దాన్ని request అనే ఆబ్జెక్ట్ ద్వారా చదువుతాం:

  • request.args (Query Params): URL చివరలో ?q=python లాగా వచ్చే డేటాని చదవడానికి.
  • request.form: HTML లో ఫారమ్ (Forms) ఫిల్ చేసి సబ్మిట్ చేస్తే ఆ డేటా ఇక్కడికి వస్తుంది.
  • request.get_json(): వేరే యాప్స్ నుంచి JSON డేటా వస్తే చదవడానికి.
💻 Example 2: Handling Query Filters (GET) and JSON Payloads (POST)
Python 3 ▶ Run in Compiler 
from flask import Flask, request, jsonify

app = Flask(__name__)

# మన దగ్గర ఉన్న చిన్న డేటాబేస్ (మెమరీలో):
PRODUCTS_DB = [
    {"id": 1, "name": "Mechanical Keyboard", "price": 2499.00},
    {"id": 2, "name": "Wireless Mouse", "price": 799.00}
]

@app.route("/api/products", methods=["GET", "POST"])
def handle_products():
    if request.method == "GET":
        # ఎవరైనా /api/products?max_price=1000 అని పంపితే:
        max_price = request.args.get("max_price", type=float)
        
        if max_price is not None:
            # ఫిల్టర్ చేసి ఇద్దాం:
            filtered = [p for p in PRODUCTS_DB if p["price"] <= max_price]
            return jsonify(filtered)
        
        # ఏమీ ఇవ్వకపోతే అన్నీ ఇచ్చేద్దాం:
        return jsonify(PRODUCTS_DB)

    elif request.method == "POST":
        # కొత్త ప్రోడక్ట్ ని క్రియేట్ చేయడానికి డేటా వస్తే:
        payload = request.get_json()
        
        if not payload or "name" not in payload:
            return jsonify({"error": "పేరు (name) ఇవ్వడం మర్చిపోయారు"}), 400

        new_item = {
            "id": len(PRODUCTS_DB) + 1,
            "name": payload["name"],
            "price": float(payload.get("price", 0))
        }
        PRODUCTS_DB.append(new_item)
        return jsonify({"message": "ప్రోడక్ట్ యాడ్ అయ్యింది!", "product": new_item}), 201
🔍 సేఫ్ గా చదవడం:

డేటాని చదివేటప్పుడు request.args['max_price'] అని డైరెక్ట్ గా అడగకూడదు (ఒకవేళ వాళ్ళు ఆ డేటా పంపకపోతే యాప్ క్రాష్ అవుతుంది). దానికి బదులు .get('max_price') వాడితే సేఫ్ గా వస్తుంది.

⚠️ Common Developer Pitfall: Production లో debug=True పెట్టి రన్ చేయడం

లోకల్ గా మనం కోడ్ రాసుకునేటప్పుడు debug=True ఉంటే, ఎర్రర్ రాగానే బ్రౌజర్ లోనే కన్సోల్ వస్తుంది. కానీ లైవ్ లో ఇది ఆన్ చేసి పెడితే... హ్యాకర్స్ మన సర్వర్ లోకి దూరి మన కంప్యూటర్ నే కంట్రోల్ చేసేస్తారు! పబ్లిక్ గా రిలీజ్ చేసే ముందు దాన్ని తీసేయాలి.

💻 Hands-on Interactive Practice Challenge

ఒక /calculator/ క్రియేట్ చేయండి. num1, num2 ని query parameters లా తీసుకుని కూడిక/తీసివేత చేసి JSON ఇవ్వాలి.

Python 3 Practice Challenge ▶ Run in Compiler 
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route("/calculator/")
def calculate(operation):
    # num1, num2 తీసుకుంటున్నాం, లేకపోతే డీఫాల్ట్ గా 0
    n1 = request.args.get("num1", 0, type=float)
    n2 = request.args.get("num2", 0, type=float)

    if operation == "add": res = n1 + n2
    elif operation == "sub": res = n1 - n2
    elif operation == "mul": res = n1 * n2
    elif operation == "div": res = n1 / n2 if n2 != 0 else "ఎర్రర్: జీరో తో భాగించలేం"
    else: return jsonify({"error": "ఆపరేషన్ తప్పు"}), 400

    return jsonify({"operation": operation, "num1": n1, "num2": n2, "result": res})

❓ Frequently Asked Questions (FAQ)

Q Flask కీ, FastAPI కీ తేడా ఏంటి?

Flask పాతది, నమ్మకమైనది, HTML టెంప్లేట్స్ కి బాగా పనికొస్తుంది. FastAPI కొత్తది, చాలా స్పీడ్ గా ఉంటుంది, ఆటోమాటిక్ గా డాక్యుమెంటేషన్ తయారు చేస్తుంది.

Q url_for() అంటే ఏంటి?

బ్రౌజర్ కి లింక్స్ ఇచ్చేటప్పుడు డైరెక్ట్ గా "/login" అని ఇవ్వకుండా url_for("login") అని ఇస్తాం. అప్పుడు రేపు మన లింక్ పేరు "/signin" కి మార్చినా, కోడ్ అంతా వెతుక్కుని మార్చుకోవాల్సిన అవసరం ఉండదు.
