లూప్ కంట్రోల్ — break, continue, pass & else

🐍 Modern Python (Python 3.12+) 🎯 Chapter 8 of 25 ⚙️ Phase 02: కంట్రోల్ ఫ్లో, లూప్స్ & స్ట్రింగ్స్ 📅 2026 Edition
📌 Covered in this chapter: లూప్ ఫ్లో ఇంటరప్షన్ · break స్టేట్‌మెంట్ & ఎర్లీ ఎగ్జిట్ · continue & డేటా ఫిల్టరింగ్ · pass ప్లేస్‌హోల్డర్ vs Ellipsis (...) · పైథాన్ ప్రత్యేకమైన for-else & while-else లూప్స్ · మల్టీ-లెవల్ నెస్టెడ్ లూప్ బ్రేక్స్ · Cyber Security Log Intrusion Engine ప్రాజెక్ట్!
లూప్స్ అనేవి మొదలైన తర్వాత సాధారణంగా తమ పరిధిలోని అన్ని అంశాలు పూర్తయ్యే వరకు లేదా ఇచ్చిన షరతు ఫాల్స్ అయ్యే వరకు నిరంతరాయంగా తిరుగుతాయి. కానీ వాస్తవ ప్రపంచ సాఫ్ట్‌వేర్ ఇంజనీరింగ్‌లో కొన్ని అనుకోని పరిస్థితులు ఎదురవుతాయి: ఉదాహరణకు మనం వెతుకుతున్న డేటా రికార్డు లూప్ ప్రారంభంలోనే దొరికినప్పుడు ఇంకా మిగిలిన 10 లక్షల రౌండ్లు తిరగడం సమయాన్ని వృధా చేయడమే అవుతుంది! లేదా ఒక చెల్లని కలుషితమైన రికార్డు వచ్చినప్పుడు దాన్ని దాటవేసి తర్వాతి రౌండ్‌కు వెళ్లాల్సి ఉంటుంది. అలాంటి సందర్భాలలో లూప్ యొక్క సహజ ప్రవాహాన్ని నియంత్రించడానికి పైథాన్ break, continue, pass మరియు ప్రపంచంలో చాలా కొద్ది భాషల్లో మాత్రమే ఉండే అరుదైన for-else / while-else నిర్మాణాలను అందిస్తుంది. ఈ ఎనిమిదవ అధ్యాయంలో — జంప్ స్టేట్‌మెంట్ల ఆర్కిటెక్చర్, నెస్టెడ్ లూప్ ఎస్కేప్ టెక్నిక్స్, మరియు సర్వర్ యాక్సెస్ లాగ్స్‌ను విశ్లేషించి సైబర్ దాడులను గుర్తించే పూర్తి స్థాయి Automated Cyber Security Log Analyzer & Intrusion Detection System ప్రాజెక్ట్ ద్వారా లూప్ కంట్రోల్‌లో పరిపూర్ణ నైపుణ్యాన్ని సాధిద్దాం!

1 లూప్ కంట్రోల్ స్టేట్‌మెంట్స్ పరిచయం (Loop Flow Interruption)

పైథాన్‌లో లూప్ నడుస్తున్నప్పుడు దాని సాధారణ ప్రవర్తనను మార్చడానికి 4 ప్రధాన కంట్రోల్ స్టేట్‌మెంట్స్ ఉన్నాయి:

స్టేట్‌మెంట్ కీలక చర్య (Action) లూప్ పరిస్థితి సాధారణ ఉపయోగం
break లూప్‌ను అక్కడికక్కడే శాశ్వతంగా నిలిపివేస్తుంది. లూప్ వెంటనే ముగుస్తుంది; కంట్రోల్ లూప్ వెలుపలికి వెళ్తుంది. సెర్చ్ ఆపరేషన్లలో ఐటెమ్ దొరికినప్పుడు, ఎర్రర్ వచ్చినప్పుడు.
continue ప్రస్తుత రౌండ్‌ను మధ్యలోనే ఆపి, తర్వాతి రౌండ్‌కు వెళ్తుంది. లూప్ ఆగదు; తర్వాతి ఐటెమ్‌ను ప్రాసెస్ చేయడం ప్రారంభిస్తుంది. చెల్లని డేటాను, నెగటివ్ విలువలను దాటవేయడానికి (Data Filtering).
pass ఏ పనీ చేయదు (No-operation / Null statement). లూప్ ప్రవాహంపై ఎటువంటి ప్రభావం ఉండదు. సింటాక్స్ ఎర్రర్ రాకుండా భవిష్యత్తు కోడ్ కోసం ప్లేస్‌హోల్డర్.
else లూప్ ఎటువంటి break లేకుండా పూర్తయినప్పుడు రన్ అవుతుంది. సహజసిద్ధంగా ముగిసినప్పుడు మాత్రమే ఎగ్జిక్యూట్ అవుతుంది. ఫ్లాగ్ వేరియబుల్స్ లేకుండా ఐటెమ్ దొరకలేదని నిర్ధారించడానికి.

2 break స్టేట్‌మెంట్ — లూప్‌ను తక్షణమే నిలిపివేయడం (Immediate Loop Exit)

break స్టేట్‌మెంట్ కనిపించిన క్షణంలోనే, లూప్ యొక్క కండిషన్ ఇంకా True గా ఉన్నప్పటికీ లేదా లిస్ట్‌లో ఇంకా ఎన్నో అంశాలు మిగిలి ఉన్నప్పటికీ — పైథాన్ ఆ లూప్‌ను తక్షణమే ముగించి బయటకు వచ్చేస్తుంది.

[break స్టేట్‌మెంట్ ఎగ్జిక్యూషన్ ఫ్లో] for item in collection: │ ▼ ┌──────────────┐ │ స్టేట్‌మెంట్ 1 │ └──────┬───────┘ │ ▼ ╱───────────────╲ (ఒకవేళ True అయితే) ╱ break condition?╲───────────────────────┐ ╲ ╱ │ ╲───────────────╱ ▼ │ (False) ┌─────────┐ ▼ │ break │ ┌──────────────┐ └────┬────┘ │ స్టేట్‌మెంట్ 2 │ │ └──────┬───────┘ │ │ │ └───────────┐ │ ▼ ▼ [ తర్వాతి రౌండ్ ] [ లూప్ పూర్తిగా సమాప్తం! ]
💡 break మరియు నెస్టెడ్ లూప్స్ (Innermost Only):

ఒక లూప్ లోపల మరొక లూప్ (Nested Loop) ఉన్నప్పుడు, లోపలి లూప్‌లో రాసిన break కేవలం ఆ లోపలి లూప్‌ను మాత్రమే ఆపుతుంది! బయటి లూప్ ఎప్పటిలాగే తన తర్వాతి రౌండ్‌ను కొనసాగిస్తుంది.

3 కోడ్ డెమో 1: break ఆధారిత బ్యాంక్ ATM పిన్ వెరిఫికేషన్

యూజర్‌కు కేవలం 3 అవకాశాలు మాత్రమే ఇచ్చి, సరైన పిన్ కొట్టినప్పుడు వెంటనే లూప్ బ్రేక్ అయ్యే లాజిక్‌ను పరిశీలించండి:

01_break_atm_security_pin.py 
# ATM సెక్యూరిటీ పిన్ వెరిఫికేషన్ (గరిష్టంగా 3 ప్రయత్నాలు)

CORRECT_PIN = "5432"
MAX_ATTEMPTS = 3
attempt = 1

# సిమ్యులేటెడ్ యూజర్ ఎంట్రీలు (టెస్టింగ్ కోసం)
user_inputs = ["1111", "5432", "9999"]

print("=" * 55)
print("     🏧 మన బ్యాంక్ ATM — పిన్ వెరిఫికేషన్ సిస్టమ్")
print("=" * 55)

for entered_pin in user_inputs:
    print(f"ప్రయత్నం {attempt} of {MAX_ATTEMPTS}: పిన్ '{entered_pin}' నమోదు చేయబడింది...")

    if entered_pin == CORRECT_PIN:
        print("✅ పిన్ ధృవీకరించబడింది! లాగిన్ విజయవంతమైంది.")
        print("➡️ ప్రధాన బ్యాంకింగ్ మెనూకి మళ్లించబడుతోంది...")
        break  # పిన్ సరైనది కాబట్టి లూప్‌ను వెంటనే ఆపివేస్తున్నాము!

    print(f"❌ తప్పుడు పిన్! మిగిలిన ప్రయత్నాలు: {MAX_ATTEMPTS - attempt}")
    attempt += 1

    if attempt > MAX_ATTEMPTS:
        print("🛑 హెచ్చరిక: 3 సార్లు తప్పుడు పిన్! మీ డెబిట్ కార్డ్ 24 గంటలు బ్లాక్ చేయబడింది.")
        break

print("=" * 55)

4 continue స్టేట్‌మెంట్ — ప్రస్తుత రౌండ్‌ను దాటవేయడం (Skipping)

continue స్టేట్‌మెంట్ కనిపించినప్పుడు, ఆ రౌండ్‌లో దాని కింద ఉన్న కోడ్ లైన్లను దాటవేసి, లూప్ యొక్క తర్వాతి రౌండ్‌కు (Next Iteration) వెంటనే వెళ్లిపోతుంది. ఇది డేటా ప్రాసెసింగ్ పైప్‌లైన్‌లలో చెల్లని అంశాలను ఫిల్టర్ చేయడానికి ఎక్కువగా ఉపయోగపడుతుంది.

లక్షణం break continue
లూప్ పరిస్థితి మొత్తం లూప్ శాశ్వతంగా ముగుస్తుంది. కేవలం ప్రస్తుత రౌండ్ మాత్రమే రద్దవుతుంది; లూప్ కొనసాగుతుంది.
మిగిలిన ఐటెమ్స్ మిగిలిన ఏ ఐటెమ్‌ను కూడా ముట్టుకోదు. మిగిలిన అన్ని ఐటెమ్స్‌ను వరుసగా ప్రాసెస్ చేస్తుంది.
వాడే సందర్భం సెర్చ్ పూర్తయినప్పుడు, ఎమర్జెన్సీ షట్‌డౌన్. స్పేస్‌లు, ఖాళీ రికార్డులు, బ్యాడ్ డేటాను ఇగ్నోర్ చేయడానికి.

5 కోడ్ డెమో 2: continue ఆధారిత డేటా శానిటైజేషన్

ఒక ఈ-కామర్స్ ఆర్డర్ల లిస్ట్‌లో నెగటివ్ విలువలు లేదా చెల్లని రికార్డులు ఉన్నప్పుడు వాటిని continue ద్వారా దాటవేసి సరైన ఆర్డర్ల మొత్తాన్ని మాత్రమే లెక్కించే కోడ్ చూడండి:

02_continue_data_sanitization.py 
# చెల్లని రికార్డులను దాటవేసే continue డెమో

raw_transactions = [
    {"txn_id": "T101", "amount": 1499.00, "status": "COMPLETED"},

]

valid_total = 0.0

8 కోడ్ డెమో 3: for-else ద్వారా ప్రైమ్ నంబర్ డిటెక్టర్

ఫ్లాగ్ వేరియబుల్స్ లేకుండా for-else ఎంత సొగసైన కోడ్‌ను అందిస్తుందో ఈ క్రింది ప్రధాన సంఖ్యల (Prime Numbers) డిటెక్టర్‌లో చూడండి:

# for-else ద్వారా ప్రైమ్ నంబర్ చెకర్

def check_prime(number: int):
    """
    ఒక సంఖ్య ప్రధాన సంఖ్య (Prime) అవునో కాదో ఫ్లాగ్స్ లేకుండా తేలుస్తుంది.
    """
    if number <= 1:
        print(f"సంఖ్య {number} ప్రధాన సంఖ్య కాదు.")
        return

    # 2 నుండి వర్గమూలం (sqrt) వరకు భాగిస్తున్నాము
    for divisor in range(2, int(number ** 0.5) + 1):
        if number % divisor == 0:
            print(f"❌ {number} ప్రధాన సంఖ్య కాదు (ఇది {divisor} చే నిశ్శేషంగా భాగించబడింది).")
            break # శేషం 0 కాగానే లూప్ ఆగిపోతుంది! else రన్ అవ్వదు!
    else:
        # లూప్ మొత్తం తిరిగి ఏ ఒక్క break రన్ కానప్పుడు మాత్రమే else రన్ అవుతుంది!
        print(f"🌟 {number} ఒక సంపూర్ణ ప్రధాన సంఖ్య (Prime Number)!")

print("=== PRIME NUMBER CHECKER DEMO ===")

9 నెస్టెడ్ లూప్స్ నుండి బయటపడటం (Multi-Level Nested Break)

పైథాన్‌లో C++ లేదా Java లలో లాగా లేబుల్డ్ బ్రేక్ (break outer;) సింటాక్స్ లేదు. మరి 2-3 స్థాయిల నెస్టెడ్ లూప్‌ల నుండి ఒకేసారి బయటపడాలంటే ప్రొడక్షన్‌లో పాటించే 3 వ్యూహాలు:

  • 1. ఫంక్షన్‌లో పెట్టి return చేయడం (అత్యంత పైథానిక్ & క్లీన్ సొల్యూషన్): మొత్తం నెస్టెడ్ లూప్‌ను ఒక ఫంక్షన్‌లో ఉంచి, ఫలితం దొరకగానే return చేస్తే అన్ని స్థాయిల లూప్‌ల నుండి తక్షణమే బయటకు వచ్చేస్తుంది.
  • 2. ఫ్లాగ్ వేరియబుల్స్ ఉపయోగించడం: found = True చేసి బయటి లూప్‌లో కూడా if found: break రాయడం.
  • 3. కస్టమ్ ఎక్సెప్షన్ రైజ్ చేయడం: చాలా లోతైన లూప్‌లలో raise ItemFoundException() ద్వారా డైరెక్ట్‌గా జంప్ చేయడం.

# 2D మ్యాట్రిక్స్ లో సెర్చ్ & ఫంక్షన్ రిటర్న్ బ్రేక్ ప్యాటర్న్

warehouse_grid = [
    ["ఖాళీ", "ఖాళీ", "టెలివిజన్", "ఖాళీ"],
    ["ఖాళీ", "ల్యాప్‌టాప్", "ఖాళీ", "ఖాళీ"],
    ["స్మార్ట్‌వాచ్", "ఖాళీ", "ఖాళీ", "ఐఫోన్"]
]

def locate_product_in_warehouse(grid, target_item):
    """
    2D గ్రిడ్‌లో వస్తువును వెతికి దాని అడ్డు, నిలువు వరుసలను రిటర్న్ చేస్తుంది.
    """
    for row_idx, row in enumerate(grid):
        for col_idx, item in enumerate(row):
            if item == target_item:
                # return రాయడం వల్ల రెండు లూప్‌లు వెంటనే ముగుస్తాయి!

    return f"❌ '{target_item}' స్టాక్‌లో లభించలేదు."

11 లూప్ కంట్రోల్ పెర్ఫార్మెన్స్ & ఎర్లీ ఎగ్జిట్ (Early Exit Pattern)

లూప్‌లలో break మరియు continue లను సరిగ్గా వాడటం వల్ల సాఫ్ట్‌వేర్ వేగం అసాధారణంగా పెరుగుతుంది. ఉదాహరణకు $1,000,000$ రికార్డులు ఉన్న డేటాబేస్‌లో ఒక ఐటెమ్ కోసం వెతుకుతున్నప్పుడు, అది 50వ స్థానంలోనే దొరికినప్పుడు break రాస్తే మిగిలిన $999,950$ అనవసరమైన ఆపరేషన్లు ఆగిపోతాయి! దీనినే ఎర్లీ ఎగ్జిట్ ప్యాటర్న్ (Early Exit Pattern) అంటారు.

12 కామన్ బిగినర్స్ మిస్టేక్స్ & ప్రొడక్షన్ బెస్ట్ ప్రాక్టీసెస్

  • Mistake 1: while లూప్‌లో continue కి ముందు ఇంక్రిమెంట్ మర్చిపోవడం: while i < 10: if i == 5: continue; i += 1 అని రాస్తే i = 5 వద్ద అనంతమైన లూప్‌లో చిక్కుకుపోతుంది! continue పిలవడానికి ముందే వేరియబుల్‌ను అప్‌డేట్ చేయాలి.
  • Mistake 2: for-else ను if-else అనుకోవడం: for-else లో else ప్రతి లూప్ రౌండ్‌లోనూ రన్ అవ్వదు; లూప్ మొత్తం break లేకుండా పూర్తయినప్పుడు మాత్రమే చివరగా ఒక్కసారి రన్ అవుతుంది.
  • Mistake 3: నెస్టెడ్ లూప్‌లో break ప్రవర్తనను తప్పుగా అర్థం చేసుకోవడం: break కేవలం తనను చుట్టుముట్టిన ఒకే ఒక్క లూప్‌ను మాత్రమే ఆపుతుంది.

సమాధానం: పైథాన్‌లో ఇండెంటేషన్ తప్పనిసరి. ఒక ఫంక్షన్, క్లాస్, లూప్ లేదా if బ్లాక్‌లో ఏ కోడూ రాయకుండా వదిలేస్తే IndentationError వస్తుంది. ఆ సింటాక్స్ ఎర్రర్ రాకుండా నిరోధించడానికి pass ను ఒక తాత్కాలిక ప్లేస్‌హోల్డర్‌గా (No-op) ఉపయోగిస్తాము.
3. for-else లూప్‌లో else బ్లాక్ ఎప్పుడు ఎగ్జిక్యూట్ అవుతుంది?
