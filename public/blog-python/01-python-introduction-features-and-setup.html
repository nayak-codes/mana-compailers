Python Introduction & Setup (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 1 of 65 📂 Phase 1: Python Basics 📅 2026 Edition
📌 Covered in this chapter: What is Python? · Design Philosophy · CPython Architecture · Setup · First Program · print() Mechanics
Python 3 పరిచయం: Guido van Rossum హిస్టరీ, డిజైన్ ఫిలాసఫీ (PEP 20), CPython compilation, విండోస్/మాక్ లో సెటప్, మరియు print() ఫంక్షన్ పనితీరు.
1Python అంటే ఏమిటి? Origins & Philosophy

Python అనేది ఒక high-level, interpreted, general-purpose, dynamically typed, multi-paradigm ప్రోగ్రామింగ్ లాంగ్వేజ్. దీనిని డిసెంబర్ 1989 లో డచ్ కంప్యూటర్ సైంటిస్ట్ Guido van Rossum నెదర్లాండ్స్ లోని CWI లో తయారు చేసారు. మెషిన్ ని ఆప్టిమైజ్ చేయడం కన్నా, డెవలపర్ కి కోడ్ సులభంగా అర్థం కావాలి అనే ఉద్దేశ్యంతో దీనిని క్రియేట్ చేసారు.

"Python" అనే పేరు పాము నుండి రాలేదు, Guido కి ఇష్టమైన BBC కామెడీ సిరీస్ Monty Python’s Flying Circus నుండి తీసుకున్నారు.

Python యొక్క ముఖ్య లక్షణాలు:

  • Interpreted & Bytecode Compiled: Python సోర్స్ ఫైల్స్ (.pyc) bytecode గా కంపైల్ అయ్యి, Python Virtual Machine (PVM) మీద ఎక్జిక్యూట్ అవుతాయి.
  • Dynamically Typed: వేరియబుల్స్ కి డేటా టైప్ ముందుగా చెప్పాల్సిన అవసరం లేదు. రన్ టైం లో అవే సెట్ అవుతాయి.
  • Multi-Paradigm: ఇది Object-Oriented Programming (OOP) మరియు Functional Programming రెంటినీ సపోర్ట్ చేస్తుంది.
  • Batteries Included: నెట్వర్కింగ్, మ్యాథ్స్, ఫైల్స్ వంటి వాటి కోసం ముందుగానే రాసిపెట్టిన ఎన్నో Standard Library మ్యాడ్యూల్స్ ఇందులో ఉంటాయి.

Python డిజైన్ సూత్రాలను PEP 20 — The Zen of Python అంటారు. వీటిని మీరు డైరెక్ట్ గా కోడ్ లో చూడొచ్చు:

💻 Example 1: Displaying The Zen of Python (PEP 20)
Python 3 ▶ Run in Compiler 
# Python యొక్క ఫిలాసఫీ (PEP 20) ప్రింట్ చేయడానికి
import this
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • import this: ఇది CPython లో దాగి ఉన్న ఒక easter egg. ఇది 19 ముఖ్యమైన Python రూల్స్ ని (ఉదా: "Simple is better than complex") స్క్రీన్ పైన చూపిస్తుంది.
2మీ మొట్టమొదటి Python Program (`print()` Function)

C, C++ లేదా Java లాంటి భాషల్లో ఒక చిన్న టెక్స్ట్ ప్రింట్ చేయాలన్నా క్లాసులు, మెథడ్స్ రాయాలి. కానీ Python లో అలాంటి అవసరమే లేదు. నేరుగా మనం కోడ్ రాసేయొచ్చు.

Built-in print() ఫంక్షన్ మనం ఇచ్చే డేటాని UTF-8 strings గా మార్చి కన్సోల్ టెర్మినల్ పైన ప్రింట్ చేస్తుంది:

💻 Example 2: Your Very First Python Program
Python 3 ▶ Run in Compiler 
# స్క్రీన్ పైన మెసేజ్ ప్రింట్ చేయడం
print("Hello, World! 🚀 Welcome to Python 3.")
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • # స్క్రీన్ పైన...: ఇది ఒక కామెంట్. # తో మొదలయ్యే లైన్స్ ని కంపైలర్ పట్టించుకోదు.
  • print(...): స్క్రీన్ పై అవుట్పుట్ ఇవ్వడానికి వాడే built-in ఫంక్షన్.
  • "Hello, World! 🚀...": డబుల్ కోట్స్ లో ఉన్న string. (సింగిల్ కోట్స్ '...' వాడినా పర్లేదు).
3Variables లో వాల్యూస్ స్టోర్ చేయడం

Python లో variable అంటే మెమరీ లో ఉన్న డేటాని పాయింట్ చేసే ఒక పేరు. ఇతర భాషల్లో లాగా int x = 10; అని డేటా టైప్ చెప్పాల్సిన పని లేదు. = వాడినప్పుడు పైథాన్ దానంతట అదే డేటా టైప్ ని గుర్తిస్తుంది.

print() ఫంక్షన్ లో కామాలతో (commas) ఎన్ని వేరియబుల్స్ ఇచ్చినా, వాటన్నిటి మధ్య ఒక స్పేస్ యాడ్ చేసి ప్రింట్ చేస్తుంది:

💻 Example 3: Variables and Multiple print() Arguments
Python 3 ▶ Run in Compiler 
# Step 1: స్టూడెంట్ డీటెయిల్స్ స్టోర్ చేద్దాం
student_name = "Balaji"           # String (Text data)
course_name = "Python Masterclass" # String
batch_year = 2026                 # Integer (Whole number)

# Step 2: వాటన్నిటినీ ప్రింట్ చేద్దాం
print("Student Name:", student_name)
print("Enrolled in:", course_name, "| Batch Year:", batch_year)
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • student_name = "Balaji": "Balaji" అనే string ని క్రియేట్ చేసి దానికి student_name అనే పేరు పెడుతుంది.
  • batch_year = 2026: 2026 అనే నెంబర్ ని స్టోర్ చేస్తుంది.
  • print("Student Name:", student_name): టెక్స్ట్ కి మరియు వేరియబుల్ కి మధ్యలో ఆటోమాటిక్ గా ఒక స్పేస్ ఇస్తుంది.
4print() Formatting: sep మరియు end పారామీటర్లు

print() ఫంక్షన్ పనితీరుని మార్చడానికి మనకు రెండు ముఖ్యమైన parameters ఉంటాయి:

  • sep=" ": రెండు వేరియబుల్స్ మధ్యలో ఏం యాడ్ చేయాలో ఇది చెప్తుంది (డిఫాల్ట్ గా ఒక స్పేస్ ఉంటుంది).
  • end="\n": ప్రింట్ అయ్యాక చివర్లో ఏం యాడ్ చేయాలో ఇది చెప్తుంది (డిఫాల్ట్ గా న్యూ-లైన్ \n ఉంటుంది కాబట్టి నెక్స్ట్ ప్రింట్ కింది లైన్ లో వస్తుంది).
💻 Example 4: Controlling Output with sep and end
Python 3 ▶ Run in Compiler 
# 1. 'sep' వాడి పదాల మధ్యలో హైఫన్ (-) పెడదాం
print("Apple", "Banana", "Orange", "Mango", sep=" - ")

# 2. 'end' వాడి నెక్స్ట్ ప్రింట్ ని అదే లైన్ లో వచ్చేలా చేద్దాం
print("Downloading files", end="... ")
print("Done! 100% Complete ✅")
🔍 Output బ్రేక్ డౌన్:
  • Line 2: Apple - Banana - Orange - Mango (స్పేస్ కి బదులు డాష్ వచ్చింది).
  • Line 5: Downloading files... అని ప్రింట్ అయ్యాక లైన్ బ్రేక్ అవ్వలేదు, అందుకే Line 6 లో ఉన్న మెసేజ్ పక్కనే ప్రింట్ అయ్యింది!
5ఆటోమేటిక్ గా Arithmetic Calculations

Python ఒక ఇంటరాక్టివ్ క్యాలిక్యులేటర్ లాగా పనిచేస్తుంది. మ్యాథ్స్ ఆపరేటర్స్ (+, -, *, /) వాడి నేరుగా లెక్కలు చేయవచ్చు:

💻 Example 5: Direct Arithmetic Calculation
Python 3 ▶ Run in Compiler 
# రేట్లు సెట్ చేద్దాం
item_price = 150
quantity = 3
discount = 50

# బిల్ క్యాలిక్యులేట్ చేద్దాం
total_bill = (item_price * quantity) - discount

# రిజల్ట్
print("Item Price: Rs.", item_price)
print("Quantity Ordered:", quantity)
print("Final Total Bill: Rs.", total_bill)
🔍 Calculation ఎలా జరిగింది:

బ్రాకెట్స్ లో ఉన్న గుణకారం (Multiplication) 150 * 3 = 450 ముందు జరుగుతుంది. ఆ తర్వాత 450 - 50 = 400 జరిగి total_bill లో సేవ్ అవుతుంది.

6Python లోపల ఏం జరుగుతుంది? (CPython Architecture)

Python లైన్ బై లైన్ డైరెక్ట్ గా ఎక్జిక్యూట్ అవుతుందని చాలామంది అనుకుంటారు. కానీ అఫీషియల్ CPython లో ఇది రెండు స్టెప్స్ లో జరుగుతుంది:

┌────────────────────────┐ │ Source Code (app.py) │ (మనం రాసే ఇంగ్లీష్ లాంటి కోడ్) └───────────┬────────────┘ │ ▼ [Step 1: Bytecode Compilation] ┌────────────────────────┐ │ Bytecode (.pyc) Cache │ (మిషన్ కి అర్థమయ్యే ఇంటర్మీడియట్ కోడ్) └───────────┬────────────┘ │ ▼ [Step 2: PVM లోకి పంపబడుతుంది] ┌────────────────────────┐ │ Python Virtual Machine │ (C లాంగ్వేజ్ లూప్ ఈ బైట్ కోడ్ ని రన్ చేస్తుంది) └───────────┬────────────┘ │ ▼ ┌────────────────────────┐ │ Terminal / OS Output │ "Hello, World! 🚀" └────────────────────────┘

Step 1: Bytecode Compilation: మనం రాసిన కోడ్ ని పార్స్ చేసి బైట్ కోడ్ (bytecode) గా మారుస్తుంది.

Step 2: Python Virtual Machine (PVM): PVM ఆ బైట్ కోడ్ ని చదివి మన కంప్యూటర్ CPU కి తగ్గట్టుగా ఎక్జిక్యూట్ చేస్తుంది.

⚠️ Common Developer Pitfall: Python 2 Print సింటాక్స్ వాడటం

పాత Python 2 లో బ్రాకెట్స్ లేకుండా 'print Hello' అని రాసేవాళ్ళు. కానీ కొత్త Python 3 లో కచ్చితంగా బ్రాకెట్స్ వాడాలి. లేకపోతే SyntaxError: Missing parentheses in call to 'print' అనే ఎర్రర్ వస్తుంది.

❓ Frequently Asked Questions (FAQ)

Q Python అనేది Compiled ఆ లేక Interpreted ఆ?

Python రెండూ చేస్తుంది. ముందుగా కోడ్ బైట్ కోడ్ (.pyc) గా కంపైల్ అవుతుంది, ఆ తర్వాత Python Virtual Machine (PVM) ద్వారా ఇంటర్‌ప్రెట్ అవుతుంది.

Q Python 2 కి Python 3 కి తేడా ఏంటి?

Python 2 లో Unicode సరిగ్గా లేదు, మరియు డివిజన్ (5/2 = 2) లాంటి తప్పులు ఉండేవి. Python 3 లో అన్నీ పర్ఫెక్ట్ గా క్లీన్ చేసి కొత్త స్టాండర్డ్స్ ని తెచ్చారు.
