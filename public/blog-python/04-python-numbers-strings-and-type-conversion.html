Python Numbers, Strings & Casting (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 4 of 65 📂 Phase 1: Python Basics 📅 2026 Edition
📌 Covered in this chapter: int (Bignum) · float (IEEE 754) · complex · Slicing [::] · F-Strings · Type Casting
Python లో ఎంత పెద్ద నెంబర్ నైనా స్టోర్ చేయగల బగ్-ఫ్రీ ఇంటిజర్స్, స్ట్రింగ్ స్లైసింగ్, ఫార్మాట్ కోసం F-Strings, మరియు టైప్ కాస్టింగ్ గురించి నేర్చుకుందాం.
1Numeric Types & Unlimited Integer Precision (Bignum)

Python 3 లో ప్రధానంగా మూడు నెంబర్ టైప్స్ ఉంటాయి: int, float, మరియు complex.

C, Java లాంటి వాటిలో ఒక నెంబర్ కి ఇంత లిమిట్ (32 bits) వరకే స్టోర్ చేయగలం అనే రూల్ ఉంటుంది. కానీ Python 3 లో ఇంటిజర్స్ కి లిమిట్ లేదు (Arbitrary precision). కంప్యూటర్ RAM కి తగ్గట్టు ఎంత పెద్ద నెంబర్ నైనా ఎర్రర్ రాకుండా స్టోర్ చేసుకోగలదు!

💻 Example 1: Numeric Primitives & Arbitrary Precision
Python 3 ▶ Run in Compiler 
# 1. 2 ని 100 సార్లు గుణిద్దాం (చాలా పెద్ద నెంబర్!)
huge_num = 2 ** 100
print("2 ** 100 is:")
print(huge_num)

# 2. Float మరియు Complex నెంబర్స్
pi_val = 3.1415926535
complex_num = 3 + 4j

print("\nFloat Pi:", pi_val)
print("Complex real part:", complex_num.real, "| Imaginary part:", complex_num.imag)
🔍 అపరిమిత కెపాసిటీ:

మీరు 100! (ఫ్యాక్టోరియల్) క్యాలిక్యులేట్ చేసినా ఇతర లాంగ్వేజెస్ లాగా Overflow ఎర్రర్ రాదు.

2Arithmetic Operators బ్రేక్ డౌన్

Python లో 7 ముఖ్యమైన ఆపరేటర్స్ ఉంటాయి:

  • +, -, * (సాధారణ మ్యాథ్స్)
  • /: True Division — ఇది ఎప్పుడూ డెసిమల్స్ నే (float) ఇస్తుంది (ఉదా: 10 / 2 -> 5.0).
  • //: Floor Division — దశాంశ స్థానాలను తీసేసి కింది నెంబర్ ని ఇస్తుంది (ఉదా: 15 // 4 -> 3).
  • %: Modulus — భాగాహారం చేయగా మిగిలిన శేషం (Remainder) ఇస్తుంది.
  • **: Exponentiation — పవర్ ($a^b$).
💻 Example 2: Arithmetic Operators
Python 3 ▶ Run in Compiler 
a = 15
b = 4

print("Addition (+):", a + b)         # 19
print("Subtraction (-):", a - b)      # 11
print("Multiplication (*):", a * b)   # 60
print("True Division (/):", a / b)    # 3.75 (Float వస్తుంది)
print("Floor Division (//):", a // b) # 3 (Int వస్తుంది)
print("Modulus (%):", a % b)          # 3 (శేషం)
print("Power (**):", 2 ** 5)          # 32
🔍 Division తేడా గమనించండి:

ఖచ్చితమైన డెసిమల్స్ కావాలంటే / వాడాలి. కేవలం పూర్ణాంకం మాత్రమే కావాలంటే // వాడాలి.

3String Indexing, Slicing & Immutability

స్ట్రింగ్స్ అనేవి అక్షరాల సముదాయం. స్ట్రింగ్ లో ఒక భాగాన్ని కట్ చేయడానికి Slicing వాడతారు: string[start : stop : step]. గుర్తుపెట్టుకోండి: స్ట్రింగ్స్ immutable (అంటే ఒక్కసారి క్రియేట్ చేసాక వాటిని డైరెక్ట్ గా మార్చలేము):

💻 Example 3: String Indexing and Slicing
Python 3 ▶ Run in Compiler 
word = "Python"

print("First char [0]:", word[0])            # P
print("Last char [-1]:", word[-1])           # n
print("Slice [0:3]:", word[0:3])             # Pyt (3వ ఇండెక్స్ కి ఒక్క అడుగు ముందు ఆగిపోతుంది)
print("Every 2nd char [::2]:", word[::2])    # Pto (రెండు రెండు అడుగులు)
print("Reversed string [::-1]:", word[::-1]) # nohtyP (రివర్స్ అవుతుంది)
🔍 Slicing పారామీటర్స్:
  • start: ఎక్కడి నుంచి మొదలవ్వాలి.
  • stop: ఎక్కడి వరకు (కానీ ఈ అక్షరాన్ని తీసుకోదు, ముందు ఆగిపోతుంది!).
  • step: ఎన్ని అడుగులు వేయాలి (-1 పెడితే వెనక నుంచి వస్తుంది).
4Modern F-Strings తో అద్భుతమైన ఫార్మాటింగ్

F-Strings వాడితే వేరియబుల్స్ ని నేరుగా స్ట్రింగ్స్ లోపల వాడుకోవచ్చు. అంతేకాకుండా నెంబర్స్ కి కామాలు, డెసిమల్స్ ని కూడా సెట్ చేసుకోవచ్చు:

💻 Example 4: Modern F-Strings
Python 3 ▶ Run in Compiler 
student = "Balaji"
score = 95.4567
price = 1499.50

# F-strings తో చాలా సింపుల్ గా ఫార్మాట్ చేయొచ్చు:
print(f"Student: {student}")
print(f"Score (2 డెసిమల్స్ మాత్రమే): {score:.2f}")
print(f"Price (కామాలతో): Rs.{price:,.2f}")
🔍 Format Specifiers:
  • {score:.2f} వాడటం వల్ల 95.4567 కాస్తా 95.46 లాగా రౌండ్ అయ్యింది.
  • {price:,.2f} వల్ల నెంబర్ మధ్యలో కామా వచ్చింది: 1,499.50.
⚠️ Common Developer Pitfall: Float Strings ని డైరెక్ట్ గా int() చేయడం

మీరు int("45.89") అని రాస్తే ఎర్రర్ వస్తుంది. డెసిమల్ ఉన్న టెక్స్ట్ ని ఇంటిజర్ చేయాలంటే, ముందుగా దాన్ని float("45.89") చేసి ఆ తర్వాత int() చేయాలి.

💻 Hands-on Interactive Practice Challenge

ఒక పేరుని తీసుకుని, దానికి ఉన్న స్పేసెస్ ని strip() తో తీసేసి, దాన్ని రివర్స్ చేసి ప్రింట్ చేయండి.

Python 3 Practice Challenge ▶ Run in Compiler

clean_text = user_input.strip()

print("Original:", repr(user_input))
print("Cleaned:", clean_text)
print("Uppercase:", clean_text.upper())
print("Reversed:", clean_text[::-1])

❓ Frequently Asked Questions (FAQ)

Q Python లో స్ట్రింగ్స్ ని ఎందుకు మార్చలేము (Immutable)?

వాటిని మార్చకుండా ఉంచడం వల్ల మెమరీ చాలా సేవ్ అవుతుంది (కంప్యూటర్ ఒకే స్ట్రింగ్ ని పది చోట్ల వాడుకోగలదు), మరియు సెక్యూరిటీ పరంగా చాలా సేఫ్.

Q str() కి repr() కి తేడా ఏంటి?

str() అనేది సాధారణ మనుషులు చదువుకోడానికి బాగుండేలా చూపిస్తుంది. repr() అనేది డెవలపర్స్ కోసం కచ్చితంగా డేటా టైప్, స్పేసెస్, డబుల్ కోట్స్ తో సహా స్పష్టంగా చూపిస్తుంది.
