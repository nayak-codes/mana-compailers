PostgreSQL, MySQL & SQLAlchemy ORM (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 44 of 65 📂 Phase 9: Databases and APIs 📅 2026 Edition
📌 Covered in this chapter: Enterprise DB Architecture · PostgreSQL vs MySQL · The ORM Pattern · SQLAlchemy 2.0 DeclarativeBase · Mapped Columns · Session CRUD Lifecycle
పెద్ద కంపెనీలు వాడే PostgreSQL, MySQL లాంటి డేటాబేస్ లని పైథాన్ తో ఎలా కనెక్ట్ చేయాలి? SQL కోడ్ రాయకుండా పైథాన్ క్లాసెస్ తోటే డేటాబేస్ ని ఎలా కంట్రోల్ చేయాలో (SQLAlchemy ORM) నేర్చుకుందాం.
1పెద్ద డేటాబేస్ లు (PostgreSQL vs MySQL)

లక్షల మంది ఒకేసారి వాడే యాప్స్ కి SQLite సరిపోదు. దానికి సపరేట్ గా సర్వర్స్ లో రన్ అయ్యే Client-Server Databases కావాలి:

PostgreSQL (పోస్ట్ గ్రెస్):

  • స్పెషాలిటీ: ఇది చాలా అడ్వాన్స్డ్. ఒకరు డేటా రాస్తుంటే, ఇంకొకరు చదువుకోవడానికి అసలు ఆపదు (MVCC).
  • ఫీచర్స్: ఇందులో JSON డేటాని సెర్చ్ చేయొచ్చు, మ్యాప్స్ డేటా, AI కి వాడే వెక్టర్ డేటాని కూడా స్టోర్ చేయొచ్చు.

MySQL (మై సీక్వెల్):

  • స్పెషాలిటీ: ఇది వెబ్సైట్స్ కి చాలా ఫేమస్. ఎక్కువ మంది డేటాని చదివే (Read-heavy) వర్క్స్ కి ఇది సూపర్ ఫాస్ట్ గా ఉంటుంది. (ఉదా: వికీపీడియా, వర్డ్ ప్రెస్).
💻 Reference: Standard Database Connection URLs (DSNs)
Python 3 ▶ Run in Compiler 
# డేటాబేస్ కి కనెక్ట్ అయ్యే URL ఫార్మాట్ ఎలా ఉంటుందంటే:
# ఫార్మాట్: dialect+driver://username:password@host:port/database_name

dsn_examples = {
    "PostgreSQL (Standard)": "postgresql+psycopg://user:pass@127.0.0.1:5432/my_db",
    "MySQL (PyMySQL)":       "mysql+pymysql://user:pass@127.0.0.1:3306/my_db",
    "SQLite (Local File)":   "sqlite:///production.db",
    "SQLite (In-Memory)":    "sqlite:///:memory:"
}

print("--- 🌐 డేటాబేస్ కనెక్షన్ URL ఫార్మాట్స్ ---")
for db_type, uri in dsn_examples.items():
    print(f"• {db_type:22}: {uri}")
🔍 12-Factor App రూల్:

డేటాబేస్ పాస్వర్డ్స్ ఎప్పుడూ పైథాన్ కోడ్ లో రాయకూడదు. వాటిని Environment Variables లో పెట్టి os.getenv("DATABASE_URL") వాడి తెచ్చుకోవాలి.

2ORM (Object-Relational Mapper) అంటే ఏంటి? ఎందుకు వాడాలి?

ORM అంటే మన పైథాన్ క్లాసెస్ ని డైరెక్ట్ గా డేటాబేస్ టేబుల్స్ తో లింక్ చేయడం. SQL క్వెరీలు (SELECT, INSERT లాంటివి) రాయాల్సిన అవసరం లేకుండా పైథాన్ కోడ్ తోటే డేటాబేస్ ని ఆపరేట్ చేయొచ్చు.

SQLAlchemy వాడటం వల్ల 4 లాభాలు:

  1. Type Safety: కాలమ్స్ కి Mapped[str] అని ఇవ్వడం వల్ల IDE లో ఆటో కంప్లీట్ వస్తుంది, తప్పులు ముందే తెలుస్తాయి.
  2. డేటాబేస్ మార్చుకోవడం ఈజీ: మీరు SQLite నుండి PostgreSQL కి మారాలంటే జస్ట్ కనెక్షన్ URL మారిస్తే చాలు, కోడ్ మార్చక్కర్లేదు!
  3. Migrations (Alembic): కొత్త కాలమ్స్ యాడ్ చేసినప్పుడు, దానంతట అదే SQL అప్డేట్ ఫైల్స్ ని తయారు చేస్తుంది.
  4. ఆటోమాటిక్ అప్డేట్: పైథాన్ ఆబ్జెక్ట్ లో వాల్యూ మారిస్తే (ఉదా: user.email = "new@mail.com"), అది ఆటోమాటిక్ గా UPDATE క్వెరీ ని రన్ చేసేస్తుంది!
💻 Example 2: Complete SQLAlchemy 2.0 Declarative Model and Session CRUD
Python 3 ▶ Run in Compiler 
from sqlalchemy import create_engine, String, Float, Integer, select
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, Session

# 1. అన్ని మోడల్స్ కి ఒక బేస్ క్లాస్ తయారు చేద్దాం:
class Base(DeclarativeBase):
    pass

# 2. 'Course' (కోర్సు) అనే టేబుల్ ని పైథాన్ క్లాస్ లా రాద్దాం:
class Course(Base):
    __tablename__ = "courses"

    id: Mapped[int] = mapped_column(Integer, primary_key=True, autoincrement=True)
    title: Mapped[str] = mapped_column(String(100), nullable=False)
    price: Mapped[float] = mapped_column(Float, default=0.0)

    def __repr__(self) -> str:
        return f""

# 3. డేటాబేస్ ఇంజిన్ క్రియేట్ చేద్దాం:
engine = create_engine("sqlite:///:memory:", echo=False)

# 4. మన క్లాసెస్ ని చూసి డేటాబేస్ లో టేబుల్స్ క్రియేట్ చేయమని చెప్దాం:
Base.metadata.create_all(engine)

# 5. Session (డేటాబేస్ తో మాట్లాడే మేనేజర్) వాడి ఆపరేషన్స్ చేద్దాం:
with Session(engine) as session:
    # CREATE: కొత్త కోర్సులు యాడ్ చేద్దాం:
    c1 = Course(title="Python 3 Masterclass", price=1499.0)
    c2 = Course(title="FastAPI Web Apps", price=1999.0)
    
    session.add_all([c1, c2])
    session.commit()
    print("✅ 2 కోర్సులు డేటాబేస్ లో సేవ్ అయ్యాయి!")

    # READ: ₹1000 పైన ఉన్న కోర్సులు వెతుకుదాం (SQL రాయకుండానే):
    query = select(Course).where(Course.price >= 1000.0)
    premium_courses = session.scalars(query).all()
    
    print("\n--- 🎓 ప్రీమియం కోర్సులు ---")
    for course in premium_courses:
        print("•", course)

    # UPDATE: FastAPI కోర్సుకి డిస్కౌంట్ ఇద్దాం:
    fastapi_course = session.scalar(select(Course).where(Course.title.contains("FastAPI")))
    if fastapi_course:
        fastapi_course.price = 1299.0  # జస్ట్ పైథాన్ వేరియబుల్ మార్చినట్టు మారిస్తే చాలు!
        session.commit()              # ఇది ఆటోమాటిక్ గా UPDATE క్వెరీ పంపిస్తుంది!
        print(f"\n🏷️ డిస్కౌంట్ అప్డేట్ అయ్యింది: {fastapi_course}")
🔍 Dirty Checking మ్యాజిక్:

మీరు ఎప్పుడైతే ఆబ్జెక్ట్ లో ఒక వాల్యూ మారుస్తారో (price = 1299), సెషన్ దాన్ని గమనిస్తుంది. commit() చేయగానే ఏవి మారాయో వాటికి మాత్రమే SQL అప్డేట్ కమాండ్స్ రన్ చేస్తుంది.

⚠️ Common Developer Pitfall: పాత SQLAlchemy 1.x సింటాక్స్ వాడటం

SQLAlchemy 2.0 లో అంతా కొత్తగా మారింది. పాత session.query(Course).filter(...) లాంటివి వాడకూడదు. కొత్త 2.0 స్టైల్ session.scalars(select(Course).where(...)).all() మాత్రమే వాడాలి.

💻 Hands-on Interactive Practice Challenge

ఒక Author మోడల్ (id, name, books) క్రియేట్ చేసి, ఇద్దరిని యాడ్ చేసి, ఎక్కువ బుక్స్ ఉన్నవాళ్ళని ప్రింట్ చేయండి.

Python 3 Practice Challenge ▶ Run in Compiler 
from sqlalchemy import create_engine, String, Integer, select
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column, Session

class Base(DeclarativeBase): pass

class Author(Base):
    __tablename__ = "authors"
    id: Mapped[int] = mapped_column(Integer, primary_key=True)
    name: Mapped[str] = mapped_column(String(50))
    books: Mapped[int] = mapped_column(Integer)

engine = create_engine("sqlite:///:memory:")
Base.metadata.create_all(engine)

with Session(engine) as session:
    session.add_all([
        Author(id=1, name="Luciano", books=2),
        Author(id=2, name="Robert", books=6)
    ])
    session.commit()

    top = session.scalar(select(Author).order_by(Author.books.desc()))
    print(f"టాప్ ఆథర్: {top.name} ({top.books} బుక్స్ తో!)")

❓ Frequently Asked Questions (FAQ)

Q Alembic అంటే ఏంటి?

ఇది SQLAlchemy కి తోడుగా వాడే టూల్. మీరు పైథాన్ క్లాస్ లో కొత్త కాలమ్ యాడ్ చేయగానే, ఇది ఆటోమాటిక్ గా డేటాబేస్ టేబుల్ లో కూడా ఆ కాలమ్ యాడ్ చేయడానికి SQL కోడ్ ని తయారు చేస్తుంది.

Q Connection Pooling అంటే ఏంటి?

డేటాబేస్ కి కనెక్ట్ అవ్వడానికి టైమ్ పడుతుంది. అందుకే SQLAlchemy కొన్ని కనెక్షన్స్ ని ముందే ఓపెన్ చేసి పెట్టి, ఎవరు వస్తే వాళ్ళకి వెంటనే ఇచ్చేస్తుంది (స్పీడ్ పెరుగుతుంది).

Q నేను అసలు రా (Raw) SQL రాయకూడదా?

చాలా టేబుల్స్ కలిపి (JOINs) పెద్ద పెద్ద రిపోర్ట్స్ తీయాల్సి వచ్చినప్పుడు ORM కంటే డైరెక్ట్ గా SQL రాయడమే బెస్ట్ (స్పీడ్ గా రన్ అవుతుంది).
