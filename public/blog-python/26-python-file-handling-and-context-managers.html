Python File Handling & with open() (తెలుగులో)

🐍 Python 3.12+ 🟢 Chapter 26 of 65 📂 Phase 6: Exception and File Handling 📅 2026 Edition
📌 Covered in this chapter: File Modes (r, w, a, x, b) · read() vs readline() · write() vs writelines() · with open() Context Manager · Buffer Management · UTF-8
పైథాన్ ద్వారా మన కంప్యూటర్ లోని ఫైల్స్ ని (txt, csv) ఎలా ఓపెన్ చేయాలి? ఎలా చదవాలి? మరియు with open() ఎందుకు వాడాలి అనేది డీటెయిల్ గా చూద్దాం.
1File ఓపెన్ చేయడం: open() ఫంక్షన్ & Modes

పైథాన్ ఫైల్ సిస్టమ్ తో మాట్లాడటానికి open("filename", mode) అనే ఫంక్షన్ ఇస్తుంది. మోడ్ ని బట్టి మనం ఫైల్ తో ఏం చేయగలమో డిసైడ్ అవుతుంది.

File Modes ఇవే:

ModeNameఏం చేస్తుంది?ఫైల్ ఉండాలా?
'r'Read (డిఫాల్ట్)ఫైల్ లోని టెక్స్ట్ చదువుతుంది.ఉండాలి (లేకపోతే FileNotFoundError వస్తుంది)
'w'Writeపాత డేటా మొత్తం తుడిపేసి (ఎరేజ్ చేసి) కొత్తది రాస్తుంది.అవసరం లేదు (లేకపోతే క్రియేట్ చేస్తుంది)
'a'Appendపాత డేటాని చెరపకుండా, దాని కింద (చివర్లో) కొత్తది యాడ్ చేస్తుంది.అవసరం లేదు
'x'Exclusiveకొత్త ఫైల్ క్రియేట్ చేస్తుంది. అప్పటికే ఆ ఫైల్ ఉంటే క్రాష్ అవుతుంది.ఉండకూడదు!
💻 Example 1: Basic File Writing and Reading with open() and close()
Python 3 ▶ Run in Compiler 
# 1. Write మోడ్ ('w') తో ఫైల్ ఓపెన్ చేద్దాం:
f_write = open("sample_demo.txt", "w", encoding="utf-8")
f_write.write("Line 1: Hello from Python File I/O! 🚀\n")
f_write.write("Line 2: Built-in file streaming is fast and portable.\n")
f_write.close() # ఎప్పుడూ మాన్యువల్ గా క్లోజ్ చేయాలి!

# 2. Read మోడ్ ('r') తో చదువుదాం:
f_read = open("sample_demo.txt", "r", encoding="utf-8")
file_contents = f_read.read()
f_read.close()

print("--- ఫైల్ నుంచి చదివిన డేటా ---")
print(file_contents)
🔍 UTF-8 ఎందుకు?:

ఫైల్ ఓపెన్ చేసేటప్పుడు encoding="utf-8" రాయడం మర్చిపోకండి. లేదంటే మీ ఫైల్ లో ఎమోజీలు కానీ, తెలుగు అక్షరాలు కానీ ఉంటే విండోస్ లో క్రాష్ అయిపోతుంది.

2"with open()" (Context Manager) ఎందుకు మ్యాండేటరీ?

మామూలుగా open() వాడితే, పని అయ్యాక కచ్చితంగా close() రాయాలి. ఒకవేళ మధ్యలో ఏదైనా ఎర్రర్ వచ్చి కోడ్ క్రాష్ అయితే, close() రన్ అవ్వదు, ఆ ఫైల్ అలాగే లాక్ అయిపోయి మెమరీ వేస్ట్ అవుతుంది.

దీనికి సొల్యూషన్ with open(...) as f:. దీన్ని వాడితే పని అయిపోగానే లేదా మధ్యలో క్రాష్ అయినా సరే, పైథాన్ ఆటోమాటిక్ గా ఫైల్ ని క్లోజ్ చేస్తుంది (దీన్నే Context Manager అంటారు)!

💻 Example 2: Automatic Resource Management with with open()
Python 3 ▶ Run in Compiler 
# ఇండస్ట్రీలో వాడే సేఫ్ పద్ధతి ఇది:
with open("audit_log.txt", "w", encoding="utf-8") as file:
    file.write("2026-08-14 10:00:00 [INFO] System initialized successfully.\n")
    file.write("2026-08-14 10:05:22 [INFO] Database connection active.\n")
    # ఇక్కడ బ్లాక్ అయిపోగానే ఆటోమాటిక్ గా ఫైల్ close() అయిపోతుంది.

# ఫైల్ క్లోజ్ అయిందో లేదో మనమే చెక్ చేద్దాం:
print("Is the file closed?", file.closed) # True! గ్యారెంటీ!
🔍 ఇక క్లోజ్ తో పనిలేదు:

with వాడిన తర్వాత మీరు మీ లైఫ్ లో ఎప్పుడూ f.close() అని రాయక్కర్లేదు. పైథాన్ చూసుకుంటుంది.

3ఫైల్ చదవడానికి పద్ధతులు (Big Data Secrets)

ఫైల్స్ చదవడానికి మూడు పద్ధతులున్నాయి:

  1. f.read(): ఫైల్ మొత్తాన్ని ఒకేసారి ర్యామ్ (RAM) లోకి లాగుతుంది. (చిన్న ఫైల్స్ కి ఓకే, 10GB లాగ్ ఫైల్స్ అయితే కంప్యూటర్ క్రాష్ అవుతుంది!).
  2. f.readlines(): ఫైల్ మొత్తాన్ని చదివి ఒక్కో లైన్ ని ఒక లిస్ట్ లో వేస్తుంది.
  3. Memory-Efficient పద్ధతి (for line in f:): ఇది ఫైల్ ని ఒకేసారి కాకుండా లైన్ బై లైన్ ఆపరేటింగ్ సిస్టం నుంచి తెస్తుంది. ఇది బెస్ట్ అప్రోచ్!
💻 Example 3: Comparing Reading Strategies and Memory Streaming
Python 3 ▶ Run in Compiler 
# 1. ఒక డెమో ఫైల్ తయారుచేద్దాం:
with open("server_metrics.txt", "w", encoding="utf-8") as f:
    f.write("CPU_Usage: 24%\nMemory_Usage: 58%\nDisk_Free: 412GB\nActive_Threads: 16\n")

# 2. బెస్ట్ పద్ధతి: For loop వాడి ఒక్కో లైన్ తెచ్చుకోవడం:
print("--- 🚀 Strategy A: Streaming lines (Best for Big Data) ---")
with open("server_metrics.txt", "r", encoding="utf-8") as f:
    for line_num, line in enumerate(f, start=1):
        # .strip() వాడితే లైన్ చివర ఉన్న అదనపు స్పేసెస్ (ఎంటర్) పోతాయి
        print(f"Line {line_num}: {line.strip()}")

# 3. మామూలు పద్ధతి: readlines() వాడి లిస్ట్ గా మార్చడం:
with open("server_metrics.txt", "r", encoding="utf-8") as f:
    all_lines = f.readlines()
print(f"\nTotal Lines in list: {len(all_lines)}")
🔍 ఇంటర్వ్యూ ప్రశ్న:

"10 GB సైజ్ ఉన్న ఫైల్ ని పైథాన్ లో ఎలా చదువుతావ్?" అని అడిగితే f.read() చెప్పకూడదు. "for line in file అని లూప్ వాడతాను, అప్పుడు RAM ఫుల్ అవ్వదు" అని చెప్పాలి.

4పాత డేటాని ఉంచి కొత్తది కలపడం ("a" Mode)

మీరు "w" (write) వాడితే పాతది మొత్తం చెరిపేసి రాస్తుంది. అలా కాకుండా డేటాని యాడ్ (Append) చేయాలంటే "a" వాడాలి:

💻 Example 4: Appending Event Logs with "a" Mode
Python 3 ▶ Run in Compiler 
# 1. ఫైల్ ని 'w' లో స్టార్ట్ చేద్దాం:
with open("app_activity.log", "w", encoding="utf-8") as log_file:
    log_file.write("=== APPLICATION EVENT LOG ===\n")

# 2. ఇప్పుడు 'a' (append) వాడి కింద లాగ్స్ రాద్దాం:
def append_log_event(event_message):
    with open("app_activity.log", "a", encoding="utf-8") as log_file:
        log_file.write(f"• EVENT: {event_message}\n")

append_log_event("User 'balaji' logged into the portal")
append_log_event("Payment of Rs.1499 processed successfully")
append_log_event("User downloaded invoice PDF")

# మళ్ళీ ఫైల్ ఓపెన్ చేసి చూద్దాం (పాత లైన్ కూడా అలాగే ఉంటుంది):
with open("app_activity.log", "r", encoding="utf-8") as log_file:
    print(log_file.read())
🔍 Append సీక్రెట్:

"a" మోడ్ వాడినప్పుడు ఫైల్ కర్సర్ ఆటోమాటిక్ గా ఎండ్ కి వెళ్లిపోతుంది, కాబట్టి కొత్త డేటా ఎప్పుడూ కిందే పడుతుంది.

⚠️ Common Developer Pitfall: కొత్త డేటా రాయడానికి పొరపాటున "w" వాడటం

మీకు పాత డేటా కావాలి, కొత్తది దానికి కింద చేర్చాలి అనుకున్నప్పుడు "w" వాడకూడదు. "w" వాడితే సెకనులో పాతది మొత్తం ఎరేజ్ అయిపోయి ఎంప్టీ అవుతుంది. అపెండ్ కి ఎప్పుడూ "a" వాడాలి.

💻 Hands-on Interactive Practice Challenge

ఒక గ్రాసరీ లిస్ట్ (ఐటమ్స్) ని ఒక ఫైల్ "groceries.txt" లోకి రైట్ చేయండి, తర్వాత మళ్ళీ రీడ్ చేసి పక్కన నెంబర్స్ వేసి ప్రింట్ చేయండి.

Python 3 Practice Challenge ▶ Run in Compiler 
# వస్తువుల లిస్ట్:
items = ["Milk", "Whole Wheat Bread", "Eggs", "Green Tea"]

with open("groceries.txt", "w", encoding="utf-8") as f:
    for item in items:
        f.write(f"{item}\n")

print("🛒 Saved Grocery List:")
with open("groceries.txt", "r", encoding="utf-8") as f:
    for idx, line in enumerate(f, 1):
        print(f"{idx}. {line.strip()}")

❓ Frequently Asked Questions (FAQ)

Q Text mode కి Binary mode ("rb") కి తేడా ఏంటి?

Text mode వాడితే పైథాన్ డేటాని మనకు అర్థమయ్యే స్ట్రింగ్స్ గా ఇస్తుంది. అదే ఒక ఇమేజ్ గానీ, PDF గానీ ఓపెన్ చేయాలంటే "rb" (read binary) వాడాలి. అప్పుడు బైట్స్ (Bytes) రూపంలో వస్తుంది.

Q with open() లో ఒకేసారి రెండు ఫైల్స్ ఓపెన్ చేయొచ్చా?

చేయొచ్చు. with open("file1.txt", "r") as f1, open("file2.txt", "w") as f2: ఇలా కామా పెట్టి రాసుకోవచ్చు.
