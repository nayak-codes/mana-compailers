Python 3 — Vectorized Dot Product
import math

# Cosine similarity between two embedding vectors
def cosine_similarity(v1, v2):
    dot = sum(a * b for a, b in zip(v1, v2))
    mag1 = math.sqrt(sum(a * a for a in v1))
    mag2 = math.sqrt(sum(b * b for b in v2))
    return dot / (mag1 * mag2) if (mag1 and mag2) else 0.0

query_emb = [0.24, 0.81, -0.45]
doc_emb = [0.21, 0.79, -0.41]
print("Semantic Score:", round(cosine_similarity(query_emb, doc_emb), 4))

Phase 6: Generative AI, Large Language Models (LLMs) & RAG

Weeks 27 – 32 · 2026 Production Tech

The most hired AI role today is building production LLM systems. Master Retrieval-Augmented Generation (RAG), Vector Databases (Pinecone, ChromaDB), LangChain, LlamaIndex, and parameter-efficient fine-tuning (LoRA / QLoRA).

✓ Retrieval-Augmented Generation (RAG) Architecture

✓ Parameter-Efficient Fine-Tuning (LoRA / PEFT)
✓ Quantization (GGUF, AWQ, 4-bit / 8-bit weights)

What is the difference between a Data Scientist and an AI Engineer?

A Data Scientist focuses on extracting statistical insights, analyzing business trends, and testing hypotheses. An AI Engineer focuses on building, fine-tuning, and deploying software systems that run neural networks and LLMs in production at scale.
