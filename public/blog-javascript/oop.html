Object-Oriented JavaScript: Prototypes, ES6 Classes, Inheritance & #Private Fields

🟨 JavaScript (ES2026+) 🟢 Lesson 19 📂 Phase 16: Object-Oriented JavaScript 📅 2026 Edition
📌 Covered in this lesson: Prototypes & Chain · ES6 Classes · constructor & Methods · static & Getters/Setters · extends & super · Polymorphism · #private Fields · Composition · 4 Projects

ప్రోగ్రామింగ్ ని వాస్తవ ప్రపంచ ఆబ్జెక్టులు మరియు వాటి బ్లూప్రింట్లు (Classes) గా డిజైన్ చేయడానికి Object-Oriented Programming (OOP) వాడతాం. పెద్ద పెద్ద అప్లికేషన్లు మరియు ఎంటర్ ప్రైజ్ సాఫ్ట్‌వేర్ రాసేటప్పుడు OOP సూత్రాలు అత్యంత అవసరం! ఈ చాప్టర్ లో ES6 Classes, Constructors, Inheritance (extends), మరియు Private Fields (#) ల గురించి క్లియర్ గా నేర్చుకుందాం!

🏗️ రియల్ లైఫ్ అనలాజీ: ఇల్లు నిర్మాణ ప్లాన్ (Building Blueprint vs Houses)

ఒక ఆర్కిటెక్ట్ ఇల్లు కట్టడానికి ఒక ప్లాన్ గీసాడు:

  • Class (బ్లూప్రింట్ ప్లాన్): ఇల్లు ఎలా ఉండాలో (గదులు, తలుపులు, రంగులు) చెప్పే కాగితం ప్లాన్. దానికి సొంతంగా ఉనికి ఉండదు.
  • Object / Instance (నిజమైన ఇల్లు): ఆ ప్లాన్ ని చూసి కట్టిన అసలైన ఇల్లు! ఒకే ప్లాన్ (Class) నుండి ఎన్ని ఇళ్ళు (Objects) అయినా కట్టవచ్చు.
1ES6 Class Syntax & Constructor

ES6 లో class కీవర్డ్ ద్వారా తరగతులను (Classes) నిర్వచిస్తాం. కొత్త ఆబ్జెక్ట్ సృష్టించినప్పుడు constructor() ఆటోమేటిక్ గా రన్ అవుతుంది.

JavaScript — ES6 Class & Methods ▶ Run Code 
"use strict";

class BankAccount {
    // Constructor: ఆబ్జెక్ట్ సృష్టించేటప్పుడు ప్రారభ విలువలను ఇస్తుంది
    constructor(accountHolder, balance) {
        this.accountHolder = accountHolder;
        this.balance = balance;
    }

    // Method: డబ్బు జమ చేయడం
    deposit(amount) {
        this.balance += amount;
        console.log("✅ ₹" + amount + " జమ అయింది. ప్రస్తుత నిల్వ: ₹" + this.balance);
    }

    // Method: డబ్బులు తీయడం
    withdraw(amount) {
        if (amount > this.balance) {
            console.log("❌ ఖాతాలో తగినంత నిల్వ లేదు!");
        } else {
            this.balance -= amount;
            console.log("✅ ₹" + amount + " తీసేశారు. మిగిలిన నిల్వ: ₹" + this.balance);
        }
    }
}

// 1. Class నుండి Object ని సృష్టించడం (new keyword వాడాలి)
let myAcc = new BankAccount("Balaji", 1000);
myAcc.deposit(500);  // ₹500 జమ అయింది (మొత్తం ₹1500)
myAcc.withdraw(200); // ₹200 తీసేశారు (మిగిలినవి ₹1300)
2Inheritance (extends & super)

ఒక పాత Class లోని లక్షణాలను కొత్త Class లోకి వారసత్వంగా (Inheritance) తెచ్చుకోవడానికి extends మరియు super() వాడతాం.

JavaScript — Class Inheritance ▶ Run Code 
// Parent Class (తండ్రి తరగతి)
class Person {
    constructor(name) {
        this.name = name;
    }
    greet() {
        console.log("నమస్తే, నా పేరు " + this.name);
    }
}

// Child Class (పిల్లల తరగతి - Inheritance)
class Student extends Person {
    constructor(name, course) {
        super(name); // Parent class constructor ని పిలుస్తుంది
        this.course = course;
    }

    study() {
        console.log(this.name + " " + this.course + " చదువుతున్నారు 📚");
    }
}

let s1 = new Student("Suresh", "B.Tech");
s1.greet(); // Parent class method పనిచేస్తుంది!
s1.study(); // Child class method పనిచేస్తుంది!
⚠️ ప్రాక్టీస్ లో వచ్చే పొరపాట్లు (Common Mistakes)
  • Class నుండి Object ని క్రియేట్ చేసేటప్పుడు new కీవర్డ్ రాయడం మర్చిపోవడం (Ex: let a = BankAccount() ❌ -> let a = new BankAccount() ✅).
  • Child class constructor లో this ని వాడే ముందు విధిగా super() ని పిలవాలి! లేకపోతే ReferenceError వస్తుంది.
3Practice Questions & Answers
Q1. Class లో Private Fields ని ఎలా క్రియేట్ చేయాలి?

రిజల్ట్: Variable పేరు ముందు # వాడాలి (Ex: #balance = 0;). వీటిని ఆ క్లాస్ బయట నుండి యాక్సెస్ చేయలేము (Encapsulation!).

Q2. super() కీవర్డ్ దేనికి ఉపయోగపడుతుంది?

రిజల్ట్: Child class నుండి Parent class constructor ని మరియు దాని మెథడ్స్ ని పిలవడానికి super() ఉపయోగపడుతుంది.

📌 Quick Summary:

  • బ్లూప్రింట్ ల కోసం class, సృష్టించడానికి new వాడండి.
  • వారసత్వానికి extends మరియు super() వాడండి.
  • సెక్యూరిటీ కోసం #private ఫీల్డ్స్ ని ఉపయోగించండి.
