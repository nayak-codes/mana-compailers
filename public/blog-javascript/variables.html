JavaScript Variables (let, const, var) in Telugu

🟨 JavaScript (ES2026+) 🟢 Lesson 3 📂 Phase 01: JavaScript Fundamentals & Basics 📅 2026 Edition
📌 Covered in this lesson: Variables ante enti? · let · const · var · Reassigning Values · Variable Naming Rules · Global vs Function vs Block Scope · TDZ

మీ ఫోన్లో కాంటాక్ట్స్ చూడండి. "అమ్మ" అని ఒక పేరు ఉంటుంది, దాని వెనుక ఒక ఫోన్ నంబర్ ఉంటుంది. ప్రతిసారీ పది అంకెల నంబర్ గుర్తుపెట్టుకోకుండా, "అమ్మ" అని పేరు చెబితే చాలు కదా? Programming లో variable కూడా అలాంటిదే. ఒక పేరు పెట్టి, దాని వెనుక ఒక విలువ (value) ని దాచిపెడతాం.

Programming లో దాదాపు ప్రతి program కి variables అవసరం. అందుకే ఈ chapter చాలా ముఖ్యమైనది. మెల్లగా, ఉదాహరణలతో నేర్చుకుందాం.

1ఈ chapter లో మీరు నేర్చుకునేవి
  • Variable అంటే ఏమిటి, ఎందుకు అవసరం
  • let, const, var తో variables ని declare చేయడం
  • ఈ మూడింటి మధ్య తేడాలు, ఏది ఎప్పుడు వాడాలి
  • Variable పేర్లు పెట్టేటప్పుడు పాటించాల్సిన నియమాలు
  • రెండు variables విలువలను swap చేయడం
2Variable అంటే ఏమిటి?

Variable అంటే data ని store చేసే ఒక డబ్బా (box). ఆ డబ్బా మీద ఒక పేరు (label) అతికిస్తాం. ఆ పేరు చెబితే లోపల ఉన్న విలువ వస్తుంది.

ఉదాహరణకు, వంటింట్లో "చక్కెర" అని రాసిన డబ్బా ఉంటుంది. లోపల ఏముందో తెరవకుండానే మనకు తెలుస్తుంది. అలాగే, age అనే variable లో 20 ఉంటే, age అని రాస్తే 20 వస్తుంది.

"Variable" అనే పదానికి అర్థం "మారగలిగేది". అంటే డబ్బాలో విలువ తర్వాత మారొచ్చు (కొన్ని సందర్భాల్లో).

మొదటి variable

JavaScript — First Variable ▶ Run Code 
let name = "రవి";
let age = 20;

console.log(name);
console.log(age);
console.log("పేరు:", name, "వయసు:", age);

Output:

రవి
20
పేరు: రవి వయసు: 20

Code అర్థం చేసుకుందాం

  • let అనేది ఒక keyword. "ఇప్పుడు ఒక కొత్త variable తయారు చేస్తున్నాను" అని JavaScript కి చెబుతుంది.
  • name అనేది variable పేరు (డబ్బా మీద label).
  • = అంటే "సమానం" కాదు. ఇక్కడ దీని అర్థం "కుడివైపు ఉన్న విలువను ఎడమవైపు ఉన్న డబ్బాలో పెట్టు" (assignment).
  • "రవి" అనేది ఆ డబ్బాలో పెట్టిన విలువ.
  • console.log("పేరు:", name, "వయసు:", age) లో కామాలతో ఎన్ని విషయాలైనా కలిపి print చేయొచ్చు.

ఖాళీ variable

JavaScript — Uninitialized Variable 
let city;
console.log(city);
city = "హైదరాబాద్";
console.log(city);

Output:

undefined
హైదరాబాద్

విలువ ఇవ్వనప్పుడు, variable లో undefined ఉంటుంది. అంటే "ఇంకా ఏ విలువా పెట్టలేదు".

3మూడు keywords: let, const, var

JavaScript లో variable తయారు చేయడానికి మూడు keywords ఉన్నాయి. ఒక్కొక్కటి చూద్దాం.

1. let: విలువ మారొచ్చు

తర్వాత విలువ మారే అవకాశం ఉన్నప్పుడు let వాడతాం. ఉదాహరణకు, ఆటలో score.

let score = 10;
console.log(score);

score = 25;
console.log(score);

Output: 10, 25. (రెండోసారి score ముందు let రాయలేదు, ఎందుకంటే డబ్బా ముందే తయారైంది).

2. const: విలువ మారదు

const అంటే constant (స్థిరంగా ఉండేది). ఒక్కసారి విలువ పెట్టాక, దాన్ని మార్చలేం. π విలువ లేదా వారంలో రోజుల సంఖ్య లాంటివి మారవు కదా, అలాంటి వాటికి const వాడతాం.

const pi = 3.14159;
console.log(pi);

// pi = 3.14; // ❌ TypeError: Assignment to constant variable.

3. var: పాత పద్ధతి

var అనేది JavaScript లో పాత పద్ధతి. 2015 లో let మరియు const వచ్చాయి. var తో ఒకే పేరుతో రెండోసారి declare చేసినా error రాదు, కానీ దానికి సరైన స్కోప్ లేకపోవడం వల్ల బగ్స్ వస్తాయి.

ఈ రోజుల్లో వాడాలా?వద్దు (పాత code లో మాత్రమే)అవునుఅవును
💡 ఏది ఎప్పుడు వాడాలి? (సులభమైన నియమం):
  1. ముందు ఎప్పుడూ const తో మొదలుపెట్టండి.
  2. తర్వాత విలువ మార్చాల్సి వస్తే మాత్రమే let కి మార్చండి.
  3. var ని కొత్త code లో వాడకండి.
4Variable పేర్లు పెట్టే నియమాలు
  1. పేరులో అక్షరాలు, అంకెలు, _ (underscore), $ ఉండొచ్చు.
  2. పేరు అంకెతో మొదలవ్వకూడదు. (1name తప్పు, name1 సరైనది).
  3. పేరులో space ఉండకూడదు. (my name తప్పు, myName సరైనది).
  4. పెద్ద అక్షరం, చిన్న అక్షరం తేడా ఉంటుంది. age మరియు Age వేరు వేరు variables.
  5. JavaScript Keywords (let, const, if, function) ని పేర్లుగా వాడకూడదు.

Naming Convention: camelCase

let studentName = "సీత";
let totalMarks = 450;
let isPassed = true;
5ఉదాహరణ: రెండు variables ని swap చేయడం

ఇంటర్వ్యూలలో తరచూ అడిగే ప్రశ్న ఇది. రెండు గ్లాసుల్లో ఒకదానిలో పాలు, ఇంకోదానిలో టీ ఉన్నాయి. వాటిని ఒకదానిలోంచి ఒకదానికి మార్చాలంటే మూడో ఖాళీ గ్లాసు (temp) కావాలి కదా!

JavaScript — Variable Swapping ▶ Run Code 
let a = 5;
let b = 10;

let temp = a;
a = b;
b = temp;

console.log("a =", a); // 10
console.log("b =", b); // 5
⚠️ Beginners చేసే సాధారణ తప్పులు
  • Declare చేయకుండా variable వాడటం: console.log(price) ని declare చేయకుండా వాడితే ReferenceError: price is not defined వస్తుంది.
  • const విలువను మార్చడం: const lang = "JS"; lang = "Py"; చేస్తే TypeError: Assignment to constant variable వస్తుంది.
  • const కి విలువ ఇవ్వకపోవడం: const rate; అని వదిలేస్తే SyntaxError: Missing initializer in const declaration వస్తుంది.
  • పేరు అంకెతో మొదలుపెట్టడం: let 1stRank = "Ravi"; రాస్తే SyntaxError వస్తుంది.
6ప్రాక్టీస్ ప్రశ్నలు & సమాధానాలు
  1. studentName అనే variable లో మీ పేరు, studentAge లో మీ వయసు పెట్టి print చేయండి.
  2. ఒక let variable balance లో 1000 పెట్టండి. తర్వాత దాన్ని 1500 గా మార్చి print చేయండి.
  3. మూడు సబ్జెక్టుల మార్కులను const లో పెట్టి, వాటి మొత్తాన్ని print చేయండి.
  4. ఈ పేర్లలో ఏవి తప్పు? my-name, _count, 2ndPlace, $price, total marks
సమాధానాలు చూడండి

1. let studentName = "రవి"; let studentAge = 20; console.log(studentName, studentAge);

2. let balance = 1000; balance = 1500; console.log(balance); (Output: 1500)

3. const s1 = 60, s2 = 70, s3 = 80; console.log(s1 + s2 + s3); (Output: 210)

4. తప్పు పేర్లు: my-name (hyphen ఉంది), 2ndPlace (నంబర్ తో మొదలైంది), total marks (space ఉంది). సరైనవి: _count, $price.

🚀 మీరే try చేయండి

ఈ code ని మన compiler లో run చేయండి. తర్వాత విలువలు మార్చి మళ్ళీ run చేయండి:

const shopName = "Ravi Stores";
let itemPrice = 50;
let quantity = 3;

let totalBill = itemPrice * quantity;
console.log(shopName);
console.log("మొత్తం బిల్లు:", totalBill);

quantity = 5;
totalBill = itemPrice * quantity;
console.log("కొత్త బిల్లు:", totalBill);

📌 Quick Summary:

  • Variable అంటే పేరు ఉన్న ఒక డబ్బా, అందులో data ని store చేస్తాం.
  • let: విలువ మారొచ్చు. const: విలువ మారదు. var: పాత పద్ధతి, వాడకండి.
  • ఎప్పుడూ const తో మొదలుపెట్టి, అవసరమైతేనే let కి మార్చండి.
  • Variable పేరు నంబర్ తో మొదలవ్వకూడదు, space ఉండకూడదు, camelCase వాడండి.
