Browser APIs, Web Storage & Timers (The Complete Masterclass)

🟨 JavaScript (ES2026+) 🟢 Lesson 16 📂 Phase 13: Browser APIs & Storage 📅 2026 Edition
📌 Covered in this lesson: window & document · Timers (setTimeout/setInterval) · localStorage vs sessionStorage vs Cookies · URL API · History API · Clipboard API · Geolocation · Notifications & Permissions · 4 Projects

యూజర్ బ్రౌజర్ ని క్లోజ్ చేసినా లేదా పేజీని రిఫ్రెష్ చేసినా డేటా దాచి ఉంచడానికి LocalStorage, మరియు నిర్ణీత సమయంలో కోడ్ రన్ చేయడానికి Timers (setTimeout / setInterval) వాడతాం. ఈ చాప్టర్ లో LocalStorage API, JSON Storage, మరియు Async Timers ల గురించి స్పష్టంగా నేర్చుకుందాం!

🔐 రియల్ లైఫ్ అనలాజీ: జిమ్ పర్సనల్ లాకర్ (Personal Gym Locker)

మీరు జిమ్ లో ఒక లాకర్ వాడుతున్నారు అనుకోండి:

  • LocalStorage: మీ సామాన్లు లాకర్ లో దాచి తాళం వేస్తే, మీరు ఇంటికి వెళ్ళి మరుసటి రోజు వచ్చినా లాకర్ లో సామాన్లు సురక్షితంగా ఉంటాయి! (Browser restart చేసినా డేటా అలాగే ఉంటుంది).
  • SessionStorage: మీరు జిమ్ లో ఉన్నంతసేపే లాకర్ పనిచేస్తుంది. బయటకు రాగానే ఖాళీ అవుతుంది! (Tab close చేస్తే డేటా పోతుంది).
1LocalStorage API Methods
Methodవివరణ (Description)ఉదాహరణ (Example)
localStorage.setItem(key, value)డేటాను దాచడానికిlocalStorage.setItem("theme", "dark")
localStorage.getItem(key)దాచిన డేటాను పొందడానికిlet t = localStorage.getItem("theme")
localStorage.removeItem(key)ఒక డేటాను తొలగించడానికిlocalStorage.removeItem("theme")
localStorage.clear()అన్నింటినీ తొలగించడానికిlocalStorage.clear()
2Storing Objects in LocalStorage (JSON.stringify & parse)
⚠️ LocalStorage కేవలం String లను మాత్రమే దాచగలదు!

మీరు ఒక Object ని నేరుగా దాచడానికి ప్రయత్నిస్తే అది "[object Object]" గా మారి డేటా పోతుంది! కాబట్టి దాచేటప్పుడు JSON.stringify() ద్వారా స్ట్రింగ్ గా మార్చి, బయటకు తీసేటప్పుడు JSON.parse() ద్వారా తిరిగి Object గా మార్చాలి.

JavaScript — Object Storage 
let user = { name: "Balaji", score: 100 };

// 1. Object ని String గా మార్చి దాచడం
localStorage.setItem("userProfile", JSON.stringify(user));

// 2. బయటకు తీసి తిరిగి Object గా మార్చడం
let savedData = localStorage.getItem("userProfile");
if (savedData) {
    let parsedUser = JSON.parse(savedData);
    console.log("User Name:", parsedUser.name); // Balaji
}
3Timers: setTimeout & setInterval
  • setTimeout(callback, ms): కొన్ని మిల్లీ సెకన్ల తర్వాత ఒకే ఒక సారి కోడ్ ని రన్ చేస్తుంది.
  • setInterval(callback, ms): ప్రతి కొన్ని మిల్లీ సెకన్లకు పదే పదే కోడ్ ని రన్ చేస్తుంది (ఆపడానికి clearInterval వాడాలి).
JavaScript — Timers ▶ Run Code 
"use strict";

// 1. 3 సెకన్ల (3000ms) తర్వాత మెసేజ్ రావడం
setTimeout(() => {
    console.log("⏰ 3 సెకన్లు ముగిసాయి!");
}, 3000);

// 2. కౌంట్ డౌన్ టైమర్ (ప్రతి 1 సెకనుకు)
let count = 1;
let timer = setInterval(() => {
    console.log("Timer Tick:", count);
    count++;

    if (count > 3) {
        clearInterval(timer); // 3 సార్లు అయ్యాక ఆగిపోతుంది
        console.log("🛑 Timer Stopped.");
    }
}, 1000);
4Practice Questions & Answers
Q1. LocalStorage కి SessionStorage కి తేడా ఏమిటి?

రిజల్ట్: LocalStorage బ్రౌజర్ క్లోజ్ చేసినా డేటాని ఉంచుతుంది (పరిమితి లేదు). SessionStorage కేవలం ఆ నిర్దిష్టమైన Tab ఓపెన్ లో ఉన్నంతవరకే డేటాని ఉంచుతుంది.

Q2. setTimeout(fn, 0) ఇస్తే కోడ్ వెంటనే రన్ అవుతుందా?

రిజల్ట్: లేదు! JavaScript Event Loop ప్రకారం, ప్రస్తుత కాల్ స్టేక్ ఖాళీ అయిన తర్వాతే (Microtask Queue/Task Queue ముగిసాక) రన్ అవుతుంది.

📌 Quick Summary:

  • శాశ్వత డేటా కోసం localStorage వాడండి.
  • ఆబ్జెక్టుల కోసం JSON.stringify మరియు JSON.parse వాడండి.
  • సమయానుకూల పనుల కోసం setTimeout / setInterval వాడండి.
