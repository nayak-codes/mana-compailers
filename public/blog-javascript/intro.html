Welcome & Hello World

🟨 JavaScript Lesson 1 Beginner

కంప్యూటర్స్ కి మనం చెప్పే పనిని అర్థమయ్యేలా చేయడానికి వాడే లాంగ్వేజెస్ లో JavaScript (JS) ఒకటి. ఇది ప్రపంచంలోనే అత్యంత పాపులర్ ప్రోగ్రామింగ్ లాంగ్వేజ్! మొదట్లో కేవలం వెబ్ పేజీలని ఇంటరాక్టివ్ (Interactive) గా చేయడానికి వాడేవారు. కానీ ఇప్పుడు గేమ్స్, మొబైల్ యాప్స్, మరియు సర్వర్ సైడ్ (Node.js) కూడా జావాస్క్రిప్ట్ తోనే చేస్తున్నారు.

🍔 రియల్ లైఫ్ స్టోరీ: JavaScript అంటే ఏంటి?

ఒక ఇల్లు (House) కడుతున్నాం అనుకోండి:

  • HTML: ఇటుకలు, గోడలు (Structure). ఇది లేకపోతే ఇల్లు నిలబడదు.
  • CSS: పెయింటింగ్, ఇంటీరియర్ డిజైన్ (Style). ఇల్లు అందంగా కనిపించడానికి.
  • JavaScript: ఎలక్ట్రిసిటీ, స్విచ్ వేస్తే ఫ్యాన్ తిరగడం, మోటార్ ఆన్ అవ్వడం (Functionality). ఇది లేకపోతే ఇల్లు కేవలం ఒక బొమ్మ లాగా ఉంటుంది!

అలాగే ఒక వెబ్సైట్ కి ప్రాణం పోసేదే JavaScript!

1 V8 Engine & JIT Compilation

జావాస్క్రిప్ట్ అనేది Interpreted మరియు Just-In-Time (JIT) Compiled లాంగ్వేజ్. మీరు రాసిన కోడ్ ని బ్రౌజర్ లో ఉండే "V8 Engine" (Google Chrome లో వాడే ఇంజిన్) చదివి, వెంటనే మెషిన్ కోడ్ కి మార్చి రన్ చేస్తుంది. అందుకే ఇది చాలా ఫాస్ట్ గా ఉంటుంది!

[ JavaScript Code ] ↓ (Parsed by Browser) [ AST (Abstract Syntax Tree) ] ↓ (JIT Compiler / Interpreter) [ Bytecode & Optimized Machine Code ] ↓ [ Executes on CPU ]
2 Your First Program

ప్రోగ్రామింగ్ నేర్చుకునేటప్పుడు ఎవరైనా ముందుగా రాసే ప్రోగ్రాం "Hello World". జావాస్క్రిప్ట్ లో ఏదైనా ఔట్పుట్ ని స్క్రీన్ మీద (లేదా Console లో) ప్రింట్ చేయడానికి console.log() వాడతాం.

JavaScript — Hello World ▶ Run Code 
// మీ మొదటి JavaScript ప్రోగ్రాం
console.log("Hello, World!");
console.log(10 + 20); // కూడికలు కూడా చేయొచ్చు (Output: 30)

💡 ఇంటర్వ్యూ ప్రశ్నలు (Interview Questions)

1. JavaScript కీ Java కీ సంబంధం ఉందా?

Answer: అస్సలు లేదు! Apple పండు కీ, Pine-apple కీ ఎంత సంబంధం ఉందో.. Java కీ, JavaScript కీ అంతే సంబంధం ఉంది. పేర్లు మాత్రమే సిమిలర్ గా ఉంటాయి.

2. JavaScript ఎక్కడ రన్ అవుతుంది?

Answer: బ్రౌజర్ (Client-side) లో మరియు Node.js ద్వారా సర్వర్ (Server-side) లో కూడా రన్ అవుతుంది.
