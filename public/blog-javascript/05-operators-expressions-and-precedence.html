JavaScript Operators తెలుగులో | Arithmetic, Comparison, Logical Operators

🟨 JavaScript (ES2026+) 🟢 Lesson 5 📂 Phase 03: Operators & Input 📅 2026 Edition
📌 Covered in this lesson: Arithmetic (+ - * / % **) · ++ / -- · += -= · Comparison (== vs ===) · Logical (&& || !) · Ternary Operator

కాలిక్యులేటర్ లో +, -, ×, ÷ బటన్లు చూశారు కదా? వాటి పని సంఖ్యలతో ఏదో ఒక చర్య (operation) చేయడం. Programming లో ఇలాంటి చిహ్నాలనే Operators అంటారు.

ఒక చర్య చేయడానికి కావాల్సినవి రెండు: చర్యను సూచించే చిహ్నం (operator) మరియు ఆ చర్య జరిగే విలువలు (operands). ఉదాహరణకు 5 + 3 లో + అనేది operator, 5 మరియు 3 అనేవి operands.

ఈ chapter లో ముఖ్యమైన మూడు రకాల operators నేర్చుకుందాం: లెక్కలకు (arithmetic), పోలికలకు (comparison), నిర్ణయాలకు (logical).

1ఈ chapter లో మీరు నేర్చుకునేవి
  • Arithmetic operators: + - * / % **
  • Increment, decrement (++, --) మరియు assignment operators (+=, -=)
  • Comparison operators: == మరియు === మధ్య తేడా
  • Logical operators: &&, ||, !
  • Ternary operator (చిన్న if-else)
  • Operator precedence (ఏ చర్య ముందు జరుగుతుంది)
21. Arithmetic Operators (లెక్కల operators)
Operatorపనిఉదాహరణఫలితం
+కూడిక10 + 313
-తీసివేత10 - 37
*గుణకారం10 * 330
/భాగహారం10 / 33.3333333333333335
%శేషం (Modulus)10 % 31
**ఘాతం (Power)10 ** 31000
JavaScript — Arithmetic Operators ▶ Run Code 
let a = 10;
let b = 3;

console.log(a + b);   // 13
console.log(a - b);   // 7
console.log(a * b);   // 30
console.log(a / b);   // 3.3333333333333335
console.log(a % b);   // 1
console.log(a ** b);  // 1000

% (Modulus) ని అర్థం చేసుకుందాం

🍬 రియల్ లైఫ్ అనలాజీ: లడ్డూల పంపకం

17 లడ్డూలను 5 మంది పిల్లలకు సమానంగా పంచారనుకోండి. ప్రతి ఒక్కరికి 3 లడ్డూలు వస్తాయి, 2 లడ్డూలు మిగులుతాయి. ఆ మిగిలిన 2 యే 17 % 5.

% తో సరి/బేసి సంఖ్యలు తెలుసుకోవడం

ఒక సంఖ్యను 2 తో భాగిస్తే శేషం 0 వస్తే అది సరి సంఖ్య (even), 1 వస్తే బేసి సంఖ్య (odd).

console.log(10 % 2); // 0 (Even)
console.log(7 % 2);  // 1 (Odd)
console.log(10 % 2 === 0); // true

ఉదాహరణ: షాప్ బిల్లు లెక్కించడం

const price = 250;
const quantity = 3;

const subtotal = price * quantity;
const gst = subtotal * 18 / 100;
const total = subtotal + gst;

console.log("Subtotal:", subtotal); // 750
console.log("GST (18%):", gst);     // 135
console.log("మొత్తం బిల్లు:", total); // 885

Operator precedence: ఏ చర్య ముందు జరుగుతుంది?

console.log(2 + 3 * 4);   // 14 (గుణకారం ముందు జరిగింది: 3 * 4 = 12 + 2)
console.log((2 + 3) * 4); // 20 (Brackets ముందు జరిగాయి: 5 * 4)

గణితంలో లాగే, JavaScript లో కూడా గుణకారం, భాగహారం కూడిక, తీసివేత కంటే ముందు జరుగుతాయి. ఎటువంటి సందేహం ఉన్నా Brackets ( ) వాడండి.

32. Increment (++) మరియు Decrement (--)

ఒక విలువను 1 పెంచడానికి ++, 1 తగ్గించడానికి -- వాడతాం.

let count = 5;

count++;
console.log(count); // 6

count--;
console.log(count); // 5

x++ మరియు ++x మధ్య తేడా

let x = 5;

console.log(x++); // 5 (ముందు పాత విలువ ఇచ్చి, తర్వాత పెంచుతుంది)
console.log(x);   // 6
console.log(++x); // 7 (ముందు పెంచి, తర్వాత కొత్త విలువ ఇస్తుంది)
43. Assignment Operators (విలువ పెట్టే operators)
Operatorఅర్థంసమానమైన రూపం
+=కూడి పెట్టుx = x + 5
-=తీసివేసి పెట్టుx = x - 5
*=గుణించి పెట్టుx = x * 5
/=భాగించి పెట్టుx = x / 5
let total = 100;

total += 50;
console.log(total); // 150 (జమ)

total -= 30;
console.log(total); // 120 (ఖర్చు)

total *= 2;
console.log(total); // 240 (రెట్టింపు)

total /= 4;
console.log(total); // 60  (నాల్గవ వంతు)
54. Comparison Operators (పోలిక operators)
Operatorఅర్థంఉదాహరణఫలితం
>కంటే ఎక్కువ5 > 3true
<కంటే తక్కువ5 < 3false
>=ఎక్కువ లేదా సమానం5 >= 5true
<=తక్కువ లేదా సమానం5 <= 4false
===సమానమా (type తో సహా)5 === 5true
!==సమానం కాదా (type తో సహా)5 !== 6true

== మరియు === మధ్య ముఖ్యమైన తేడా

console.log(5 == "5");   // true  (Types వేరైనా ఆటోమేటిక్ గా మార్చి పోల్చింది)
console.log(5 === "5");  // false (విలువ మరియు type రెండూ పోల్చింది - Strict!)
console.log(5 != "5");   // false
console.log(5 !== "5");  // true
⚠️ బంగారు నియమం:

ఎప్పుడూ === మరియు !== వాడండి. == మరియు != ని వాడకండి. దీనివల్ల ఊహించని bugs రావు.

Strings పోలిక

console.log("apple" < "banana"); // true  (అక్షరక్రమం ప్రకారం 'a' ముందు వస్తుంది)
console.log("apple" === "Apple"); // false (చిన్న, పెద్ద అక్షరాలు వేరు)
65. Logical Operators (&&, ||, !)
💡 రియల్ లైఫ్ అనలాజీ:
  • && (AND): ATM లో డబ్బు రావాలంటే కార్డ్ మరియు PIN రెండూ సరిగ్గా ఉండాలి.
  • || (OR): షాప్ లో బిల్లు కట్టడానికి Cash లేదా UPI, ఏదైనా ఒకటి ఉంటే చాలు.
  • ! (NOT): స్విచ్ ఆన్ ని ఆఫ్ గా, true ని false గా మారుస్తుంది.

ఉదాహరణ: ఓటు అర్హత & సెలవు రోజు

const age = 20;
const isCitizen = true;
console.log("ఓటు వేయొచ్చా?", age >= 18 && isCitizen); // true

const isSunday = false;
const isFestival = true;
console.log("ఈ రోజు సెలవా?", isSunday || isFestival);        // true
console.log("ఈ రోజు పని దినమా?", !(isSunday || isFestival)); // false
76. Ternary Operator: చిన్న if-else

ఒక షరతు ఆధారంగా రెండు విలువల్లో ఒకదాన్ని ఎంచుకోవడానికి Ternary Operator వాడతాం:

const marks = 60;
const result = marks >= 35 ? "Pass" : "Fail";
console.log(result); // Pass

marks >= 35 నిజం కాబట్టి ? తర్వాత ఉన్న "Pass" ఎంపిక అయ్యింది. False అయితే : తర్వాత ఉన్న "Fail" వచ్చేది.

⚠️ Beginners చేసే సాధారణ తప్పులు
  • === బదులు = వాడటం: if (x = 5) అని రాస్తే అది విలువ పెట్టేస్తుంది (Assignment), పోల్చదు! పోల్చడానికి ఎప్పుడూ === వాడండి.
  • String మరియు number ని కూడటం: "2" + 3 ఫలితం "23" అవుతుంది. కానీ "2" * 3 ఫలితం 6 మరియు "10" - 5 ఫలితం 5 అవుతాయి.
  • Number strings ని పోల్చడం: "10" < "9" ఫలితం true! ఎందుకంటే strings ని అక్షరక్రమం ప్రకారం పోలుస్తుంది. సంఖ్యలుగా పోల్చాలంటే నంబర్ టైప్ లో ఉండాలి.
  • వరుసగా పోలికలు రాయడం: 1 < 5 < 3 ఇస్తుంది true! ఎందుకంటే 1 < 5 (true/1) అయి 1 < 3 అవుతుంది. సరైన మార్గం: 5 > 1 && 5 < 3.
8ప్రాక్టీస్ ప్రశ్నలు & సమాధానాలు
  1. a = 20, b = 6 అయితే a + b, a - b, a * b, a / b, a % b విలువలు కనుక్కోండి.
  2. ఒక సంఖ్య సరి సంఖ్యా కాదా చెక్ చేసే expression రాయండి. (సంఖ్య 42)
  3. P = 1000, R = 5, T = 2 అయితే సాధారణ వడ్డీ (Simple Interest = P × R × T / 100) లెక్కించి print చేయండి.
  4. ఈ ఫలితాలు ఏమిటి? 10 == "10", 10 === "10", true && false, true || false, !true.
  5. ఒక సంవత్సరం leap year అవునా కాదా తెలుసుకునే code రాయండి (2024 మరియు 1900 లతో).
సమాధానాలు చూడండి

1. 26, 14, 120, 3.3333333333333335, 2.

2. 42 % 2 === 0 (Output: true).

3. const simpleInterest = 1000 * 5 * 2 / 100; console.log(simpleInterest); (Output: 100).

4. true, false, false, true, false.

5.
const isLeap = (y) => (y % 4 === 0 && y % 100 !== 0) || y % 400 === 0;
2024: true (Leap year), 1900: false (Leap year కాదు).

📌 Quick Summary:

  • Operator అంటే సంఖ్యలు/విలువలతో చర్య చేసే చిహ్నం. విలువలను operands అంటారు.
  • Arithmetic: + - * / % **. % శేషాన్ని ఇస్తుంది, సరి/బేసి చెక్ చేయడానికి వాడతాం.
  • ++ / -- విలువను 1 పెంచుతాయి/తగ్గిస్తాయి. +=, -= సంక్షిప్త రూపాలు.
  • Comparison: > < >= <= === !== ఫలితంగా boolean ఇస్తాయి. ఎప్పుడూ === వాడండి.
  • Logical: && (రెండు నిజం), || (ఏదైనా ఒకటి నిజం), ! (వ్యతిరేకం).
  • Ternary: షరతు ? విలువ1 : విలువ2.
