JavaScript DOM: ఎలిమెంట్లను ఎంచుకోవడం & సవరించడం (Master Guide)

🟨 JavaScript (ES2026+) 🟢 Lesson 18 of 25 📂 Part 04: DOM & Events (Page 1 of 4) ⏱️ 17 min read
📌 Covered in this lesson: DOM Tree Architecture · querySelector vs getElementById · NodeList vs HTMLCollection · textContent vs innerHTML (XSS) · classList (add, remove, toggle) · style Object & camelCase · createElement & appendChild · Live Interactive Card Project

ఇప్పటివరకు మనం నేర్చుకున్న JavaScript కేవలం కంప్యూటర్ మెమరీలో లేదా కన్సోల్ (Console) లో మాత్రమే పనిచేసింది. కానీ వెబ్ డెవలప్‌మెంట్‌లో అసలైన మ్యాజిక్ ఎప్పుడు జరుగుతుందంటే — జావాస్క్రిప్ట్ నేరుగా స్క్రీన్ పై కనిపించే HTML బటన్లు, టెక్స్ట్, కలర్స్, ఇమేజ్‌లను మార్చడం ప్రారంభించినప్పుడు!

టీవీ & రిమోట్ కంట్రోల్ అనాలజీ (TV & Remote Control Analogy):
ఒక టెలివిజన్‌ను ఊహించుకోండి. స్క్రీన్ పై బొమ్మలు చూపించేది HTML/CSS అయితే, చేతిలో ఉన్న రిమోట్ కంట్రోల్ JavaScript. మరి రిమోట్ నొక్కిన బటన్ సిగ్నల్‌ను టీవీ అర్థం చేసుకోవడానికి మధ్యలో ఉండే ఇన్‌ఫ్రారెడ్ సిగ్నల్ మరియు సర్క్యూట్ బోర్డే DOM (Document Object Model).
HTML ఫైల్ లోని ప్రతి ట్యాగ్‌ను బ్రౌజర్ ఒక JavaScript ఆబ్జెక్ట్‌గా మారుస్తుంది. జావాస్క్రిప్ట్ అనే రిమోట్ ద్వారా మనం ఏ బటన్ నొక్కితే ఆ HTML ఎలిమెంట్ తక్షణమే మారిపోతుంది!

ఈ పాఠంతో మనం Part 04: DOM & Events లోకి అడుగుపెడుతున్నాం. ఆధునిక వెబ్ డెవలప్‌మెంట్‌లో ఎలిమెంట్లను ఎలా పట్టుకోవాలి (Select), వాటి రంగులు & తరగతులను ఎలా మార్చాలి (Manipulate), మరియు కొత్త ఎలిమెంట్లను డైనమిక్‌గా ఎలా సృష్టించాలో పూర్తి డీటెయిల్‌గా నేర్చుకుందాం.

1DOM అంటే ఏమిటి? (తలక్రిందుల చెట్టు అనాలజీ)

DOM అంటే Document Object Model. బ్రౌజర్ ఒక HTML డాక్యుమెంట్‌ను లోడ్ చేసినప్పుడు, అది కేవలం సాదా టెక్స్ట్ ఫైల్‌గా చదివి ఊరుకోదు. ఆ HTML కోడ్‌ను విశ్లేషించి, ఒక తలక్రిందుల చెట్టు (Inverted Tree Data Structure) ఆకారంలో ఆబ్జెక్టుల సమాహారంగా మారుస్తుంది.

🌳 ది ఫ్యామిలీ ట్రీ నిర్మాణం (DOM Tree Structure):

• Root Node (మూలం): window.document (మొత్తం వెబ్ పేజీకి గేట్‌వే).
• Root Element (కాండం): <html> ట్యాగ్.
• Parent Branches (కొమ్మలు): <head> మరియు <body>.
• Child Nodes / Leaves (ఆకులు, చిగుళ్ళు): <h1>, <p>, <div>, <button>, మరియు వాటిలోని అక్షరాలు (Text Nodes).

ఈ చెట్టులోని ప్రతి ఆకును ఒక Node అంటారు. జావాస్క్రిప్ట్ ఈ నోడ్స్‌ని తన చేతుల్లోకి తీసుకుని, రంగులు మార్చడం, తొలగించడం, కొత్తవి చేర్చడం వంటి ఎన్నో అద్భుతాలు చేయగలదు!

2Selecting Elements: Modern vs Legacy పద్ధతులు

ఒక HTML ఎలిమెంట్‌ను మార్చాలంటే, ముందు దాన్ని JavaScript లోకి పట్టుకోవాలి (Select చేసుకోవాలి). దీని కోసం పాత పద్ధతులు (Legacy) మరియు ఆధునిక పద్ధతులు (Modern) ఉన్నాయి:

Method దేని ఆధారంగా వెతుకుతుంది? రిటర్న్ చేసేది ఆధునిక సిఫార్సు
document.querySelector(selector) ఏదైనా CSS Selector (#id, .class, tag) సరిపోలిన మొట్టమొదటి ఎలిమెంట్ (లేకపోతే null) ✅ అత్యుత్తమం: 90% కోడింగ్‌లో ఇదే వాడతాం.
document.querySelectorAll(selector) ఏదైనా CSS Selector సరిపోలిన అన్ని ఎలిమెంట్స్ (NodeList) ✅ అత్యుత్తమం: గ్రూప్ ఎలిమెంట్స్ కోసం.
document.getElementById(id) ఖచ్చితమైన ID పేరు మాత్రమే (# అవసరం లేదు) ఆ ID గల ఏకైక ఎలిమెంట్ మంచిది: చాలా వేగవంతమైనది (Fastest).
document.getElementsByClassName(class) Class పేరు మాత్రమే (. అవసరం లేదు) లైవ్ HTMLCollection ⚠️ పాతది: లూపింగ్ కొద్దిగా కష్టం.
document.getElementsByTagName(tag) HTML Tag పేరు (ఉదా: 'p', 'button') లైవ్ HTMLCollection ⚠️ పాతది: అరుదుగా వాడతారు.
⚠️ `#` మరియు `.` గుర్తు మర్చిపోకండి!

getElementById("title") రాసేటప్పుడు # పెట్టకూడదు.
కానీ querySelector("#title") రాసేటప్పుడు ఖచ్చితంగా # పెట్టాలి (క్లాస్ అయితే .btn పెట్టాలి). ఇది బిగినర్స్ అత్యధికంగా చేసే పొరపాటు!

3NodeList vs HTMLCollection (Static vs Live తేడా)

ఒకటి కంటే ఎక్కువ ఎలిమెంట్లను ఎంచుకున్నప్పుడు బ్రౌజర్ మనకు ఇచ్చే కలెక్షన్లలో రెండు రకాలు ఉంటాయి. ఇంటర్వ్యూలలో అడిగే అత్యంత ముఖ్యమైన కాన్సెప్ట్ ఇది:

📸 ఫోటోగ్రాఫ్ (Static NodeList) vs లైవ్ సీసీటీవీ (Live HTMLCollection):

• NodeList (querySelectorAll ఇచ్చేది): ఇది ఒక ఫోటోగ్రాఫ్ (Static Snapshot) లాంటిది. మీరు సెలెక్ట్ చేసుకున్న తర్వాత పేజీలో కొత్తగా మరో <p> ట్యాగ్ జోడించినా, ఈ లిస్ట్ లో సంఖ్య పెరగదు. పైగా దీనిపై నేరుగా forEach() లూప్ వాడవచ్చు!

• HTMLCollection (getElementsByClassName ఇచ్చేది): ఇది ఒక లైవ్ సీసీటీవీ ఫుటేజ్ (Live Collection) లాంటిది. పేజీలో కొత్త ఎలిమెంట్ రాగానే ఈ కలెక్షన్ లో ఆటోమేటిక్‌గా అప్‌డేట్ అవుతుంది. కానీ దీనిపై నేరుగా forEach() పని చేయదు (ముందుగా Array.from() తో మార్చాలి).

ఆధునిక ప్రామాణికం: ఎలాంటి తలనొప్పులు లేకుండా సూటిగా పనిచేస్తుంది కాబట్టి ఎల్లప్పుడూ querySelectorAll() వాడటమే ఉత్తమ పద్ధతి!

4Content మార్పులు: textContent vs innerHTML vs innerText

ఒక ఎలిమెంట్‌ను పట్టుకున్న తర్వాత, దాని లోపల ఉన్న సమాచారాన్ని మార్చడానికి మూడు ప్రముఖ ప్రాపర్టీలు ఉన్నాయి:

Property ఎలా ప్రవర్తిస్తుంది? HTML ట్యాగ్స్ ఇస్తే? భద్రత & వేగం
textContent ఎలిమెంట్ లోపల ఉన్న సాదా టెక్స్ట్‌ను మాత్రమే చదువుతుంది/మారుస్తుంది. ట్యాగ్స్‌ను కూడా మామూలు అక్షరాలుగానే చూపిస్తుంది (Render చేయదు). ✅ 100% సురక్షితం & వేగవంతమైనది. సాధారణ టెక్స్ట్ కోసం ఇదే వాడాలి.
innerText స్క్రీన్ పై మనిషి కంటికి కనిపించే టెక్స్ట్ మాత్రమే (CSS display: none లో ఉన్నదాన్ని వదిలేస్తుంది). ట్యాగ్స్‌ను రెండర్ చేయదు. కొద్దిగా నెమ్మది (బ్రౌజర్ లేఅవుట్ ని మళ్లీ లెక్కిస్తుంది).
innerHTML ఎలిమెంట్ లోపల పూర్తి HTML కోడ్‌ను చదువుతుంది మరియు కొత్త HTML ట్యాగ్స్‌ను నిర్మిస్తుంది. <b>bold</b> వంటి ట్యాగ్స్‌ను నిజమైన బటన్లు, బోల్డ్ టెక్స్ట్‌గా మారుస్తుంది. 🚨 జాగ్రత్త (XSS Risk): యూజర్ ఇచ్చిన ఇన్‌పుట్ నేరుగా innerHTML లో పెడితే హ్యాకర్లు మాల్వేర్ స్క్రిప్ట్‌లు రన్ చేయగలరు!

🛡️ భద్రతా సూత్రం (Security Golden Rule):

మీరు కేవలం పేరు, సంఖ్య, సందేశం వంటి సాధారణ అక్షరాలు మాత్రమే మార్చాలనుకుంటే కళ్లు మూసుకుని textContent వాడండి. ఒకవేళ జావాస్క్రిప్ట్ ద్వారా కొత్తగా ఒక <span class="badge"> ట్యాగ్‌ను చొప్పించాలనుకుంటే మాత్రమే innerHTML వాడండి.

5Attributes & Classes మార్చడం (classList API)

వెబ్‌సైట్లలో డార్క్ మోడ్ ఆన్ చేయడం, ఎర్రర్ బాక్స్ ఎరుపు రంగులోకి మారడం, లేదా పాప్‌అప్ ఓపెన్ అవ్వడం వెనుక అంతా CSS Classes ని జావాస్క్రిప్ట్ ద్వారా జోడించడం లేదా తొలగించడమే జరుగుతుంది.

🎨 classList API యొక్క 4 సూపర్ పవర్స్:

• element.classList.add("dark-theme") ➔ ఆ క్లాస్ లేకపోతే జోడిస్తుంది.
• element.classList.remove("hidden") ➔ ఆ క్లాస్ ఉంటే తొలగిస్తుంది.
• element.classList.toggle("active") ➔ స్విచ్ లాంటిది: క్లాస్ ఉంటే తీసేస్తుంది, లేకపోతే పెడుతుంది! (డార్క్ మోడ్ టోగుల్ కి పర్ఫెక్ట్).
• element.classList.contains("active") ➔ ఆ క్లాస్ ఉందో లేదో చూసి true/false ఇస్తుంది.

Attributes (లక్షణాలు) మార్చడం:

  • element.setAttribute("href", "https://ourcompiler.com") ➔ లింక్ లేదా ఇమేజ్ సోర్స్ మార్చడానికి.
  • element.getAttribute("src") ➔ ప్రస్తుత లింక్ లేదా అట్రిబ్యూట్ విలువను తెలుసుకోవడానికి.
  • element.removeAttribute("disabled") ➔ బటన్ డిజేబుల్ అట్రిబ్యూట్ ని తీసివేయడానికి.
6Styles (CSS) & Dynamic Elements (createElement)

1. Inline Styles మార్చడం:
element.style.color = "blue"; అని రాస్తే అది నేరుగా ఆ ట్యాగ్‌పై CSS రాస్తుంది.
Gotcha (CamelCase నియమం): CSS లో background-color లేదా font-size అని రాస్తాం. కానీ JavaScript లో హైఫన్ (-) మైనస్ ఆపరేటర్‌గా భావించబడుతుంది. కాబట్టి ఎల్లప్పుడూ camelCase వాడాలి:
card.style.backgroundColor = "#1e293b";
card.style.fontSize = "18px";

2. కొత్త ఎలిమెంట్లను సృష్టించడం & తొలగించడం:
పేజీలో ముందే లేని ఒక కొత్త బటన్ లేదా లిస్ట్ ఐటమ్‌ను గాల్లో సృష్టించి పేజీలో అతికించవచ్చు:

  1. const newLi = document.createElement("li"); ➔ మెమరీలో ఒక కొత్త <li> సృష్టిస్తుంది.
  2. newLi.textContent = "కొత్త టాస్క్"; ➔ దానిలో టెక్స్ట్ నింపుతుంది.
  3. parentUl.appendChild(newLi); ➔ పేరెంట్ లిస్ట్ లోపల చివరిలో అతికిస్తుంది.
  4. newLi.remove(); ➔ ఆ ఎలిమెంట్‌ను స్క్రీన్ పై నుండి శాశ్వతంగా తుడిచిపెట్టేస్తుంది!
7Master Code Demo: Core DOM Operations ఒకేచోట

పైన మనం నేర్చుకున్న సెలెక్టర్లు, టెక్స్ట్ మార్పులు, క్లాస్‌ల టోగులింగ్ మరియు కొత్త ఎలిమెంట్ చేర్చే విధానాన్ని ప్రదర్శించే ఏకైక సమగ్ర కోడ్ ఉదాహరణ ఇది. బ్రౌజర్ లో ఇది ఎలా రన్ అవుతుందో ప్రతి లైన్ గమనించండి:

JavaScript / HTML — Master DOM Operations Demo ▶ Run Code

card.classList.add("highlight-card");

8Beginners చేసే 5 సాధారణ తప్పులు (Common Mistakes)

DOM తో పనిచేసేటప్పుడు కొత్త డెవలపర్లు ఎదుర్కొనే ప్రధాన తప్పులు మరియు వాటి నివారణ మార్గాలు:

1. Cannot read properties of null (Script ట్యాగ్ పైన పెట్టడం):

బ్రౌజర్ ఇంకా HTML ట్యాగ్‌ను లోడ్ చేయకముందే పైన <head> లో జావాస్క్రిప్ట్ రన్ అయితే, ఎలిమెంట్ దొరకక null వస్తుంది.
పరిష్కారం: <script src="app.js" defer></script> లో defer వాడండి లేదా స్క్రిప్ట్‌ను </body> కి సరిగ్గా పైన రాయండి.

2. querySelectorAll ఫలితంపై నేరుగా style మార్చాలనుకోవడం:

const items = document.querySelectorAll(".item");
items.style.color = "red"; // ❌ పనిచేయదు! ఎందుకంటే items అనేది ఒక కలెక్షన్ (Array లాంటిది).
పరిష్కారం: లూప్ వాడాలి: items.forEach(el => el.style.color = "red"); // ✅

3. querySelector లో '#' లేదా '.' మర్చిపోవడం:

document.querySelector("my-btn"); // ❌ <my-btn> అనే HTML ట్యాగ్ కోసం వెతుకుతుంది.
పరిష్కారం: ID అయితే #my-btn, క్లాస్ అయితే .my-btn అని ఖచ్చితంగా ఇవ్వాలి.

4. యూజర్ ఇన్‌పుట్ కి innerHTML వాడటం (XSS భద్రతా లోపం):

యూజర్ టైప్ చేసిన పేరును నేరుగా box.innerHTML = userInput అని పెడితే హ్యాకర్లు స్క్రిప్ట్ ఇంజెక్ట్ చేయగలరు. ఎల్లప్పుడూ box.textContent = userInput వాడాలి.

5. CSS స్టైల్స్ లో హైఫన్ వాడటం:

box.style.font-size = "20px"; // ❌ Syntax Error!
పరిష్కారం: CamelCase వాడాలి: box.style.fontSize = "20px"; // ✅

9Real-World Try-It: Interactive Profile Card Customizer

వెబ్‌సైట్‌లలో డైనమిక్ యూజర్ ప్రొఫైల్ కార్డును అప్‌డేట్ చేసే ఒక పూర్తి స్థాయి DOM మేనిప్యులేషన్ స్క్రిప్ట్ ఇది. బటన్ క్లిక్ చేసినప్పుడు ప్రొఫైల్ నేమ్ మార్చడం, ప్రీమియం బ్యాడ్జ్ జోడించడం, మరియు వ్యూ కౌంటర్ పెంచే లాజిక్‌ను ఇది ప్రదర్శిస్తుంది:

🚀 మీరే స్వయంగా Try చేయండి! (Live Profile Customizer Logic)

ఈ DOM ఫంక్షన్‌ను మన ఆన్‌లైన్ కంపైలర్ లో రన్ చేసి స్వయంగా పరిశీలించండి:

// ఒక వెబ్ అప్లికేషన్‌లో యూజర్ కార్డును డైనమిక్‌గా మార్చే ఫంక్షన్
function upgradeUserProfile(userConfig) {
  // ఊహాత్మక DOM ఎలిమెంట్స్ ఆబ్జెక్ట్
  const mockDOM = {
    title: { textContent: "Guest User", style: {} },
    card: { classList: new Set(["base-card"]), style: {} },
    badgesContainer: { children: [] }
  };

  // 1. టైటిల్ & టెక్స్ట్ సురక్షితంగా మార్చడం
  mockDOM.title.textContent = userConfig.name;

  // 2. ప్రీమియం థీమ్ వర్తింపజేయడం (CSS inline styles)
  if (userConfig.isPremium) {
    mockDOM.card.style.borderColor = "#10b981";
    mockDOM.card.style.boxShadow = "0 8px 24px rgba(16, 185, 129, 0.2)";
    mockDOM.card.classList.add("premium-tier");
  }

  // 3. కొత్త బ్యాడ్జ్ ఎలిమెంట్ ని సృష్టించి జోడించడం
  const badge = {
    tag: "span",
    textContent: userConfig.badgeText || "PRO Member",
    className: "badge-pro"
  };
  mockDOM.badgesContainer.children.push(badge);

  return {
    displayName: mockDOM.title.textContent,
    activeClasses: Array.from(mockDOM.card.classList).join(" "),
    borderHighlight: mockDOM.card.style.borderColor,
    totalBadges: mockDOM.badgesContainer.children.length
  };
}

const result = upgradeUserProfile({

console.log("మొత్తం బ్యాడ్జ్‌లు:", result.totalBadges);

10ఆలోచింపజేసే ప్రాక్టీస్ ప్రశ్నలు & సమాధానాలు

ఈ క్రింది ప్రశ్నలకు స్వయంగా ఆలోచించి సమాధానం చెప్పడానికి ప్రయత్నించండి, ఆపై డ్రాప్‌డౌన్ తెరిచి వివరణను సరిచూసుకోండి:

  1. querySelector మరియు querySelectorAll మధ్య ప్రధాన వ్యత్యాసం ఏమిటి?
  2. యూజర్ కామెంట్స్‌ను స్క్రీన్ పై ప్రదర్శించేటప్పుడు innerHTML కంటే textContent ఎందుకు సురక్షితమైనది?
  3. ఒక బటన్ క్లిక్ చేసినప్పుడు క్లాస్ ఉంటే తీసేయడానికి, లేకపోతే పెట్టడానికి ఏ classList మెథడ్ వాడతారు?
  4. జావాస్క్రిప్ట్ ద్వారా ఒక ఎలిమెంట్ యొక్క font-size ని మార్చడానికి సరైన కోడ్ ఏమిటి?
  5. పేజీలో ఉన్న అన్ని <button> ఎలిమెంట్స్ యొక్క బ్యాక్‌గ్రౌండ్ కలర్ మార్చడానికి లూప్ ఎందుకు అవసరం?
  6. డైనమిక్‌గా ఒక కొత్త HTML ఎలిమెంట్‌ను మెమరీలో సృష్టించే బిల్ట్-ఇన్ మెథడ్ ఏది?
👉 సమాధానాలు మరియు వివరణలు చూడండి (Click to Expand)

1. సమాధానం: querySelector సరిపోలిన మొట్టమొదటి ఎలిమెంట్‌ను మాత్రమే ఇస్తుంది (సింగిల్ ఎలిమెంట్). querySelectorAll సరిపోలిన అన్ని ఎలిమెంట్లను NodeList రూపంలో కలెక్షన్‌గా ఇస్తుంది.

2. సమాధానం: textContent టెక్స్ట్ లోపల ఉన్న ఏ కోడ్‌ను రెండర్ చేయదు (సాదా అక్షరాలుగానే ఉంచుతుంది). దీనివల్ల హ్యాకర్లు ప్రమాదకరమైన <script> ట్యాగ్స్ ఇంజెక్ట్ చేసే XSS (Cross-Site Scripting) దాడి జరగకుండా కాపాడుతుంది.

3. సమాధానం: element.classList.toggle("className"). ఇది స్విచ్ లాగా పనిచేసి క్లాస్ ఉంటే తీసేస్తుంది, లేకపోతే జోడిస్తుంది.

4. సమాధానం: element.style.fontSize = "16px"; (హైఫన్ లేకుండా CamelCase వాడాలి మరియు యూనిట్స్ 'px' ఖచ్చితంగా పేర్కొనాలి).

5. సమాధానం: querySelectorAll("button") రిటర్న్ చేసేది ఒకే ఎలిమెంట్ కాదు, ఎలిమెంట్ల సమాహారం (NodeList). ఒక లిస్ట్ పై నేరుగా style ప్రాపర్టీ ఉండదు, కాబట్టి ప్రతి బటన్‌ను విడివిడిగా తాకడానికి buttons.forEach(btn => btn.style.backgroundColor = 'blue') వాడాలి.

6. సమాధానం: document.createElement("tagName") (ఉదా: document.createElement("div")).

📌 సారాంశం (Quick Summary):

  • DOM: HTML డాక్యుమెంట్‌ను బ్రౌజర్ నిర్మించే ఆబ్జెక్టుల వృక్ష నిర్మాణం.
  • ఎలిమెంట్స్ ఎంపిక: సింగిల్ ఎలిమెంట్ కోసం querySelector('#id' లేదా '.class'), గ్రూప్ కోసం querySelectorAll() వాడాలి.
  • కంటెంట్ మేనిప్యులేషన్: టెక్స్ట్ కోసం ఎల్లప్పుడూ textContent వాడండి. HTML ట్యాగ్స్ నిర్మించాల్సి వస్తేనే జాగ్రత్తగా innerHTML వాడండి.
  • క్లాస్ నిర్వహణ: క్లాస్‌లను జోడించడానికి, తీసివేయడానికి, టోగుల్ చేయడానికి element.classList అత్యంత శక్తివంతమైనది.
  • స్టైలింగ్: element.style.camelCaseProperty రూపంలో రాయాలి.
  • డైనమిక్ సృష్టి: document.createElement() తో సృష్టించి, appendChild() తో అతికించాలి.
