Browser Events, Forms & Event Delegation (The Complete Masterclass)

🟨 JavaScript (ES2026+) 🟢 Lesson 15 📂 Phase 12: Events & Forms 📅 2026 Edition
📌 Covered in this lesson: addEventListener · Click, Mouse & Keyboard · Input vs Change · Submit & preventDefault() · Bubbling & Delegation · Form Validation · 6 Complete Projects

వెబ్‌సైట్ లో యూజర్ జరిపే చర్యలపై (User Actions — బటన్ క్లిక్ చేయడం, కీబోర్డ్ టైప్ చేయడం, ఫారం సబ్మిట్ చేయడం) స్పందించడానికి Events & Event Listeners వాడతాం. ఈ చాప్టర్ లో addEventListener, Event Object (e.target), ఫారమ్స్ సబ్మిషన్ మరియు preventDefault() ల గురించి స్పష్టంగా నేర్చుకుందాం!

🔔 రియల్ లైఫ్ అనలాజీ: ఇంటి కాలింగ్ బెల్ (Calling Bell)

మీ ఇంటి ముందు ఒక కాలింగ్ బెల్ ఉంది:

  • Event (చర్య): విజిటర్ బెల్ బటన్ ప్రెస్ చేయడం (Click Event).
  • Event Listener (చెవి రంధ్రం): బెల్ శబ్దం కోసం ఎదురుచూడటం.
  • Event Handler (స్పందన): బెల్ మోగగానే మీరు వెళ్ళి తలుపు తీయడం (Callback Function).
1addEventListener Syntax & Common Events

ఎలిమెంట్ కి ఈవెంట్ ని లింక్ చేయడానికి addEventListener("event", callback) వాడతాం:

Event Nameఎప్పుడు జరుగుతుంది (Trigger)ఉదాహరణ వాడకం
clickయూజర్ ఎలిమెంట్ పై క్లిక్ చేసినప్పుడుబటన్ క్లిక్, లింక్ క్లిక్
submitఫారమ్ ని సబ్మిట్ చేసినప్పుడుLogin / Register Forms
inputఇన్ పుట్ ఫీల్డ్ లో టైప్ చేస్తున్న ప్రతిసారీSearch suggestions, Live character count
changeDropdown లేదా Radio లో వాల్యూ మారినప్పుడుSelect country dropdown
keydownకీబోర్డ్ లో కీ నొక్కినప్పుడుEnter ప్రెస్ చేసి మెసేజ్ పంపడం
2Event Object & Form Handling (e.preventDefault)

ఫారమ్ సబ్మిట్ చేసినప్పుడు బ్రౌజర్ పేజీ రిఫ్రెష్ అయిపోతుంది. దాన్ని అడ్డుకోవడానికి e.preventDefault() వాడతాం.

JavaScript — Event Listener & Form Submit 
// HTML Elements: <form id="loginForm">, <input id="username">

let form = document.querySelector("#loginForm");
let usernameInput = document.querySelector("#username");

form.addEventListener("submit", function(e) {
    // 1. పేజీ రిఫ్రెష్ అవ్వకుండా అడ్డుకోవడం
    e.preventDefault();

    // 2. యూజర్ ఎంటర్ చేసిన టెక్స్ట్ ని పొందడం
    let name = usernameInput.value.trim();

    if (name === "") {
        alert("దయచేసి పేరు ఎంటర్ చేయండి!");
    } else {
        alert("నమస్తే " + name + "! Login successful 🎉");
    }
});
⚠️ ప్రాక్టీస్ లో వచ్చే పొరపాట్లు (Common Mistakes)
  • addEventListener("click", handleClick()) అని ఫంక్షన్ పక్కన Parentheses () పెడితే పేజీ లోడ్ కాగానే ఫంక్షన్ రన్ అయిపోతుంది! కేవలం ఫంక్షన్ పేరు మాత్రమే ఇవ్వాలి: addEventListener("click", handleClick).
  • Form లో సబ్మిట్ ఈవెంట్ కి e.preventDefault() రాయడం మర్చిపోతే డేటా పోయి పేజీ రిఫ్రెష్ అయిపోతుంది.
3Practice Questions & Answers
Q1. e.target అంటే ఏమిటి?

రిజల్ట్: e.target అనేది ఈవెంట్ జరిగిన నిర్దిష్టమైన HTML ఎలిమెంట్ ని సూచిస్తుంది. (Ex: e.target.value ద్వారా ఇన్ పుట్ లో ఉన్న టెక్స్ట్ ని పొందవచ్చు).

Q2. input ఈవెంట్ కి change ఈవెంట్ కి తేడా ఏంటి?

రిజల్ట్: input ప్రతి అక్షరం టైప్ చేయగానే వెంటనే ఫైర్ అవుతుంది. change యూజర్ టైపింగ్ పూర్తి చేసి బాక్స్ బయట క్లిక్ చేసినప్పుడు (Blur అయినప్పుడు) మాత్రమే ఫైర్ అవుతుంది.

📌 Quick Summary:

  • చర్యలపై స్పందించడానికి addEventListener() వాడండి.
  • ఫారమ్ రిఫ్రెష్ ని అడ్డుకోవడానికి e.preventDefault() వాడండి.
  • ఈవెంట్ సమాచారం కోసం Event Object (e) ని వాడండి.
