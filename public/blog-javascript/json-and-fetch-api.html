JSON, Fetch API & REST Integration (The Complete Masterclass)

🟨 JavaScript (ES2026+) 🟢 Lesson 17 📂 Phase 14: JSON & Fetch API 📅 2026 Edition
📌 Covered in this lesson: JSON.stringify & parse · HTTP GET/POST/PUT/DELETE · Headers & Body · response.ok & Status · Loading States · Auth & Tokens · 5 Projects

సర్వర్ ల నుండి డేటాను పొందడానికి (Fetch Data from External APIs) మరియు క్లయింట్-సర్వర్ మధ్య డేటాని మార్పిడి చేసుకోవడానికి JSON (JavaScript Object Notation) మరియు Fetch API వాడతాం. వాతావరణ సమాచారం (Weather Data), బ్యాంక్ వివరాలు, లేదా ఇ-కామర్స్ ప్రొడక్ట్స్ డిస్ప్లే చేయడానికి ఇవే కీలకం! ఈ చాప్టర్ లో JSON Rules, HTTP Methods, Fetch API, మరియు async/await లతో API Integration క్లియర్ గా నేర్చుకుందాం!

🍽️ రియల్ లైఫ్ అనలాజీ: హోటల్ వెయిటర్ (Hotel Waiter & Kitchen)

మీరు ఒక రెస్టారెంట్ కి వెళ్ళారు:

  • Client (మీరు): ఆర్డర్ ఇవ్వాలనుకుంటున్న యూజర్ / బ్రౌజర్.
  • Server (కిచెన్): ఆహారం (డేటా) సిద్ధంగా ఉన్న సర్వర్.
  • API (వెయిటర్): మీ ఆర్డర్ ని కిచెన్ కి తీసుకెళ్ళి, తయారైన వంటకాన్ని (JSON Response) మీ టేబుల్ కి తెచ్చిచ్చే మధ్యవర్తి!
1JSON Rules & Parsing Methods

JSON అనేది లైట్-వెయిట్ డేటా ఫార్మాట్. ఇందులో Keys ని విధిగా Double Quotes "key" లోనే రాయాలి.

JSON Functionపని (Purpose)ఉదాహరణ (Example)
JSON.stringify(obj)JavaScript Object ని JSON Text String గా మారుస్తుందిJSON.stringify({ a: 1 }) -> '{"a":1}'
JSON.parse(jsonStr)JSON Text String ని తిరిగి JavaScript Object గా మారుస్తుందిJSON.parse('{"a":1}') -> { a: 1 }
2Fetching API Data with async/await

ఆధునిక JavaScript లో API నుండి డేటా తెచ్చుకోవడానికి fetch() తో పాటు async/await వాడతాం:

JavaScript — Fetch API Integration ▶ Run Code 
// 1. API నుండి డేటా తెచ్చే అసింక్ ఫంక్షన్
async function fetchUserData() {
    try {
        console.log("⏳ Loading User Data...");
        let response = await fetch("https://jsonplaceholder.typicode.com/users/1");
        
        // HTTP సంకేతం సరిగ్గా ఉందో లేదో తనిఖీ చేయడం
        if (!response.ok) {
            throw new Error("HTTP Error Status: " + response.status);
        }

        let user = await response.json(); // JSON ని Object గా మార్చడం
        console.log("✅ User Loaded:", user.name);
        console.log("📧 Email:", user.email);
        console.log("🏙️ City:", user.address.city);
    } catch (error) {
        console.log("❌ Error Fetching Data:", error.message);
    }
}

fetchUserData();
⚠️ ప్రాక్టీస్ లో వచ్చే పొరపాట్లు (Common Mistakes)
  • response.json() కి ముందు await రాయడం మర్చిపోవడం. let data = response.json(); అని రాస్తే అది డేటా కి బదులు ఒక తులసి ప్లాంట్ లాంటి విఫలమైన Promise ని ఇస్తుంది. await response.json() అని రాయాలి.
  • fetch() కి HTTP 404 (Not Found) లేదా 500 (Server Error) వచ్చినా నాచురల్ గా Promise Reject అవ్వదు! response.ok === false ని మ్యాన్యువల్ గా చెక్ చేయాలి.
3Practice Questions & Answers
Q1. HTTP GET మరియు POST ల తేడా ఏమిటి?

రిజల్ట్: GET సర్వర్ నుండి డేటాను చదవడానికి (Read Data) వాడతాం. POST కొత్త డేటాను సర్వర్ కి పంపడానికి (Create Data) వాడతాం.

Q2. JSON.parse() లో చెల్లని JSON ఇస్తే ఏమవుతుంది?

రిజల్ట్: SyntaxError వస్తుంది. కాబట్టి JSON.parse() ని ఎప్పుడూ try...catch లోపల వాడటం మంచిది.

📌 Quick Summary:

  • డేటా మార్పిడికి JSON వాడతాం (stringify / parse).
  • API Requests కోసం fetch() తో async/await వాడండి.
  • Errors ని క్యాచ్ చేయడానికి try...catch ఉపయోగించండి.
