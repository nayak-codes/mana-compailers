JavaScript Syntax & Errors | కోడ్ ఎలా రాయాలి (Telugu)

🟨 JavaScript (ES2026+) 🟢 Lesson 2 📂 Phase 01: JavaScript Fundamentals 📅 2026 Edition
📌 Covered in this lesson: Comments (Single & Multi-line) · Statements · Semicolons & ASI · Case Sensitivity · Syntax Errors · Runtime Errors · Logical Errors

పోయిన chapter లో మనం మన మొదటి program రాసాం కదా? ఈ chapter లో JavaScript రాసేటప్పుడు పాటించాల్సిన కొన్ని ముఖ్యమైన నియమాలు (Grammar rules) నేర్చుకుందాం. ఇంగ్లీష్ కి grammar ఎలానో, programming కి Syntax అలా అన్నమాట.

అలాగే మనం తప్పులు చేసినప్పుడు కంప్యూటర్ ఎలా అరుస్తుందో (Errors) కూడా చూద్దాం. భయపడకండి, తప్పులు చేయడం వల్లే బాగా నేర్చుకుంటారు!

1ఈ chapter లో మీరు నేర్చుకునేవి
  • Comments అంటే ఏమిటి, ఎందుకు వాడతారు
  • Statements మరియు Semicolon ; ప్రాముఖ్యత
  • Automatic Semicolon Insertion (ASI) అంటే ఏంటి
  • Case Sensitivity అంటే ఏమిటి
  • Errors లోని మూడు రకాలు (Syntax, Runtime, Logical)
2Comments (కామెంట్స్) అంటే ఏమిటి?

మనం రాసిన code ఏమి చేస్తుందో రేపు మనకు కానీ, వేరేవాళ్లకు కానీ అర్థం కావడానికి రాసుకునే నోట్స్ నే Comments అంటారు.

కంప్యూటర్ ఈ కామెంట్స్ ని పూర్తిగా వదిలేస్తుంది, వాటిని run చేయదు. కేవలం మనుషులు చదువుకోవడానికే ఇవి ఉంటాయి.

JavaScript లో 2 రకాల కామెంట్స్ ఉన్నాయి:

  1. Single-line comment: ఇది // తో మొదలవుతుంది.
  2. Multi-line comment: ఇది /* తో మొదలై */ తో ముగుస్తుంది.
JavaScript ▶ Run Code 
// ఇది Single-line comment. కింది లైన్ లో పేరు print చేస్తున్నాను
console.log("రాము"); 

/* 
ఇది Multi-line comment.
ఇందులో మీరు ఎన్ని లైన్స్ అయినా రాయొచ్చు.
కంప్యూటర్ దీన్ని అస్సలు పట్టించుకోదు.
*/
console.log("హైదరాబాద్");
3Statements మరియు Semicolons (;)

కంప్యూటర్ కి మనం ఇచ్చే ఒక పూర్తి ఆదేశాన్ని (Instruction) Statement అంటారు. ఇంగ్లీష్ లో ఒక వాక్యం పూర్తవ్వగానే Full stop (.) ఎలా పెడతామో, JavaScript లో ఒక statement పూర్తవ్వగానే Semicolon (;) పెడతాం.

JavaScript 
console.log("Hello"); // ఇది ఒక statement
console.log("World"); // ఇది ఇంకొక statement

అదే ఒకవేళ మీరు రెండు statements ని ఒకే లైన్ లో రాయాలంటే, కచ్చితంగా మధ్యలో ; పెట్టాలి. లేకపోతే error వస్తుంది.

console.log("Hello"); console.log("World"); // సరైనది
4Automatic Semicolon Insertion (ASI)

కొన్నిసార్లు మనం కంగారులో చివరన సెమికోలన్ ; పెట్టడం మర్చిపోతాం. అయినా మన program పని చేస్తుంది! ఎందుకంటే జావాస్క్రిప్ట్ ఇంజిన్ చాలా మంచిది. మీరు సెమికోలన్ పెట్టకపోతే, అది అర్థం చేసుకుని తనంతట తానే ఒక సెమికోలన్ ని ఊహించుకుంటుంది. దీనినే Automatic Semicolon Insertion (ASI) అంటారు.

కానీ, ఎప్పుడూ ASI మీద ఆధారపడకండి. అది కొన్నిసార్లు తప్పుగా ఊహించుకుని ఊహించని errors కి దారి తీస్తుంది. కాబట్టి ప్రతీ statement చివర ; పెట్టడం ఒక మంచి అలవాటుగా చేసుకోండి.

5Case Sensitivity (చిన్న అక్షరాలు - పెద్ద అక్షరాలు)

JavaScript కి Case Sensitivity ఉంటుంది. అంటే దానికి A వేరు, a వేరు. రెండు ఒకటే కాదు.

JavaScript 
let Name = "Ravi";
let name = "Teja";
let NAME = "Kiran";

పైన రాసిన మూడు వేర్వేరు variables! కాబట్టి మీరు console.log ని Console.log అని రాస్తే పని చేయదు.

6Errors (తప్పులు) లో 3 రకాలు

Program రాసేటప్పుడు errors రావడం చాలా సహజం. పెద్ద పెద్ద programmers కి కూడా రోజుకి వందల errors వస్తాయి. Errors లో ముఖ్యంగా 3 రకాలు ఉంటాయి.

Error రకంవివరణరియల్ లైఫ్ ఉదాహరణ
1. Syntax Error JavaScript grammar రూల్స్ పాటించకపోతే వస్తుంది. Program అసలు run అవ్వదు. తెలుగులో "నేను అన్నం తిన్నాను" కి బదులు "అన్నం నేను తిన్నాను" అని రాయడం.
2. Runtime Error Syntax కరెక్టే కానీ, run అవుతున్నప్పుడు లేని దాన్ని అడిగితే వస్తుంది. హోటల్ కి వెళ్లి మెనూలో లేని వంటకం తీసుకురమ్మని అడగటం.
3. Logical Error ఎలాంటి error మెసేజ్ రాదు. కానీ మీకు కావాల్సిన output రాదు. ఇది పట్టుకోవడం చాలా కష్టం. టీ పెట్టబోయి అందులో పంచదారకి బదులు ఉప్పు వేయడం! అంతా బాగానే జరిగింది కానీ తాగితే తెలుస్తుంది తప్పు జరిగిందని.

ఉదాహరణలు చూద్దాం:

JavaScript — Errors 
// 1. Syntax Error: బ్రాకెట్ మూసివేయలేదు
console.log("Hello" ; 

// 2. Runtime Error: console.log స్పెల్లింగ్ తప్పు రాసాం
consol.log("Hello"); 

// 3. Logical Error: కూడిక చేయబోయి తీసివేత చేశాం
console.log("5 + 5 = " + (5 - 5)); // Output: 5 + 5 = 0 అని వస్తుంది!

8ప్రాక్టీస్ ప్రశ్నలు
  1. ఈ కోడ్ లో తప్పు ఏమిటో కనుక్కోండి: Console.log("Hello");
  2. Automatic Semicolon Insertion (ASI) అంటే ఏమిటి?
  3. మీకు బాగా ఇష్టమైన సినిమా పేరును print చేయండి, ఆ లైన్ పైన అదెందుకు ఇష్టమో ఒక కామెంట్ రాయండి.
  4. Syntax error కి Logical error కి ఉన్న ముఖ్యమైన తేడా ఏమిటి?

9సారాంశం (Quick Summary)
  • కోడ్ ని అర్థం చేసుకోవడానికి Comments వాడతాం (// లేదా /* */).
  • ఒక ఇన్స్ట్రక్షన్ ని Statement అంటారు, ఇది సెమికోలన్ ; తో ముగుస్తుంది.
  • మనం మర్చిపోతే జావాస్క్రిప్ట్ ఇంజిన్ దానంతట అదే పెట్టుకునేదే ASI.
  • JavaScript కి పెద్ద అక్షరాలు చిన్న అక్షరాలు (Case Sensitivity) అంటే పట్టింపు ఎక్కువ.
  • Errors లో 3 రకాలు: Syntax, Runtime, Logical.
