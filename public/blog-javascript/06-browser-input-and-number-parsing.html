JavaScript Type Conversion తెలుగులో | Number(), parseInt(), Template Literals

🟨 JavaScript (ES2026+) 🟢 Lesson 6 📂 Phase 03: Operators & Input 📅 2026 Edition
📌 Covered in this lesson: Implicit vs Explicit · Number() · parseInt() · parseFloat() · String() · Boolean() · Truthy & Falsy · Template Literals (Backticks)

కరెంట్ ప్లగ్ లో మన ఫోన్ ఛార్జర్ పెట్టాలంటే, కొన్నిసార్లు అడాప్టర్ కావాలి కదా? ఒక రకం ప్లగ్ ని ఇంకో రకం సాకెట్ కి సరిపోయేలా మార్చడమే అడాప్టర్ పని. Programming లో కూడా ఒక data type ని ఇంకో data type గా మార్చాల్సిన సందర్భాలు చాలా వస్తాయి. దీన్నే Type Conversion అంటారు.

గత chapters లో "5" + 3 ఫలితం "53" అవ్వడం చూశాం. ఇలాంటి గందరగోళాలు రాకుండా, విలువలను సరైన type కి ఎలా మార్చాలో ఈ chapter లో నేర్చుకుందాం. తర్వాత, text ని అందంగా, సులభంగా రాయడానికి Template Literals కూడా చూద్దాం.

1ఈ chapter లో మీరు నేర్చుకునేవి
  • Implicit మరియు Explicit type conversion అంటే ఏమిటి
  • Number(), parseInt(), parseFloat(), String(), Boolean() ఎలా వాడాలి
  • Truthy మరియు Falsy విలువలు
  • Template literals (backticks) తో text రాయడం
  • Multi-line strings
2Type Conversion అంటే ఏమిటి?

ఒక విలువ యొక్క data type ని మార్చడమే type conversion. ఇది రెండు రకాలుగా జరుగుతుంది:

  1. Implicit conversion (అంతర్గత మార్పు): JavaScript తనంతట తాను, మనకు చెప్పకుండానే type మార్చేస్తుంది.
  2. Explicit conversion (స్పష్టమైన మార్పు): మనం ఉద్దేశపూర్వకంగా, function వాడి type మారుస్తాం.
31. Implicit Conversion (JavaScript తనంతట తానే మార్చేది)
JavaScript — Implicit Conversion ▶ Run Code 
console.log("5" + 2);
console.log("5" - 2);
console.log(true + 1);
Output:
52
3
2
  • "5" + 2 → + string తో వస్తే అతికిస్తుంది, కాబట్టి "52".
  • "5" - 2 → - కి అతికించడం అనే పని లేదు, కాబట్టి "5" ని సంఖ్యగా మార్చి లెక్కించింది: 3.
  • true + 1 → true ని 1 గా మార్చి కూడింది: 2.

ఈ ఆటోమేటిక్ మార్పులు ఎప్పుడు ఎలా జరుగుతాయో గుర్తుంచుకోవడం కష్టం, పైగా పొరపాట్లకు దారి తీస్తాయి. అందుకే మనమే స్పష్టంగా (explicitly) మార్చడం మంచి అలవాటు.

42. Explicit Conversion: మనమే మార్చడం

Number(): ఏదైనా విలువను number గా మార్చడం

console.log(Number("42"));
console.log(Number("3.14"));
console.log(Number("abc"));
console.log(Number(true));
console.log(Number(false));
Output:
42
3.14
NaN
1
0
  • "42" మరియు "3.14" సరైన సంఖ్యల్లా ఉన్నాయి కాబట్టి మారాయి.
  • "abc" ని సంఖ్యగా మార్చలేం కాబట్టి NaN వచ్చింది.
  • true → 1, false → 0.

మరికొన్ని ఉదాహరణలు:

console.log(Number(" 12 "));
console.log(Number(""));
console.log(Number("12px"));
console.log(Number(null));
console.log(Number(undefined));
Output:
12
0
NaN
0
NaN
  • రెండు వైపులా ఉన్న ఖాళీలు (spaces) ని పట్టించుకోదు: 12.
  • ఖాళీ string "" → 0 వస్తుంది. ఇది జాగ్రత్తగా గమనించాల్సిన విషయం.
  • "12px" లో అక్షరాలు ఉన్నాయి కాబట్టి NaN.

ఉదాహరణ: రెండు సంఖ్యలను కూడటం

Website లో user టైప్ చేసే ప్రతిదీ string గా వస్తుంది. అది సంఖ్యలా కనిపించినా. అందుకే లెక్కలు చేసే ముందు మార్చాలి.

const input1 = "25";
const input2 = "15";

console.log(input1 + input2);
console.log(Number(input1) + Number(input2));
Output:
2515
40

మార్చకపోతే "2515" వచ్చింది (అతికింపు), మార్చాక సరైన కూడిక 40 వచ్చింది.

💡 చిట్కా:

string ముందు + పెట్టడం కూడా ఒక చిన్న మార్గం: +"25" అంటే 25. కానీ కొత్తవారికి Number() చదవడానికి సులభం.

parseInt() మరియు parseFloat(): string నుంచి సంఖ్యను తీయడం

parseInt() string ని ఎడమ నుంచి కుడికి చదివి, పూర్ణ సంఖ్య (integer) ని తీసుకుంటుంది. అక్షరం కనిపించగానే ఆగిపోతుంది.

console.log(parseInt("42px"));
console.log(parseInt("3.99"));
console.log(parseInt("abc"));
console.log(parseInt("px42"));
Output:
42
3
NaN
NaN
  • "42px" → 42 (p దగ్గర ఆగింది).
  • "3.99" → 3 (దశాంశం తీసేసింది, round చేయదు, కేవలం కత్తిరిస్తుంది).
  • "px42" → మొదటి అక్షరమే సంఖ్య కాదు, కాబట్టి NaN.

parseFloat() దశాంశాలను కూడా తీసుకుంటుంది:

console.log(parseFloat("3.14abc"));
console.log(parseFloat("2.5"));
Output:
3.14
2.5

Number() మరియు parseInt() మధ్య తేడా

console.log(Number("42px"));
console.log(parseInt("42px"));
Output:
NaN
42
  • Number() కఠినంగా ఉంటుంది: మొత్తం string సరైన సంఖ్య అయితేనే మారుస్తుంది.
  • parseInt() / parseFloat() ఉదారంగా ఉంటాయి: ముందు ఉన్న సంఖ్య భాగాన్ని తీసుకుంటాయి.

String(): ఏదైనా విలువను string గా మార్చడం

console.log(String(123));
console.log(String(true));
console.log(String(null));
console.log(String(undefined));
console.log(typeof String(123));

true
null

string

Screen మీద చూస్తే 123 అలాగే కనిపిస్తుంది, కానీ typeof చూస్తే string అని వస్తుంది.

Boolean(): ఏదైనా విలువను true/false గా మార్చడం

console.log(Boolean(1));
console.log(Boolean(0));
console.log(Boolean("hello"));
console.log(Boolean(""));
Output:
true
false
true
false

ఏ విలువ true గా, ఏది false గా మారుతుందో తెలుసుకోవడమే తర్వాతి భాగం.

5Truthy మరియు Falsy విలువలు

JavaScript లో ప్రతి విలువ ని boolean గా చూస్తే, అది true లేదా false గా పరిగణించబడుతుంది.

  • Truthy: boolean గా మారినప్పుడు true అయ్యే విలువలు.
  • Falsy: boolean గా మారినప్పుడు false అయ్యే విలువలు.

Falsy విలువలు (ఇవి కేవలం 6 మాత్రమే గుర్తుంచుకోండి)

Falsy విలువవివరణ
falseboolean false
0సున్నా
""ఖాళీ string
nullఉద్దేశపూర్వకంగా ఖాళీ
undefinedవిలువ ఇవ్వలేదు
NaNNot a Number

(మరో రెండు అరుదైనవి ఉన్నాయి: -0 మరియు 0n. వాటిని ఇప్పుడు పట్టించుకోవక్కర్లేదు.)

ఇవి తప్ప మిగతావన్నీ Truthy! ఇది చాలా సులభమైన నియమం.

console.log(Boolean(0));
console.log(Boolean(""));
console.log(Boolean(null));
console.log(Boolean(undefined));
console.log(Boolean(NaN));
Output:
false
false
false
false
false

ఇప్పుడు ఆశ్చర్యపరిచే truthy విలువలు చూడండి:

console.log(Boolean("0"));
console.log(Boolean("false"));
console.log(Boolean(" "));
console.log(Boolean(-1));
console.log(Boolean("hello"));
Output:
true
true
true
true
true
  • "0" అనేది సున్నా కాదు, అది 0 అనే అక్షరం ఉన్న string, కాబట్టి truthy.
  • "false" అనేది కేవలం text, boolean false కాదు. అందుకే truthy. (Chapter 4 లో మనం చెప్పిన bug ఇదే!)
  • " " (ఒక space ఉన్న string) ఖాళీ string కాదు కాబట్టి truthy.
  • -1 సున్నా కాదు, కాబట్టి truthy.

(ఖాళీ array [] మరియు ఖాళీ object {} కూడా truthy. Arrays, objects ని తర్వాత chapters లో నేర్చుకుంటాం.)

Truthy/Falsy ఎందుకు ముఖ్యం?

Condition లో boolean ఆశించే చోట ఏ విలువ ఉన్నా, JavaScript దాన్ని truthy లేదా falsy గా చూస్తుంది.

const userName = "";
console.log(userName ? "పేరు ఉంది" : "పేరు ఖాళీగా ఉంది");

const city = "హైదరాబాద్";
console.log(city ? "ఊరు ఉంది" : "ఊరు ఖాళీగా ఉంది");
Output:
పేరు ఖాళీగా ఉంది
ఊరు ఉంది

Form లో user ఏదైనా టైప్ చేశాడా లేదా అని చెక్ చేయడానికి ఈ పద్ధతి చాలా ఉపయోగపడుతుంది.

!! ట్రిక్

ఏ విలువనైనా నేరుగా true/false గా మార్చడానికి !! (double not) వాడతారు:

console.log(!!"hello");
console.log(!!0);
Output:
true
false

Boolean() తో సమానమైన ఫలితం. ఇది code లో కనిపిస్తే భయపడకండి, అర్థం ఇదే.

పోలిక పట్టిక: ఒకే విలువ, మూడు రకాల మార్పులు

6Template Literals: text ని సులభంగా రాయడం

ఇప్పటివరకు variables తో text ని కలపాలంటే + వాడాం. ఉదాహరణకు:

const name = "రవి";
const age = 20;

console.log("నా పేరు " + name + ", నా వయసు " + age);
Output:
నా పేరు రవి, నా వయసు 20

పని చేస్తుంది, కానీ quotes, + గుర్తులు, ఖాళీలు, అన్నీ చూసుకోవడం కష్టం. పెద్ద వాక్యాల్లో పొరపాట్లు తప్పవు. దీనికి సులభమైన మార్గమే Template Literals.

Backticks మరియు ${}

Template literal ని " " బదులు backticks ` ` తో రాస్తాం. (Keyboard లో 1 పక్కన, Tab పైన ఉన్న key.) లోపల variable విలువ చేర్చాలంటే ${variableName} అని రాస్తాం.

const name = "రవి";
const age = 20;

console.log(`నా పేరు ${name}, నా వయసు ${age}`);
Output:
నా పేరు రవి, నా వయసు 20

ఫలితం ఒకటే, కానీ ఎంత శుభ్రంగా, చదవడానికి సులభంగా ఉందో చూడండి! + మరియు quotes గందరగోళం లేదు.

${} లోపల expressions కూడా రాయొచ్చు

${ } లోపల కేవలం variable పేరు మాత్రమే కాదు, లెక్కలు, పోలికలు, ternary కూడా రాయొచ్చు.

const price = 250;
const quantity = 3;
const marks = 60;

console.log(`2 + 3 = ${2 + 3}`);
console.log(`మొత్తం బిల్లు: ₹${price * quantity}`);
console.log(`ఫలితం: ${marks >= 35 ? "Pass" : "Fail"}`);
Output:
2 + 3 = 5
మొత్తం బిల్లు: ₹750
ఫలితం: Pass

Multi-line strings (ఎక్కువ లైన్ల text)

పాత పద్ధతిలో ఎక్కువ లైన్లు కావాలంటే \n (కొత్త లైన్ గుర్తు) వాడాలి:

console.log("మొదటి లైన్\nరెండో లైన్");
Output:
మొదటి లైన్
రెండో లైన్

Template literal తో, Enter నొక్కి కొత్త లైన్ లో రాస్తే చాలు:

const message = `నమస్కారం,
ఇది రెండో లైన్,
ఇది మూడో లైన్`;

console.log(message);
Output:
నమస్కారం,
ఇది రెండో లైన్,
ఇది మూడో లైన్

ఉదాహరణ: విద్యార్థి Report

const studentName = "సీత";
const maths = 80;
const science = 70;
const english = 90;

const total = maths + science + english;
const average = total / 3;

console.log(`విద్యార్థి: ${studentName}
Maths: ${maths}
Science: ${science}
English: ${english}
మొత్తం: ${total}
సగటు: ${average}
ఫలితం: ${average >= 35 ? "Pass" : "Fail"}`);
Output:
విద్యార్థి: సీత
Maths: 80
Science: 70
English: 90
మొత్తం: 240
సగటు: 80
ఫలితం: Pass

ఒకే template లో variables, లెక్కలు, ternary, multi-line అన్నీ కలిపి వాడాం. ఇదే Template Literals శక్తి.

⚠️ Beginners చేసే సాధారణ తప్పులు
  • 1. లెక్కలకు ముందు string ని number గా మార్చకపోవడం: 
    console.log("10" + 5);         // "105"
console.log(Number("10") + 5); // 15
  • 2. parseInt("abc") NaN ఇస్తుందని మర్చిపోవడం: 
    const value = parseInt("abc");
console.log(value);                // NaN
console.log(value + 10);           // NaN
console.log(Number.isNaN(value));  // true
    NaN తో ఏ లెక్క చేసినా NaN నే వస్తుంది. మార్చిన తర్వాత Number.isNaN() తో సరైన సంఖ్య వచ్చిందో లేదో చెక్ చేయండి. (value === NaN అని రాస్తే ఎప్పుడూ false వస్తుంది, Chapter 4 లో చూశాం.)
  • 3. ఖాళీ string Number("") తో 0 అవుతుందని మర్చిపోవడం: User ఏమీ టైప్ చేయకపోతే "" వస్తుంది. Number("") అది 0 గా మారుస్తుంది, NaN కాదు. కాబట్టి "user సంఖ్య ఇవ్వలేదు" అని గుర్తించడానికి ముందు, string ఖాళీనా కాదా అని చెక్ చేయాలి.
  • 4. parseInt దశాంశాన్ని round చేస్తుందనుకోవడం: 
    console.log(parseInt("3.99")); // 3
    ఇది 4 కాదు. కేవలం దశాంశ భాగాన్ని కత్తిరిస్తుంది.
  • 5. "0" మరియు "false" ని falsy అనుకోవడం: ఇవి రెండూ truthy. ఖాళీ కాని ఏ string అయినా truthy.
  • 6. Template literal లో backticks కి బదులు సాధారణ quotes వాడటం: 
    // తప్పు:
console.log("నా పేరు ${name}"); // Output: నా పేరు ${name}
    సాధారణ quotes లో ${} పని చేయదు, అది కేవలం text లాగే కనిపిస్తుంది. ${} వాడాలంటే backticks (`) తప్పనిసరి.
7ప్రాక్టీస్ ప్రశ్నలు & సమాధానాలు
  1. "100" మరియు "50" అనే రెండు strings ని number లుగా మార్చి కూడండి.
  2. ఈ ఫలితాలు ఏమిటి? Number("abc"), parseInt("25kg"), parseFloat("2.5m"), Number(true), String(99) + 1.
  3. కింది విలువలు Truthy నా Falsy నా చెప్పండి: 0, "hello", "", " ", null, "0", NaN, 5.
  4. name, city, age variables తీసుకుని, template literal తో "నా పేరు ..., నేను ... లో ఉంటాను, నా వయసు ..." అనే వాక్యం print చేయండి.
  5. ఈ code 30 print చేసేలా సరిచేయండి: let a = "10"; let b = "20"; console.log(a + b);

📌 Quick Summary (సారాంశం):

  • Type conversion అంటే ఒక data type ని ఇంకో దాని గా మార్చడం. Implicit (JavaScript తనంతట తానే) మరియు Explicit (మనమే) అని రెండు రకాలు.
  • Number() ఏదైనా విలువను number గా మారుస్తుంది. సరిపోకపోతే NaN.
  • parseInt() / parseFloat() string ముందు భాగంలో ఉన్న సంఖ్యను తీసుకుంటాయి.
  • String() ఏదైనా విలువను string గా, Boolean() true/false గా మారుస్తుంది.
  • 6 Falsy విలువలు: false, 0, "", null, undefined, NaN. మిగతావన్నీ Truthy ("0", "false", " " కూడా).
  • Template literals: backticks ` ` తో రాసి, ${} లో variables/expressions పెట్టొచ్చు. Multi-line text కూడా సులభంగా రాయొచ్చు.
  • User ఇచ్చే input ఎప్పుడూ string గా వస్తుంది. లెక్కలకు ముందు Number() తో మార్చండి.
