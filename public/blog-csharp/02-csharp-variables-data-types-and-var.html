వేరియబుల్స్, CTS డేటా టైప్స్ (Value vs Reference) & var

⚡ Modern C# 12 & .NET 8 🟢 Chapter 2 of 20 📂 Phase 01: C# ఫండమెంటల్స్ & బేసిక్స్ 📅 2026 Edition
📌 Covered in this chapter: Common Type System (CTS) · Stack (Value Types) vs Heap (Reference Types) · var టైప్ ఇన్ఫరెన్స్ · const & readonly తేడాలు
కంప్యూటర్ ప్రోగ్రామింగ్ అంటే వాస్తవానికి డేటాను మెమరీలో భద్రపరచడం, ప్రాసెస్ చేయడం మరియు తిరిగి ప్రదర్శించడమే. C# లో బలమైన Common Type System (CTS) ఉంది. మెమరీ నిర్వహణలో కీలకమైన Stack (Value Types) vs Heap (Reference Types) వ్యత్యాసం, var టైప్ ఇన్ఫరెన్స్, మరియు const vs readonly ల గురించి ఈ అధ్యాయంలో సమగ్రంగా తెలుసుకుందాం.
1Common Type System (CTS) — Value Types vs Reference Types

C# లోని ప్రతి డేటా రకం అంతర్గతంగా System.Object మూల క్లాస్ నుండి ఉద్భవిస్తుంది. అయితే కంప్యూటర్ మెమరీలో డేటా నిల్వ అయ్యే విధానాన్ని బట్టి C# డేటా టైప్స్‌ను రెండు ప్రధాన వర్గాలుగా విభజించింది:

📦 Value Types (స్టాక్ మెమరీ):

ఈ వేరియబుల్స్ తమ వాస్తవ డేటాను నేరుగా Stack Memory లోనే భద్రపరుస్తాయి. ఒక వేరియబుల్‌ను మరొకదానికి అసైన్ చేసినప్పుడు విలువ యొక్క పూర్తి నకలు (Copy of value) ఏర్పడుతుంది.

ఉదాహరణలు: int, float, double, decimal, bool, char, struct, enum.

🌐 Reference Types (హీప్ మెమరీ):

వాస్తవ డేటా Heap Memory లో ఉంటుంది. స్టాక్‌లో కేవలం ఆ హీప్ డేటా ఉన్న మెమరీ అడ్రస్ (Reference / Pointer) మాత్రమే నిల్వ ఉంటుంది. ఒకదానికి మరొకటి అసైన్ చేస్తే మెమరీ అడ్రస్ షేర్ అవుతుంది.

ఉదాహరణలు: string, object, class, array, interface, delegate.
2C# ఫండమెంటల్ డేటా టైప్స్ మ్యాట్రిక్స్

ఆధునిక .NET 8 లో అందుబాటులో ఉన్న ప్రైమరీ డేటా టైప్స్, వాటి మెమరీ పరిమాణాలు మరియు విలువల పరిధుల పట్టిక:

C# టైప్ .NET CTS టైప్ మెమరీ పరిమాణం విలువల పరిధి (Range)
byte System.Byte 1 Byte (8 bits) 0 నుండి 255
short System.Int16 2 Bytes (16 bits) -32,768 నుండి 32,767
int System.Int32 4 Bytes (32 bits) -2.14 బిలియన్లు నుండి +2.14 బిలియన్లు
long System.Int64 8 Bytes (64 bits) -9.22 × 1018 నుండి +9.22 × 1018
float System.Single 4 Bytes (32 bits) 6 - 9 దశాంశ అంకెల ఖచ్చితత్వం (ఉదా: 3.14f)
double System.Double 8 Bytes (64 bits) 15 - 17 దశాంశ అంకెలు (డీఫాల్ట్ దశాంశం)
decimal System.Decimal 16 Bytes (128 bits) 28 - 29 అంకెల గరిష్ట ఖచ్చితత్వం (కరెన్సీ/ఫైనాన్స్: 99.99m)
bool System.Boolean 1 Byte true లేదా false
char System.Char 2 Bytes (16 bits) ఒకే ఒక UTF-16 యూనికోడ్ క్యారెక్టర్ ('A')
3var టైప్ ఇన్ఫరెన్స్ (Type Inference)

C# లో var కీవర్డ్ ను చూసి చాలామంది బిగినర్స్ ఇది JavaScript లోని var లాంటి డైనమిక్ టైప్ అని పొరబడతారు. కానీ C# లో var అనేది ఖచ్చితమైన కంపైల్-టైమ్ స్టాటిక్ టైప్ ఇన్ఫరెన్స్.

C# — var keyword demo ⚡ Try in C# Compiler 
// కంపైలర్ కుడివైపు ఉన్న విలువను చూసి డేటా టైప్‌ను స్వయంగా నిర్ణయిస్తుంది
var age = 25;           // కంపైలర్ దీనిని 'int' గా స్థిరీకరిస్తుంది
var salary = 75000.50;  // కంపైలర్ దీనిని 'double' గా గుర్తిస్తుంది
var company = "Google"; // కంపైలర్ దీనిని 'string' గా లాక్ చేస్తుంది

// age = "ఇరవై ఐదు"; // ❌ Compiler Error! 'int' లోకి 'string' అసైన్ చేయలేం!
Console.WriteLine($"వయస్సు: {age}, సంస్థ: {company}");
4కాన్‌స్టాంట్స్: const vs readonly వ్యత్యాసాలు

మారకూడని స్థిర విలువలను నిర్వచించడానికి C# లో రెండు కీవర్డ్లు ఉన్నాయి:

1. const (Compile-Time Constant):

public const double PI = 3.14159;

డిక్లరేషన్ సమయంలోనే విలువ ఇవ్వాలి. కంపైలర్ ఎక్కడైతే PI ఉందో అక్కడ నేరుగా 3.14159 విలువను హార్డ్‌కోడ్ చేస్తుంది.

2. readonly (Run-Time Constant):

public readonly DateTime CreatedAt;

రన్‌టైమ్‌లో కన్‌స్ట్రక్టర్ లోపల డేటాబేస్ లేదా కాన్ఫిగరేషన్ నుండి విలువను అసైన్ చేసుకోవచ్చు. ఒక్కసారి అసైన్ అయ్యాక మారదు.

5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. ఫైనాన్స్ లేదా బ్యాంకింగ్ లెక్కలకు double వాడడం:
double balance = 0.1 + 0.2; // ఫలితం 0.30000000000000004 వస్తుంది! ఫ్లోటింగ్ పాయింట్ సంఖ్యలు బైనరీ బేస్-2 లో నిల్వ ఉండటం వల్ల దశాంశాల ఖచ్చితత్వం లోపిస్తుంది. డబ్బు లెక్కలకు ఎల్లప్పుడూ decimal మాత్రమే వాడాలి: decimal bal = 0.1m + 0.2m; // 0.3m.
❌ 2. var రాసి ఇనీషియలైజ్ చేయకపోవడం:
var total; // Compiler Error! Implicitly-typed variables must be initialized var వాడినప్పుడు కంపైలర్ టైప్‌ను గ్రహించడానికి కుడివైపు కచ్చితంగా ఒక ప్రారంభ విలువ ఉండాలి.
6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: C# లో string అనేది Value Type ఆ లేక Reference Type ఆ?

string అనేది ఖచ్చితంగా Reference Type! ఇది హీప్ మెమరీలోనే నిల్వ ఉంటుంది. అయితే పోలికలలో (str1 == str2) సులభంగా ఉండటానికి C# దీనికి వాల్యూ-టైప్ లాంటి ఇమ్యుటబుల్ (Immutable) ప్రవర్తనను కల్పించింది.

Q: int మరియు System.Int32 ల మధ్య తేడా ఏమిటి?

రెండింటికీ సాంకేతికంగా ఎటువంటి తేడా లేదు! System.Int32 అనేది .NET ఫ్రేమ్‌వర్క్ యొక్క అధికారిక టైప్ పేరు, మరియు int అనేది C# లాంగ్వేజ్ మనకు అందించిన సులభమైన అలియాస్ (Keyword Alias).
