ఇంటర్‌ఫేసెస్, అబ్‌స్ట్రాక్ట్ క్లాసెస్ & C# Records

⚡ Modern C# 12 & .NET 8 🟢 Chapter 16 of 20 📂 Phase 04: ఆబ్జెక్ట్ ఓరియెంటెడ్ ప్రోగ్రామింగ్ (OOP) 📅 2026 Edition

లార్జ్-స్కేల్ ఎంటర్‌ప్రైజ్ సాఫ్ట్‌వేర్ ఆర్కిటెక్చర్‌లో కోడ్‌ను విడదీసి (Decoupling) నిర్వహించడానికి Abstract Classes మరియు Interfaces గుండెకాయ లాంటివి. వీటితో పాటు, ఆధునిక C# లో డేటాను ఇమ్మ్యూటబుల్‌గా మరియు సురక్షితంగా నిర్వహించడానికి C# 9+ లో ప్రవేశపెట్టబడిన record టైప్స్ విప్లవాత్మక మార్పు తెచ్చాయి. ఈ అధ్యాయంలో అబ్‌స్ట్రాక్షన్, మల్టిపుల్ ఇంటర్‌ఫేస్ ఇంప్లిమెంటేషన్ మరియు రికార్డ్స్ యొక్క Value Equality మెకానిజమ్స్‌ను లోతుగా నేర్చుకుందాం.
1 Abstract Classes & Abstract Methods: అసంపూర్ణ బ్లూప్రింట్

abstract class: దీనికి నేరుగా new ఆపరేటర్ ద్వారా ఆబ్జెక్ట్‌ను క్రియేట్ చేయలేము (ఉదా: new Shape() కుదరదు). ఇది చైల్డ్ క్లాసులకు ఒక కామన్ బేస్ క్లాస్‌గా మాత్రమే ఉపయోగపడుతుంది.

abstract method: దీనికి బాడీ (ఇంప్లిమెంటేషన్) ఉండదు. చైల్డ్ క్లాసులు తప్పనిసరిగా override కీవర్డ్ వాడి బాడీని రాసి తీరాలి.

AbstractShapeDemo.cs ⚡ Try in C# Compiler 
using System;

abstract class Shape
{
    public string Color { get; set; } = "Red";

    // Abstract method: MUST be implemented by child classes
    public abstract double GetArea();

    // Regular concrete method: Can be directly shared
    public void Display() => Console.WriteLine($"Shape [{Color}] -> Area = {GetArea():F2}");
}

class Circle : Shape
{
    public double Radius { get; set; }
    public Circle(double radius) => Radius = radius;

    public override double GetArea() => Math.PI * Radius * Radius;
}

class Program
{
    static void Main()
    {
        Shape s = new Circle(5.0);
        s.Display();
    }
}
2 Interfaces (interface): సంపూర్ణ కాంట్రాక్ట్ & Multiple Implementation

ఇంటర్‌ఫేస్ అనేది క్లాస్ పాటించాల్సిన నియమాలను నిర్దేశించే ఒక కాంట్రాక్ట్ (Contract). ఇంటర్‌ఫేస్‌లో ఏ మెథడ్స్, ప్రాపర్టీస్ ఉండాలో డిక్లేర్ చేస్తాం తప్ప వాటికి సొంత స్టేట్ (ఇన్స్టాన్స్ ఫీల్డ్స్) ఉండదు.

C# లో ఒక క్లాస్ ఎన్ని ఇంటర్‌ఫేస్‌లనైనా ఇంప్లిమెంట్ చేసుకోవచ్చు (Multiple Interface Implementation). .NET నేమింగ్ కన్వెన్షన్ ప్రకారం ఇంటర్‌ఫేస్ పేరు ఎల్లప్పుడూ I తో మొదలవ్వాలి (ఉదా: IDisposable, ILogger, IPaymentGateway).

MultipleInterfaces.cs ⚡ Try in C# Compiler 
using System;

interface IPrintable
{
    void Print();
}

interface ISerializable
{
    string ToJson();
}

// Class implementing multiple interfaces
class Invoice : IPrintable, ISerializable
{
    public int InvoiceNumber { get; set; }
    public decimal Amount { get; set; }

    public void Print() => Console.WriteLine($"Printing Invoice #{InvoiceNumber}: {Amount:C}");

    public string ToJson() => $"{{"id": {InvoiceNumber}, "amount": {Amount}}}";
}

class Program
{
    static void Main()
    {
        Invoice inv = new Invoice { InvoiceNumber = 501, Amount = 1250m };
        inv.Print();
        Console.WriteLine($"JSON Payload: {inv.ToJson()}");
    }
}

4 Modern C# Records: Value Equality & Immutability

సాధారణ C# క్లాసుల్లో రెండు వేర్వేరు ఆబ్జెక్టులు ఒకే డేటాను కలిగి ఉన్నా, == తో పోల్చినప్పుడు మెమరీ అడ్రస్ ఆధారంగా false వస్తుంది. దీనికి విరుద్ధంగా, C# 9+ లో వచ్చిన record టైప్స్ విలువల సమానత్వాన్ని (Value-based Equality) ఆధారం చేసుకుంటాయి.

ఒకే ఒక్క లైన్‌లో ఇమ్మ్యూటబుల్ డేటా ఆబ్జెక్ట్‌ను డిక్లేర్ చేయడానికి Positional Record సింటాక్స్ వాడతాం. అదనంగా with expression ద్వారా ఉన్న రికార్డును మార్చకుండా కొత్త కాపీని సృష్టించవచ్చు (Nondestructive Mutation).

RecordDemo.cs ⚡ Try in C# Compiler 
using System;

// Single line immutable record declaration
record Person(string FirstName, string LastName, int Age);

class Program
{
    static void Main()
    {
        Person p1 = new Person("Rajesh", "Sharma", 30);
        Person p2 = new Person("Rajesh", "Sharma", 30);

        // 1. Value-based Equality check
        Console.WriteLine($"Are p1 and p2 equal? {p1 == p2}"); // True! (In class it would be false)

        // 2. Built-in Pretty ToString()
        Console.WriteLine(p1); // Person { FirstName = Rajesh, LastName = Sharma, Age = 30 }

        // 3. Nondestructive Mutation with 'with' keyword
        Person p3 = p1 with { Age = 31 };
        Console.WriteLine($"Original: {p1.Age}, Updated Copy: {p3.Age}");
    }
}
5 రియల్-వరల్డ్ కేస్ స్టడీ: పేమెంట్ గేట్‌వే ప్రాసెసర్ (Dependency Injection పునాది)

వాస్తవ ASP.NET Core ప్రాజెక్టులలో ఇంటర్‌ఫేసెస్ వాడి లూజ్ కప్లింగ్ (Loose Coupling) ఎలా సాధిస్తారో పరిశీలిద్దాం:

PaymentServiceArchitecture.cs ⚡ Try in C# Compiler 
using System;

interface IPaymentGateway
{
    bool ProcessPayment(decimal amount);
}

class UpiPayment : IPaymentGateway
{
    public bool ProcessPayment(decimal amount)
    {
        Console.WriteLine($"[UPI] Processing payment of {amount:C} via GooglePay");
        return true;
    }
}

class CreditCardPayment : IPaymentGateway
{
    public bool ProcessPayment(decimal amount)
    {
        Console.WriteLine($"[Card] Processing payment of {amount:C} via Visa/MasterCard");
        return true;
    }
}

class OrderService
{
    private readonly IPaymentGateway _gateway;
    public OrderService(IPaymentGateway gateway) => _gateway = gateway;

    public void Checkout(decimal total) => _gateway.ProcessPayment(total);
}

class Program
{
    static void Main()
    {
        // Effortlessly swap payment modes without touching OrderService!
        OrderService order1 = new OrderService(new UpiPayment());
        order1.Checkout(499m);

        OrderService order2 = new OrderService(new CreditCardPayment());
        order2.Checkout(2499m);
    }
}
6 బిగినర్ తప్పులు & ఇంటర్వ్యూ FAQ
⚠️ ప్రమాదకరమైన తప్పు: ఇంటర్‌ఫేస్ ఇంప్లిమెంట్ చేసేటప్పుడు public పెట్టకపోవడం
ఒక క్లాస్‌లో ఇంటర్‌ఫేస్ మెథడ్‌ను ఇంప్లిమెంట్ చేసేటప్పుడు కచ్చితంగా public అని రాయాలి. ఎందుకంటే ఇంటర్‌ఫేస్ కాంట్రాక్ట్ ఎల్లప్పుడూ పబ్లిక్ అయి ఉండాలి. public మిస్ అయితే కంపైలర్ ఎర్రర్ ఇస్తుంది.

తరచుగా అడిగే ప్రశ్నలు (FAQ):

  • Record మరియు Class మధ్య ప్రధాన తేడా ఏమిటి?
    Class రిఫరెన్స్ ఆధారంగా సమానత్వాన్ని (Reference Equality) కొలుస్తుంది. Record విలువల ఆధారంగా సమానత్వాన్ని (Value Equality) కొలుస్తుంది మరియు డిఫాల్ట్‌గా ఇమ్మ్యూటబుల్ ప్రాపర్టీలను అందిస్తుంది.
  • C# లో Default Interface Methods అంటే ఏమిటి?
    C# 8.0 నుండి ఇంటర్‌ఫేస్‌లలో కూడా డీఫాల్ట్ బాడీతో కూడిన మెథడ్స్ రాయవచ్చు. దీనివల్ల పాత క్లాసులను బ్రేక్ చేయకుండా ఇంటర్‌ఫేస్‌కు కొత్త ఫీచర్లు జోడించవచ్చు.
