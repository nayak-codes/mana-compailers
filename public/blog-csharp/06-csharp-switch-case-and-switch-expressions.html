switch స్టేట్‌మెంట్ & మోడ్రన్ switch ఎక్స్‌ప్రెషన్స్

⚡ Modern C# 12 & .NET 8 🟢 Chapter 6 of 20 📂 Phase 02: కంట్రోల్ ఫ్లో, లూప్స్ & ప్యాటర్న్ మ్యాచింగ్ 📅 2026 Edition
📌 Covered in this chapter: క్లాసిక్ switch-case vs C# 8+ switch expressions · when గార్డ్ కండిషన్స్ · Multiple Case Grouping · O(1) జంప్ టేబుల్
ఒక ప్రోగ్రామ్‌లో బహుళ స్థిర విలువలపై (Discrete choices) నిర్ణయాలు తీసుకోవాల్సి వచ్చినప్పుడు వరుసగా else-if లు రాయడం కోడ్‌ను సంక్లిష్టంగా చేస్తుంది. C# లో ఇందుకు సంప్రదాయ switch-case స్టేట్‌మెంట్‌తో పాటు, C# 8 లో ప్రవేశపెట్టిన అత్యాధునిక switch Expressions (=>) అందుబాటులో ఉన్నాయి. C లాంగ్వేజ్‌లా కాకుండా C# లో స్ట్రింగ్స్‌తో switch ఎలా పనిచేస్తుంది, No Fall-Through రూల్, మరియు when గార్డ్ క్లాజెస్‌ను ఈ అధ్యాయంలో నేర్చుకుందాం.
1క్లాసిక్ switch-case & C# 'No Fall-Through' రూల్

C లేదా C++ లలో ఒక కేస్ చివర break రాయకపోతే కంపైలర్ నిశ్శబ్దంగా తర్వాతి కేస్‌లోకి జారిపోతుంది (Fall-through bug). కానీ C# లో ఇది పూర్తిగా నిషిద్ధం. C# కంపైలర్ ప్రతి కేస్ చివర తప్పనిసరిగా break;, return;, లేదా throw; ఉండాలని డిమాండ్ చేస్తుంది.

C# — Classic switch-case statement ⚡ Try in C# Compiler 
int dayNumber = 3;
string dayName;

switch (dayNumber) {
    case 1: dayName = "సోమవారం"; break;
    case 2: dayName = "మంగళవారం"; break;
    case 3: dayName = "బుధవారం"; break;
    case 4: dayName = "గురువారం"; break;
    case 5: dayName = "శుక్రవారం"; break;
    case 6:
    case 7: 
        dayName = "వీకెండ్ (శని/ఆదివారం)"; // బహుళ కేస్‌లను గ్రూప్ చేయవచ్చు
        break;
    default:
        dayName = "చెల్లని రోజు సంఖ్య";
        break;
}
Console.WriteLine($"ఎంపిక చేసిన రోజు: {dayName}");
2మోడ్రన్ switch Expressions (=>) — C# 8+ సూపర్ పవర్

ఆధునిక C# లో switch అనేది కేవలం ఒక స్టేట్‌మెంట్ మాత్రమే కాదు; అది నేరుగా ఒక విలువను రిటర్న్ చేసే ఎక్స్‌ప్రెషన్ (switch Expression). case, break, : వంటి బోయిలర్‌ప్లేట్ పదాలు లేకుండా ల్యాంబ్డా యారో => తో అత్యంత క్లీన్‌గా రాయవచ్చు:

C# — Modern switch Expression ⚡ Try in C# Compiler 
int statusCode = 200;

// switch ఎక్స్‌ప్రెషన్ ద్వారా ఫలితాన్ని నేరుగా వేరియబుల్‌కు అసైన్ చేయడం
string message = statusCode switch {
    200 => "OK: అభ్యర్థన విజయవంతమైంది",
    400 => "Bad Request: తప్పుడు ఇన్‌పుట్",
    404 => "Not Found: రిసోర్స్ లభించలేదు",
    500 => "Internal Server Error: సర్వర్ లోపం",
    _   => "Unknown: తెలియని స్టేటస్ కోడ్" // _ అంటే default కేస్
};

Console.WriteLine($"సర్వర్ రెస్పాన్స్: {message}");
3when గార్డ్ కండిషన్స్ (Guard Clauses)

ఒక కేస్ సరిపోలిన తర్వాత కూడా దానిలో అదనపు షరతులను (ఉదా: సంఖ్య పాజిటివా, నెగటివా) తనిఖీ చేయడానికి when క్లాజ్ అద్భుతంగా ఉపయోగపడుతుంది:

C# — switch with 'when' clause ⚡ Try in C# Compiler 
int score = 88;

string grade = score switch {
    >= 90 => "A+ (డిస్టింక్షన్)",
    >= 75 when score < 90 => "A (ఫస్ట్ క్లాస్)",
    >= 50 => "B (సెకండ్ క్లాస్)",
    >= 35 => "C (పాస్)",
    _ => "F (ఫెయిల్)"
};

Console.WriteLine($"విద్యార్థి గ్రేడ్: {grade}");
4ప్రాక్టికల్ కేస్ స్టడీ: రోల్-బేస్డ్ యాక్సెస్ కంట్రోల్ (RBAC Engine)

ఎంటర్‌ప్రైజ్ సాఫ్ట్‌వేర్ ఆర్కిటెక్చర్‌లో యూజర్ రోల్ ఆధారంగా అనుమతులను నిర్ణయించే క్లీన్ C# ఇంజిన్:

C# — Role-Based Permission Engine ⚡ Try in C# Compiler 
string userRole = "Manager";

string permissions = userRole.ToLower() switch {
    "admin"   => "పూర్తి యాక్సెస్ (Create, Read, Update, Delete)",
    "manager" => "మధ్యస్థ యాక్సెస్ (Create, Read, Update)",
    "user"    => "కేవలం చదవడం మాత్రమే (Read-Only)",
    _         => "యాక్సెస్ నిరాకరించబడింది (Access Denied)"
};

Console.WriteLine($"అనుమతులు: {permissions}");
5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. switch Expression లో డిస్కార్డ్ (_) మిస్ చేయడం:
switch ఎక్స్‌ప్రెషన్‌లో అన్ని సాధ్యమయ్యే కేసులను కవర్ చేయకపోతే (Non-exhaustive match), కంపైల్-టైమ్ వార్నింగ్ మరియు రన్‌టైమ్‌లో SwitchExpressionException క్రాష్ వస్తుంది. ఎల్లప్పుడూ చివర _ => ... తప్పనిసరిగా ఉండాలి.
❌ 2. డూప్లికేట్ కేస్ వాల్యూస్ ఇవ్వడం:
case 1: ... case 1: ... // Compiler Error: The switch statement contains multiple cases with the same label value ఒకే switch లో రెండు సార్లు ఒకే స్థిరాంకం ఉండకూడదు. కంపైలర్ వెంటనే ఎర్రర్ చూపిస్తుంది.
6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: C లాంగ్వేజ్‌లో switch కి string పనిచేయదు, C# లో ఎలా పనిచేస్తుంది?

C లో స్ట్రింగ్స్ కేవలం పాయింటర్లు. కానీ C# లో స్ట్రింగ్ అనేది ఫస్ట్-క్లాస్ ఆబ్జెక్ట్. కంపైలర్ స్ట్రింగ్ switch ను అంతర్గతంగా ఒక వేగవంతమైన హ్యాష్ టేబుల్ లూకప్ మరియు string.Equals తో ఆప్టిమైజ్ చేస్తుంది.

Q: switch లో ఒక కేస్ నుండి మరొక కేస్‌కు జంప్ చేయవచ్చా?

చేయవచ్చు! C# లో ఇంప్లిసిట్ ఫాల్-త్రూ నిషిద్ధం అయినప్పటికీ, డెవలపర్ కావాలనుకుంటే స్పష్టంగా goto case 2; లేదా goto default; అని రాసి జంప్ చేయవచ్చు.
