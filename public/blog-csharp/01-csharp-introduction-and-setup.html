మైక్రోసాఫ్ట్ సంస్థ రూపొందించిన ఆధునిక సాఫ్ట్‌వేర్ ప్రపంచంలో అత్యంత శక్తివంతమైన, పాపులర్ మరియు బహుముఖ ప్రోగ్రామింగ్ భాష C# (సీ-షార్ప్). ఎంటర్‌ప్రైజ్ వెబ్ అప్లికేషన్లు, క్లౌడ్ మైక్రోసర్వీసెస్ (Azure/AWS), గేమింగ్ ఇండస్ట్రీ (Unity Engine), మరియు క్రాస్-ప్లాట్‌ఫామ్ మొబైల్ యాప్స్‌ను నిర్మించడానికి C# & .NET 8 పవర్‌హౌస్ లాంటివి. ఈ అధ్యాయంలో C# పుట్టుక, .NET 3-టైర్ ఆర్కిటెక్చర్ (CIL, CLR & JIT Compiler), మరియు మీ మొదటి C# 12 ప్రోగ్రామ్ అంతర్గత పనితీరును సమగ్రంగా పరిశీలిద్దాం.
1C# అంటే ఏమిటి? Origins & Anders Hejlsberg ఫిలాసఫీ

C# అనేది ఒక modern, object-oriented, type-safe, component-oriented, garbage-collected ప్రోగ్రామింగ్ భాష. దీనిని 2000వ సంవత్సరంలో మైక్రోసాఫ్ట్‌లోని ప్రముఖ సాఫ్ట్‌వేర్ ఆర్కిటెక్ట్ Anders Hejlsberg (ఆండర్స్ హెజ్ల్స్‌బర్గ్) (Turbo Pascal మరియు Delphi సృష్టికర్త) నేతృత్వంలో రూపొందించారు.

💡 C# యొక్క ప్రధాన మూలస్తంభాలు (Core Pillars):

  • Type Safety (టైప్ సేఫ్టీ): కంపైలర్ ప్రతి వేరియబుల్ డేటా రకాన్ని కఠినంగా తనిఖీ చేస్తుంది. తప్పు డేటా టైప్స్ వల్ల వచ్చే రన్‌టైమ్ క్రాష్‌లను ముందే నివారిస్తుంది.
  • Automatic Memory Management (Garbage Collector): C/C++ లో లాగా మెమరీని మాన్యువల్‌గా free() చేయాల్సిన అవసరం లేదు. బ్యాక్‌గ్రౌండ్‌లో రన్ అయ్యే CLR Garbage Collector (GC) పనికిరాని ఆబ్జెక్టులను స్వయంచాలకంగా క్లీన్ చేస్తుంది.
  • Modern & Expressive Syntax: Pattern Matching, Records, LINQ, Async/Await మరియు Nullable Reference Types వంటి అత్యాధునిక ఫీచర్లు కోడ్‌ను సంక్షిప్తంగా, సురక్షితంగా చేస్తాయి.
  • Cross-Platform Freedom: .NET Core మరియు .NET 8 లతో C# కోడ్ విండోస్ మాత్రమే కాకుండా Linux, macOS, Docker మరియు WebAssembly (Blazor) లపై అద్భుతంగా రన్ అవుతుంది.

🌍 పరిశ్రమల్లో C# ను ఎక్కడ ఉపయోగిస్తున్నారు?

🌐 Enterprise Web APIs ప్రపంచంలోని అతిపెద్ద బ్యాంకులు, ఈ-కామర్స్ పోర్టల్స్ ASP.NET Core తో హై-స్పీడ్ REST APIs నిర్మిస్తున్నాయి.
🎮 Game Development (Unity) ప్రపంచవ్యాప్తంగా 70% కంటే ఎక్కువ మొబైల్ & PC గేమ్స్ Unity 3D ఇంజిన్ లో C# తోనే కోడ్ చేయబడుతున్నాయి.
☁️ Cloud & Microservices Azure మరియు AWS లపై మైక్రోసర్వీసెస్, సర్వర్‌లెస్ ఫంక్షన్లు, మరియు డాకర్ కంటైనర్లలో C# రారాజు.
📱 Cross-Platform Apps .NET MAUI ద్వారా ఒకే C# కోడ్‌బేస్‌తో Android, iOS, Windows, మరియు macOS యాప్‌లు తయారుచేయవచ్చు.
2.NET 8 ఆర్కిటెక్చర్ — CIL, CLR & JIT కంపైలర్ పైప్‌లైన్

చాలామంది బిగినర్స్ C# కోడ్ రాసినప్పుడు అది నేరుగా కంప్యూటర్ మెషిన్ లాంగ్వేజ్ (0s & 1s) గా మారిపోతుందని భావిస్తారు. కానీ తెరవెనుక .NET ప్లాట్‌ఫామ్ ఒక 3-దశల ఎగ్జిక్యూషన్ పైప్‌లైన్ ను ఉపయోగిస్తుంది:

దశ 1: Roslyn Compiler — సోర్స్ కోడ్ నుండి CIL బైనరీ

మీరు రాసిన .cs ఫైల్‌ను మైక్రోసాఫ్ట్ Roslyn కంపైలర్ పరిశీలించి, ప్రాసెసర్-స్వతంత్ర ఇంటర్మీడియట్ కోడ్ అయిన CIL (Common Intermediate Language) లేదా IL Bytecode మరియు మెటాడేటాగా మారుస్తుంది. దీని అవుట్‌పుట్ .dll (లేదా .exe) అసెంబ్లీ.

దశ 2: Common Language Runtime (CLR) — వర్చువల్ ఎగ్జిక్యూషన్ ఇంజిన్

CLR అనేది .NET యొక్క వర్చువల్ మెషిన్ ఇంజిన్. ఇది ప్రోగ్రామ్‌కు అవసరమైన మెమరీని కేటాయించడం, టైప్ సేఫ్టీని ధృవీకరించడం, ఎక్సెప్షన్లను హ్యాండిల్ చేయడం, మరియు గార్బేజ్ కలెక్షన్‌ను నిర్వహించే అంతర్గత రక్షక కవచం.

దశ 3: Just-In-Time (JIT) Compiler — నేటివ్ CPU మెషిన్ కోడ్

ప్రోగ్రామ్ రన్ అవుతున్న ఖచ్చితమైన క్షణంలో (At Runtime), CLR లోని JIT కంపైలర్ ఆ IL బైట్‌కోడ్‌ను మీ కంప్యూటర్ ప్రాసెసర్ (x86-64, ARM64) నేరుగా అమలు చేయగల అత్యంత వేగవంతమైన నేటివ్ మెషిన్ కోడ్‌గా మారుస్తుంది.

3డెవలప్‌మెంట్ ఎన్విరాన్‌మెంట్ సెటప్ — .NET SDK & CLI

C# కోడింగ్ ప్రారంభించడానికి మీ కంప్యూటర్‌లో .NET 8 SDK మాత్రమే అవసరం. SDK (Software Development Kit) లో కంపైలర్, రన్‌టైమ్ మరియు శక్తివంతమైన dotnet CLI టూల్స్ ఉంటాయి.

💻 ప్రతి C# డెవలపర్ తెలుసుకోవలసిన 3 ప్రాథమిక CLI కమాండ్లు:

dotnet new console -o HelloApp : కొత్త కన్సోల్ ప్రాజెక్ట్‌ను సృష్టిస్తుంది.
cd HelloApp && dotnet run : కోడ్‌ను కంపైల్ చేసి వెంటనే రన్ చేస్తుంది.
dotnet build : కోడ్‌లో ఎర్రర్లు ఉన్నాయో లేదో కంపైల్ చేసి తనిఖీ చేస్తుంది.
4మొదటి C# ప్రోగ్రామ్: Hello World & Top-Level Statements

ఆధునిక C# (C# 9 నుండి C# 12 వరకు) లో అనవసరమైన బోయిలర్‌ప్లేట్ కోడ్‌ను తీసివేసి Top-Level Statements అనే విప్లవాత్మక ఫీచర్‌ను ప్రవేశపెట్టారు. విద్యార్థులు క్లాసులు, నేమ్‌స్పేస్‌లతో సతమతం కాకుండా నేరుగా లాజిక్ రాయవచ్చు:

C# — Modern Hello World (Top-Level Statement) ⚡ Try in C# Compiler 
// ఆధునిక C# 12 ప్రోగ్రామ్: ఒకే లైన్ తో అద్భుతమైన ప్రారంభం!
Console.WriteLine("నమస్కారం, C# & .NET 8 ప్రపంచానికి స్వాగతం!");

int year = 2026;
Console.WriteLine($"ప్రస్తుత ఎడిషన్: {year}");

🔍 క్లాసిక్ C# స్ట్రక్చర్ vs మోడ్రన్ టాప్-లెవల్ స్ట్రక్చర్:

🏛️ క్లాసిక్ C# 8 వరకు (సాంప్రదాయ పద్ధతి): 
using System;

namespace HelloWorldApp {
    class Program {
        static void Main(string[] args) {
            Console.WriteLine("Hello!");
        }
    }
}
⚡ మోడ్రన్ C# 9 నుండి C# 12 (ఆధునిక పద్ధతి): 
// కంపైలర్ స్వయంచాలకంగా Main() మరియు class ని సృష్టిస్తుంది!
Console.WriteLine("Hello!");
• Console: ఇది System నేమ్‌స్పేస్‌లో ఉన్న ఒక స్టాటిక్ క్లాస్. ఇది కీబోర్డ్ ఇన్‌పుట్ మరియు స్క్రీన్ అవుట్‌పుట్ స్ట్రీమ్‌లను నిర్వహిస్తుంది.
• WriteLine(): ఇచ్చిన టెక్స్ట్‌ను స్క్రీన్‌పై ముద్రించి కర్సర్‌ను తర్వాతి లైన్‌కు (Newline) తీసుకువెళుతుంది.
• $"{year}" (String Interpolation): డాలర్ $ గుర్తుతో వేరియబుల్స్ ను కర్లీ బ్రేసెస్ లోపల సులువుగా ఎంబెడ్ చేయవచ్చు.
5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. కేస్-సెన్సిటివిటీ మర్చిపోవడం (Case Sensitivity Error):
console.writeline("Hello"); // తప్పు! C# లో C మరియు W క్యాపిటల్ లెటర్స్ C# కచ్చితమైన Case-Sensitive లాంగ్వేజ్. Console.WriteLine ని స్మాల్ లెటర్స్‌తో రాస్తే కంపైలర్ ఎర్రర్ ఇస్తుంది.
❌ 2. .NET SDK కి బదులుగా కేవలం Runtime డౌన్‌లోడ్ చేసుకోవడం:
కేవలం .NET Runtime డౌన్‌లోడ్ చేసుకుంటే ముందే కంపైల్ అయిన యాప్‌లను మాత్రమే రన్ చేయగలం కానీ కొత్త కోడ్ కంపైల్ చేయలేం. డెవలపర్లు ఎల్లప్పుడూ .NET SDK నే ఇన్‌స్టాల్ చేసుకోవాలి.
❌ 3. ఒకే ప్రాజెక్ట్‌లో రెండు ఫైల్స్‌లో టాప్-లెవల్ స్టేట్‌మెంట్స్ రాయడం:
C# లో ఒక ప్రాజెక్ట్‌లోని కేవలం ఒకే ఒక్క ఫైల్ మాత్రమే Top-Level Statements కలిగి ఉండాలి. రెండు ఫైల్స్‌లో రాస్తే "Only one compilation unit can have top-level statements" ఎర్రర్ వస్తుంది.

Q: C# నేర్చుకోవడానికి ముందు C లేదా C++ నేర్చుకోవడం తప్పనిసరా?

అస్సలు అవసరం లేదు! C# చాలా యూజర్ ఫ్రెండ్లీ మరియు అధునాతన లాంగ్వేజ్. పాయింటర్లు, మాన్యువల్ మెమరీ డీఅలొకేషన్ వంటి సంక్లిష్టతలు లేకుండా నేరుగా మొదటి లాంగ్వేజ్‌గా C# ను ఎవరైనా సులభంగా నేర్చుకోవచ్చు.

Q: పాత .NET Framework మరియు మోడ్రన్ .NET 8 ల మధ్య ముఖ్యమైన తేడా ఏమిటి?

పాత .NET Framework (4.x వరకు) కేవలం విండోస్ ఆపరేటింగ్ సిస్టమ్‌పై మాత్రమే పనిచేసేది. ఆధునిక .NET 8 అనేది పూర్తిగా ఓపెన్-సోర్స్, అత్యంత వేగవంతమైనది మరియు లైనక్స్, డాకర్, మాక్, విండోస్‌లలో సమానంగా రన్ అయ్యే క్రాస్-ప్లాట్‌ఫామ్ ఫ్రేమ్‌వర్క్.
