ఇన్‌హెరిటెన్స్, పాలిమార్ఫిజం (virtual, override, sealed)

⚡ Modern C# 12 & .NET 8 🟢 Chapter 15 of 20 📂 Phase 04: ఆబ్జెక్ట్ ఓరియెంటెడ్ ప్రోగ్రామింగ్ (OOP) 📅 2026 Edition
📌 Covered in this chapter: base కీవర్డ్ · Method Overriding vs Hiding (new) · virtual & override మెకానిక్స్ · sealed క్లాసులు & మెథడ్స్
సాఫ్ట్‌వేర్ అభివృద్ధిలో కోడ్‌ను మళ్ళీ మళ్ళీ రాయకుండా (DRY - Don't Repeat Yourself), ఇప్పటికే ఉన్న క్లాస్ లక్షణాలను మరొక క్లాస్‌కు వారసత్వంగా అందించే పద్ధతినే Inheritance (ఇన్‌హెరిటెన్స్) అంటారు. దీనితో పాటు, ఒకే యాక్షన్ వివిధ ఆబ్జెక్ట్‌లలో వివిధ రూపాల్లో ప్రవర్తించేలా చేయడాన్ని Polymorphism (పాలిమార్ఫిజం) అంటారు. C# లో రన్‌టైమ్ పాలిమార్ఫిజం కోసం virtual, override, మరియు ఇన్‌హెరిటెన్స్‌ను నిరోధించడానికి sealed కీవర్డ్స్ ఎలా పనిచేస్తాయో ఈ అధ్యాయంలో నేర్చుకుందాం.
1 ఇన్‌హెరిటెన్స్ పునాది: Base & Derived Classes

C# లో ఒక క్లాస్ మరొక క్లాస్ నుండి వారసత్వం పొందడానికి కోలన్ (:) సింటాక్స్ వాడతారు. లక్షణాలను ఇచ్చే క్లాస్‌ను Base Class (Parent) అని, లక్షణాలను స్వీకరించే క్లాస్‌ను Derived Class (Child) అని పిలుస్తారు.

సింగిల్ క్లాస్ ఇన్‌హెరిటెన్స్: C# లో ఒక క్లాస్ ఒకే ఒక బేస్ క్లాస్ నుండి మాత్రమే వారసత్వం పొందగలదు (Multiple Class Inheritance అనుమతించబడదు, దీనివల్ల వచ్చే డైమండ్ ప్రాబ్లమ్‌ను నివారించడానికి .NET ఇంటర్‌ఫేసెస్ వాడుతుంది). అయితే .NET లోని అన్ని క్లాసులకు System.Object అనేది అల్టిమేట్ రూట్ బేస్ క్లాస్.

InheritanceBasics.cs ⚡ Try in C# Compiler 
using System;

// Base Class (Parent)
class Animal
{
    public string Name { get; set; }

    public void Sleep() => Console.WriteLine($"{Name} is sleeping... Zzz");
}

// Derived Class (Child inherits Animal)
class Dog : Animal
{
    public void Bark() => Console.WriteLine($"{Name} says: Woof! Woof!");
}

class Program
{
    static void Main()
    {
        Dog myDog = new Dog();
        myDog.Name = "Snoopy"; // Inherited property from Animal!
        myDog.Sleep();         // Inherited method from Animal!
        myDog.Bark();          // Dog's own method!
    }
}
2 base కీవర్డ్ & Base Constructor చైనింగ్

చైల్డ్ క్లాస్ ఆబ్జెక్ట్ తయారైనప్పుడు, చైల్డ్ కన్‌స్ట్రక్టర్ కంటే ముందే బేస్ క్లాస్ కన్‌స్ట్రక్టర్ రన్ అవుతుంది. బేస్ క్లాస్‌కు అవసరమైన పారామీటర్లను పంపించడానికి base(...) కీవర్డ్ ఉపయోగిస్తాం.

BaseConstructorDemo.cs ⚡ Try in C# Compiler 
using System;

class Vehicle
{
    public string Brand { get; }
    public Vehicle(string brand)
    {
        Brand = brand;
        Console.WriteLine($"1. Vehicle Constructor initialized for {Brand}");
    }
}

class Car : Vehicle
{
    public int MaxSpeed { get; }
    // Calling base class constructor
    public Car(string brand, int maxSpeed) : base(brand)
    {
        MaxSpeed = maxSpeed;
        Console.WriteLine($"2. Car Constructor initialized: {MaxSpeed} km/h");
    }
}

class Program
{
    static void Main()
    {
        Car myCar = new Car("Tata", 180);
    }
}
3 Polymorphism: virtual, override & V-Table డిస్పాచ్

పేరెంట్ క్లాస్‌లోని ఒక మెథడ్‌ను చైల్డ్ క్లాస్ తన సొంత లాజిక్‌తో మార్చుకోవడానికి (Override చేయడానికి) C# రన్‌టైమ్ పాలిమార్ఫిజంను అందిస్తుంది:

  • virtual కీవర్డ్: బేస్ క్లాస్‌లో మెథడ్‌కు virtual అని పెడితే, "ఈ మెథడ్‌ను చైల్డ్ క్లాసులు తమ ఇష్టం వచ్చినట్లు మార్చుకోవచ్చు" అని అర్థం.
  • override కీవర్డ్: డిరైవ్డ్ క్లాస్‌లో ఆ మెథడ్‌ను రీడిఫైన్ చేయడానికి override కీవర్డ్ తప్పనిసరి.

V-Table (Virtual Method Table): రన్‌టైమ్‌లో CLR ఆబ్జెక్ట్ యొక్క వాస్తవ టైప్‌ను బట్టి సరైన మెథడ్‌ను ఎగ్జిక్యూట్ చేస్తుంది. దీనివల్ల బేస్ క్లాస్ రిఫరెన్స్‌తో చైల్డ్ ఆబ్జెక్ట్‌ను కాల్ చేసినా చైల్డ్ మెథడే రన్ అవుతుంది!

PolymorphismInAction.cs ⚡ Try in C# Compiler 
using System;
using System.Collections.Generic;

class Employee
{
    public string Name { get; set; }
    public virtual decimal CalculateSalary() => 20000m;
}

class Developer : Employee
{
    public decimal CodingBonus { get; set; } = 15000m;
    public override decimal CalculateSalary() => base.CalculateSalary() + CodingBonus;
}

class Manager : Employee
{
    public override decimal CalculateSalary() => 55000m;
}

class Program
{
    static void Main()
    {
        // Polymorphic Collection
        List team = new List
        {
            new Employee { Name = "Ravi" },
            new Developer { Name = "Sneha" },
            new Manager { Name = "Arun" }
        };

        foreach (Employee emp in team)
        {
            // Dynamic Dispatch: Calls the right overridden method at runtime!
            Console.WriteLine($"{emp.Name} Salary: {emp.CalculateSalary():C}");
        }
    }
}
4 Method Hiding (new) vs Overriding (override)

ఇంటర్వ్యూలలో అత్యంత ప్రాచుర్యం పొందిన ప్రశ్న: override మరియు new మధ్య తేడా ఏమిటి?

  • override: బేస్ క్లాస్ రిఫరెన్స్ వాడినా చైల్డ్ క్లాస్ మెథడే రన్ అవుతుంది (True Runtime Polymorphism).
  • new (Method Hiding): పాలిమార్ఫిజం తెగిపోతుంది. బేస్ క్లాస్ రిఫరెన్స్‌తో పిలిస్తే బేస్ మెథడ్ రన్ అవుతుంది; కేవలం చైల్డ్ క్లాస్ రిఫరెన్స్‌తో పిలిచినప్పుడు మాత్రమే కొత్త మెథడ్ రన్ అవుతుంది.
OverrideVsNew.cs ⚡ Try in C# Compiler 
using System;

class Parent
{
    public virtual void Show() => Console.WriteLine("Parent Show");
}

class ChildA : Parent
{
    public override void Show() => Console.WriteLine("ChildA (Override) Show");
}

class ChildB : Parent
{
    public new void Show() => Console.WriteLine("ChildB (New/Hidden) Show");
}

class Program
{
    static void Main()
    {
        Parent p1 = new ChildA();
        p1.Show(); // Prints: "ChildA (Override) Show" (Polymorphic!)

        Parent p2 = new ChildB();
        p2.Show(); // Prints: "Parent Show" (Hiding broke polymorphism!)
    }
}
5 sealed కీవర్డ్: ఇన్‌హెరిటెన్స్ నిరోధించడం

సెక్యూరిటీ లేదా పెర్ఫార్మెన్స్ కారణాల రీత్యా ఒక క్లాస్‌ను మరెవరూ ఇన్‌హెరిట్ చేసుకోకుండా ఆపడానికి sealed కీవర్డ్ వాడతారు. ఉదాహరణకు .NET లోని System.String క్లాస్ ఒక sealed క్లాస్.

JIT ఆప్టిమైజేషన్: ఒక క్లాస్ sealed అయినప్పుడు, వర్చువల్ మెథడ్ కాల్స్ అవసరం లేదని JIT కంపైలర్‌కు తెలుస్తుంది. దీనివల్ల డైరెక్ట్ మెథడ్ ఇన్లైనింగ్ జరిగి అప్లికేషన్ వేగం పెరుగుతుంది.

SealedDemo.cs ⚡ Try in C# Compiler 
using System;

// Nobody can inherit from SecurityVault!
sealed class SecurityVault
{
    public void OpenSafe() => Console.WriteLine("Vault unlocked safely.");
}

// class HackerVault : SecurityVault {} // Compile Error: Cannot inherit from sealed class!

class Program
{
    static void Main()
    {
        SecurityVault vault = new SecurityVault();
        vault.OpenSafe();
    }
}
6 బిగినర్ తప్పులు & ఇంటర్వ్యూ FAQ
⚠️ ప్రమాదకరమైన తప్పు: override రాయడం మర్చిపోయి వార్నింగ్ రావడం
చైల్డ్ క్లాస్‌లో బేస్ క్లాస్ మెథడ్ పేరు రాసి override కీవర్డ్ పెట్టకపోతే కంపైలర్ CS0114 వార్నింగ్ ఇస్తుంది మరియు ఆటోమేటిక్‌గా new (Hiding) గా పరిగణిస్తుంది. దీనివల్ల పాలిమార్ఫిక్ కాల్స్ పని చేయవు.

తరచుగా అడిగే ప్రశ్నలు (FAQ):

  • C# లో Multiple Inheritance ఎందుకు లేదు?
    రెండు వేర్వేరు పేరెంట్ క్లాసుల్లో ఒకే పేరుతో మెథడ్స్ ఉన్నప్పుడు చైల్డ్ క్లాస్‌కు ఏది రావాలో తెలియని డెడ్‌లాక్ (Diamond Problem) వస్తుంది. దీని నివారణకు C# మల్టిపుల్ ఇంటర్‌ఫేసెస్‌ను మాత్రమే అనుమతిస్తుంది.
  • కన్‌స్ట్రక్టర్లను override చేయవచ్చా?
    లేదు! కన్‌స్ట్రక్టర్లు ఇన్‌హెరిట్ అవ్వవు, కాబట్టి వాటిని ఓవర్‌రైడ్ చేయడం సాధ్యం కాదు. కేవలం base(...) ద్వారా కాల్ చేయవచ్చు.
