C# అర్రేలు (1D, 2D Rectangular & Jagged Arrays)

⚡ Modern C# 12 / .NET 8 LTS 📖 Chapter 11 of 20 📁 Phase 03: మెథడ్స్, స్ట్రింగ్స్ & కలెక్షన్స్ 🎓 2026 Academic Edition

Slicing · Array Immutability Myth · Comparison Matrix Table · Real-World Project: Multiplex Cinema Seat Booking & Reservation Engine · 7 Common Beginner Mistakes · Self-Assessment Quiz

స్వాగతం అధ్యాయం 11 కి! 🗃️ కంప్యూటర్ మెమరీలో డేటా వరుసలు & గ్రిడ్స్

మీ దగ్గర 50 మంది విద్యార్థుల మార్కులు లేదా 1000 మంది ఉద్యోగుల శాలరీల వివరాలు ఉన్నాయనుకుందాం. వాటన్నింటి కోసం 1000 వేర్వేరు వేరియబుల్స్ (emp1, emp2, emp3...) సృష్టించడం అసాధ్యం. ఒకే పేరుతో, ఒకే రకమైన డేటా విలువలను కంప్యూటర్ మెమరీలో వరుసగా (Contiguous Memory) భద్రపరిచే అత్యంత ప్రాథమికమైన డేటా స్ట్రక్చరే అర్రే (Array)!

కానీ C# లో అర్రేల వ్యవస్థ సాధారణ భాషల కంటే ఎంతో వైవిధ్యమైనది. ఇది సాధారణ 1-డైమెన్షనల్ అర్రేలతో పాటు — పక్కా దీర్ఘచతురస్ర ఆకారంలో ఉండే 2D రెక్టాంగ్యులర్ అర్రేస్ (int[,]), మరియు ప్రతి అడ్డువరుసలో వేర్వేరు సంఖ్యలో అంశాలను అనుమతించే శక్తిమంతమైన జాగ్డ్ అర్రేస్ (int[][] - Array of Arrays) లను అందిస్తుంది.

అంతేకాకుండా, సరికొత్త C# 12 లో వచ్చిన Collection Expressions ([1, 2, 3]) మరియు స్ప్రెడ్ ఆపరేటర్ (..) అర్రేలను డిక్లేర్ చేసే పద్ధతినే సమూలంగా మార్చివేశాయి! ఈ అధ్యాయంలో మనం మెమరీ లేఅవుట్స్, క్యాష్ లొకాలిటీ, సార్టింగ్ అల్గారిథమ్స్ నేర్చుకొని — ఒక మల్టీప్లెక్స్ సినిమా థియేటర్ సీటింగ్ బుకింగ్ ఇంజిన్‌ను నిర్మిస్తాం!

1 🗃️ కంప్యూటర్ మెమరీలో డేటా వరుసలు & Cache Locality

అర్రే యొక్క అతిపెద్ద బలం: కంటిగ్యుయస్ మెమరీ అలోకేషన్ (Contiguous Allocation). అంటే ఒక అర్రే కోసం మెమరీ హీప్‌లో కేటాయించబడిన బ్లాక్‌లో అన్ని ఎలిమెంట్స్ ఒకదాని ప్రక్కన ఒకటి ఎటువంటి ఖాళీ లేకుండా వరుసగా అమర్చబడి ఉంటాయి.

⚡ హార్డ్‌వేర్ రహస్యం: CPU Cache Locality అంటే ఏమిటి?

CPU ప్రాసెసర్ arr[0] ని చదివినప్పుడు, అది కేవలం ఆ ఒక్క ఎలిమెంట్‌ను మాత్రమే తీసుకురాదు! మెమరీ బస్ ద్వారా దాని ప్రక్కనే ఉన్న arr[1], arr[2], arr[3] లను కూడా ఒకేసారి అతివేగవంతమైన L1/L2 CPU Cache లోకి లోడ్ చేస్తుంది. దీనివల్ల లూప్ తిరుగుతున్నప్పుడు రామ్ (RAM) వరకు వెళ్లే పనిలేకుండా ప్రాసెసర్ మెరుపు వేగంతో లెక్కింపులు పూర్తి చేస్తుంది.

అర్రేలు ఎల్లప్పుడూ 0-ఇండెక్స్డ్ (Zero-based indexing) ఆధారంగా పనిచేస్తాయి. మొదటి ఎలిమెంట్ 0 వద్ద, చివరి ఎలిమెంట్ Length - 1 వద్ద ఉంటుంది.

2 📐 1D అర్రేస్ (Single-Dimensional Arrays)

ఒకే వరుసలో ఉండే డేటాను భద్రపరచడానికి 1D అర్రేస్ ఉపయోగిస్తారు.

C# లో ఒక అర్రేను సృష్టించినప్పుడు అందులోని ప్రతి స్థానం సంబంధిత డేటా టైప్ యొక్క డీఫాల్ట్ విలువతో (Default Value) ఆటోమేటిక్‌గా నింపబడుతుంది:

  • సంఖ్యలకు (int, double, decimal): 0
  • బూలియన్‌లకు (bool): false
  • రిఫరెన్స్ టైప్స్‌కు (string, ఆబ్జెక్ట్స్): null
csharp · 1D Array Declaration & Initialization 
// Style 1: సైజు పేర్కొని ఆ తర్వాత విలువలు ఇవ్వడం
int[] scores = new int[3]; // [0, 0, 0]
scores[0] = 85;
scores[1] = 92;
scores[2] = 78;

// Style 2: సృష్టించే సమయంలోనే విలువలు ఇవ్వడం
string[] cities = { "హైదరాబాద్", "విజయవాడ", "విశాఖపట్నం", "తిరుపతి" };

Console.WriteLine($"నగరాల సంఖ్య: {cities.Length}");
Console.WriteLine($"రెండవ నగరం  : {cities[1]}"); // విజయవాడ

3 ⏹️ 2D రెక్టాంగ్యులర్ అర్రేస్ (Multidimensional Arrays: int[,])

గణిత మ్యాట్రిక్స్, ఎక్సెల్ షీట్లు లేదా చెస్ బోర్డుల లాంటి గ్రిడ్ డేటాను భద్రపరచడానికి C# ప్రత్యేకంగా రెక్టాంగ్యులర్ అర్రేస్ (Rectangular Arrays) ను అందిస్తుంది.

ఇక్కడ బ్రాకెట్ల మధ్య కామా పెడతారు: int[,] matrix = new int[rows, cols];. దీనిలో ప్రతి అడ్డువరుసలోనూ సరిగ్గా ఒకే సంఖ్యలో నిలువు వరుసలు (Columns) ఉంటాయి.

csharp · 2D Rectangular Array Grid 
// 3 అడ్డు వరుసలు, 3 నిలువు వరుసలతో కూడిన 3x3 మ్యాట్రిక్స్
int[,] matrix = {
    { 1, 2, 3 },
    { 4, 5, 6 },
    { 7, 8, 9 }
};

// డైమెన్షన్ పొడవును పొందడానికి GetLength() వాడాలి:
int rows = matrix.GetLength(0); // 3 (Rows)
int cols = matrix.GetLength(1); // 3 (Columns)

Console.WriteLine("2D మ్యాట్రిక్స్ విజువలైజేషన్:");
for (int r = 0; r < rows; r++)
{
    for (int c = 0; c < cols; c++)
    {
        Console.Write($"{matrix[r, c],3} ");
    }
    Console.WriteLine();
}

4 🪜 జాగ్డ్ అర్రేస్ (Jagged Arrays: int[][])

రెక్టాంగ్యులర్ అర్రేలలో అన్ని వరుసలలోనూ ఒకే సంఖ్యలో కాలమ్స్ ఉండాలి. కానీ నిజ జీవితంలో ఒక కాలేజీలో సెక్షన్ A లో 30 మంది, సెక్షన్ B లో 45 మంది, సెక్షన్ C లో 20 మంది ఉండవచ్చు. రెక్టాంగ్యులర్ అర్రే వాడితే ఖాళీ మెమరీ వృధా అవుతుంది.

ఈ సమస్యకు పరిష్కారమే జాగ్డ్ అర్రే (Jagged Array - అర్రేలలోని అర్రే / Array of Arrays)! దీనిలో ప్రతి రో తన స్వంత సైజును కలిగి ఉంటుంది:

csharp · Jagged Array with Variable Row Lengths 
// 3 సెక్షన్లు కలిగిన జాగ్డ్ అర్రే
int[][] studentSections = new int[3][];

studentSections[0] = new int[] { 85, 90, 78 };          // 3 మంది
studentSections[1] = new int[] { 95, 88, 72, 91, 84 };  // 5 మంది
studentSections[2] = new int[] { 60, 75 };              // 2 మంది

for (int s = 0; s < studentSections.Length; s++)
{
    Console.Write($"సెక్షన్ {s + 1} మార్కులు ({studentSections[s].Length} మంది): ");
    foreach (int mark in studentSections[s])
    {
        Console.Write($"{mark} ");
    }
    Console.WriteLine();
}

5 🔍 Array క్లాస్ మెథడ్స్ పవర్‌హౌస్ (Sort, Search, Copy)

.NET లోని System.Array క్లాస్ అర్రేలతో పనిచేయడానికి అద్భుతమైన స్టాటిక్ మెథడ్స్‌ను అందిస్తుంది:

csharp · Essential Array Utility Methods 
int[] numbers = { 45, 12, 85, 32, 89, 21 };

// 1. సార్టింగ్ (ఆరోహణ క్రమం)
Array.Sort(numbers);
Console.WriteLine($"సార్ట్ చేసిన అర్రే: {string.Join(", ", numbers)}");

// 2. రివర్సింగ్ (అవరోహణ క్రమం)
Array.Reverse(numbers);
Console.WriteLine($"రివర్స్ చేసిన అర్రే: {string.Join(", ", numbers)}");

// 3. బైనరీ సెర్చ్ (సార్ట్ అయి ఉన్నప్పుడు మాత్రమే పనిచేస్తుంది - O(log N))
Array.Sort(numbers);
int foundIndex = Array.BinarySearch(numbers, 45);
Console.WriteLine($"45 ఉన్న ఇండెక్స్: {foundIndex}");

// 4. క్లియరింగ్ (విలువలను డీఫాల్ట్ 0 కి మార్చడం)
Array.Clear(numbers, 0, 2); // మొదటి 2 ఎలిమెంట్స్ 0 అవుతాయి
Console.WriteLine($"క్లియర్ చేసిన తర్వాత: {string.Join(", ", numbers)}");

6 🎯 మోడ్రన్ C# 12 కలెక్షన్ ఎక్స్‌ప్రెషన్స్ ([]) & Spread (..)

C# 12 లో వచ్చిన అత్యంత ఆధునిక ఫీచర్ Collection Expressions. ఇకపై new int[] { 1, 2 } అని పెద్దగా రాయవలసిన అవసరం లేకుండా — కేవలం బ్రాకెట్లు [1, 2, 3] తో అర్రేలు, లిస్ట్‌లు, స్పాన్‌లు అన్నింటినీ ఒకేలా సృష్టించవచ్చు!

అదనంగా స్ప్రెడ్ ఆపరేటర్ (Spread ..) ద్వారా రెండు వేర్వేరు అర్రేలను ఒక్క లైన్‌లో విలీనం (Merge) చేయవచ్చు:

csharp · Modern C# 12 Collection Expressions 
// C# 12 క్లీన్ సింటాక్స్:
int[] batchA = [10, 20, 30];
int[] batchB = [40, 50];

// స్ప్రెడ్ ఆపరేటర్ (..) తో రెండు అర్రేలను కలపడం:
int[] mergedBatches = [..batchA, 999, ..batchB];

Console.WriteLine($"కలిపిన అర్రే: {string.Join(", ", mergedBatches)}");

7 📏 ఇండెక్స్ (^) మరియు రేంజ్ (..) తో అర్రే స్లైసింగ్

C# 8 లో వచ్చిన ఇండెక్స్ మరియు రేంజ్ ఆపరేటర్లు అర్రేల భాగాలను కత్తిరించడానికి (Slicing) ఎంతో సహకరిస్తాయి:

  • ^1: చివరి ఎలిమెంట్ (Last Element).
  • ^2: చివరి నుండి రెండవది.

void DisplayTheatreLayout(char[,] seats)
{

bool BookSeat(char[,] seats, int row, int col, out decimal ticketPrice)
{
    ticketPrice = 0m;
    if (row < 0 || row >= seats.GetLength(0) || col < 0 || col >= seats.GetLength(1))
    {
        Console.WriteLine("❌ చెల్లని సీటు నంబర్!");
        return false;
    }

    if (seats[row, col] == 'X')

        return false;
    }

    // సీటు బుకింగ్ కన్ఫర్మ్ చేయడం
    seats[row, col] = 'X';
    
    ticketPrice = row switch
    {
        0 => 350.00m,
        1 => 250.00m,
        _ => 150.00m
    };
    return true;
}

❓ ప్రశ్న 1: int[,] (రెక్టాంగ్యులర్) మరియు int[][] (జాగ్డ్) అర్రేల మధ్య ప్రధాన మెమరీ వ్యత్యాసం ఏమిటి?

సమాధానం: స్ప్రెడ్ ఆపరేటర్ ఒక కలెక్షన్ లోని ఎలిమెంట్స్ అన్నింటినీ విడదీసి సరికొత్త కలెక్షన్ లోకి ఇన్‌లైన్‌గా విలీనం (Inline Flattening / Merging) చేస్తుంది. ఉదాహరణకు [..a, ..b] ద్వారా రెండు అర్రేలను లూప్ లేకుండా సులభంగా కలపవచ్చు.
❓ ప్రశ్న 4: int[] b = a; అని రాసి b[0] = 500; అని మార్చితే a[0] మారుతుందా?
సమాధానం: ఖచ్చితంగా మారుతుంది! అర్రేలు C# లో Reference Types. b = a అన్నప్పుడు కేవలం మెమరీ పాయింటర్ మాత్రమే కాపీ అవుతుంది, కొత్త అర్రే పుట్టదు. కాబట్టి రెండూ ఒకే మెమరీ లొకేషన్‌ను సూచిస్తాయి.
❓ ప్రశ్న 5: అర్రేలలో CPU Cache Locality ఎందుకు అత్యంత వేగవంతమైన పనితీరును ఇస్తుంది?
సమాధానం: అర్రే ఎలిమెంట్స్ మెమరీలో ఒకదాని ప్రక్కన ఒకటి కంటిగ్యుయస్ గా ఉండటం వల్ల, CPU ఒక ఎలిమెంట్‌ను చదివినప్పుడే దాని ప్రక్కనున్న ఎలిమెంట్స్ ను కూడా నేరుగా హై-స్పీడ్ L1/L2 Cache లోకి ప్రీ-ఫెచ్ చేస్తుంది. దీనివల్ల రామ్ (RAM) లాటెన్సీ తప్పి ప్రాసెసింగ్ అత్యంత వేగంగా పూర్తవుతుంది.
