అర్రేలు (1D, 2D Rectangular & Jagged Arrays)

⚡ Modern C# 12 & .NET 8 🟢 Chapter 11 of 20 📂 Phase 03: మెథడ్స్, స్ట్రింగ్స్ & కలెక్షన్స్ 📅 2026 Edition
📌 Covered in this chapter: 1D అర్రేస్ · 2D రెక్టాంగ్యులర్ [,] vs జాగ్‌డ్ అర్రేస్ [][] (Array of Arrays) · Array క్లాస్ మెథడ్స్ (Sort, Reverse, IndexOf)
ఒకే డేటా టైప్‌కు చెందిన బహుళ విలువలను మెమరీలో ఒకే వరుస క్రమంలో నిల్వ చేయడానికి Arrays (అరేలు) ప్రాథమిక సాధనాలు. C# లో అరేలు రన్‌టైమ్ ద్వారా నిర్వహించబడే రిఫరెన్స్ టైప్స్ (Reference Types on Heap). C# లో సింగిల్ డైమెన్షనల్ అరేలతో పాటు, టేబుల్స్ కోసం Multidimensional Arrays (int[,]) మరియు వేర్వేరు పొడవులు ఉండే Jagged Arrays (int[][]) ఉంటాయి. ఈ అధ్యాయంలో వాటి మెమరీ లేఅవుట్, ఇండెక్స్ ఆపరేటర్లు మరియు ఆప్టిమైజేషన్లను పరిశీలిద్దాం.
1 Single-Dimensional Arrays (1D) & Zero-based Indexing

1D అరే అనేది ఫిక్స్‌డ్ సైజ్ కలిగిన వరుస మెమరీ బ్లాక్. అరేలోని మొదటి ఎలిమెంట్ ఇండెక్స్ ఎల్లప్పుడూ 0 తో మొదలవుతుంది, చివరి ఎలిమెంట్ ఇండెక్స్ Length - 1 అవుతుంది.

C# 8 లో ప్రవేశపెట్టిన Index from End (^) మరియు Range (..) ఆపరేటర్ల ద్వారా అరే ఎలిమెంట్స్‌ను మరింత సులువుగా యాక్సెస్ చేయవచ్చు. ఉదాహరణకు ^1 అంటే చివరి ఎలిమెంట్, 1..4 అంటే సబ్-అరే స్లైస్.

OneDArrayDemo.cs ⚡ Try in C# Compiler 
using System;

class Program
{
    static void Main()
    {
        // Array initialization
        int[] scores = { 88, 92, 79, 95, 84 };
        
        Console.WriteLine($"Total Elements: {scores.Length}");
        Console.WriteLine($"First Score: {scores[0]}");
        
        // Modern C# Index from end operator (^)
        Console.WriteLine($"Last Score: {scores[^1]}");
        Console.WriteLine($"Second to Last: {scores[^2]}");
        
        // Range slicing (..)
        int[] topThree = scores[0..3]; // indices 0, 1, 2
        Console.WriteLine($"Top 3 count: {topThree.Length}");
    }
}
2 Rectangular Multidimensional Arrays (int[,])

గ్రిడ్ లేదా మ్యాట్రిక్స్ రూపంలో ఉండే డేటా (ఉదాహరణకు గేమ్‌లలో చెస్ బోర్డు, లేదా ఇమేజ్ పిక్సెల్స్) నిల్వ చేయడానికి C# లో Rectangular Multidimensional Array ([,]) వాడతారు. ఇందులో ప్రతి అడ్డు వరుస (Row) లోనూ కచ్చితంగా సమాన సంఖ్యలో నిలువు వరుసలు (Columns) ఉంటాయి.

మెమరీలో ఇవి ఒకే నిరంతర (single contiguous) బ్లాక్‌గా స్టోర్ అవుతాయి. రోస్ సంఖ్య తెలుసుకోవడానికి GetLength(0) మరియు కాలమ్స్ సంఖ్య కోసం GetLength(1) వాడాలి.

Matrix2DDemo.cs ⚡ Try in C# Compiler 
using System;

class Program
{
    static void Main()
    {
        // 3 Rows, 3 Columns Matrix
        int[,] matrix = {
            { 1, 2, 3 },
            { 4, 5, 6 },
            { 7, 8, 9 }
        };

        int rows = matrix.GetLength(0);
        int cols = matrix.GetLength(1);

        Console.WriteLine($"Matrix Dimension: {rows}x{cols}");
        for (int r = 0; r < rows; r++)
        {
            for (int c = 0; c < cols; c++)
            {
                Console.Write($"{matrix[r, c],4} ");
            }
            Console.WriteLine();
        }
    }
}
3 Jagged Arrays (int[][]) — అరేల యొక్క అరే (Arrays of Arrays)

ఒక్కో వరుసలో వేర్వేరు సంఖ్యలో ఎలిమెంట్స్ ఉండాల్సి వచ్చినప్పుడు (ఉదాహరణకు ప్రతి క్లాస్‌లో వేర్వేరు సంఖ్యలో విద్యార్థులు ఉన్నప్పుడు) Jagged Array ([][]) వాడతారు. ఇది నిజానికి ఇతర అరేలకు పాయింట్ చేసే రిఫరెన్స్‌ల అరే.

హై-పెర్ఫార్మెన్స్ ఇన్సైట్: ఆశ్చర్యకరంగా .NET JIT కంపైలర్ రెక్టాంగ్యులర్ అరేల ([,]) కంటే జాగెడ్ అరేల ([][]) పై లూపులను వేగంగా ఎగ్జిక్యూట్ చేస్తుంది. ఎందుకంటే 1D వెక్టార్ బౌండ్స్ చెకింగ్ కోసం CPU ఆర్కిటెక్చర్‌లో ప్రత్యేక ఆప్టిమైజేషన్లు ఉంటాయి.
JaggedArrayDemo.cs ⚡ Try in C# Compiler 
using System;

class Program
{
    static void Main()
    {
        // Array of 3 arrays
        int[][] jagged = new int[3][];
        
        jagged[0] = new int[] { 10, 20 };
        jagged[1] = new int[] { 30, 40, 50, 60 };
        jagged[2] = new int[] { 70 };

        for (int i = 0; i < jagged.Length; i++)
        {
            Console.Write($"Row {i} (Length {jagged[i].Length}): ");
            for (int j = 0; j < jagged[i].Length; j++)
            {
                Console.Write($"{jagged[i][j]} ");
            }
            Console.WriteLine();
        }
    }
}
4 System.Array యుటిలిటీ మెథడ్స్ (Sort, Reverse, IndexOf)

అరేలపై వేగవంతమైన ఆపరేషన్స్ చేయడానికి .NET లోని స్టాటిక్ క్లాస్ System.Array అత్యుత్తమ మెథడ్స్‌ను కలిగి ఉంది:

ArrayUtilityMethods.cs ⚡ Try in C# Compiler 
using System;

class Program
{
    static void Main()
    {
        string[] cities = { "Visakhapatnam", "Hyderabad", "Vijayawada", "Tirupati" };

        // 1. Array.Sort (Ascending order)
        Array.Sort(cities);
        Console.WriteLine($"Sorted: {string.Join(", ", cities)}");

        // 2. Array.Reverse
        Array.Reverse(cities);
        Console.WriteLine($"Reversed: {string.Join(", ", cities)}");

        // 3. Array.IndexOf (Linear search)
        int index = Array.IndexOf(cities, "Hyderabad");
        Console.WriteLine($"Hyderabad found at index: {index}");
    }
}
5 రియల్-వరల్డ్ కేస్ స్టడీ: స్టూడెంట్ గ్రేడ్స్ కాలిక్యులేటర్

విద్యార్థుల మార్కులను ప్రాసెస్ చేసి సగటు (average) మరియు గరిష్ట స్కోర్ కనుగొనే సంపూర్ణ C# ప్రోగ్రామ్:

StudentGradesApp.cs ⚡ Try in C# Compiler 
using System;

class Program
{
    static void Main()
    {
        string[] students = { "Kiran", "Lavanya", "Mahesh" };
        int[] marks = { 85, 94, 78 };

        int highestMark = marks[0];
        string topStudent = students[0];
        int total = 0;

        for (int i = 0; i < marks.Length; i++)
        {
            total += marks[i];
            if (marks[i] > highestMark)
            {
                highestMark = marks[i];
                topStudent = students[i];
            }
        }

        double average = (double)total / marks.Length;
        Console.WriteLine($"Class Average: {average:F2}");
        Console.WriteLine($"Topper: {topStudent} with {highestMark} marks");
    }
}
6 బిగినర్ తప్పులు & ఇంటర్వ్యూ FAQ
⚠️ ప్రమాదకరమైన తప్పు: IndexOutOfRangeException
ఒక అరే సైజు 5 ఉన్నప్పుడు, చెల్లుబాటు అయ్యే ఇండెక్స్‌లు 0 నుండి 4 మాత్రమే. అనుకోకుండా scores[5] అని యాక్సెస్ చేయడానికి ప్రయత్నిస్తే రన్‌టైమ్‌లో అప్లికేషన్ క్రాష్ అవుతుంది. లూపుల్లో ఎల్లప్పుడూ i < array.Length కండిషన్ మాత్రమే వాడాలి.

తరచుగా అడిగే ప్రశ్నలు (FAQ):

  • Rectangular Array ([,]) మరియు Jagged Array ([][]) ల మధ్య తేడా ఏమిటి?
    రెక్టాంగ్యులర్ అరేలో అన్ని వరుసలు సమాన పొడవును కలిగి ఉంటాయి మరియు సింగిల్ బ్లాక్‌గా కేటాయించబడతాయి. జాగెడ్ అరేలో ఒక్కో వరుస వేర్వేరు పొడవును కలిగి ఉంటుంది మరియు హీప్‌పై స్వతంత్ర అరేలుగా ఉంటాయి.
  • C# లో Array సైజును డైనమిక్‌గా పెంచవచ్చా?
    లేదు, C# లో అరేలు ఫిక్స్‌డ్ సైజ్ కలిగి ఉంటాయి. డైనమిక్ సైజు కావాలంటే List<T> కలెక్షన్ వాడాలి.
