జెనెరిక్ కలెక్షన్స్ (List, Dictionary, HashSet)

⚡ Modern C# 12 & .NET 8 🟢 Chapter 12 of 20 📂 Phase 03: మెథడ్స్, స్ట్రింగ్స్ & కలెక్షన్స్ 📅 2026 Edition
📌 Covered in this chapter: Non-generic (ArrayList Boxing/Unboxing) సమస్య · List డైనమిక్ అరే · Dictionary $O(1)$ లూకప్ · HashSet యూనిక్ సెట్
ఫిక్స్‌డ్ సైజ్ గల సాధారణ అరేలకు భిన్నంగా, డేటాను డైనమిక్‌గా జోడించడానికి మరియు వేగంగా సెర్చ్ చేయడానికి .NET మనకు Generic Collections (System.Collections.Generic) ను అందిస్తుంది. పాత కాలపు నాన్-జెనెరిక్ కలెక్షన్స్ (ఉదా: ArrayList) వల్ల వచ్చే బాక్సింగ్/అన్‌బాక్సింగ్ పర్ఫార్మెన్స్ సమస్యలను తొలగించి, కంపైల్-టైమ్ టైప్ సేఫ్టీని కల్పించడమే జెనెరిక్స్ యొక్క ముఖ్య లక్ష్యం. ఈ అధ్యాయంలో List<T>, Dictionary<TKey, TValue>, మరియు HashSet<T> ల అంతర్గత పనితీరును క్షుణ్ణంగా నేర్చుకుందాం.
1 జెనెరిక్స్ ప్రాముఖ్యత: బాక్సింగ్ & అన్‌బాక్సింగ్ నివారణ

C# 1.0 లో ఉన్న ArrayList అన్ని రకాల డేటాను object గా నిల్వ చేసేది. దీనివల్ల రెండు పెద్ద ప్రమాదాలు ఉండేవి:

  1. Boxing & Unboxing: విలువైన Value Type (ఉదా: int) ను object గా మార్చినప్పుడు హీప్‌పై అలొకేషన్ జరిగి వేగం పడిపోతుంది.
  2. Type Safety లోపం: ఒకే లిస్టులో పూర్ణాంకాలు, స్ట్రింగ్స్ అన్నీ కలిసిపోయి రన్‌టైమ్‌లో InvalidCastException కు కారణమయ్యేవి.

C# 2.0 లో వచ్చిన Generics ఈ సమస్యకు శాశ్వత పరిష్కారం చూపాయి. List<int> అని రాస్తే అది కేవలం ఇంటిజర్లను మాత్రమే అనుమతిస్తుంది. జీరో బాక్సింగ్, మరియు 100% కంపైల్-టైమ్ భద్రత లభిస్తుంది.

GenericsSafety.cs ⚡ Try in C# Compiler 
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        // Safe, High Performance Generic List
        List numbers = new List();
        numbers.Add(10);
        numbers.Add(20);
        // numbers.Add("Hello"); // Compile Error! Type safe!

        int first = numbers[0]; // No casting or unboxing needed
        Console.WriteLine($"First number: {first}");
    }
}
2 List<T> ఇంటర్నల్ వర్కింగ్ & కెపాసిటీ గ్రోత్

List<T> వెనుక బ్యాక్‌గ్రౌండ్‌లో ఒక సాధారణ అరే పనిచేస్తుంది. దీనికి Count (ప్రస్తుతం ఉన్న ఎలిమెంట్స్ సంఖ్య) మరియు Capacity (ఇంటర్నల్ అరే గరిష్ట పరిమాణం) అనే రెండు ప్రాపర్టీలు ఉంటాయి.

కెపాసిటీ నిండిపోగానే, List<T> ఇంటర్నల్ అరే సైజును రెట్టింపు (4 → 8 → 16 → 32...) చేస్తుంది. మీకు ముందుగానే ఎలిమెంట్స్ సంఖ్య తెలిస్తే, కన్‌స్ట్రక్టర్‌లో కెపాసిటీని నిర్దేశించడం (ఉదా: new List<int>(1000)) ద్వారా రీ-అలొకేషన్లను నివారించవచ్చు.

ListOperations.cs ⚡ Try in C# Compiler 
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        List skills = new List { "C#", "SQL", ".NET" };
        
        // Adding and inserting
        skills.Add("Docker");
        skills.Insert(1, "Azure"); // Inserts at index 1
        
        // Searching
        bool hasCSharp = skills.Contains("C#");
        Console.WriteLine($"Contains C#? {hasCSharp}");
        
        // Removing
        skills.Remove("SQL");
        
        Console.WriteLine($"Count: {skills.Count}, Capacity: {skills.Capacity}");
        foreach (string skill in skills)
        {
            Console.WriteLine($"- {skill}");
        }
    }
}
3 Dictionary<TKey, TValue> & O(1) లుకప్ మెకానిజమ్స్

కీ-విలువ జంటలుగా (Key-Value Pairs) డేటాను నిల్వ చేయడానికి Dictionary<TKey, TValue> ఉత్తమమైనది. ఇది అంతర్గతంగా హాష్ టేబుల్ (Hash Table) ను ఉపయోగిస్తుంది. దీనివల్ల మిలియన్ల కొద్దీ రికార్డులు ఉన్నప్పటికీ సగటున O(1) కాన్‌స్టంట్ టైమ్ లో రికార్డును వెతకవచ్చు.

TryGetValue సేఫ్ పాటర్న్: కీ లేనప్పుడు ఇండెక్సర్ dict[key] వాడితే KeyNotFoundException వస్తుంది. దీని నివారణకు ఎల్లప్పుడూ TryGetValue వాడాలి.

DictionaryDemo.cs ⚡ Try in C# Compiler 
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        // Employee ID -> Name mapping
        Dictionary employees = new Dictionary()
        {
            { 101, "Anil Kumar" },
            { 102, "Sneha Reddy" }
        };

        employees[103] = "Vikas Rao"; // Add or Update

        // Safe Lookup using TryGetValue
        int targetId = 102;
        if (employees.TryGetValue(targetId, out string empName))
        {
            Console.WriteLine($"Found Employee {targetId}: {empName}");
        }
        else
        {
            Console.WriteLine($"Employee {targetId} not found!");
        }
    }
}
4 HashSet<T> & హై-స్పీడ్ సెట్ ఆపరేషన్స్

డూప్లికేట్స్ (నకిలీ విలువలు) ఉండకూడదనుకున్నప్పుడు మరియు ఒక ఎలిమెంట్ కలెక్షన్‌లో ఉందో లేదో క్షణాల్లో కనుగొనడానికి HashSet<T> వాడతారు. ఇది ఇండెక్స్ ఆధారంగా కాకుండా హాష్ ఆధారంగా పనిచేస్తుంది.

HashSetDemo.cs ⚡ Try in C# Compiler 
using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        HashSet activeIds = new HashSet { 1001, 1002, 1003 };
        
        bool addedAgain = activeIds.Add(1002); // Duplicate! Returns false
        Console.WriteLine($"Was 1002 added again? {addedAgain}");
        
        // O(1) membership check
        Console.WriteLine($"Contains 1003? {activeIds.Contains(1003)}");
        
        // Set Operations: Union, Intersect
        HashSet teamB = new HashSet { 1003, 1004, 1005 };
        activeIds.IntersectWith(teamB); // Keeps common elements only
        
        Console.WriteLine($"Common IDs count: {activeIds.Count}");
    }
}
5 సరైన కలెక్షన్‌ను ఎంచుకోవడానికి గైడ్ (Cheat Sheet)
Collection Type Lookup Speed Duplicates Allowed? ఉత్తమ వినియోగ సందర్భం
T[] (Array) O(1) index Yes సైజు స్థిరంగా ఉన్నప్పుడు, మెమరీ ఆప్టిమైజేషన్ కోసం
List<T> O(1) index, O(N) value Yes డైనమిక్ సైజు, ఆర్డర్ ముఖ్యం అయినప్పుడు సాధారణ లిస్టుల కోసం
Dictionary<K,V> O(1) key Keys: No, Values: Yes ఐడీ లేదా పేరు ద్వారా వేగంగా డేటాను ఫెచ్ చేయడానికి
HashSet<T> O(1) value No యూనిక్ ఎలిమెంట్స్ భద్రపరచడానికి, డూప్లికేట్స్ ఫిల్టర్ చేయడానికి
6 బిగినర్ తప్పులు & ఇంటర్వ్యూ FAQ
⚠️ ప్రమాదకరమైన తప్పు: foreach లూప్ తిరుగుతున్నప్పుడు కలెక్షన్‌ను మార్చడం
foreach (var item in list) { list.Remove(item); } అని రాస్తే రన్‌టైమ్‌లో InvalidOperationException: Collection was modified; enumeration operation may not execute ఎర్రర్ వస్తుంది. లూప్ లోపల ఎలిమెంట్స్ తొలగించాలంటే రివర్స్ for లూప్ లేదా list.RemoveAll(...) వాడాలి.

తరచుగా అడిగే ప్రశ్నలు (FAQ):

  • IEnumerable<T> మరియు List<T> మధ్య తేడా ఏమిటి?
    IEnumerable<T> అనేది కేవలం ఫార్వర్డ్-ఓన్లీ రీడ్-ఓన్లీ ఇటరేషన్ కోసం ఇంటర్‌ఫేస్ (Lazy evaluation). List<T> అనేది మెమరీలో స్టోర్ అయి ఉండే పూర్తి కలెక్షన్, ఇందులో యాడ్, రిమూవ్, ఇండెక్సింగ్ చేయవచ్చు.
  • Dictionary లో ఒకే కీని మళ్ళీ Add చేస్తే ఏమవుతుంది?
    dict.Add("k", v) వాడితే ArgumentException: An item with the same key has already been added వస్తుంది. అదే dict["k"] = v వాడితే ఉన్న వ్యాల్యూ ఓవర్‌రైట్ అవుతుంది.
