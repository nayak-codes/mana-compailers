లూప్స్ (for, while, do-while & foreach)

⚡ Modern C# 12 & .NET 8 🟢 Chapter 7 of 20 📂 Phase 02: కంట్రోల్ ఫ్లో, లూప్స్ & ప్యాటర్న్ మ్యాచింగ్ 📅 2026 Edition
📌 Covered in this chapter: for, while, do-while లైఫ్‌సైకిల్ · foreach & IEnumerable అంతర్గత పనితీరు · ఇన్ఫినిట్ లూప్స్ · Off-by-one బగ్స్
కంప్యూటర్ల యొక్క అద్భుతమైన సామర్థ్యం వేలాది పునరావృత పనులను (Repetitive Tasks) క్షణాల్లో అలసట లేకుండా ఖచ్చితత్వంతో పూర్తి చేయగలగడమే. C# లో ఇటరేషన్ల కోసం నాలుగు ప్రధాన లూప్స్ ఉన్నాయి — for, while, do-while, మరియు ఆధునిక కలెక్షన్స్ కోసం రూపొందించిన foreach. ఈ అధ్యాయంలో వాటి 4-దశల లైఫ్‌సైకిల్, IEnumerable అంతర్గత పనితీరు, మరియు ఇన్ఫినిట్ లూప్స్ ప్రమాదాలను లోతుగా నేర్చుకుందాం.
1for లూప్ — 4-దశల ఎగ్జిక్యూషన్ లైఫ్‌సైకిల్

ఇటరేషన్ల సంఖ్య ముందే ఖచ్చితంగా తెలిసినప్పుడు (ఉదాహరణకు 1 నుండి 100 వరకు సంఖ్యలు లేదా అర్రే ఇండెక్సింగ్) for లూప్ అత్యంత ప్రాచుర్యం పొందింది:

🔄 for లూప్ 4-దశల చక్రం:

  1. ఇనీషియలైజేషన్ (Initialization): లూప్ ప్రారంభంలో ఒకే ఒక్కసారి రన్ అవుతుంది (int i = 1).
  2. కండిషన్ టెస్ట్ (Condition Check): ప్రతి ఇటరేషన్‌కు ముందు పరీక్షించబడుతుంది (i <= 10). నిజమైతే లోపలికి వెళ్తుంది; అబద్ధమైతే లూప్ ఆగిపోతుంది.
  3. బాడీ ఎగ్జిక్యూషన్ (Body Execution): లూప్ లోపల ఉన్న కోడ్ స్టేట్‌మెంట్లు రన్ అవుతాయి.
  4. అప్‌డేట్ / ఇంక్రిమెంట్ (Update Step): బాడీ ముగియగానే వేరియబుల్ పెరుగుతుంది (i++). వెంటనే మళ్లీ స్టెప్ 2 కి వెళ్తుంది.
C# — for loop calculation ⚡ Try in C# Compiler 
int sum = 0;
// 1 నుండి 10 వరకు సహజ సంఖ్యల మొత్తం
for (int i = 1; i <= 10; i++) {
    sum += i;
}
Console.WriteLine($"1 నుండి 10 సంఖ్యల మొత్తం: {sum}");
2while & do-while లూప్స్ — ఎంట్రీ vs ఎగ్జిట్ కంట్రోల్

1. while లూప్ (ఎంట్రీ-కంట్రోల్డ్):

లూప్ లోపలికి ప్రవేశించే ముందే కండిషన్ చెక్ అవుతుంది. మొదట్లోనే కండిషన్ అబద్ధమైతే కోడ్ జీరో సార్లు రన్ అవుతుంది.

2. do-while లూప్ (ఎగ్జిట్-కంట్రోల్డ్):

కండిషన్ మొదట్లోనే అబద్ధమైనా కోడ్ బ్లాక్ కనీసం ఒక్కసారైనా (At least once) ఖచ్చితంగా రన్ అవుతుంది. మెనూ రిపీటేషన్‌కు బెస్ట్.

C# — while loop number reversing ⚡ Try in C# Compiler 
int number = 12345;
int reversed = 0;

while (number > 0) {
    int remainder = number % 10;
    reversed = (reversed * 10) + remainder;
    number /= 10; // వేరియబుల్ తగ్గించడం - ఇది లేకపోతే ఇన్ఫినిట్ లూప్ అవుతుంది!
}
Console.WriteLine($"తిరగేసిన సంఖ్య (Reversed): {reversed}");
3foreach లూప్ & IEnumerable అంతర్గత ఆర్కిటెక్చర్

C# లో అర్రేలు, లిస్టులు, మరియు కలెక్షన్స్ పై తిరగడానికి అత్యంత శుభ్రమైన, సిఫార్సు చేయబడిన లూప్ foreach. దీనికి ఇండెక్స్ వేరియబుల్స్ (i) లేదా బౌండరీ కాలిక్యులేషన్స్ అవసరం లేదు:

C# — foreach loop on string array ⚡ Try in C# Compiler 
string[] programmingLanguages = { "C#", "C++", "Python", "Java", "Go" };

Console.WriteLine("ప్రోగ్రామింగ్ భాషల జాబితా:");
foreach (string lang in programmingLanguages) {
    Console.WriteLine($"• {lang}");
}
⚙️ తెరవెనుక ఏం జరుగుతోంది? (IEnumerable & IEnumerator):

కంపైలర్ foreach ను అంతర్గతంగా IEnumerator enumerator = list.GetEnumerator() గా మారుస్తుంది. అది while (enumerator.MoveNext()) తో ఒక్కో అంశాన్ని చదువుతుంది. ముఖ్య గమనిక: foreach లోపల ఇటరేట్ అవుతున్న ఎలిమెంట్ రీడ్-ఓన్లీ (Read-Only); దాన్ని నేరుగా మార్చడం లేదా కలెక్షన్ నుండి రిమూవ్ చేయడం సాధ్యం కాదు.

4ఇన్ఫినిట్ లూప్స్ & CPU హ్యాంగ్ నివారణ

ఒక లూప్ కండిషన్ ఎప్పటికీ false కాకపోతే అది అనంతంగా రన్ అవుతూ CPU ని 100% స్ట్రెస్ చేసి అప్లికేషన్‌ను ఫ్రీజ్ చేస్తుంది. ప్రొడక్షన్ బ్యాక్‌గ్రౌండ్ వర్కర్లలో ఉద్దేశపూర్వకంగా అనంత లూప్స్ రాసేటప్పుడు CancellationToken లేదా Thread.Sleep() / await Task.Delay() వాడటం తప్పనిసరి.

5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. foreach లోపల కలెక్షన్‌ను సవరించడం (Collection Modified Trap):
foreach (var item in list) { list.Remove(item); } // InvalidOperationException! foreach రన్ అవుతున్నప్పుడు లిస్ట్‌లో ఎలిమెంట్లను తీసివేయడం లేదా చేర్చడం నిషిద్ధం. ఎలిమెంట్లను తీసివేయాలంటే రివర్స్ for లూప్ లేదా list.RemoveAll() వాడాలి.
❌ 2. Off-by-one ఇండెక్స్ ఎర్రర్:
for (int i = 0; i <= arr.Length; i++) // IndexOutOfRangeException! అర్రే ఇండెక్స్ ఎల్లప్పుడూ 0 నుండి Length - 1 వరకే ఉంటుంది. <= వాడితే ఆఖరి ఇటరేషన్‌లో అప్లికేషన్ క్రాష్ అవుతుంది. ఎల్లప్పుడూ < arr.Length రాయాలి.
6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: for లూప్ మరియు foreach లలో ఏది ఎక్కువ వేగవంతమైనది?

సాధారణ అర్రేల (Arrays) పై ఆధునిక .NET JIT కంపైలర్ రెండింటికీ ఒకే విధమైన ఆప్టిమైజ్డ్ అసెంబ్లీ కోడ్ ఉత్పత్తి చేస్తుంది కాబట్టి వేగంలో తేడా ఉండదు. అయితే లింక్డ్ లిస్టులు లేదా కాంప్లెక్స్ కలెక్షన్లలో foreach క్లీన్ కోడ్ పరంగా అత్యంత శ్రేయస్కరం.

Q: do-while లూప్ చివర సెమికోలన్ తప్పనిసరా?

అవును! while (...) లూప్‌కు సెమికోలన్ ఉండదు, కానీ do { ... } while (...); చివర సెమికోలన్ తప్పనిసరిగా ఉండాలి. లేకపోతే కంపైలర్ సింటాక్స్ ఎర్రర్ ఇస్తుంది.
