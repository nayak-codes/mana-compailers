break, continue & నెస్టెడ్ లూప్స్ (2D గ్రిడ్స్)

⚡ Modern C# 12 & .NET 8 🟢 Chapter 8 of 20 📂 Phase 02: కంట్రోల్ ఫ్లో, లూప్స్ & ప్యాటర్న్ మ్యాచింగ్ 📅 2026 Edition
📌 Covered in this chapter: break ఎర్లీ ఎగ్జిట్ · continue స్కిప్పింగ్ · నెస్టెడ్ లూప్స్ & 2D మ్యాట్రిక్స్ ప్రాసెసింగ్ · goto వివాదం
లూప్స్ ఎగ్జిక్యూట్ అవుతున్నప్పుడు సాధారణ ఫ్లోను నియంత్రించడానికి, అవసరమైన రికార్డు దొరకగానే లూప్ నుండి వెంటనే బయటకు రావడానికి లేదా కొన్ని అనవసరమైన ఇటరేషన్లను దాటవేయడానికి break మరియు continue కీవర్డ్లు తప్పనిసరి. 2D గ్రిడ్ ప్రాసెసింగ్ మరియు ఇంటర్వ్యూలలో ఎక్కువగా అడిగే నెస్టెడ్ లూప్స్ (Nested Loops) మరియు ప్యాటర్న్లను ఈ అధ్యాయంలో లోతుగా తెలుసుకుందాం.
1break కీవర్డ్ — అత్యవసర లూప్ ఎగ్జిట్ (Early Exit)

లూప్ ఎన్నిసార్లు తిరగాలని నిర్ణయించబడిందో ఆ లక్ష్యం ఇంకా పూర్తికాకముందే, ఒక నిర్దిష్ట పరిస్థితి రాగానే ఆ లూప్‌ను తక్షణమే శాశ్వతంగా ముగించి బయటకు రావడానికి break ఉపయోగపడుతుంది:

C# — Linear Search with break ⚡ Try in C# Compiler 
int[] employeeIds = { 101, 105, 109, 115, 120, 125 };
int searchId = 115;
bool found = false;

for (int i = 0; i < employeeIds.Length; i++) {
    if (employeeIds[i] == searchId) {
        Console.WriteLine($"లక్ష్యం {searchId} ఇండెక్స్ {i} వద్ద లభించింది!");
        found = true;
        break; // ఎలిమెంట్ దొరికింది! మిగిలిన ఇటరేషన్లు అవసరం లేదు
    }
}

if (!found) Console.WriteLine("ఐడీ లభించలేదు.");

💡 break లేకపోతే టార్గెట్ మొదట్లోనే దొరికినా అరే చివరి వరకు అనవసరంగా లూప్ రన్ అవుతూ సర్వర్ సమయాన్ని వృధా చేస్తుంది.

2continue కీవర్డ్ — ప్రస్తుత ఇటరేషన్ స్కిప్ చేయడం

లూప్‌ను పూర్తిగా ఆపేయకుండా, కేవలం ఆ ప్రస్తుత ఒక్క ఇటరేషన్‌లోని తర్వాతి లైన్లను మాత్రమే స్కిప్ చేసి వెంటనే తర్వాతి రౌండ్‌కు దూకడానికి continue వాడతాం:

C# — continue (Skip Multiples of 3) ⚡ Try in C# Compiler 
Console.WriteLine("3 యొక్క గుణిజాలు మినహా మిగిలిన సంఖ్యలు:");
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) {
        continue; // 3, 6, 9 వచ్చినప్పుడు ప్రింట్ చేయకుండా తర్వాతి రౌండ్‌కు వెళ్తుంది
    }
    Console.Write($"{i} ");
}
Console.WriteLine();
⚠️ while లూప్‌లో continue వాడేటప్పుడు జాగ్రత్త!

for లూప్‌లో continue ఆటోమేటిక్‌గా i++ ఇంక్రిమెంట్‌కు వెళ్తుంది. కానీ while లూప్‌లో ఇంక్రిమెంట్ బాడీ చివర ఉంటే, continue వల్ల ఆ ఇంక్రిమెంట్ లైన్ ఎప్పటికీ రన్ కాక ప్రోగ్రామ్ ఇన్ఫినిట్ లూప్‌లో ఇరుక్కుపోతుంది! కాబట్టి continue కి ముందే ఇంక్రిమెంట్ చేయాలి.

3నెస్టెడ్ లూప్స్ (Nested Loops) & 2D గ్రిడ్ ప్రాసెసింగ్

ఒక లూప్ లోపల మరొక లూప్ ఉండడాన్ని నెస్టెడ్ లూప్ (Nested Loop) అంటారు. బయటి లూప్ (Outer Loop) అడ్డు వరుసలను (Rows) నియంత్రిస్తే, లోపలి లూప్ (Inner Loop) నిలువు వరుసలను (Columns) నియంత్రిస్తుంది:

C# — Right-Angled Star Pyramid ⚡ Try in C# Compiler 
int totalRows = 5;

for (int r = 1; r <= totalRows; r++) {
    // లోపలి లూప్: ప్రతి వరుసలో నక్షత్రాలను ముద్రించడం
    for (int c = 1; c <= r; c++) {
        Console.Write("* ");
    }
    Console.WriteLine(); // వరుస పూర్తయిన తర్వాత కొత్త లైన్‌కు వెళ్లడం
}

💡 నెస్టెడ్ లూప్స్ యొక్క టైమ్ కాంప్లెక్సిటీ సాధారణంగా $O(N imes M)$ లేదా $O(N^2)$ అవుతుంది. కాబట్టి 3 లేదా 4 స్థాయిల కంటే ఎక్కువ నెస్టెడ్ లూప్స్ రాయడం పర్ఫార్మెన్స్‌కు హానికరం.

4నెస్టెడ్ లూప్స్ నుండి ఒకేసారి బయటకు రావడం (Multi-Loop Break)

చాలామంది బిగినర్స్ break రాస్తే అన్ని నెస్టెడ్ లూప్స్ నుండి బయటకు వచ్చేస్తుందని అనుకుంటారు. కానీ break కేవలం తాను ఉన్న అత్యంత సమీపంలోని ఇన్నర్ లూప్‌ను మాత్రమే ఆపుతుంది; బయటి లూప్ నడుస్తూనే ఉంటుంది.

✅ ప్రొఫెషనల్ సొల్యూషన్: Method Return టెక్నిక్

సంక్లిష్టమైన నెస్టెడ్ లూప్స్ లో టార్గెట్ దొరకగానే అన్ని లూప్స్ నుండి ఒకేసారి శాశ్వతంగా బయటకు రావడానికి ఆ లాజిక్‌ను ఒక ప్రత్యేక ప్రైవేట్ మెథడ్‌లో ఉంచి నేరుగా return; చేయడం అత్యంత క్లీన్, ఆధునిక సాఫ్ట్‌వేర్ పద్ధతి.

5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. ఇన్నర్ మరియు ఔటర్ లూప్‌లలో ఒకే వేరియబుల్ వాడటం:
for (int i = 0; ... ) { for (int i = 0; ... ) } // Compiler Error! A local variable named 'i' cannot be declared in this scope C# వేరియబుల్ స్కోప్‌లను కఠినంగా రక్షిస్తుంది. ఔటర్ లూప్‌కు i వాడితే, ఇన్నర్ లూప్‌కు j లేదా r, c (Row, Column) అని వేర్వేరు పేర్లు ఇవ్వాలి.
❌ 2. లూప్‌లను దాటవేయడానికి విచ్చలవిడిగా goto వాడటం:
goto స్టేట్‌మెంట్ వాడితే కోడ్ స్పఘెట్టి (Spaghetti code) లా మారి డీబగ్గింగ్ అసాధ్యం అవుతుంది. స్ట్రక్చర్డ్ లూప్స్ (break, return) మాత్రమే వాడాలి.
6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: Environment.Exit(0) మరియు break ల మధ్య తేడా ఏమిటి?

break కేవలం ఆ నిర్దిష్ట లూప్ నుండి మాత్రమే బయటకు తెస్తుంది; ప్రోగ్రామ్‌లోని మిగిలిన కోడ్ కొనసాగుతుంది. కానీ Environment.Exit(0) మొత్తం అప్లికేషన్‌ను అక్కడికక్కడే మూసివేసి ఆపరేటింగ్ సిస్టమ్‌కు కంట్రోల్‌ను తిరిగి ఇస్తుంది.

Q: for (;;) మరియు while (true) లలో ఏది రాయడం మంచిది?

రెండు సమానమైన IL బైట్‌కోడ్‌ను ఉత్పత్తి చేస్తాయి. అయితే రీడబిలిటీ (చదవడానికి స్పష్టత) పరంగా C# లో while (true) రాయడమే మోడ్రన్ కోడింగ్ స్టాండర్డ్.
