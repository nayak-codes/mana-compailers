స్ట్రింగ్స్, ఇమ్యుటబిలిటీ & StringBuilder ఆప్టిమైజేషన్

⚡ Modern C# 12 & .NET 8 🟢 Chapter 10 of 20 📂 Phase 03: మెథడ్స్, స్ట్రింగ్స్ & కలెక్షన్స్ 📅 2026 Edition
📌 Covered in this chapter: String Immutability & String Pool · String Interpolation ($) · StringBuilder హై-పెర్ఫార్మెన్స్ లూప్స్ · Raw String Literals (""")
సాఫ్ట్‌వేర్ డెవలప్‌మెంట్‌లో టెక్స్ట్ డేటాను నిర్వహించడం అత్యంత సాధారణమైన టాస్క్. C# లో string అనేది Reference Type అయినప్పటికీ, దీనికి Immutability (మార్చలేని స్వభావం) ఉంటుంది. భారీ లూపుల్లో స్ట్రింగ్స్ కలిపినప్పుడు మెమరీ ఓవర్‌హెడ్ లేకుండా ఉండటానికి .NET లో StringBuilder ని ఎలా వాడాలో, మోడరన్ C# లో స్ట్రింగ్ ఇంటర్‌పోలేషన్, వెర్బాటిమ్ స్ట్రింగ్స్ మరియు Span<char> పనితీరును ఈ అధ్యాయంలో విశదీకరిస్తాం.
1 String Immutability & Heap మెమరీ పనితీరు

C# లో స్ట్రింగ్ ఆబ్జెక్ట్ ఒకసారి క్రియేట్ అయిన తర్వాత దాని కంటెంట్‌ను మార్చడం అసాధ్యం. మీరు ఏదైనా స్ట్రింగ్ మెథడ్ (ఉదాహరణకు .ToUpper() లేదా str += "!") వాడినప్పుడు, ఉన్న స్ట్రింగ్ మారదు; బదులుగా మేనేజ్డ్ హీప్ (Heap) పై సరికొత్త స్ట్రింగ్ ఆబ్జెక్ట్ సృష్టించబడుతుంది.

String Interning Pool: మెమరీ ఆదా చేయడానికి CLR ఒకే విధమైన లిటరల్ స్ట్రింగ్స్ (ఉదాహరణకు "Hello") కోసం ఒక ప్రత్యేక ఇంటర్న్ పూల్ నిర్వహిస్తుంది. కోడ్‌లో ఎన్ని చోట్ల "Hello" అని రాసినా అవన్నీ హీప్‌లోని ఒకే మెమరీ అడ్రస్‌ను పాయింట్ చేస్తాయి.

StringImmutability.cs ⚡ Try in C# Compiler 
using System;

class Program
{
    static void Main()
    {
        string s1 = "Hyderabad";
        string s2 = s1; // Both point to the same memory
        
        s1 += ", India"; // Creates a brand new string on Heap!
        
        Console.WriteLine($"s1: {s1}"); // "Hyderabad, India"
        Console.WriteLine($"s2: {s2}"); // "Hyderabad" (Unchanged!)
        
        // Checking reference equality
        Console.WriteLine($"Are references equal? {object.ReferenceEquals(s1, s2)}");
    }
}
2 Modern String Interpolation ($), Verbatim (@) & Raw Strings (""")

C# లో స్ట్రింగ్స్ రాయడానికి మూడు ఆధునిక విధానాలు ఉన్నాయి:

  • String Interpolation ($""): కర్లీ బ్రేసెస్ లోపల వేరియబుల్స్ లేదా ఎక్స్‌ప్రెషన్స్‌ను నేరుగా పొందుపరచవచ్చు. ఫార్మాట్ స్పెసిఫైయర్స్ (ఉదా: {val:C2} కరెన్సీ కోసం, {val:F2} డెసిమల్ కోసం) మద్దతు ఇస్తుంది.
  • Verbatim Strings (@""): ఎస్కేప్ సీక్వెన్సెస్ (ఉదా: , ) ని ఇగ్నోర్ చేస్తుంది. ఫైల్ పాత్‌లు మరియు రెగ్యులర్ ఎక్స్‌ప్రెషన్స్ రాయడానికి అనువైనది.
  • Raw String Literals (""" C# 11+): డబుల్ కోట్స్ మరియు మల్టీ-లైన్ టెక్స్ట్‌లను (ముఖ్యంగా JSON, SQL లేదా HTML) ఎటువంటి ఎస్కేపింగ్ లేకుండా రాయడానికి ఇది ఉత్తమమైన పద్ధతి.
StringFormats.cs ⚡ Try in C# Compiler 
using System;

class Program
{
    static void Main()
    {
        string name = "Sita";
        decimal balance = 12500.75m;
        
        // 1. Interpolated String with Formatting
        Console.WriteLine($"Customer: {name}, Balance: {balance:C}");
        
        // 2. Verbatim String (No escaping needed for backslashes)
        string filePath = @"C:UsersBalajiDocuments
eport.pdf";
        Console.WriteLine($"Path: {filePath}");
        
        // 3. Raw String Literal (C# 11+) for Clean JSON
        string json = """
        {
            "id": 101,
            "title": "C# Masterclass",
            "active": true
        }
        """;
        Console.WriteLine(json);
    }
}
3 StringBuilder vs String Concatenation: పెర్ఫార్మెన్స్ విశ్లేషణ

ఒక లూప్ లోపల += ఆపరేటర్ వాడి వందలాది సార్లు స్ట్రింగ్స్ కలిపితే, ప్రతి ఐటరేషన్‌లోనూ పాత స్ట్రింగ్ కాపీ చేయబడి కొత్త ఆబ్జెక్ట్ సృష్టించబడుతుంది. దీనివల్ల O(N²) మెమరీ అలొకేషన్స్ జరిగి గార్బేజ్ కలెక్టర్ (GC) పై విపరీతమైన భారం పడుతుంది.

దీనికి పరిష్కారమే System.Text.StringBuilder. ఇది ఒక మ్యూటబుల్ (మార్చదగిన) ఇంటర్నల్ బఫర్‌ను నిర్వహిస్తుంది. కాబట్టి కొత్త ఆబ్జెక్ట్స్ క్రియేట్ అవ్వకుండా ఉన్న బఫర్‌లోనే క్యారెక్టర్స్ అపెండ్ అవుతాయి.

StringBuilderBenchmark.cs ⚡ Try in C# Compiler 
using System;
using System.Text;

class Program
{
    static void Main()
    {
        // Recommended for loops: StringBuilder
        StringBuilder sb = new StringBuilder();
        sb.Append("List of IDs: ");
        
        for (int i = 1; i <= 5; i++)
        {
            sb.Append(i).Append(i < 5 ? ", " : ".");
        }
        
        string result = sb.ToString();
        Console.WriteLine(result);
    }
}
గోల్డెన్ రూల్: 3-4 స్ట్రింగ్స్ సాధారణంగా కలపడానికి స్ట్రింగ్ ఇంటర్‌పోలేషన్ $"{a} {b}" వాడండి. కానీ లూపుల్లో (లూప్ 5 కంటే ఎక్కువ సార్లు తిరిగితే) ఎల్లప్పుడూ StringBuilder వాడాలి.
4 నిత్యజీవితంలో వాడే ముఖ్యమైన String మెథడ్స్

వాస్తవ ప్రాజెక్టులలో డేటా క్లీనింగ్ మరియు పార్సింగ్ కోసం C# అనేక శక్తివంతమైన ఇన్-బిల్ట్ మెథడ్స్ అందిస్తుంది:

StringMethodsDemo.cs ⚡ Try in C# Compiler 
using System;

class Program
{
    static void Main()
    {
        string rawInput = "  kiran@gmail.com, suresh@yahoo.com, rani@outlook.com  ";
        
        // 1. Trim: Whitespace తొలగింపు
        string cleaned = rawInput.Trim();
        
        // 2. Split: అరేగా విభజించడం
        string[] emails = cleaned.Split(new string[] { ", " }, StringSplitOptions.RemoveEmptyEntries);
        
        foreach (string email in emails)
        {
            // 3. Case-Insensitive Search
            if (email.Contains("GMAIL", StringComparison.OrdinalIgnoreCase))
            {
                Console.WriteLine($"Found Gmail user: {email.ToUpper()}");
            }
        }

        // 4. Join: అరే ఎలిమెంట్స్ ను ఒకే స్ట్రింగ్ గా కలపడం
        string joined = string.Join(" | ", emails);
        Console.WriteLine($"Joined: {joined}");
    }
}
5 Span<char> & Zero-Allocation టెక్నిక్ అవలోకనం

.NET Core మరియు .NET 8 ప్రపంచంలో అత్యంత వేగవంతమైన రన్‌టైమ్‌గా నిలవడానికి గల ముఖ్య కారణాలలో ReadOnlySpan<char> ఒకటి. సాధారణంగా str.Substring(0, 5) వాడితే హీప్‌పై కొత్త సబ్‌స్ట్రింగ్ ఆబ్జెక్ట్ ఏర్పడుతుంది. కానీ ReadOnlySpan వాడితే మెమరీని కాపీ చేయకుండా అసలు స్ట్రింగ్‌లోని నిర్దిష్ట క్యారెక్టర్ల భాగానికి కేవలం ఒక విండో (view) ను మాత్రమే అందిస్తుంది (Zero Allocation!).

SpanDemo.cs ⚡ Try in C# Compiler 
using System;

class Program
{
    static void Main()
    {
        string dateStr = "2026-10-30";
        
        // Creating spans without allocating memory on Heap
        ReadOnlySpan span = dateStr.AsSpan();
        ReadOnlySpan year = span.Slice(0, 4);
        ReadOnlySpan month = span.Slice(5, 2);
        ReadOnlySpan day = span.Slice(8, 2);
        
        Console.WriteLine($"Year: {year.ToString()}, Month: {month.ToString()}, Day: {day.ToString()}");
    }
}
6 బిగినర్ తప్పులు & ఇంటర్వ్యూ FAQ
⚠️ ప్రమాదకరమైన తప్పు: Case Sensitivity మరియు Culture పరిగణించకపోవడం
str1.ToLower() == str2.ToLower() అని రాయడం వల్ల రెండు కొత్త స్ట్రింగ్స్ హీప్‌పై క్రియేట్ అవుతాయి. దానికి బదులుగా ఎల్లప్పుడూ string.Equals(str1, str2, StringComparison.OrdinalIgnoreCase) వాడటం ద్వారా పెర్ఫార్మెన్స్ పెరుగుతుంది మరియు అనవసర మెమరీ వేస్ట్ కాదు.

తరచుగా అడిగే ప్రశ్నలు (FAQ):

  • String మరియు StringBuilder మధ్య తేడా ఏమిటి?
    String ఇమ్మ్యూటబుల్ (మార్చలేము), ఏదైనా మార్పు చేస్తే కొత్త ఆబ్జెక్ట్ తయారవుతుంది. StringBuilder మ్యూటబుల్, ఇప్పటికే ఉన్న బఫర్‌లోనే క్యారెక్టర్లను మారుస్తుంది.
  • String Interning అంటే ఏమిటి?
    ఒకే విధమైన స్ట్రింగ్ లిటరల్స్‌ను CLR ఒక ప్రత్యేక టేబుల్‌లో భద్రపరిచి, మెమరీ ఆదా చేయడానికి అన్ని రిఫరెన్సులకు అదే అడ్రస్‌ను షేర్ చేస్తుంది.
