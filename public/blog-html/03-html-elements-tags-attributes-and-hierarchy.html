ఎలిమెంట్స్, ట్యాగ్స్, గ్లోబల్ అట్రిబ్యూట్స్ & DOM హైరార్కీ

🌐 Modern HTML5 (W3C/WHATWG) 🟢 Chapter 3 of 20 📂 Phase 01: HTML5 పునాదులు & ఆర్కిటెక్చర్ 📅 2026 Edition
📌 Covered in this chapter: HTML ఎలిమెంట్ vs ట్యాగ్ వ్యత్యాసం · Void Elements (స్వీయ-ముగింపు ట్యాగ్‌లు) · Global Attributes (id, class, style, title, hidden, tabindex) · Custom Data Attributes (data-*) · DOM Tree & నెస్టెడ్ పేరెంట్-చైల్డ్ రిలేషన్‌షిప్స్ · లైవ్ ఎడిటర్ కోడింగ్ · బిగినర్స్ తప్పులు & క్విజ్

మీరు ఎప్పుడైనా చిన్నప్పుడు లెగో బ్రిక్స్ (Lego Blocks) తో అందమైన ఇల్లు లేదా కారు బొమ్మను నిర్మించారా? చిన్న చిన్న ప్లాస్టిక్ ముక్కలను ఒకదానిలో ఒకటి పద్ధతిగా బిగిస్తూ పోతే చివరకు ఒక అద్భుతమైన భారీ భవంతి రూపుదిద్దుకుంటుంది కదా!

వెబ్ డెవలప్‌మెంట్ ప్రపంచంలో కూడా సరిగ్గా ఇదే జరుగుతుంది. ఒక వెబ్‌పేజీలో కనిపించే ప్రతి హెడ్డింగ్, బటన్, ఇమేజ్, పేరాగ్రాఫ్ అన్నీ ఒక్కొక్క "HTML Element" అనే లెగో బ్రిక్ లాంటివి. కానీ ఆ బ్రిక్స్‌కి ప్రత్యేకమైన గుర్తింపు ఇవ్వడానికి (ఆధార్ కార్డ్ నంబర్ లాంటి id, గ్రూప్ పేరు లాంటి class), రంగులు అద్దడానికి (style), మరియు గుప్త సమాచారాన్ని దాచడానికి (data-*) మనం Attributes (లక్షణాలు) ని ఉపయోగిస్తాం.

ఈ మూడవ అధ్యాయంలో మనం ట్యాగ్స్ కి ఎలిమెంట్స్ కి మధ్య ఉన్న సూక్ష్మమైన తేడాలను, బ్రౌజర్ మెమరీలో రూపుదిద్దుకునే DOM Tree (కుటుంబ వృక్ష వ్యవస్థ: Parents, Children, Siblings), మరియు జావాస్క్రిప్ట్/CSS లకు ప్రాణవాయువైన గ్లోబల్ ఆట్రిబ్యూట్లను పూర్తి తెలుగులో, ప్రాక్టికల్ లైవ్ కోడింగ్‌తో నేర్చుకుందాం!

1ఈ Chapter లో మీరు నేర్చుకునే అంశాలు
  • ట్యాగ్ vs ఎలిమెంట్: చాలామంది కన్‌ఫ్యూజ్ అయ్యే ఈ రెండు పదాల మధ్య ఉన్న ఖచ్చితమైన సాంకేతిక వ్యత్యాసం.
  • Void Elements (స్వీయ-ముగింపు ట్యాగ్‌లు): క్లోజింగ్ ట్యాగ్ అవసరం లేని ప్రత్యేక ఎలిమెంట్స్ (br, hr, img, input, meta).
  • Global Attributes నిఘంటువు: HTML లోని ప్రతి ఎలిమెంట్‌కి ఉపయోగించగల సార్వత్రిక లక్షణాలు (id, class, style, title, hidden, tabindex, contenteditable).
  • id vs class సమగ్ర పోలిక: ఎప్పుడు ఏది వాడాలి? CSS మరియు JavaScript పాయింట్ ఆఫ్ వ్యూలో బెస్ట్ ప్రాక్టీసెస్.
  • Custom Data Attributes (data-*): వెబ్‌పేజీలో జావాస్క్రిప్ట్ కోసం అదనపు సమాచారాన్ని భద్రపరిచే ఆధునిక పద్ధతి.
  • DOM Tree ఆర్కిటెక్చర్: బ్రౌజర్ HTML కోడ్‌ను తల్లిదండ్రులు-పిల్లల (Parent-Child) చెట్టుగా ఎలా మారుస్తుంది?
  • బిగినర్స్ సాధారణ పొరపాట్లు & క్విజ్: డూప్లికేట్ ఐడీలు, స్పేస్ బగ్స్ మరియు ఇంటర్వ్యూ ప్రశ్నలకు సమాధానాలు.
2ట్యాగ్ (Tag) vs ఎలిమెంట్ (Element) — అసలు తేడా ఏమిటి?

వెబ్ డెవలప్‌మెంట్ ఇంటర్వ్యూలలో అడిగే అత్యంత ప్రాథమిక ప్రశ్న ఇది. చాలామంది ట్యాగ్ అన్నా ఎలిమెంట్ అన్నా ఒకటే అనుకుంటారు, కానీ రెండింటికీ స్పష్టమైన తేడా ఉంది:

🏷️ HTML Tag (ట్యాగ్)

కోణీయ బ్రాకెట్ల (< >) లోపల ఉండే పదాన్ని మాత్రమే ట్యాగ్ అంటారు. ప్రారంభంలో ఉండేది Opening Tag (ఉదా: <p>), చివర స్లాష్‌తో ముగిసేది Closing Tag (ఉదా: </p>). ట్యాగ్ అనేది కేవలం ఒక గుర్తు మాత్రమే.

🧱 HTML Element (ఎలిమెంట్)

ప్రారంభ ట్యాగ్ + అందులోని ఆట్రిబ్యూట్స్ + మధ్యలోని కంటెంట్ + ముగింపు ట్యాగ్ — ఈ సమగ్ర ప్యాకేజీని Element అంటారు. ఉదాహరణకు: <p class="lead">నమస్కారం!</p> అనేది ఒక సంపూర్ణ పేరాగ్రాఫ్ ఎలిమెంట్.

3సాధారణ ఎలిమెంట్స్ vs వాయిడ్ ఎలిమెంట్స్ (Normal vs Void Elements)

HTML5 లో ఎలిమెంట్స్ రెండు ప్రధాన వర్గాలుగా ఉంటాయి:

  1. కంటెంట్ ఉన్న సాధారణ ఎలిమెంట్స్ (Container Elements): వీటికి తప్పనిసరిగా ఓపెనింగ్ ట్యాగ్ మరియు క్లోజింగ్ ట్యాగ్ రెండూ ఉంటాయి. వాటి మధ్యలో టెక్స్ట్ లేదా ఇతర ఎలిమెంట్స్ ఉంటాయి. ఉదాహరణకు: <h1>..</h1>, <p>..</p>, <button>..</button>, <div>..</div>.
  2. Void Elements (స్వీయ-ముగింపు / ఖాళీ ఎలిమెంట్స్): వీటికి ఎలాంటి కంటెంట్ ఉండదు. కాబట్టి వీటికి ముగింపు ట్యాగ్ (Closing Tag) రాయాల్సిన అవసరమే లేదు!
Void Element వాడే విధానం బ్రౌజర్‌లో అసలు ఏం చేస్తుంది?
<br> టెక్స్ట్ లైన్ 1 <br> టెక్స్ట్ లైన్ 2 లైన్ బ్రేక్ — టెక్స్ట్‌ను తర్వాతి లైన్‌కు పంపుతుంది (Enter కీ లాంటిది).
<hr> <hr> క్షితిజ సమాంతర విభజన రేఖ (Horizontal Thematic Break Line) గీస్తుంది.
<img> <img src="pic.jpg" alt="ఫోటో"> బాహ్య చిత్రాన్ని పేజీలో పొందుపరుస్తుంది.
<input> <input type="text" placeholder="పేరు"> యూజర్ డేటా ఎంటర్ చేయడానికి ఇన్‌పుట్ బాక్స్‌ను సృష్టిస్తుంది.
<meta> <meta charset="UTF-8"> బ్రౌజర్ కోసం డాక్యుమెంట్ మెటాడేటాను అందిస్తుంది.
💡 HTML5 లో స్వీయ-ముగింపు స్లాష్ (<br />) అవసరమా?

పాతకాలపు XHTML లో <br /> లేదా <img /> అని చివర స్లాష్ పెట్టడం తప్పనిసరిగా ఉండేది. కానీ ఆధునిక HTML5 ప్రమాణాల ప్రకారం స్లాష్ పూర్తిగా ఆప్షనల్. మీరు కేవలం <br>, <hr>, <img> అని రాస్తే సరిపోతుంది. ఇది మరింత క్లీన్ మరియు వేగవంతం!

4గ్లోబల్ ఆట్రిబ్యూట్స్ నిఘంటువు (Global Attributes Architecture)

HTML లో కొన్ని ఆట్రిబ్యూట్లు నిర్దిష్ట ఎలిమెంట్లకు మాత్రమే పరిమితం (ఉదాహరణకు src కేవలం <img> కి, href కేవలం <a> కి మాత్రమే ఉంటాయి). కానీ గ్లోబల్ ఆట్రిబ్యూట్స్ (Global Attributes) ను HTML లోని ఏ ఎలిమెంట్‌కైనా నిర్భయంగా ఉపయోగించవచ్చు:

గ్లోబల్ ఆట్రిబ్యూట్ సింటాక్స్ ఉదాహరణ వాస్తవ వెబ్ అప్లికేషన్లలో ఉపయోగం
id id="header-nav" పేజీ మొత్తంలో ఏకైక ప్రత్యేక గుర్తింపు (Unique ID). CSS & JS లో నేరుగా టార్గెట్ చేయడానికి.
class class="btn btn-primary" ఎలిమెంట్లను గ్రూపింగ్ చేయడానికి. ఒకే క్లాస్‌ను వందలాది ఎలిమెంట్లకు పునర్వినియోగించవచ్చు.
title title="ఇక్కడ క్లిక్ చేయండి" యూజర్ మౌస్ కర్సర్‌ను ఎలిమెంట్‌పై ఉంచినప్పుడు (Hover) చిన్న వివరణ టూల్‌టిప్ చూపిస్తుంది.
style style="color: green; font-size: 16px;" నేరుగా ఆ ఎలిమెంట్‌పై మాత్రమే పని చేసే ఇన్‌లైన్ CSS నియమాలు.
hidden <p hidden>రహస్యం</p> ఎలిమెంట్‌ను బ్రౌజర్ స్క్రీన్ మీద నుండి అదృశ్యం చేస్తుంది (CSS display: none సమానం).
tabindex tabindex="1" కీబోర్డ్‌లోని Tab కీ నొక్కినప్పుడు నావిగేషన్ ఫోకస్ ఏ క్రమంలో వెళ్లాలో నిర్ణయిస్తుంది (a11y).
contenteditable <p contenteditable="true"> వెబ్‌పేజీలోని టెక్స్ట్‌ను యూజర్ నేరుగా బ్రౌజర్‌లోనే క్లిక్ చేసి ఎడిట్ చేసేలా మారుస్తుంది!
5id vs class — ఎప్పుడు ఏది వాడాలి?

ఇది వెబ్ డెవలప్‌మెంట్‌లో అత్యంత ప్రధానమైన డిజైన్ నిర్ణయం. దీనిని ఒక కాలేజీ లేదా ఆఫీస్ ఉదాహరణతో గుర్తుపెట్టుకోవచ్చు:

🏢 రియల్ వరల్డ్ అనాలజీ:
• ID (ఆధార్ కార్డు / రోల్ నంబర్ లాంటిది): ఒక కాలేజీలో ఒక రోల్ నంబర్ ఒక్క విద్యార్థికి మాత్రమే ఉంటుంది. ఇద్దరు విద్యార్థులకు ఒకే రోల్ నంబర్ ఉండకూడదు. అలాగే ఒక వెబ్‌పేజీలో ఒక id కేవలం ఒక్క ఎలిమెంట్‌కు మాత్రమే ఉండాలి!
• Class (బ్రాంచ్ లేదా యూనిఫాం లాంటిది): కాలేజీలో "Computer Science" బ్రాంచ్‌లో వందలాది విద్యార్థులు ఉండవచ్చు. అందరికీ ఒకే యూనిఫాం రూల్ వర్తిస్తుంది. అలాగే ఒకే class పేరును పేజీలోని వందలాది బటన్లకు, కార్డ్స్‌కు ఇవ్వవచ్చు.

ఫీచర్ ID (#) Class (.)
పేజీలో ఎన్నిసార్లు వాడవచ్చు? ఒక పేజీలో ఒక్కసారి మాత్రమే (Unique). ఎన్నిసార్లయినా, ఎన్ని ఎలిమెంట్లకైనా వాడవచ్చు (Reusable).
ఒక ఎలిమెంట్‌కు ఎన్ని ఉండవచ్చు? ఒక్కటే ID ఉండాలి. స్పేస్ ఇచ్చి మల్టిపుల్ క్లాసులు ఇవ్వవచ్చు: class="card dark shadow".
CSS సెలెక్టర్ గుర్తు హ్యాష్ ట్యాగ్: #main-header { ... } డాట్ గుర్తు: .btn { ... }
JavaScript సెలెక్టర్ document.getElementById("main-header") document.querySelectorAll(".btn")
6Custom Data Attributes (data-*) — జావాస్క్రిప్ట్ బ్రిడ్జ్

HTML5 రాకముందు డెవలపర్లు బటన్ లేదా డివ్ లో అదనపు సమాచారాన్ని (ఉదాహరణకు ప్రొడక్ట్ ప్రైస్, యూజర్ ఐడీ) దాచడానికి అక్రమంగా క్లాస్ పేర్లలోనో లేదా అనధికార ఆట్రిబ్యూట్లలోనో రాసేవారు. ఇది వ్యాలిడేషన్ ఎర్రర్లకు దారితీసేది.

దీన్ని శాశ్వతంగా పరిష్కరించడానికి HTML5 లో Custom Data Attributes (data-*) ని ప్రవేశపెట్టారు. data- తర్వాత మీరు మీకు నచ్చిన పేరు పెట్టుకోవచ్చు:

HTML5 Custom Data 
<!-- ఇ-కామర్స్ ప్రొడక్ట్ కార్డులో కస్టమ్ డేటా దాచడం -->
<div class="product-card" 
     data-product-id="4501" 
     data-price="1499" 
     data-category="electronics"
     data-in-stock="true">
  <h3>వైర్‌లెస్ హెడ్‌ఫోన్స్</h3>
  <p>ధర: ₹1,499</p>
  <button class="buy-btn">కార్ట్‌కు జోడించండి</button>
</div>

JavaScript లో దీనిని ఎలా సులభంగా చదువుతారో చూడండి:

JavaScript Dataset API 
const card = document.querySelector(".product-card");

// dataset ప్రాపర్టీ ద్వారా నేరుగా వేల్యూలను పొందవచ్చు!
console.log(card.dataset.productId);  // Output: "4501"
console.log(card.dataset.price);      // Output: "1499"
console.log(card.dataset.category);   // Output: "electronics"

ఈ టెక్నిక్ ఉపయోగించి వెబ్ డెవలపర్లు బ్యాకెండ్ డేటాను ఫ్రంట్-ఎండ్ బటన్లు మరియు కార్డ్స్‌లో సురక్షితంగా అనుసంధానిస్తారు.

7DOM Tree ఆర్కిటెక్చర్ — నెస్టెడ్ ఫ్యామిలీ హైరార్కీ

బ్రౌజర్ మీ HTML ఫైల్‌ను చదివినప్పుడు, అది లోపల ఒక కుటుంబ వృక్షం (Family Tree) లాంటి నెస్టెడ్ నిర్మాణాన్ని సృష్టిస్తుంది. దీనినే DOM (Document Object Model) Tree అంటారు.

ఇందులో ప్రతి ఎలిమెంట్‌కు కుటుంబ సంబంధాలు ఉంటాయి:

┌──────────────┐ │ <html> │ ── Root Element (ముత్తాత) └──────┬───────┘ ┌────────┴────────┐ │ │ ┌───────▼──────┐ ┌──────▼──────┐ │ <head> │ │ <body> │ ── Siblings (తోబుట్టువులు) └───────┬──────┘ └──────┬──────┘ │ │ ┌──────▼──────┐ ┌──────┴──────────────┐ │ <title> │ │ │ └─────────────┘ ┌─▼──────────┐ ┌──────▼──────┐ │ <header> │ │ <main> │ ── Siblings └─────┬──────┘ └──────┬──────┘ │ │ ┌─────▼──────┐ ┌──────▼──────┐ │ <h1> │ │ <p> │ ── Children └────────────┘ └─────────────┘
  • Parent (తల్లి లేదా తండ్రి): మరొక ఎలిమెంట్‌ను నేరుగా తన కడుపులో ఉంచుకున్నది. పైన చిత్రంలో <body> అనేది <header> మరియు <main> లకు Parent.
  • Child (బిడ్డ / సంతానం): Parent లోపల నేరుగా ఉన్న ఎలిమెంట్. <h1> అనేది <header> కు Child.
  • Siblings (తోబుట్టువులు): ఒకే Parent ను పంచుకునే పక్కపక్క ఎలిమెంట్స్. <head> మరియు <body> తోబుట్టువులు.
  • Ancestor (పూర్వీకులు): ఒక ఎలిమెంట్‌కి పైన ఉండే Parents, Grandparents అందరూ పూర్వీకులే. <html> అందరికీ Ancestor.
  • Descendants (వంశజులు): ఒక ఎలిమెంట్ లోపల ఎన్ని తరాలైనా కింద ఉన్న అన్ని ఎలిమెంట్స్ దాని Descendants అవుతాయి.

9Beginners చేసే 5 ప్రధాన తప్పులు (Common Pitfalls)

ఎలిమెంట్స్ మరియు ఆట్రిబ్యూట్లతో పనిచేసేటప్పుడు బిగినర్స్ తరచుగా చేసే 5 తీవ్రమైన తప్పులు:

❌ తప్పు 1: పేజీలో ఒకే ID ని రెండు వేర్వేరు ఎలిమెంట్లకు ఇవ్వడం (Duplicate ID)

<!-- తీవ్రమైన తప్పు: ఇద్దరికీ ఒకే id ఇచ్చారు -->
<button id="submit-btn">మొదటి బటన్</button>
<button id="submit-btn">రెండవ బటన్</button>

సమస్య: JavaScript లో document.getElementById("submit-btn") అని రాసినప్పుడు బ్రౌజర్ ఎల్లప్పుడూ మొదటి బటన్‌ను మాత్రమే తీసుకుంటుంది. రెండవ బటన్‌ను పట్టించుకోదు! ఒకే రకమైన స్టైల్స్ కావాలంటే class="submit-btn" వాడాలి.

❌ తప్పు 2: క్లాస్ పేర్లలో పొరపాటున స్పేస్‌లు ఇవ్వడం

<!-- డెవలపర్ అనుకున్నది ఒకే క్లాస్, కానీ బ్రౌజర్ 2 క్లాసులుగా భావిస్తుంది! -->
<div class="card header">...</div>

నియమం: క్లాస్ పేర్లలో స్పేస్ ఇస్తే అది రెండు వేర్వేరు క్లాసులు (card మరియు header) అవుతాయి. ఒకే క్లాస్ కోసం హైఫన్ వాడాలి: class="card-header".

❌ తప్పు 3: Void Elements కి క్లోజింగ్ ట్యాగ్ రాయడం

<!-- తప్పు: img మరియు br కి క్లోజింగ్ ట్యాగ్స్ ఉండవు -->
<img src="logo.png"></img>
<br></br>

సరైన రూపం: కేవలం <img src="logo.png" alt="లోగో"> మరియు <br> అని రాస్తే చాలు.

❌ తప్పు 4: ఆట్రిబ్యూట్ విలువలకు కొటేషన్స్ (Quotes) మర్చిపోవడం

<h1 title=నా మొదటి పేజీ> అని రాస్తే స్పేస్ వల్ల మొదటి పదం మాత్రమే టైటిల్‌గా మారుతుంది. ఎల్లప్పుడూ కొటేషన్స్ వాడాలి: <h1 title="నా మొదటి పేజీ">.

❌ తప్పు 5: నెస్టెడ్ ట్యాగ్స్ ఓవర్‌ల్యాప్ చేయడం (Cross-Nesting Bug)

<p><span>హలో</p></span> అని పొరపాటున రాస్తే DOM ట్రీ బ్రేక్ అవుతుంది. లోపల ఓపెన్ చేసిన ట్యాగ్‌ను లోపలే క్లోజ్ చేయాలి: <p><span>హలో</span></p>.

10ప్రాక్టీస్ టాస్క్స్ & ఇంటర్వ్యూ క్విజ్ ప్రశ్నలు

ఈ క్రింది ప్రశ్నలకు స్వయంగా సమాధానాలు రాసి చూడండి, ఆపై డ్రాప్‌డౌన్ తెరిచి పరిశీలించండి:

  1. ట్యాగ్ (Tag) మరియు ఎలిమెంట్ (Element) మధ్య ప్రాథమిక వ్యత్యాసం ఏమిటి? ఒక ఉదాహరణతో వివరించండి.
  2. ఒక వెబ్‌పేజీలో ఒకే id ని రెండు ఎలిమెంట్లకు ఇస్తే ఏం జరుగుతుంది? బ్రౌజర్ ఎర్రర్ చూపిస్తుందా?
  3. Void Elements అంటే ఏమిటి? కనీసం 4 Void Elements పేర్లు చెప్పండి.
  4. data-* ఆట్రిబ్యూట్లను ఎందుకు వాడతారు? JavaScript లో వాటిని ఏ ప్రాపర్టీ ద్వారా యాక్సెస్ చేస్తారు?
  5. DOM Tree లో Parent, Child మరియు Siblings అనగా ఏమిటి?

1. సమాధానం: <p> అనేది కేవలం ఓపెనింగ్ ట్యాగ్. కానీ <p>కంటెంట్</p> మొత్తం కలిపి ఒక Element అవుతుంది. ప్రారంభ ట్యాగ్ + ఆట్రిబ్యూట్స్ + కంటెంట్ + ముగింపు ట్యాగ్ = ఎలిమెంట్.

2. సమాధానం: HTML లో బ్రౌజర్ ఎర్రర్ చూపించదు (Silent failure). కానీ JavaScript లో getElementById() మొదటి ఎలిమెంట్‌ను మాత్రమే పట్టుకుంటుంది, రెండవది పనిచేయదు. అలాగే W3C వాలిడేషన్ ఫెయిల్ అవుతుంది.

3. సమాధానం: ఎలాంటి కంటెంట్ మరియు క్లోజింగ్ ట్యాగ్ అవసరం లేని ఎలిమెంట్లను Void Elements అంటారు. ఉదాహరణలు: <br>, <hr>, <img>, <input>, <meta>, <link>.

4. సమాధానం: HTML ఎలిమెంట్లలో అదనపు కస్టమ్ సమాచారాన్ని భద్రపరచడానికి వాడతారు. JavaScript లో element.dataset ప్రాపర్టీ ద్వారా నేరుగా యాక్సెస్ చేయవచ్చు.

5. సమాధానం: మరొక ఎలిమెంట్‌ను నేరుగా తన లోపల ఉంచుకున్నది Parent, దాని లోపల ఉన్నది Child. ఒకే Parent లోపల పక్కపక్కనే ఉండే ఎలిమెంట్స్ తోబుట్టువులు (Siblings).

12సారాంశం (Quick Summary)
  • Element: Opening tag + Attributes + Content + Closing tag ల సంపూర్ణ సమాహారం.
  • Void Elements: క్లోజింగ్ ట్యాగ్ లేని ఖాళీ ఎలిమెంట్స్ (<br>, <hr>, <img>, <input>).
  • id vs class: id పేజీలో ఒక్కసారే ఉండే ఆధార్ నంబర్ లాంటిది; class ఎన్నిసార్లయినా పునర్వినియోగించగల గ్రూప్ పేరు.
  • Global Attributes: ప్రతి ఎలిమెంట్‌కీ ఉపయోగించగల లక్షణాలు (id, class, style, title, hidden, tabindex).
  • Custom Data: data-* ద్వారా బ్యాకెండ్ సమాచారాన్ని HTML లో భద్రపరిచి JS లో dataset ద్వారా చదవడం.
  • DOM Tree: HTML లోని పేరెంట్, చైల్డ్, సిబ్లింగ్స్ క్రమానుగత కుటుంబ వృక్షం.
13తర్వాతి అధ్యాయంలో మీరు నేర్చుకోబోయేవి (What's Next?)
