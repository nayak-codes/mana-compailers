Form Attributes Reference (required, readonly, disabled, pattern, autocomplete)

🌐 HTML5 🟢 Chapter 17 of 32 📂 Phase 07: Forms & Input Controls 📅 2026 Edition
📌 Covered in this chapter: Form Attributes · required, readonly, disabled · min, max, step · minlength, maxlength · pattern (Regex) · autocomplete & multiple
Welcome to Phase 7 (Chapter 17): Form Attributes Reference! HTML form controls support powerful attributes that configure validation rules, default states, and submission behaviors. In this chapter, we master name, value, placeholder, required, readonly, disabled, checked, selected, min/max, step, minlength/maxlength, pattern (Regex), autocomplete, multiple, accept, and overrides (formaction, formenctype, formmethod).
1Form Control Attributes Reference Table
AttributePurpose & DescriptionExample Syntax

  <!-- Zip Code pattern matching 5 digits -->
  <label for="zip">US Zip Code (5 Digits):</label>
  <input id="zip" name="zip" type="text" pattern="[0-9]{5}" title="Enter 5 digit zip code" required>

  <br><br>

  <!-- Multiple File Upload restricted to Images -->
  <label for="photos">Upload Photos (PNG/JPG only):</label>
  <input id="photos" name="photos" type="file" accept="image/png, image/jpeg" multiple>

  <button type="submit">Submit Data</button>
</form>
❓ Frequently Asked Questions (FAQ)

Q1: What is the difference between disabled and readonly?

A disabled field cannot be focused, clicked, or submitted to the server. A readonly field can be focused and its value IS submitted to the server with the form.
