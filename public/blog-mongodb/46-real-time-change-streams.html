11Common Mistakes & Anti-Patterns
⚠️ Anti-Patterns to Avoid
  • Creating unbounded arrays inside single documents — exceeds the 16MB document size limit. Use referencing for 1-to-N relationships.
  • Running unindexed queries on large collections — results in expensive full collection scans (COLLSCAN). Always verify indexes with explain().
  • Using $where or custom JavaScript evaluation functions in production queries — disables index optimization and slows down throughput.
  • Forgetting to handle connection disconnects or missing index creation during Node.js application startup.
  • Over-normalizing schemas like a relational SQL database instead of leveraging document embedding.
