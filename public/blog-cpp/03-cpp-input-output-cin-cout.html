ఇన్‌పుట్ & అవుట్‌పుట్ (cin, cout, getline & Fast I/O)

⚡ Modern C++20 / C++17 🟢 Chapter 3 of 20 📂 Phase 1: C++ Basics & Fundamentals 📅 2026 Edition
📌 Covered in this chapter: std::cin & Stream Extraction (>>) · Chained Input · The Whitespace Trap · std::getline() for Multi-word Strings · The cin/getline Buffer Trap & cin.ignore() Fix · Output Formatting with <iomanip> (fixed, setprecision, setw) · Competitive Programming Fast I/O Optimization
రియల్ వరల్డ్ అప్లికేషన్లు ఎల్లప్పుడూ యూజర్ ఇచ్చే డేటా ఆధారంగా నడుస్తాయి. ఈ అధ్యాయంలో కీబోర్డ్ నుండి యూజర్ డేటాను చదవడం (std::cin), స్పేస్‌లతో కూడిన పెద్ద వాక్యాలను తీసుకోవడం (getline), బిగినర్లను వేధించే ఘోరమైన బఫర్ ట్రాప్‌లను cin.ignore() తో పరిష్కరించడం, మరియు కాంపిటీటివ్ ప్రోగ్రామింగ్‌లో ఉపయోగించే 10x Fast I/O ట్రిక్స్ ను ప్రాక్టికల్‌గా నేర్చుకుందాం.
1`std::cin` & Stream Extraction Operator (`>>`)

C++ లో స్క్రీన్ పై డేటాను చూపించడానికి std::cout వాడినట్లే, కీబోర్డ్ నుండి యూజర్ టైప్ చేసిన డేటాను చదవడానికి `std::cin` (Character Input) స్ట్రీమ్ ఆబ్జెక్ట్ ఉపయోగపడుతుంది.

🔄 Arrows Direction: `<<` vs `>>` (కన్ఫ్యూజన్ లేకుండా గుర్తుపెట్టుకోండి!)

బిగినర్లు తరచూ ఏ బాణం గుర్తు ఎక్కడ వాడాలో కన్ఫ్యూజ్ అవుతుంటారు:

  • cout << data; : డేటా మీ వేరియబుల్ నుండి బయట ఉన్న కన్సోల్‌కు ప్రవహిస్తుంది (Insertion).
  • cin >> variable; : డేటా బయట ఉన్న కీబోర్డ్ నుండి మీ వేరియబుల్ లోపలికి పంపిణీ అవుతుంది (Extraction).
💻 Example 1: Basic Input with std::cin
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    int userAge = 0;
    double accountBalance = 0.0;

    std::cout << "Enter your age: ";
    std::cin >> userAge;

    std::cout << "Enter your account balance: ";
    std::cin >> accountBalance;

    std::cout << "\n--- User Data Captured ---\n";
    std::cout << "Age: " << userAge << " years | Balance: Rs. " << accountBalance << "\n";

    return 0;
}
2Chained Input: ఒకేసారి అనేక విలువలను చదవడం

C++ లో cin >> a >> b >> c; అని ఒకే లైన్‌లో గొలుసుకట్టుగా (Chaining) రాసి యూజర్ నుండి స్పేస్‌లు లేదా ఎంటర్‌లతో వేరు చేయబడిన విలువలను ఒకేసారి చదవవచ్చు:

💻 Example 2: Chaining Multiple Inputs
C++17 Chaining ▶ Run in Compiler 
#include <iostream>

int main() {
    int length = 0, breadth = 0;

    std::cout << "Enter rectangle Length and Breadth (separated by space): ";
    // యూజర్ '15 20' అని టైప్ చేస్తే ఒకేసారి చదువుతుంది
    std::cin >> length >> breadth;

    int area = length * breadth;
    std::cout << "Calculated Area: " << area << " sq. units\n";

    return 0;
}
3The Whitespace Trap & `std::getline()`

కీబోర్డ్ నుండి యూజర్ పేరును చదవడానికి cin >> fullName; అని రాస్తే ఒక పెద్ద సమస్య వస్తుంది!

⚠️ The Whitespace Bug: "Balaji Nayak" ఇస్తే ఏమవుతుంది?

cin >> అనేది Whitespace Delimited. అంటే స్పేస్ (Space), ట్యాబ్ (\t), లేదా న్యూలైన్ (\n) కనిపించగానే చదవడం ఆపేస్తుంది!

యూజర్ "Balaji Nayak" అని టైప్ చేస్తే, cin కేవలం "Balaji" ని మాత్రమే తీసుకుంటుంది. మిగిలిన "Nayak" కీబోర్డ్ బఫర్‌లో ఉండిపోయి తర్వాతి వేరియబుల్స్‌ను పాడుచేస్తుంది!

✅ పరిష్కారం: `std::getline(std::cin, stringVariable)`

స్పేస్‌లతో కూడిన పూర్తి వాక్యాలను లైన్ మొత్తం చదవడానికి C++ స్ట్రింగ్ లైబ్రరీలోని `std::getline()` వాడాలి:

💻 Example 3: Capturing Full Lines with getline
C++17 getline ▶ Run in Compiler 
#include <iostream>
#include <string>

int main() {
    std::string fullAddress;

    std::cout << "Enter your complete street address: ";
    // స్పేస్‌లతో సహా ఎంటర్ కొట్టే వరకు మొత్తం లైన్ చదువుతుంది
    std::getline(std::cin, fullAddress);

    std::cout << "Delivery Address Confirmed: " << fullAddress << "\n";

    return 0;
}
4ది నైట్‌మేర్ బగ్: `cin` తర్వాత `getline` వాడటం & `cin.ignore()`

ప్రతి C++ డెవలపర్ తన జీవితంలో కనీసం ఒక్కసారైనా తలపట్టుకునే అత్యంత ప్రమాదకరమైన బగ్ ఇది! ఒక నంబర్ తీసుకున్న తర్వాత పేరు అడిగితే ప్రోగ్రామ్ పేరు అడగకుండానే స్కిప్ అయిపోతుంది:

కీబోర్డ్ యూజర్ టైపింగ్ : [ 25 ] + [ ENTER (\n) ] │ cin >> age; చదివింది : [ 25 ] మాత్రమే చదివింది! బఫర్ లో మిగిలింది : [ \n ] (Enter కీ బఫర్ లోనే ఉండిపోయింది!) │ getline(cin, name); : బఫర్ లో ఉన్న [ \n ] ని చూసి "ఇన్‌పుట్ అయిపోయింది" అనుకుని ఖాళీగా ముగుస్తుంది! ❌

✅ ది అల్టిమేట్ ఫిక్స్: `std::cin.ignore()`

cin >> వాడిన వెంటనే, బఫర్‌లో మిగిలిపోయిన Enter కీని తొలగించడానికి `std::cin.ignore();` లేదా std::cin.ignore(1000, '\n'); వాడాలి:

💻 Example 4: The Clean Buffer Pattern with cin.ignore()
C++17 Buffer Clean ▶ Run in Compiler 
#include <iostream>
#include <string>

int main() {
    int rollNumber = 0;
    std::string studentName;

    std::cout << "Enter Student Roll Number: ";
    std::cin >> rollNumber;

    // 🔥 CRITICAL: బఫర్‌లో మిగిలిన '\n' ను తుడిచివేయాలి!
    std::cin.ignore();

    std::cout << "Enter Full Student Name: ";
    std::getline(std::cin, studentName); // ఇప్పుడు స్కిప్ అవ్వకుండా సరిగ్గా పనిచేస్తుంది!

    std::cout << "\nRegistered: " << studentName << " (Roll: " << rollNumber << ")\n";

    return 0;
}
5Output Formatting: `` తో ప్రొఫెషనల్ లుక్

బ్యాంకింగ్, బిల్లింగ్ మరియు టేబులర్ రిపోర్టులలో దశాంశాలను (Decimals) నియంత్రించడానికి C++ లో `<iomanip>` (Input/Output Manipulators) హెడర్ ఫైల్ ఉంది:

  • std::fixed: సైంటిఫిక్ నోటేషన్ (1e+05) రాకుండా సాధారణ దశాంశ రూపంలో చూపిస్తుంది.
  • std::setprecision(2): దశాంశం తర్వాత కచ్చితంగా 2 స్థానాలు మాత్రమే ఉండేలా చేస్తుంది (ఉదా: 95.50).
  • std::setw(15): కాలమ్ వెడల్పును 15 క్యారెక్టర్లుగా సెట్ చేసి పట్టికలను నిలువుగా సమలేఖనం (Alignment) చేస్తుంది.
💻 Example 5: Beautiful Formatting with <iomanip>
C++17 <iomanip> ▶ Run in Compiler 
#include <iostream>
#include <iomanip> // Manipulators కోసం అవసరం

int main() {
    double itemPrice1 = 49.9;
    double itemPrice2 = 1250.758;

    std::cout << "--- Formatted Receipt ---\n";
    // దశాంశం తర్వాత కచ్చితంగా 2 అంకెలు మాత్రమే ప్రింట్ అవ్వాలి
    std::cout << std::fixed << std::setprecision(2);

    std::cout << std::left << std::setw(20) << "Item Name" 
              << std::right << std::setw(10) << "Price (Rs)" << "\n";
    std::cout << "------------------------------\n";
    std::cout << std::left << std::setw(20) << "Wireless Mouse" 
              << std::right << std::setw(10) << itemPrice1 << "\n";
    std::cout << std::left << std::setw(20) << "Mechanical Keybd" 
              << std::right << std::setw(10) << itemPrice2 << "\n";

    return 0;
}
6Competitive Programming Secret: 10x Fast I/O

LeetCode, Codeforces, లేదా CodeChef లో లక్షలాది టెస్ట్ కేస్‌లు ఉన్నప్పుడు సాధారణ cin/cout వాడితే TLE (Time Limit Exceeded) వస్తుంది.

⚡ The 2 Magical Lines for 10x Speedup

C++ డీఫాల్ట్‌గా C లాంగ్వేజ్ లోని stdio తో సింక్రనైజ్ అయి ఉంటుంది. ఈ 2 లైన్లను main() ప్రారంభంలో రాస్తే ఆ సింక్ ఆగిపోయి cin/cout అల్ట్రా-ఫాస్ట్‌గా పనిచేస్తాయి: 

std::ios_base::sync_with_stdio(false);
std::cin.tie(NULL);

ఇది చేయడం వల్ల C++ స్ట్రీమ్స్ C బఫర్లతో మాట్లాడటం ఆపేస్తాయి మరియు ప్రతి ఇన్‌పుట్‌కు ముందు అవుట్‌పుట్‌ను ఫ్లష్ చేయవు.

⚠️ Common Developer Pitfalls in Chapter 3
  • రాంగ్ డేటా టైప్ ఎంటర్ చేయడం (cin Fail State): ప్రోగ్రామ్ నంబర్ int అడిగినప్పుడు యూజర్ అక్షరాలు (ఉదా: "abc") ఎంటర్ చేస్తే, cin ఒక Fail State లోకి వెళ్లిపోతుంది. ఆ తర్వాత ప్రోగ్రామ్ ఎలాంటి ఇన్‌పుట్‌ను తీసుకోదు.
  • cin >> str వాడి స్పేస్‌లు పోగొట్టుకోవడం: ఫుల్ పేర్లు లేదా వాక్యాలు కావాలన్నప్పుడు ఎప్పుడూ getline() నే వాడాలి.
💻 Hands-on Interactive Practice Challenge

టాస్క్: ఒక స్టూడెంట్ కాలేజ్ అడ్మిషన్ కార్డును ప్రింట్ చేసే ప్రోగ్రామ్ రాయండి. విద్యార్థి పూర్తి పేరు (స్పేస్‌లతో సహా getline ద్వారా), రోల్ నంబర్, 3 సబ్జెక్టుల మార్కులు ఇన్‌పుట్‌గా తీసుకుని, మొత్తం మార్కులు మరియు సగటు (Average) ను కచ్చితంగా 2 డెసిమల్ స్థానాలతో ఫార్మాట్ చేసి ప్రింట్ చేయండి:

C++17 Report Card Challenge ▶ Run in Compiler 
#include <iostream>
#include <string>
#include <iomanip>

int main() {
    int rollNo = 1042;
    std::string fullName = "Venkata Satish Kumar";
    double mathMarks = 94.5;
    double physicsMarks = 88.0;
    double csMarks = 99.5;

    // గణనలు
    double totalMarks = mathMarks + physicsMarks + csMarks;
    double averageMarks = totalMarks / 3.0;

    // ఫార్మాటెడ్ అవుట్‌పుట్
    std::cout << "========================================\n";
    std::cout << "       COLLEGE STUDENT REPORT CARD      \n";
    std::cout << "========================================\n";
    std::cout << "Roll Number   : " << rollNo << "\n";
    std::cout << "Student Name  : " << fullName << "\n";
    std::cout << "----------------------------------------\n";
    std::cout << std::fixed << std::setprecision(2);
    std::cout << "Mathematics   : " << mathMarks << " / 100\n";
    std::cout << "Physics       : " << physicsMarks << " / 100\n";
    std::cout << "Computer Sci  : " << csMarks << " / 100\n";
    std::cout << "----------------------------------------\n";
    std::cout << "Total Marks   : " << totalMarks << " / 300\n";
    std::cout << "Percentage    : " << averageMarks << " %\n";
    std::cout << "Grade Result  : " << (averageMarks >= 90.0 ? "DISTINCTION (A+) 🌟" : "FIRST CLASS (A) ✅") << "\n";
    std::cout << "========================================\n";

    return 0;
}

❓ Frequently Asked Questions (FAQ)

Q cin తర్వాత getline() వాడినప్పుడు ఇన్పుట్ తీసుకోకుండా ఎందుకు స్కిప్ అవుతుంది?

cin >> కేవలం విలువను మాత్రమే చదువుతుంది, కానీ మీరు కీబోర్డుపై నొక్కిన Enter (Newline \n) కీ బఫర్‌లో అలానే ఉండిపోతుంది. తర్వాతి లైన్‌లో ఉన్న getline() ఆ మిగిలిపోయిన \n ను చదివి ముగిసిపోతుంది. దీనిని నివారించడానికి cin >> తర్వాత కచ్చితంగా std::cin.ignore(); వాడాలి.

Q Competitive Programming లో Fast I/O ఎందుకు వాడతారు?

డీఫాల్ట్‌గా C++ లోని cin/cout C లాంగ్వేజ్ లోని scanf/printf తో సింక్ అయి ఉంటాయి (I/O Synchronization). std::ios_base::sync_with_stdio(false); std::cin.tie(NULL); వాడటం వల్ల ఆ సింక్ ఆగిపోయి, భారీ డేటాను చదవడం 5 నుండి 10 రెట్లు వేగవంతం అవుతుంది.

Q డెసిమల్స్ తర్వాత కచ్చితంగా 2 అంకెలు మాత్రమే ప్రింట్ అవ్వాలంటే ఏం చేయాలి?

#include <iomanip> హెడర్ ఫైల్‌ను చేర్చి, std::cout << std::fixed << std::setprecision(2); అని సెట్ చేస్తే డెసిమల్ తర్వాత కచ్చితంగా రెండు స్థానాలు మాత్రమే ప్రింట్ అవుతాయి (ఉదా: 98.50).
