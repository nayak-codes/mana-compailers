ఇన్‌పుట్ & అవుట్‌పుట్ (cin, cout, getline & I/O Formatting)

⚡ Modern C++20 / C++17 🟢 Chapter 3 of 20 📂 Phase 1: C++ Basics & Fundamentals 📅 2026 Edition
📌 Covered in this chapter: C++ Stream Architecture · std::cout Insertion (<<) · std::cin Extraction (>>) · std::getline() for Sentences · The Fatal Cin Buffer Newline Bug & Fix · Input Validation (cin.fail()) · I/O Formatting with
వినియోగదారుడి నుండి కీబోర్డ్ ద్వారా సమాచారాన్ని స్వీకరించడం మరియు ఫలితాన్ని కన్సోల్ స్క్రీన్‌పై స్పష్టంగా ప్రదర్శించడం ఏ సాఫ్ట్‌వేర్‌కైనా ప్రాథమిక అవసరం. C++ లో అత్యంత వేగవంతమైన Stream I/O సిస్టమ్, బిగినర్స్ తలపట్టుకునే cin బఫర్ న్యూలైన్ ట్రాప్ మరియు దాని పరిష్కారాన్ని ఈ అధ్యాయంలో నేర్చుకుందాం.
1C++ లో Streams అంటే ఏమిటి? (కన్వేయర్ బెల్ట్ పోలిక)

C++ లో డేటా అనేది ఒక Stream (ప్రవాహం) లాగా ప్రయాణిస్తుంది. ఒక కన్వేయర్ బెల్ట్ మీద పెట్టెలు ఎలా ఒకదాని తర్వాత ఒకటి వెళ్తాయో, కీబోర్డ్ నుండి CPU కి మరియు CPU నుండి మానిటర్ స్క్రీన్‌కు క్యారెక్టర్లు వరుస క్రమంలో ప్రవహిస్తాయి:

std::cout (Standard Output Stream)

<< (Insertion Operator) ను వాడుతుంది. మీ ప్రోగ్రామ్ నుండి డేటాను స్క్రీన్ కన్సోల్‌లోకి ఇంజెక్ట్ చేస్తుంది. ఉదాహరణ: std::cout << "Hello";

std::cin (Standard Input Stream)

>> (Extraction Operator) ను వాడుతుంది. కీబోర్డ్ బఫర్ నుండి డేటాను లాగి (Extract చేసి) మీ వేరియబుల్‌లో భద్రపరుస్తుంది. ఉదాహరణ: std::cin >> age;

2std::cin యొక్క పరిమితి: Whitespace Truncation

std::cin >> ఆపరేటర్ కేవలం స్పేస్ లేని ఒకే పదాన్ని మాత్రమే చదవగలదు. వినియోగదారుడు స్పేస్ ఇచ్చిన వెంటనే (Space, Tab, Enter), అక్కడితో ఆగిపోతుంది:

💻 Example 1: Reading Strings with Whitespaces using std::getline
C++17 ▶ Run in Compiler 
#include <iostream>
#include <string>

int main() {
    std::string fullName;
    std::cout << "Enter your full name (with spaces): ";
    
    // std::getline వాడటం వల్ల స్పేస్‌లతో సహా ఎంటర్‌కొట్టే వరకు లైన్ మొత్తం చదువుతుంది
    std::getline(std::cin, fullName);

    std::cout << "Welcome aboard, " << fullName << "! 🚀\n";
    return 0;
}
3ది ఫేమస్ C++ బగ్: cin >> తర్వాత getline() స్కిప్ అవ్వడం!

ప్రతి C++ ప్రోగ్రామర్ తన జీవితంలో కనీసం వందసార్లు ఈ బగ్‌తో తలపట్టుకుంటాడు. ఒక నంబర్‌ను cin >> తో చదివిన వెంటనే getline() వాడితే, అది యూజర్ దగ్గర ఏమీ అడగకుండా ఖాళీగా స్కిప్ అయిపోతుంది!

🔍 ఎందుకు ఇలా జరుగుతుంది? (The Buffer Mystery)

మీరు కీబోర్డ్‌లో 25 అని టైప్ చేసి [Enter] కొట్టినప్పుడు, మెమరీ బఫర్‌లో '2' '5' '\n' ఉంటాయి.
cin >> age; కేవలం 25 ను మాత్రమే తీసుకుంటుంది. ఆ '\n' (ఎంటర్ క్యారెక్టర్) బఫర్‌లోనే ఉండిపోతుంది!
వెంటనే తర్వాతి లైన్‌లో ఉన్న getline(cin, name); ఆ పాత '\n' ను చూసి, "యూజర్ ఆల్రెడీ ఎంటర్ కొట్టేశారు" అనుకుని ఖాళీ స్ట్రింగ్‌ను రీడ్ చేసి వెళ్లిపోతుంది!

💻 Example 2: The Definitive cin.ignore() Fix
C++17 ▶ Run in Compiler 
#include <iostream>
#include <string>
#include <limits>

int main() {
    int rollNumber;
    std::string studentName;

    std::cout << "Enter Roll Number: ";
    std::cin >> rollNumber;

    // సీక్రెట్ పరిష్కారం: బఫర్‌లో మిగిలిపోయిన '\n' ను క్లియర్ చేయండి
    std::cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');

    std::cout << "Enter Student Full Name: ";
    std::getline(std::cin, studentName); // ఇప్పుడు పర్ఫెక్ట్‌గా ఆగి అడుగుతుంది!

    std::cout << "ID: " << rollNumber << " | Name: " << studentName << "\n";
    return 0;
}
4అవుట్‌పుట్ ఫార్మాటింగ్: <iomanip> తో అద్భుతమైన డిస్‌ప్లే

కరెన్సీ లేదా పర్సంటేజీలను ప్రింట్ చేసేటప్పుడు 2 డెసిమల్ ప్లేసెస్ మాత్రమే రావాలన్నా (ఉదా: 99.50), లేదా టేబుల్ లాగా సమానమైన వెడల్పుతో కాలమ్స్ రావాలన్నా <iomanip> హెడర్ వాడతాం:

  • std::fixed << std::setprecision(2): కచ్చితంగా రెండు డెసిమల్ పాయింట్లు మాత్రమే చూపిస్తుంది.
  • std::setw(15): కాలమ్ విడ్త్‌ను 15 క్యారెక్టర్లకు సెట్ చేస్తుంది.
5తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: యూజర్ ఇంటిజర్ బదులు అక్షరం టైప్ చేస్తే ప్రోగ్రామ్ క్రాష్ అవుతుందా?

క్రాష్ అవ్వదు, కానీ std::cin ఒక 'Fail State' లోకి వెళ్లిపోతుంది. తర్వాతి ఇన్‌పుట్‌లను తీసుకోదు. దీనిని పరిష్కరించడానికి if (std::cin.fail()) { std::cin.clear(); } వాడాలి.
