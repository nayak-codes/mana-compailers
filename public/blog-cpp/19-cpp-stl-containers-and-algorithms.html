STL కంటైనర్లు & అల్గారిథమ్స్ (C++ STL Guide)

C++ ప్రపంచానికి కిరీటం లాంటి లైబ్రరీ! STL యొక్క 3 స్తంభాలు (Containers, Iterators, Algorithms), std::vector మెమరీ డబ్లింగ్ సూత్రం, std::map (Red-Black Tree) vs std::unordered_map (Hash Table) మధ్య ఉన్న తేడాలు, Iterator Invalidation ప్రమాదం, మరియు std::sort వెనుక ఉన్న ఇంజనీరింగ్ అద్భుతం IntroSort.

📌 Covered in this chapter: STL 3 Pillars · Vector Capacity Scaling · Map vs Unordered_Map · Iterators & Invalidation · IntroSort (std::sort) · Modern Lambdas
1 STL ఆర్కిటెక్చర్: 3 స్తంభాలు (Containers, Iterators, Algorithms)

C++ లో లింక్డ్ లిస్టులు, బైనరీ ట్రీలు, హ్యాష్ టేబుల్స్ లాంటి సంక్లిష్టమైన డేటా స్ట్రక్చర్లను ప్రతిసారీ స్క్రాచ్ నుండి రాయాల్సిన అవసరం లేకుండా, ప్రపంచంలోని అత్యుత్తమ ఇంజనీర్లు ఆప్టిమైజ్ చేసి అందించిన రెడీమేడ్ టూల్‌కిట్టే Standard Template Library (STL).

🏛️ STL త్రయం: పరస్పర అనుసంధాన స్తంభాలు:

1. Containers
డేటాను భద్రపరిచేవి
(vector, map, set, deque)
2. Iterators
కంటైనర్లకు అల్గారిథమ్స్ కు వారధి
(begin(), end(), ++)
3. Algorithms
డేటాను ప్రాసెస్ చేసే లాజిక్
(sort, find, count)
2 STL కంటైనర్ల వర్గీకరణ & కాంప్లెక్సిటీ మ్యాట్రిక్స్

ఏ సందర్భంలో ఏ కంటైనర్‌ను ఎంచుకోవాలో తెలియడమే కోడింగ్ ఇంటర్వ్యూలలో సెలెక్ట్ అవ్వడానికి కీలకమైన రహస్యం:

కంటైనర్ అంతర్గత డేటా స్ట్రక్చర్ యాక్సెస్ స్పీడ్ శోధన (Search) సార్టెడ్ గా ఉంటుందా?
std::vector Dynamic Contiguous RAM Array O(1) Direct Indexing O(N) Linear Search లేదు (మనం ఇన్సర్ట్ చేసిన క్రమం)
std::map Red-Black Tree (Self-balancing BST) O(log N) O(log N) Guaranteed అవును (కీలు క్రమపద్ధతిలో ఉంటాయి)
std::unordered_map Hash Table (Buckets + Hash Function) O(1) Average O(1) Average Case! లేదు (ర్యాండమ్ ఆర్డర్)
std::set Red-Black Tree (Only unique keys) O(log N) O(log N) (డూప్లికేట్స్ ఉండవు) అవును (Ascending Order)
💻 Example 1: Vector Scaling & Fast O(1) Hash Map
stl_containers_quick.cpp
⚡ Try in Compiler 
#include <iostream>
#include <vector>
#include <unordered_map>
#include <string>

int main() {
    // 1. Vector: Contiguous RAM
    std::vector<int> numbers = {10, 20, 30};
    numbers.push_back(40);
    std::cout << "Vector size: " << numbers.size() << " | Element 0: " << numbers[0] << "\n";

    // 2. Unordered_map: O(1) Hash Table
    std::unordered_map<std::string, double> prices;
    prices["Book"] = 499.0;
    prices["Pen"] = 25.0;

    std::cout << "Price of Book: Rs " << prices["Book"] << "\n";
    return 0;
}
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • std::vector<int> numbers: ర్యామ్‌లో ఒకదాని పక్కన ఒకటి ఉండే మెమరీ కాబట్టి CPU Cache కి అత్యంత అనుకూలమైనది (Cache Friendly).
  • prices["Book"] = 499.0;: హ్యాష్ టేబుల్ ద్వారా "Book" అనే కీని మెరుపు వేగంతో O(1) లో ఇన్సర్ట్ చేస్తుంది.
3 STL Algorithms: std::sort (IntroSort) & Lambdas

C++ లోని std::sort అనేది సాధారణ సార్టింగ్ కాదు; అది ప్రపంచ ప్రఖ్యాత IntroSort (Introspective Sort) అనే 3 హైబ్రిడ్ అల్గారిథమ్స్ కలయిక:

🚀 IntroSort యొక్క 3-దశల ఆర్కిటెక్చర్:

1. Phase 1 (QuickSort): వేగంగా విభజిస్తూ సార్టింగ్ ప్రారంభిస్తుంది.
2. Phase 2 (HeapSort Fallback): రికర్షన్ లోతు ఎక్కువైతే QuickSort $O(N^2)$ కి పడిపోకుండా వెంటనే HeapSort కి మారిపోయి ఖచ్చితమైన $O(N \log N)$ గ్యారెంటీ ఇస్తుంది!
3. Phase 3 (InsertionSort): సబ్‌అర్రే సైజ్ 16 కంటే తక్కువైతే ఇన్సర్షన్ సార్ట్ తో మెరుపు వేగంతో ముగిస్తుంది.
💻 Example 2: std::sort with Modern Lambda Comparator
stl_sort_lambda.cpp
⚡ Try in Compiler 
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> scores = {45, 12, 89, 73, 23};

    // Descending Sort using Modern C++ Lambda
    std::sort(scores.begin(), scores.end(), [](int a, int b) {
        return a > b; // Largest first
    });

    std::cout << "Sorted Scores: ";
    for (int s : scores) std::cout << s << " ";
    std::cout << "\n";
    return 0;
}
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • scores.begin(), scores.end(): అల్గారిథమ్స్ నేరుగా వెక్టర్ కాకుండా ఇటరేటర్ల పరిధిని తీసుకుంటాయి.
  • [](int a, int b) { return a > b; }: ప్రత్యేకమైన ఫంక్షన్ రాయకుండా ఇన్-లైన్ గా లాంబ్డా ద్వారా కస్టమ్ కంపేరిజన్ లాజిక్ ను అందించాం.
4 సాధారణంగా బిగినర్స్ చేసే తప్పులు & బెస్ట్ ప్రాక్టీసెస్

⚠️ Common Beginner Traps

  • Iterator Invalidation Trap: వెక్టర్‌లో లూప్ తిరుగుతున్న సమయంలో కొత్త ఎలిమెంట్లను push_back చేస్తే పాత ఇటరేటర్లు చెల్లవు (Crash).
  • map[key] Silent Insertion: మ్యాప్‌లో లేని కీ కోసం map[key] అని పిలిస్తే, C++ సైలెంట్ గా డిఫాల్ట్ వాల్యూతో ఆ కీని ఇన్సర్ట్ చేస్తుంది! కేవలం చెక్ చేయడానికి map.find() వాడాలి.

💡 Industry Best Practices

  • Always use vector.reserve(N): లూప్‌లో వేలాది ఎలిమెంట్లు వేసేటప్పుడు ముందుగానే v.reserve(10000) కాల్ చేయండి; 2x రీ-అలొకేషన్ కాపీ వేస్ట్ పూర్తిగా ఆగిపోతుంది.
  • Prefer emplace_back over push_back: emplace_back() ఆబ్జెక్ట్ ను డైరెక్ట్ గా వెక్టర్ మెమరీలోనే కన్‌స్ట్రక్ట్ చేస్తుంది, అనవసరమైన కాపీలను నివారిస్తుంది.
❓ Frequently Asked Questions (FAQ)

Q std::map కి std::unordered_map కి మధ్య ప్రధాన వ్యత్యాసాలు ఏమిటి?

std::map అనేది అంతర్గతంగా Red-Black Tree (Self-balancing Binary Search Tree) పై ఆధారపడి ఉంటుంది; కీలు క్రమపద్ధతిలో (Sorted order) ఉంటాయి మరియు శోధన సమయం O(log N). std::unordered_map అనేది Hash Table పై ఆధారపడి ఉంటుంది; కీలు సార్ట్ అయి ఉండవు కానీ సగటు శోధన సమయం మెరుపు వేగంతో O(1) లో పూర్తవుతుంది.

Q std::vector లో 'size' కి 'capacity' కి తేడా ఏమిటి?

'size' అనేది ప్రస్తుతం వెక్టర్‌లో ఉన్న అసలైన ఎలిమెంట్ల సంఖ్య. 'capacity' అనేది కొత్తగా మెమరీ రీ-అలొకేషన్ అవసరం లేకుండా వెక్టర్ గరిష్టంగా ఉంచుకోగల స్థలం. ఎలిమెంట్లు కెపాసిటీని దాటినప్పుడు వెక్టర్ ఆటోమేటిక్‌గా తన కెపాసిటీని దాదాపు రెట్టింపు (2x) చేసుకుంటుంది (Amortized O(1) push_back).

Q std::sort అల్గారిథమ్ వెనుక ఏ సార్టింగ్ టెక్నిక్ ఉంటుంది?

C++ std::sort అనేది 'IntroSort' (Introspective Sort) అనే ఒక హైబ్రిడ్ అల్గారిథమ్‌ను ఉపయోగిస్తుంది. ఇది QuickSort తో ప్రారంభమై, రికర్షన్ లోతు ఎక్కువైతే HeapSort కి మారి, చిన్న సబ్‌అర్రేల కోసం InsertionSort కి మారుతుంది. దీనివల్ల అధ్వాన్నమైన సందర్భంలోనూ (Worst Case) ఖచ్చితమైన O(N log N) టైమ్ కాంప్లెక్సిటీని ఇస్తుంది.
