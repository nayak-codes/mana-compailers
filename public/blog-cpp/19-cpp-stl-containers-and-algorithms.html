STL కంటైనర్లు & అల్గారిథమ్స్ (C++ STL Guide)

ప్రపంచస్థాయి కాంపిటేటివ్ ప్రోగ్రామింగ్ టూల్‌కిట్! Standard Template Library (STL) నిర్మాణం: Sequence Containers (std::vector, std::deque), Associative Red-Black Trees (std::map, std::set), $O(1)$ Hash Tables (std::unordered_map), Iterators, Iterator Invalidation ముప్పు, మరియు IntroSort (std::sort) తో పాటు ఆధునిక Lambdas.

1 STL ఆర్కిటెక్చర్: 3 స్తంభాలు (Containers, Iterators, Algorithms)

C++ లో డేటా స్ట్రక్చర్లను స్క్రాచ్ నుండి మళ్ళీ మళ్ళీ రాయాల్సిన అవసరం లేకుండా, ప్రపంచంలోని అత్యుత్తమ కంప్యూటర్ ఇంజనీర్లు ఆప్టిమైజ్ చేసి అందించిన రెడీమేడ్ టూల్‌కిట్టే Standard Template Library (STL). STL ప్రధానంగా 3 పరస్పర అనుసంధాన స్తంభాలపై ఆధారపడి ఉంటుంది:

2 STL కంటైనర్ల వర్గీకరణ & టైమ్ కాంప్లెక్సిటీ మ్యాట్రిక్స్

సరైన సందర్భంలో సరైన కంటైనర్‌ను ఎంచుకోవడమే కోడింగ్ ఇంటర్వ్యూలలో కీలకమైన నైపుణ్యం:

కంటైనర్ అంతర్గత డేటా స్ట్రక్చర్ యాక్సెస్ స్పీడ్ శోధన (Search) సార్టెడ్ గా ఉంటుందా?
std::vector Dynamic Contiguous RAM Array $O(1)$ Direct Indexing $O(N)$ (లేదా $O(\log N)$ సార్ట్ అయితే) లేదు (మనం వేసిన ఆర్డర్)
std::map Red-Black Tree (Self-balancing BST) $O(\log N)$ $O(\log N)$ Guaranteed అవును (కీల క్రమం ఆటోమేటిక్)
std::unordered_map Hash Table (Buckets + Hash Function) $O(1)$ Average $O(1)$ Average Case! లేదు (ర్యాండమ్ ఆర్డర్)
std::set Red-Black Tree (Only unique keys) $O(\log N)$ $O(\log N)$ (డూప్లికేట్స్ తీసేస్తుంది) అవును (Strictly Ascending)
3 Vector మెమరీ డబ్లింగ్ & Iterator Invalidation ముప్పు

std::vector లో push_back() చేసినప్పుడు మెమరీ ఎలా పెరుగుతుందో అర్థం చేసుకోవడం చాలా ముఖ్యం:

⚡ Capacity Doubling Formula (Amortized $O(1)$):
ఒక వెక్టర్ ప్రస్తుత సైజ్ దాని కెపాసిటీని చేరుకోగానే, C++ పాత ఎరేను రీసైజ్ చేయదు! అది రామ్‌లో వేరే చోట 2 రెట్లు పెద్దదైన (2x Capacity) కొత్త మెమరీ బ్లాక్‌ను రిజర్వ్ చేసి, పాత ఎలిమెంట్లను అక్కడికి మూవ్ చేస్తుంది.

🚨 Iterator Invalidation Trap: ఈ మెమరీ రీ-అలొకేషన్ జరిగినప్పుడు, పాత మెమరీ డిలీట్ అయిపోతుంది! కాబట్టి ఆ పాత అడ్రస్‌లను పట్టుకున్న పాయింటర్లు లేదా Iterators వెంటనే డ్యాంగ్లింగ్ (Invalid) అయిపోతాయి. రీసైజ్ అయ్యే లూప్స్ లో పాత ఇటరేటర్లను వాడితే సిస్టమ్ క్రాష్ అవుతుంది!
💻 Code Example 1: Compact Vector Capacity & Fast O(1) Hash Table
stl_containers_compact.cpp
⚡ Try in Compiler 
#include <iostream>
#include <vector>
#include <unordered_map>
#include <string>

int main() {
    // 1. Vector Size vs Capacity Growth
    std::vector<int> v;
    std::cout << "--- Vector Dynamic Capacity Scaling ---\n";
    for (int i = 1; i <= 5; ++i) {
        v.push_back(i * 10);
        std::cout << "Pushed " << i * 10 << " | Size: " << v.size() 
                  << " | Capacity: " << v.capacity() << "\n";
    }

    // 2. Fast O(1) Hash Table Lookup (unordered_map)
    std::cout << "\n--- O(1) Key-Value Hash Map Lookup ---\n";
    std::unordered_map<std::string, double> salaries = {
        {"Software Engineer", 120000.0},
        {"Cloud Architect", 160000.0}
    };

    salaries["AI Researcher"] = 185000.0; // ఇన్సర్షన్

    // శోధన (Lookup)
    auto it = salaries.find("Cloud Architect");
    if (it != salaries.end()) {
        std::cout << "Found: " << it->first << " -> $" << it->second << "\n";
    }

    return 0;
}

4 STL Algorithms: std::sort (IntroSort) & Lambdas

<algorithm> హెడర్ లోని ఫంక్షన్లు నేరుగా కంటైనర్లతో పనిచేయవు; అవి Iterators ద్వారా పనిచేస్తాయి. దీనివల్ల ఒకే సార్ట్ ఫంక్షన్ ఎరేస్, వెక్టర్స్, లేదా డెక్స్ పై సమానంగా పనిచేస్తుంది.

[IntroSort: std::sort ఇంజనీరింగ్ అద్భుతం] C++ std::sort అనేది సాధారణ క్విక్ సార్ట్ కాదు, అది 3 అల్గారిథమ్స్ కలయిక (IntroSort): 1. Phase 1 (QuickSort): చాలా వేగంగా విభజిస్తూ సార్ట్ చేస్తుంది. 2. Phase 2 (HeapSort): ఒకవేళ రికర్షన్ డెప్త్ 2 * log(N) దాటితే, క్విక్‌సార్ట్ O(N^2) వర్స్ట్ కేస్ కి వెళ్లకుండా వెంటనే హీప్‌సార్ట్‌కు మారిపోతుంది! 3. Phase 3 (InsertionSort): ఎలిమెంట్ల సంఖ్య 16 కంటే తక్కువైతే ఇన్‌సర్షన్‌సార్ట్ మెరుపు వేగంతో ముగిస్తుంది.
💻 Code Example 2: std::sort with Custom Lambda Comparator & Binary Search
stl_algorithms_compact.cpp
⚡ Try in Compiler 
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> scores = {45, 12, 89, 73, 23, 99, 56};

    // 1. Ascending Sort via std::sort
    std::sort(scores.begin(), scores.end());
    std::cout << "Ascending Sort : ";
    for (int n : scores) std::cout << n << " ";
    std::cout << "\n";

    // 2. Custom Lambda Comparator తో Descending Sort
    std::sort(scores.begin(), scores.end(), [](int a, int b) {
        return a > b; // పెద్ద సంఖ్యలు ముందు రావాలి
    });

    std::cout << "Descending Sort: ";
    for (int n : scores) std::cout << n << " ";
    std::cout << "\n";

    // 3. Fast Binary Search (O(log N))
    std::sort(scores.begin(), scores.end()); // సార్టెడ్ గా ఉండాలి
    bool exists = std::binary_search(scores.begin(), scores.end(), 73);
    std::cout << "Does 73 exist? : " << (exists ? "FOUND ✔️" : "NOT FOUND ❌") << "\n";

    return 0;
}

❓ Frequently Asked Questions (FAQ)

Q std::map కి std::unordered_map కి మధ్య ప్రధాన వ్యత్యాసాలు ఏమిటి?

std::map అనేది అంతర్గతంగా Red-Black Tree (Self-balancing Binary Search Tree) పై ఆధారపడి ఉంటుంది; కీలు క్రమపద్ధతిలో (Sorted order) ఉంటాయి మరియు శోధన సమయం $O(\log N)$. std::unordered_map అనేది Hash Table పై ఆధారపడి ఉంటుంది; కీలు సార్ట్ అయి ఉండవు కానీ సగటు శోధన సమయం మెరుపు వేగంతో $O(1)$ లో పూర్తవుతుంది.

Q std::vector లో 'size' కి 'capacity' కి తేడా ఏమిటి?

size అనేది ప్రస్తుతం వెక్టర్‌లో ఉన్న అసలైన ఎలిమెంట్ల సంఖ్య. capacity అనేది కొత్తగా మెమరీ రీ-అలొకేషన్ అవసరం లేకుండా వెక్టర్ గరిష్టంగా ఉంచుకోగల స్థలం. ఎలిమెంట్లు కెపాసిటీని దాటినప్పుడు వెక్టర్ ఆటోమేటిక్‌గా తన కెపాసిటీని దాదాపు రెట్టింపు (2x) చేసుకుంటుంది (Amortized $O(1)$ push_back).

Q std::sort అల్గారిథమ్ వెనుక ఏ సార్టింగ్ టెక్నిక్ ఉంటుంది?

C++ std::sort అనేది IntroSort (Introspective Sort) అనే ఒక హైబ్రిడ్ అల్గారిథమ్‌ను ఉపయోగిస్తుంది. ఇది QuickSort తో ప్రారంభమై, రికర్షన్ లోతు ఎక్కువైతే HeapSort కి మారి, చిన్న సబ్‌అర్రేల కోసం InsertionSort కి మారుతుంది. దీనివల్ల అధ్వాన్నమైన సందర్భంలోనూ (Worst Case) ఖచ్చితమైన $O(N \log N)$ టైమ్ కాంప్లెక్సిటీని ఇస్తుంది.
