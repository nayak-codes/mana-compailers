break, continue & లూప్ కంట్రోల్ (Loop Flow Control)

⚡ Modern C++20 / C++17 🟢 Chapter 8 of 20 📂 Phase 2: Control Flow & Loops 📅 2026 Edition
📌 Covered in this chapter: Early Loop Termination with break · Skipping Iterations with continue · The while Loop continue Trap · Breaking Out of Nested Loops · Clean Refactoring Strategies · goto Controversy
లూప్ 10,000 సార్లు నడవాలని రాసినప్పటికీ, మనకు కావాల్సిన ఫలితం 3వ రౌండ్‌లోనే దొరికితే మిగిలిన 9,997 రౌండ్లు సమయం వేస్ట్ చేయడం మూర్ఖత్వం. ప్రోగ్రామ్ రన్ అవుతున్నప్పుడు లూప్‌ను మధ్యలోనే ఆపేయడానికి (break), లేదా నిర్దిష్ట చెత్త డేటా వచ్చినప్పుడు ఆ ఒక్క రౌండ్‌ను మాత్రమే దాటేయడానికి (continue) ఉపయోగపడే Loop Control Statements గురించి ఈ అధ్యాయంలో నేర్చుకుందాం.
1The break Statement (తక్షణ లూప్ రద్దు)

లూప్ కండిషన్ ఇంకా true గా ఉన్నప్పటికీ, break; ఎదురైన వెంటనే ఆ లూప్ అక్కడికక్కడే ముగిసిపోయి కర్సర్ బయటకు వచ్చేస్తుంది:

💻 Example 1: Linear Search with Early Exit
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    int rollNumbers[] = {101, 108, 125, 142, 160, 185};
    int target = 142;

    for (int i = 0; i < 6; ++i) {
        if (rollNumbers[i] == target) {
            std::cout << "Target Student " << target << " FOUND at index: " << i << " 🎯\n";
            break; // దొరికాడు, ఇక మిగతా అరే చూడాల్సిన పనిలేదు!
        }
    }

    return 0;
}
2The continue Statement (ప్రస్తుత రౌండ్ మాత్రమే దాటవేయడం)

continue; ఎదురైనప్పుడు లూప్ మొత్తం ఆగదు! కేవలం ఆ ఒక్క రౌండ్‌లో కింద ఉన్న మిగతా కోడ్‌ను స్కిప్ చేసి, నేరుగా తదుపరి రౌండ్ (Next Iteration) కు వెళ్లిపోతుంది:

💻 Example 2: Skipping Invalid Data
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    // కేవలం ధనాత్మక (Positive) సంఖ్యల మొత్తం మాత్రమే కనుక్కోవడం
    int data[] = {10, -5, 20, -8, 30};
    int total = 0;

    for (int i = 0; i < 5; ++i) {
        if (data[i] < 0) {
            continue; // నెగెటివ్ వస్తే స్కిప్ చేసి నెక్స్ట్ ఎలిమెంట్‌కి వెళ్ళు!
        }
        total += data[i];
    }

    std::cout << "Positive Sum: " << total << "\n";
    return 0;
}
3ది డేంజరస్ while Loop + continue ఇన్ఫినిట్ లూప్ ట్రాప్!
❌ The Infinite Loop Bug:

while (i < 10) { if (i == 5) continue; ++i; } అని రాస్తే, i విలువ 5 అయినప్పుడు continue జరిగి ++i ని దాటేస్తుంది! తర్వాతి రౌండ్‌లో మళ్లీ i 5 గానే ఉంటుంది, మళ్లీ continue అవుతుంది... ఇలా ప్రోగ్రామ్ అనంతమైన లూప్‌లో చిక్కుకుపోతుంది. ఎల్లప్పుడూ continue; రాసే ముందే ఇంక్రిమెంట్ చేయాలి!
