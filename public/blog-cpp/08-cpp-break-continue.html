break, continue & లూప్ కంట్రోల్ (Loop Control Statements)

⚡ Modern C++20 / C++17 🟢 Chapter 8 of 20 📂 Phase 2: Control Flow & Loops 📅 2026 Edition
📌 Covered in this chapter: Early Loop Exit with break · Skipping Iterations with continue · Nested Loops Breaking Strategies · The goto Statement Controversy · while Loop + continue Trap · Unreachable Code Clean Practices
లూప్ 1000 సార్లు నడవాలని రాసినప్పటికీ, మనకు కావాల్సిన సమాధానం 5వ రౌండ్‌లోనే దొరికితే మిగిలిన 995 సార్లు సమయం వేస్ట్ చేయడం దండగ! ప్రోగ్రామ్ రన్ అయ్యే సమయంలో లూప్‌ను మధ్యలోనే ముగించడానికి (break), లేదా ఏదైనా నిర్దిష్ట చెత్త డేటా వచ్చినప్పుడు ఆ రౌండ్‌ను మాత్రమే దాటేయడానికి (continue) ఉపయోగపడే Loop Control Statements గురించి ఈ అధ్యాయంలో సమగ్రంగా నేర్చుకుందాం.
1The `break` Statement (తక్షణ లూప్ రద్దు)

ఒక లూప్ లోపల `break;` స్టేట్‌మెంట్ ఎదురైన క్షణమే, లూప్ కండిషన్ ఇంకా true గా ఉన్నప్పటికీ, ఆ లూప్ అక్కడికక్కడే ముగిసిపోయి కర్సర్ బయటకు వచ్చేస్తుంది:

💻 Example 1: Linear Search with Early break
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    int rollNumbers[] = {101, 108, 125, 142, 160, 185};
    int targetStudent = 142;
    bool isFound = false;

    for (int i = 0; i < 6; ++i) {
        if (rollNumbers[i] == targetStudent) {
            std::cout << "Target Student " << targetStudent << " FOUND at index: " << i << " 🎯\n";
            isFound = true;
            break; // విద్యార్థి దొరికాడు, ఇక మిగతా అరే చూడాల్సిన పనిలేదు!
        }
    }

    if (!isFound) std::cout << "Student NOT found in database.\n";
    return 0;
}
2The `continue` Statement (ప్రస్తుత రౌండ్ స్కిప్ చేయడం)

`continue;` లూప్‌ను రద్దు చేయదు! కేవలం ప్రస్తుత రౌండ్‌లో (Current Iteration) దాని కింది లైన్లను స్కిప్ చేసి, నేరుగా తర్వాతి రౌండ్‌కు దూకుతుంది:

💻 Example 2: Printing Only Even Numbers with continue
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    std::cout << "Even Numbers (1 to 10): ";

    for (int i = 1; i <= 10; ++i) {
        if (i % 2 != 0) {
            continue; // బేసి సంఖ్య అయితే ప్రింట్ చేయకుండా తర్వాతి నంబర్‌కి వెళ్లు!
        }
        std::cout << i << " ";
    }
    std::cout << "\n";

    return 0;
}
3The Dangerous `while` Loop + `continue` Trap

బిగినర్లు తరచూ చేసే ప్రమాదకరమైన బగ్: while లూప్‌లో continue రాసేటప్పుడు ఇంక్రిమెంట్ మర్చిపోవడం!

⚠️ The Frozen Infinite Loop Trap

int i = 0;
while (i < 5) {
    if (i == 2) {
        continue; // ❌ BUG: i++ కింది లైన్‌లో ఉంది! అది స్కిప్ అయి i ఎప్పటికీ 2 గానే ఉండిపోతుంది!
    }
    std::cout << i << " ";
    i++;
}

పరిష్కారం: continue కొట్టే ముందే మాన్యువల్‌గా i++; రాయాలి, లేదా for లూప్ వాడాలి (ఎందుకంటే for లూప్‌లో continue కొట్టినా స్టెప్ ఆటోమేటిక్‌గా రన్ అవుతుంది!).

4Breaking Out of Nested Loops (నెస్టెడ్ లూప్‌ల నుండి బయటపడటం)

ఒక నెస్టెడ్ లూప్‌లో break; రాస్తే కేవలం ఆ లోపలి లూప్ మాత్రమే ఆగుతుంది. కానీ రెండు లూప్‌ల నుండి ఒకేసారి బయటపడాలంటే 2 శుభ్రమైన పద్ధతులు ఉన్నాయి:

💻 Example 3: Multi-Level Loop Break with Boolean Flag
C++17 Matrix Search ▶ Run in Compiler 
#include <iostream>

int main() {
    int matrix[3][3] = {
        {1, 2, 3},
        {4, 99, 6},
        {7, 8, 9}
    };

    int searchItem = 99;
    bool shouldStopSearch = false;

    for (int r = 0; r < 3; ++r) {
        for (int c = 0; c < 3; ++c) {
            if (matrix[r][c] == searchItem) {
                std::cout << "Item " << searchItem << " FOUND at Row " << r << ", Col " << c << " ✅\n";
                shouldStopSearch = true;
                break; // లోపలి లూప్ ఆగుతుంది
            }
        }
        if (shouldStopSearch) {
            break; // బయటి లూప్ కూడా ఆగుతుంది!
        }
    }

    return 0;
}
⚠️ Common Developer Pitfalls in Chapter 8
  • Unreachable Code: break; లేదా return; తర్వాత అదే బ్లాక్‌లో కోడ్ రాస్తే కంపైలర్ వార్నింగ్ ఇస్తుంది. ఆ లైన్లు ఎప్పటికీ రన్ కావు.
  • goto స్టేట్‌మెంట్ మితిమీరి వాడటం: C++ లో goto label; ఉంది కానీ ఎడ్గర్ డిజ్క్‌స్ట్రా (Edsger Dijkstra) చెప్పినట్లు ఇది కోడ్‌ను "Spaghetti Code" (అర్థం పర్థం లేని గజిబిజి) గా మారుస్తుంది. కేవలం లోతైన ఎర్రర్ హ్యాండ్లింగ్ తప్ప సాధారణ లూప్‌లలో goto వాడకూడదు.
💻 Hands-on Interactive Practice Challenge

టాస్క్: ఒక బ్యాంక్ ట్రాన్సాక్షన్ స్ట్రీమ్ ప్రాసెసర్ రాయండి:
• నెగెటివ్ లేదా సున్నా ట్రాన్సాక్షన్లు (ఫ్రాడ్ / రద్దయినవి) వస్తే continue తో స్కిప్ చేయండి.
• మొత్తం ప్రాసెస్ చేసిన మొత్తం రోజువారీ పరిమితి ₹50,000 దాటితే break తో సెషన్ ముగించండి:

C++17 Transaction Challenge ▶ Run in Compiler 
#include <iostream>

int main() {
    double streamTransactions[] = {12000.0, -500.0, 15000.0, 0.0, 28000.0, 9000.0};
    double cumulativeProcessed = 0.0;
    const double DAILY_LIMIT = 50000.0;

    std::cout << "========================================\n";
    std::cout << "       BANK TRANSACTION STREAM          \n";
    std::cout << "========================================\n";

    for (const auto& amount : streamTransactions) {
        if (amount <= 0.0) {
            std::cout << "[-] Ignored Invalid / Fraud Amount: Rs. " << amount << " (Skipped)\n";
            continue;
        }

        if (cumulativeProcessed + amount > DAILY_LIMIT) {
            std::cout << "[!] Daily Limit Exceeded with Rs. " << amount << "! Halting Stream.\n";
            break;
        }

        cumulativeProcessed += amount;
        std::cout << "[+] Approved Transaction : Rs. " << amount 
                  << " | Total So Far: Rs. " << cumulativeProcessed << "\n";
    }

    std::cout << "========================================\n";
    std::cout << "Final Approved Total: Rs. " << cumulativeProcessed << "\n";
    std::cout << "========================================\n";

    return 0;
}

❓ Frequently Asked Questions (FAQ)

Q break కి continue కి ప్రధాన వ్యత్యాసం ఏమిటి?

break మొత్తం లూప్‌ను తక్షణమే రద్దు చేసి బయటకు వచ్చేస్తుంది. continue కేవలం ప్రస్తుత రౌండ్‌ను (Current Iteration) మాత్రమే స్కిప్ చేసి, తర్వాతి రౌండ్‌కు వెళ్తుంది (లూప్ రద్దు అవ్వదు).

Q నెస్టెడ్ లూప్‌లలో break రాస్తే అన్ని లూప్‌ల నుండి బయటకు వస్తుందా?

లేదు! break కేవలం అది ఏ లూప్ లోపల రాసారో ఆ ఒక్క లోపలి లూప్ (Innermost Loop) నుండి మాత్రమే బయటకు వస్తుంది. బయటి లూప్‌ల నుండి కూడా బయటకు రావడానికి బూలియన్ ఫ్లాగ్ (bool flag) లేదా ఫంక్షన్ నుండి return వాడాలి.

Q while లూప్‌లో continue వాడేటప్పుడు వచ్చే ప్రమాదం ఏమిటి?

while లూప్‌లో ఇంక్రిమెంట్ (++i) స్టేట్‌మెంట్ కంటే ముందే continue రాస్తే, ఇంక్రిమెంట్ జరగకుండానే తర్వాతి రౌండ్‌కు వెళ్ళిపోయి లూప్ ఇన్ఫినిట్ లూప్‌గా (Infinite Loop) మారిపోతుంది.
