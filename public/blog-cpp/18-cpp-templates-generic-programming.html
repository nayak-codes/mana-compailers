టెంప్లేట్లు & Generic Programming (C++ Templates)

ఒక్కసారే కోడ్ రాయండి, ఏ డేటా టైప్‌కైనా నడపండి! Generic Programming ఫిలాసఫీ, Function Templates మరియు Class Templates సింటాక్స్, కంపైలర్ యొక్క Template Instantiation (Monomorphization) రహస్యం, Zero Runtime Overhead సూత్రం, Template Specialization, మరియు C++20 లో వచ్చిన అధునాతన Concepts ప్రివ్యూ.

📌 Covered in this chapter: Generic Programming · Function Templates · Type Deduction · Monomorphization · Class Templates · Specialization · C++20 Concepts
1 Generic Programming అంటే ఏమిటి? DRY సూత్రం

సాంప్రదాయ ప్రోగ్రామింగ్‌లో రెండు పూర్ణాంకాలను (integers) కూడాలంటే int add(int a, int b) రాయాలి. మళ్ళీ డబుల్స్ కోసం double add(double a, double b) రాయాలి. రేపు స్ట్రింగ్స్ కోసం మరొక ఫంక్షన్ రాయాలి. లాజిక్ ఒక్కటే అయినప్పటికీ కేవలం డేటా టైప్స్ మారిన ప్రతిసారీ కోడ్‌ను డూప్లికేట్ చేయడం DRY (Don't Repeat Yourself) సూత్రానికి పూర్తి విరుద్ధం!

ఈ సమస్యను శాశ్వతంగా పరిష్కరించే ఆధునిక సాఫ్ట్‌వేర్ పద్ధతినే Generic Programming అంటారు. డేటా టైప్‌ను ఒక పారామీటర్‌గా మార్చి, ఏ డేటా టైప్‌కైనా సమర్థవంతంగా పనిచేసే సాధారణ కోడ్ బ్లూప్రింట్ రాయడానికి C++ లో Templates ఉపయోగపడతాయి.

2 Function Templates & ఆటోమేటిక్ Type Deduction

ఫంక్షన్ టెంప్లేట్‌ను ప్రకటించడానికి template <typename T> ఉపయోగిస్తారు. ఇక్కడ T అనేది ఏదైనా డేటా టైప్‌ను సూచించే ప్లేస్‌హోల్డర్ (Type Placeholder):

💻 Example 1: Function Template with Automatic Type Deduction
template_function.cpp
⚡ Try in Compiler 
#include <iostream>
#include <string>

template <typename T>
T getMax(T a, T b) {
    return (a > b) ? a : b;
}

int main() {
    std::cout << "Max int   : " << getMax(10, 25) << "\n";       // T is int
    std::cout << "Max double: " << getMax(3.14, 2.71) << "\n";   // T is double
    std::cout << "Max string: " << getMax(std::string("Apple"), std::string("Zebra")) << "\n";
    return 0;
}
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • template <typename T>: కంపైలర్ కు చెప్తుంది: "ఇది సాధారణ ఫంక్షన్ కాదు, ఏదైనా టైప్ T కి పనిచేసే జెనరిక్ బ్లూప్రింట్".
  • getMax(10, 25): మనం getMax<int>(10, 25) అని ప్రత్యేకంగా చెప్పకపోయినా, రెండు ఆర్గ్యుమెంట్లు int కాబట్టి కంపైలర్ ఆటోమేటిక్ గా T = int అని నిర్ణయిస్తుంది (Type Deduction).
3 అంతర్గత హార్డ్‌వేర్ పనితీరు: Monomorphization (Zero Overhead)

జావా (Java Generics) లేదా పైథాన్ (Python) లో జెనరిక్స్ రన్‌టైమ్ లో పనిచేస్తాయి, దీనివల్ల స్పీడ్ తగ్గుతుంది. కానీ C++ లో టెంప్లేట్లకు రన్‌టైమ్‌తో ఎటువంటి సంబంధం లేదు!

⚙️ కంపైల్-టైమ్ కోడ్ జనరేషన్ (Monomorphization):

కంపైలేషన్ సమయంలో మీరు వాడిన కాల్స్‌ను బట్టి కంపైలర్ తానే స్వయంగా బైనరీ కోడ్ లో విడివిడి నేటివ్ ఫంక్షన్లను ఉత్పత్తి చేస్తుంది:

• getMax(10, 25) పిలిచారు ──► కంపైలర్ int getMax(int, int) కోడ్ జనరేట్ చేస్తుంది.
• getMax(3.14, 2.71) పిలిచారు ──► కంపైలర్ double getMax(double, double) కోడ్ జనరేట్ చేస్తుంది.

ఫలితం: రన్‌టైమ్‌లో ఎలాంటి టైప్-చెక్కింగ్ లేదా స్పీడ్ లాస్ ఉండదు! "Zero Runtime Overhead — What you don't use, you don't pay for!"

4 క్లాస్ టెంప్లేట్లు (Class Templates) & Generic Containers

ఫంక్షన్ల లాగే క్లాసులను కూడా జెనరిక్ గా మార్చవచ్చు. Standard Library లోని std::vector<T>, std::pair<T1, T2> లు క్లాస్ టెంప్లేట్లకు అద్భుతమైన ఉదాహరణలు.

💻 Example 2: Generic KeyValuePair Class Template
class_template.cpp
⚡ Try in Compiler 
#include <iostream>
#include <string>

template <typename K, typename V>
class KeyValuePair {
private:
    K key;
    V val;
public:
    KeyValuePair(K k, V v) : key(k), val(v) {}
    void print() const {
        std::cout << "[" << key << " : " << val << "]\n";
    }
};

int main() {
    KeyValuePair<int, std::string> student(101, "Mahesh");
    student.print();

    KeyValuePair<std::string, double> product("Laptop", 75000.50);
    product.print();
    return 0;
}
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • template <typename K, typename V>: ఒకే క్లాస్ లో ఎన్ని విభిన్న డేటా టైప్స్ నైనా పారామీటర్లుగా తీసుకోవచ్చు.
  • KeyValuePair<int, std::string>: ఒక్కసారి రాసిన క్లాస్ ను విభిన్న కాంబినేషన్లలో రీ-యూజ్ చేసుకోవచ్చు.
5 Template Specialization & Modern C++20 Concepts

సాధారణ టెంప్లేట్ లాజిక్ ఏదైనా ఒక నిర్దిష్ట డేటా టైప్ (ఉదా: bool లేదా const char*) కోసం పనిచేయనప్పుడు, ఆ ఒక్క టైప్ కోసం ప్రత్యేకమైన కోడ్ రాయడాన్ని Template Specialization అంటారు.

🚀 Modern C++20 Concepts ప్రివ్యూ:
పాత C++ లో టెంప్లేట్లలో తప్పుడు టైప్ పంపితే (ఉదా: స్ట్రింగ్ ను కూడటానికి ప్రయత్నించినప్పుడు), కంపైలర్ 100 లైన్ల భయంకరమైన ఎర్రర్ ఇచ్చేది. C++20 లో వచ్చిన Concepts (std::integral, std::floating_point) ద్వారా మనం టెంప్లేట్ కు కచ్చితమైన నిబంధనలను విధించవచ్చు: template <std::integral T> అని రాస్తే పూర్ణాంకాలు మాత్రమే అనుమతించబడతాయి!
6 సాధారణంగా బిగినర్స్ చేసే తప్పులు & బెస్ట్ ప్రాక్టీసెస్

⚠️ Common Beginner Traps

  • Header & Implementation విడదీయడం: సాధారణ ఫంక్షన్ల లాగా టెంప్లేట్ డిక్లరేషన్‌ను .h లో, డెఫినిషన్‌ను .cpp లో పెడితే Linker Error (Undefined Reference) వస్తుంది! కంపైల్-టైమ్ లో కోడ్ జనరేట్ అవ్వాలి కాబట్టి టెంప్లేట్ కోడ్ మొత్తం హెడర్ ఫైల్ లోనే ఉండాలి.
  • Mismatching Argument Types: getMax(10, 20.5) అని పిలిస్తే, కంపైలర్ T ని int అనుకోవాలో double అనుకోవాలో తెలియక ఎర్రర్ ఇస్తుంది. స్పష్టంగా getMax<double>(10, 20.5) అని రాయాలి.

💡 Industry Best Practices

  • Prefer typename over class: template <class T> కంటే template <typename T> వాడటం ఆధునిక C++ పరిశ్రమ ప్రమాణం.
  • Use C++20 auto in functions: Modern C++20 లో auto add(auto a, auto b) అని రాస్తే కంపైలర్ ఆటోమేటిక్ గా దాన్ని టెంప్లేట్ గా మార్చేస్తుంది (Abbreviated Function Template).
❓ Frequently Asked Questions (FAQ)

Q C++ లో Templates రన్‌టైమ్ లో పనిచేస్తాయా లేక కంపైల్-టైమ్ లోనా?

Templates పూర్తిగా కంపైల్-టైమ్ (Compile-time) లోనే పనిచేస్తాయి! మనం కోడ్‌లో రాసే template అనేది కేవలం ఒక బ్లూప్రింట్ లేదా కోడ్-జనరేటర్ లాంటిది. కంపైలర్ ప్రోగ్రామ్‌ను కంపైల్ చేసేటప్పుడు మనం ఏయే డేటా టైప్స్ (int, double, string) ఉపయోగించామో చూసి, వాటికి ప్రత్యేకమైన విడివిడి ఫంక్షన్లను తానే స్వయంగా సృష్టిస్తుంది (దీనినే Template Instantiation లేదా Monomorphization అంటారు). కాబట్టి రన్‌టైమ్‌లో ఎటువంటి స్పీడ్ లాస్ ఉండదు (Zero Runtime Overhead).

Q template <typename T> కి template <class T> కి ఏదైనా తేడా ఉందా?

సాంకేతికంగా రెండింటి మధ్య ఏ విధమైన తేడా లేదు! రెండూ ఒకేలా పనిచేస్తాయి. ప్రాచీన C++ లో కేవలం 'class' మాత్రమే ఉండేది; అయితే T అనేది ప్రాథమిక రకం (int, double) కూడా కావచ్చనే ఉద్దేశంతో Modern C++ లో 'typename' ప్రవేశపెట్టారు. ఆధునిక C++ కోడింగ్ స్టాండర్డ్స్ లో 'typename' వాడటాన్ని ఎక్కువగా సిఫార్సు చేస్తారు.

Q Template Specialization అంటే ఏమిటి? ఎప్పుడు వాడతారు?

సాధారణంగా టెంప్లేట్ అన్ని డేటా టైప్స్‌కు ఒకే సాధారణ లాజిక్‌ను వర్తింపజేస్తుంది. కానీ ఏదైనా ఒక నిర్దిష్ట డేటా టైప్ కోసం (ఉదాహరణకు 'char*' లేదా 'bool' కోసం) ఆ సాధారణ లాజిక్ సరిపోనప్పుడు లేదా ప్రత్యేక ఆప్టిమైజేషన్ అవసరమైనప్పుడు, ఆ ఒక్క టైప్ కోసం విడిగా కస్టమ్ కోడ్ రాయడాన్నే Template Specialization అంటారు.
