టెంప్లేట్లు & Generic Programming (C++ Templates)

ఒక్కసారే కోడ్ రాయండి, ఏ డేటా టైప్‌కైనా నడపండి! Generic Programming ఫిలాసఫీ, Function Templates మరియు Class Templates సింటాక్స్, కంపైలర్ యొక్క Template Instantiation (Monomorphization) రహస్యం, Zero Runtime Overhead సూత్రం, Template Specialization, మరియు C++20 లో వచ్చిన అధునాతన Concepts ప్రివ్యూ.

1 Generic Programming అంటే ఏమిటి? DRY సూత్రం

సాంప్రదాయ ప్రోగ్రామింగ్‌లో రెండు సంఖ్యలను కూడాలంటే int add(int a, int b) రాయాలి. మళ్ళీ ఫ్లోటింగ్ పాయింట్ సంఖ్యల కోసం double add(double a, double b) రాయాలి. రేపు స్ట్రింగ్స్ లేదా ఇతర ఆబ్జెక్టుల కోసం మళ్ళీ రాయాలి. లాజిక్ ఒక్కటే అయినప్పటికీ డేటా టైప్స్ మారిన ప్రతిసారీ కోడ్‌ను డూప్లికేట్ చేయడం DRY (Don't Repeat Yourself) సూత్రానికి విరుద్ధం.

ఈ సమస్యను శాశ్వతంగా పరిష్కరించే ఆధునిక సాఫ్ట్‌వేర్ పద్ధతినే Generic Programming అంటారు. డేటా టైప్‌ను ఒక పారామీటర్‌గా మార్చి, ఏ డేటా టైప్‌కైనా సమర్థవంతంగా పనిచేసే సాధారణ కోడ్ రాయడానికి C++ లో Templates ఉపయోగపడతాయి.

2 Function Templates & Type Deduction

ఒక ఫంక్షన్ టెంప్లేట్‌ను ప్రకటించడానికి template <typename T> లేదా template <class T> ఉపయోగిస్తారు. ఇక్కడ T అనేది ఏదైనా డేటా టైప్‌ను సూచించే ప్లేస్‌హోల్డర్ (Type Placeholder):

[Function Template సింటాక్స్ & ఆటోమేటిక్ డిడక్షన్] template <typename T> T getMax(T a, T b) { return (a > b) ? a : b; } కంపైలర్ గుర్తింపు (Template Type Deduction): • getMax(10, 20) ──► కంపైలర్ T ని 'int' గా గుర్తిస్తుంది • getMax(3.14, 2.71) ──► కంపైలర్ T ని 'double' గా గుర్తిస్తుంది • getMax('x', 'z') ──► కంపైలర్ T ని 'char' గా గుర్తిస్తుంది
3 లోపల ఏం జరుగుతుంది? Template Instantiation (Monomorphization)

చాలామంది ప్రారంభకులు టెంప్లేట్లు రన్‌టైమ్‌లో నెమ్మదిగా పనిచేస్తాయేమో (Java Generics లేదా Python లాగా) అనుకుంటారు. కానీ C++ లో టెంప్లేట్లకు రన్‌టైమ్‌తో ఎలాంటి సంబంధం లేదు!

[కంపైల్-టైమ్ కోడ్ జనరేషన్ (Monomorphization Architecture)] మీరు రాసినది: కేవలం ఒకే ఒక్క టెంప్లేట్ బ్లూప్రింట్: template <typename T> T add(T a, T b) { return a + b; } కంపైలేషన్ సమయంలో మీరు వాడిన కాల్స్ చూసి కంపైలర్ బైనరీలో సృష్టించే అసలైన ఫంక్షన్లు: 1. add(5, 10) పిలిస్తే ──► int add(int a, int b) { return a + b; } 2. add(2.5, 4.5) పిలిస్తే ──► double add(double a, double b) { return a + b; } 3. add("A", "B") పిలిస్తే ──► string add(string a, string b) { return a + b; } ఫలితం: ప్రతి ఫంక్షన్ నేరుగా మెషిన్ కోడ్ లో నేటివ్ స్పీడ్ తో రన్ అవుతుంది! "Zero Runtime Overhead — What you don't use, you don't pay for!"
💻 Code Example 1: Function Template & Explicit Specialization
templates_func_demo.cpp
⚡ Try in Compiler 
#include <iostream>
#include <string>

// 1. Generic Function Template
template <typename T>
T findMax(T a, T b) {
    return (a > b) ? a : b;
}

// 2. Full Template Specialization (bool కోసం ప్రత్యేకమైన లాజిక్)
template <>
bool findMax<bool>(bool a, bool b) {
    std::cout << "  [Specialized bool Logic]: ";
    return a || b; // బూలియన్లలో లాజికల్ OR ఫలితాన్ని ఇస్తుంది
}

int main() {
    std::cout << "Max int   : " << findMax(45, 89) << "\n";
    std::cout << "Max double: " << findMax(3.1415, 2.7182) << "\n";
    std::cout << "Max string: " << findMax(std::string("Apple"), std::string("Zebra")) << "\n";
    std::cout << "Max bool  : " << std::boolalpha << findMax(true, false) << "\n";
    return 0;
}

4 క్లాస్ టెంప్లేట్లు (Class Templates) & మల్టిపుల్ పారామీటర్లు

ఫంక్షన్ల లాగే క్లాసులను కూడా జెనరిక్ గా మార్చవచ్చు. Standard Library లోని std::vector<T>, std::pair<T, U> లు క్లాస్ టెంప్లేట్లకు అత్యుత్తమ ఉదాహరణలు. ఒకే క్లాస్‌ను ఉపయోగించి పూర్ణాంకాలు, స్ట్రింగ్స్ లేదా ఏదైనా యూజర్ డిఫైన్డ్ ఆబ్జెక్టుల కోసం కస్టమ్ కంటైనర్లను నిర్మించవచ్చు.

💻 Code Example 2: Generic Multi-Type Container Class Template
generic_pair_class.cpp
⚡ Try in Compiler 
#include <iostream>
#include <string>

// రెండు వేర్వేరు రకాల డేటాను భద్రపరిచే Generic Pair క్లాస్
template <typename T1, typename T2>
class KeyValuePair {
private:
    T1 key;
    T2 value;

public:
    KeyValuePair(T1 k, T2 v) : key(k), value(v) {}

    void print() const {
        std::cout << "Key: [" << key << "] => Value: [" << value << "]\n";
    }
};

int main() {
    // 1. int, string తో క్లాస్ టెంప్లేట్
    KeyValuePair<int, std::string> student(101, "Suresh");
    student.print();

    // 2. string, double తో క్లాస్ టెంప్లేట్
    KeyValuePair<std::string, double> product("MacBook M3", 149999.0);
    product.print();

    return 0;
}

5 Modern C++20: Concepts & Constraints ప్రివ్యూ

పాత C++ లో టెంప్లేట్లకు ఏ విధమైన పరిమితులు ఉండేవి కావు. ఒకవేళ టెంప్లేట్ ఫంక్షన్ లో a + b అని ఉండి, మీరు + ఆపరేటర్ సపోర్ట్ చేయని ఒక ఆబ్జెక్ట్‌ను పాస్ చేస్తే, కంపైలర్ 100 లైన్ల భయంకరమైన ఎర్రర్ మెసేజ్ ఇచ్చేది!

దీనికి పరిష్కారంగా Modern C++20 లో Concepts పరిచయమయ్యాయి:

💎 Concepts తో క్లీన్ కంపైలర్ రక్షణ:
template <std::integral T> T add(T a, T b) { return a + b; }
ఇప్పుడు ఎవరైనా 실수గా ఫ్లోట్ లేదా స్ట్రింగ్ పంపితే, కంపైలర్ వెంటనే క్లియర్ గా చెబుతుంది: "Constraint not satisfied: T must be an integral type!"
❓ Frequently Asked Questions (FAQ)

Q C++ లో Templates రన్‌టైమ్ లో పనిచేస్తాయా లేక కంపైల్-టైమ్ లోనా?

Templates పూర్తిగా కంపైల్-టైమ్ (Compile-time) లోనే పనిచేస్తాయి! మనం కోడ్‌లో రాసే template అనేది కేవలం ఒక బ్లూప్రింట్ లేదా కోడ్-జనరేటర్ లాంటిది. కంపైలర్ ప్రోగ్రామ్‌ను కంపైల్ చేసేటప్పుడు మనం ఏయే డేటా టైప్స్ (int, double, string) ఉపయోగించామో చూసి, వాటికి ప్రత్యేకమైన విడివిడి ఫంక్షన్లను తానే స్వయంగా సృష్టిస్తుంది (దీనినే Template Instantiation లేదా Monomorphization అంటారు). కాబట్టి రన్‌టైమ్‌లో ఎటువంటి స్పీడ్ లాస్ ఉండదు (Zero Runtime Overhead).

Q template <typename T> కి template <class T> కి ఏదైనా తేడా ఉందా?

సాంకేతికంగా రెండింటి మధ్య ఏ విధమైన తేడా లేదు! రెండూ ఒకేలా పనిచేస్తాయి. ప్రాచీన C++ లో కేవలం class మాత్రమే ఉండేది; అయితే T అనేది ప్రాథమిక రకం (int, double) కూడా కావచ్చనే ఉద్దేశంతో Modern C++ లో typename ప్రవేశపెట్టారు. ఆధునిక C++ కోడింగ్ స్టాండర్డ్స్ లో typename వాడటాన్ని ఎక్కువగా సిఫార్సు చేస్తారు.

Q Template Specialization అంటే ఏమిటి? ఎప్పుడు వాడతారు?

సాధారణంగా టెంప్లేట్ అన్ని డేటా టైప్స్‌కు ఒకే సాధారణ లాజిక్‌ను వర్తింపజేస్తుంది. కానీ ఏదైనా ఒక నిర్దిష్ట డేటా టైప్ కోసం (ఉదాహరణకు char* లేదా bool కోసం) ఆ సాధారణ లాజిక్ సరిపోనప్పుడు లేదా ప్రత్యేక ఆప్టిమైజేషన్ అవసరమైనప్పుడు, ఆ ఒక్క టైప్ కోసం విడిగా కస్టమ్ కోడ్ రాయడాన్నే Template Specialization అంటారు.
