OOP, Classes, Objects & Encapsulation (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 9 📂 Phase 09: Object-Oriented Programming 📅 2026 Master Edition
📌 Covered in this in-depth guide: OOP Concepts · Class vs Object · Access Specifiers (public/private) · Encapsulation · this keyword

C లాంగ్వేజ్ నుండి C++ పుట్టడానికి గల ఒకేఒక్క ముఖ్య కారణం Object-Oriented Programming (OOP). ఒక బ్యాంక్ సాఫ్ట్‌వేర్ రాస్తున్నప్పుడు... కస్టమర్ పేరు, అకౌంట్ బ్యాలెన్స్, డ్రా చేసే ఫంక్షన్స్ ఇవన్నీ విడివిడిగా రాస్తే పెద్ద గందరగోళంగా మారుతుంది. ఆ డేటాని (Variables), మరియు ఆ డేటాతో ఆడుకునే పనులని (Functions) అన్నిటినీ కలిపి ఒక సింగిల్ ప్యాకెట్ లాగా చేయడాన్నే OOP అంటారు. ఈ ఆర్టికల్ లో Classes (క్లాసెస్), Objects (ఆబ్జెక్ట్స్), మరియు డేటాని ఎలా దాచాలి (Encapsulation) అనే బేసిక్ పిల్లర్స్ గురించి డీప్ గా నేర్చుకుందాం.

1 Class మరియు Object అంటే ఏమిటి?

Class (క్లాస్): ఇది కేవలం ఒక డిజైన్ లేదా బ్లూప్రింట్ మాత్రమే. మెమరీలో ఇది ఎలాంటి జాగా తీసుకోదు.

Object (ఆబ్జెక్ట్): ఆ బ్లూప్రింట్ ని వాడుకుని మీరు తయారు చేసే అసలైన ప్రొడక్ట్ నే ఆబ్జెక్ట్ అంటారు. దీనికి మెమరీ లోపల ప్రాణం ఉంటుంది.

🏠 రియల్ లైఫ్ స్టోరీ: ఇంటి డిజైన్ ప్లాన్ vs ఇల్లు

ఒక ఇంజనీర్ పేపర్ మీద "ఇంటి ప్లాన్" గీసాడు. ఆ ప్లాన్ లో రెండు బెడ్ రూమ్స్, ఒక కిచెన్ ఉంటాయి అని రాసి ఉంది. ఆ పేపర్ (Plan) ని మీరు వెళ్లి అందులో పడుకోలేరు కదా! దాన్ని Class అంటారు.

ఇప్పుడు ఒక మేస్త్రి ఆ పేపర్ ప్లాన్ ని చూసి ఇటుకలు, సిమెంట్ పెట్టి కరెక్ట్ గా ఒక బిల్డింగ్ కట్టాడు అనుకోండి. ఆ కట్టిన అసలైన బిల్డింగ్ నే Object అంటారు. ఒక్క ప్లాన్ (Class) తో మీరు ఆ కాలనీలో 100 ఇళ్లు (Objects) అయినా కట్టొచ్చు. ప్రోగ్రామింగ్ లో కూడా ఒక్కసారి క్లాస్ రాస్తే, దాని నుండి ఎన్ని ఆబ్జెక్ట్స్ అయినా క్రియేట్ చేసుకోవచ్చు.

2 Encapsulation (ఎన్‌క్యాప్సులేషన్) ఎందుకు కావాలి?

కొన్ని వేరియబుల్స్ ని బయట వాళ్ళు డైరెక్ట్ గా మార్చకుండా దాచి పెట్టడాన్నే (Hiding) ఎన్‌క్యాప్సులేషన్ అంటారు. దీన్ని C++ లో private మరియు public అనే యాక్సెస్ స్పెసిఫైయర్స్ (Access Specifiers) తో సాధిస్తాం.

ఉదాహరణ: మీ బ్యాంక్ అకౌంట్ బ్యాలెన్స్ ని బయట నుండి డైరెక్ట్ గా account.balance = 100000; అని మార్చేస్తే అది పెద్ద హ్యాకింగ్ అవుతుంది. అందుకే బ్యాలెన్స్ ని private గా పెట్టి, కేవలం deposit() అనే public ఫంక్షన్ ద్వారా మాత్రమే మార్చేలా లిమిట్ చేస్తారు.

3 ఒకే ఒక సింపుల్ కోడ్ (Class & Encapsulation)

కింద కోడ్ లో బ్యాంక్ అకౌంట్ అనే క్లాస్ ని రాసి, బ్యాలెన్స్ ని ప్రైవేట్ గా ఎలా సేఫ్ గా దాచామో చూడండి.

C++ — Class, Object & Encapsulation ▶ Run Code 
#include <iostream>
#include <string>

// క్లాస్ డిజైన్ (బ్లూప్రింట్)
class BankAccount {
private:
    // ప్రైవేట్ డేటా (బయట నుండి యాక్సెస్ కుదరదు)
    double balance = 0.0;

public:
    // పబ్లిక్ ఫంక్షన్స్ (బయట నుండి వాడొచ్చు)
    void deposit(double amount) {
        if (amount > 0) {
            balance += amount; // ఇక్కడ లోపల లాజిక్ చెక్ చేస్తాం
        }
    }

    void showBalance() {
        std::cout << "Current Balance: " << balance << std::endl;
    }
};

int main() {
    // క్లాస్ నుండి ఒక ఆబ్జెక్ట్ ని క్రియేట్ చేసాం
    BankAccount myAccount;
    
    // myAccount.balance = 5000; // ఇది రాస్తే కంపైలర్ కొడుతుంది! (Error)
    
    // పబ్లిక్ ఫంక్షన్స్ ద్వారా మాత్రమే డేటాని మారుస్తున్నాం
    myAccount.deposit(1500);
    myAccount.showBalance();
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • class BankAccount: ఇది ఒక కొత్త డేటా టైప్ ని మనమే సొంతంగా డిజైన్ చేస్తున్నాం అని అర్థం.
  • private: double balance: ఇక్కడ ప్రైవేట్ అనడం వల్ల, main() లో నుండి ఎవరైనా డాట్ (.) పెట్టి ఆ బ్యాలెన్స్ ని డైరెక్ట్ గా మార్చాలని చూస్తే కంపైలర్ సెక్యూరిటీ ఎర్రర్ ఇస్తుంది.
  • public: void deposit(): ఇది బయట వాళ్ళకు కనిపించే సర్వీస్. ఇందులో మీరు లాజిక్ రాసుకున్నారు (amount > 0 అయితేనే కలపాలి అని). దీని ద్వారా బ్యాలెన్స్ సేఫ్ గా అప్‌డేట్ అవుతుంది.
  • దీన్నే డేటా హైడింగ్ (Data Hiding) అంటారు. సింపుల్ గా గుళిక (Capsule) లాగా డేటాని, ఫంక్షన్స్ ని కవర్ చేయడమే ఎన్‌క్యాప్సులేషన్.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: క్లాస్ లో public, private ఏమీ రాయకపోతే ఏమవుతుంది?

మీరు ఏమీ రాయకపోతే, C++ లో ఒక క్లాస్ లోని డేటా అంతా బై డిఫాల్ట్ (By default) private అయిపోతుంది. మీరు బయట నుండి ఏమీ వాడలేరు. అదే C లో స్ట్రక్చర్ (struct) అయితే బై డిఫాల్ట్ అంతా public గా ఉంటుంది.

Q2: క్లాస్ కి, C లో ఉండే Struct కి మెయిన్ డిఫరెన్స్ ఏంటి?

C లాంగ్వేజ్ లోని struct లో మీరు కేవలం వేరియబుల్స్ మాత్రమే పెట్టగలరు, ఫంక్షన్స్ పెట్టలేరు (పాయింటర్స్ వాడితే తప్ప). కానీ C++ లోని క్లాస్ లో వేరియబుల్స్ తో పాటు వాటిని ఆపరేట్ చేసే ఫంక్షన్స్ అన్నీ కలిపి ఒకే ప్యాకేజీ గా ఉంటాయి. అలాగే ప్రైవేట్, పబ్లిక్ సెక్యూరిటీ వస్తుంది.

Q3: Getter, Setter ఫంక్షన్స్ అంటే ఏంటి?

ప్రైవేట్ లో ఉన్న డేటాని బయట వాళ్లు కేవలం చదవడానికి వాడే పబ్లిక్ ఫంక్షన్ ని "Getter" అంటారు (ఉదా: getBalance()). అదే ఆ డేటాని మార్చడానికి వాడే సేఫ్ ఫంక్షన్ ని "Setter" అంటారు (ఉదా: setBalance()). ఇవి ఎన్‌క్యాప్సులేషన్ కి ప్రాణం లాంటివి.
