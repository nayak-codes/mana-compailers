if-else Ladders, Logical Logic & switch-case (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 4 📂 Phase 04: Conditional Statements 📅 2026 Master Edition
📌 Covered in this in-depth guide: Control Flow · if-else Logic · Logical AND/OR · switch-case · fallthrough

కంప్యూటర్ కు స్వతహాగా ఆలోచించే శక్తి లేదు. అది ఏది మంచిదో, ఏది చెడ్డదో డిసైడ్ చేయలేదు. "వర్షం వస్తే గొడుగు తీసుకో, ఎండ కాస్తే టోపీ పెట్టుకో" లాంటి డెసిషన్స్ (Decisions) మనం కోడ్ రూపంలో దానికి నేర్పించాలి. ఒకవేళ ఇలా జరిగితే ఇటు వెళ్ళు, లేకపోతే అటు వెళ్ళు అని కంప్యూటర్ కి దారి చూపించడానికి C++ లో మనం వాడే టెక్నిక్స్ నే Conditional Statements (కండిషనల్ స్టేట్‌మెంట్స్) అంటారు. ఇందులో ముఖ్యంగా if-else మరియు switch అనేవి ఎలా వాడాలో, వాటితో కాంప్లెక్స్ లాజిక్ ఎలా రాయాలో ఈ పాఠంలో చూద్దాం.

1 if-else అనేది ఎలా పనిచేస్తుంది?

if అంటే "ఒకవేళ". బ్రాకెట్స్ లో పెట్టిన కండిషన్ నిజం (True) అయితే లోపల ఉన్న కోడ్ రన్ అవుతుంది. ఒకవేళ అబద్ధం (False) అయితే, పక్కనే ఉన్న else (లేకపోతే) లోపల ఉన్న కోడ్ రన్ అవుతుంది.

💳 రియల్ లైఫ్ స్టోరీ: ఏటీఎం (ATM) లో డబ్బులు డ్రా చేయడం

మీరు ఏటీఎంలో కార్డు పెట్టి పిన్ నంబర్ కొడతారు కదా. అక్కడ ఏటీఎం మెషిన్ లోపల సాఫ్ట్‌వేర్ ఇలా ఆలోచిస్తుంది:

ఒకవేళ (if): మీరు ఎంటర్ చేసిన పిన్ == బ్యాంక్ లో ఉన్న పిన్ అయితే...
👉 అప్పుడు డబ్బులు కౌంట్ చేసి బయటకి ఇవ్వు.

లేకపోతే (else):
👉 "Wrong PIN" అని స్క్రీన్ మీద చూపించు.

ఇలా మన రియల్ లైఫ్ లో ఉన్న ప్రతి కండిషన్ ని if-else తో రాయొచ్చు! ఒకవేళ కండిషన్స్ మరీ ఎక్కువ ఉంటే else if వాడుకుంటూ వెళ్ళొచ్చు (దీన్నే if-else ladder అంటారు).

2 switch-case ఎందుకు వాడాలి?

మీ దగ్గర ఒకే వేరియబుల్ ఉండి, దానికి చాలా ఆప్షన్స్ ఉంటే (ఉదాహరణకు 1 నొక్కితే కస్టమర్ కేర్ కి తెలుగు, 2 నొక్కితే హిందీ, 3 నొక్కితే ఇంగ్లీష్) దానికి పదే పదే else if రాయడం కోడ్ చదవడానికి చాలా కష్టంగా ఉంటుంది. ఇలాంటి మెనూ (Menu) లాంటి సిచువేషన్స్ కోసం C++ మనకు switch ని ఇచ్చింది. ఇది డైరెక్ట్ గా ఏ ఆప్షన్ మ్యాచ్ అయితే అక్కడికి జంప్ చేస్తుంది, స్పీడ్ ఎక్కువ!

3 ఒకే ఒక సింపుల్ కోడ్ (Switch Case Menu)

కింద కోడ్ లో switch వాడి ఒక సింపుల్ టోల్ గేట్ సిస్టమ్ ని ఎలా డిజైన్ చేసామో చూడండి.

C++ — Switch Case Demo ▶ Run Code 
#include <iostream>

int main() {
    int vehicleType = 2; // 1: Bike, 2: Car, 3: Bus
    
    std::cout << "Approaching Toll Gate..." << std::endl;
    
    // Switch లోపలికి డైరెక్ట్ గా జంప్ చేస్తుంది
    switch(vehicleType) {
        case 1:
            std::cout << "Bike Toll: 20 Rs" << std::endl;
            break; // ఇక్కడ బ్రేక్ చేస్తే బయటకి వచ్చేస్తుంది
        case 2:
            std::cout << "Car Toll: 50 Rs" << std::endl;
            break;
        case 3:
            std::cout << "Bus Toll: 150 Rs" << std::endl;
            break;
        default:
            std::cout << "Unknown Vehicle! Go to Office." << std::endl;
    }
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • switch(vehicleType) అనగానే కంపైలర్ vehicleType వాల్యూ ఎంత ఉందో (ఇక్కడ 2) చూసుకుని, మిగతావి వదిలేసి డైరెక్ట్ గా case 2: దగ్గరికి జంప్ అవుతుంది.
  • అక్కడ "Car Toll" ప్రింట్ అయ్యాక, break; వస్తుంది. ఆ బ్రేక్ ఉండటం వల్లే అది అక్కడితో ఆగిపోయి స్విచ్ బాక్స్ లోనుండి బయటకి వచ్చేస్తుంది.
  • ఒకవేళ మీరు పైన 5 అని ఇచ్చారనుకోండి, అసలు ఆ ఆప్షన్ అక్కడ లేదు కాబట్టి, ఆటోమేటిక్ గా default: లో ఉన్నది రన్ అవుతుంది.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: Switch లోపల break; రాయకపోతే ఏమవుతుంది?

దీన్నే Fallthrough (ఫాల్ త్రూ) అంటారు. బ్రేక్ లేకపోతే అది మ్యాచ్ అయిన దగ్గర నుండి కింద ఉన్న అన్ని కేసులను (సంబంధం లేకపోయినా) బ్లైండ్ గా రన్ చేసుకుంటూ వెళ్ళిపోతుంది! కొన్నిసార్లు ఉద్దేశపూర్వకంగా మల్టిపుల్ కేసులకు ఒకటే రిజల్ట్ ఇవ్వడానికి దీన్ని వాడతారు.

Q2: switch లో స్ట్రింగ్స్ (పదాలు) వాడొచ్చా?

లేదండి! C++ లో switch అనేది కేవలం ఇంటీజర్స్ (నంబర్స్) మరియు అక్షరాలకు (chars లేదా enums) మాత్రమే సపోర్ట్ చేస్తుంది. జావా లాగా C++ లో డైరెక్ట్ గా టెక్స్ట్ తో మ్యాచ్ చేయడం కుదరదు. స్ట్రింగ్స్ తో మ్యాచ్ చేయాలంటే మీరు ఖచ్చితంగా if-else మాత్రమే వాడాలి.

Q3: = కి మరియు == కి తేడా ఏంటి?

= అంటే ఒక డబ్బాలోకి వాల్యూ ని అసైన్ చేయడం (పెట్టడం). == అంటే రెండు వాల్యూస్ సమానంగా ఉన్నాయా లేదా అని పోల్చడం (Compare). చాలామంది స్టూడెంట్స్ if(a = 5) అని రాస్తారు, అది తప్పు! అప్పుడు ఆ కండిషన్ ఎప్పటికీ నిజమే అవుతుంది. కరెక్ట్ పద్ధతి if(a == 5).
