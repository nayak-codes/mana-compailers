ఆపరేటర్లు & ఎక్స్‌ప్రెషన్స్ (Operators & Expressions in C++)

⚡ Modern C++20 / C++17 🟢 Chapter 4 of 20 📂 Phase 1: C++ Basics & Fundamentals 📅 2026 Edition
📌 Covered in this chapter: Arithmetic Operators & Integer Division Trap · Pre-increment (++x) vs Post-increment (x++) · Relational & Comparison Operators · Logical Operators & Short-Circuit Evaluation · Fast Bitwise Operations (&, |, ^, ~, <<, >>) · Ternary Operator (? :) · Operator Precedence & Associativity Table
ప్రోగ్రామింగ్‌లో వేరియబుల్స్ అనేవి ఇటుకలైతే, వాటిని కలిపి అద్భుతమైన లాజిక్‌ను నిర్మించే సిమెంట్ ఆపరేటర్లు (Operators). ఈ అధ్యాయంలో లెక్కలు చేసే గణిత ఆపరేటర్ల నుండి CPU హార్డ్‌వేర్ లెవల్‌లో మెరుపు వేగంతో పనిచేసే Bitwise Operators వరకు, మరియు కంపైలర్ ఆర్డర్ ఆఫ్ ఎగ్జిక్యూషన్ ఎలా చేస్తుందో లోతుగా విశ్లేషిద్దాం.
1Arithmetic Operators (గణిత ఆపరేటర్లు & Division Trap)

C++ లో ప్రాథమిక గణిత పనుల కోసం 5 ముఖ్యమైన Arithmetic Operators ఉన్నాయి:

  • + (Addition): రెండు సంఖ్యలను కలుపుతుంది.
  • - (Subtraction): తీసివేత చేస్తుంది.
  • * (Multiplication): గుణకారం చేస్తుంది.
  • / (Division): భాగాహారం చేస్తుంది.
  • % (Modulo / Remainder): భాగాహారంలో శేషాన్ని (Remainder) ఇస్తుంది (కేవలం ఇంటిజర్లపై మాత్రమే పనిచేస్తుంది).

⚠️ The Silent Killer: Integer Division Trap (5 / 2 = 2)

గణితంలో $5 \div 2 = 2.5$. కానీ C++ లో రెండు int విలువలను భాగిస్తే, రిజల్ట్ కూడా కచ్చితంగా int మాత్రమే అవుతుంది! అంటే పాయింట్ తర్వాత ఉన్న దశాంశం తుడిచిపెట్టుకుపోతుంది: 

int result = 5 / 2; // ఫలితం: 2 (0.5 పోయింది! ❌)
double correct = 5.0 / 2; // ఫలితం: 2.5 (ఒక్కటి డబుల్ అయినా సరిపోతుంది! ✅)
💻 Example 1: Arithmetic Operators & Modulo
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    int totalMinutes = 145;

    // గంటలు మరియు మిగిలిన నిమిషాలు లెక్కించడం
    int hours = totalMinutes / 60;     // 145 / 60 = 2 గంటలు
    int remainingMins = totalMinutes % 60; // 145 % 60 = 25 నిమిషాలు

    std::cout << totalMinutes << " minutes = " 
              << hours << " hours and " << remainingMins << " minutes.\n";

    return 0;
}
2Pre-increment (`++x`) vs Post-increment (`x++`)

ఒక వేరియబుల్ విలువను 1 పెంచడానికి ఇంక్రిమెంట్ (++) వాడతాం. కానీ అది వేరియబుల్ కంటే ముందుందా (Pre), వెనకాల ఉందా (Post) అనేదాన్ని బట్టి ఫలితం పూర్తిగా మారిపోతుంది!

┌─────────────────────┬─────────────────────────────────────────────────────────┐ │ Operator │ ఎలా పనిచేస్తుంది? (Execution Order) │ ├─────────────────────┼─────────────────────────────────────────────────────────┤ │ ++x (Pre-increment) │ 1. ముందు విలువ 1 పెరుగుతుంది. │ │ │ 2. పెరిగిన కొత్త విలువ ఆ స్టేట్‌మెంట్‌లో వాడబడుతుంది. │ ├─────────────────────┼─────────────────────────────────────────────────────────┤ │ x++ (Post-increment)│ 1. ముందు పాత విలువ ఆ స్టేట్‌మెంట్‌లో వాడబడుతుంది. │ │ │ 2. ఆ తర్వాత మాత్రమే మెమరీలో 1 పెరుగుతుంది. │ └─────────────────────┴─────────────────────────────────────────────────────────┘
💻 Example 2: Pre vs Post Increment in Action
C++17 Increment ▶ Run in Compiler 
#include <iostream>

int main() {
    int a = 10;
    int b = 10;

    // Pre-increment: ముందు పెరుగుతుంది
    int preResult = ++a; 
    std::cout << "Pre-increment  : preResult = " << preResult << ", a = " << a << "\n";

    // Post-increment: పాత విలువ అసైన్ అయ్యాక పెరుగుతుంది
    int postResult = b++;
    std::cout << "Post-increment : postResult = " << postResult << ", b = " << b << "\n";

    return 0;
}
💡 Performance Tip:

x++ పాత విలువను తాత్కాలిక కాపీ (Temporary Object) గా దాచుకోవాలి కాబట్టి, లూప్‌లలో లేదా ఇటరేటర్లలో (Iterators) ఎల్లప్పుడూ `++x` వాడటమే వేగవంతమైన ప్రొఫెషనల్ పద్ధతి.

3Relational Operators (పోలిక ఆపరేటర్లు)

రెండు విలువలని పోల్చి చూసి true (1) లేదా false (0) బూలియన్ ఫలితాన్ని ఇవ్వడానికి ఇవి వాడబడతాయి:

  • == (Equal to): రెండు విలువలూ సమానమైతే true. (సింగిల్ = అసైన్‌మెంట్ కోసం వాడతాం, సమానత్వం కోసం డబుల్ == వాడాలి!).
  • != (Not Equal to): సమానం కాకపోతే true.
  • >, <: గ్రేటర్ దాన్, లెస్ దాన్.
  • >=, <=: గ్రేటర్ దాన్ ఆర్ ఈక్వల్ టు, లెస్ దాన్ ఆర్ ఈక్వల్ టు.
4Logical Operators & Short-Circuit Evaluation

అనేక షరతులను (Multiple Conditions) ఒకేసారి పరీక్షించడానికి లాజికల్ ఆపరేటర్లు వాడతాం:

  • && (Logical AND): ఇచ్చిన అన్ని షరతులూ true అయితేనే true.
  • || (Logical OR): ఇచ్చిన వాటిలో ఏదైనా ఒక్క షరతు true అయినా true.
  • ! (Logical NOT): ఉన్న విలువను తిరగేస్తుంది (true ని false గా, false ని true గా).

⚡ Short-Circuit Evaluation (స్మార్ట్ కంపైలర్ ఆప్టిమైజేషన్)

C++ అనవసరమైన పనులు చేయదు:

  • AND (&&) లో: మొదటి కండిషన్ false అయితే, మొత్తం స్టేట్‌మెంట్ ఎప్పటికీ true కాలేదు కాబట్టి, రెండవ కండిషన్‌ను కంపైలర్ అస్సలు ఎగ్జిక్యూట్ చేయదు!
  • OR (||) లో: మొదటి కండిషన్ true అయితే, మొత్తం స్టేట్‌మెంట్ ఆటోమేటిక్‌గా true కాబట్టి, రెండవదాన్ని పరీక్షించకుండా వదిలేస్తుంది!
💻 Example 3: Logical Operators & Eligibility Check
C++17 Logical ▶ Run in Compiler 
#include <iostream>

int main() {
    int age = 21;
    bool hasDrivingLicense = true;
    bool hasCarInsurance = false;

    // కారు నడపడానికి వయస్సు 18 దాటాలి మరియు లైసెన్స్ ఉండాలి
    bool canDrive = (age >= 18) && hasDrivingLicense;

    // ప్రయాణం చేయడానికి సొంత కారు ఇన్సూరెన్స్ ఉండాలి లేదా ట్యాక్సీ పిలవాలి
    bool canTravel = hasCarInsurance || true; // Taxi option is always true

    std::cout << std::boolalpha; // 1, 0 కి బదులుగా true, false ప్రింట్ చేస్తుంది
    std::cout << "Eligible to Drive : " << canDrive << "\n";
    std::cout << "Able to Travel    : " << canTravel << "\n";

    return 0;
}
5Bitwise Operators (ట్రాన్సిస్టర్ లెవల్ మెరుపు వేగం)

కాంపిటీటివ్ ప్రోగ్రామింగ్, గేమింగ్ ఇంజిన్లు, మరియు ఎంబెడెడ్ డివైసెస్‌లో మెమరీలోని బైనరీ బిట్స్ (0s & 1s) పై నేరుగా పనిచేయడానికి Bitwise Operators వాడతారు:

  • & (Bitwise AND): రెండు బిట్స్ 1 అయితేనే 1.
  • | (Bitwise OR): ఏదో ఒక బిట్ 1 అయినా 1.
  • ^ (Bitwise XOR): రెండు బిట్స్ వేర్వేరుగా ఉంటేనే 1 (1^0=1, 1^1=0).
  • ~ (Bitwise NOT / Complement): 0 ని 1 గా, 1 ని 0 గా మారుస్తుంది.
  • << (Left Shift): బిట్లను ఎడమవైపు జరుపుతుంది (2 తో గుణించినట్లు: x << 1 అంటే x * 2).
  • >> (Right Shift): బిట్లను కుడివైపు జరుపుతుంది (2 తో భాగించినట్లు: x >> 1 అంటే x / 2).
💻 Example 4: Competitive Programming Bit Manipulation Tricks
C++17 Bitwise ▶ Run in Compiler 
#include <iostream>

int main() {
    int num = 14; // Binary: 00001110

    // ట్రిక్ 1: సరిసంఖ్యో బేసిసంఖ్యో కనుగొనడం (Even or Odd)
    // బేసిసంఖ్య చివరి బిట్ ఎల్లప్పుడూ 1 ఉంటుంది
    bool isOdd = (num & 1);
    std::cout << num << " is " << (isOdd ? "ODD" : "EVEN") << "\n";

    // ట్రిక్ 2: Left Shift తో 2 తో గుణకారం (Fastest Multiply by 2)
    int doubled = num << 1; // 14 * 2 = 28
    std::cout << "Fast Multiply 14 * 2 (num << 1) : " << doubled << "\n";

    // ట్రిక్ 3: Right Shift తో 2 తో భాగాహారం (Fastest Divide by 2)
    int halved = num >> 1; // 14 / 2 = 7
    std::cout << "Fast Divide 14 / 2 (num >> 1)   : " << halved << "\n";

    return 0;
}
6Ternary Operator (`? :`) & Operator Precedence

చిన్న if-else కండిషన్‌ను ఒకే లైన్‌లో రాసేందుకు Ternary Operator వాడతాం:
condition ? value_if_true : value_if_false;

ఆపరేటర్ ప్రాధాన్యత (Operator Precedence Table):

గణితంలో BODMAS లాగే C++ లో కూడా ఏ ఆపరేషన్ ముందు జరగాలో ఒక నిర్దిష్ట ఆర్డర్ ఉంటుంది:

Priority Operators Associativity
1 (Highest) () Parentheses, :: Scope, ++ -- (Post) Left to Right
2 ++ -- (Pre), ! ~, Unary + - Right to Left
3 * / % (Multiplicative) Left to Right
4 + - (Additive) Left to Right
5 << >> (Bitwise Shifts & Streams) Left to Right
6 < <= > >=, == != Left to Right
7 & ^ | (Bitwise) Left to Right
8 && || (Logical) Left to Right
9 (Lowest) ? : (Ternary), = += -= *= (Assignment) Right to Left
⚠️ Common Developer Pitfalls in Chapter 4
  • = కి == కి తేడా మర్చిపోవడం: if (x = 5) అని రాస్తే, x లోకి 5 అసైన్ అయ్యి అది ఎల్లప్పుడూ true అయిపోతుంది! పోల్చడానికి కచ్చితంగా if (x == 5) అని రెండు సమాన గుర్తులు వాడాలి.
  • ఒకే స్టేట్‌మెంట్‌లో వేరియబుల్‌ను మార్చి వాడటం (Undefined Behavior): int y = x++ + ++x; అని రాస్తే కంపైలర్‌కు కచ్చితమైన రూల్ ఉండదు (Undefined Behavior). ఇలాంటి గందరగోళ కోడ్ ఎప్పుడూ రాయకూడదు.
💻 Hands-on Interactive Practice Challenge

టాస్క్: ఒక సంవత్సరం లీప్ ఇయరా (Leap Year) కాదా అనేదాన్ని లాజికల్ ఆపరేటర్లు మరియు టెర్నరీ ఆపరేటర్ వాడి ఒకే స్టేట్‌మెంట్‌లో కనిపెట్టే ప్రోగ్రామ్ రాయండి:
నియమం: 4 తో భాగించబడాలి మరియు 100 తో భాగించబడకూడదు, లేదా 400 తో భాగించబడాలి.

C++17 Leap Year Challenge ▶ Run in Compiler 
#include <iostream>

int main() {
    int testYear1 = 2024;
    int testYear2 = 1900;
    int testYear3 = 2000;

    // లీప్ ఇయర్ లాజిక్: (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)
    auto isLeapYear = [](int y) {
        return ((y % 4 == 0 && y % 100 != 0) || (y % 400 == 0));
    };

    std::cout << "========================================\n";
    std::cout << "       LEAP YEAR LOGICAL EVALUATOR      \n";
    std::cout << "========================================\n";
    std::cout << "Year " << testYear1 << " : " << (isLeapYear(testYear1) ? "LEAP YEAR 🎉" : "COMMON YEAR") << "\n";
    std::cout << "Year " << testYear2 << " : " << (isLeapYear(testYear2) ? "LEAP YEAR" : "COMMON YEAR (Div by 100!) ❌") << "\n";
    std::cout << "Year " << testYear3 << " : " << (isLeapYear(testYear3) ? "LEAP YEAR (Div by 400!) 🎉" : "COMMON YEAR") << "\n";
    std::cout << "========================================\n";

    return 0;
}

❓ Frequently Asked Questions (FAQ)

Q ++x (Pre-increment) కి x++ (Post-increment) కి తేడా ఏమిటి?

++x ముందుగా వేరియబుల్ విలువను 1 పెంచి, ఆ తర్వాత ప్రస్తుత ఎక్స్‌ప్రెషన్‌లో ఉపయోగిస్తుంది. x++ ముందు పాత విలువను ఉపయోగించి, ఆ స్టేట్‌మెంట్ పూర్తయిన తర్వాత మాత్రమే 1 పెంచుతుంది. లూప్‌లలో సాధారణంగా ++x వాడటమే ఎక్కువ ఆప్టిమైజ్డ్.

Q లాజికల్ ఆపరేటర్లలో Short-Circuit Evaluation అంటే ఏమిటి?

C++ లో AND (&&) ఆపరేషన్‌లో మొదటి కండిషన్ false అయితే, రెండవ కండిషన్‌ను కంపైలర్ అస్సలు పరీక్షించదు. అలాగే OR (||) లో మొదటిది true అయితే రెండవదాన్ని పరీక్షించదు. దీనిని Short-Circuit Evaluation అంటారు. ఇది ప్రోగ్రామ్ స్పీడ్‌ను పెంచుతుంది.

Q C++ లో Bitwise ఆపరేటర్లు ఎందుకు అంత ఫాస్ట్ గా ఉంటాయి?

Bitwise ఆపరేటర్లు కంప్యూటర్ మెమరీలోని బైనరీ బిట్స్ (0s & 1s) పై నేరుగా CPU ట్రాన్సిస్టర్ లెవల్‌లో పనిచేస్తాయి. ఉదాహరణకు n & 1 ద్వారా ఒక సంఖ్య సరిసంఖ్యో బేసిసంఖ్యో కనుగొనడం సాధారణ డివిజన్ % కంటే చాలా రెట్లు వేగవంతమైనది.
