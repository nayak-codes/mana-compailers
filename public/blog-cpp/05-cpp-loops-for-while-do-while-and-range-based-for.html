for, while, Range-for & Practice (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 5 📂 Phase 05: Loops & Control Flow 📅 2026 Master Edition
📌 Covered in this in-depth guide: Iteration · for Loop · while Loop · Range-based for (C++11) · break & continue

కంప్యూటర్లకు ఉన్న అతిపెద్ద పవర్ ఏంటంటే అలసిపోకుండా ఒకే పనిని కోట్లాది సార్లు సెకన్ల వ్యవధిలో చేయడం! మీరు ఒక లైన్ ని 10 సార్లు ప్రింట్ చేయాలంటే 10 సార్లు cout రాయొచ్చు. కానీ లక్ష సార్లు ప్రింట్ చేయాలంటే? అలా కోడ్ రాసుకుంటూ పోవడం సాధ్యం కాదు. ఇక్కడే మనకు Loops (లూప్స్) అనే బ్రహ్మాస్త్రం ఉపయోగపడుతుంది. ఒక కండిషన్ నిజం అయ్యేంతవరకు ఒకే కోడ్ ని పదే పదే తిప్పడాన్నే లూప్స్ అంటారు. పాత లూప్స్ తో పాటు మోడరన్ C++ లో వచ్చిన Range-based for loop అనే అద్భుతమైన ఫీచర్ గురించి ఇక్కడ డీప్ గా నేర్చుకుందాం.

1 లూప్స్ లో రకాలు (Types of Loops)

మనకి మూడు ప్రధానమైన లూప్స్ ఉన్నాయి. అవసరాలను బట్టి ప్రోగ్రామర్ సరైన లూప్ ని ఎంచుకోవాలి.

  • for Loop: మీకు "ఎన్నిసార్లు" తిప్పాలో ముందే ఖచ్చితంగా తెలిస్తే (ఉదా: 1 నుండి 100 వరకు) ఇది బెస్ట్.
  • while Loop: ఎన్నిసార్లు తిరగాలో తెలీదు, కానీ ఒక కండిషన్ బ్రేక్ అయ్యేవరకు తిరుగుతూనే ఉండాలి అంటే (ఉదా: యూజర్ 0 నొక్కేదాకా గేమ్ ఆడాలి) ఇది బెస్ట్.
  • do-while Loop: కండిషన్ చెక్ చేయకుండా కనీసం ఒక్కసారి అయినా కోడ్ రన్ అవ్వాలి, ఆ తర్వాతే చెక్ చేయాలి అనుకుంటే ఇది వాడాలి.

🎧 రియల్ లైఫ్ స్టోరీ: మ్యూజిక్ ప్లేయర్ లో "Repeat" బటన్

మీరు ఒక పాట వింటున్నారు, అది చాలా నచ్చింది. మీరు ఆ పాటను 5 సార్లు వినాలనుకుంటే మీరు ప్లేయర్ లో కౌంట్ పెట్టుకుంటారు. (ఇదే for లూప్).

కానీ, మీరు పని చేసుకుంటున్నంత సేపు ఆ పాట ప్లే అవుతూనే ఉండాలి, పని అవ్వగానే మీరే ఆపేస్తారు. ఇది while లూప్ లాంటిది (పని జరుగుతున్నంత సేపు సాంగ్ లూప్ అవుతూనే ఉంటుంది). కంప్యూటర్లు ఈ సైక్లింగ్ ని ఉపయోగించే ప్రపంచంలో ఎన్నో అద్భుతాలు చేస్తాయి.

2 Modern C++ లో Range-based for loop

పాత స్టైల్ for(int i=0; i<10; i++) రాయాలంటే చాలా మంది తప్పులు చేస్తారు (ఉదాహరణకు <= పెట్టాల్నా వద్దా అని). ఈ కన్ఫ్యూజన్ పోగొట్టడానికి C++11 లో పైథాన్ లాంటి ఒక సింపుల్ సింటాక్స్ తెచ్చారు. అదే Range-based for loop. మీ దగ్గర ఒక డేటా బాక్స్ (Array/Vector) ఉంటే, ఆ బాక్స్ లో ఉన్న ప్రతి వస్తువు (Item) దగ్గరికి అది ఆటోమేటిక్ గా వెళ్లి డేటాని తెస్తుంది, మనమేమీ కౌంట్ చేయక్కర్లేదు!

3 ఒకే ఒక సింపుల్ కోడ్ (Range-based for)

కింద కోడ్ లో పాత స్టైల్ కౌంటింగ్ లేకుండా, C++11 వాడి ఎంత క్లీన్ గా లూప్ రాశామో చూడండి.

C++11 — Range-based for Loop ▶ Run Code 
#include <iostream>

int main() {
    // ఒక అర్రే (బాక్స్) లో 5 మార్కులు ఉన్నాయి
    int marks[] = {85, 90, 75, 92, 88};
    
    std::cout << "Marks List:" << std::endl;
    
    // C++11 మ్యాజిక్: అర్రే లో ఉన్న ప్రతి మార్కు 'm' లోకి వస్తుంది
    for (int m : marks) {
        std::cout << "=> " << m << std::endl;
    }
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • int marks[]: ఇక్కడ 5 నంబర్స్ ని ఒక గ్రూప్ గా పెట్టుకున్నాం.
  • for (int m : marks): దీని అర్థం "marks అనే గ్రూప్ లో ఉన్న ప్రతి ఒక్క ఐటమ్ ని తీసుకుని, దానికి m అని పేరు పెట్టు" అని.
  • మొదటి సారి లూప్ తిరిగినప్పుడు m వాల్యూ 85 అవుతుంది, రెండోసారి 90 అవుతుంది... ఇలా ఆ బాక్స్ లో ఐటమ్స్ అయిపోయేదాకా అది దానంతట అదే తిరుగుతుంది. ఇండెక్స్ లు (i=0) కౌంట్ చేయాల్సిన పని లేదు!
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: break మరియు continue కి తేడా ఏంటి?

లూప్ నడుస్తున్నప్పుడు మధ్యలో ఆగిపోయి మొత్తం లూప్ లోనుండి బయటకి పారిపోవాలంటే break వాడతారు. కానీ కేవలం ఆ ఒక్క రౌండ్ ని స్కిప్ చేసి (దూకేసి) నెక్స్ట్ రౌండ్ ని కంటిన్యూ చేయాలంటే continue వాడతారు.

Q2: ఇన్ఫినిట్ లూప్ (Infinite Loop) అంటే ఏంటి? అది మంచిదేనా?

కండిషన్ ఎప్పటికీ అబద్ధం కాకపోతే లూప్ ఆగదు, జీవితాంతం తిరుగుతూనే ఉంటుంది. పొరపాటున పడితే ప్రోగ్రామ్ క్రాష్ అవుతుంది (బ్రౌజర్ హ్యాంగ్ అయినట్లు). కానీ గేమ్స్ లో (గేమ్ ఇంజిన్ లూప్) మరియు సర్వర్స్ లో ఉద్దేశపూర్వకంగా while(true) అని రాసి ఇన్ఫినిట్ లూప్స్ వాడుతారు, ఎందుకంటే అవి ఎప్పటికీ ఆఫ్ అవ్వకూడదు కాబట్టి!

Q3: Range-based for loop లో int m బదులు auto m రాయొచ్చా?

ఖచ్చితంగా రాయొచ్చు! అదొక్కటే కాదు, మోడరన్ C++ లో మెమరీ వేస్ట్ కాకుండా ఉండటానికి auto& m అని పాయింటర్స్ రిఫరెన్స్ లాగా రాస్తారు. ఇది డేటాని కాపీ చేయకుండా డైరెక్ట్ గా అసలు డేటాని వాడుకుంటుంది, దీని వల్ల స్పీడ్ అమాంతం పెరుగుతుంది.
