Ranges & Views (C++20) Masterclass (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 21 📂 Phase 21: Ranges & Views (C++20) 📅 2026 Master Edition
📌 Covered in this in-depth guide: Ranges TS · std::views · Pipeline syntax (|) · Lazy Evaluation · Functional Programming

C++ హిస్టరీలో C++20 అనేది ఇంకొక పెద్ద మైలురాయి. పాత C++ లో ఒక వెక్టార్ ని సార్ట్ చేయాలంటే std::sort(v.begin(), v.end()); అని రాసేవాళ్లం. ఆ begin(), end() రాయడం చాలా మందికి విసుగు తెప్పించేది. వాటన్నిటిని సింపుల్ చేస్తూ, ఫంక్షనల్ ప్రోగ్రామింగ్ (Functional Programming) ని C++ లోకి తీసుకురావడానికి తయారు చేసిందే Ranges (రేంజెస్) లైబ్రరీ. పైప్‌లైన్ సింబల్ (|) వాడి డేటాని ఫిల్టర్ చేయడం, మార్చడం లాంటి పనులు గాలిలో తేలుతున్నట్లు ఎంతో స్మూత్ గా ఎలా రాయొచ్చో ఈ మాస్టర్ క్లాస్ లో నేర్చుకుందాం. ఇది C++ భవిష్యత్తు!

1 Ranges అంటే ఏమిటి? begin/end ఎందుకు రాయక్కర్లేదు?

రేంజ్ (Range) అంటే సింపుల్ గా చెప్పాలంటే దేనికైతే begin మరియు end ఉంటాయో అదొక రేంజ్ (ఉదాహరణకు ఒక వెక్టార్, ఒక అర్రే). C++20 నుండి మీరు ప్రతి ఫంక్షన్ కి begin(), end() పాస్ చేయాల్సిన పనిలేదు, డైరెక్ట్ గా ఆ వెక్టార్ నే పాస్ చేస్తే కంపైలర్ దానంతట అదే అర్థం చేసుకుంటుంది (ఉదాహరణకు std::ranges::sort(v);). ఇదొక పెద్ద రిలీఫ్!

🚿 రియల్ లైఫ్ స్టోరీ: వాటర్ పైప్‌లైన్ మరియు ఫిల్టర్స్ (Pipelines & Views)

ఒక మురుగు నీటి కాలువ (Vector of junk numbers) ఉంది. అందులో నుండి మీకు కావాల్సిన స్వచ్ఛమైన నీటిని (Even numbers) మీరు ఎలా తీస్తారు?

మామూలుగా అయితే ఒక పెద్ద బకెట్ తీసుకుని, అందులో నీళ్ళు వడగట్టి ఇంకో బకెట్ లో పోయాలి (అంటే మెమరీ వేస్ట్). కానీ Views (వ్యూస్) వాడితే మీరు అక్కడ ఒక పైపు (Pipeline |) మరియు ఒక ఫిల్టర్ (Filter) ఫిక్స్ చేస్తారు. ఆ నీరు ఫిల్టర్ గుండా ప్రయాణిస్తున్నప్పుడు మాత్రమే క్లీన్ అవుతుంది, అనవసరమైన ఎక్స్ట్రా బకెట్ అవసరం లేదు!
దీన్నే C++ లో Lazy Evaluation (లేజీ ఎవాల్యుయేషన్) అంటారు. అంటే మీరు ఫిల్టర్ పెట్టినప్పుడు అది డేటాని కాపీ చేయదు. మీరు ఆ డేటాని ఎప్పుడైతే అడుగుతారో (చదువుతారో) అప్పుడు ఆన్ ది స్పాట్ లో లాజిక్ రన్ అవుతుంది. ఇది అల్టిమేట్ పర్ఫార్మెన్స్ హ్యాక్!

2 పైప్‌లైన్ సింటాక్స్ (|) యొక్క అద్భుతం

లైనక్స్ (Linux) లో కమాండ్స్ ని ఒకదానితో ఒకటి కలపడానికి పైప్ (|) వాడుతారు. దాన్ని సేమ్ టు సేమ్ C++20 లో ప్రవేశపెట్టారు.

లాజిక్: డేటా | ముందు ఫిల్టర్ చెయ్ | తర్వాత మార్చు | తర్వాత ప్రింట్ చెయ్. ఇలా గొలుసుకట్టు లాగా (Chaining) ఎంత పెద్ద కాంప్లెక్స్ లాజిక్ నైనా సరే ఒకే లైన్ లో రాసుకుంటూ వెళ్లిపోవచ్చు.

3 ఒకే ఒక సింపుల్ కోడ్ (Ranges & Views)

కింద కోడ్ లో 1 నుండి 6 వరకు ఉన్న నంబర్స్ లో... కేవలం సరి సంఖ్యలను (Even) మాత్రమే తీసుకుని, వాటిని డబుల్ (x2) చేసి ఎలా ప్రింట్ చేస్తున్నామో (అదీ వితౌట్ ఎక్స్ట్రా మెమరీ) చూడండి.

C++20 — Ranges & Views Pipeline ▶ Run Code 
#include <iostream>
#include <vector>
#include <ranges> // C++20 మ్యాజిక్ ఇక్కడే ఉంది

int main() {
    std::vector<int> numbers = {1, 2, 3, 4, 5, 6};
    
    // ఒకే ఒక లైన్ లో పైప్‌లైన్ తో లాజిక్ (Lazy Evaluation)
    auto result = numbers 
                | std::views::filter([](int n) { return n % 2 == 0; })  // సరి సంఖ్యలు (2, 4, 6) ఫిల్టర్ 
                | std::views::transform([](int n) { return n * 2; });   // వాటిని డబుల్ చేయడం (4, 8, 12)
                
    std::cout << "Processed Even Numbers:" << std::endl;
    
    // ఆ పైప్‌లైన్ రిజల్ట్ ని రేంజ్ లూప్ వాడి ప్రింట్ చేస్తున్నాం
    for (int n : result) {
        std::cout << "- " << n << std::endl;
    }
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • #include <ranges>: C++20 కంపైలర్ లో ఈ హెడర్ ద్వారా పైప్‌లైన్ సింటాక్స్ వస్తుంది.
  • std::views::filter(...): ఇది ఒక అద్దం (View) లాంటిది. ఒరిజినల్ వెక్టార్ ని ఏమీ మార్చదు, కొత్త వెక్టార్ ని క్రియేట్ చేయదు. కేవలం ఒరిజినల్ వెక్టార్ లో ఉన్న ఈవెన్ నంబర్స్ ని మాత్రమే మనకు చూపిస్తుంది. (Memory = 0 bytes).
  • std::views::transform(...): ఫిల్టర్ అయిన వాటిని తీసుకుని దానికి ఇంటూ 2 చేస్తుంది. ఇదంతా ఎప్పుడు జరుగుతుంది? auto result అని రాసినప్పుడు జరగదు (లేజీ). కింద ఫర్ లూప్ లో మీరు n కోసం అడిగినప్పుడే పైకెళ్ళి క్యాలిక్యులేట్ చేసి ఇస్తుంది. ఇదే Lazy Evaluation పవర్.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: C++20 Ranges కి, పాత <algorithm> లో ఉన్న ఫంక్షన్స్ కి మెయిన్ డిఫరెన్స్ ఏంటి?

పాత అల్గారిథమ్స్ లో (ఉదా: std::transform) వాడుతున్నప్పుడు, రిజల్ట్ ని స్టోర్ చేసుకోవడానికి మీరు ముందే ఒక ఖాళీ వెక్టార్ ని క్రియేట్ చేసి పెట్టుకోవాలి (దీనివల్ల చాలా మెమరీ అండ్ టైమ్ కాపీ చేయడానికి వేస్ట్ అవుతుంది). కానీ C++20 వ్యూస్ (Views) లో అసలు డేటా కాపీ అనేది జరగదు. కేవలం ఒరిజినల్ డేటా పైన ఒక లాజికల్ లేయర్ యాడ్ అవుతుంది అంతే. ఇది మిలియన్ల కొద్దీ డేటా ఉన్నప్పుడు సూపర్ ఫాస్ట్.

Q2: "Lazy Evaluation" వల్ల లాభం ఏంటి?

దీన్ని డిమాండ్-బేస్డ్ ప్రోగ్రామింగ్ అంటారు. మీ దగ్గర ఒక కోటి నంబర్లు ఉన్నాయి. అందులో మీరు మొదటి 10 ఈవెన్ నంబర్లు తీసుకుని ప్రింట్ చేయాలి. పాత లాజిక్ వాడితే, కోటి నంబర్లను ఫిల్టర్ చేసి కొత్త అర్రే లో పెట్టి, అప్పుడు 10 ప్రింట్ చేసేది. కానీ లేజీ ఎవాల్యుయేషన్ వల్ల, ఇది 10 ఈవెన్ నంబర్స్ రాగానే ఆటోమేటిక్ గా ఫిల్టరింగ్ ని ఆపేస్తుంది! మిగతా 99 లక్షల నంబర్లకి అసలు లాజిక్ రన్ చేయదు, టైమ్ ఆదా అవుతుంది.

Q3: C++20 కోడ్ రాస్తే పాత కంపైలర్స్ లో పనిచేస్తుందా?

పనిచేయదు! C++20 ఫీచర్స్ (Ranges, Concepts, Modules, Coroutines) వాడాలంటే మీ దగ్గర లేటెస్ట్ కంపైలర్ (GCC 10+, Clang 11+, MSVC 2019+) ఉండాలి. మరియు కంపైల్ చేసేటప్పుడు ఫ్లాగ్ -std=c++20 అని కచ్చితంగా ఇవ్వాలి. ప్రపంచవ్యాప్తంగా ఉన్న పెద్ద కంపెనీలు అన్నీ నెమ్మదిగా పాత C++ నుండి C++20 కి అప్డేట్ అవుతున్నాయి, ఎందుకంటే ఇది కోడ్ ని చాలా ఈజీ చేస్తుంది.
