Iterators & STL Algorithms (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 15 📂 Phase 15: Iterators & Algorithms 📅 2026 Master Edition
📌 Covered in this in-depth guide: Iterators Concept · std::sort · std::find · std::transform · Lambda with STL

గత పాఠంలో మనం STL కంటైనర్స్ (Containers) వాడి డేటాని ఎలా దాచుకోవాలో చూసాము. కానీ ఆ దాచిన డేటాని ఒక పద్ధతిలో యాక్సెస్ చేయడానికి (లూప్ తిప్పడానికి) మనకు ఒక దారి కావాలి, ఆ దారి చూపించేవే Iterators (ఇటరేటర్స్). అంతే కాకుండా, ఒక లక్ష నంబర్స్ ని షార్ట్ (చిన్న దాని నుండి పెద్ద దానికి అమర్చడం) చేయడానికి మీరు 20 లైన్ల కోడ్ రాయక్కర్లేదు. C++ లో Algorithms (అల్గారిథమ్స్) అనే లైబ్రరీ లో మనకు అవసరమైన 100 కి పైగా పవర్ ఫుల్ లాజిక్స్ అన్నీ రెడీమేడ్ గా దొరుకుతాయి. ఇటరేటర్స్ ని, ఈ అల్గారిథమ్స్ ని కలిపి వాడితే మీరు గంటలో రాయాల్సిన కోడ్ ని ఒక్క నిమిషంలో ముగించేయొచ్చు. ఇవన్నీ ఎలా పనిచేస్తాయో డీప్ గా చూద్దాం.

1 అసలు Iterator (ఇటరేటర్) అంటే ఏమిటి?

ఇటరేటర్ అనేది ఒక అడ్వాన్స్డ్ పాయింటర్ లాంటిది. మీరు వెక్టార్ వాడినా, మ్యాప్ వాడినా, లిస్ట్ వాడినా... వాటన్నింటి లోపల డేటా అరేంజ్ మెంట్ వేరువేరుగా ఉంటుంది. మీరే సొంతంగా లూప్ (for loop) రాసి డేటాని బయటకి తీయాలంటే, ప్రతి కంటైనర్ కి వేరువేరు లాజిక్ రాయాలి. అలా కాకుండా, కంటైనర్ ఏదైనా సరే, మొదటి ఐటమ్ (begin) నుండి చివరి ఐటమ్ (end) వరకు ఎలాంటి ఇబ్బంది లేకుండా ఒక స్మార్ట్ పాయింటర్ లాగా డేటాని చూపించే ఫీచరే ఈ ఇటరేటర్.

🔍 రియల్ లైఫ్ స్టోరీ: ఒక గైడ్ మరియు టూరిస్ట్ బస్సు

ఒక మ్యూజియం కి వెళ్లారు అనుకోండి (అదే కంటైనర్). అందులో రకరకాల గదుల్లో రకరకాల వస్తువులు ఉన్నాయి. మీరు స్వయంగా వెతికితే దారి తప్పిపోయే ప్రమాదం ఉంది.

కానీ మీకొక టూర్ గైడ్ (Iterator) దొరికాడు అనుకోండి. మీరు అతనికి "నెక్స్ట్ ఐటమ్ చూపించు" (అంటే it++) అని చెప్తే చాలు, అతనే ఆ గదులన్నీ పర్ఫెక్ట్ ఆర్డర్ లో చూపించుకుంటూ తీసుకువెళతాడు. మీరు దారి గురించి టెన్షన్ పడక్కర్లేదు. ఇటరేటర్ కూడా ఇదే చేస్తుంది, కంటైనర్ కాంప్లెక్సిటీ ని దాచేసి, డేటాని సింపుల్ గా యాక్సెస్ చేసేలా చేస్తుంది.

2 మ్యాజికల్ STL Algorithms (రెడీమేడ్ కోడ్స్)

C++ వాళ్ళు #include <algorithm> అనే ఒక గొప్ప లైబ్రరీ ని ఇచ్చారు. ఇందులో మనం రెగ్యులర్ గా వాడే కోడ్స్ అన్నీ సింగిల్ లైన్ లో ఉంటాయి.

  • std::sort(): అర్రే ని గానీ వెక్టార్ ని గానీ చాలా ఫాస్ట్ గా సార్ట్ (ఆర్డర్) చేస్తుంది. ఇది బ్యాక్ గ్రౌండ్ లో IntroSort అనే అల్గారిథమ్ వాడుతుంది (ప్రపంచంలోనే బెస్ట్ టైమ్ కాంప్లెక్సిటీ O(N log N) ).
  • std::find(): ఒక పెద్ద వెక్టార్ లో మీకు కావాల్సిన డేటా ఎక్కడుందో వెతికిపెడుతుంది.
  • std::reverse(): డేటాని మొత్తం ఉల్టా (రివర్స్) చేస్తుంది.
3 ఒకే ఒక సింపుల్ కోడ్ (Sort & Iterators)

కింద కోడ్ లో కొన్ని జంబుల్ అయిన నంబర్స్ ని sort() వాడి ఎలా ఆర్డర్ లో పెట్టామో, మరియు రివర్స్ ఎలా చేసామో చూడండి.

C++ — STL Algorithms ▶ Run Code 
#include <iostream>
#include <vector>
#include <algorithm> // ఇక్కడే సార్ట్ ఫంక్షన్లు ఉంటాయి

int main() {
    // చెల్లాచెదురుగా ఉన్న నంబర్స్ (Vector)
    std::vector<int> nums = {50, 10, 80, 20, 40};
    
    // 1. చిన్న దాని నుండి పెద్ద దానికి సార్ట్ చేయడం
    // begin() మరియు end() అనేవి ఇటరేటర్స్ (గైడ్స్) ని ఇస్తాయి
    std::sort(nums.begin(), nums.end());
    
    std::cout << "Sorted Order (Ascending):" << std::endl;
    for (int n : nums) {
        std::cout << n << " ";
    }
    std::cout << std::endl;
    
    // 2. పెద్ద దాని నుండి చిన్న దానికి రివర్స్ చేయడం
    // rbegin() అంటే రివర్స్ బిగిన్ అని అర్థం!
    std::sort(nums.rbegin(), nums.rend());
    
    std::cout << "Sorted Order (Descending):" << std::endl;
    for (int n : nums) {
        std::cout << n << " ";
    }
    std::cout << std::endl;
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • #include <algorithm>: మీరు పైన దీన్ని ఇన్‌క్లూడ్ చేయకపోతే కింద sort() లాంటివి పనిచేయవు.
  • nums.begin() మరియు nums.end(): ఇవే ఇటరేటర్స్. సార్ట్ ఫంక్షన్ కి మనం "మొదటి పొజిషన్ నుండి చివరి పొజిషన్ దాకా సార్ట్ చెయ్యి" అని దారి చూపిస్తున్నాం అన్నమాట.
  • nums.rbegin(): ఇది చాలా స్మార్ట్ ఫీచర్ (Reverse Iterator). ఇది వెక్టార్ ని రివర్స్ లో చదువుకుంటూ వెళ్తుంది. కాబట్టి sort() ఫంక్షన్ కి రివర్స్ లో డేటా వెళ్ళి ఆటోమేటిక్ గా డిసెండింగ్ ఆర్డర్ (పెద్ద నుండి చిన్నకి) వస్తుంది. దీనికోసం మళ్ళీ ఇంకో సార్ట్ లాజిక్ రాయక్కర్లేదు!
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: నాకు నచ్చిన విధంగా డేటాని సార్ట్ చేయొచ్చా? (Custom Sorting)

ఖచ్చితంగా! ఉదాహరణకు మీ దగ్గర స్టూడెంట్స్ ఆబ్జెక్ట్స్ ఉన్నాయి. మీరు మార్కుల బట్టి సార్ట్ చేయాలా లేక పేర్ల బట్టి సార్ట్ చేయాలా అని కంపైలర్ కి తెలీదు. అప్పుడు మీరు std::sort(begin, end, customLogic) లాగా ఒక లాంబ్డా ఫంక్షన్ ని మూడవ ఆర్గ్యుమెంట్ గా పంపొచ్చు. ఆ కస్టమ్ లాజిక్ ని బట్టి కంపైలర్ సార్ట్ చేస్తుంది.

Q2: std::transform అంటే ఏంటి?

మీ వెక్టార్ లో 10 నంబర్స్ ఉన్నాయి. వాటన్నిటినీ డబుల్ (x2) చేసి ఇంకో వెక్టార్ లో పెట్టాలి అనుకుంటే, మీరు ఫర్ లూప్ రాసుకుంటూ కూర్చోక్కర్లేదు. డైరెక్ట్ గా std::transform(begin, end, output_begin, డబుల్ చేసే లాజిక్) రాస్తే, ఒక్క సెకనులో అన్ని నంబర్స్ మారిపోయి అవుట్పుట్ లోకి వచ్చేస్తాయి. ఇది మోడరన్ ఫంక్షనల్ ప్రోగ్రామింగ్ కి చాలా ముఖ్యం.

Q3: .end() ఇటరేటర్ కరెక్ట్ గా లాస్ట్ ఐటమ్ ని చూపిస్తుందా?

లేదు, ఇది చాలా మంది చేసే తప్పు. .begin() కరెక్ట్ గా మొదటి ఐటమ్ పైనే పాయింట్ చేస్తుంది. కానీ .end() అనేది లాస్ట్ ఐటమ్ తర్వాత ఉన్న ఒక "ఖాళీ జాగా" (Past-the-end) ని చూపిస్తుంది. అందుకే మనం లూప్స్ వాడేటప్పుడు ఎప్పుడూ it != nums.end() అని రాస్తాం (అంటే ఎండ్ కి వచ్చేదాకా ఆగు అని). దాన్ని డైరెక్ట్ గా ప్రింట్ చేయాలని చూస్తే గార్బేజ్ వాల్యూ వస్తుంది.
