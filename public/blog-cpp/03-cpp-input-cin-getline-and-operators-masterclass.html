cin, getline(), Operators Masterclass (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 3 📂 Phase 03: Input & Operators 📅 2026 Master Edition
📌 Covered in this in-depth guide: User Input (std::cin) · Buffer Issues · getline() · Operators · Math Logic

మన ప్రోగ్రామ్ లో అన్ని వాల్యూస్ మనమే కోడ్ లో రాసేస్తే (Hardcoding) దానివల్ల ఉపయోగం లేదు. ఉదాహరణకు, క్యాలిక్యులేటర్ యాప్ లో యూజర్ ఏ నంబర్స్ ఇస్తాడో మనకు ముందుగా తెలీదు కదా! అంటే ప్రోగ్రామ్ రన్ అవుతున్నప్పుడు, కీబోర్డ్ ద్వారా యూజర్ దగ్గర నుండి వాల్యూస్ తీసుకోవాలి. దీనికోసమే C++ లో std::cin అనే అద్భుతమైన ఫీచర్ ఉంది. కానీ cin వాడేటప్పుడు చాలా మంది స్టూడెంట్స్ బఫర్ (Buffer) ఇష్యూస్ ఫేస్ చేస్తారు, సగం సగం పేర్లు మాత్రమే వస్తాయి. ఈ ఆర్టికల్ లో cin మరియు getline() ఎలా వాడాలో, వాటితో పాటు ఆపరేటర్స్ (Operators) ఎలా పనిచేస్తాయో డీప్ గా చూద్దాం.

1 cin (Character Input) ఎలా పనిచేస్తుంది?

మనం C లాంగ్వేజ్ లో scanf వాడినట్లు, C++ లో cin వాడుతాం. cout వాడేటప్పుడు ఎడమ వైపు (<<) ఆరోస్ ఉంటాయో, cin వాడేటప్పుడు కుడి వైపు (>>) ఆరోస్ ఉంటాయి. అంటే కీబోర్డ్ నుండి వచ్చిన డేటాని ఆ వేరియబుల్ లోకి తోస్తుంది అని అర్థం.

⚠️ రియల్ లైఫ్ ప్రాబ్లెమ్: Space వస్తే cin ఎందుకు ఆగిపోతుంది?

మీరు యూజర్ పేరు అడిగారు, అతను "Ratan Tata" అని టైప్ చేసాడు అనుకోండి. మీరు cin >> name; అని వాడితే, కంప్యూటర్ కి కేవలం "Ratan" మాత్రమే తీసుకుంటుంది! "Tata" ని వదిలేస్తుంది.

ఎందుకంటే cin ఎప్పుడూ కూడా ఒక స్పేస్ (Space) లేదా ఎంటర్ (Enter) రాగానే ఆగిపోతుంది. దానికి పదాల మధ్య ఉన్న ఖాళీ జాగాలు అర్థం కావు. ఆ సమస్యని పరిష్కరించడానికి వాడేదే std::getline(). ఇది ఒక లైన్ మొత్తాన్ని, స్పేస్ లతో సహా పూర్తిగా చదువుతుంది.

2 Operators (ఆపరేటర్స్) అంటే ఏమిటి?

ఆపరేటర్స్ అంటే సింబల్స్. మ్యాథ్స్ లో +, - లాగా ప్రోగ్రామింగ్ లో చాలా సింబల్స్ ఉంటాయి.

  • Arithmetic: + (కూడిక), - (తీసివేత), * (గుణకారం), / (భాగాహారం), % (శేషం / Modulo).
  • Relational: == (సమానమా?), != (సమానం కాదా?), >, <.
  • Logical: && (రెండూ నిజం అయితే), || (ఏదో ఒకటి నిజం అయితే).
3 ఒకే ఒక సింపుల్ కోడ్ (Input & getline)

కింద కోడ్ లో ముందుగా వయసు (నంబర్) తీసుకుని, ఆ తర్వాత getline() వాడి పేరు ఎలా తీసుకుంటున్నామో చూడండి. (ఇక్కడ బఫర్ క్లియర్ చేయడం చాలా ముఖ్యం).

C++ — cin & getline Demo ▶ Run Code 
#include <iostream>
#include <string>

int main() {
    int age;
    std::string fullName;
    
    std::cout << "Enter your age: ";
    std::cin >> age;
    
    // cin తర్వాత ఎంటర్ (\n) బఫర్ లో ఉండిపోతుంది, దాన్ని క్లియర్ చేయాలి
    std::cin.ignore(); 
    
    std::cout << "Enter your Full Name: ";
    // స్పేస్ లతో సహా మొత్తం లైన్ ని తీసుకుంటుంది
    std::getline(std::cin, fullName); 
    
    std::cout << "Hello " << fullName << ", you are " << age << " years old.\n";
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • std::cin >> age;: యూజర్ టైప్ చేసిన నంబర్ ని age లోకి పంపుతుంది. కానీ యూజర్ నంబర్ టైప్ చేసి 'Enter' నొక్కుతాడు కదా, ఆ Enter క్యారెక్టర్ (\n) కీబోర్డ్ బఫర్ లోనే ఉండిపోతుంది.
  • std::cin.ignore();: ఇది ఆ మిగిలిపోయిన Enter ని చెత్తబుట్టలో వేస్తుంది (Clear Buffer). ఒకవేళ ఇది రాయకపోతే, కింద ఉన్న getline() దానంతట అదే ఆ Enter ని చదివేసుకుని ఎంప్టీ లైన్ (Empty) ని తీసుకుని ఆగిపోతుంది!
  • std::getline(std::cin, fullName);: ఇప్పుడు ఇది కరెక్ట్ గా యూజర్ టైప్ చేసిన పూర్తి పేరుని (space లతో కలిపి) చదివి fullName లో పెడుతుంది.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: Modulo (%) ఆపరేటర్ ఎక్కడ వాడతారు?

భాగాహారం (Division) చేస్తే వచ్చేది కోషంట్ (Quotient). కానీ మోడ్యులో (%) వాడితే వచ్చేది రిమైండర్ (శేషం). ఉదాహరణకు 10 % 3 = 1 వస్తుంది. దీన్ని సరి సంఖ్య (Even) బేసి సంఖ్య (Odd) కనుక్కోవడానికి ఎక్కువగా వాడతారు.

Q2: cin.ignore() లేకుండా ఉంటే ప్రోగ్రామ్ క్రాష్ అవుతుందా?

క్రాష్ అవ్వదు కానీ, లాజికల్ బగ్ వస్తుంది. మీరు ఎప్పుడైతే ఒక నంబర్ (cin) అడిగి, ఆ వెంటనే ఒక స్ట్రింగ్ (getline) అడుగుతారో, అప్పుడు మునుపటి బఫర్ వల్ల సెకండ్ ఇన్పుట్ స్కిప్ అయిపోయి ప్రోగ్రామ్ ముందుకు వెళ్లిపోతుంది. అందుకే cin తర్వాత getline వస్తే ఖచ్చితంగా ignore() వాడాలి.

Q3: C++ లో string అనేది డేటా టైపా లేక క్లాస్ (Class) ఆ?

C లాంగ్వేజ్ లో స్ట్రింగ్ అనేది ఒక అక్షరాల సమూహం (Array of characters) మాత్రమే. కానీ C++ లో std::string అనేది ఒక ఫుల్లీ పవర్ ఫుల్ క్లాస్ (Class). దానికి ఎంత పెద్ద టెక్స్ట్ ఇచ్చినా దానంతట అదే సైజు పెంచుకుంటుంది, మరియు అక్షరాలు యాడ్ చేయడం లాంటివి చాలా సింపుల్ గా చేయొచ్చు.
