లూప్స్ (for, while, do-while & Range-based for)

⚡ Modern C++20 / C++17 🟢 Chapter 7 of 20 📂 Phase 2: Control Flow & Loops 📅 2026 Edition
📌 Covered in this chapter: Need for Loops · for Loop Anatomy (Init, Condition, Step) · while Loop (Entry-Controlled) · do-while Loop (Exit-Controlled) · Nested Loops & Star Patterns · Modern C++11 Range-based for loop · Infinite Loops & Server Event Loops
కంప్యూటర్లు మనుషుల కంటే వేగంగా పనిచేయడానికి ప్రధాన కారణం విసుగు లేకుండా ఒకే పనిని కోట్లాది సార్లు పునరావృతం (Looping / Iteration) చేయగలగడం. ఈ అధ్యాయంలో C++ లోని మూడు ప్రాథమిక లూప్‌లు (for, while, do-while), స్టార్ ప్యాటర్న్స్ కోసం Nested Loops, మరియు Modern C++11 లో వచ్చిన అత్యంత ఆధునిక Range-based for loop ను లోతుగా నేర్చుకుందాం.
1The `for` Loop Anatomy (ఆర్కిటెక్చర్ & ఎగ్జిక్యూషన్ ఫ్లో)

ఒక పని ఎన్నిసార్లు జరగాలో మనకు ముందే ఖచ్చితంగా తెలిసినప్పుడు (ఉదా: 100 సార్లు, లేదా n సార్లు) `for` లూప్ అత్యుత్తమమైన ఎంపిక:

for ( [1. Initialization] ; [2. Condition Check] ; [4. Increment / Step] ) { // [3. Loop Body Code] } ఫ్లో ఆర్డర్: 1. Initialization (కేవలం లూప్ మొదలైనప్పుడు ఒక్కసారి మాత్రమే రన్ అవుతుంది). 2. Condition Check (షరతు true అయితేనే లోపలికి వెళ్తుంది, false అయితే లూప్ ఆగిపోతుంది). 3. Loop Body (లోపల ఉన్న కోడ్ ఎగ్జిక్యూట్ అవుతుంది). 4. Step / Increment (కౌంటర్ వేరియబుల్ పెరుగుతుంది, మళ్ళీ Step 2 కి వెళ్తుంది!).
💻 Example 1: Sum of First N Natural Numbers with for Loop
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    int targetN = 10;
    int totalSum = 0;

    // 1 నుండి 10 వరకు కూడటం
    for (int i = 1; i <= targetN; ++i) {
        totalSum += i;
    }

    std::cout << "Sum of numbers from 1 to " << targetN << " = " << totalSum << "\n";
    return 0;
}
2The `while` Loop (కండిషన్-ఆధారిత పునరావృతం)

ఒక పని ఎన్నిసార్లు జరగాలో మనకు ముందే తెలియక, కేవలం ఒక షరతు నెరవేరేంత వరకు మాత్రమే నడవాలి అనుకున్నప్పుడు `while` లూప్ వాడతాం (Entry-Controlled Loop):

💻 Example 2: Reversing a Number with while Loop
C++17 while ▶ Run in Compiler 
#include <iostream>

int main() {
    int originalNumber = 12345;
    int temp = originalNumber;
    int reversedNumber = 0;

    // సంఖ్య 0 అయ్యేంతవరకు చివరి అంకెను తీసి తిరగేయడం
    while (temp > 0) {
        int lastDigit = temp % 10;
        reversedNumber = (reversedNumber * 10) + lastDigit;
        temp /= 10; // temp = temp / 10
    }

    std::cout << "Original Number : " << originalNumber << "\n";
    std::cout << "Reversed Number : " << reversedNumber << "\n";

    return 0;
}
3The `do-while` Loop (కనీసం 1 సారి గ్యారెంటీ ఎగ్జిక్యూషన్)

while లూప్‌లో మొదట్లోనే కండిషన్ తప్పు అయితే కోడ్ ఒక్కసారి కూడా రన్ అవ్వదు. కానీ `do-while` లూప్‌లో షరతు చివర్లో ఉంటుంది (Exit-Controlled Loop). కాబట్టి కండిషన్ తప్పు అయినా సరే, కనీసం ఒక్కసారైనా కోడ్ రన్ అవుతుంది!

ఎక్కడ వాడతారు? ATM పిన్ ఎంటర్ చేయమనడం, లేదా ఇంటరాక్టివ్ యూజర్ మెనూ అడగడం లాంటి పనుల్లో వాడతారు (ఎందుకంటే యూజర్‌కు ముందు మెనూ చూపించాలి, ఆ తర్వాతే ఎగ్జిట్ అవ్వాలా వద్దా అనేది చెక్ చేయాలి!).

💻 Example 3: Menu-Driven Interactive Loop with do-while
C++17 do-while ▶ Run in Compiler 
#include <iostream>

int main() {
    int userChoice = 0;

    do {
        std::cout << "\n--- MINI CALCULATOR MENU ---\n";
        std::cout << "1. Check Balance\n";
        std::cout << "2. Mini Statement\n";
        std::cout << "3. Exit System\n";
        std::cout << "Simulating selection: 3 (Exit)\n";
        userChoice = 3; // ఉదాహరణకు యూజర్ 3 ఎంచుకున్నారు
    } while (userChoice != 3);

    std::cout << "Session Ended. Thank you! 👋\n";
    return 0;
}
4Nested Loops & Star Patterns (నెస్టెడ్ లూప్స్ మ్యాజిక్)

ఒక లూప్ లోపల మరొక లూప్ రాయడాన్ని Nested Loop అంటారు. సాధారణంగా మ్యాట్రిక్స్‌లు (2D Arrays) ప్రాసెస్ చేయడానికి మరియు ఆకర్షణీయమైన స్టార్ ప్యాటర్న్స్ ప్రింట్ చేయడానికి ఇది అత్యంత ప్రాచుర్యం పొందింది:

💻 Example 4: Right-Angled Star Pyramid
C++17 Patterns ▶ Run in Compiler 
#include <iostream>

int main() {
    int totalRows = 5;

    // బయట లూప్: వరుసలను (Rows) నియంత్రిస్తుంది
    for (int row = 1; row <= totalRows; ++row) {
        // లోపలి లూప్: ఆ వరుసలో ఎన్ని స్టార్స్ ప్రింట్ చేయాలో చూస్తుంది
        for (int star = 1; star <= row; ++star) {
            std::cout << "* ";
        }
        std::cout << "\n"; // ప్రతి వరుస ముగిశాక కొత్త లైన్
    }

    return 0;
}

5Modern C++11 Range-based `for` Loop

సాంప్రదాయ for (int i = 0; i < n; i++) లో ఇండెక్స్ తప్పులు (Index out of bounds) జరిగే అవకాశం ఉంది. Modern C++11 లో పైథాన్ లాంటి క్లీన్ సింటాక్స్‌తో Range-based for loop ప్రవేశపెట్టారు:

💻 Example 5: Clean Array Traversal with Range-based for
Modern C++11/17 ▶ Run in Compiler 
#include <iostream>

int main() {
    int scores[] = {98, 85, 92, 78, 100};

    std::cout << "Exam Scores: ";
    // ఇండెక్స్ అవసరం లేదు! ప్రతి ఎలిమెంట్ నేరుగా score లోకి వస్తుంది
    for (const auto& score : scores) {
        std::cout << score << " ";
    }
    std::cout << "\n";

    return 0;
}
⚠️ Common Developer Pitfalls in Chapter 7
  • లూప్ కౌంటర్ పెంచడం మర్చిపోవడం (Infinite Loop Disaster): while (i < 10) { ... } లోపల ++i; రాయడం మర్చిపోతే, i ఎప్పటికీ 0 గానే ఉండి కంప్యూటర్ CPU 100% కి చేరి ప్రోగ్రామ్ ఫ్రీజ్ అయిపోతుంది!
  • Off-by-one Error: 10 సార్లు రన్ చేయాలనుకున్నప్పుడు i < 10 బదులు i <= 10 అని రాస్తే 11 సార్లు రన్ అయ్యి అర్రే బౌండరీని దాటే ప్రమాదం ఉంటుంది.
💻 Hands-on Interactive Practice Challenge

టాస్క్: గణితంలో అత్యంత ప్రసిద్ధమైన Fibonacci Series (0, 1, 1, 2, 3, 5, 8, 13, 21...) లోని మొదటి 10 సంఖ్యలను for లూప్ ఉపయోగించి స్క్రీన్ పై ప్రింట్ చేసే ప్రోగ్రామ్ రాయండి:

C++17 Fibonacci Challenge ▶ Run in Compiler 
#include <iostream>

int main() {
    int totalTerms = 10;
    long long first = 0, second = 1;

    std::cout << "========================================\n";
    std::cout << "       FIBONACCI SERIES GENERATOR       \n";
    std::cout << "========================================\n";
    std::cout << "First " << totalTerms << " Terms: ";

    for (int i = 1; i <= totalTerms; ++i) {
        std::cout << first << (i == totalTerms ? "" : ", ");
        long long nextTerm = first + second;
        first = second;
        second = nextTerm;
    }
    std::cout << "\n========================================\n";

    return 0;
}

❓ Frequently Asked Questions (FAQ)

Q while కి do-while కి ముఖ్యమైన తేడా ఏమిటి?

while లూప్ మొదట్లోనే కండిషన్ చెక్ చేస్తుంది (Entry-Controlled). కండిషన్ మొదట్లోనే false అయితే లూప్ ఒక్కసారి కూడా రన్ అవ్వదు. కానీ do-while లూప్ కోడ్‌ను ఒకసారి రన్ చేసిన తర్వాతే చివర్లో కండిషన్ చెక్ చేస్తుంది (Exit-Controlled). కాబట్టి కండిషన్ false అయినా సరే కనీసం ఒక్కసారైనా ఎగ్జిక్యూట్ అవుతుంది.

Q Modern C++ లో Range-based for loop ఎందుకు వాడాలి?

సాంప్రదాయ for లూప్‌లో ఇండెక్స్ వేరియబుల్ (i = 0; i < n; i++) రాయాలి, దీనివల్ల 'Off-by-one errors' మరియు అర్రే సరిహద్దులు దాటే ప్రమాదం ఉంటుంది. Range-based for loop (for (const auto& x : arr)) ఎలాంటి ఇండెక్స్ తప్పులు లేకుండా నేరుగా ఎలిమెంట్లను సురక్షితంగా మరియు క్లీన్‌గా ఇటరేట్ చేస్తుంది.

Q ఇన్ఫినిట్ లూప్ (Infinite Loop) ఎప్పుడు వాడతారు?

ఆపరేటింగ్ సిస్టమ్‌లు, వెబ్ సర్వర్లు, మైక్రోకంట్రోలర్లు, మరియు వీడియో గేమ్‌లలో 'Game Loop' లేదా 'Event Loop' (ఉదా: while (true)) నిరంతరం కీబోర్డ్ ఈవెంట్‌లను వింటూ రన్ అవ్వడానికి ఉద్దేశపూర్వకంగానే ఇన్ఫినిట్ లూప్‌లను వాడతారు.
