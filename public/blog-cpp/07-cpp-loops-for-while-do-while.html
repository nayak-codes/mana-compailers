లూప్స్ (for, while, do-while & Range-based for)

⚡ Modern C++20 / C++17 🟢 Chapter 7 of 20 📂 Phase 2: Control Flow & Loops 📅 2026 Edition
📌 Covered in this chapter: Repetition & Automation · The 4-Phase for Loop Execution Cycle · while vs do-while Comparison · Modern C++11 Range-based for Loop · Off-by-one Pitfalls · Performance Best Practices
కంప్యూటర్లకు మానవుల కంటే ఉన్న అతిపెద్ద బలం: విసుగు చెందకుండా ఒకే పనిని కోట్ల సార్లు అత్యంత వేగంగా పునరావృతం (Repeat) చేయడం. C++ లో క్లాసిక్ for లూప్, while, do-while మరియు మోడరన్ Range-based for లూప్‌ల పూర్తి అంతర్గత పనితీరును ఈ అధ్యాయంలో నేర్చుకుందాం.
1The Classic for Loop: 4 దశల చక్రం

ఒక పని ఎన్ని సార్లు జరగాలో ముందే ఖచ్చితంగా తెలిసినప్పుడు (Known Iteration Count) for లూప్ వాడతాం. ఇది 4 దశల చక్రంలా తిరుగుతుంది:

  1. Step 1 (Initialization): లూప్ ప్రారంభంలో కేవలం ఒక్కసారి మాత్రమే జరుగుతుంది (ఉదా: int i = 0;).
  2. Step 2 (Condition Check): ప్రతి రౌండ్ మొదట్లో కండిషన్ ట్రూ అయితేనే లోపలికి వెళ్తుంది (ఉదా: i < 5;).
  3. Step 3 (Loop Body Execution): బ్రాకెట్ల లోపల రాసిన కోడ్ ఎగ్జిక్యూట్ అవుతుంది.
  4. Step 4 (Increment / Step): రౌండ్ ముగిసిన వెంటనే వేరియబుల్ అప్‌డేట్ అవుతుంది (ఉదా: ++i), ఆపై తిరిగి Step 2 కి వెళ్తుంది.
💻 Example 1: Classic for Loop Execution
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    // 1 నుండి 5 వరకు సంఖ్యల కూడిక
    int sum = 0;
    for (int i = 1; i <= 5; ++i) {
        sum += i;
        std::cout << "Step " << i << ": Running Total = " << sum << "\n";
    }

    std::cout << "Final Sum: " << sum << "\n";
    return 0;
}
2while vs do-while: ఎంట్రీ vs ఎగ్జిట్ కంట్రోల్

while Loop (Entry-Controlled)

కండిషన్ మొదట్లోనే తనిఖీ చేయబడుతుంది. మొదటి ప్రయత్నంలోనే కండిషన్ ఫాల్స్ అయితే లూప్ బాడీ ఒక్కసారి కూడా రన్ అవ్వదు!

do-while Loop (Exit-Controlled)

కండిషన్ చివర్లో తనిఖీ చేయబడుతుంది. కండిషన్ ఫాల్స్ అయినా సరే, లూప్ బాడీ కనీసం ఒక్కసారి కచ్చితంగా ఎగ్జిక్యూట్ అవుతుంది (ఉదా: ATM పిన్ ఎంటర్ ప్రాంప్ట్).

3Modern C++11 Range-based for Loop

అర్రేలు లేదా వెక్టార్లలోని ప్రతి ఎలిమెంట్‌ను చదవడానికి ఇండెక్స్ i = 0; i < n రాయాల్సిన అవసరం లేకుండా క్లీన్‌గా చదవడానికి మోడరన్ C++ Range-for లూప్‌ను ఇస్తుంది:

💻 Example 2: Range-based for Loop
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    int primes[] = {2, 3, 5, 7, 11, 13};

    // const auto& వాడటం వల్ల కాపీ అవ్వదు, మెమరీ సేవ్ అవుతుంది
    for (const auto& num : primes) {
        std::cout << num << " ";
    }
    std::cout << "\n";
    return 0;
}
