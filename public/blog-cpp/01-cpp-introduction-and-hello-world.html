C++ పరిచయం & మొదటి ప్రోగ్రామ్ (Introduction, History & Hello World)

📌 Covered in this chapter: What is C++? · History & Bjarne Stroustrup · Zero-overhead Principle · C vs C++ · The 4-Stage Compilation Pipeline · First Hello World Program · Line-by-Line Breakdown · std::cout & std::endl · \n Performance Secret · using namespace std Controversy
ఈ మొదటి అధ్యాయంలో, ప్రపంచంలో అత్యంత వేగవంతమైన కంప్యూటింగ్ సిస్టమ్స్‌ను నడిపించే C++ ప్రోగ్రామింగ్ లాంగ్వేజ్ యొక్క మూలాలు, అంతర్గత కంపైలర్ ఆర్కిటెక్చర్, మరియు మీ మొట్టమొదటి Hello, World! ప్రోగ్రామ్‌ను ప్రతి అక్షరాన్ని మైక్రోస్కోపిక్‌గా విశ్లేషిస్తూ నేర్చుకుందాం.
1C++ అంటే ఏమిటి? (Origins, Philosophy & Real-World Power)

C++ అనేది ఒక high-performance, statically typed, compiled, general-purpose ప్రోగ్రామింగ్ లాంగ్వేజ్. దీనిని 1979 లో డెన్మార్క్‌కు చెందిన లెజెండరీ కంప్యూటర్ సైంటిస్ట్ Bjarne Stroustrup బెల్ లాబొరేటరీస్ (Bell Labs) లో రూపొందించారు.

మొదట్లో దీని పేరు "C with Classes" అని ఉండేది. 1983 లో దీనికి అధికారికంగా C++ అని పేరు మార్చారు. C లాంగ్వేజ్‌లో ++ అంటే ఒక విలువను పెంచడం (Increment Operator). అంటే "C లాంగ్వేజ్‌కు శక్తివంతమైన ఆబ్జెక్ట్ ఓరియెంటెడ్ ఫీచర్లను జోడించి తదుపరి స్థాయికి తీసుకెళ్లిన ఉన్నతమైన భాష" అని దీని అర్థం!

💡 The Core Philosophy: "Zero-Overhead Principle"

Bjarne Stroustrup C++ ను డిజైన్ చేసినప్పుడు ఒక బలమైన సూత్రాన్ని పెట్టుకున్నారు: "What you don't use, you don't pay for. And what you do use, you couldn't hand-code any better."

అంటే మీరు ఒక ఫీచర్‌ను ఉపయోగించకపోతే, అది మీ ప్రోగ్రామ్ మెమరీని గానీ, స్పీడ్‌ను గానీ ఒక్క శాతం కూడా వేస్ట్ చేయదు. అందుకే నేటికీ microsecond లేటెన్సీ అవసరమైన చోట ప్రపంచం మొత్తం C++ నే వాడుతుంది.

🌍 C++ ను నిజ జీవితంలో ఎక్కడ వాడుతున్నారు?

  • AAA Video Games & Game Engines: Unreal Engine 5, Unity core, మరియు PlayStation 5 / Xbox గేమింగ్ టైటిల్స్ అన్నీ C++ తోనే రన్ అవుతాయి.
  • Operating Systems: Windows OS Kernel, macOS కోర్ భాగాలు, మరియు Linux సిస్టమ్ డ్రైవర్లు.
  • Web Browsers: Google Chrome (V8 JavaScript Engine & Blink rendering engine) మరియు Mozilla Firefox కోర్ ఇంజిన్లు.
  • High-Frequency Trading (HFT): స్టాక్ మార్కెట్లో మిల్లీసెకను కంటే తక్కువ సమయంలో వేల కోట్ల రూపాయల ట్రేడింగ్ ఆర్డర్లను ప్రాసెస్ చేసే వాల్ స్ట్రీట్ ఫైనాన్షియల్ ఇంజిన్లు.
  • Aerospace & Robotics: NASA మార్స్ రోవర్ మిషన్లు, స్పేస్ ఎక్స్ రాకెట్ గైడెన్స్ సిస్టమ్స్, మరియు టెస్లా అటానమస్ డ్రైవింగ్ విజన్ నెట్‌వర్క్‌లు.
2C vs C++: తేడా ఏమిటి? (Procedural vs Multi-Paradigm)

చాలామంది విద్యార్థులు C మరియు C++ రెండూ ఒకటే అనుకుంటారు. కానీ C అనేది కేవలం Procedural Language (విధులు మరియు పనుల కేంద్రంగా నడుస్తుంది). కాగా C++ అనేది Multi-Paradigm Language.

లక్షణం (Feature) C Language Modern C++
Programming Paradigm కేవలం Procedural (Step-by-step functions) Multi-paradigm (Procedural + OOPs + Generic Templates + Functional)
Data Security (Encapsulation) డేటాకు భద్రత తక్కువ; గ్లోబల్ వేరియబుల్స్ సులభంగా మారుతాయి Classes & Access Specifiers (private, protected) తో పూర్తి భద్రత
Memory Management మాన్యువల్ (malloc, free) — లీక్స్ అయ్యే ప్రమాదం ఎక్కువ RAII సూత్రం, Smart Pointers (std::unique_ptr, std::shared_ptr) తో ఆటోమేటిక్ సేఫ్టీ
Standard Library పరిమితమైన లైబ్రరీ (C Standard Library) శక్తివంతమైన Standard Template Library (STL: vector, map, algorithms)
I/O Operations printf(), scanf() (టైప్ సేఫ్టీ ఉండదు) std::cout, std::cin (100% టైప్-సేఫ్ స్ట్రీమ్స్)
3C++ కంపైలర్ పైప్‌లైన్ (The 4-Stage Compilation Pipeline)

Python లాంటి ఇంటర్‌ప్రెటెడ్ భాషల్లో కోడ్ నేరుగా లైన్ బై లైన్ రన్ అవుతుంది. కానీ C++ లో మనం రాసే ఇంగ్లీష్ లాంటి కోడ్ నేరుగా CPU కి అర్థం కాదు. మనం రాసిన కోడ్ కంప్యూటర్ ప్రాసెసర్ అర్థం చేసుకునే బైనరీ మెషిన్ కోడ్ (0s & 1s) గా మారడానికి 4 దశలు (4 Stages) దాటాలి.

Stage 01: Preprocessing
హెడర్స్ మరియు మాక్రోల విస్తరణ (#include, #define)
main.cpp $ ightarrow$ ప్రీ-ప్రాసెసర్ #include <iostream> కోడ్‌ను తీసుకొచ్చి ఫైల్ పైన అతికిస్తుంది $ ightarrow$ main.i / main.ii ఫైల్ తయారవుతుంది.
Tool: cpp
Stage 02: Compilation
హై-లెవల్ C++ కోడ్ నుండి CPU అసెంబ్లీ కోడ్ మార్పు
సింటాక్స్ చెకింగ్, టైప్ ఎర్రర్ల గుర్తింపు, ఆప్టిమైజేషన్లు చేసి CPU రిజిస్టర్ ఇన్స్ట్రక్షన్లను (mov, push, call) ఉత్పత్తి చేస్తుంది $ ightarrow$ main.s / main.asm.
Tool: g++ / clang++
Stage 03: Assembly
అసెంబ్లీ ఇన్స్ట్రక్షన్ల నుండి బైనరీ ఆబ్జెక్ట్ ఫైల్ నిర్మాణం
అసెంబ్లర్ CPU సూచనలను స్వచ్ఛమైన మెషిన్ బైట్స్ (0s & 1s) గా మారుస్తుంది $ ightarrow$ రీలోకేటబుల్ ఆబ్జెక్ట్ ఫైల్ main.o / main.obj.
Tool: as (Assembler)
Stage 04: Linking
లైబ్రరీ ఫంక్షన్ల అనుసంధానం & ఎగ్జిక్యూటబుల్ తయారీ
మీ main.o ఫైల్‌కు C++ స్టాండర్డ్ లైబ్రరీ (libc++) మరియు సిస్టమ్ రన్‌టైమ్ ఫంక్షన్లను కలిపి నేరుగా OS రన్ చేయగల program.exe / a.out ను అందిస్తుంది.
Tool: ld (Linker)
4మీ మొదటి C++ Program: Hello, World!

ఇప్పుడు ప్రపంచవ్యాప్తంగా ప్రతి ప్రోగ్రామర్ తన మొదటి అడుగు వేసే సాంప్రదాయ "Hello, World!" ప్రోగ్రామ్‌ను మోడరన్ C++ ప్రమాణాలతో రాద్దాం:

💻 Example 1: The Modern C++ Hello World Program
C++17 / C++20 ▶ Run in Compiler 
#include <iostream>

int main() {
    std::cout << "Hello, World! 🚀 Welcome to C++ Masterclass." << std::endl;
    return 0;
}

🔍 మైక్రోస్కోపిక్ లైన్-బై-లైన్ కోడ్ విశ్లేషణ:

  • #include <iostream>: ఇది Preprocessor Directive. iostream అంటే Input Output Stream. స్క్రీన్ పైన టెక్స్ట్ ప్రింట్ చేయాలన్నా (cout), కీబోర్డ్ నుండి ఇన్‌పుట్ తీసుకోవాలన్నా (cin) ఈ హెడర్ ఫైల్ కచ్చితంగా ఉండాలి.
  • int main(): ఇది Main Function (Entry Point). ఆపరేటింగ్ సిస్టమ్ మీ ప్రోగ్రామ్‌ను ఎగ్జిక్యూట్ చేయడం ఎల్లప్పుడూ main() మొదటి లైన్ నుండే ప్రారంభిస్తుంది. int అంటే ఈ ఫంక్షన్ చివరికి OS కు ఒక ఇంటిజర్ ఫలితాన్ని ఇస్తుందని అర్థం.
  • { ... }: కర్లీ బ్రేసెస్ ఫంక్షన్ యొక్క పరిధిని (Scope) సూచిస్తాయి. ప్రోగ్రామ్ లాజిక్ అంతా ఈ బ్రాకెట్ల మధ్యలోనే ఉండాలి.
  • std::cout: cout అంటే Character Output. ఇది టెర్మినల్ కన్సోల్‌కు కనెక్ట్ అయి ఉన్న ఒక స్ట్రీమ్ ఆబ్జెక్ట్. std:: అనేది Standard Namespace ను సూచిస్తుంది.
  • <<: దీనిని Stream Insertion Operator అంటారు. దీని కుడివైపు ఉన్న డేటాను ఎడమవైపు ఉన్న కన్సోల్ స్ట్రీమ్ (cout) లోకి పంపుతుంది.
  • "Hello, World! 🚀...": డబుల్ కోట్స్ మధ్య ఉన్న టెక్స్ట్‌ను String Literal అంటారు. ఇది ఉన్నది ఉన్నట్లుగా స్క్రీన్‌పై ప్రింట్ అవుతుంది.
  • std::endl: End Line. ఇది ప్రింట్ అయ్యాక కర్సర్‌ను తర్వాతి లైన్‌కి పంపుతుంది మరియు అవుట్‌పుట్ బఫర్‌ను ఫ్లష్ చేస్తుంది.
  • return 0;: ఆపరేటింగ్ సిస్టమ్‌కు "నా ప్రోగ్రామ్ ఎటువంటి లోపాలు లేకుండా 100% విజయవంతంగా ముగిసింది (EXIT_SUCCESS)" అని తెలియజేసే ఎగ్జిట్ స్టేటస్ కోడ్.
5std::endl vs '\n': పర్ఫార్మెన్స్ సీక్రెట్

C++ లో కొత్త లైన్‌కి వెళ్లడానికి రెండు మార్గాలు ఉన్నాయి: std::endl మరియు '\n'. బిగినర్స్ రెండూ ఒకటే అనుకుంటారు, కానీ వాటి మధ్య చాలా పెద్ద టెక్నికల్ తేడా ఉంది:

🐢 std::endl (స్లో)

ఇది కొత్త లైన్‌కి తీసుకెళ్లడమే కాకుండా, సిస్టమ్ I/O బఫర్‌ను తక్షణమే ఖాళీ (Force Flush) చేయమని ఆపరేటింగ్ సిస్టమ్‌కు సిగ్నల్ పంపుతుంది. లూప్‌లలో ప్రతి రౌండ్‌కు ఇది వాడితే ప్రోగ్రామ్ 10 రెట్లు స్లో అయిపోతుంది!

⚡ '\n' (హై-స్పీడ్ రికమండెడ్)

ఇది కేవలం ఒక న్యూలైన్ క్యారెక్టర్‌ను మాత్రమే బఫర్‌లో ఉంచుతుంది. బఫర్ నిండినప్పుడు లేదా ప్రోగ్రామ్ ముగిసినప్పుడు సింగిల్ షాట్‌లో ఆటోమేటిక్‌గా ఫ్లష్ అవుతుంది. కాంపిటీటివ్ ప్రోగ్రామింగ్ & రియల్-టైమ్ ఇంజిన్లలో ఎల్లప్పుడూ '\n' మాత్రమే వాడాలి!

6బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ Trap 1: using namespace std; ను హెడర్లలో వాడటం

బిగినర్స్ ప్రతిసారీ std:: రాయడం బద్ధకించి using namespace std; అని గ్లోబల్‌గా రాస్తారు. కానీ దీనివల్ల C++ స్టాండర్డ్ లైబ్రరీలోని వేలాది పేర్లు (ఉదా: count, size, min) మీ స్వంత వేరియబుల్ పేర్లతో ఢీకొని భయంకరమైన Name Collision (Ambiguity Error) సృష్టిస్తాయి. ప్రొఫెషనల్ కోడ్‌లో ఎల్లప్పుడూ స్పష్టంగా std::cout రాయడమే ఉత్తమ విధానం.

❌ Trap 2: void main() వాడటం

పాత 1990ల Turbo C++ పుస్తకాలు చదివి చాలామంది void main() రాస్తుంటారు. ISO Modern C++ ప్రమాణాల ప్రకారం void main() చెల్లదు. ఆపరేటింగ్ సిస్టమ్‌కు ప్రోగ్రామ్ స్టేటస్ తెలియడానికి తప్పనిసరిగా int main() మాత్రమే రాయాలి.

7తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: C++ నేర్చుకోవడానికి ముందు C లాంగ్వేజ్ కచ్చితంగా వచ్చి ఉండాలా?

అస్సలు అవసరం లేదు! C++ అనేది స్వతంత్రమైన మోడరన్ లాంగ్వేజ్. మీరు నేరుగా C++ తోనే మీ మొదటి ప్రోగ్రామింగ్ జర్నీని ప్రారంభించవచ్చు.

Q: g++ మరియు clang++ మధ్య తేడా ఏమిటి?

g++ అనేది GNU కంపైలర్ కలెక్షన్ (GCC) కి చెందినది; Linux ప్లాట్‌ఫారమ్‌లలో విస్తృతంగా వాడతారు. clang++ అనేది LLVM ఆధారిత మోడరన్ కంపైలర్; ఇది స్పష్టమైన ఎర్రర్ మెసేజ్‌లు మరియు మెరుపువేగవంతమైన కంపైలేషన్‌ను అందిస్తుంది (Apple Xcode & Google వాడుతుంది).
