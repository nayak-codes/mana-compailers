అర్రేస్ (Arrays) & std::string (Fixed Buffers, Memory & Strings)

⚡ Modern C++20 / C++17 🟢 Chapter 10 of 20 📂 Phase 3: Functions, Memory & Pointers 📅 2026 Edition
📌 Covered in this chapter: Contiguous RAM Memory Layout · Multi-dimensional 2D Arrays & Row-Major Order · Array Decay to Pointer Trap · C-Strings vs Modern std::string · Small String Optimization (SSO) · C++17 std::string_view
వేలాది ఒకే రకమైన సమాచారాన్ని (ఉదా: 50 మంది విద్యార్థుల మార్కులు, గేమ్ స్క్రీన్ పిక్సెల్స్) భద్రపరచడానికి RAM లో వరుసగా ఉండే ఖాళీలను కేటాయించే పద్ధతిని అర్రేస్ (Arrays) అంటారు. C-స్టైల్ డేంజరస్ బఫర్ ఓవర్‌ఫ్లోలు, ఆధునిక std::string పనితీరు మరియు జీరో-అలొకేషన్ std::string_view గురించి ఈ అధ్యాయంలో నేర్చుకుందాం.
1అర్రేస్ యొక్క అంతర్గత RAM లేఅవుట్ (Contiguous Allocation)

అర్రేలోని ఎలిమెంట్స్ అన్నీ RAM లో ఒకదాని పక్కన ఒకటి వరుసగా (Contiguous Memory) ఉంటాయి. కాబట్టి ఇండెక్స్ తెలిస్తే మొదటి ఎలిమెంట్ అడ్రస్ నుండి డైరెక్ట్‌గా ఆ స్థలానికి క్షణంలో వెళ్లిపోవచ్చు:

2The Array Decay Trap (ఫంక్షన్లకు అర్రేను పంపే ప్రమాదం)
⚠️ Array Decay అంటే ఏమిటి?

C++ లో ఒక అర్రేను ఫంక్షన్‌కు పాస్ చేసినప్పుడు, అది అర్రే యొక్క పూర్తి సైజును గుర్తుంచుకోదు! అది కేవలం మొదటి ఎలిమెంట్ యొక్క పాయింటర్‌గా క్షీణించిపోతుంది (Decays to a pointer). ఫంక్షన్ లోపల sizeof(arr) అని రాస్తే మొత్తం అర్రే సైజు రాదు, కేవలం పాయింటర్ సైజు (8 బైట్లు) మాత్రమే వస్తుంది! అందుకే అర్రేతో పాటు దాని సైజును కూడా విడిగా పాస్ చేయాలి లేదా ఆధునిక std::vector వాడాలి.

3C-Strings vs Modern std::string (SSO Secret)

పాత C-స్టైల్ స్ట్రింగ్స్ కేవలం char str[] = "Hi"; రూపంలో '\0' (నల్ టెర్మినేటర్) తో ముగుస్తాయి. కానీ బఫర్ నిండిపోతే మెమరీ క్రాష్ అవుతుంది. Modern C++ ఇచ్చే std::string ఆటోమేటిక్‌గా డైనమిక్ మెమరీని పెంచుకుంటుంది:

🚀 Small String Optimization (SSO)

మీరు ఒక చిన్న స్ట్రింగ్ (15 క్యారెక్టర్ల కంటే తక్కువ) రాసినప్పుడు, std::string హీప్ మెమరీ (Heap Allocation) వద్దకు వెళ్లదు! స్టాక్ మెమరీలోని తన స్వంత లోకల్ బఫర్‌లోనే ఉంచుకుంటుంది. దీనివల్ల C++ స్ట్రింగ్స్ మెరుపు వేగంతో రన్ అవుతాయి.

💻 Example 1: Modern std::string Operations
C++17 ▶ Run in Compiler 
#include <iostream>
#include <string>

int main() {
    std::string text = "C++ Masterclass";
    
    // Length & Substrings
    std::cout << "Length: " << text.length() << " characters\n";
    std::cout << "Sub-slice: " << text.substr(0, 3) << "\n";

    // Safe Modification
    text.append(" 2026 Edition 🚀");
    std::cout << text << "\n";
    return 0;
}
