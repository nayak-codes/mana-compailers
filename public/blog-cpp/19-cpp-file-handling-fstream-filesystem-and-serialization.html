File Handling & std::filesystem (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 19 📂 Phase 19: File Handling & Filesystem 📅 2026 Master Edition
📌 Covered in this in-depth guide: fstream (Read/Write) · Binary files · std::filesystem (C++17) · Path manipulation · Directories

మనం ప్రోగ్రామ్ లో క్రియేట్ చేసే వేరియబుల్స్ అన్నీ RAM లో ఉంటాయి. అంటే పవర్ ఆఫ్ చేయగానే ఆ డేటా అంతా ఎగిరిపోతుంది (Volatile Memory). కానీ డేటాని పర్మనెంట్ గా ఒక టెక్స్ట్ ఫైల్ లో గాని, ఇమేజ్ లాగా గాని హార్డ్ డిస్క్ (SSD) లో సేవ్ చేయాలంటే File Handling (ఫైల్ హ్యాండ్లింగ్) కావాలి. C++ లో దీనికోసం <fstream> అనే లైబ్రరీ ఉంటుంది. అదేవిధంగా, ఫోల్డర్స్ ని క్రియేట్ చేయడం, ఫైల్ సైజు తెలుసుకోవడం లాంటి విండోస్/లైనక్స్ పనుల కోసం C++17 లో std::filesystem అనే అద్భుతమైన ఫీచర్ తెచ్చారు. ఈ పాఠంలో ఆ రెండిటి పవర్ ఏంటో డీప్ గా తెలుసుకుందాం.

1 fstream తో ఫైల్స్ లో రాయడం (Writing) మరియు చదవడం (Reading)

C లాంగ్వేజ్ లో ఫైల్స్ హ్యాండిల్ చేయడానికి fopen, fprintf లాంటి కష్టమైన ఫంక్షన్స్ ఉంటాయి. కానీ C++ లో మనం cout ని ఎలా వాడతామో, ఫైల్స్ ని కూడా అంతే ఈజీగా వాడుకోవచ్చు!

  • ofstream (Output File Stream): ఇది ఫైల్స్ ని కొత్తగా క్రియేట్ చేయడానికి లేదా డేటాని ఫైల్ లోపలికి రైట్ చేయడానికి వాడుతారు (cout లాగా).
  • ifstream (Input File Stream): ఇది హార్డ్ డిస్క్ లో ముందే ఉన్న ఫైల్ ని ఓపెన్ చేసి చదవడానికి వాడుతారు (cin లాగా).
  • fstream: ఇది రైట్ మరియు రీడ్ రెండూ చేయగలదు.
2 C++17 లో వచ్చిన std::filesystem మ్యాజిక్

పాత కాలంలో ఒక ఫోల్డర్ ఉందో లేదో తెలుసుకోవాలన్నా, లేదా ఆ ఫోల్డర్ లోపల ఎన్ని ఫైల్స్ ఉన్నాయో కౌంట్ చేయాలన్నా... విండోస్ లో ఒకలా, లైనక్స్ లో ఒకలా (OS-specific OS APIs) కోడ్ రాయాల్సి వచ్చేది. ఇది చాలా పెద్ద తలనొప్పి. దాన్ని క్యూర్ చేయడానికి C++17 లో std::filesystem వచ్చింది. ఇది వాడితే విండోస్, మ్యాక్, లైనక్స్ ఎక్కడైనా ఒకటే కోడ్ పనిచేస్తుంది. (దీని కోసం #include <filesystem> వాడాలి).

3 ఒకే ఒక సింపుల్ కోడ్ (Filesystem & fstream)

కింద కోడ్ లో ముందుగా ఒక కొత్త ఫోల్డర్ ని ఎలా క్రియేట్ చేసామో (C++17 వాడి), ఆ తర్వాత అందులో ఒక ఫైల్ క్రియేట్ చేసి డేటా ఎలా సేవ్ చేసామో, మళ్ళీ ఆ డేటాని ఎలా చదివామో చూడండి.

C++17 — Filesystem & fstream ▶ Run Code 
#include <iostream>
#include <fstream>
#include <string>
#include <filesystem> // C++17 Filesystem

namespace fs = std::filesystem; // పేరు చిన్నగా ఉండటానికి షార్ట్ కట్

int main() {
    std::string folderName = "MyGameData";
    std::string fileName = folderName + "/save_state.txt";
    
    // 1. ఫోల్డర్ క్రియేషన్ (C++17 Filesystem)
    if (!fs::exists(folderName)) {
        fs::create_directory(folderName);
        std::cout << "[+] Created Folder: " << folderName << std::endl;
    }
    
    // 2. ఫైల్ లోపలికి రైట్ చేయడం (ofstream)
    std::ofstream outFile(fileName);
    if (outFile.is_open()) {
        outFile << "PlayerLevel: 50\n";
        outFile << "Score: 9999\n";
        outFile.close(); // ఫైల్ ని సేఫ్ గా లాక్ చేస్తున్నాం 
        std::cout << "[+] Game Saved Successfully!" << std::endl;
    }
    
    // 3. ఫైల్ ని చదవడం (ifstream)
    std::ifstream inFile(fileName);
    std::string line;
    
    std::cout << "\n--- Loading Game ---" << std::endl;
    if (inFile.is_open()) {
        // ఫైల్ ఎండ్ అయ్యేదాకా లైన్ బై లైన్ చదువుతుంది
        while (std::getline(inFile, line)) {
            std::cout << "Read: " << line << std::endl;
        }
        inFile.close();
    }
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • fs::create_directory(): ఇది C++17 ఫీచర్. మనం ఇచ్చిన పేరుతో ఒక కొత్త డైరెక్టరీ (Folder) ని ఆపరేటింగ్ సిస్టమ్ లో క్రియేట్ చేస్తుంది.
  • std::ofstream outFile(...): ఇది ఫైల్ ని క్రియేట్ చేసి, రైట్ చేయడానికి కనెక్షన్ ఓపెన్ చేస్తుంది. దాన్ని మనం cout వాడినట్లే outFile << "Text" అని వాడుకోవచ్చు.
  • std::getline(inFile, line): ఫైల్ ని స్పేస్ లతో కాకుండా, ఒక లైన్ (Enter కొట్టేదాకా) మొత్తాన్ని చదివి స్ట్రింగ్ లోకి వేస్తుంది. ఆ తర్వాత నెక్స్ట్ లైన్ కి వెళ్తుంది.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: ఫైల్ ని ఓపెన్ చేసాక కచ్చితంగా .close() చేయాలా? చేయకపోతే ఏమవుతుంది?

సింపుల్ స్కోప్ లో .close() మర్చిపోయినా పర్లేదు, ఎందుకంటే fstream క్లాస్ లోపల రాసిన డిస్ట్రక్టర్ (RAII కాన్సెప్ట్) దానంతట అదే ఫైల్ ని క్లోజ్ చేస్తుంది. కానీ మీరు ఒకే ఫంక్షన్ లో పెద్ద ప్రోగ్రామ్ రాస్తుంటే, వాడుకున్న వెంటనే మీరే క్లోజ్ చేయడం బెస్ట్, లేకపోతే మెమరీ లీక్ అవ్వకపోయినా ఆ ఫైల్ అప్పటిదాకా లాక్ అయి ఉంటుంది, వేరే వాళ్ళు దాన్ని ఓపెన్ చేయలేరు.

Q2: టెక్స్ట్ ఫైల్స్ కి, బైనరీ (Binary) ఫైల్స్ కి తేడా ఏంటి?

టెక్స్ట్ ఫైల్స్ అంటే మనం నోట్ పాడ్ (Notepad) లో చదవగలిగే ఇంగ్లీష్ అక్షరాలు ఉంటాయి (పై కోడ్ లో రాసినట్లు). కానీ ఆబ్జెక్ట్స్ ని, ఇమేజెస్ ని, లేదా వీడియో ఫైల్స్ ని సేవ్ చేయాలంటే ios::binary అనే మోడ్ వాడాలి. అప్పుడు డేటా డైరెక్ట్ గా 0s & 1s లాగా వెళ్తుంది (మనుషులు చదవలేరు కానీ కంప్యూటర్ కి చాలా ఫాస్ట్).

Q3: C++17 Filesystem లో ఒక ఫోల్డర్ లో ఉన్న అన్ని ఫైల్స్ ని ఎలా చూడాలి?

దీనికి fs::directory_iterator అనే అద్భుతమైన ఇటరేటర్ ని వాడతారు. ఒక ఫర్ లూప్ for (const auto& entry : fs::directory_iterator(path)) అని రాస్తే, ఆ ఫోల్డర్ లోపల ఉన్న అన్నీ ఫైల్స్ పేర్లు వరుసగా ప్రింట్ అయిపోతాయి (Python os.listdir లాగా). ఇది చాలా మోడరన్ ఫీచర్.
