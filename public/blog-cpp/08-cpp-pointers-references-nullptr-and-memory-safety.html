Pointers, References & nullptr (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 8 📂 Phase 08: Pointers & Memory Safety 📅 2026 Master Edition
📌 Covered in this in-depth guide: Memory Addresses · Pointers vs References · nullptr vs NULL · Dereferencing · Pass by Reference

C++ ప్రపంచాన్ని శాసిస్తోంది అంటే దానికి ఒకేఒక్క కారణం ఉంది, అదే మెమరీ కంట్రోల్ (Memory Control). జావా, పైథాన్ లాంటి లాంగ్వేజెస్ లో మెమరీ అంతా వాటంతట అవే చూసుకుంటాయి, మనం ఏమీ చేయలేం. కానీ C++ లో మీకు RAM మెమరీ మీద పూర్తి అధికారం ఉంటుంది. ప్రతి ఒక్క బైట్ ఎక్కడ ఉందో తెలుసుకుని, దాన్ని మార్చే పవర్ మన చేతుల్లో ఉంటుంది. ఆ పవర్ ఇచ్చే మ్యాజికల్ కాన్సెప్ట్ లే Pointers (పాయింటర్స్) మరియు References (రిఫరెన్సెస్). చాలా మంది వీటికి భయపడతారు కానీ, ఈ ఆర్టికల్ చదివాక అది ఎంత సింపులో మీకే అర్థమవుతుంది.

1 అసలు పాయింటర్స్ మరియు రిఫరెన్సెస్ అంటే ఏంటి?

ప్రతి వేరియబుల్ (బాక్స్) క్రియేట్ అయినప్పుడు దానికి RAM లో ఒక అడ్రస్ (ఉదాహరణకు 0x7ffe1234) దొరుకుతుంది. ఆ అడ్రస్ ని సేవ్ చేసుకునే స్పెషల్ వేరియబుల్ నే Pointer (పాయింటర్) అంటారు. పాయింటర్ అనేది దారి చూపే మ్యాప్ లాంటిది.

📍 రియల్ లైఫ్ స్టోరీ: మీ ఇల్లు, అడ్రస్ కార్డు, మరియు నిక్ నేమ్

మీకొక ఇల్లు (Variable) ఉంది అనుకుందాం. అందులో మీరు (Data) ఉన్నారు.

Pointer అంటే: ఒక విజిటింగ్ కార్డు లాంటిది. ఆ కార్డు మీద మీ ఇంటి అడ్రస్ రాసి ఉంది. నేను ఆ అడ్రస్ పట్టుకుని మీ ఇంటికి వచ్చి మిమ్మల్ని కలవచ్చు. ఆ కార్డు (పాయింటర్) ని నేను నా ఫ్రెండ్ కి ఇస్తే, వాడు కూడా ఆ అడ్రస్ తో మీ ఇంటికి రాగలడు. పాయింటర్ ఎప్పుడైనా మారొచ్చు (మీరు వేరే అడ్రస్ కి మారొచ్చు).

Reference అంటే: ఇది మీ ఇంటికి ఉన్న ఇంకొక ముద్దు పేరు (Alias/Nickname) లాంటిది. ఉదాహరణకు "రాము ఇల్లు" అన్నా "సురేష్ ఇల్లు" అన్నా ఒకటే అని ఫిక్స్ అయిపోవడం. ఇది ఒకసారి ఫిక్స్ అయితే మళ్ళీ ఇంకో ఇంటికి మార్చడం కుదరదు! C++ లో పాయింటర్స్ కంటే ఈ References వాడటం చాలా సేఫ్ అండ్ ఈజీ.

2 NULL బదులు C++11 లో వచ్చిన "nullptr"

పాత C లో ఒక పాయింటర్ కి ఏ అడ్రస్ లేకపోతే దానికి NULL (అంటే కేవలం 0) అని ఇచ్చేవాళ్లు. కానీ కొన్ని ఫంక్షన్స్ కి పంపినప్పుడు 0 అంటే నంబర్ 0 నా లేక ఎంప్టీ పాయింటరా అని కంపైలర్ కి విపరీతమైన కన్ఫ్యూజన్ వచ్చేది. ఆ బగ్ ని తీసేయడానికి C++11 లో nullptr ని తెచ్చారు. ఇక మీదట ఎప్పుడైనా ఎంప్టీ పాయింటర్ వాడాలంటే nullptr మాత్రమే వాడాలి.

3 ఒకే ఒక సింపుల్ కోడ్ (References vs Pointers)

కింద కోడ్ లో ఒకే ఒక వాల్యూ ని పాయింటర్ ద్వారా మరియు రిఫరెన్స్ ద్వారా ఎలా మారుస్తున్నామో జాగ్రత్తగా గమనించండి.

C++ — Pointers & References ▶ Run Code 
#include <iostream>

int main() {
    int score = 50;
    
    // 1. Reference (నిక్ నేమ్). ఇది ఎప్పుడూ & తో రాయాలి.
    int &ref = score; 
    
    // 2. Pointer (అడ్రస్ కార్డు). దీనికి అడ్రస్ (&score) ఇవ్వాలి.
    int *ptr = &score;
    
    // రిఫరెన్స్ వాడి మార్చుతున్నాం (ఇది డైరెక్ట్ గా వాడుకోవచ్చు)
    ref = 75;
    
    // పాయింటర్ వాడి మార్చుతున్నాం (దీనికి స్టార్ * వాడాలి)
    *ptr = 100;
    
    // ఫైనల్ గా స్కోర్ ఎంత ఉందో చూద్దాం
    std::cout << "Final Score: " << score << std::endl;
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • int &ref = score;: ఇక్కడ ref అనేది కొత్త వేరియబుల్ కాదు. అది కేవలం score కి పెట్టిన ఇంకొక పేరు మాత్రమే. ref ని మార్చినా డైరెక్ట్ గా score మారిపోతుంది.
  • int *ptr = &score;: ఇక్కడ ptr ఒక కొత్త బాక్స్. అందులో score యొక్క RAM అడ్రస్ ని దాచుకున్నాం.
  • *ptr = 100;: పాయింటర్ కి ముందు * (Dereference) పెడితే, దాని అర్థం "ఆ అడ్రస్ కి వెళ్ళి, అక్కడ ఉన్న వాల్యూ ని 100 కి మార్చు" అని అర్థం. కాబట్టి ఫైనల్ గా స్కోర్ 100 ప్రింట్ అవుతుంది.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: పాయింటర్ కి, రిఫరెన్స్ కి మెయిన్ డిఫరెన్స్ ఏంటి? ఏది వాడాలి?

రిఫరెన్స్ ని ఒకసారి క్రియేట్ చేసాక దాన్ని వేరే దానికి లింక్ చేయడం కుదరదు, మరియు దానికి nullptr ఇవ్వలేము. కానీ పాయింటర్ ని మీరు ఎప్పుడైనా వేరే అడ్రస్ కి మార్చుకోవచ్చు. C++ లో ఫంక్షన్స్ కి డేటా పంపేటప్పుడు 90% రిఫరెన్సెస్ (ఉదా: void print(const string& str)) వాడటమే బెస్ట్ ప్రాక్టీస్, ఎందుకంటే అవి క్రాష్ కావు, సేఫ్.

Q2: Dangling Pointer (డాంగ్లింగ్ పాయింటర్) అంటే ఏంటి?

మీ పాయింటర్ ఒక మెమరీ అడ్రస్ ని పట్టుకుని ఉంది. కానీ ఆ మెమరీ ని వేరే వాళ్ళు డిలీట్ చేసేశారు. ఇప్పుడు మీ పాయింటర్ దగ్గర ఉన్న అడ్రస్ లో ఏమీ లేదు, కానీ అది ఇంకా అక్కడికే పాయింట్ చేస్తూ ఉంటుంది. ఆ చెత్త అడ్రస్ కి పాయింట్ చేసే దాన్నే డాంగ్లింగ్ పాయింటర్ అంటారు. దీన్ని వాడితే ప్రోగ్రామ్ వంద శాతం క్రాష్ అవుతుంది.

Q3: * సింబల్ రెండు సార్లు (ఉదా: int **ptr) ఉంటే అర్థం ఏంటి?

దీన్నే Pointer to a Pointer అంటారు. అంటే మొదటి పాయింటర్ ఇంకొక పాయింటర్ యొక్క అడ్రస్ ని దాచుకుంది అని అర్థం. 2D అర్రేస్ ని మరియు కాంప్లెక్స్ మ్యాట్రిక్స్ ని హ్యాండిల్ చేయడానికి అడ్వాన్స్డ్ ప్రోగ్రామర్స్ దీన్ని వాడుతారు.
