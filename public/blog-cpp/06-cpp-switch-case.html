⚡ switch-case: O(1) Jump Table Dispatch

C++ కంపైలర్ కేస్ లేబుల్స్ ఆధారంగా బైనరీలో ఒక ఇండెక్స్డ్ Jump Table తయారు చేస్తుంది. 100 కేస్ లేబుల్స్ ఉన్నా సరే, విలువను బట్టి నేరుగా ఆ మెమరీ అడ్రస్‌కు ఒక్క క్షణంలో (O(1) Time) దూకేస్తుంది!

2switch-case సింటాక్స్ & Fall-through మెకానిక్స్

కేస్ లేబుల్ మ్యాచ్ అయిన తర్వాత కింద ఉన్న మిగతా కేస్‌లను రన్ చేయకుండా ఆపడానికి తప్పనిసరిగా break; వాడాలి:

💻 Example 1: Modern Menu-Driven Calculator
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    char operation = '+';
    double num1 = 12.0, num2 = 4.0;

    switch (operation) {
        case '+':
            std::cout << "Sum: " << (num1 + num2) << "\n";
            break;
        case '-':
            std::cout << "Difference: " << (num1 - num2) << "\n";
            break;
        case '*':
            std::cout << "Product: " << (num1 * num2) << "\n";
            break;
        case '/':
            if (num2 != 0) std::cout << "Quotient: " << (num1 / num2) << "\n";
            break;
        default:
            std::cout << "Invalid Operator!\n";
            break;
    }

    return 0;
}
3బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ Trap 1: strings లేదా floats ను switch లో వాడటం

C++ లో switch కేవలం Integral Types (int, char, enum, short, long) పై మాత్రమే పనిచేస్తుంది. std::string లేదా float/double ను switch ఎక్స్‌ప్రెషన్‌లో వాడితే కంపైల్-టైమ్ ఎర్రర్ వస్తుంది. స్ట్రింగ్స్ కోసం if-else లేదా హాష్ మ్యాప్ వాడాలి.

❌ Trap 2: Case లోపల వేరియబుల్స్ ఇనిషియలైజేషన్ (Cross-initialization Error)

ఒక కేస్ లోపల case 1: int x = 10; break; అని రాస్తే, కంపైలర్ "cross-initialization" ఎర్రర్ ఇస్తుంది. ఎందుకంటే కేస్ 2 మ్యాచ్ అయితే int x డిక్లరేషన్‌ను దాటి వెళ్లిపోతుంది. పరిష్కారం: ఆ కేస్ కోడ్‌ను కర్లీ బ్రేసెస్ case 1: { int x = 10; break; } తో ఎన్‌క్లోజ్ చేసి లోకల్ స్కోప్ ఇవ్వాలి!
