Variables, Data Types, constexpr, auto & Scope (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 2 📂 Phase 02: Variables, Data Types & Scope 📅 2026 Master Edition
📌 Covered in this in-depth guide: Variables in Memory · Data Types · Modern C++ (auto) · constexpr · Scope & Lifetime

కంప్యూటర్ ప్రోగ్రామ్ అంటేనే డేటాని తీసుకోవడం, దాన్ని ప్రాసెస్ చేయడం, రిజల్ట్ ఇవ్వడం. ఆ డేటాని ప్రాసెస్ చేసేటప్పుడు టెంపరరీ గా దాచుకోవడానికి రామ్ (RAM) లో మనకు కొన్ని ఖాళీ డబ్బాలు కావాలి. ఆ డబ్బాలనే మనం Variables (వేరియబుల్స్) అంటాం. పాత C లాంగ్వేజ్ తో పోలిస్తే C++ లో వేరియబుల్స్ క్రియేట్ చేయడంలో చాలా కొత్త ఫీచర్స్ వచ్చాయి. ముఖ్యంగా auto మరియు constexpr లాంటి మోడరన్ C++ (C++11/14/17) ఫీచర్స్ కోడ్ ని చాలా సింపుల్ గా మార్చేశాయి. ఈ ఆర్టికల్ లో వాటి గురించి డీప్ గా తెలుసుకుందాం.

1 Variables మరియు Data Types

మీరు ఒక బాక్స్ (Variable) తయారు చేసే ముందే... ఆ బాక్స్ లో మీరు నీళ్ళు పోస్తారా, ఇసుక పోస్తారా, లేక బట్టలు పెడతారా అనేది కంపైలర్ కి చెప్పాలి. దీన్నే Data Type అంటారు.

📦 రియల్ లైఫ్ స్టోరీ: స్వీట్ బాక్స్ vs వాటర్ బాటిల్

మీరు నీళ్ళు నింపాలంటే ఒక టైట్ గా ఉండే ప్లాస్టిక్ లేదా గ్లాస్ బాటిల్ వాడతారు. అదే స్వీట్స్ పెట్టాలంటే ఒక అట్టపెట్టె వాడతారు. ఏ దానికి పనికొచ్చే డబ్బా దానికి ఉంటుంది.

ప్రోగ్రామింగ్ లో కూడా నంబర్స్ దాచాలంటే int అనే డబ్బా కావాలి (4 బైట్స్). పాయింట్స్ ఉన్న నంబర్స్ (ఉదా: 9.5) దాచాలంటే float లేదా double కావాలి. అక్షరాలు దాచాలంటే char కావాలి (1 బైట్). మీరు int డబ్బాలో 9.5 ని వేయాలని చూస్తే అది .5 ని కట్ చేసి కేవలం 9 ని మాత్రమే తీసుకుంటుంది!

2 Modern C++ లో వచ్చిన అద్భుతాలు (auto & constexpr)

మీరు పెద్ద పెద్ద డేటా టైప్స్ రాయాలంటే కొన్నిసార్లు చాలా కష్టంగా ఉంటుంది (ఉదాహరణకు: unsigned long long int). దానికి C++11 లో ఒక సొల్యూషన్ వచ్చింది, అదే auto కీవర్డ్. మీరు కేవలం auto x = 10; అని రాస్తే చాలు, ఆ 10 అనే నంబర్ ని చూసి అది int అని కంపైలర్ ఆటోమేటిక్ గా అర్థం చేసుకుంటుంది.

అలాగే, కొన్ని వాల్యూస్ ప్రోగ్రామ్ రన్ అయ్యేటప్పుడు మారవు (ఉదా: వారానికి 7 రోజులు). వాటిని కంపైల్ చేసే టైమ్ లోనే ఫిక్స్ చేసి, స్పీడ్ పెంచడానికి constexpr ని వాడతారు. ఇది C లో ఉన్న const కి అడ్వాన్స్డ్ వెర్షన్.

3 ఒకే ఒక సింపుల్ కోడ్ (Modern C++ Variables)

కింద కోడ్ లో మామూలు వేరియబుల్స్ తో పాటు auto మరియు constexpr ఎలా వాడాలో చూద్దాం.

C++11/17 — Variables Demo ▶ Run Code 
#include <iostream>

int main() {
    // కంపైల్ టైమ్ లోనే ఫిక్స్ అయ్యే వాల్యూ (చాలా ఫాస్ట్)
    constexpr int DAYS_IN_WEEK = 7;
    
    // ఆటోమేటిక్ గా కంపైలర్ డేటా టైప్ కనుక్కుంటుంది
    auto price = 99.99;  // ఇది పాయింట్ ఉంది కాబట్టి 'double' అవుతుంది
    auto name = 'A';     // ఇది సింగిల్ కోట్స్ లో ఉంది కాబట్టి 'char' అవుతుంది
    
    std::cout << "Days: " << DAYS_IN_WEEK << std::endl;
    std::cout << "Price: " << price << std::endl;
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • constexpr int DAYS_IN_WEEK = 7;: ఇది మామూలు వేరియబుల్ కాదు. రన్ టైం దాకా ఆగకుండా, కోడ్ కంపైల్ అవుతున్నప్పుడే దీని వాల్యూ సెట్ అయిపోతుంది. దీని వల్ల సాఫ్ట్‌వేర్ పర్ఫార్మెన్స్ పెరుగుతుంది.
  • auto price = 99.99;: ఇక్కడ మనం double అని రాయలేదు. కానీ కుడి వైపు ఉన్న వాల్యూ (99.99) ని చూసి, కంపైలర్ కి అర్థమైపోయి, దానంతట అదే double price లాగా మార్చుకుంటుంది.
  • ప్రింట్ చేసేటప్పుడు std::cout తో అన్నీ ఒకేసారి పంపిస్తున్నాం.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: auto వాడితే పైథాన్ లాగా డైనమిక్ (Dynamic) లాంగ్వేజ్ లా మారిపోతుందా?

అస్సలు కాదు! పైథాన్ లో వేరియబుల్ టైప్ రన్ అవుతున్నప్పుడు డిసైడ్ అవుతుంది. కానీ C++ లోని auto కేవలం టైప్ చేయకుండా ఉండటానికి షార్ట్ కట్ మాత్రమే. కంపైలర్ ముందే దాన్ని కనిపెట్టి దానికి ఒక టైప్ ని ఫిక్స్ చేస్తుంది. కాబట్టి 1% కూడా స్పీడ్ తగ్గదు, పర్ఫెక్ట్ C++ లాగానే ఫాస్ట్ గా ఉంటుంది.

Q2: const కి మరియు constexpr కి తేడా ఏంటి?

const అంటే ఒకసారి వాల్యూ ఇచ్చాక దాన్ని మళ్ళీ మార్చలేము అని అర్థం, కానీ ఆ వాల్యూ ఎప్పుడు వస్తుందో (కంపైల్ టైమ్ ఆ లేక రన్ టైమ్ ఆ) కంపైలర్ కి కచ్చితంగా తెలీదు. కానీ constexpr వాడితే, కంపైల్ చేసే టైమ్ లోనే దాని వాల్యూ కంప్యూటర్ కి తెలిసిపోవాలి. ఇది చాలా ఫాస్ట్ మరియు ఆప్టిమైజ్డ్ గా పనిచేస్తుంది.

Q3: వేరియబుల్ స్కోప్ (Scope) అంటే ఏమిటి?

ఒక వేరియబుల్ ఎక్కడ పుట్టింది, ఎక్కడ చనిపోతుంది అని చెప్పేదే స్కోప్. మీరు { ... } బ్రాకెట్స్ మధ్యలో ఒక వేరియబుల్ క్రియేట్ చేస్తే, ఆ బ్రాకెట్ అవ్వగానే ఆ వేరియబుల్ ఆటోమేటిక్ గా మెమరీ నుండి డిలీట్ అయిపోతుంది. దీన్నే Local Scope అంటారు.
