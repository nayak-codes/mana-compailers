Templates & Generic Programming (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 13 📂 Phase 13: Templates & Generic Programming 📅 2026 Master Edition
📌 Covered in this in-depth guide: Function Templates · Class Templates · Generic Programming · Template Specialization · Concepts (C++20)

ఒక ఫంక్షన్ రాసి దాన్ని రకరకాలుగా వాడుకోవచ్చు (Overloading) అని మనం నేర్చుకున్నాం. కానీ అందులో ఒక ప్రాబ్లెమ్ ఉంది. మీరు రెండు ఇంటీజర్స్ (int) కూడటానికి ఒక ఫంక్షన్ రాశారు. రేపు మీకు ఫ్లోట్స్ (float) కూడాలి అనిపించింది, మళ్ళీ ఇంకో ఫంక్షన్ రాయాలి. ఎల్లుండి డబుల్స్ (double) కూడాలి, ఇంకోటి రాయాలి. ఇదంతా ఒకే లాజిక్ (కూడిక) అయినప్పుడు, అన్నిటికీ విడివిడిగా కోడ్ రాయడం టైమ్ వేస్ట్ కాదా? ఈ ప్రాబ్లెమ్ ని రూట్ తో సహా పీకేయడానికి C++ కనిపెట్టిన బ్రహ్మాస్త్రమే Templates (టెంప్లేట్స్). దీన్నే మనం Generic Programming (జెనెరిక్ ప్రోగ్రామింగ్) అని అంటాము. అసలు ఈ టెంప్లేట్స్ ఎంత పవర్ ఫుల్ అంటే, మొత్తం C++ STL (Standard Template Library) పుట్టిందే దీని మీద!

1 Templates (టెంప్లేట్స్) ఎలా పనిచేస్తాయి?

టెంప్లేట్ అంటే ఒక మౌల్డ్ (అచ్చు లేదా స్వరూపం) లాంటిది. అందులో మీరు లాజిక్ ఒకసారి రాసి పెడతారు, కానీ ఏ డేటా టైప్ వాడాలో చెప్పరు. ఆ డేటా టైప్ ని <T> అనే ఒక స్పెషల్ వేరియబుల్ లాగా పక్కన పెడతారు. మీరు ఎప్పుడైతే ఫంక్షన్ ని కాల్ చేసి దానికి నంబర్ ఇస్తారో... అప్పుడు కంపైలర్ ఆ నంబర్ ని చూసి, బ్యాక్ గ్రౌండ్ లో ఆ <T> ని int కింద మార్చుకుని దానంతట అదే ఒక ఫంక్షన్ ని తయారు చేసుకుంటుంది!

🏭 రియల్ లైఫ్ స్టోరీ: బొమ్మల ఫ్యాక్టరీ లో ఇనుప అచ్చు (Mould)

ఒక ఫ్యాక్టరీ లో కారు ఆకారంలో ఉన్న ఒక ఇనుప అచ్చు (Mould) ఉంది అనుకోండి. ఆ అచ్చు ని టెంప్లేట్ (Template) అంటారు.

అందులో మీరు ప్లాస్టిక్ పోస్తే (int పంపిస్తే)... ప్లాస్టిక్ కారు వస్తుంది.
అందులో మీరు కరిగించిన చాక్లెట్ పోస్తే (double పంపిస్తే)... చాక్లెట్ కారు వస్తుంది.
అందులో మైనం పోస్తే (string పంపిస్తే)... మైనపు కారు వస్తుంది.

షేప్ (లాజిక్) ఒకటే... కానీ మీరు పోసే మెటీరియల్ (డేటా టైప్) ని బట్టి ఫైనల్ ప్రోడక్ట్ మారిపోతుంది. ప్రోగ్రామింగ్ లో కూడా మీరు లాజిక్ ఒకసారే రాస్తారు, కంపైలర్ మీరు పంపిన డేటా ని బట్టి రకరకాల ఫంక్షన్స్ ని ఆటోమేటిక్ గా రాసుకుంటుంది. ప్రోగ్రామర్ కి పని చాలా ఈజీ అయిపోతుంది.

2 Class Templates మరియు Specialization

కేవలం ఫంక్షన్స్ కి మాత్రమే కాకుండా, మొత్తం ఒక క్లాస్ కి కూడా మనం టెంప్లేట్ రాయొచ్చు. ఉదాహరణకు vector<int> మరియు vector<string> ఇవన్నీ క్లాస్ టెంప్లేట్స్ వల్లే సాధ్యం అయ్యాయి.

Template Specialization: టెంప్లేట్ అన్నిటికీ ఒకేలా పనిచేస్తుంది కదా. కానీ ఏదైనా ఒక పర్టికులర్ డేటా టైప్ (ఉదాహరణకు char*) వచ్చినప్పుడు మాత్రం వేరే లాజిక్ రన్ అవ్వాలి అనుకుంటే, దానికి మనం ఒక స్పెషల్ టెంప్లేట్ రాసుకోవచ్చు. దీన్నే స్పెషలైజేషన్ అంటారు.

3 ఒకే ఒక సింపుల్ కోడ్ (Function Template)

కింద కోడ్ లో getMax అనే ఒకటే ఫంక్షన్ ని టెంప్లేట్ వాడి రాసాం. అదే ఫంక్షన్ ఇంటీజర్స్ ని, ఫ్లోట్స్ ని, స్ట్రింగ్స్ ని ఎలా క్యాలిక్యులేట్ చేస్తుందో చూడండి.

C++ — Generic Templates ▶ Run Code 
#include <iostream>
#include <string>

// T అనేది డేటా టైప్ (int, float, string ఏదైనా కావొచ్చు)
template <typename T>
T getMax(T a, T b) {
    // రెండిట్లో ఏది పెద్దదైతే అది ఇస్తుంది
    if (a > b) {
        return a;
    } else {
        return b;
    }
}

int main() {
    // 1. ఇంటీజర్స్ (నంబర్స్) పంపుతున్నాం
    int maxInt = getMax(10, 25);
    std::cout << "Max Int: " << maxInt << std::endl;
    
    // 2. డబుల్స్ (పాయింట్ నంబర్స్) పంపుతున్నాం
    double maxDouble = getMax(9.99, 4.55);
    std::cout << "Max Double: " << maxDouble << std::endl;
    
    // 3. క్యారెక్టర్స్ (అక్షరాలు) పంపుతున్నాం (ఆస్కీ కోడ్ బట్టి వస్తుంది)
    char maxChar = getMax('A', 'Z');
    std::cout << "Max Char: " << maxChar << std::endl;
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • template <typename T>: ఇక్కడ T అంటే Type అని అర్థం (మీరు ఏ పేరు అయినా పెట్టుకోవచ్చు). ఇది రాసిన తర్వాత కింద ఉన్న ఫంక్షన్ అంతా T మీద ఆధారపడి ఉంటుంది.
  • మనం getMax(10, 25) కాల్ చేసినప్పుడు, కంపైలర్ చూసుకుని "అరె ఇవి int వాల్యూస్ కదా" అని అర్థం చేసుకుని, బ్యాక్ గ్రౌండ్ లో T ప్లేస్ లో int పెట్టి ఒక ఫంక్షన్ క్రియేట్ చేస్తుంది.
  • అదే getMax(9.99, 4.55) పిలిచినప్పుడు, డబుల్స్ కి సరిపడే ఇంకొక ఫంక్షన్ ని దానంతట అదే క్రియేట్ చేస్తుంది. ఇదంతా ప్రోగ్రామ్ రన్ అయ్యేటప్పుడు కాదు, కంపైల్ అయ్యేటప్పుడే జరిగిపోతుంది. కాబట్టి స్పీడ్ ఏమాత్రం తగ్గదు. సూపర్ ఫాస్ట్!
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: C++20 లో కొత్తగా వచ్చిన "Concepts" అంటే ఏంటి?

టెంప్లేట్స్ లో ఉన్న పెద్ద మైనస్ ఏంటంటే, మీరు T లోపలికి ఏ చెత్త పంపినా అది తీసుకుంటుంది, లోపల లాజిక్ ఫెయిల్ అయ్యి భయంకరమైన ఎర్రర్ మెసేజెస్ ఇస్తుంది. దీన్ని ఆపడానికి C++20 లో Concepts (కాన్సెప్ట్స్) తెచ్చారు. దీని ద్వారా మీరు T మీద కండిషన్స్ పెట్టొచ్చు (ఉదాహరణకు: template <Integral T> అని రాస్తే, కేవలం నంబర్స్ ని మాత్రమే అలో చేస్తుంది, వేరేవి ఇస్తే సింపుల్ ఎర్రర్ ఇస్తుంది).

Q2: జావా లో ఉండే Generics కి, C++ లో ఉండే Templates కి తేడా ఏంటి?

జావా లో జెనెరిక్స్ కేవలం కోడ్ రాసేటప్పుడు మాత్రమే పనిచేస్తాయి (Type Erasure), ప్రోగ్రామ్ రన్ అయ్యేటప్పుడు అన్నీ ఒకే ఆబ్జెక్ట్ కింద మారిపోతాయి. కానీ C++ లో కంపైలర్ ప్రతి ఒక్క డేటా టైప్ కి విడివిడిగా ఒరిజినల్ మెషిన్ కోడ్ (Assembly) జనరేట్ చేస్తుంది. అందుకే C++ టెంప్లేట్స్ చాలా ఫాస్ట్ గా ఉంటాయి, కానీ దానివల్ల ఫైనల్ .exe ఫైల్ సైజ్ కొంచెం పెరుగుతుంది (దీన్నే Code Bloat అంటారు).

Q3: template <class T> కి మరియు template <typename T> కి తేడా ఉందా?

పాత C++ వెర్షన్స్ లో class T వాడేవాళ్ళు. కానీ అది చూసి స్టూడెంట్స్ ఇది కేవలం క్లాసెస్ కి మాత్రమే అప్లై అవుతుందేమో అని కన్ఫ్యూజ్ అయ్యేవారు (int కి క్లాస్ ఉండదు కదా). ఆ కన్ఫ్యూజన్ పోగొట్టడానికి తర్వాత typename T ని కూడా అలో చేశారు. ఈ రెండిటి మధ్య 99% ఎలాంటి తేడా లేదు, ఏది వాడినా ఒకటే.
