C++ Fundamentals, Compiler Pipeline & Hello World (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 1 📂 Phase 01: C++ Basics & Architecture 📅 2026 Master Edition
📌 Covered in this in-depth guide: History of C++ · C vs C++ · Compiler Pipeline · Hello World · std::cout

ప్రపంచంలో వేగంగా పనిచేసే సాఫ్ట్‌వేర్స్ అయిన గేమ్ ఇంజిన్స్ (Unreal Engine), బ్రౌజర్స్ (Google Chrome, Firefox), మరియు ఆపరేటింగ్ సిస్టమ్స్ లోపల ఉండే ఇంజిన్స్... ఇవన్నీ దేనితో రాస్తారో తెలుసా? C++ తో! పైథాన్, జావా లాంటి ఎన్నో కొత్త లాంగ్వేజెస్ వచ్చినా, స్పీడ్ (Speed) మరియు పర్ఫార్మెన్స్ విషయానికి వస్తే C++ దరిదాపుల్లోకి కూడా రాలేవు. ఎందుకంటే C++ డైరెక్ట్ గా కంప్యూటర్ హార్డ్ వేర్ తో మాట్లాడుతుంది. ఈ మొదటి పాఠంలో C++ అసలు ఎందుకు పుట్టింది, C లాంగ్వేజ్ కి దీనికి తేడా ఏంటి, మరియు మనం రాసిన కోడ్ అసలు ఎగ్జిక్యూట్ ఎలా అవుతుందో (Compiler Pipeline) డీప్ గా తెలుసుకుందాం.

1 అసలు C++ ఎందుకు పుట్టింది? (C vs C++)

1970ల కాలంలో C లాంగ్వేజ్ సూపర్ హిట్ అయింది. కానీ సాఫ్ట్‌వేర్స్ సైజు పెరుగుతున్న కొద్దీ ఒక ప్రాబ్లెమ్ వచ్చింది. C లో ఉన్న ఫంక్షన్స్ అన్నీ విడివిడిగా గాలిలో తేలుతూ ఉంటాయి. వాటిని కంట్రోల్ చేయడం ఒక పెద్ద తలనొప్పిగా మారింది. అప్పుడే Bjarne Stroustrup అనే ఆయనకు ఒక ఐడియా వచ్చింది... "డేటాని మరియు ఆ డేటాతో పనిచేసే ఫంక్షన్స్ ని ఒకే బాక్స్ లో పెడితే ఎలా ఉంటుంది?" అని. ఆ బాక్స్ నే మనం Classes (క్లాసెస్) అంటాం.

🚗 రియల్ లైఫ్ స్టోరీ: కార్ మెకానిక్ షాప్

ఒక C ప్రోగ్రామర్ కార్ డిజైన్ చేయాలంటే... టైర్లు ఒక దగ్గర, ఇంజిన్ ఇంకో దగ్గర, స్టీరింగ్ ఇంకో దగ్గర పెడతాడు. వాటిని విడివిడిగా కంట్రోల్ చేసే ఫంక్షన్స్ రాస్తాడు. దీనివల్ల ఏ పార్ట్ దేనికి లింక్ అయ్యిందో కన్ఫ్యూజ్ అయ్యే ఛాన్స్ ఉంది.

అదే ఒక C++ ప్రోగ్రామర్ ఏం చేస్తాడంటే... ఒక పెద్ద బాక్స్ (Class) తీసుకుని, దానికి "కార్" అని పేరు పెట్టి, అందులో టైర్లు, ఇంజిన్, అన్నీ కలిపి ఒకే ప్యాకేజీ లాగా చేస్తాడు. ఇప్పుడు మీరు డైరెక్ట్ గా "కార్, ముందుకు వెళ్లు!" అంటే చాలు. దీన్నే Object-Oriented Programming (OOP) అంటారు. C కి ఈ OOP ఫీచర్ ని కలిపితే వచ్చిందే C++ (C కి ఇంక్రిమెంట్).

2 కంపైలర్ పైప్‌లైన్ (Compiler Pipeline) ఎలా పనిచేస్తుంది?

మనం ఇంగ్లీష్ లో రాసిన కోడ్ కంప్యూటర్ (CPU) కి అర్థం కాదు. దానికి 0s అండ్ 1s మాత్రమే తెలుసు. కాబట్టి మనం రాసిన C++ కోడ్ 4 దశల్లో మారిపోయి ఒక .exe ఫైల్ లాగా మారుతుంది.

  • 1. Preprocessing (ప్రీ ప్రాసెసింగ్): మనం పైన రాసిన #include లైన్స్ అన్నీ చదివి, ఆ ఫైల్స్ లోని డేటా అంతా కాపీ పేస్ట్ చేస్తుంది.
  • 2. Compilation (కంపైలేషన్): ఆ కాపీ అయిన పెద్ద కోడ్ ని తీసుకుని అసెంబ్లీ కోడ్ (Assembly Code) లాగా మారుస్తుంది.
  • 3. Assembly (అసెంబ్లీ): అసెంబ్లీ కోడ్ ని డైరెక్ట్ గా మెషిన్ కోడ్ (0s & 1s) గా మారుస్తుంది. దీన్నే ఆబ్జెక్ట్ ఫైల్ (.o లేదా .obj) అంటారు.
  • 4. Linking (లింకింగ్): అన్ని ఆబ్జెక్ట్ ఫైల్స్ ని, లైబ్రరీస్ ని కలిపి కుట్టి ఒక ఫైనల్ రన్ అయ్యే యాప్ (.exe) ని తయారు చేస్తుంది.
3 ఒకే ఒక సింపుల్ కోడ్ (C++ Hello World)

ఇప్పుడు మనం C++ లో ఒక సింపుల్ ప్రోగ్రామ్ ఎలా రాయాలో చూద్దాం. ఇందులో C లాగా printf బదులు std::cout వాడతాము.

C++ — First Program ▶ Run Code 
#include <iostream>  // ఇన్పుట్, అవుట్పుట్ కోసం

int main() {
    // స్క్రీన్ మీద ప్రింట్ చేయడం
    std::cout << "Hello, C++ World!" << std::endl;
    
    return 0; // సక్సెస్ ఫుల్ గా పూర్తయింది అని చెప్పడానికి
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • #include <iostream>: C లో ఉన్న stdio.h లాగే ఇది కూడా. iostream అంటే Input Output Stream. ఇది లేకపోతే మనం ప్రింట్ చేయలేము.
  • std::cout: "c-out" అని చదవాలి. అంటే Character Output. std అంటే స్టాండర్డ్ లైబ్రరీ.
  • <<: దీన్ని Insertion Operator అంటారు. కుడి వైపు ఉన్న డేటాని ఎడమవైపు ఉన్న cout లోకి తోస్తుంది (పంపుతుంది).
  • std::endl: "end-line" అని చదవాలి. ప్రింట్ చేసాక నెక్స్ట్ లైన్ కి వెళ్లడానికి (New Line) ఇది వాడతారు. ఇది \n లాగా పనిచేస్తుంది.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: C++ లో C కోడ్ రన్ అవుతుందా?

చాలా వరకు అవుతుంది! C++ అనేది C కి ఎక్స్టెన్షన్. మీరు C++ ఫైల్ (.cpp) లో C లాంగ్వేజ్ కోడ్ (printf, scanf లాంటివి) రాసినా కూడా కంపైలర్ ఏమీ అనదు, పర్ఫెక్ట్ గా రన్ చేస్తుంది.

Q2: ప్రతిసారి std:: అని రాయడం విసుగ్గా ఉంది, సొల్యూషన్ లేదా?

ఉంది! పైన using namespace std; అని రాస్తే, ఇక కింద ఎక్కడ కూడా std:: అని రాయక్కర్లేదు, డైరెక్ట్ గా cout వాడేయొచ్చు. కానీ పెద్ద ప్రాజెక్ట్స్ లో ఇలా రాయడం డేంజర్, పేరు క్లాషెస్ వస్తాయి కాబట్టి std:: వాడటమే మంచి పద్ధతి.

Q3: C++ ఫాస్ట్ అని ఎందుకు అంటారు? జావా ఎందుకు ఫాస్ట్ కాదు?

జావా లాంటి లాంగ్వేజెస్ నేరుగా హార్డ్ వేర్ మీద రన్ అవ్వవు, వాటికి మధ్యలో JVM (Java Virtual Machine) అనే ఒక ట్రాన్స్లేటర్ ఉంటుంది, దాని వల్ల స్పీడ్ తగ్గుతుంది. కానీ C++ అలా కాదు, కంపైలర్ డైరెక్ట్ గా మెషిన్ కోడ్ కి మారిపోతుంది, మధ్యలో ఏమీ ఉండదు. అందుకే గేమ్స్ అన్నీ C++ తోనే రాస్తారు.
