Runtime Errors ను సురక్షితంగా ఎదుర్కొనే try, catch, మరియు throw మెకానిజమ్స్, కాల్ స్టాక్ ఆటో-క్లీనప్ Stack Unwinding, std::fstream ద్వారా హార్డ్‌డిస్క్‌లో ఫైల్స్ రాయడం/చదవడం, మరియు అన్ని C++ కాన్సెప్టులను కలిపి రూపొందించిన Student Management System Capstone Project.

1 ఎక్సెప్షన్ హ్యాండ్లింగ్ (Exception Handling) అంటే ఏమిటి?

ఒక ప్రోగ్రామ్ రన్ అవుతున్నప్పుడు అనుకోకుండా సున్నాతో భాగహారం చేయడం (Division by Zero), ఫైల్ లభించకపోవడం, లేదా రామ్ మెమరీ అయిపోవడం వంటి అనూహ్య సమస్యలు రావచ్చు. వీటిని ముందస్తుగా హ్యాండిల్ చేయకపోతే ఆపరేటింగ్ సిస్టమ్ ప్రోగ్రామ్‌ను బలవంతంగా క్రాష్ చేస్తుంది (Crash/Abort).

క్రాష్ అవ్వకుండా ఎర్రర్‌ను గుర్తించి, ప్రత్యామ్నాయ మార్గాన్ని అందించడమే Exception Handling. C++ లో ఇది మూడు కీవర్డ్స్ తో పనిచేస్తుంది:

[try - throw - catch ట్రయాంగిల్ ఆర్కిటెక్చర్] 1. try { ... } ప్రమాదం జరిగే అవకాశం ఉన్న అనుమానాస్పద కోడ్‌ను ఈ బ్లాక్ లోపల ఉంచుతాము. 2. throw ExceptionObject; ఏదైనా సమస్య వచ్చినప్పుడు తగిన ఎర్రర్ ఆబ్జెక్ట్‌ను బయటకు విసురుతాము (Throw). 3. catch (const std::exception& e) { ... } విసిరిన ఆ ఎర్రర్‌ను సురక్షితంగా ఒడిసిపట్టుకుని, e.what() ద్వారా యూజర్‌కు స్పష్టమైన కారణాన్ని తెలియజేస్తాము.
2 లోపల ఏం జరుగుతుంది? Stack Unwinding మ్యాజిక్

ఎక్సెప్షన్ వచ్చినప్పుడు మెమరీ లీక్ అవ్వకుండా C++ ఎలా కాపాడుతుంది? ఇక్కడే C++ యొక్క అద్భుతమైన మెకానిజమ్ Stack Unwinding పనికొస్తుంది:

[Stack Unwinding సమయంలో ఆటోమేటిక్ Destructor క్లీనప్] main() ──► processOrder() ──► chargeCard() [ఇక్కడ throw జరిగింది!] కాల్ స్టాక్ లో జరిగే ప్రక్రియ: 1. chargeCard() లోని throw వెంటనే catch కోసం వెతుకుతుంది. 2. స్థానికంగా catch లేకపోతే ఆ ఫంక్షన్ స్టాక్ ఫ్రేమ్ నుండి బయటకు దూకుతుంది. 3. దూకే ముందు: chargeCard() లో ఉన్న అన్ని లోకల్ ఆబ్జెక్టుల Destructors ఆటోమేటిక్‌గా రన్ అవుతాయి! 4. ఆ తర్వాత processOrder() లోని ఆబ్జెక్టుల Destructors రన్ అవుతాయి! 5. చివరకు main() లోని catch బ్లాక్ వద్ద ఆగిపోతుంది. ఫలితం: RAII సూత్రం పాటించిన ప్రతి ఆబ్జెక్ట్ ఎక్సెప్షన్ వచ్చినా సురక్షితంగా క్లీన్ అవుతుంది!
💻 Code Example 1: Custom Exception with Safe Division & Stack Cleanup
exception_handling_compact.cpp
⚡ Try in Compiler 
#include <iostream>
#include <stdexcept>
#include <string>

// సురక్షిత భాగహార ఫంక్షన్
double safeDivide(double numerator, double denominator) {
    if (denominator == 0.0) {
        // స్టాండర్డ్ లైబ్రరీ ఎక్సెప్షన్ విసరడం
        throw std::invalid_argument("Math Error: Division by Zero is not allowed!");
    }
    return numerator / denominator;
}

int main() {
    std::cout << "=== Testing C++ Exception Handling ===\n";

    try {
        std::cout << "100 / 4 = " << safeDivide(100.0, 4.0) << "\n";
        std::cout << "Attempting 50 / 0...\n";
        double result = safeDivide(50.0, 0.0); // ఎక్సెప్షన్ విసురుతుంది!
        std::cout << "Result: " << result << "\n"; // ఈ లైన్ ఎగ్జిక్యూట్ అవ్వదు!
    } 
    catch (const std::invalid_argument& e) {
        std::cerr << "  [CAUGHT EXCEPTION]: " << e.what() << "\n";
    }
    catch (const std::exception& e) {
        std::cerr << "  [GENERIC EXCEPTION]: " << e.what() << "\n";
    }

    std::cout << "Program resumed normally without crashing! ✔️\n";
    return 0;
}

3 ఫైల్ హ్యాండ్లింగ్ (File I/O with <fstream>)

ప్రోగ్రామ్ ముగిసిన తర్వాత కూడా డేటా కంప్యూటర్ హార్డ్‌డిస్క్‌లో పదిలంగా ఉండాలంటే (Persistence), మనం ఫైల్స్‌లో రాయడం మరియు చదవడం చేయాలి:

స్ట్రీమ్ క్లాస్ దిశ (Direction) ఎప్పుడు వాడాలి?
std::ofstream Output (రాయడం) కొత్త ఫైల్ సృష్టించి టెక్స్ట్/డేటాను సేవ్ చేయడానికి. std::ios::app వాడితే అపెండ్ అవుతుంది.
std::ifstream Input (చదవడం) ఇప్పటికే ఉన్న ఫైల్ నుండి డేటాను లైన్ బై లైన్ లేదా వర్డ్ బై వర్డ్ చదవడానికి.
std::fstream రెండు వైపులా (Bi-directional) ఒకే ఫైల్ పై చదవడం మరియు రాయడం రెండూ అవసరమైనప్పుడు.
4 కోర్స్ ఫినాలే: Student Management System Mini Project

ఇప్పటివరకు మనం నేర్చుకున్న C++ కాన్సెప్టులన్నింటినీ — Classes, Encapsulation, Constructors, Vectors, Exception Handling, మరియు File I/O — కలిపి రూపొందించిన సంపూర్ణ ప్రాజెక్ట్ ఇది!

💻 Code Example 2: Complete Student Records File Management Capstone Project
student_management_capstone.cpp
⚡ Try in Compiler 
#include <iostream>
#include <fstream>
#include <vector>
#include <string>
#include <stdexcept>

class Student {
public:
    int id;
    std::string name;
    double gpa;

    Student(int i, const std::string& n, double g) : id(i), name(n), gpa(g) {
        if (gpa < 0.0 || gpa > 10.0) {
            throw std::invalid_argument("Invalid GPA! Must be between 0.0 and 10.0");
        }
    }
};

int main() {
    std::cout << "=== C++ Capstone: Student Records System ===\n";
    std::vector<Student> roster;

    // 1. రికార్డులను ఎక్సెప్షన్ సేఫ్టీ తో లోడ్ చేయడం
    try {
        roster.push_back(Student(101, "Kavya Sharma", 9.4));
        roster.push_back(Student(102, "Rahul Varma", 8.8));
    } catch (const std::exception& e) {
        std::cerr << "Creation Error: " << e.what() << "\n";
    }

    // 2. ofstream ద్వారా ఫైల్ లోకి శాశ్వతంగా రాయడం
    std::ofstream outFile("students.txt");
    if (outFile.is_open()) {
        for (const auto& s : roster) {
            outFile << s.id << "," << s.name << "," << s.gpa << "\n";
        }
        outFile.close(); // ఫైల్ సేవ్ అయింది
        std::cout << "Successfully exported " << roster.size() << " students to 'students.txt'\n";
    }

    // 3. ifstream ద్వారా ఫైల్ నుండి చదివి కన్సోల్ లో చూపించడం
    std::cout << "\n--- Reading Back from 'students.txt' ---\n";
    std::ifstream inFile("students.txt");
    std::string line;
    while (std::getline(inFile, line)) {
        std::cout << "File Record: " << line << "\n";
    }
    inFile.close();

    std::cout << "\n🎉 Congratulations! You have completed the 20-Chapter C++ Masterclass!\n";
    return 0;
}

❓ Frequently Asked Questions (FAQ)

Q C++ లో 'Stack Unwinding' అంటే ఏమిటి?

ఒక ఫంక్షన్ లో throw ద్వారా ఎక్సెప్షన్ విడుదలైనప్పుడు, దానికి సరిపడే catch బ్లాక్ దొరికే వరకు కంపైలర్ కాల్ స్టాక్ లోని ఫంక్షన్లను వెనక్కి రివర్స్ చేస్తుంది. ఈ ప్రక్రియలో మధ్యలో సృష్టించబడిన అన్ని లోకల్ స్టాక్ ఆబ్జెక్టుల Destructors ఆటోమేటిక్‌గా ఎగ్జిక్యూట్ అయి మెమరీ మరియు రిసోర్సెస్ శుభ్రపరచబడతాయి. దీనినే Stack Unwinding అంటారు.

Q C++ లో ఫైల్ ఆపరేషన్ల కోసం <fstream> లోని క్లాసెస్ ఏమిటి?

ప్రధానంగా మూడు క్లాసెస్ ఉంటాయి: 1. std::ifstream (Input File Stream) - ఫైల్ నుండి డేటాను చదవడానికి. 2. std::ofstream (Output File Stream) - ఫైల్ లోకి కొత్త డేటాను రాయడానికి. 3. std::fstream - ఒకే ఫైల్ పై చదవడం మరియు రాయడం రెండూ చేయడానికి. RAII సూత్రం ప్రకారం ఆబ్జెక్ట్ స్కోప్ దాటగానే ఫైల్ ఆటోమేటిక్‌గా క్లోజ్ అవుతుంది.

Q catch (const std::exception& e) ద్వారా పట్టుకోవడం ఎందుకు మంచి పద్ధతి?

std::exception అనేది C++ లోని అన్ని స్టాండర్డ్ ఎక్సెప్షన్లకు (runtime_error, out_of_range, bad_alloc) మూల పేరెంట్ క్లాస్. దీనిని కాన్స్ట్ రిఫరెన్స్ (&) ద్వారా పట్టుకోవడం వల్ల ఆబ్జెక్ట్ స్లైసింగ్ (Object Slicing) జరగదు మరియు e.what() ద్వారా ఎర్రర్ ఖచ్చితమైన కారణాన్ని తెలుసుకోవచ్చు.
