1 ఎక్సెప్షన్ హ్యాండ్లింగ్ అంటే ఏమిటి? Try-Throw-Catch త్రయం

ఒక అప్లికేషన్ రన్ అవుతున్నప్పుడు సున్నాతో భాగహారం చేయడం (Division by Zero), ఫైల్ లభించకపోవడం (File Not Found), లేదా రామ్ అయిపోవడం (Out of Memory) వంటి తీవ్రమైన సమస్యలు ఎదురుకావచ్చు. సాధారణంగా ఇలాంటి సమయాల్లో ఆపరేటింగ్ సిస్టమ్ ప్రోగ్రామ్‌ను బలవంతంగా క్రాష్ చేసి ఆపివేస్తుంది.

క్రాష్ అవ్వకుండా ఎర్రర్‌ను గుర్తించి, ప్రత్యామ్నాయ సురక్షిత మార్గాన్ని ఇవ్వడమే Exception Handling. C++ లో ఇది 3 కీవర్డ్స్‌తో నడుస్తుంది:

🛡️ try - throw - catch ట్రయాంగిల్ ఆర్కిటెక్చర్:

1. try { ... }
సమస్య వచ్చే అవకాశం ఉన్న కోడ్‌ను ఇందులో పెడతాం.
2. throw
ఎర్రర్ రాగానే ఆబ్జెక్ట్‌ను బయటకు విసురుతాం.
3. catch { ... }
విసిరిన ఎర్రర్‌ను పట్టుకుని సురక్షితంగా హ్యాండిల్ చేస్తాం.
💻 Example 1: Safe Division & Catching Standard Exceptions
exception_basics.cpp
⚡ Try in Compiler 
#include <iostream>
#include <stdexcept>

double divide(double a, double b) {
    if (b == 0.0) throw std::invalid_argument("Division by Zero is not allowed!");
    return a / b;
}

int main() {
    try {
        std::cout << "10 / 2 = " << divide(10.0, 2.0) << "\n";
        std::cout << "10 / 0 = " << divide(10.0, 0.0) << "\n"; // Throws exception!
    } catch (const std::invalid_argument& e) {
        std::cerr << "Caught Error: " << e.what() << "\n";
    }
    std::cout << "Program completed smoothly without crashing! ✔️\n";
    return 0;
}
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • throw std::invalid_argument(...): ప్రామాణిక C++ ఎక్సెప్షన్ ఆబ్జెక్ట్‌ను విసురుతుంది.
  • catch (const std::invalid_argument& e): కాన్స్ట్ రిఫరెన్స్ ద్వారా పట్టుకుని, e.what() ద్వారా స్పష్టమైన ఎర్రర్ మెసేజ్‌ను స్క్రీన్ పై చూపిస్తుంది.
2 లోపల ఏం జరుగుతుంది? Stack Unwinding మ్యాజిక్

ఒక లోతైన ఫంక్షన్ లో throw జరిగినప్పుడు, కాల్ స్టాక్ (Call Stack) లో ఉన్న మధ్యంతర ఫంక్షన్ల పరిస్థితి ఏమిటి?

🔄 Stack Unwinding మెకానిజమ్:

ఎక్సెప్షన్ విడుదలైన వెంటనే, దానికి తగిన catch బ్లాక్ దొరికే వరకు కంపైలర్ కాల్ స్టాక్‌లోని ఫంక్షన్లను వెనక్కి రివర్స్ చేస్తుంది. ఈ ప్రయాణంలో మార్గమధ్యంలో సృష్టించబడిన అన్ని లోకల్ స్టాక్ ఆబ్జెక్టుల Destructors ఆటోమేటిక్‌గా రన్ అయ్యి మెమరీ, ఓపెన్ ఫైల్స్ శుభ్రపరచబడతాయి!

RAII సూత్రం పాటించిన ఏ ప్రోగ్రామ్‌లోనూ ఎక్సెప్షన్ వచ్చినా ఒక్క బైట్ కూడా మెమరీ లీక్ అవ్వదు!

3 ఫైల్ హ్యాండ్లింగ్ (File I/O with <fstream>)

ప్రోగ్రామ్ ముగిసిన తర్వాత కూడా డేటా కంప్యూటర్ హార్డ్‌డిస్క్‌లో శాశ్వతంగా భద్రంగా ఉండాలంటే <fstream> లైబ్రరీని ఉపయోగిస్తాం:

💻 Example 2: Writing and Reading Data from a Disk File
file_io_quick.cpp
⚡ Try in Compiler 
#include <iostream>
#include <fstream>
#include <string>

int main() {
    // 1. Write to File (ofstream)
    std::ofstream outFile("welcome.txt");
    outFile << "Hello C++ 2026 Edition!\nLearning file handling in Telugu.";
    outFile.close();

    // 2. Read from File (ifstream)
    std::ifstream inFile("welcome.txt");
    std::string line;
    std::cout << "File Content:\n";
    while (std::getline(inFile, line)) {
        std::cout << "  > " << line << "\n";
    }
    return 0;
}
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • std::ofstream outFile("welcome.txt"): ఫైల్ ను రాయడానికి ఓపెన్ చేస్తుంది (లేకపోతే కొత్తది క్రియేట్ చేస్తుంది).
  • std::getline(inFile, line): ఫైల్ నుండి లైన్ బై లైన్ టెక్స్ట్ ను రీడ్ చేసి స్క్రీన్ పై ప్రింట్ చేస్తుంది.
4 కోర్స్ ఫినాలే: Student Management System Capstone Project

ఈ 20-అధ్యాయాల C++ మాస్టర్ కోర్స్‌లో మనం నేర్చుకున్న Classes, Encapsulation, Vectors, Exceptions, మరియు File Persistence లను అనుసంధానించే సమగ్ర మినీ ప్రాజెక్ట్:

💻 Capstone Project: Robust Student Record Manager
student_system_capstone.cpp
⚡ Try in Compiler 
#include <iostream>
#include <vector>
#include <string>
#include <stdexcept>

class Student {
public:
    int id;
    std::string name;
    double gpa;

    Student(int i, std::string n, double g) : id(i), name(n), gpa(g) {
        if (gpa < 0.0 || gpa > 10.0) {
            throw std::invalid_argument("GPA must be between 0.0 and 10.0!");
        }
    }
};

int main() {
    std::vector<Student> database;
    try {
        database.emplace_back(101, "Sita", 9.8);
        database.emplace_back(102, "Ram", 9.5);
        std::cout << "Enrolled Students: " << database.size() << " records active.\n";
    } catch (const std::exception& e) {
        std::cerr << "Enrollment Error: " << e.what() << "\n";
    }
    return 0;
}
❓ Frequently Asked Questions (FAQ)

Q C++ లో 'Stack Unwinding' అంటే ఏమిటి?

ఒక ఫంక్షన్ లో 'throw' ద్వారా ఎక్సెప్షన్ విడుదలైనప్పుడు, దానికి సరిపడే 'catch' బ్లాక్ దొరికే వరకు కంపైలర్ కాల్ స్టాక్ లోని ఫంక్షన్లను వెనక్కి రివర్స్ చేస్తుంది. ఈ ప్రక్రియలో మధ్యలో సృష్టించబడిన అన్ని లోకల్ స్టాక్ ఆబ్జెక్టుల Destructors ఆటోమేటిక్‌గా ఎగ్జిక్యూట్ అయి మెమరీ మరియు రిసోర్సెస్ శుభ్రపరచబడతాయి. దీనినే Stack Unwinding అంటారు.

Q C++ లో ఫైల్ ఆపరేషన్ల కోసం <fstream> లోని క్లాసెస్ ఏమిటి?

ప్రధానంగా మూడు క్లాసెస్ ఉంటాయి: 1. std::ifstream (Input File Stream) - ఫైల్ నుండి డేటాను చదవడానికి. 2. std::ofstream (Output File Stream) - ఫైల్ లోకి కొత్త డేటాను రాయడానికి. 3. std::fstream - ఒకే ఫైల్ పై చదవడం మరియు రాయడం రెండూ చేయడానికి. RAII సూత్రం ప్రకారం ఆబ్జెక్ట్ స్కోప్ దాటగానే ఫైల్ ఆటోమేటిక్‌గా క్లోజ్ అవుతుంది.

Q catch (const std::exception& e) ద్వారా పట్టుకోవడం ఎందుకు మంచి పద్ధతి?

std::exception అనేది C++ లోని అన్ని స్టాండర్డ్ ఎక్సెప్షన్లకు (runtime_error, out_of_range, bad_alloc) మూల పేరెంట్ క్లాస్. దీనిని కాన్స్ట్ రిఫరెన్స్ (&) ద్వారా పట్టుకోవడం వల్ల ఆబ్జెక్ట్ స్లైసింగ్ (Object Slicing) జరగదు మరియు 'e.what()' ద్వారా ఎర్రర్ ఖచ్చితమైన కారణాన్ని తెలుసుకోవచ్చు.
