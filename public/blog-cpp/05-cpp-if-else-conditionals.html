డెసిషన్ మేకింగ్ (if, else if, else & Nested Conditions)

⚡ Modern C++20 / C++17 🟢 Chapter 5 of 20 📂 Phase 2: Control Flow & Loops 📅 2026 Edition
📌 Covered in this chapter: Control Flow Foundations · if Statement · if-else Statement · else-if Ladder · Nested if & Dangling Else Ambiguity · Modern C++17 if with Initializer · Clean Code Guard Clauses (Avoiding Deep Nesting)
కంప్యూటర్ కేవలం లెక్కలు మాత్రమే చేయదు, సందర్భాన్ని బట్టి సరైన నిర్ణయాలు (Decisions) కూడా తీసుకుంటుంది. ఈ అధ్యాయంలో ప్రోగ్రామ్ ఫ్లోను కంట్రోల్ చేసే if, if-else, else-if ladder, బగ్స్‌కు కారణమయ్యే Dangling Else సమస్య, మరియు Modern C++17 లో వచ్చిన సూపర్ ఆప్టిమైజ్డ్ `if with initializer` ఫీచర్‌ను నేర్చుకుందాం.
1Decision Making అంటే ఏమిటి? (Branching Logic)

సాధారణంగా ఒక ప్రోగ్రామ్ మొదటి లైన్ నుండి చివరి లైన్ వరకు వరుసగా (Sequentially) రన్ అవుతుంది. కానీ నిజ జీవితంలో పరిస్థితులను బట్టి దారి మార్చుకోవాల్సి వస్తుంది.

🚦 Real-World Analogy: ట్రాఫిక్ సిగ్నల్

రోడ్డుపై వెళ్తున్నప్పుడు:

  • సిగ్నల్ GREEN అయితే $\rightarrow$ ముందుకు వెళ్ళు.
  • సిగ్నల్ YELLOW అయితే $\rightarrow$ వేగం తగ్గించు.
  • సిగ్నల్ RED అయితే $\rightarrow$ బండి ఆపు.

సాఫ్ట్‌వేర్‌లో ఇలాంటి నిబంధనల ఆధారంగా ఒక బ్లాక్ కోడ్‌ను రన్ చేయాలా వద్దా అని నిర్ణయించడాన్ని Conditional Branching అంటారు.

2The Simple `if` Statement

ఒక నిర్దిష్ట షరతు (Condition) true అయినప్పుడు మాత్రమే ఒక పని జరగాలి అనుకుంటే if స్టేట్‌మెంట్ వాడతాం:

💻 Example 1: ATM Cash Withdrawal Check
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    double bankBalance = 5000.0;
    double withdrawAmount = 2000.0;

    // షరతు: విత్ డ్రా మొత్తం బ్యాలెన్స్ కంటే తక్కువ లేదా సమానం ఉండాలి
    if (withdrawAmount <= bankBalance) {
        bankBalance -= withdrawAmount;
        std::cout << "Transaction Successful! Cash Dispensed: Rs. " << withdrawAmount << "\n";
    }

    std::cout << "Remaining Balance: Rs. " << bankBalance << "\n";
    return 0;
}
3`if - else` Statement (ద్విముఖ నిర్ణయం)

కండిషన్ true అయితే ఒక పని, false అయితే మరొక ప్రత్యామ్నాయ పని చేయాలంటే if-else వాడతాం:

💻 Example 2: Pass or Fail Checker
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    int studentMarks = 42;

    if (studentMarks >= 35) {
        std::cout << "Congratulations! You have PASSED the exam. 🎉\n";
    } else {
        std::cout << "Work Hard! You have NOT passed this time. 📚\n";
    }

    return 0;
}
4`else if` Ladder (బహుముఖ నిర్ణయాలు)

రెండు కంటే ఎక్కువ అవకాశాలు ఉన్నప్పుడు `else if` నిచ్చెన (Ladder) వాడతాం. పై నుంచి కిందకి పరిశీలిస్తూ ఏ కండిషన్ మొదట true అయితే ఆ బ్లాక్ ఎగ్జిక్యూట్ చేసి నిచ్చెన నుండి బయటకు వచ్చేస్తుంది:

💻 Example 3: Academic Grade Evaluator
C++17 else-if ▶ Run in Compiler 
#include <iostream>

int main() {
    double scorePercentage = 87.5;
    char gradeLetter = 'F';

    if (scorePercentage >= 90.0) {
        gradeLetter = 'S'; // Superior
    } else if (scorePercentage >= 80.0) {
        gradeLetter = 'A';
    } else if (scorePercentage >= 70.0) {
        gradeLetter = 'B';
    } else if (scorePercentage >= 60.0) {
        gradeLetter = 'C';
    } else if (scorePercentage >= 35.0) {
        gradeLetter = 'D';
    } else {
        gradeLetter = 'F'; // Fail
    }

    std::cout << "Score: " << scorePercentage << "% | Awarded Grade: " << gradeLetter << "\n";
    return 0;
}
5Nested `if` & The Notorious Dangling Else Ambiguity

ఒక if బ్లాక్ లోపల మరొక if స్టేట్‌మెంట్ రాయడాన్ని Nested if అంటారు.

⚠️ The Dangling Else Trap (కర్లీ బ్రేసెస్ లేకపోతే ప్రమాదం!)

C++ లో ఒక లైన్ ఉన్నప్పుడు { } పెట్టకపోయినా కంపైల్ అవుతుంది. కానీ అది తీవ్రమైన గందరగోళానికి దారితీస్తుంది: 

if (isUserLoggedIn)
    if (isAdmin)
        std::cout << "Admin Panel";
else
    std::cout << "Please Login"; // ❌ ఈ else దేనికి చెందుతుంది?

ఇండెంటేషన్ చూస్తే బయట ఉన్న if కి చెందుతుంది అనుకుంటారు. కానీ C++ రూల్ ప్రకారం else ఎల్లప్పుడూ దానికి దగ్గరగా ఉన్న if (isAdmin) కి మాత్రమే జతకడుతుంది! దీనివల్ల యూజర్ లాగిన్ అవ్వకపోయినా అస్సలు ఎర్రర్ రాదు! ఎల్లప్పుడూ కర్లీ బ్రేసెస్ { } వాడాలి!

6Modern C++17 Feature: `if` with Initializer

C++17 లో ప్రవేశపెట్టిన ఒక అద్భుతమైన ఫీచర్ `if (init; condition)`. ఒక వేరియబుల్‌ను క్రియేట్ చేసి, వెంటనే కండిషన్ చెక్ చేయవచ్చు. ఆ వేరియబుల్ యొక్క జీవితకాలం కేవలం ఆ if-else బ్లాక్ లో మాత్రమే ఉంటుంది:

💻 Example 4: C++17 Scoped Initialization in if
C++17 Modern Feature ▶ Run in Compiler 
#include <iostream>

int fetchBatteryPercentage() { return 18; }

int main() {
    // C++17: batteryLevel వేరియబుల్ కేవలం ఈ if-else లోనే ఉంటుంది!
    if (int batteryLevel = fetchBatteryPercentage(); batteryLevel < 20) {
        std::cout << "Low Battery Warning: " << batteryLevel << "%! Enable Battery Saver 🪫\n";
    } else {
        std::cout << "Battery Sufficient: " << batteryLevel << "% 🔋\n";
    }

    // std::cout << batteryLevel; // ❌ ERROR: batteryLevel ఇక్కడ ఉండదు (మెమరీ క్లీన్!)
    return 0;
}
⚠️ Common Developer Pitfalls in Chapter 5
  • if (x = 0) ప్రమాదం: ఒకే ఈక్వల్ = రాస్తే అదొక అసైన్‌మెంట్ అవుతుంది. 0 అసైన్ అయితే అది ఎల్లప్పుడూ false అయి if లోపలికి అస్సలు వెళ్లదు! పోల్చడానికి == వాడాలి.
  • if (condition); సెమికోలన్ బగ్: if (x > 10); { ... } అని if పక్కనే సెమికోలన్ పెడితే, if స్టేట్‌మెంట్ అక్కడితో ముగిసిపోతుంది. ఆ కింది బ్లాక్ ఎల్లప్పుడూ రన్ అయిపోతుంది!
💻 Hands-on Interactive Practice Challenge

టాస్క్: ఒక కరెంట్ బిల్లు (Electricity Bill) కాలిక్యులేటర్ తయారు చేయండి. స్లాబ్ రేట్లు:
• మొదటి 100 యూనిట్లు: ₹1.50 / యూనిట్
• తదుపరి 200 యూనిట్లు (101 - 300): ₹3.00 / యూనిట్
• 300 యూనిట్లు దాటినవి: ₹5.00 / యూనిట్
మొత్తం బిల్లు ₹500 దాటితే 10% సర్‌ఛార్జ్ యాడ్ చేసి ఫైనల్ బిల్లును లెక్కించండి:

C++17 Electricity Bill Challenge ▶ Run in Compiler 
#include <iostream>
#include <iomanip>

int main() {
    int consumedUnits = 350;
    double totalBill = 0.0;

    // స్లాబ్ లెక్కలు
    if (consumedUnits <= 100) {
        totalBill = consumedUnits * 1.50;
    } else if (consumedUnits <= 300) {
        totalBill = (100 * 1.50) + (consumedUnits - 100) * 3.00;
    } else {
        totalBill = (100 * 1.50) + (200 * 3.00) + (consumedUnits - 300) * 5.00;
    }

    // సర్‌ఛార్జ్ తనిఖీ
    if (totalBill > 500.0) {
        double surcharge = totalBill * 0.10; // 10% Surcharge
        totalBill += surcharge;
    }

    std::cout << "========================================\n";
    std::cout << "       ELECTRICITY BOARD INVOICE        \n";
    std::cout << "========================================\n";
    std::cout << "Consumed Units: " << consumedUnits << " units\n";
    std::cout << std::fixed << std::setprecision(2);
    std::cout << "Total Payable : Rs. " << totalBill << "\n";
    std::cout << "========================================\n";

    return 0;
}

❓ Frequently Asked Questions (FAQ)

Q C++ లో Dangling Else సమస్య అంటే ఏమిటి?

కర్లీ బ్రేసెస్ { } వాడకుండా నెస్టెడ్ if రాసినప్పుడు, ఒక else ఏ if కి చెందుతుందో అస్పష్టత ఏర్పడుతుంది. C++ నియమం ప్రకారం ఎల్లప్పుడూ else అనేది దానికంటే ముందున్న అత్యంత సమీపంలోని if కి జతకడుతుంది. దీనిని నివారించడానికి ఎల్లప్పుడూ కర్లీ బ్రేసెస్ వాడాలి.

Q Modern C++17 లో 'if with initializer' ఎందుకు ప్రవేశపెట్టారు?

if (int status = check(); status == 200) లాగా ఒక వేరియబుల్ ను if లోనే ఇనిషియలైజ్ చేయవచ్చు. ఆ వేరియబుల్ కేవలం if-else బ్లాక్ లో మాత్రమే బ్రతికి ఉంటుంది, బయట లీక్ అవ్వదు. ఇది మెమరీని మరియు గ్లోబల్ వేరియబుల్ పొల్యూషన్‌ను తగ్గిస్తుంది.

Q if (x = 5) అని రాస్తే ఏమవుతుంది?

ఇది C++ లో అతి సాధారణమైన బగ్. == కి బదులుగా = వాడితే, x లోకి 5 అసైన్ అవుతుంది. 5 అనేది 0 కాని సంఖ్య కాబట్టి అది ఎల్లప్పుడూ true గా మారి if బ్లాక్ ఎగ్జిక్యూట్ అవుతుంది. పోల్చడానికి కచ్చితంగా == వాడాలి.
