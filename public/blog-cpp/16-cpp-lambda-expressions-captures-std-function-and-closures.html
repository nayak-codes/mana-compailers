Lambda Expressions & Closures (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 16 📂 Phase 16: Lambda Expressions 📅 2026 Master Edition
📌 Covered in this in-depth guide: Anonymous Functions · Capture List [=, &] · std::function · Closures · Modern C++ Callbacks

మనం ఇంతకుముందు నేర్చుకున్నట్లుగా, ఒక పని చేయాలంటే దానికి ఒక ఫంక్షన్ రాసి, ఒక పేరు పెట్టి, మెయిన్ ఫంక్షన్ లోకి పిలవాలి. కానీ ఒకేఒక్క లైన్ లాజిక్ (ఉదాహరణకు రెండు నంబర్స్ ని గుణించడం) కోసం ఇంకో పెద్ద ఫంక్షన్ రాసి పేరు పెట్టడం టైమ్ వేస్ట్ కాదా? ఈ ప్రాబ్లెమ్ ని సాల్వ్ చేయడానికే C++11 లో Lambda Expressions (లాంబ్డా ఎక్స్‌ప్రెషన్స్) వచ్చాయి. ఇవి పేరు లేని ఫంక్షన్స్ (Anonymous Functions). వీటిని డైరెక్ట్ గా కోడ్ మధ్యలోనే ఎక్కడ పడితే అక్కడ వాడేయొచ్చు. ముఖ్యంగా GUI ఈవెంట్స్ లో, త్రెడ్స్ (Threads) లో వీటి వాడకం విపరీతంగా ఉంటుంది. ఇవి ఎలా పనిచేస్తాయో డీప్ గా చూద్దాం.

1 అసలు లాంబ్డా (Lambda) అంటే ఏమిటి?

లాంబ్డా అనేది పేరు లేని ఒక చిన్న ఫంక్షన్. దీని సింటాక్స్ చూడటానికి చాలా విచిత్రంగా ఉంటుంది: [] (పరామీటర్స్) { కోడ్ }. బ్రాకెట్స్ ఉన్నాయి కదా, వాటినే లాంబ్డా ఐడెంటిటీ అంటారు.

🍔 రియల్ లైఫ్ స్టోరీ: హోటల్ మెనూ vs డ్రైవ్-త్రూ ఆర్డర్

ఒక రెగ్యులర్ ఫంక్షన్ రాయడం అనేది పెద్ద హోటల్ లో మెనూ డిజైన్ చేసి, వంటగాడికి పేరు పెట్టి చేయించడం లాంటిది. ఇది చాలా ఫార్మల్ ప్రాసెస్.

కానీ ఒక లాంబ్డా ఫంక్షన్ అనేది డ్రైవ్-త్రూ (Drive-thru) లో ఆర్డర్ ఇవ్వడం లాంటిది. "నాకు ఒక బర్గర్ కావాలి" అని ఫాస్ట్ గా ఆన్ ది స్పాట్ లోనే చెప్పేస్తాం. ఎవరి పేరు అడగం, మెనూ చూడము. జస్ట్ పని అయిపోయిందా లేదా అన్నదే ముఖ్యం. అలాగే కోడ్ లో ఎక్కడైనా ఒక చిన్న ఫంక్షన్ ఆన్ ది స్పాట్ లో కావాలంటే (ఉదా: std::sort కి కస్టమ్ లాజిక్ ఇవ్వడానికి) లాంబ్డాస్ ని వాడుతారు.

2 Capture List (క్యాప్చర్ లిస్ట్) యొక్క పవర్!

సాధారణ ఫంక్షన్స్ కి బయట మెయిన్ లో ఉన్న వేరియబుల్స్ ఏమి జరుగుతున్నాయో తెలీదు. కానీ లాంబ్డాస్ కు ఉన్న సూపర్ పవర్ ఏంటంటే, అవి బయట ఉన్న వేరియబుల్స్ ని లోపలికి లాగేసుకుంటాయి. దీన్నే Capturing (క్యాప్చర్) అంటారు. ఇది [] స్క్వేర్ బ్రాకెట్స్ ద్వారా జరుగుతుంది.

  • [=] : బయట ఉన్న వేరియబుల్స్ అన్నిటినీ జిరాక్స్ (Copy / Value) తీసుకుని లోపలికి వస్తుంది. లోపల మీరు ఆ వాల్యూ ని మార్చలేరు (Read-only).
  • [&] : బయట ఉన్న వేరియబుల్స్ అన్నిటినీ ఒరిజినల్ అడ్రస్ (Reference) ద్వారా లోపలికి తెస్తుంది. లోపల మీరు మార్చితే, బయట కూడా వాల్యూ మారిపోతుంది!
  • [x, &y] : కేవలం x ని కాపీ లాగా, y ని రిఫరెన్స్ లాగా పర్టికులర్ గా తీసుకోవడం.
3 ఒకే ఒక సింపుల్ కోడ్ (Lambda Demo)

కింద కోడ్ లో auto కీవర్డ్ వాడి ఒక లాంబ్డా ని ఎలా సేవ్ చేసుకుంటున్నామో, మరియు క్యాప్చర్ లిస్ట్ ఎలా వాడుతున్నామో చూడండి.

C++11 — Lambda Expressions ▶ Run Code 
#include <iostream>
#include <vector>
#include <algorithm> // For for_each

int main() {
    int outsideNumber = 50;
    int multiplier = 2;
    
    // 1. సింపుల్ లాంబ్డా (దీనికి పేరు లేదు, కాబట్టి auto లో స్టోర్ చేసాం)
    auto sayHello = []() {
        std::cout << "Hello from Lambda!" << std::endl;
    };
    sayHello(); // ఫంక్షన్ లాగా కాల్ చేయడం
    
    // 2. Capture by Reference [&] వాడి లాంబ్డా రాయడం
    // బయట ఉన్న outsideNumber ని లోపల మార్చేస్తున్నాం!
    auto changeNumber = [&]() {
        outsideNumber += 100; // Original value changes
    };
    changeNumber();
    std::cout << "After Lambda, Number is: " << outsideNumber << std::endl;
    
    // 3. అల్గారిథమ్స్ లో ఆన్ ది స్పాట్ వాడకం
    std::vector<int> marks = {10, 20, 30};
    std::cout << "Marks multiplied by " << multiplier << ":" << std::endl;
    
    // [multiplier] వాడి బయట ఉన్న 2 ని లోపలికి (కాపీ) తెచ్చుకున్నాం
    std::for_each(marks.begin(), marks.end(), [multiplier](int m) {
        std::cout << m * multiplier << " ";
    });
    std::cout << std::endl;
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • auto sayHello = []() { ... }: ఇక్కడ లాంబ్డా కి అసలు పేరు లేదు. కానీ దాన్ని ఎప్పుడైనా మళ్ళీ వాడుకోవడానికి మనం ఒక auto వేరియబుల్ కి అసైన్ చేశాం.
  • [&](): ఈ స్క్వేర్ బ్రాకెట్ లో & ఉండటం వల్ల, ఆ ఫంక్షన్ బయట ఉన్న outsideNumber ని డైరెక్ట్ గా రిఫరెన్స్ చేసుకుంది. ఒకవేళ [=] అని రాసి ఉంటే లోపల += 100 చేసినప్పుడు కంపైలర్ ఎర్రర్ ఇచ్చేది (Read-only అని).
  • std::for_each: ఇది ఒక అద్భుతమైన ఫంక్షన్. వెక్టార్ లో ఉన్న ప్రతి ఐటమ్ ని తీసుకుని, మనం పక్కన రాసిన లాంబ్డా లోపలికి (పరామీటర్ గా) పంపుతుంది. ఇలా సింగిల్ లైన్ లో లూప్స్ ని ముగించేయొచ్చు.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: C++ లో క్లోజర్ (Closure) అంటే ఏమిటి?

మీరు ఒక లాంబ్డా ఎక్స్‌ప్రెషన్ ని రాసినప్పుడు, ఆ లాంబ్డా బయట ఉన్న వేరియబుల్స్ ని క్యాప్చర్ (Capture) చేసుకుని, తనలోపల దాచుకుంటుంది కదా. అలా డేటాని, ఫంక్షన్ లాజిక్ ని కలిపి ప్యాక్ చేసిన ఒక రన్-టైమ్ ఆబ్జెక్ట్ నే Closure అంటారు. లాంబ్డా అనేది కోడ్ (Syntax), క్లోజర్ అనేది మెమరీలో క్రియేట్ అయిన వస్తువు.

Q2: std::function అంటే ఏంటి? అది లాంబ్డా తో ఎందుకు వాడుతారు?

మనం లాంబ్డా ని auto లో స్టోర్ చేసాం. కానీ ఒక లాంబ్డా ని ఇంకో ఫంక్షన్ కి ఆర్గ్యుమెంట్ గా పంపాలంటే (ఉదాహరణకు త్రెడ్ స్టార్ట్ చేయడానికి), అప్పుడు దాని డేటా టైప్ ఎంటో కచ్చితంగా చెప్పాలి. అప్పుడే std::function<void(int)> అనే దాన్ని వాడతారు. ఇది ఎలాంటి ఫంక్షన్ లేదా లాంబ్డా ని అయినా తనలో స్టోర్ చేసుకోగల ఒక స్పెషల్ రాపర్ (Wrapper) క్లాస్.

Q3: క్యాప్చర్ లిస్ట్ లో ఉన్న mutable కీవర్డ్ ఎందుకు?

మీరు [=] (కాపీ) వాడినప్పుడు లోపల వాల్యూస్ మార్చలేరు అని చెప్పుకున్నాం. కానీ మీకు ఒరిజినల్ వేరియబుల్ ని మార్చకుండా, కేవలం కాపీ చేసుకున్న వాల్యూ ని మాత్రమే లోపల మార్చుకోవాలి అనిపిస్తే (ఉదాహరణకు ఒక కౌంటర్ లాగా), అప్పుడు లాంబ్డా పక్కన mutable కీవర్డ్ రాస్తారు. (ఉదా: [=]() mutable { ... }). అప్పుడు రీడ్-ఓన్లీ రెస్ట్రిక్షన్ పోతుంది.
