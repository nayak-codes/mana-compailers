వేరియబుల్స్, డేటా టైప్స్, కాన్‌స్టాంట్స్ & auto (Variables & Types)

⚡ Modern C++20 / C++17 🟢 Chapter 2 of 20 📂 Phase 1: C++ Basics & Fundamentals 📅 2026 Edition
📌 Covered in this chapter: What is a Variable? · RAM Memory Architecture · Primitive Data Types (Sizes & Ranges) · Signed vs Unsigned Overflow Trap · Floating Point Precision · auto Type Deduction · const vs constexpr · Variable Shadowing
ప్రోగ్రామింగ్ అంటేనే డేటాను ప్రాసెస్ చేయడం. కంప్యూటర్ మెమరీ (RAM) లో డేటాను ఎలా భద్రపరచాలి, ఎన్ని బైట్ల స్థలం అవసరం, మరియు C++ లో టైప్ సేఫ్టీ ద్వారా బగ్స్ రాకుండా ఎలా అరికట్టవచ్చో ఈ అధ్యాయంలో ప్రాక్టికల్‌గా నేర్చుకుందాం.
1వేరియబుల్ అంటే ఏమిటి? (RAM మెమరీలో ఒక పేరున్న బాక్స్)

ఒక Variable (వేరియబుల్) అంటే కంప్యూటర్ RAM మెమరీలోని ఒక నిర్దిష్ట అడ్రస్‌కు మనం పెట్టుకునే స్నేహపూర్వక పేరు (Named Memory Location).

2C++ ఫండమెంటల్ డేటా టైప్స్ (Data Types Matrix)

C++ లో ప్రతి వేరియబుల్‌కు తప్పనిసరిగా ఒక డేటా టైప్ ఉండాలి (Statically Typed). కంపైలర్ ఆ టైప్‌ను బట్టి RAM లో ఎన్ని బైట్లు కేటాయించాలో నిర్ణయిస్తుంది:

డేటా టైప్ (Type) మెమరీ పరిమాణం (Size) విలువల పరిధి (Range) సాధారణ ఉపయోగం
bool 1 Byte true (1) లేదా false (0) నిజం / అబద్ధం ఫ్లాగ్స్
char 1 Byte -128 to 127 (లేదా 0 to 255) సింగిల్ అక్షరం ('A', 'z')
int 4 Bytes -2,147,483,648 to 2,147,483,647 పూర్ణాంకాలు (Numbers)
long long 8 Bytes $-9 imes 10^{18}$ to $9 imes 10^{18}$ భారీ నంబర్లు, కరెన్సీ పైసలు
float 4 Bytes $approx 7$ దశాంశ ఖచ్చితత్వం గ్రాఫిక్స్ కోఆర్డినేట్స్
double 8 Bytes $approx 15-17$ దశాంశ ఖచ్చితత్వం సైంటిఫిక్ గణనలు, డాలర్లు
3auto కీవర్డ్: మోడరన్ టైప్ డిడక్షన్

Modern C++11 నుండి ప్రవేశపెట్టబడిన అత్యంత శక్తివంతమైన ఫీచర్ `auto`. వేరియబుల్‌కు మనం ఇచ్చే విలువ ఆధారంగా కంపైలరే స్వయంగా సరైన టైప్‌ను పసిగడుతుంది (Type Deduction):

💻 Example 1: Type Deduction with auto
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    auto age = 21;          // Compiler deduces: int
    auto price = 99.99;     // Compiler deduces: double
    auto grade = 'A';       // Compiler deduces: char
    auto isPassed = true;   // Compiler deduces: bool

    std::cout << "Age size in RAM: " << sizeof(age) << " bytes\n"
              << "Price size in RAM: " << sizeof(price) << " bytes\n";
    return 0;
}

⚡ Performance Fact about 'auto'

చాలామంది auto అంటే Python లాగా రన్‌టైమ్‌లో స్లో అవుతుంది అనుకుంటారు. కానీ C++ లో auto పూర్తిగా కంపైల్ సమయంలోనే నిర్ణయించబడుతుంది. రన్‌టైమ్‌లో ZERO పెనాల్టీ! మీ ప్రోగ్రామ్ మెరుపు వేగంతో నడుస్తుంది.

4const vs constexpr: స్థిర విలువల భద్రత

ప్రోగ్రామ్‌లో కొన్ని విలువలు ఎప్పటికీ మారకూడదు (ఉదా: $pi = 3.14159$, కాంతి వేగం). వాటిని భద్రపరచడానికి రెండు మార్గాలు ఉన్నాయి:

  • const: రన్‌టైమ్‌లో వేరియబుల్‌ను రీడ్-ఓన్లీగా మారుస్తుంది. ఒకసారి విలువ అసైన్ చేసిన తర్వాత మార్చడానికి ప్రయత్నిస్తే కంపైలర్ ఎర్రర్ ఇస్తుంది.
  • constexpr (C++11): ఇది కంపైల్ సమయంలోనే స్థిర విలువను లెక్కించి, ప్రోగ్రామ్ బైనరీ మెషిన్ కోడ్‌లోనే పొందుపరుస్తుంది. దీనివల్ల రన్‌టైమ్ CPU సైకిల్స్ ఆదా అవుతాయి!
5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ Trap 1: Uninitialized Variables (గార్బేజ్ వ్యాల్యూ ట్రాష్)

C++ లో int count; అని రాసి వదిలేస్తే దానికి డీఫాల్ట్‌గా 0 రాదు! ఆ సమయంలో RAM లో ఉన్న పాత చెత్త విలువ (Garbage Value: ఉదాహరణకు -858993460) అందులోకి వస్తుంది. ఎల్లప్పుడూ int count = 0; లేదా int count{0}; అని బ్రాకెట్ ఇనిషియలైజేషన్ చేయాలి!

❌ Trap 2: Unsigned Integer Wrap-around Overflow

unsigned int x = 0; x--; అని రాస్తే -1 రాదు! అన్‌సైన్డ్ ఇంటిజర్‌కు నెగెటివ్ ఉండదు కాబట్టి అది డైరెక్ట్‌గా గరిష్ట విలువ 4294967295 కు వెళ్ళిపోయి లూప్స్‌లో అనంతమైన ఇన్ఫినిట్ లూప్‌ను సృష్టిస్తుంది.

6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: float మరియు double మధ్య ఏది ఎంచుకోవాలి?

మోడరన్ CPU లలో double వాడటమే ప్రామాణికం. ఎందుకంటే ఆధునిక 64-బిట్ ప్రాసెసర్లు 8-బైట్ డబుల్ లెక్కలను అంతే వేగంగా చేస్తాయి మరియు 15 దశాంశాల ఖచ్చితత్వాన్ని ఇస్తాయి.

Q: sizeof ఆపరేటర్ రన్‌టైమ్‌లో పనిచేస్తుందా?

లేదు! sizeof అనేది ఒక కంపైల్-టైమ్ ఆపరేటర్. కంపైలర్ కోడ్‌ను ప్రాసెస్ చేసేటప్పుడే ఆ టైప్ ఎన్ని బైట్లు తీసుకుంటుందో లెక్కించి స్థిర విలువను బైనరీలో రాసిపెడుతుంది.
