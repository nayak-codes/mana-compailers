వేరియబుల్స్, డేటా టైప్స్ & auto కీవర్డ్ (Variables, Data Types & auto)

⚡ Modern C++20 / C++17 🟢 Chapter 2 of 20 📂 Phase 1: C++ Basics & Fundamentals 📅 2026 Edition
📌 Covered in this chapter: What is a Variable? · RAM Memory Layout · Primitive Types (int, float, double, char, bool) · sizeof Operator · Type Modifiers (signed/unsigned, short/long) · Integer Overflow Under the Hood · const vs constexpr · Modern C++ auto Type Deduction · Variable Scope & Shadowing · Safe Type Casting (static_cast)
కంప్యూటర్ ప్రోగ్రామింగ్ అంటేనే డేటాను స్టోర్ చేయడం మరియు దానిపై గణనలు చేయడం. ఈ అధ్యాయంలో C++ కంప్యూటర్ ర్యామ్ (RAM) లో మెమరీని ఎలా కేటాయిస్తుంది, ప్రాథమిక డేటా రకాలు, పరిమితులు దాటితే జరిగే Overflow విపత్తులు, మరియు ఆధునిక C++ లోని శక్తివంతమైన auto & constexpr ఫీచర్లను లోతుగా నేర్చుకుందాం.
1Variable అంటే ఏమిటి? (Memory Lockers in RAM)

ఒక Variable అంటే కంప్యూటర్ RAM (Random Access Memory) లో డేటాను దాచుకోవడానికి మనం రిజర్వ్ చేసుకునే ఒక నిర్దిష్ట మెమరీ బ్లాక్‌కు ఇచ్చే పేరు (Identifier).

📦 Real-World Analogy: హోటల్ లాకర్ లేదా స్టోరేజ్ బాక్స్

మీరు ఒక సూపర్ మార్కెట్‌కి వెళ్ళినప్పుడు మీ బ్యాగ్‌ని భద్రపరచడానికి ఒక లాకర్ కేటాయించి, దానికి ఒక నంబర్ లేదా స్టిక్కర్ వేస్తారు కదా? అలాగే కంప్యూటర్ మెమరీలో లక్షలాది చిరునామాలు (Hexadecimal Memory Addresses: 0x7ffd5e...) ఉంటాయి.

మనం ఆ క్లిష్టమైన హెక్సాడెసిమల్ అడ్రస్‌లను గుర్తుపెట్టుకోలేం కాబట్టి, ఆ లొకేషన్‌కు age, salary, score అని సులభమైన పేర్లు పెట్టుకుంటాం. అదే Variable!

Variable Declaration vs Initialization (C++ లో తేడా ఏమిటి?):

  • Declaration (డిక్లరేషన్): int age; — కంపైలర్‌కు "నాకు ఒక పూర్ణాంకం దాచుకోవడానికి మెమరీ సిద్ధం చెయ్యి" అని చెప్పడం. కానీ అందులో ఏ విలువ ఉండదు (Garbage Value ఉంటుంది).
  • Initialization (ఇనిషియలైజేషన్): డిక్లేర్ చేసేటప్పుడే విలువను కేటాయించడం:
    1. Copy Initialization: int score = 95;
    2. Direct Initialization: int score(95);
    3. Brace / Uniform Initialization (Modern C++11 Recommended): int score{95}; — ఇది డెసిమల్స్ కోల్పోయే ప్రమాదాన్ని (Narrowing Conversion) కంపైల్ టైమ్‌లోనే ఆపుతుంది!
2C++ Primitive Data Types & `sizeof` ఆపరేటర్

C++ అనేది Statically Typed Language. అంటే ప్రతి వేరియబుల్‌కు ఏ రకమైన డేటా స్టోర్ చేయాలో (పూర్ణాంకమా, దశాంశమా, అక్షరమా) ముందే స్పష్టంగా చెప్పాలి.

┌───────────────┬────────────┬─────────────┬──────────────────────────────────────────┐ │ Data Type │ Size (RAM) │ Bit Width │ Typical Value Range │ ├───────────────┼────────────┼─────────────┼──────────────────────────────────────────┤ │ bool │ 1 Byte │ 8 Bits │ true (1) లేదా false (0) │ │ char │ 1 Byte │ 8 Bits │ 'A', 'z', '$' (ASCII -128 to 127) │ │ int │ 4 Bytes │ 32 Bits │ -2,147,483,648 to 2,147,483,647 (~2 Billion) │ │ float │ 4 Bytes │ 32 Bits │ ~7 decimal digits precision (3.14159f) │ │ double │ 8 Bytes │ 64 Bits │ ~15-17 decimal digits precision │ │ long long │ 8 Bytes │ 64 Bits │ -9*10^18 to 9*10^18 (Astronomical Range) │ └───────────────┴────────────┴─────────────┴──────────────────────────────────────────┘

మీ కంప్యూటర్ ఆర్కిటెక్చర్‌లో ఒక డేటా టైప్ ఎన్ని బైట్ల స్థలాన్ని ఆక్రమిస్తుందో తెలుసుకోవడానికి C++ లో `sizeof` ఆపరేటర్ ఉంది. కింది ఉదాహరణను పరిశీలించండి:

💻 Example 1: Discovering Primitive Types & Memory Sizes with sizeof
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    int studentId = 101;
    double gradeAverage = 9.45;
    char gradeSection = 'A';
    bool isEnrolled = true;

    std::cout << "--- Data Types & Actual Memory Sizes in RAM ---\n";
    std::cout << "studentId (int)       : " << studentId 
              << " | Size: " << sizeof(studentId) << " bytes\n";
    std::cout << "gradeAverage (double) : " << gradeAverage 
              << " | Size: " << sizeof(gradeAverage) << " bytes\n";
    std::cout << "gradeSection (char)   : " << gradeSection 
              << " | Size: " << sizeof(gradeSection) << " byte\n";
    std::cout << "isEnrolled (bool)     : " << isEnrolled 
              << " | Size: " << sizeof(isEnrolled) << " byte\n";

    return 0;
}
🔍 అవుట్‌పుట్ విశ్లేషణ:

bool విలువ నిజానికి 1 బిట్ (0 లేదా 1) మాత్రమే అయినప్పటికీ, ఆధునిక CPU లు 1 బైట్ కంటే తక్కువ అడ్రస్‌ను నేరుగా యాక్సెస్ చేయలేవు కాబట్టి bool కూడా 1 పూర్తి బైట్‌ను తీసుకుంటుంది.

3Type Modifiers (signed vs unsigned & Overflow విపత్తు)

ప్రాథమిక డేటా టైప్‌ల పరిధిని పెంచడానికి లేదా మార్చడానికి C++ లో 4 ముఖ్యమైన Type Modifiers ఉన్నాయి:

  • signed: పాజిటివ్ మరియు నెగెటివ్ రెంటినీ అనుమతిస్తుంది (ఇది డీఫాల్ట్).
  • unsigned: కేవలం సున్నా మరియు పాజిటివ్ విలువలను మాత్రమే అనుమతిస్తుంది. దీనివల్ల పాజిటివ్ రేంజ్ రెట్టింపు అవుతుంది (0 to ~4.29 Billion for 32-bit int).
  • short: మెమరీని ఆదా చేయడానికి 2 బైట్లకు పరిమితం చేస్తుంది.
  • long / long long: భారీ సంఖ్యలను స్టోర్ చేయడానికి 8 బైట్ల వరకు పెంచుతుంది.

⚠️ The Dreaded "Integer Overflow" (ఓడోమీటర్ ఎఫెక్ట్)

మీ బైక్ ఓడోమీటర్ 99999 కి చేరిన తర్వాత మరో కిలోమీటర్ వెళ్తే ఏమవుతుంది? అది 00000 కి రోల్ అవుతుంది కదా!

కంప్యూటర్ మెమరీలో కూడా అంతే. ఒక 32-bit signed int గరిష్ట విలువ 2147483647. దానికి + 1 కలిపితే, అత్యంత చిన్న నెగెటివ్ నంబర్ -2147483648 గా మారిపోతుంది! దీనిని Integer Overflow అంటారు.

💻 Example 2: Demonstrating Integer Overflow in Action
C++17 Overflow Demo ▶ Run in Compiler 
#include <iostream>

int main() {
    // 32-bit signed int గరిష్ట విలువ
    int maxLimit = 2147483647;
    std::cout << "Original Max int: " << maxLimit << "\n";

    // 1 కలిపితే overflow జరిగి నెగెటివ్ అవుతుంది!
    maxLimit = maxLimit + 1;
    std::cout << "After + 1 (Overflow!): " << maxLimit << "\n";

    // పరిష్కారం: కాంపిటీటివ్ కోడింగ్‌లో 'long long' వాడాలి!
    long long safeBigNumber = 2147483647LL;
    safeBigNumber = safeBigNumber + 1;
    std::cout << "With long long (Safe!): " << safeBigNumber << "\n";

    return 0;
}
4`const` vs `constexpr` (Constants in C++)

కొన్ని విలువలని ప్రోగ్రామ్ మధ్యలో పొరపాటున కూడా ఎవరూ మార్చకూడదు (ఉదాహరణకు: పై విలువ $\pi = 3.14159$, లేదా వారానికి 7 రోజులు). అటువంటి వాటిని కాపాడటానికి C++ లో `const` మరియు `constexpr` ఉన్నాయి.

లక్షణం const (Run-time or Compile-time) constexpr (Pure Compile-time)
ఎప్పుడు సెట్ అవుతుంది? రన్ టైంలో యూజర్ ఇన్‌పుట్ ద్వారా కూడా సెట్ అవ్వచ్చు. కచ్చితంగా కంపైలర్ కోడ్ బిల్డ్ చేసేటప్పుడే కాలిక్యులేట్ అవ్వాలి.
Performance వేగవంతం (Read-only memory) అత్యంత వేగవంతం (Zero runtime overhead, CPU కి ముందే తెలుస్తుంది)
💻 Example 3: const and constexpr in Practice
C++17 ▶ Run in Compiler 
#include <iostream>

int main() {
    // 1. const: విలువను మార్చలేరు
    const double PI = 3.1415926535;
    // PI = 3.15; // ❌ ERROR: assignment of read-only variable 'PI'

    // 2. constexpr: కంపైల్ టైంలోనే 24 * 60 * 60 లెక్కించబడుతుంది
    constexpr int SECONDS_IN_A_DAY = 24 * 60 * 60; // 86400

    std::cout << "Value of PI: " << PI << "\n";
    std::cout << "Seconds in a day (Compile-time): " << SECONDS_IN_A_DAY << "\n";

    return 0;
}
5Modern C++ `auto` Keyword (Automatic Type Deduction)

C++11 కి ముందు ప్రతి వేరియబుల్‌కు తప్పనిసరిగా డేటా టైప్ చేత్తో రాయాల్సి వచ్చేది. కానీ C++11 లో ప్రవేశపెట్టిన `auto` కీవర్డ్ ద్వారా, కుడివైపు ఉన్న విలువను బట్టి కంపైలరే స్వయంచాలకంగా సరైన డేటా టైప్‌ను నిర్ణయిస్తుంది.

⚡ Does `auto` slow down your program? (NO!)

Python లేదా JavaScript లాంటి భాషల్లో రన్ టైంలో డేటా టైప్ చెక్ అవుతుంది కాబట్టి అవి స్లో అవుతాయి. కానీ C++ లో auto అనేది Compile-Time Type Deduction. అంటే కంపైలర్ కోడ్ కంపైల్ చేసేటప్పుడే auto స్థానంలో అసలైన టైప్ (ఉదా: int, double) ను భర్తీ చేస్తుంది. కాబట్టి Zero Performance Penalty!

💻 Example 4: Modern Type Deduction with auto
C++17 auto ▶ Run in Compiler 
#include <iostream>

int main() {
    auto count = 42;             // int గా గుర్తించబడుతుంది
    auto price = 199.99;         // double గా గుర్తించబడుతుంది
    auto grade = 'S';            // char గా గుర్తించబడుతుంది
    auto isVerified = true;      // bool గా గుర్తించబడుతుంది

    std::cout << "Count (int)      : " << count << " | Size: " << sizeof(count) << " bytes\n";
    std::cout << "Price (double)   : " << price << " | Size: " << sizeof(price) << " bytes\n";
    std::cout << "Grade (char)     : " << grade << " | Size: " << sizeof(grade) << " byte\n";
    std::cout << "Verified (bool)  : " << isVerified << " | Size: " << sizeof(isVerified) << " byte\n";

    return 0;
}
6Variable Scope (Local vs Global & Shadowing)

ఒక వేరియబుల్‌ను ప్రోగ్రామ్‌లో ఎక్కడ యాక్సెస్ చేయవచ్చు అనే పరిధిని Scope అంటారు:

  • Local Variable: ఒక ఫంక్షన్ లేదా బ్లాక్ { ... } లోపల డిక్లేర్ చేయబడిన వేరియబుల్. ఆ బ్లాక్ ముగియగానే మెమరీ నుండి తుడిచిపెట్టుకుపోతుంది.
  • Global Variable: అన్ని ఫంక్షన్ల కంటే పైన బయట డిక్లేర్ చేయబడే వేరియబుల్. ప్రోగ్రామ్ మొదలైనప్పటి నుండి ముగిసే వరకు బ్రతికే ఉంటుంది.
  • Variable Shadowing & Scope Resolution (`::`): ఒకే పేరుతో లోకల్ మరియు గ్లోబల్ వేరియబుల్స్ ఉన్నప్పుడు, లోకల్ దే ప్రాధాన్యత పొందుతుంది. గ్లోబల్ దాన్ని యాక్సెస్ చేయడానికి ::variableName వాడాలి.
💻 Example 5: Local vs Global Scope & Scope Resolution Operator
C++17 Scope ▶ Run in Compiler 
#include <iostream>

// గ్లోబల్ వేరియబుల్
int serverPort = 8080;

int main() {
    // లోకల్ వేరియబుల్ (గ్లోబల్‌ను Shadow చేస్తుంది)
    int serverPort = 3000;

    std::cout << "Local Server Port               : " << serverPort << "\n";
    std::cout << "Global Server Port (using ::)   : " << ::serverPort << "\n";

    return 0;
}
7Type Casting (ఆటోమేటిక్ vs `static_cast`)

ఒక డేటా టైప్‌ను మరొక డేటా టైప్‌లోకి మార్చడాన్ని Type Casting అంటారు.

1. Implicit Type Conversion (ఆటోమేటిక్): కంపైలరే చిన్న టైప్‌ను పెద్ద టైప్‌లోకి ప్రమోట్ చేస్తుంది (ఉదా: int + double చేసినప్పుడు రిజల్ట్ ఆటోమేటిక్‌గా double అవుతుంది).

2. Explicit Type Casting (Modern `static_cast`): బిగినర్లు C-style లో (double)sum / count; అని రాస్తుంటారు. కానీ మోడరన్ C++ లో కంపైలర్ భద్రత కోసం `static_cast<double>` వాడాలి:

💻 Example 6: Avoiding Integer Division Bug with static_cast
C++17 static_cast ▶ Run in Compiler 
#include <iostream>

int main() {
    int totalScore = 195;
    int totalSubjects = 2;

    // ❌ BUG: రెండు ints భాగిస్తే డెసిమల్స్ పోతాయి! (195 / 2 = 97)
    double wrongAverage = totalScore / totalSubjects;

    // ✅ SOLUTION: static_cast తో సురక్షితంగా double లోకి మార్చడం
    double correctAverage = static_cast<double>(totalScore) / totalSubjects;

    std::cout << "Wrong Integer Division  : " << wrongAverage << "\n";
    std::cout << "Correct with static_cast: " << correctAverage << "\n";

    return 0;
}
⚠️ Common Developer Pitfalls in Chapter 2
  • గార్బేజ్ విలువలు (Uninitialized Variables): int score; std::cout << score; అని రాస్తే 0 రాదు! మెమరీలో ఉన్న పాత చెత్త విలువ (ఉదా: 4201948) ప్రింట్ అవుతుంది. ఎల్లప్పుడూ int score = 0; లేదా int score{}; అని ఇనిషియలైజ్ చేయండి.
  • ఫ్లోటింగ్ పాయింట్ ప్రెసిషన్ ట్రాప్: కంప్యూటర్లు బైనరీలో పనిచేస్తాయి కాబట్టి 0.1 + 0.2 == 0.3 ఎప్పటికీ సమానం కాదు (చివర్లో 0.30000000000000004 వస్తుంది). ఫైనాన్షియల్ లెక్కల్లో డెసిమల్స్ పోల్చేటప్పుడు జాగ్రత్త పడాలి.
💻 Hands-on Interactive Practice Challenge

టాస్క్: ఒక రియల్-వరల్డ్ ఈ-కామర్స్ ఆర్డర్ ఇన్వాయిస్ క్యాలిక్యులేటర్ తయారు చేయండి. వస్తువు ధర (double), కొన్న పరిమాణం (int), GST టాక్స్ రేటు, డిస్కౌంట్ వర్తింపజేసి, ఫైనల్ బిల్లు ₹1000 దాటితే ఉచిత డెలివరీ లభిస్తుందో లేదో (bool) చెక్ చేసి కన్సోల్ పై ప్రింట్ చేయండి:

C++17 Invoice Challenge ▶ Run in Compiler 
#include <iostream>

int main() {
    const double GST_RATE = 0.18; // 18% GST
    
    // ఆర్డర్ వివరాలు
    auto itemPrice = 450.00;
    auto quantity = 3;
    auto discountAmount = 100.00;

    // లెక్కలు
    double subtotal = itemPrice * quantity;
    double tax = subtotal * GST_RATE;
    double finalPayable = (subtotal - discountAmount) + tax;
    bool isFreeDeliveryEligible = (finalPayable >= 1000.00);

    // ఇన్వాయిస్ ప్రింట్ చేద్దాం
    std::cout << "========================================\n";
    std::cout << "        OUR COMPILER E-COMMERCE BILL    \n";
    std::cout << "========================================\n";
    std::cout << "Subtotal (3 Items)   : Rs. " << subtotal << "\n";
    std::cout << "Discount Applied     : Rs. " << discountAmount << "\n";
    std::cout << "GST Tax (18%)        : Rs. " << tax << "\n";
    std::cout << "Final Total Payable  : Rs. " << finalPayable << "\n";
    std::cout << "Free Delivery Status : " << (isFreeDeliveryEligible ? "ELIGIBLE 🚚" : "NOT ELIGIBLE ❌") << "\n";
    std::cout << "========================================\n";

    return 0;
}

❓ Frequently Asked Questions (FAQ)

Q float కి double కి తేడా ఏమిటి? ఏది వాడాలి?

float 4 బైట్ల మెమరీ తీసుకుని 6-7 డెసిమల్ అంకెల ఖచ్చితత్వాన్ని ఇస్తుంది. double 8 బైట్లు తీసుకుని 15-17 డెసిమల్ అంకెల ఖచ్చితత్వాన్ని ఇస్తుంది. ఆధునిక కంప్యూటర్ల 64-bit ప్రాసెసర్లలో double చాలా సమర్థవంతంగా పనిచేస్తుంది కాబట్టి మోడరన్ C++ లో డెసిమల్స్ కోసం double వాడటమే ఉత్తమం.

Q Modern C++ లో 'auto' వాడటం వల్ల ప్రోగ్రామ్ స్పీడ్ తగ్గుతుందా?

అస్సలు తగ్గదు! auto రన్ టైంలో కాదు, కంపైల్ టైంలోనే డేటా టైప్‌ను కచ్చితంగా గుర్తిస్తుంది (Zero Runtime Cost). కాబట్టి int వాడినా auto వాడినా ప్రోగ్రామ్ స్పీడ్ లో ఎలాంటి వ్యత్యాసం ఉండదు.

Q C++ లో uninitialized వేరియబుల్స్ ఎందుకు ప్రమాదకరం?

Python లాంటి భాషల్లో వేరియబుల్స్‌కి ఆటోమేటిక్‌గా None లేదా 0 ఉంటుంది. కానీ C++ లో వేరియబుల్‌కు విలువ ఇవ్వకపోతే (Uninitialized), ఆ మెమరీ లొకేషన్‌లో ముందు నుంచి ఉన్న పాత వ్యర్థ విలువ (Garbage Value) అందులోకి వస్తుంది, దీనివల్ల ఊహించని తప్పుడు లెక్కలు మరియు క్రాష్‌లు వస్తాయి.
