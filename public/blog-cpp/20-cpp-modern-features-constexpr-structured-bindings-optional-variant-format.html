Modern C++ (17/20): optional, variant & Bindings (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 20 📂 Phase 20: Modern C++ Features 📅 2026 Master Edition
📌 Covered in this in-depth guide: Structured Bindings · std::optional · std::variant · constexpr if · std::format

C++11 అనేది ఒక పెద్ద విప్లవం ఐతే, C++17 మరియు C++20 ఆ విప్లవాన్ని ఇంకో రేంజ్ కి తీసుకెళ్లాయి. చాలామంది C++ కష్టం అంటారు కానీ, ఈ మోడరన్ ఫీచర్స్ వాడితే పైథాన్ లాంటి లాంగ్వేజెస్ కంటే కూడా చాలా క్లీన్ గా, సింపుల్ గా కోడ్ రాయొచ్చు. మల్టిపుల్ వాల్యూస్ ని ఒకేసారి రిటర్న్ చేయడానికి వచ్చిన Structured Bindings, NULL పాయింటర్స్ క్రాష్ ల నుండి కాపాడే std::optional, మరియు ఒకే వేరియబుల్ లో రకరకాల డేటాని దాచుకునే std::variant... ఈ మోడరన్ మ్యాజిక్స్ ఏంటో ఈ రోజు డీప్ గా నేర్చుకుందాం.

1 Structured Bindings (స్ట్రక్చర్డ్ బైండింగ్స్) - C++17

ఒక ఫంక్షన్ సాధారణంగా ఒకే ఒక వాల్యూ రిటర్న్ చేస్తుంది. కానీ మీకు 3 వాల్యూస్ రిటర్న్ కావాలి (ఉదాహరణకు 3D గేమ్ లో X, Y, Z కోఆర్డినేట్స్). పాత కాలంలో పాయింటర్స్ వాడి తెచ్చుకునే వాళ్ళం. కానీ C++17 లో auto [x, y, z] = getCoordinates(); అని పైథాన్ లాగా సింపుల్ గా మల్టిపుల్ వాల్యూస్ ని ఒకేసారి తెచ్చుకోవచ్చు. దీనివల్ల వందల లైన్ల కోడ్ పది లైన్లకి తగ్గిపోతుంది.

2 std::optional మరియు std::variant మ్యాజిక్

🎁 రియల్ లైఫ్ స్టోరీ: స్విగ్గీ ఆర్డర్ డెలివరీ (Optional & Variant)

std::optional (ఉండొచ్చు లేదా లేకపోవచ్చు): మీరు ఒక ఆర్డర్ పెట్టారు. డెలివరీ బాయ్ వచ్చాడు. ఆ ప్యాకెట్ లో మీరు అడిగిన బిర్యానీ ఉండొచ్చు, లేదా ఏదైనా క్యాన్సిల్ అయితే ప్యాకెట్ ఖాళీగా కూడా ఉండొచ్చు. పాత C++ లో ఖాళీకి బదులు -1 లేదా 0 ఇచ్చేవాళ్లు (అవి కన్ఫ్యూజింగ్). కానీ optional వాడితే, బాక్స్ లో నిజంగా డేటా ఉందా (has_value) లేదా అది nullopt (ఖాళీ) నా అని సేఫ్ గా చెక్ చేయొచ్చు.

std::variant (ఇదైనా, అదైనా): మీ ఆర్డర్ లో కేవలం ఒక్క ఐటమ్ మాత్రమే పంపాలి, కానీ అది పిజ్జా అయినా కావొచ్చు లేదా కోక్ బాటిల్ అయినా కావొచ్చు. రెండు రకాల వస్తువులకి ఒకటే బాక్స్ కావాలి! std::variant<Pizza, Coke> అని రాస్తే, ఆ బాక్స్ లో మీరు ఏదైనా ఒకదాన్ని సేఫ్ గా ప్యాక్ చేయొచ్చు (ఇది C లో ఉండే Union కి ఆధునిక, సురక్షితమైన వెర్షన్).

3 ఒకే ఒక సింపుల్ కోడ్ (Modern C++17/20)

కింద కోడ్ లో పైథాన్ లాంటి స్ట్రక్చర్డ్ బైండింగ్స్ ని మరియు సేఫ్ గా ఉండే std::optional ని ఎలా వాడామో చూడండి.

C++17 — Modern Features ▶ Run Code 
#include <iostream>
#include <string>
#include <tuple>
#include <optional>

// 1. మల్టిపుల్ వాల్యూస్ ని Tuple లో రిటర్న్ చేస్తున్నాం
std::tuple<std::string, int, double> getEmployeeDetails() {
    return {"Rajesh", 101, 75000.50};
}

// 2. రిజల్ట్ ఉంటే నంబర్ ఇస్తుంది, లేదంటే nullopt (ఖాళీ) ఇస్తుంది
std::optional<int> findAge(std::string name) {
    if (name == "Rajesh") return 28;
    return std::nullopt; // డేటా దొరకలేదు
}

int main() {
    // మ్యాజిక్: స్ట్రక్చర్డ్ బైండింగ్స్ (C++17) 
    // రిటర్న్ వచ్చిన 3 వాల్యూస్ ని డైరెక్ట్ గా 3 వేరియబుల్స్ లోకి విడగొట్టాం!
    auto [empName, empId, salary] = getEmployeeDetails();
    
    std::cout << "Employee: " << empName << " (ID: " << empId << ")" << std::endl;
    
    // Optional ని చెక్ చేయడం (Null pointer crashes ఇంక ఉండవు!)
    std::optional<int> ageResult = findAge("Ramesh");
    
    if (ageResult.has_value()) {
        std::cout << "Age found: " << ageResult.value() << std::endl;
    } else {
        std::cout << "Age NOT found! (Safe Null Handling)" << std::endl;
    }
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • std::tuple: ఇది ఒక గ్రూప్. ఒక స్ట్రింగ్, ఇంట్, డబుల్ ని కలిపి ఒకే ప్యాకెట్ లాగా రిటర్న్ చేస్తుంది.
  • auto [empName, empId, salary]: C++17 లో ఈ స్క్వేర్ బ్రాకెట్స్ వాడితే, ఆ ట్యూపుల్ (Tuple) లో ఉన్న 3 వాల్యూస్ డైరెక్ట్ గా విడిపోయి మనం ఇచ్చిన ఈ కొత్త పేర్లలోకి సేవ్ అయిపోతాయి (Unpacking). ఇది పైథాన్ లో చాలా పాపులర్ ఫీచర్, ఇప్పుడు C++ లో కూడా ఉంది!
  • std::optional<int>: మామూలు ఫంక్షన్స్ డేటా దొరకకపోతే -1 ఇస్తాయి. కానీ ఎవరైనా ఏజ్ -1 ఇస్తే కన్ఫ్యూజింగ్ కదా! అందుకే ఆప్షనల్ వాడితే, డేటా లేనప్పుడు అది nullopt (ఖాళీ) పంపుతుంది, మనం .has_value() తో సేఫ్ గా చెక్ చేసుకోవచ్చు.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: std::variant కి, C లో ఉండే union కి తేడా ఏంటి?

C లోని union చాలా అన్-సేఫ్ (Unsafe). అందులో ఇంటీజర్ పెట్టి, మీరు పొరపాటున స్ట్రింగ్ లాగా చదివితే భయంకరమైన గార్బేజ్ వాల్యూ లేదా క్రాష్ వస్తుంది. కానీ C++17 లోని std::variant అనేది "Type-Safe Union". అంటే అందులో ప్రస్తుతం ఏ డేటా టైప్ (int ఆ లేక string ఆ) ఉందో అది గుర్తుపెట్టుకుంటుంది. తప్పు టైప్ ని చదవాలని చూస్తే ప్రోగ్రామ్ బగ్ వస్తుందని ఎర్రర్ ఇస్తుంది (std::bad_variant_access). ఫుల్ సేఫ్టీ అన్నమాట!

Q2: constexpr if అంటే ఏంటి? మామూలు if కి తేడా ఏంటి?

మామూలు if-else అనేది ప్రోగ్రామ్ రన్ అవుతున్నప్పుడు (Runtime) కంప్యూటర్ డెసిషన్ తీసుకుంటుంది. కానీ constexpr if (C++17) వాడితే, కోడ్ కంపైల్ అవుతున్నప్పుడే ఏ లాజిక్ రన్ అవ్వాలో డిసైడ్ చేసి, మిగతా డెడ్ కోడ్ (Dead Code) ని ఫైనల్ .exe లో లేకుండా కట్ చేసేస్తుంది! దీనివల్ల టెంప్లేట్స్ రాసేటప్పుడు యాప్ సైజు చాలా తగ్గుతుంది మరియు పర్ఫార్మెన్స్ పెరుగుతుంది.

Q3: C++20 లో వచ్చిన std::format స్పెషాలిటీ ఏంటి?

చాలా ఏళ్ల నుండి C++ డెవలపర్స్ కి std::cout << "Age: " << a << " name: " << n; అని విడగొట్టి రాయడం విసుగ్గా ఉండేది. పైథాన్ లో లాగా సింపుల్ ఫార్మాటింగ్ లేదు. ఆ వెలితి తీర్చడానికే std::format("Age: {}, name: {}", a, n) ని తెచ్చారు. ఇది printf లాగా ఫాస్ట్ గా ఉంటుంది, మరియు వంద శాతం టైప్-సేఫ్ (Type-safe).
