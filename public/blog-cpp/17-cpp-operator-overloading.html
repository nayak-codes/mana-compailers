ఆపరేటర్ ఓవర్‌లోడింగ్ & Friend Functions (తెలుగులో)

యూజర్ డిఫైన్డ్ ఆబ్జెక్టులకు సహజమైన గణిత వ్యక్తీకరణలు! Binary మరియు Unary ఆపరేటర్ ఓవర్‌లోడింగ్, ఓవర్‌లోడ్ చేయలేని 5 ఆపరేటర్లు, std::cout Stream Insertion (<<) కి Friend Function ఎందుకు అవసరం, Friend Classes భద్రతా నియమాలు, మరియు Modern C++20 లో వచ్చిన గేమ్ చేంజర్ Spaceship Operator (<=>).

📌 Covered in this chapter: Operator Overloading Mechanics · 5 Non-Overloadable Operators · cout Stream Insertion · Friend Functions · Friend Classes · C++20 Spaceship <=>
1 ఆపరేటర్ ఓవర్‌లోడింగ్ అంటే ఏమిటి? Syntactic Sugar

C++ లో +, -, *, == వంటి ప్రామాణిక ఆపరేటర్లు ప్రాథమిక డేటా టైపులైన int, double లపై సహజంగా పనిచేస్తాయి. కానీ మన స్వంత క్లాస్ ఆబ్జెక్టులైన Complex Numbers (కాంప్లెక్స్ సంఖ్యలు), Vector3D (3D కోఆర్డినేట్లు), లేదా Matrix లపై కూడా c1 + c2 అని సహజంగా కూడాలనుకుంటే?

జావా (Java) వంటి భాషల్లో దీనికి అనుమతి లేదు; వారు c1.add(c2) అని ఫంక్షన్ రాయాలి. కానీ C++ లో మన స్వంత ఆబ్జెక్టులకు కూడా సహజమైన గణిత వ్యక్తీకరణలను జోడించడానికి కంపైలర్ ఇచ్చిన అద్భుతమైన ఫీచరే Operator Overloading!

🔄 కంపైలర్ అంతర్గతంగా ఎలా మారుస్తుంది?

డెవలపర్ రాసే సహజమైన కోడ్:

Complex c3 = c1 + c2;

కంపైలర్ కాల్ చేసే ఫంక్షన్:

Complex c3 = c1.operator+(c2);

ఎడమవైపున్న c1 ఆబ్జెక్ట్ this అవుతుంది, కుడివైపున్న c2 ఆబ్జెక్ట్ ఫంక్షన్ పారామీటర్ గా వెళ్తుంది!

💻 Example 1: Overloading the '+' Binary Operator
operator_plus.cpp
⚡ Try in Compiler 
#include <iostream>

class Complex {
public:
    double real, imag;
    Complex(double r = 0, double i = 0) : real(r), imag(i) {}

    // Overloading '+' operator (Member function)
    Complex operator+(const Complex& other) const {
        return Complex(this->real + other.real, this->imag + other.imag);
    }
};

int main() {
    Complex c1(3.0, 4.0), c2(1.5, 2.5);
    Complex c3 = c1 + c2; // Natural math syntax!
    std::cout << "c3 = " << c3.real << " + " << c3.imag << "i\n";
    return 0;
}
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • Complex operator+(const Complex& other) const: ఆపరేటర్ ఓవర్‌లోడింగ్ కు operator కీవర్డ్ మరియు చిహ్నం (+) వాడాలి.
  • const Complex& other: అదనపు కాపీ వేస్ట్ అవ్వకుండా const రిఫరెన్స్ ద్వారా రెండవ ఆబ్జెక్ట్ ను తీసుకుంటుంది.
  • Complex c3 = c1 + c2;: క్లీన్ మరియు సహజమైన గణిత సూత్రంలా కనిపిస్తుంది.
2 ఓవర్‌లోడ్ చేయలేని 5 ఆపరేటర్లు (The 5 Forbidden Operators)

C++ లో దాదాపు ప్రతి ఆపరేటర్‌ను ఓవర్‌లోడ్ చేయవచ్చు. కానీ కంపైలర్ భద్రత మరియు మెమరీ అలైన్‌మెంట్ కోసం ఈ క్రింది 5 ఆపరేటర్లను ఎట్టి పరిస్థితుల్లోనూ ఓవర్‌లోడ్ చేయలేము (ఇది ప్రతి టెక్ ఇంటర్వ్యూలో అడిగే ఫేవరెట్ ప్రశ్న!):

1. Dot (.)

డైరెక్ట్ మెంబర్ యాక్సెస్

2. Scope (::)

నేమ్‌స్పేస్ & క్లాస్ స్కోప్

3. Ternary (?:)

కండిషనల్ స్టేట్‌మెంట్

4. Size (sizeof)

బైట్ల లెక్కింపు

5. Pointer-to-member (.*)

మెంబర్ పాయింటర్ డిరిఫరెన్స్

ఎందుకు నిషేధించబడ్డాయి? ఒకవేళ డాట్ (.) లేదా స్కోప్ (::) ను ఓవర్‌లోడ్ చేయడానికి అనుమతిస్తే, ఏ మెంబర్ అసలైనదో ఏది యూజర్ కోడో కంపైలర్ కనిపెట్టలేక ప్రోగ్రామ్ సింటాక్స్ కుప్పకూలిపోతుంది!

3 Stream Insertion (<<) & Friend Functions రహస్యం

మనం ఒక ఆబ్జెక్ట్‌ను ప్రింట్ చేయడానికి ప్రత్యేకంగా c1.display() అని పిలవకుండా, బిల్ట్-ఇన్ వేరియబుల్స్ లాగే std::cout << c1 << std::endl; అని రాయాలనుకుంటే, మనం Stream Insertion Operator (<<) ను ఓవర్‌లోడ్ చేయాలి.

💡 ఎందుకు Stream Operators ను మెంబర్ ఫంక్షన్ గా రాయలేము?
std::cout << c1 ఎక్స్‌ప్రెషన్‌లో ఎడమ వైపు ఉన్న మొదటి ఆపరాండ్ std::cout (ఇది std::ostream రకం).
ఒకవేళ ఇది క్లాస్ మెంబర్ ఫంక్షన్ కావాలంటే, మనం std::ostream క్లాస్ లోపలికి వెళ్లి కోడ్ మార్చాలి! కానీ ostream అనేది C++ స్టాండర్డ్ లైబ్రరీకి చెందిన కోడ్; దానిని మనం మార్చలేము.

అందుకే దీనిని క్లాస్ బయట ఉండే గ్లోబల్ ఫంక్షన్‌గా రాయాలి. అయితే క్లాస్ లోని ప్రైవేట్ వేరియబుల్స్‌ను చదవడానికి ఆ ఫంక్షన్‌కు క్లాస్ లోపల friend పర్మిషన్ ఇవ్వాలి!
💻 Example 2: Stream Insertion (<<) Overload using friend
stream_insertion.cpp
⚡ Try in Compiler 
#include <iostream>

class Point {
private:
    int x, y;
public:
    Point(int xVal = 0, int yVal = 0) : x(xVal), y(yVal) {}

    // Friend Function for std::cout << pt
    friend std::ostream& operator<<(std::ostream& os, const Point& pt) {
        os << "(" << pt.x << ", " << pt.y << ")";
        return os; // Enables chaining: cout << p1 << p2;
    }
};

int main() {
    Point p1(10, 20);
    std::cout << "Point Coordinates: " << p1 << "\n";
    return 0;
}
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • friend std::ostream& operator<<(...): క్లాస్ లోపల friend అని రాసి డిక్లేర్ చేశాం కాబట్టి ఈ ఫంక్షన్ x మరియు y ప్రైవేట్ వేరియబుల్స్ ను చదవగలిగింది.
  • return os;: std::ostream& ను తిరిగి ఇవ్వడం వల్ల మనం cout << p1 << " and " << p2; లాగా చైనింగ్ (Chaining) చేసుకోవచ్చు.
4 Friend Classes & భద్రతా నియమాలు

ఒక క్లాస్ తన పూర్తి private మరియు protected మెంబర్లను మరొక నిర్దిష్ట క్లాస్‌కు మాత్రమే ఓపెన్ చేయాలనుకున్నప్పుడు Friend Class (friend class Auditor;) ను వాడతారు.

రియల్-వరల్డ్ ఉదాహరణ:
ఒక బ్యాంక్ కస్టమర్ అకౌంట్ లోని ప్రైవేట్ బ్యాలెన్స్ బయటి వ్యక్తులకు కనిపించదు. కానీ బ్యాంక్ నియమించిన అధికారిక ఆడిటర్ (Auditor) కు మాత్రం ఆ ప్రైవేట్ బ్యాలెన్స్ ను తనిఖీ చేసే ప్రత్యేక అధికార పాస్ (Friendship) ఉంటుంది!

  • Friendship is NOT Mutual: క్లాస్ A క్లాస్ B ని ఫ్రెండ్ గా ప్రకటిస్తే, B క్లాస్ A యొక్క ప్రైవేట్ డేటాను చూడగలదు; కానీ A ఆటోమేటిక్ గా B యొక్క ప్రైవేట్ డేటాను చూడలేదు!
  • Friendship is NOT Inherited: తండ్రికి ఉన్న ఫ్రెండ్ కొడుక్కి ఆటోమేటిక్ గా ఫ్రెండ్ కానట్లే, Base క్లాస్ ఫ్రెండ్స్ చైల్డ్ క్లాస్ కు వర్తించరు.
5 Modern C++20: Spaceship Operator (<=>) విప్లవం

C++20 రాకముందు రెండు ఆబ్జెక్టులను పూర్తిగా పోల్చడానికి మనం 6 వేర్వేరు ఆపరేటర్లను (<, <=, >, >=, ==, !=) విడివిడిగా రాసేవాళ్ళం. ఇది ఎంతో బోరింగ్ మరియు తప్పులు జరిగే అవకాశం ఉన్న పని!

Modern C++20 లో వచ్చిన Three-Way Comparison (Spaceship) Operator (<=>) తో కేవలం ఒకే ఒక్క లైన్ కోడ్ తో మొత్తం 6 రిలేషనల్ ఆపరేటర్లు ఆటోమేటిక్ గా తయారవుతాయి:

💻 Example 3: C++20 Spaceship Operator (<=>) in 1 Line
spaceship_operator.cpp
⚡ Try in Compiler 
#include <iostream>
#include <compare>

struct Player {
    int score;
    int rank;

    // C++20 Magic: 1 line generates all 6 comparison operators!
    auto operator<=>(const Player&) const = default;
};

int main() {
    Player p1{100, 1}, p2{90, 2};
    std::cout << std::boolalpha;
    std::cout << "Is p1 > p2? " << (p1 > p2) << "\n";  // true
    std::cout << "Is p1 == p2? " << (p1 == p2) << "\n"; // false
    return 0;
}
🔍 Line-by-Line కోడ్ బ్రేక్ డౌన్:
  • auto operator<=>(const Player&) const = default;: = default అని పెట్టగానే కంపైలర్ స్వయంగా మెంబర్ల ఆధారంగా ఆరు ఆపరేటర్లను మెరుపు వేగంతో సింథసైజ్ చేస్తుంది.
  • p1 > p2: మనం ప్రత్యేకంగా operator> రాయకపోయినా Spaceship ఆపరేటర్ స్వయంగా నిర్ణయిస్తుంది.
6 సాధారణంగా బిగినర్స్ చేసే తప్పులు & బెస్ట్ ప్రాక్టీసెస్

⚠️ Common Beginner Traps

  • లోకల్ ఆబ్జెక్ట్ ను రిఫరెన్స్ గా రిటర్న్ చేయడం: Complex& operator+() అని రిఫరెన్స్ రిటర్న్ చేస్తే, ఫంక్షన్ ముగియగానే ఆ లోకల్ ఆబ్జెక్ట్ నశించి Dangling Reference ఎర్రర్ వస్తుంది. అర్థమెటిక్ ఆపరేటర్లలో ఎల్లప్పుడూ బై-వాల్యూ (Complex operator+) రిటర్న్ చేయాలి!
  • సహజమైన అర్థాన్ని మార్చడం: + ఆపరేటర్ తో సబ్ట్రాక్షన్ చేయడం లాంటి వింత కోడ్ రాయకండి; ఇది టీమ్‌లోని ఇతర ఇంజనీర్లను గందరగోళానికి గురిచేస్తుంది.

💡 Industry Best Practices

  • Chaining కోసం స్ట్రీమ్ రిఫరెన్స్ రిటర్న్ చేయండి: operator<< లో ఎల్లప్పుడూ return os; చేయాలి, లేదంటే cout << a << b; చైనింగ్ ఫెయిల్ అవుతుంది.
  • Compound Assignment తో కోడ్ తగ్గించండి: operator+= ని మొదట రాసి, దాని ఆధారంగా operator+ ని రాయడం ప్రొఫెషనల్ పద్ధతి.

Q C++ లో Stream Insertion Operator (<<) ని మెంబర్ ఫంక్షన్ గా కాకుండా ఎల్లప్పుడూ 'friend' ఫంక్షన్ గానే ఎందుకు రాయాలి?

std::cout << obj అని రాసినప్పుడు ఎడమ వైపు ఉన్న మొదటి ఆబ్జెక్ట్ std::ostream. ఒకవేళ మెంబర్ ఫంక్షన్ గా రాయాలంటే మనం ostream క్లాస్ లోపలికి వెళ్లి కోడ్ మార్చాలి, అది స్టాండర్డ్ లైబ్రరీ కాబట్టి అసాధ్యం. అందుకే friend ostream& operator<<(ostream& os, const MyClass& obj) రూపంలో బయటి గ్లోబల్ ఫ్రెండ్ ఫంక్షన్ గా నిర్వచిస్తాం.

Q C++ లో ఏయే ఆపరేటర్లను ఓవర్‌లోడ్ చేయడం కుదరదు?

C++ లో కేవలం 5 ఆపరేటర్లను ఓవర్‌లోడ్ చేయలేము: 1. డాట్ ఆపరేటర్ (.) 2. పాయింటర్ టు మెంబర్ (.*) 3. స్కోప్ రిజల్యూషన్ (::) 4. టెర్నరీ కండిషనల్ ఆపరేటర్ (?:) 5. sizeof ఆపరేటర్. ఇవి కంపైలర్ యొక్క ప్రాథమిక సింటాక్స్ మరియు మెమరీ అలైన్‌మెంట్‌కు అవసరమైనవి.

Q Modern C++20 లో 'Spaceship Operator' (<=>) అంటే ఏమిటి?

C++20 లో వచ్చిన Three-Way Comparison Operator (<=>). పూర్వం ఆరు ఆపరేటర్లను (<, <=, >, >=, ==, !=) విడివిడిగా ఓవర్‌లోడ్ చేయాల్సి వచ్చేది. Spaceship ఆపరేటర్‌తో auto operator<=>(const MyClass&) const = default; అని ఒక్క లైన్ రాస్తే చాలు, కంపైలర్ అన్నింటినీ మెరుపు వేగంతో ఆటోమేటిక్‌గా రూపొందిస్తుంది.
