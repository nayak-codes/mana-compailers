ఆపరేటర్ ఓవర్‌లోడింగ్ & Friend Functions (తెలుగులో)

యూజర్ డిఫైన్డ్ ఆబ్జెక్టులకు సహజమైన గణిత వ్యక్తీకరణలు! Binary మరియు Unary ఆపరేటర్ ఓవర్‌లోడింగ్, ఓవర్‌లోడ్ చేయలేని 5 ఆపరేటర్లు, std::cout Stream Insertion (<<) కి Friend Function ఎందుకు అవసరం, Friend Classes భద్రతా నియమాలు, మరియు Modern C++20 లో వచ్చిన గేమ్ చేంజర్ Spaceship Operator (<=>).

1 ఆపరేటర్ ఓవర్‌లోడింగ్ అంటే ఏమిటి?

సాధారణంగా +, -, == వంటి ఆపరేటర్లు int, float లాంటి ప్రాథమిక డేటా టైప్స్ పై పనిచేస్తాయి. కానీ మన స్వంత క్లాస్ ఆబ్జెక్టులపై (ఉదా: రెండు కాంప్లెక్స్ నంబర్లు, రెండు మ్యాట్రిక్స్‌లు, లేదా రెండు వెక్టార్లు) + ఆపరేటర్ ఉపయోగించాలనుకుంటే?

అందుకోసం C++ మనకు Operator Overloading సదుపాయాన్ని అందిస్తుంది:

[Operator Overloading సింటాక్స్ & పరివర్తన] మనం రాసే క్లీన్ కోడ్: Complex c3 = c1 + c2; కంపైలర్ అంతర్గతంగా పిలిచే ఫంక్షన్: Complex c3 = c1.operator+(c2); ▲ └── c1 ఆబ్జెక్ట్ యొక్క operator+ ఫంక్షన్ లోకి c2 పారామీటర్ గా వెళ్తుంది!
⚠️ ఓవర్‌లోడ్ చేయలేని ఆపరేటర్లు ఏవి? (Interview Question):
C++ లో దాదాపు అన్ని ఆపరేటర్లను ఓవర్‌లోడ్ చేయవచ్చు, కానీ ఈ క్రింది 5 ఆపరేటర్లను ఎట్టి పరిస్థితుల్లోనూ ఓవర్‌లోడ్ చేయలేము:
1. Dot Operator (.)
2. Pointer-to-member Operator (.*)
3. Scope Resolution Operator (::)
4. Ternary Conditional Operator (?:)
5. Size Operator (sizeof)
💻 Code Example 1: Arithmetic & Equality Operator Overloading (+, ==)
complex_operators.cpp
⚡ Try in Compiler 
#include <iostream>

class Complex {
private:
    double real;
    double imag;

public:
    Complex(double r = 0.0, double i = 0.0) : real(r), imag(i) {}

    // '+' Binary Operator Overloading (Member Function)
    Complex operator+(const Complex& other) const {
        return Complex(this->real + other.real, this->imag + other.imag);
    }

    // '==' Equality Operator Overloading
    bool operator==(const Complex& other) const {
        return (this->real == other.real) && (this->imag == other.imag);
    }

    void display() const {
        std::cout << real << " + " << imag << "i\n";
    }
};

int main() {
    Complex c1(3.5, 2.5);
    Complex c2(1.5, 4.5);

    std::cout << "c1 = "; c1.display();
    std::cout << "c2 = "; c2.display();

    // '+' ఆపరేటర్ ద్వారా రెండు ఆబ్జెక్టులను కూడడం
    Complex c3 = c1 + c2; // Calls c1.operator+(c2)
    std::cout << "\nc3 (c1 + c2) = "; c3.display();

    // '==' ఆపరేటర్ తో పోలిక
    Complex c4(3.5, 2.5);
    std::cout << "\nChecking c1 == c4: " << (c1 == c4 ? "EQUAL ✔️" : "NOT EQUAL ❌") << "\n";
    std::cout << "Checking c1 == c2: " << (c1 == c2 ? "EQUAL ✔️" : "NOT EQUAL ❌") << "\n";

    return 0;
}

2 Stream Insertion (<<) & Friend Functions

మనం ఒక ఆబ్జెక్ట్‌ను c1.display() అని కాకుండా నేరుగా std::cout << c1; అని ప్రింట్ చేయాలనుకుంటే, operator<< ని ఓవర్‌లోడ్ చేయాలి. కానీ ఇక్కడ ఒక చిక్కు సమస్య ఉంది:

💡 ఎందుకు Stream Operators ని మెంబర్ ఫంక్షన్ గా రాయలేము?
std::cout << c1 లో ఎడమ వైపు ఉన్న మొదటి ఆపరాండ్ std::cout (ఇది std::ostream రకం).
ఒకవేళ ఇది మెంబర్ ఫంక్షన్ అవ్వాలంటే, ostream క్లాస్ లోపల మన క్లాస్ కోసం మెథడ్ ఉండాలి! కానీ ostream అనేది C++ స్టాండర్డ్ లైబ్రరీకి చెందినది; దానిని మనం ఎడిట్ చేయలేము.

అందుకే దీనిని క్లాస్ బయట ఉండే గ్లోబల్ ఫంక్షన్‌గా రాయాలి. అయితే క్లాస్ ప్రైవేట్ వేరియబుల్స్ (real, imag) ను చదవడానికి ఆ ఫంక్షన్‌కు క్లాస్ లోపల friend పర్మిషన్ ఇవ్వాలి!
3 Friend Functions & Friend Classes నియమాలు

ఒక క్లాస్ తన private మరియు protected మెంబర్లను బయటి ఒక నిర్దిష్ట ఫంక్షన్‌కు లేదా మరొక క్లాస్‌కు మాత్రమే అనుమతించాలనుకున్నప్పుడు friend కీవర్డ్ వాడుతుంది.

  • Friendship is not mutual: క్లాస్ A క్లాస్ B కి ఫ్రెండ్ అయితే, ఆటోమేటిక్‌గా B క్లాస్ A కి ఫ్రెండ్ అవ్వదు!
  • Friendship is not inherited: పేరెంట్ క్లాస్ ఫ్రెండ్స్ చైల్డ్ క్లాస్ కు ఆటోమేటిక్‌గా ఫ్రెండ్స్ కాలేరు.
  • పరిమితంగా వాడాలి: మితిమీరిన ఫ్రెండ్స్ వాడకం వల్ల ఎన్‌క్యాప్సులేషన్ భద్రత బలహీనపడుతుంది.
4 Modern C++20: Spaceship Operator (<=>)

పూర్వం రెండు ఆబ్జెక్టులను పోల్చడానికి మనం 6 వేర్వేరు ఆపరేటర్లను (<, <=, >, >=, ==, !=) విడివిడిగా రాసేవాళ్ళం. C++20 లో పరిచయమైన Three-Way Comparison (Spaceship) Operator <=> తో ఈ బాధలన్నీ తీరిపోయాయి!

[C++20 Spaceship Operator Magic] struct Point { int x; int y; // ఒక్క లైన్ తో మొత్తం 6 రిలేషనల్ ఆపరేటర్లు ఆటోమేటిక్ గా తయారవుతాయి! auto operator<=>(const Point&) const = default; }; Point p1{1, 2}, p2{2, 3}; bool b1 = (p1 < p2); // Works automatically! bool b2 = (p1 == p2); // Works automatically!
💻 Code Example 2: Stream Insertion (<<) Overload & Friend Class Auditing
stream_friend_demo.cpp
⚡ Try in Compiler 
#include <iostream>
#include <string>

class BankAccount {
private:
    std::string owner;
    double balance;

public:
    BankAccount(const std::string& name, double bal) : owner(name), balance(bal) {}

    // 1. Friend Function for Stream Insertion (std::cout << account)
    friend std::ostream& operator<<(std::ostream& os, const BankAccount& acc) {
        os << "[Account: " << acc.owner << " | Verified Balance: $" << acc.balance << "]";
        return os; // చైనింగ్ (cout << a << b) కోసం os రిటర్న్ చేయాలి
    }

    // 2. Friend Class Declaration - TaxAuditor కి ప్రైవేట్ యాక్సెస్ ఇస్తుంది
    friend class TaxAuditor;
};

class TaxAuditor {
public:
    void auditAccount(const BankAccount& acc) {
        std::cout << "  [TAX AUDIT] Inspecting Private Records...\n";
        // 'owner' & 'balance' private అయినప్పటికీ TaxAuditor కి friend కాబట్టి యాక్సెస్ ఉంది!
        std::cout << "  Auditing: " << acc.owner << " | Liquid Cash: $" << acc.balance << "\n";
    }
};

int main() {
    BankAccount userAcc("Suresh Kumar", 75000.0);

    std::cout << "=== 1. Direct Object Printing via overloaded << ===\n";
    std::cout << userAcc << "\n\n";

    std::cout << "=== 2. Friend Class Accessing Private Members ===\n";
    TaxAuditor governmentAuditor;
    governmentAuditor.auditAccount(userAcc);

    return 0;
}

❓ Frequently Asked Questions (FAQ)

Q C++ లో Stream Insertion Operator (<<) ని మెంబర్ ఫంక్షన్ గా కాకుండా ఎల్లప్పుడూ 'friend' ఫంక్షన్ గానే ఎందుకు రాయాలి?

std::cout << obj అని రాసినప్పుడు ఎడమ వైపు ఉన్న మొదటి ఆబ్జెక్ట్ std::ostream. ఒకవేళ మెంబర్ ఫంక్షన్ గా రాయాలంటే మనం ostream క్లాస్ లోపలికి వెళ్లి కోడ్ మార్చాలి, అది స్టాండర్డ్ లైబ్రరీ కాబట్టి అసాధ్యం. అందుకే friend ostream& operator<<(ostream& os, const MyClass& obj) రూపంలో బయటి గ్లోబల్ ఫ్రెండ్ ఫంక్షన్ గా నిర్వచిస్తాం.

Q C++ లో ఏయే ఆపరేటర్లను ఓవర్‌లోడ్ చేయడం కుదరదు?

C++ లో కేవలం 5 ఆపరేటర్లను ఓవర్‌లోడ్ చేయలేము: 1. డాట్ ఆపరేటర్ (.) 2. పాయింటర్ టు మెంబర్ (.*) 3. స్కోప్ రిజల్యూషన్ (::) 4. టెర్నరీ కండిషనల్ ఆపరేటర్ (?:) 5. sizeof ఆపరేటర్. ఇవి కంపైలర్ యొక్క ప్రాథమిక సింటాక్స్ మరియు మెమరీ అలైన్‌మెంట్‌కు అవసరమైనవి.

Q Modern C++20 లో 'Spaceship Operator' (<=>) అంటే ఏమిటి?

C++20 లో వచ్చిన Three-Way Comparison Operator (<=>). పూర్వం ఆరు ఆపరేటర్లను (<, <=, >, >=, ==, !=) విడివిడిగా ఓవర్‌లోడ్ చేయాల్సి వచ్చేది. Spaceship ఆపరేటర్‌తో auto operator<=>(const MyClass&) const = default; అని ఒక్క లైన్ రాస్తే చాలు, కంపైలర్ అన్నింటినీ మెరుపు వేగంతో ఆటోమేటిక్‌గా రూపొందిస్తుంది.
