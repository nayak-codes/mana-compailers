Exception Handling: try, catch, throw (తెలుగులో)

⚡ Modern C++ (C++17 / C++20 / C++23) 🟢 Lesson 18 📂 Phase 18: Exception Handling 📅 2026 Master Edition
📌 Covered in this in-depth guide: try / catch Blocks · throw keyword · Custom Exceptions · std::exception · noexcept guarantee

కంప్యూటర్ ప్రోగ్రామ్స్ లో ఎర్రర్స్ రావడం చాలా కామన్. ఉదాహరణకు, మీరు ఒక ఫైల్ ని చదవాలని కోడ్ రాశారు, కానీ కంప్యూటర్ లో ఆ ఫైల్ డిలీట్ అయిపోయింది. అప్పుడు మీ యాప్ ఏమవుతుంది? డైరెక్ట్ గా క్రాష్ అయిపోయి ఆగిపోతుంది. ఒకవేళ అది బ్యాంక్ సర్వర్ అయితే? అలా క్రాష్ అయితే లక్షల రూపాయలు నష్టం వస్తుంది! ఈ ప్రాబ్లెమ్స్ ని ముందే పసిగట్టి, "ఒకవేళ ఫెయిల్ అయితే ఏం చేయాలి?" అని కంప్యూటర్ కి నేర్పించడాన్నే Exception Handling (ఎక్సెప్షన్ హ్యాండ్లింగ్) అంటారు. C++ లో దీన్ని try, catch, throw అనే మూడు బ్రహ్మాస్త్రాలతో ఎలా హ్యాండిల్ చేయాలో ఈ పాఠంలో చూద్దాం.

1 Try, Catch మరియు Throw అంటే ఏంటి?

try { ... } : రిస్క్ ఉన్న కోడ్ ని (ఉదాహరణకు డివైడ్ బై జీరో, ఫైల్ ఓపెన్ చేయడం) ఈ బ్రాకెట్స్ లో పెడతారు. అంటే "ఒకసారి ట్రై చెయ్" అని అర్థం.

throw : ట్రై చేస్తున్నప్పుడు ఏదైనా కండిషన్ ఫెయిల్ అయితే, ప్రోగ్రామ్ క్రాష్ అవ్వకుండా ఒక సిగ్నల్ (బాల్ లాగా) బయటకి విసిరేయడాన్ని (Throw) త్రో అంటారు.

catch (error) { ... } : లోపల నుండి త్రో చేయబడిన బాల్ ని (ఎర్రర్ ని) ఇక్కడ పట్టుకుని (Catch), యూజర్ కి సింపుల్ గా "Please check your inputs" అని ఫెయిల్-సేఫ్ మెసేజ్ ఇస్తారు. అప్పుడు యాప్ ఆగిపోకుండా కంటిన్యూ అవుతుంది.

🔥 రియల్ లైఫ్ స్టోరీ: సర్కస్ లో ట్రెపీజ్ (Trapeze) జంప్

సర్కస్ లో గాలిలో ఒక ఊయల నుండి ఇంకో ఊయల మీదకి దూకుతారు చూసారా? (ఇదే try బ్లాక్).

ఒకవేళ ఆ వ్యక్తి చేతికి ఊయల అందకపోతే, కింద పడిపోతాడు (ఇదే throw).
అలా పడిపోయినప్పుడు ప్రాణాలు పోకుండా కింద ఒక పెద్ద వల (Net) కట్టి ఉంచుతారు. ఆ వల అతన్ని సేఫ్ గా పట్టుకుంటుంది (ఇదే catch). వల ఉంటే ఆట మళ్ళీ కంటిన్యూ అవుతుంది. ప్రోగ్రామింగ్ లో ఈ వల లేకపోతే... మీ యాప్ డైరెక్ట్ గా డెస్క్ టాప్ కి క్రాష్ అయిపోతుంది (Crash to Desktop).

2 Custom Exceptions (సొంత ఎర్రర్స్ రాయడం)

C++ లో std::exception అనే ఒక బేస్ క్లాస్ ఉంది (ఇది <stdexcept> లో ఉంటుంది). దాన్ని వాడుకుని మనం మన సొంత ఎర్రర్స్ రాసుకోవచ్చు. ఉదాహరణకు బ్యాంక్ యాప్ లో "InsufficientFundsException" అనే క్లాస్ రాసి, బ్యాలెన్స్ తక్కువ ఉంటే త్రో చేయొచ్చు.

3 ఒకే ఒక సింపుల్ కోడ్ (Try Catch Demo)

కింద కోడ్ లో డివైడ్ బై జీరో (0 తో భాగించడం) వస్తే యాప్ క్రాష్ అవ్వకుండా, try-catch తో ఆపరేషన్ ని సేఫ్ గా ఎలా ఆపామో చూడండి.

C++ — Exception Handling ▶ Run Code 
#include <iostream>
#include <stdexcept> // runtime_error కోసం

// ఈ ఫంక్షన్ ఎర్రర్ వస్తే త్రో (throw) చేస్తుంది
double divideNumbers(double a, double b) {
    if (b == 0) {
        // ఇక్కడ మనం ఎర్రర్ ని విసిరేస్తున్నాం!
        throw std::runtime_error("Math Error: Division by Zero!");
    }
    return a / b;
}

int main() {
    std::cout << "Program Started..." << std::endl;
    
    // రిస్క్ ఉన్న పనిని try లో పెడతాం
    try {
        double result = divideNumbers(10, 0); // 0 పంపుతున్నాం కాబట్టి ఫెయిల్ అవుతుంది
        std::cout << "Result: " << result << std::endl;
        std::cout << "This line will NOT print!" << std::endl; // ఇది స్కిప్ అవుతుంది
    } 
    // విసిరేసిన ఎర్రర్ ని ఇక్కడ క్యాచ్ చేస్తాం
    catch (const std::exception& e) {
        std::cout << "[X] Exception Caught: " << e.what() << std::endl;
    }
    
    // ప్రోగ్రామ్ సేఫ్ గా కంటిన్యూ అవుతుంది!
    std::cout << "Program Finished Safely." << std::endl;
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • throw std::runtime_error(...): 0 తో డివైడ్ చేస్తే CPU క్రాష్ అవుతుంది. అందుకే మనం ముందుగానే చెక్ చేసి, ఒక ఆబ్జెక్ట్ ని త్రో చేశాం. త్రో చేసిన క్షణంలోనే ఫంక్షన్ ఆగిపోయి వెనక్కి వచ్చేస్తుంది.
  • catch (const std::exception& e): కింద వల (Net) లాగా ఇది పట్టుకుంది. అందులో ఉన్న మెసేజ్ ని ప్రింట్ చేయడానికి e.what() అని కాల్ చేశాం. (Reference తో పట్టుకోవడం వల్ల కాపీ మెమరీ వేస్ట్ అవ్వదు).
  • అదంతా అయ్యాక, "Program Finished Safely" ప్రింట్ అయ్యింది. అదే మీరు try-catch వాడకపోతే ఆ లాస్ట్ లైన్ దాకా రాకుండానే యాప్ ఆగిపోయేది!
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: C++ లో ఏదైనా త్రో చేయొచ్చా? (ఉదా: throw 404;)

అవును! జావా లో లాగా కేవలం ఎక్సెప్షన్ ఆబ్జెక్ట్స్ నే త్రో చేయాలని రూల్ లేదు. C++ లో మీరు ఒక ఇంటిజర్ throw 404; లేదా ఒక స్ట్రింగ్ throw "Error"; ని కూడా త్రో చేయొచ్చు. వాటిని పట్టుకోవడానికి catch(int code) అని రాసుకుంటారు. కానీ బెస్ట్ ప్రాక్టీస్ ఏంటంటే ఎప్పుడూ std::exception చైల్డ్ క్లాసెస్ నే వాడాలి.

Q2: Catch-All బ్లాక్ (catch(...)) అంటే ఏంటి?

కొన్నిసార్లు లోపల నుండి ఏ ఎర్రర్ వస్తుందో మనకు తెలీదు (ఇంటిజర్ ఆ, స్ట్రింగ్ ఆ, ఆబ్జెక్ట్ ఆ). అలాంటప్పుడు అన్ని రకాల ఎర్రర్స్ ని పట్టుకోవడానికి catch(...) అని మూడు చుక్కలు పెడతారు. ఇది డిఫాల్ట్ క్యాచ్ లాగా పనిచేస్తుంది. కానీ లోపల మెసేజ్ ఏంటో మనకు తెలీదు.

Q3: noexcept కీవర్డ్ ఎందుకు వాడుతారు?

మీకు 100% నమ్మకం ఉంటే "నా ఫంక్షన్ లో ఎట్టి పరిస్థితుల్లో ఎర్రర్ రాదు" అని, అప్పుడు ఫంక్షన్ పక్కన noexcept అని రాస్తారు. ఇది చూసి కంపైలర్ చాలా ఫాస్ట్ గా ఆప్టిమైజ్ చేస్తుంది. ఒకవేళ మీరు noexcept అని రాసి లోపల త్రో చేస్తే, యాప్ వెంటనే std::terminate() అయ్యి డైరెక్ట్ గా క్రాష్ అయిపోతుంది (క్యాచ్ కూడా పనిచేయదు).
