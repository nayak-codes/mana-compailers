❓ Frequently Asked Questions

Is Our Compiler 100% free to use?

Yes! Running code, testing scripts, and reading all 775+ programming tutorial lessons is completely free with zero subscription fees.

How do I report a bug or broken code example?

Use the contact form above or email us directly at balanjusolutions@gmail.com with the URL and description of the bug.

Can I request a new programming language or feature?

Absolutely! We welcome feature suggestions. Many of our recent additions originated from developer feedback.

Do you store or monitor my submitted source code?

No. Source code is executed in memory inside an isolated Docker sandbox and destroyed immediately upon execution completion.
