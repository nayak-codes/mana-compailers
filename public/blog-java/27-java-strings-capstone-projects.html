Java Strings Capstone Projects: 5 Production-Grade Systems (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 27 of 47 📂 Phase 6: Strings & Text Processing 📅 2026 Edition
📌 Covered in this chapter:

Project 1: Palindrome Checker · Project 2: Word Counter & Text Stats · Project 3: Character & Frequency Analyzer · Project 4: Enterprise Username Validator · Project 5: Password Security & Entropy Evaluator

ఇప్పటిదాకా స్ట్రింగ్స్ మీద నేర్చుకున్న కాన్సెప్ట్స్ అన్నీ కలిపి 5 రియల్-వరల్డ్ ప్రాజెక్ట్స్ చేద్దాం: పాలిండ్రోమ్ చెక్కర్, టెక్స్ట్ ఎనలైజర్, క్యారెక్టర్ ఫ్రీక్వెన్సీ, ఎంటర్ప్రైజ్ యూజర్ నేమ్ వాలిడేటర్, మరియు పాస్వర్డ్ స్ట్రెంత్ క్యాలిక్యులేటర్. ఇవి టెక్నికల్ ఇంటర్వ్యూస్ లో ఎక్కువగా అడిగే మోస్ట్ ఇంపార్టెంట్ ప్రాజెక్ట్స్.

1. ఈ 5 క్యాప్-స్టోన్ ప్రాజెక్ట్స్ ఏంటి?

ఈ చాప్టర్ లో మనం Phase 6 మొత్తాన్ని (Immutability, Methods, Regex, StringBuilder అన్నీ) రియల్-వరల్డ్ కు అప్లై చేస్తున్నాం:

1. ప్రాజెక్ట్ 1: టూ-పాయింటర్ పాలిండ్రోమ్ (Two-Pointer Palindrome):
పదాన్ని రివర్స్ చేసినా సేమ్ వస్తుందో లేదో చెక్ చేస్తుంది. కానీ స్పేస్ లు, స్పెషల్ క్యారెక్టర్స్ వదిలేసి కేవలం లెటర్స్ ని మాత్రమే ఫాస్ట్ గా (O(N) స్పీడ్ లో) మెమరీ వేస్ట్ చేయకుండా చెక్ చేస్తుంది.

2. ప్రాజెక్ట్ 2: వర్డ్ కౌంటర్ & టెక్స్ట్ స్టాటిస్టిక్స్:
ఒక పెద్ద డాక్యుమెంట్ ఇస్తే.. అందులో ఎన్ని పదాలున్నాయి, క్యారెక్టర్స్ ఎన్ని, ఆవరేజ్ పదం సైజు ఎంత లాంటివి కౌంట్ చేస్తుంది.

3. ప్రాజెక్ట్ 3: క్యారెక్టర్ ఫ్రీక్వెన్సీ ఎనలైజర్:
అచ్చుల (Vowels) సంఖ్య, హల్లుల (Consonants) సంఖ్య, నంబర్స్, స్పెషల్ క్యారెక్టర్స్ ఎన్ని ఉన్నాయో కేటగిరీల వారీగా డివైడ్ చేస్తుంది.

4. ప్రాజెక్ట్ 4: ఎంటర్ప్రైజ్ యూజర్ నేమ్ వాలిడేటర్:
కంపెనీ యాప్స్ లో యూజర్ నేమ్ ఎలా పడితే అలా ఇవ్వడానికి కుదరదు. లెంత్ 5-20 ఉండాలి, నంబర్ తో స్టార్ట్ అవ్వకూడదు, admin, root లాంటి పేర్లు పెట్టుకోకూడదు. వీటన్నింటినీ చెక్ చేసే సిస్టమ్ ఇది.

5. ప్రాజెక్ట్ 5: అడ్వాన్స్డ్ పాస్వర్డ్ సెక్యూరిటీ చెక్కర్:
యూజర్ పెట్టిన పాస్వర్డ్ స్ట్రాంగ్ గా ఉందో లేదో (0-100) స్కోర్ ఇస్తుంది. క్యాపిటల్స్, స్మాల్స్, స్పెషల్ క్యారెక్టర్స్ ఉన్నాయా? డిక్షనరీ లోని కామన్ పాస్వర్డ్స్ పెట్టారా అని మొత్తం చెక్ చేస్తుంది.

2. స్ట్రింగ్ అల్గారిథమ్స్ - మైండ్ సెట్

ప్రాజెక్ట్ 1 లాజిక్ (టూ-పాయింటర్ పాలిండ్రోమ్):
  లెఫ్ట్ (i=0) -> [A] m a n a p l a n a c a n a l p a n a m [a] <- రైట్ (j=len-1)
                         |                                       |
                         +----------------(మ్యాచ్ అయ్యింది!)---------------+
  అక్షరాలు కాకపోతే స్కిప్ చేసి, రెండు పాయింటర్స్ ని దగ్గరకి తీసుకువస్తూ చెక్ చేయాలి.

ప్రాజెక్ట్ 5 లాజిక్ (పాస్వర్డ్ స్కోర్):
  + లెంత్ >= 8 (+15 పాయింట్స్), లెంత్ >= 12 (+25 పాయింట్స్)
  + క్యాపిటల్స్ (+15), స్మాల్స్ (+15)
  + నంబర్స్ (+15), స్పెషల్ క్యారెక్టర్స్ (+15)
  - బ్లాక్ లిస్ట్ లో ఉన్న పాస్వర్డ్ పెడితే (-40 పాయింట్స్ కట్)
  ======================================================
  స్కోర్: 0-40 (వీక్) | 41-70 (మీడియం) | 71-100 (స్ట్రాంగ్)

public class Main {
    // -------------------------------------------------------------
    // ప్రాజెక్ట్ 1: పాలిండ్రోమ్ చెక్కర్ (కొత్త మెమరీ వాడకుండా సూపర్ ఫాస్ట్ గా)
    // -------------------------------------------------------------
    public static boolean isPalindrome(String input) {
        if (input == null) return false;
        int left = 0;
        int right = input.length() - 1;

        while (left < right) {
            char lChar = input.charAt(left);
            char rChar = input.charAt(right);

            // అక్షరం లేదా నంబర్ కాకపోతే స్కిప్ చేస్తాం
            if (!Character.isLetterOrDigit(lChar)) {
                left++;
            } else if (!Character.isLetterOrDigit(rChar)) {
                right--;
            } else {
                // స్మాల్ లెటర్స్ కి మార్చి చెక్ చేస్తున్నాం
                if (Character.toLowerCase(lChar) != Character.toLowerCase(rChar)) {
                    return false;
                }
                left++;
                right--;
            }
        }
        return true;
    }

    // -------------------------------------------------------------
    // ప్రాజెక్ట్ 2: వర్డ్ కౌంటర్ & టెక్స్ట్ స్టాటిస్టిక్స్
    // -------------------------------------------------------------
    public static void printTextStatistics(String text) {
        if (text == null || text.isBlank()) return;

        String[] words = text.trim().split("\\s+"); // స్పేస్ లతో ముక్కలు చేస్తున్నాం
        int totalCharsWithSpaces = text.length();
        int totalCharsNoSpaces = text.replace(" ", "").replace("\n", "").replace("\t", "").length();
        String[] sentences = text.split("[.!?]+");

        int totalWordLength = 0;
        String longestWord = "";
        for (String w : words) {
            String cleanWord = w.replaceAll("[^a-zA-Z0-9]", "");
            totalWordLength += cleanWord.length();
            if (cleanWord.length() > longestWord.length()) {
                longestWord = cleanWord;
            }
        }
        double avgWordLength = words.length > 0 ? (double) totalWordLength / words.length : 0;

        System.out.println("  మొత్తం పదాలు           : " + words.length);
        System.out.println("  క్యారెక్టర్స్ (స్పేస్ తో)  : " + totalCharsWithSpaces);
        System.out.println("  క్యారెక్టర్స్ (స్పేస్ లేకుండా) : " + totalCharsNoSpaces);
        System.out.println("  వాక్యాలు (Sentences)   : " + sentences.length);
        System.out.println("  అతిపెద్ద పదం           : " + longestWord + " (" + longestWord.length() + " అక్షరాలు)");
        System.out.printf("  ఆవరేజ్ పదం సైజు        : %.2f అక్షరాలు%n", avgWordLength);
    }

    // -------------------------------------------------------------
    // ప్రాజెక్ట్ 3: క్యారెక్టర్ కేటగిరీ ఎనలైజర్
    // -------------------------------------------------------------
    public static void analyzeCharacterFrequencies(String text) {
        int vowels = 0, consonants = 0, digits = 0, special = 0, spaces = 0;

        for (int i = 0; i < text.length(); i++) {
            char ch = text.charAt(i);

            if (Character.isDigit(ch)) {
                digits++;
            } else if (Character.isWhitespace(ch)) {
                spaces++;
            } else if (Character.isLetter(ch)) {
                char lower = Character.toLowerCase(ch);
                if (lower == 'a' || lower == 'e' || lower == 'i' || lower == 'o' || lower == 'u') {
                    vowels++;
                } else {
                    consonants++;
                }
            } else {
                special++;
            }
        }

        System.out.println("  అచ్చులు (Vowels)       : " + vowels);
        System.out.println("  హల్లులు (Consonants)   : " + consonants);
        System.out.println("  నంబర్స్ (Digits)       : " + digits);
        System.out.println("  స్పేస్ లు (Spaces)      : " + spaces);
        System.out.println("  స్పెషల్ క్యారెక్టర్స్       : " + special);
    }

    // -------------------------------------------------------------
    // ప్రాజెక్ట్ 4: ఎంటర్ప్రైజ్ యూజర్ నేమ్ వాలిడేటర్
    // -------------------------------------------------------------
    public static boolean validateUsername(String username) {
        if (username == null) return false;
        String clean = username.trim();

        // రూల్ 1: సైజు 5 నుంచి 20 మధ్యలో ఉండాలి
        if (clean.length() < 5 || clean.length() > 20) return false;

        // రూల్ 2: నంబర్ తో స్టార్ట్ అవ్వకూడదు
        if (!Character.isLetter(clean.charAt(0))) return false;

        // రూల్ 3: కేవలం ఇంగ్లీష్ అక్షరాలు, నంబర్స్, అండర్ స్కోర్ మాత్రమే ఉండాలి
        if (!clean.matches("^[a-zA-Z0-9_]+$")) return false;

        // రూల్ 4: ఇవి పెట్టుకోకూడదు (Blacklist)
        String lower = clean.toLowerCase();
        String[] reserved = {"admin", "root", "system", "administrator", "null", "superuser"};
        for (String r : reserved) {
            if (lower.equals(r)) return false;
        }

        return true;
    }

    // -------------------------------------------------------------
    // ప్రాజెక్ట్ 5: పాస్వర్డ్ స్ట్రెంత్ ఎనలైజర్ (0-100 స్కోర్)
    // -------------------------------------------------------------
    public static String evaluatePasswordStrength(String password) {
        if (password == null || password.length() < 6) return "CRITICAL: చాలా చిన్నగా ఉంది (Score: 0/100)";

        int score = 0;
        if (password.length() >= 8) score += 15;
        if (password.length() >= 12) score += 15;
        if (password.length() >= 16) score += 10;

        boolean hasUpper = false, hasLower = false, hasDigit = false, hasSpecial = false;
        for (char ch : password.toCharArray()) {
            if (Character.isUpperCase(ch)) hasUpper = true;
            else if (Character.isLowerCase(ch)) hasLower = true;
            else if (Character.isDigit(ch)) hasDigit = true;
            else hasSpecial = true;
        }

        if (hasUpper) score += 15;
        if (hasLower) score += 15;
        if (hasDigit) score += 15;
        if (hasSpecial) score += 15;

        // కామన్ పాస్వర్డ్స్ ఇస్తే స్కోర్ తగ్గిస్తాం
        String[] commonWeak = {"password", "12345678", "qwerty", "admin123", "password123"};
        for (String weak : commonWeak) {
            if (password.toLowerCase().contains(weak)) {
                score = Math.max(0, score - 40); // 40 పాయింట్స్ కట్
            }
        }

        String rating = score >= 80 ? "స్ట్రాంగ్ 🟢" : (score >= 50 ? "మీడియం 🟡" : "వీక్ 🔴");
        return String.format("%s (స్కోర్: %d/100)", rating, score);
    }

    public static void main(String[] args) {
        System.out.println("=== ప్రాజెక్ట్ 1: పాలిండ్రోమ్ చెక్కర్ ===");
        String p1 = "A man, a plan, a canal: Panama";
        String p2 = "Java Programming";
        System.out.println(""" + p1 + "" పాలిండ్రోమా? -> " + isPalindrome(p1)); // true
        System.out.println(""" + p2 + "" పాలిండ్రోమా? -> " + isPalindrome(p2)); // false

        System.out.println("
=== ప్రాజెక్ట్ 2: వర్డ్ కౌంటర్ & టెక్స్ట్ స్టాటిస్టిక్స్ ===");
        String article = "Java is a powerful, multi-threaded programming language! It enables robust enterprise systems. Java 21 LTS is blazing fast.";
        printTextStatistics(article);

        System.out.println("
=== ప్రాజెక్ట్ 3: క్యారెక్టర్ ఎనలైజర్ ===");
        analyzeCharacterFrequencies("Java 21 LTS Released on Sep 2023! #1 Backend");

        System.out.println("
=== ప్రాజెక్ట్ 4: యూజర్ నేమ్ వాలిడేటర్ ===");
        String[] testUsers = {"ravi_kumar", "admin", "99developer", "alex_dev_2026", "a"};
        for (String u : testUsers) {
            System.out.printf("యూజర్: %-16s | కరెక్టేనా?: %b%n", u, validateUsername(u));
        }

        System.out.println("
=== ప్రాజెక్ట్ 5: పాస్వర్డ్ స్ట్రెంత్ ఎనలైజర్ ===");
        String[] testPasswords = {"pass", "password123", "Java2026", "J@v4_Str0ng_P@ssw0rd!#2026"};
        for (String pwd : testPasswords) {
            System.out.printf("పాస్వర్డ్: %-26s | %s%n", pwd, evaluatePasswordStrength(pwd));
        }
    }

⚠️ Common Mistakes & Professional Best Practices
  • split(" ") వాడటం. ఇలా రాస్తే ఒకవేళ యూజర్ రెండు మూడు స్పేస్ లు ఇస్తే, వాటిని కూడా పదాలుగా కౌంట్ చేస్తుంది. ఎప్పుడూ split("\\s+") వాడాలి.
  • పాస్వర్డ్ కరెక్టేనా అని చూడటానికి జస్ట్ లెంత్ ఒక్కటే చెక్ చేయడం. హ్యాకర్స్ కామన్ పాస్వర్డ్స్ (dictionary attack) తో ఈజీగా హ్యాక్ చేస్తారు, అందుకే బ్లాక్ లిస్ట్ చెక్ కచ్చితంగా ఉండాలి.
  • పాలిండ్రోమ్ కోసం ముందు reverse() చేసి ఆ తర్వాత equals() వాడటం. ఇది చిన్న పదాలకు ఓకే, కానీ పెద్ద పారాగ్రాఫ్ ఇస్తే మెమరీ మొత్తం లాగేసుకుంటుంది. టూ-పాయింటర్ పద్ధతే బెస్ట్.

// Coding Challenge:
// ఇంకో సెక్యూరిటీ మెథడ్ రాయండి: sanitizePhoneNumber(String phone)
// 1. ఫోన్ నంబర్ ఎలా ఇచ్చినా సరే: "+1 (555) 234-5678", "555.234.5678", "555 234 5678"
// 2. అందులో ఉన్న నంబర్స్ మాత్రమే బయటికి తీయాలి.
// 3. దాన్ని పర్ఫెక్ట్ ఫార్మాట్ లో: "+1-555-234-5678" అని మార్చి రిటర్న్ చేయాలి.

public class Challenge {
    public static String sanitizePhoneNumber(String phone) {
        // అంకెల (0-9) కి మినహా మిగతా ఏమున్నా తీసేస్తున్నాం
        String digits = phone.replaceAll("[^0-9]", "");
        if (digits.length() == 10) {
            digits = "1" + digits; // కంట్రీ కోడ్ లేకపోతే కలుపుతున్నాం
        }
        if (digits.length() == 11) {
            return String.format("+%s-%s-%s-%s",
                digits.substring(0, 1),
                digits.substring(1, 4),
                digits.substring(4, 7),
                digits.substring(7, 11));
        }
        return "ఇన్వాలిడ్ ఫోన్ నంబర్";
    }

    public static void main(String[] args) {
        System.out.println(sanitizePhoneNumber("+1 (555) 234-5678"));
        System.out.println(sanitizePhoneNumber("555.234.5678"));
    }
}

❓ StringBuilder.reverse() వదిలేసి టూ-పాయింటర్ పద్ధతి ఎందుకు వాడాలి?

టూ-పాయింటర్ పద్ధతి ఏ కొత్త మెమరీ తీసుకోకుండా (O(1) స్పేస్), ఉన్నదానిలోనే ఫాస్ట్ గా చెక్ చేస్తుంది. రివర్స్ చేయడం అంటే కొత్త స్ట్రింగ్ క్రియేట్ చేయాల్సి వస్తుంది, దానివల్ల యాప్ స్లో అవుతుంది.

❓ పాస్వర్డ్ లో బ్లాక్ లిస్ట్ ఎందుకు చెక్ చేయాలి?
