Java Static Members, Nested Classes & Enums Masterclass (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 40 of 47 📂 Phase 9: Classes & Objects 📅 2026 Edition
📌 Covered in this chapter:

Static Fields (Class Variables) · Static Methods · Static Initializer Blocks · Static vs Instance Memory Layout · Inner Classes (Non-static) · Static Nested Classes · Anonymous Inner Classes · Enums: Type-Safe Constants · Enum Methods & Constructors

క్లాస్ మొత్తానికీ కలిపి ఒకే ఒక్క కామన్ డేటా ఉండాలంటే ఏం చేయాలి? ఒక క్లాస్ లోపల ఇంకో క్లాస్ ని ఎందుకు రాస్తారు? జావాలో మ్యాజిక్ లా పనిచేసే Enums (ఎనమ్స్) అంటే ఏంటి? ఈ చాప్టర్ లో `static` మాయాజాలం తో పాటు ఇవన్నీ క్లియర్ గా తెలుసుకుందాం.

1. Static Fields (క్లాస్ వేరియబుల్స్)

static field (దీన్నే క్లాస్ వేరియబుల్ అంటారు) అంటే ఒక క్లాస్ కి సంబంధించిన డేటా. ఇది ఆబ్జెక్ట్స్ అన్నింటికీ కలిపి ఒకే ఒక్క కాపీ JVM మెథడ్ ఏరియాలో ఉంటుంది. దాన్ని అందరూ షేర్ చేసుకుంటారు:

class Student {
    static int totalStudents = 0; // ఇది అందరికీ కామన్. ఒక్కటే కాపీ ఉంటుంది.
    String name;                  // ఇది ఎవరి పేరు వాళ్ళకే ఉంటుంది (సపరేట్ కాపీ)

Student(String name) {
        this.name = name;
        Student.totalStudents++;  // కొత్త ఆబ్జెక్ట్ రాగానే కామన్ కౌంటర్ ని పెంచుతున్నాం
    }
}


Student s1 = new Student("Ravi");
Student s2 = new Student("Priya");
System.out.println(Student.totalStudents); // 2 వస్తుంది (అందరూ షేర్ చేసుకున్నారు కాబట్టి!)

మెమరీలో ఎక్కడ ఉంటాయి?
- మామూలు వేరియబుల్స్ (Instance) → Heap లో ఒక్కో ఆబ్జెక్ట్ కి ఒక్కో కాపీ.
- static వేరియబుల్స్ → Class Area లో ఒకే ఒక్క కాపీ.

2. Static Initializer Blocks

క్లాస్ లోపల static { ... } అని ఒక బ్లాక్ రాయొచ్చు. దీన్ని Static Block అంటారు. JVM మొదటిసారి ఈ క్లాస్ ని లోడ్ చేసినప్పుడు, ఇది ఒకే ఒక్కసారి రన్ అవుతుంది. కాంప్లెక్స్ గా ఉండే సెటప్ పనులకి దీన్ని వాడతారు:

class DatabaseConfig {
    static String host;
    static int port;

static {
        // క్లాస్ లోడ్ అయినప్పుడు ఒకేసారి రన్ అవుతుంది
        host = System.getenv("DB_HOST") != null ? System.getenv("DB_HOST") : "localhost";
        port = 5432;
        System.out.println("[INIT] డేటాబేస్ సెటప్ రెడీ!");
    }
}

3. Inner Classes (క్లాస్ లోపల క్లాస్)

ఒక క్లాస్ లోపల ఇంకో క్లాస్ ని రాయడాన్నే Inner Class అంటారు. లోపల ఉన్న క్లాస్ కి బయట క్లాస్ లో ఉన్న ప్రతిదీ (ప్రైవేట్ ఉన్నవి కూడా) యాక్సెస్ ఉంటుంది:

class Engine {
    private int horsepower = 400;

class TurboCharger {              // ఇది ఇన్నర్ క్లాస్
        void boost() {
            System.out.println("బూస్టింగ్ " + horsepower + " HP ఇంజిన్!"); // ప్రైవేట్ ది కూడా వాడుకుంది!
        }
    }
}


Engine engine = new Engine();
// ఇన్నర్ క్లాస్ ఆబ్జెక్ట్ కావాలంటే బయటి ఆబ్జెక్ట్ ఉండి తీరాలి
Engine.TurboCharger turbo = engine.new TurboCharger(); 
turbo.boost();

4. Java Enums: తప్పులు చేయకుండా ఆపే సూపర్ పవర్

Enum అంటే కొన్ని ఫిక్స్డ్ వాల్యూస్ ని సేవ్ చేసుకోవడానికి వాడే ఒక స్పెషల్ క్లాస్. ఇది వాడితే మనం స్పెల్లింగ్ తప్పులు రాసి బగ్స్ తెచ్చుకునే బాధ తప్పుతుంది:

// Enum వాడకపోతే: ఎవరైనా ఇలా తప్పు స్పెల్లింగ్ రాసినా జావా పట్టుకోలేదు!
String day = "MONDAI";

// Enum వాడితే: ఇవి తప్ప వేరేది రాయలేరు!
enum Day { MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY }
Day today = Day.MONDAY; // జావా కంపైలర్ పర్ఫెక్ట్ గా చెక్ చేస్తుంది!

Enums లో కూడా వేరియబుల్స్, కన్స్ట్రక్టర్స్ రాయొచ్చు తెలుసా!

enum Planet {
    MERCURY(3.303e+23, 2.4397e6),
    EARTH  (5.976e+24, 6.37814e6);


private final double mass;
    private final double radius;


Planet(double mass, double radius) {
        this.mass = mass;
        this.radius = radius;
    }
}

// Enum క్రియేట్ చేస్తున్నాం
enum OrderStatus {
    PENDING("ఆర్డర్ రిసీవ్ అయ్యింది, వెయిటింగ్"),
    PROCESSING("ఆర్డర్ ప్యాక్ చేస్తున్నారు"),
    SHIPPED("ఆర్డర్ బయలుదేరింది"),
    DELIVERED("కస్టమర్ కి డెలివరీ అయిపొయింది"),
    CANCELLED("ఆర్డర్ క్యాన్సిల్ చేసారు");

    private final String description;

    OrderStatus(String description) {
        this.description = description;
    }

    public String getDescription() {
        return description;
    }
}

class ShoppingCart {
    // Static ఫీల్డ్: అందరికీ కామన్ కౌంటర్
    static int totalCartsCreated = 0;
    static final double TAX_RATE  = 0.18; // 18% GST అందరికీ ఒకటే

    // Static ఇనిషియలైజర్ బ్లాక్
    static {
        System.out.println("  [క్లాస్ లోడ్ అయ్యింది] షాపింగ్ కార్ట్ రెడీ. టాక్స్ రేటు: " + (TAX_RATE * 100) + "%");
    }

    String customerId;
    double subtotal;
    OrderStatus status;

    ShoppingCart(String customerId, double subtotal) {
        this.customerId = customerId;
        this.subtotal   = subtotal;
        this.status     = OrderStatus.PENDING; // డిఫాల్ట్ గా వెయిటింగ్ లో పెడతాం
        ShoppingCart.totalCartsCreated++; // కౌంటర్ పెంచుతున్నాం
    }

    double calculateTotalWithTax() {
        return subtotal * (1 + TAX_RATE);
    }

    void updateStatus(OrderStatus newStatus) {
        this.status = newStatus;
    }

    void displayOrderSummary() {
        System.out.printf("  కస్టమర్: %-10s | సబ్-టోటల్: $%7.2f | టోటల్+టాక్స్: $%7.2f | స్టేటస్: %s%n",
                customerId, subtotal, calculateTotalWithTax(), status.name());
        System.out.println("    -> " + status.getDescription());
    }

    // Static Nested Class (దీనికి బయటి ఆబ్జెక్ట్ తో పనిలేదు)
    static class TaxCalculator {
        static double computeGST(double amount) {
            return amount * TAX_RATE;
        }
    }
}

public class Main {
    public static void main(String[] args) {
        System.out.println("=== 1. Static బ్లాక్ & ఆబ్జెక్ట్స్ ===");
        ShoppingCart cart1 = new ShoppingCart("CUST-001", 499.99);
        ShoppingCart cart2 = new ShoppingCart("CUST-002", 1200.00);

        System.out.println("మొత్తం ఎన్ని కార్ట్స్ క్రియేట్ అయ్యాయి: " + ShoppingCart.totalCartsCreated);

        System.out.println("
=== 2. Order Status Enum ఎలా మారుతుందో చూద్దాం ===");
        cart1.displayOrderSummary();
        cart1.updateStatus(OrderStatus.PROCESSING);
        cart1.displayOrderSummary();
        cart1.updateStatus(OrderStatus.SHIPPED);
        cart1.displayOrderSummary();

        System.out.println("
=== 3. Enum లో ఏమేమి ఉన్నాయో లిస్ట్ చేయడం (values() వాడి) ===");
        System.out.println("అందుబాటులో ఉన్న స్టేటస్ లు:");
        for (OrderStatus s : OrderStatus.values()) {
            System.out.printf("  %-12s [#%d] -> %s%n", s.name(), s.ordinal(), s.getDescription());
        }

        System.out.println("
=== 4. Static Nested Class వాడుక ===");
        double gst = ShoppingCart.TaxCalculator.computeGST(cart2.subtotal);
        System.out.printf("  $%.2f మీద GST ఎంతంటే = $%.2f%n", cart2.subtotal, gst);

        System.out.println("
=== 5. Enum ని switch లో వాడటం ===");
        OrderStatus current = OrderStatus.DELIVERED;
        String message = switch (current) {
            case PENDING    -> "మీ ఆర్డర్ క్యూలో ఉంది.";
            case PROCESSING -> "మీ వస్తువులు ప్యాక్ అవుతున్నాయి!";
            case SHIPPED    -> "మీ ఆర్డర్ బయలుదేరింది!";
            case DELIVERED  -> "ఎంజాయ్ యార్!";
            case CANCELLED  -> "క్యాన్సిల్ అయిపొయింది కదరా.";
        };
        System.out.println("  స్టేటస్ మెసేజ్: " + message);
    }
}

🔍 Line-by-Line Code Explanation

static int totalCartsCreated = 0;

ఇది ఒక్కటే ఉంటుంది. ఏ ఆబ్జెక్ట్ క్రియేట్ అయినా ఈ కౌంటర్ నే పెంచుతాయి.

static { System.out.println(...) }

క్లాస్ రన్ అయిన ఫస్ట్ సెకన్ లోనే ఇది రన్ అయ్యి ప్రింట్ అవుతుంది.

enum OrderStatus { PENDING(...), ... }

ఇవి ఫైనల్ గా ఉన్న ఫిక్స్డ్ వాల్యూస్. ఇవి తప్ప వేరేవేవీ ఈ వేరియబుల్ కి ఎసైన్ చేయలేము.

OrderStatus.values()

జావా ఎనమ్స్ లోపల ఉన్న వాల్యూస్ అన్నీ ఒక అరే లాగా రిటర్న్ చేసే ఇన్-బిల్ట్ మెథడ్ ఇది.

static class TaxCalculator

ఇది Nested క్లాస్, పైగా స్టాటిక్. కాబట్టి దీన్ని బయట నుంచి పిలవడానికి ShoppingCart ఆబ్జెక్ట్ అవసరం లేదు.

Practical Real-World Example

☕ PracticalApplication.java — Industry Implementation 
enum UserRole { ADMIN, MANAGER, EMPLOYEE, GUEST }

class Employee {
    static int headcount = 0;
    String name;
    double salary;
    UserRole role;

    Employee(String name, double salary, UserRole role) {
        this.name   = name;
        this.salary = salary;
        this.role   = role;
        headcount++;
    }

    void displayInfo() {
        System.out.printf("  %-14s | రోల్: %-8s | శాలరీ: $%,.2f%n", name, role, salary);
    }
}

public class PracticalApplication {
    public static void main(String[] args) {
        Employee e1 = new Employee("Ravi Kumar",   85000, UserRole.MANAGER);
        Employee e2 = new Employee("Priya Devi",   62000, UserRole.EMPLOYEE);
        Employee e3 = new Employee("Admin Singh", 110000, UserRole.ADMIN);

        System.out.println("=== HR పోర్టల్ — ఎంప్లాయీ లిస్ట్ ===");
        e1.displayInfo(); e2.displayInfo(); e3.displayInfo();
        System.out.println("మొత్తం ఎంప్లాయీస్ (Headcount) : " + Employee.headcount);
    }
}

⚠️ Common Mistakes & Professional Best Practices
  • స్టాటిక్ వేరియబుల్ ని ఆబ్జెక్ట్ పేరుతో పిలవడం (s1.totalCount). ఇది రన్ అవుతుంది కానీ చూడటానికి తప్పుగా ఉంటుంది, క్లాస్ పేరుతోనే (Student.totalCount) పిలవాలి.
  • స్టాటిక్ మెథడ్ లోపల this వాడదామని ట్రై చేయడం. (స్టాటిక్ కి ఆబ్జెక్ట్ తో సంబంధం లేదు కాబట్టి ఎర్రర్ వస్తుంది).
  • Enums వాడకుండా డేంజర్ గా ఉండే స్ట్రింగ్స్ ని వాడి స్టేటస్ మెయింటైన్ చేయడం (status = "Pendin" అని స్పెల్లింగ్ తప్పు రాస్తే గోవిందా!).

// Coding Challenge:
// Season అనే ఒక ఎనమ్ (Enum) క్రియేట్ చేయండి. అందులో SPRING, SUMMER, MONSOON, WINTER ఉండాలి.
// ప్రతి ఎనమ్ కి ఒక String activity (ఉదా: SUMMER కి "స్విమ్మింగ్"), getRecommendation() మెథడ్ ఉండాలి.
// వాటన్నింటినీ ఒక లూప్ లో ప్రింట్ చేయండి.

enum Season {
    SPRING("సైక్లింగ్ అండ్ పిక్నిక్"),
    SUMMER("స్విమ్మింగ్ అండ్ వాటర్ స్పోర్ట్స్"),
    MONSOON("ట్రెక్కింగ్ అండ్ వేడి బజ్జీలు"),
    WINTER("స్కీయింగ్ అండ్ కాఫీ");

    private final String activity;
    Season(String activity) { this.activity = activity; }

    public String getRecommendation() {
        return name() + ": " + activity;
    }
}

public class Challenge {
    public static void main(String[] args) {
        for (Season s : Season.values()) {
            System.out.println(s.getRecommendation());
        }
    }
}

💡 Frequently Asked Questions & Interview Insights

❓ స్టాటిక్ ఎప్పుడు వాడాలి, మామూలు (ఇన్స్టాన్స్) ఎప్పుడు వాడాలి?

అందరికీ కామన్ గా ఉండే డేటాకి (ఉదా: స్కూల్ పేరు, టోటల్ కౌంట్, టాక్స్ రేట్) `static` వాడాలి. ఎవరికీ వాళ్లకే సపరేట్ గా ఉండే వాటికి (పేరు, వయసు, బ్యాలెన్స్) మామూలువి వాడాలి.

❓ Static Nested Class కి, మామూలు Inner Class కి తేడా ఏంటి?

స్టాటిక్ క్లాస్ బయటి క్లాస్ ఆబ్జెక్ట్ మీద ఆధారపడదు, అది స్వతంత్రంగా బ్రతుకుతుంది. కానీ ఇన్నర్ క్లాస్ రన్ అవ్వాలంటే కచ్చితంగా బయట ఒక ఆబ్జెక్ట్ ఉండి తీరాలి. అది బయటి ప్రైవేట్ డేటాని కూడా యాక్సెస్ చేయగలదు.

❓ Enum లో వేరు వేరు కన్స్ట్రక్టర్స్ వాడొచ్చా?

లేదు, ఎనమ్ లో అన్నీ ఒకే టైప్ కన్స్ట్రక్టర్ ని ఫాలో అవ్వాలి (ఓవర్ లోడ్ చేయొచ్చు, కానీ అంత రిస్క్ అవసరం లేదు).

🚀 Quick Chapter Recap

  • static అంటే అందరికీ షేర్ చేయబడే ఒకే కాపీ (క్లాస్ ఏరియాలో ఉంటుంది).
  • Static Block అనేది క్లాస్ లోడ్ అవ్వగానే ఒక్కసారే రన్ అయ్యి ఆగిపోతుంది.
  • ఒక క్లాస్ లోపల ఇంకో క్లాస్ రాయొచ్చు (Inner / Nested Classes).
  • తప్పులు చేయకుండా ఫిక్స్డ్ ఆప్షన్స్ ని మాత్రమే వాడుకోవడానికి Enums అద్భుతంగా పనిచేస్తాయి.
  • Enum.values() తో ఎనమ్స్ అన్నింటినీ అరే లాగా వాడుకోవచ్చు.
