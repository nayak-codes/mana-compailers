Java Array Sorting, Copying & java.util.Arrays (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 30 of 47 📂 Phase 7: Arrays & Matrices 📅 2026 Edition
📌 Covered in this chapter:

In-Place Array Reversal · Bubble Sort Algorithm · Arrays.sort() Internals (Dual-Pivot Quicksort) · 4 Array Copying Techniques · System.arraycopy() vs Arrays.copyOf() · Shallow vs Deep Copy · Arrays.fill(), Arrays.equals(), Arrays.mismatch()

అరే ని రివర్స్ చేయడం ఎలా? Bubble Sort లాంటి బేసిక్ సార్టింగ్ ఎలా పనిచేస్తుంది? జావాలో ముందే ఉన్న `Arrays.sort()` వెనక ఉన్న సీక్రెట్ ఏంటి? ఒక అరే ని ఇంకో అరే లోకి కాపీ చేయాలంటే `=` వాడితే ఎందుకు తప్పు వస్తుంది? ఇలాంటి బేసిక్ కానీ చాలా పవర్ఫుల్ కాన్సెప్ట్స్ మరియు `java.util.Arrays` క్లాస్ గురించి క్లియర్ గా తెలుసుకుందాం.

1. అరే ని రివర్స్ చేయడం (కొత్త మెమరీ వాడకుండా)

ఒక అరే ని రివర్స్ చేయాలంటే కొత్త అరే క్రియేట్ చేసి వెనకనుంచి కాపీ చేయొచ్చు. కానీ అది మెమరీ వేస్ట్. దానికి బదులు Two-Pointer టెక్నిక్ వాడితే అసలు మెమరీ వాడకుండానే (In-Place) రివర్స్ అయిపోతుంది:

int left = 0, right = arr.length - 1;
while (left < right) {
    // లెఫ్ట్ లో ఉన్నదాన్ని రైట్ కి, రైట్ లో ఉన్నదాన్ని లెఫ్ట్ కి స్వాప్ (Swap) చేస్తున్నాం
    int temp = arr[left];
    arr[left] = arr[right];
    arr[right] = temp;
    
    left++;  // లెఫ్ట్ ది ఒక అడుగు ముందుకి
    right--; // రైట్ ది ఒక అడుగు వెనక్కి (సగం వరకు రాగానే ఆగిపోతాయి)
}
- ఇది చాలా ఫాస్ట్ గా ఉంటుంది ($O(N)$ టైమ్). - ఏ కొత్త అరే క్రియేట్ చేయలేదు కాబట్టి మెమరీ అసలు వాడలేదు ($O(1)$ స్పేస్).

2. బబుల్ సార్ట్ (Bubble Sort) ఎలా పనిచేస్తుంది?

Bubble Sort అంటే పక్కపక్కన ఉన్న రెండు నంబర్స్ ని చూసి.. అందులో ఏది పెద్దదైతే దాన్ని రైట్ సైడ్ కి తోసుకుంటూ వెళ్లడం. ఇలా ఒక్కో రౌండ్ కి అరే లో ఉన్న అన్నిటికన్నా పెద్ద నంబర్ బుడగ లాగా లాస్ట్ కి చేరిపోతుంది:

రౌండ్ 1: [5, 1, 4, 2, 8] -> [1, 5, 4, 2, 8] -> [1, 4, 5, 2, 8] -> [1, 4, 2, 5, 8] (8 కరెక్ట్ ప్లేస్ కి వెళ్ళిపోయింది)
  రౌండ్ 2: [1, 4, 2, 5, 8] -> [1, 2, 4, 5, 8] (5 కరెక్ట్ ప్లేస్ కి వెళ్ళిపోయింది)
  రౌండ్ 3: అరే మొత్తం సార్ట్ అయిపొయింది!

- ఇది చాలా బేసిక్ సార్టింగ్. అర్థం చేసుకోవడానికి బాగుంటుంది కానీ పెద్ద డేటా ఇస్తే చాలా స్లో ($O(N^2)$ టైమ్).

3. అరే ని కాపీ చేయడానికి ఉన్న 4 పద్ధతులు

జావాలో మీరు int[] copy = original; అని రాస్తే అరే కాపీ అయిపోయింది అనుకుంటారు. కానీ అది కాపీ కాదు! జస్ట్ ఒకే అరే కి ఇంకో పేరు పెట్టినట్టు అవుతుంది. మీరు copy లో ఏదైనా మారిస్తే original లో కూడా మారిపోతుంది. అసలైన డూప్లికేట్ కావాలంటే ఈ 4 పద్ధతులు వాడాలి:

పద్ధతి (Method) సింటాక్స్ (Syntax) డీటెయిల్స్
1. మ్యాన్యువల్ లూప్ for (int i=0; i<len; i++) copy[i] = orig[i]; లూప్ వేసి మనమే ఒక్కొక్కటి కాపీ చేయడం (సింపుల్).
2. System.arraycopy() System.arraycopy(src, 0, dest, 0, len); సూపర్ ఫాస్ట్ (ఇది డైరెక్ట్ గా ర్యామ్ లో కాపీ కొట్టేస్తుంది, టైమ్ అస్సలు పట్టదు).
3. Arrays.copyOf() int[] copy = Arrays.copyOf(orig, newLength); కాపీతో పాటు ఒకేసారి అరే సైజు ని కూడా పెంచుకోవచ్చు.
4. clone() int[] copy = orig.clone(); ఇది పాత పద్ధతి. ఉన్న అరే కి ఎగ్జాక్ట్ క్లోన్ క్రియేట్ చేస్తుంది.

4. java.util.Arrays క్లాస్ పవర్ ఏంటి?

అరేస్ ని ఈజీగా మేనేజ్ చేయడానికి జావా వల్లే java.util.Arrays అనే క్లాస్ లో కొన్ని రెడీమేడ్ మెథడ్స్ ఇచ్చారు:

- Arrays.toString(arr): అరే ని నీట్ గా బ్రాకెట్స్ లో "[1, 2, 3]" అని ప్రింట్ చేస్తుంది.
- Arrays.sort(arr): చాలా ఫాస్ట్ గా సార్ట్ చేస్తుంది.
- Arrays.fill(arr, val): అరే మొత్తం ఒకే నంబర్ తో నింపేయాలంటే ఇది వాడాలి.
- Arrays.equals(arr1, arr2): రెండు అరేస్ లో డేటా సేమ్ ఉందా లేదా అని చెక్ చేస్తుంది.
- Arrays.mismatch(arr1, arr2): (Java 9+) రెండు అరేస్ ఎక్కడ (ఏ ఇండెక్స్ దగ్గర) డిఫరెంట్ గా ఉన్నాయో ఆ నంబర్ ఇస్తుంది.
- Arrays.compare(arr1, arr2): (Java 9+) ఏ అరే పెద్దదో చెక్ చేస్తుంది.

Beginner Example & Code Anatomy

☕ Main.java — Chapter 30 Core Example 
import java.util.Arrays;

public class Main {
    // బబుల్ సార్ట్ (సార్ట్ అయిపోగానే ఆగిపోయేలా ఆప్టిమైజ్ చేసాం)
    public static void bubbleSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            boolean swapped = false;
            for (int j = 0; j < n - 1 - i; j++) {
                if (arr[j] > arr[j + 1]) {
                    // స్వాప్ చేయడం
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                    swapped = true;
                }
            }
            if (!swapped) break; // ముందే సార్ట్ అయిపోతే అనవసరంగా లూప్ తిరగకుండా ఆపేస్తాం
        }
    }

    // టూ-పాయింటర్ వాడి ఇన్-ప్లేస్ లో రివర్స్ చేయడం
    public static void reverseArray(int[] arr) {
        int left = 0, right = arr.length - 1;
        while (left < right) {
            int temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;
            left++;
            right--;
        }
    }

    public static void main(String[] args) {
        System.out.println("=== 1. ఇన్-ప్లేస్ రివర్స్ (మెమరీ సేవ్) ===");
        int[] numbers = {10, 20, 30, 40, 50};
        System.out.println("ఒరిజినల్ అరే           : " + Arrays.toString(numbers));
        reverseArray(numbers);
        System.out.println("రివర్స్ చేసిన తర్వాత     : " + Arrays.toString(numbers));

        System.out.println("
=== 2. బబుల్ సార్ట్ (Bubble Sort) ===");
        int[] unsorted = {64, 34, 25, 12, 22, 11, 90};
        System.out.println("సార్టింగ్ కి ముందు      : " + Arrays.toString(unsorted));
        bubbleSort(unsorted);
        System.out.println("సార్ట్ చేసిన తర్వాత      : " + Arrays.toString(unsorted));

        System.out.println("
=== 3. అరే కాపీ చేయడానికి పద్ధతులు ===");
        int[] original = {100, 200, 300, 400};

        // టెక్నిక్ 1: Arrays.copyOf()
        int[] copyA = Arrays.copyOf(original, original.length);

        // టెక్నిక్ 2: System.arraycopy() (ఇది ఫాస్టెస్ట్)
        int[] copyB = new int[original.length];
        System.arraycopy(original, 0, copyB, 0, original.length);

        // టెక్నిక్ 3: clone()
        int[] copyC = original.clone();

        System.out.println("Arrays.copyOf తో కాపీ : " + Arrays.toString(copyA));
        System.out.println("arraycopy() తో కాపీ   : " + Arrays.toString(copyB));
        System.out.println("clone() తో కాపీ       : " + Arrays.toString(copyC));

        System.out.println("
=== 4. Arrays రెడీమేడ్ మెథడ్స్ ===");
        System.out.println("రెండు అరేస్ ఒకటేనా? (equals) : " + Arrays.equals(copyA, copyB)); // true

        int[] fillArray = new int[5];
        Arrays.fill(fillArray, 7); // మొత్తం 7 తో నింపేస్తుంది
        System.out.println("Arrays.fill(..., 7) వాడితే  : " + Arrays.toString(fillArray));

        // 1 నుంచి 3 వరకు మాత్రమే కట్ చేసి కొత్త అరే ఇస్తుంది (3 రాదు, దాని ముందు వరకే)
        int[] rangeCopy = Arrays.copyOfRange(original, 1, 3);
        System.out.println("Arrays.copyOfRange(1,3)     : " + Arrays.toString(rangeCopy));
    }
}

🔍 Line-by-Line Code Explanation

reverseArray(numbers);

టూ-పాయింటర్ టెక్నిక్ వాడి లెఫ్ట్, రైట్ ఎలిమెంట్స్ ని స్వాప్ చేయడం వల్ల, కొత్త అరే క్రియేట్ చేయకుండానే అరే ఉల్టా అయిపోయింది.

System.arraycopy(original, 0, copyB, 0, original.length);

ఇది జావాలో అన్నిటికన్నా ఫాస్ట్ గా కాపీ చేసే పద్ధతి. ఎందుకంటే ఇది డైరెక్ట్ గా ఆపరేటింగ్ సిస్టమ్ ర్యామ్ లో కాపీ కొడుతుంది.

Arrays.copyOf(original, original.length);

ఇది చాలా సింపుల్ గా ఉంటుంది. కొత్త అరే క్రియేట్ చేసి కాపీ అంతా ఇదే చేసేస్తుంది.

Arrays.fill(fillArray, 7);

లక్ష సైజు ఉన్న అరే లో అన్నీ ఒకే వాల్యూ తో నింపాలంటే లూప్ వేయకుండా సింపుల్ గా దీన్ని వాడొచ్చు.

Arrays.equals(copyA, copyB);

రెండు అరేస్ లో డేటా సేమ్ ఉందా లేదా అని పర్ఫెక్ట్ గా చెక్ చేసి true లేదా false చెప్తుంది.

Practical Real-World Example

☕ PracticalApplication.java — Industry Implementation 
public class PracticalApplication {
    public static void main(String[] args) {
        // రియల్ టైమ్ సినారియో: సర్వర్ బఫర్ సైజు ని పెంచడం (Dynamic Expansion)
        int[] buffer = {10, 20, 30};
        System.out.println("స్టార్టింగ్ బఫర్ (సైజు 3): " + Arrays.toString(buffer));

        // కొత్త డేటా వచ్చింది కానీ అరే ఫుల్ అయిపొయింది, ఇప్పుడు సైజు డబుల్ చేయాలి
        int[] expandedBuffer = Arrays.copyOf(buffer, buffer.length * 2);
        // పాతవి అన్నీ వచ్చేసాయి, ఇప్పుడు కొత్తవి యాడ్ చేద్దాం
        expandedBuffer[3] = 40;
        expandedBuffer[4] = 50;

        System.out.println("పెంచిన బఫర్ (సైజు 6)   : " + Arrays.toString(expandedBuffer));
    }
}

⚠️ Common Mistakes & Professional Best Practices
  • int[] b = a; అని రాసి అరే కాపీ అయిపోయింది అనుకోవడం. ఇది కాపీ కాదు, జస్ట్ రిమోట్ కంట్రోల్ (Reference) పాస్ చేసినట్టు అంతే. ఒకదాంట్లో మారిస్తే ఇంకోదాంట్లో మారుతుంది.
  • రెండు అరేస్ ని a.equals(b) అని చెక్ చేయడం. స్ట్రింగ్స్ కి ఇది కరెక్టే కానీ, అరేస్ కి ఎప్పుడూ Arrays.equals(a, b) వాడాలి. లేకపోతే అడ్రెస్ లు చెక్ చేసి ఎప్పుడూ false ఇస్తుంది.
  • అరే ని డైరెక్ట్ గా System.out.println(arr) అని ప్రింట్ చేయడం. అలా చేస్తే [I@1b6d3586 లాంటి పిచ్చి అడ్రెస్ ప్రింట్ అవుతుంది. ఎప్పుడూ Arrays.toString(arr) వాడాలి.
  • Arrays.copyOfRange(arr, 1, 4) వాడినప్పుడు 4 కూడా వస్తుందని కన్ఫ్యూజ్ అవ్వడం. ఎప్పుడైనా ఎండింగ్ ఇండెక్స్ ఇంక్లూడ్ అవ్వదు (దాని ముందు వరకే కట్ అవుతుంది).

// Coding Challenge:
// మీ దగ్గర సార్ట్ చేసి ఉన్న ఒక అరే ఉంది. అందులో ఒకే నంబర్ చాలాసార్లు రిపీట్ అయ్యింది: {1, 1, 2, 2, 3, 4, 4, 5}.
// 1. దాన్ని అదే అరే లోపల క్లీన్ చేసి డూప్లికేట్స్ తీసేయాలి (O(N) టైమ్ లో).
// 2. కొత్తగా ఎన్ని యూనిక్ నంబర్స్ ఉన్నాయో ఆ కౌంట్ ని రిటర్న్ చేయాలి.

public class Challenge {
    public static int removeDuplicates(int[] arr) {
        if (arr.length == 0) return 0;
        int uniqueIdx = 0;
        for (int i = 1; i < arr.length; i++) {
            if (arr[i] != arr[uniqueIdx]) {
                uniqueIdx++;
                arr[uniqueIdx] = arr[i]; // పాత దాని ప్లేస్ లో యూనిక్ నంబర్ తో రీప్లేస్ చేస్తున్నాం
            }
        }
        return uniqueIdx + 1; // యూనిక్ నంబర్స్ కౌంట్
    }

    public static void main(String[] args) {
        int[] sorted = {1, 1, 2, 2, 3, 4, 4, 5};
        int newLength = removeDuplicates(sorted);
        System.out.println("యూనిక్ కౌంట్ : " + newLength);
        System.out.print("యూనిక్ అరే   : ");
        for (int i = 0; i < newLength; i++) {
            System.out.print(sorted[i] + " ");
        }
        System.out.println();
    }
}

💡 Frequently Asked Questions & Interview Insights

❓ System.out.println(new int[]{1,2,3}) అని రాస్తే [I@6d06d69c లాంటి చెత్త ఎందుకు వస్తుంది?

ఎందుకంటే అరేస్ కి జావాలో డీఫాల్ట్ గా `toString()` అనే మెథడ్ ఆబ్జెక్ట్ అడ్రెస్ (హ్యాష్ కోడ్) ని ప్రింట్ చేసేలా సెట్ చేసి ఉంటుంది. అందులో `[I` అంటే ఇంటిజర్ అరే అని, `@` తర్వాత ఉండేది దాని అడ్రెస్ అని అర్థం. వాల్యూస్ కావాలంటే `Arrays.toString(arr)` ఏ వాడాలి.

❓ Arrays.sort() అనేది లోపల ఏ అల్గారిథమ్ ని వాడుతుంది?

నార్మల్ నంబర్స్ (int, double లాంటివి) ఇస్తే **Dual-Pivot Quicksort** ని వాడుతుంది (ఇది చాలా ఫాస్ట్). అదే Objects (String లాంటివి) ఇస్తే **Timsort** ని వాడుతుంది.

❓ అన్నిటికన్నా ఫాస్ట్ గా కాపీ చేసే పద్ధతి ఏది?

`System.arraycopy()` అనేది దేనికైనా కింగ్. ఎందుకంటే ఇది జావా కోడ్ కాదు, డైరెక్ట్ గా C/C++ లో రాసిన నేటివ్ సిస్టమ్ కాల్. ఇది ర్యామ్ లో అమాంతం డేటాని తీసుకెళ్లి కాపీ కొడుతుంది.

🚀 Quick Chapter Recap

  • రివర్స్ చేయడానికి టూ-పాయింటర్ టెక్నిక్ వాడితే మెమరీ ఫుల్ గా సేవ్ అవుతుంది.
  • int[] b = a; రాస్తే డేటా కాపీ అవ్వదు, కేవలం లింక్ క్రియేట్ అవుతుంది. నిజంగా కాపీ కావాలంటే Arrays.copyOf() వాడాలి.
  • అరేస్ ని ప్రింట్ చేయడానికి, కంపేర్ చేయడానికి ఎప్పుడూ Arrays క్లాస్ లోని మెథడ్స్ ఏ వాడాలి.
  • Arrays.sort() అనేది ప్రపంచంలోనే అత్యంత ఫాస్ట్ అయిన సార్టింగ్ అల్గారిథమ్స్ ని ఇంటర్నల్ గా వాడుకుంటుంది.
  • System.arraycopy() వాడితే సూపర్ ఫాస్ట్ గా మెమరీ కాపీ జరుగుతుంది.
