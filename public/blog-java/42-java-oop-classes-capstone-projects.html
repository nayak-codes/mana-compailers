Java OOP Capstone Projects: 4 Production-Grade Class Systems (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 42 of 47 📂 Phase 9: Classes & Objects 📅 2026 Edition
📌 Covered in this chapter:

Project 1: Student Management System · Project 2: Book Library System · Project 3: Product Inventory Manager · Project 4: Bank Account Application · OOP Design Principles Review

ఇప్పటివరకు నేర్చుకున్న జావా ఆబ్జెక్ట్ ఓరియెంటెడ్ ప్రోగ్రామింగ్ (OOP) మొత్తాన్ని వాడి 4 ఇండస్ట్రీ-లెవెల్ ప్రాజెక్ట్స్ క్రియేట్ చేద్దాం. స్టూడెంట్స్ సిస్టమ్, లైబ్రరీలో బుక్స్ మేనేజ్మెంట్, ప్రొడక్ట్ ఇన్వెంటరీ, ఇంకా ట్రాన్సాక్షన్స్ తో కూడిన బ్యాంక్ అకౌంట్ యాప్. ఇందులో ఎన్క్యాప్సులేషన్, కన్స్ట్రక్టర్స్, ఎనమ్స్ అన్నీ పర్ఫెక్ట్ గా వాడబోతున్నాం.

1. ఈ ప్రాజెక్ట్స్ లో మనం వాడుతున్న OOP రూల్స్

కోడ్ రాసేముందు, ప్రొఫెషనల్ గా ఈ 4 ప్రాజెక్ట్స్ ఎలా డిజైన్ చేసామో చూద్దాం:

1. Encapsulation (ఎన్క్యాప్సులేషన్): ఫీల్డ్స్ అన్నీ కచ్చితంగా private లో పెట్టి గెట్టర్స్, సెట్టర్స్ వాడాం.
2. Constructor Overloading: ఆబ్జెక్ట్ క్రియేట్ చేయడానికి రకరకాల ఆప్షన్స్ (కన్స్ట్రక్టర్స్) ఇచ్చాం.
3. Static Members (స్టాటిక్): ఐడీలు (STU-001) ఆటోమాటిక్ గా జనరేట్ అవ్వడానికి స్టాటిక్ కౌంటర్స్ వాడాం.
4. toString() Override: ఆబ్జెక్ట్ ని డైరెక్ట్ గా ప్రింట్ చేస్తే అందంగా వచ్చేలా డిజైన్ చేసాం.
5. Enums: స్టేటస్ లు (యాక్టివ్, క్యాన్సిల్) లాంటి వాటికి స్పెల్లింగ్ మిస్టేక్స్ రాకుండా Enums వాడాం.
6. Single Responsibility: ఒక క్లాస్ ఒక పనే చేస్తుంది (బ్యాంక్ బ్యాంక్ పనే చేస్తుంది, బుక్ బుక్ పనే చూసుకుంటుంది).

import java.util.Arrays;

// =====================================================================
// ప్రాజెక్ట్ 1: స్టూడెంట్ మేనేజ్మెంట్ సిస్టమ్
// =====================================================================
class Student {
    private static int totalStudents = 0; // అందరికీ కామన్ కౌంటర్

    enum AcademicStatus { ACTIVE, ON_LEAVE, GRADUATED, EXPELLED }

    private final String studentId; // ఐడీ ఎప్పటికీ మారకూడదు
    private String name;
    private int age;
    private double gpa;
    private AcademicStatus status;

    Student(String name, int age, double gpa) {
        totalStudents++;
        // ఆటోమాటిక్ గా STU-0001, STU-0002 అని ఐడీలు వస్తాయి
        this.studentId = String.format("STU-%04d", totalStudents);
        setName(name);
        setAge(age);
        setGpa(gpa);
        this.status = AcademicStatus.ACTIVE;
    }

    public static int getTotalStudents() { return totalStudents; }
    public String getName()    { return name; }
    public double getGpa()     { return gpa; }
    public AcademicStatus getStatus() { return status; }

    // సెట్టర్స్ విత్ వాలిడేషన్
    public void setName(String name) {
        if (name == null || name.isBlank()) throw new IllegalArgumentException("పేరు కచ్చితంగా కావాలి!");
        this.name = name.trim();
    }
    public void setAge(int age) {
        if (age < 15 || age > 80) throw new IllegalArgumentException("వయసు తప్పు: " + age);
        this.age = age;
    }
    public void setGpa(double gpa) {
        if (gpa < 0.0 || gpa > 4.0) throw new IllegalArgumentException("GPA 0 నుంచి 4 వరకే");
        this.gpa = gpa;
    }
    public void setStatus(AcademicStatus status) { this.status = status; }

    @Override
    public String toString() {
        return String.format("[%s] %-18s | వయసు: %2d | GPA: %.2f | స్టేటస్: %s",
                studentId, name, age, gpa, status);
    }
}

class Book {
    enum Genre { FICTION, NON_FICTION, SCIENCE, TECHNOLOGY, HISTORY, BIOGRAPHY }

    private final String isbn;
    private String title;
    private String author;
    private double price;
    private int availableCopies;
    private Genre genre;

    Book(String isbn, String title, String author, double price, int copies, Genre genre) {
        this.isbn            = isbn;
        this.title           = title;
        this.author          = author;
        this.price           = price;
        this.availableCopies = copies;
        this.genre           = genre;
    }

    public boolean isAvailable()       { return availableCopies > 0; }
    public String getTitle()           { return title; }
    public String getAuthor()          { return author; }
    public int getAvailableCopies()    { return availableCopies; }

    // బుక్ అద్దెకి ఇవ్వడం
    public boolean checkOut() {
        if (!isAvailable()) return false; // బుక్స్ లేకపోతే ఫాల్స్
        availableCopies--;
        return true;
    }

    // బుక్ తిరిగి ఇవ్వడం
    public void returnBook() { availableCopies++; }

    @Override
    public String toString() {
        return String.format("[%s] %-30s రాసింది: %-18s | రకం: %-11s | బుక్స్: %d | దొరుకుతుందా: %b",
                isbn, title, author, genre, availableCopies, isAvailable());
    }
}

// =====================================================================
class Product {
    enum Category { ELECTRONICS, CLOTHING, FOOD, SPORTS, FURNITURE }

    private static int productCount = 0;
    private final String productId;
    private String name;
    private double price;
    private int stock;
    private Category category;

    Product(String name, double price, int stock, Category category) {
        productCount++;
        this.productId = String.format("PRD-%03d", productCount);
        this.name      = name;
        this.price     = price;
        this.stock     = stock;
        this.category  = category;
    }

    public static int getProductCount() { return productCount; }
    public String getName()   { return name; }
    public double getPrice()  { return price; }
    public int getStock()     { return stock; }

    // స్టాక్ అమ్ముడుపోవడం
    public boolean sellUnits(int qty) {
        if (qty <= 0 || qty > stock) return false;
        stock -= qty;
        return true;
    }

    // కొత్త స్టాక్ రావడం
    public void restock(int qty) {
        if (qty > 0) stock += qty;
    }

    @Override
    public String toString() {
        return String.format("[%s] %-25s | $%7.2f | స్టాక్: %3d | రకం: %s",
                productId, name, price, stock, category);
    }
}

// ప్రాజెక్ట్ 4: బ్యాంక్ అకౌంట్ యాప్ (ట్రాన్సాక్షన్స్ తో సహా)
// =====================================================================
class BankAccount {
    enum AccountType { SAVINGS, CURRENT, FIXED_DEPOSIT }

    private static int accountSerial = 1000;
    private final String accountNumber;
    private String holderName;
    private double balance;
    private AccountType type;
    private int transactionCount;

    BankAccount(String holderName, double initialDeposit, AccountType type) {
        this.accountNumber   = "ACC-" + (++accountSerial);
        this.holderName      = holderName;
        this.balance         = Math.max(0, initialDeposit);
        this.type            = type;
        this.transactionCount = 1;
    }

    public String getAccountNumber() { return accountNumber; }
    public double getBalance()       { return balance; }

    public void deposit(double amount) {
        if (amount <= 0) throw new IllegalArgumentException("డిపాజిట్ మైనస్ లో ఉండకూడదు!");
        balance += amount;
        transactionCount++;
        System.out.printf("    + డిపాజిట్  $%8.2f | కొత్త బ్యాలెన్స్: $%10.2f%n", amount, balance);
    }

    public void withdraw(double amount) {
        if (amount <= 0 || amount > balance)
            throw new IllegalArgumentException("తప్పు అమౌంట్ లేదా బ్యాలెన్స్ లేదు: $" + amount);
        balance -= amount;
        transactionCount++;
        System.out.printf("    - విత్-డ్రా $%8.2f | కొత్త బ్యాలెన్స్: $%10.2f%n", amount, balance);
    }

    // ఇద్దరి మధ్య ట్రాన్స్ఫర్ (స్టాటిక్ మెథడ్)
    public static boolean transfer(BankAccount from, BankAccount to, double amount) {
        if (from.balance < amount) return false;
        from.balance -= amount;
        to.balance   += amount;
        from.transactionCount++;
        to.transactionCount++;
        return true;
    }

    @Override
    public String toString() {
        return String.format("[%s] %-15s | రకం: %-14s | బ్యాలెన్స్: $%10.2f | మొత్తం ట్రాన్సాక్షన్స్: %d",
                accountNumber, holderName, type, balance, transactionCount);
    }
}

Student.getTotalStudents()

public class PracticalApplication {
    public static void main(String[] args) {
        // 3 సెకన్లలో OOP పవర్ చూద్దాం
        System.out.println("=== 3-Second OOP క్రాష్ కోర్స్ ===");

        // ఒకేసారి 3 ఆబ్జెక్ట్స్ ని ఒక అరే లో క్రియేట్ చేస్తున్నాం
        Student[] batch = {
            new Student("Ravi",  19, 3.5),
            new Student("Priya", 20, 3.8),
            new Student("Kiran", 21, 3.9)
        };

        double totalGpa = 0;
        for (Student s : batch) {
            totalGpa += s.getGpa();
            System.out.println("  " + s);
        }
        System.out.printf("ఈ బ్యాచ్ ఆవరేజ్ GPA: %.2f%n", totalGpa / batch.length);
    }
}

⚠️ Common Mistakes & Professional Best Practices
  • ఆబ్జెక్ట్ తో సంబంధం ఉన్న withdraw() లాంటి పనులకి పొరపాటున static అని పెట్టడం. (ఎవరి అకౌంట్ లో డబ్బులు తీయాలో జావాకి ఎలా తెలుస్తుంది?)
  • ఐడీలకి final పెట్టకపోవడం. రేపు ఎవడైనా హ్యాకర్ వచ్చి ఐడీ మార్చేస్తే ఇరుక్కుపోతాం.
  • కొత్త ఆబ్జెక్ట్ క్రియేట్ చేసినప్పుడు కన్స్ట్రక్టర్ లో కౌంటర్ (count++) పెంచడం మర్చిపోవడం.
  • ప్రైవేట్ పెట్టకుండా పబ్లిక్ వేరియబుల్స్ వదిలేయడం. అప్పుడు డేటా సెక్యూరిటీ ఉండదు.

// Coding Challenge:
// BankAccount కి తోడుగా ఒక ఫిక్స్డ్ డిపాజిట్ మెథడ్ యాడ్ చేయండి:
// 1. calculateMaturity(int years, double annualRate) అనే మెథడ్ రాయాలి.
//    ఇది: balance * Math.pow(1 + annualRate/100, years) ని రిటర్న్ చేయాలి.
// 2. దాన్ని FIXED_DEPOSIT అకౌంట్ తో టెస్ట్ చేయండి.

class ExtendedBankAccount extends BankAccount {
    ExtendedBankAccount(String holder, double deposit, AccountType type) {
        super(holder, deposit, type);
    }

    public double calculateMaturity(int years, double annualRate) {
        return getBalance() * Math.pow(1 + annualRate / 100.0, years);
    }
}

public class Challenge {
    public static void main(String[] args) {
        ExtendedBankAccount fd = new ExtendedBankAccount("Savings Plan", 50000, BankAccount.AccountType.FIXED_DEPOSIT);
        System.out.printf("5 ఏళ్ల తర్వాత 7.5%% వడ్డీతో: $%.2f%n", fd.calculateMaturity(5, 7.5));
    }
}

💡 Frequently Asked Questions & Interview Insights

❓ ఒకదాని కంటే ఎక్కువ ఆబ్జెక్ట్స్ ని స్టోర్ చేయడానికి Array వాడాలా, లేక ArrayList వాడాలా?

మీకు సైజు ముందే తెలిస్తే (ఉదా: థియేటర్ లో 100 సీట్లు) మామూలు Array వాడొచ్చు. కానీ స్టూడెంట్స్ వస్తూ పోతూ ఉంటే (సైజు మారుతూ ఉంటే) ArrayList వాడటమే కరెక్ట్. దాని గురించి మనం 15వ ఫేజ్ లో క్లియర్ గా నేర్చుకుందాం.

❓ ఇద్దరు స్టూడెంట్స్ లో ఎవరి GPA ఎక్కువ ఉందో ఆటోమాటిక్ గా ఎలా సార్ట్ (Sort) చేయాలి?

దీనికోసం `Comparable` అనే ఒక ఇంటర్ఫేస్ ని వాడాలి. అందులో `compareTo` మెథడ్ రాసి మనం ఎవరి మార్కులు ఎక్కువో జావాకి చెప్తే.. అది ఆటోమాటిక్ గా ర్యాంక్స్ ఇచ్చేస్తుంది.

❓ `null` కి, మామూలు ఆబ్జెక్ట్ కి (డిఫాల్ట్ వాల్యూస్ తో ఉన్నదానికి) తేడా ఏంటి?

`null` అంటే అక్కడ అసలు ఇల్లే (ఆబ్జెక్ట్) లేదు అని అర్థం. డిఫాల్ట్ వాల్యూస్ తో ఉన్న ఆబ్జెక్ట్ (`new Student()`) అంటే.. ఇల్లు ఉంది, కానీ అందులో ఫర్నిచర్ (డేటా) ఇంకా వేయలేదు అని అర్థం.
