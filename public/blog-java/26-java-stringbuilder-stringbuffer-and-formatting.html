Java StringBuilder, StringBuffer & String Formatting (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 26 of 47 📂 Phase 6: Strings & Text Processing 📅 2026 Edition
📌 Covered in this chapter:

The Concatenation Problem (O(N^2)) · StringBuilder Architecture & Capacity Growth · append() · insert() · delete() · reverse() · StringBuffer vs StringBuilder · String.format() & printf() · Text Blocks (""")

స్ట్రింగ్స్ ని లూప్ లో పెట్టి కలపడం వల్ల (Concatenation) యాప్ ఎందుకు స్లో అవుతుంది? దానికి సొల్యూషన్ గా వచ్చిన `StringBuilder` మరియు `StringBuffer` అంటే ఏంటి? వాటితో స్ట్రింగ్స్ ని మార్చడం ఎంత ఈజీ? అలాగే అవుట్పుట్ ని నీట్ గా టేబుల్స్ లాగా ఫార్మాట్ చేయడానికి `String.format()` మరియు కొత్తగా వచ్చిన Text Blocks (`"""`) గురించి నేర్చుకుందాం.

1. స్ట్రింగ్స్ ని లూప్ లో కలిపితే వచ్చే ప్రాబ్లమ్ (O(N^2))

స్ట్రింగ్ ని ఎవరూ మార్చలేరు (Immutable) అని ముందే తెలుసుకున్నాం. కాబట్టి మీరు + వాడి రెండు స్ట్రింగ్స్ ని కలిపిన ప్రతిసారీ.. జావా ఒక కొత్త స్ట్రింగ్ ని క్రియేట్ చేసి పాత అక్షరాలను కాపీ చేస్తుంది:

// ఇది చాలా తప్పు పద్ధతి (మెమరీ వేస్ట్):
String result = "";
for (int i = 0; i < 10000; i++) {
    result += i; // ఇది రన్ అయిన ప్రతిసారీ 10,000 టెంపరరీ ఆబ్జెక్ట్స్ క్రియేట్ అవుతాయి!
}
దీన్ని లక్ష సార్లు రన్ చేస్తే, జావా మెమరీ ఫుల్ అయ్యి 15 సెకన్లకి పైగా టైమ్ తీసుకుంటుంది!

సొల్యూషన్: దీనికోసమే StringBuilder ని తీసుకొచ్చారు. ఇది ఒక ప్లాస్టిక్ డబ్బా లాంటిది. కొత్త ఆబ్జెక్ట్స్ ని క్రియేట్ చేయకుండా ఉన్నదానిలోనే కలుపుకుంటూ వెళ్తుంది. లక్ష సార్లు రన్ చేయడానికి దీనికి 5 మిల్లీ సెకన్లు మాత్రమే పడుతుంది!

2. StringBuilder సైజు ఎలా పెరుగుతుంది? (Capacity)

StringBuilder ఇంటర్నల్ గా ఒక అక్షరాల అరే (Array) ని మైంటైన్ చేస్తుంది:
- స్టార్టింగ్ కెపాసిటీ (Capacity): బై డీఫాల్ట్ గా 16 అక్షరాలకు సరిపడా ఖాళీ ప్లేస్ ఇస్తుంది.
- కస్టమ్ కెపాసిటీ: new StringBuilder(100) అంటే ముందే 100 క్యారెక్టర్స్ కి ప్లేస్ రిజర్వ్ చేసుకోవచ్చు.
- ఆటోమాటిక్ గా పెరగడం: ఒకవేళ ఆ 16 ప్లేసులు ఫుల్ అయిపోతే.. వెంటనే పాత సైజు కి డబుల్ చేసి దానికి ఇంకో 2 కలుపుతుంది:
కొత్త సైజు = (పాత సైజు * 2) + 2

స్టార్టింగ్ బఫర్ (సైజు = 16):
  ['J']['a']['v']['a'][ ][ ][ ][ ][ ][ ][ ][ ][ ][ ][ ][ ]  (వాడింది 4)

ఇంకో 20 అక్షరాలు కలిపితే ఏమవుతుంది?:
  కొత్త సైజు = (16 * 2) + 2 = 34 వస్తుంది (ఆటోమాటిక్ గా)
  ['J']['a']['v']['a'][' ']['2']['1']['.']['.']['.'][ ... ]

3. StringBuilder లో ముఖ్యమైన మెథడ్స్

మెథడ్ ఏం చేస్తుంది? ఎగ్జాంపుల్
append(డేటా) స్ట్రింగ్ చివర్లో మనం ఇచ్చిన డేటాని కలుపుతుంది. sb.append(" Java ").append(21);
insert(ఇండెక్స్, డేటా) మనం చెప్పిన పొజిషన్ లోకి టెక్స్ట్ ని దూరేలా చేస్తుంది. sb.insert(0, "START: ");
delete(start, end) మధ్యలో ఉన్న టెక్స్ట్ ని కట్ చేసి తీసేస్తుంది. sb.delete(0, 7);
reverse() మొత్తం స్ట్రింగ్ ని రివర్స్ చేస్తుంది. sb.reverse();
setCharAt(idx, char) ఒక్క అక్షరాన్ని మాత్రమే మారుస్తుంది. sb.setCharAt(0, 'X');
toString() ఫైనల్ గా ఆ డబ్బాలో ఉన్నదాన్ని నార్మల్ String లాగా మార్చేస్తుంది. String text = sb.toString();

4. String vs StringBuilder vs StringBuffer తేడాలు

ఫీచర్ String StringBuilder StringBuffer
మార్చొచ్చా? (Mutable) మార్చలేము (Immutable) మార్చొచ్చు (Mutable) మార్చొచ్చు (Mutable)
Thread Safety (సేఫేనా?) Thread-Safe Thread-Safe కాదు (లాక్స్ లేవు) Thread-Safe (లాక్స్ ఉంటాయి)
స్పీడ్ చాలా స్లో (లూప్స్ లో) సూపర్ ఫాస్ట్ కాస్త స్లో (లాక్స్ ఉండటం వల్ల)
మెమరీ SCP లేదా Heap Heap Heap
ఎప్పుడు వాడాలి? నార్మల్ టెక్స్ట్ కి, మ్యాప్ కీస్ కి లూప్స్ లో టెక్స్ట్ ని కలిపేటప్పుడు మల్టీ-త్రెడింగ్ ఉన్నప్పుడు మాత్రమే

5. టెక్స్ట్ ని ప్రొఫెషనల్ గా డిజైన్ చేయడం (String Formatting)

అవుట్పుట్ ని నీట్ గా టేబుల్స్ లాగా చూపించాలంటే String formatting వాడతాం:

String message = String.format("ప్రొడక్ట్: %-12s | ధర: $%7.2f | క్వాంటిటీ: %03d", "Laptop", 899.954, 5);
// రిజల్ట్: "ప్రొడక్ట్: Laptop       | ధర: $ 899.95 | క్వాంటిటీ: 005"

వాడే కోడ్స్ ఇవే:
- %s: స్ట్రింగ్ కోసం
- %d: నార్మల్ నంబర్స్ కి (int)
- %f: పాయింట్స్ ఉన్న నంబర్స్ కి (%.2f అంటే పాయింట్ తర్వాత 2 నంబర్స్ ఏ వస్తాయి)
- %-15s: లెఫ్ట్ సైడ్ కరెక్ట్ గా 15 స్పేస్ లతో సెట్ అవ్వడానికి
- %05d: నంబర్ ముందు జీరోలు యాడ్ చేయడానికి (ఉదా: 00042)

కొత్త Java 15+ Text Blocks ("""):
HTML లాంటి పెద్ద పెద్ద కోడ్స్ రాసేటప్పుడు జావాలో మల్టిపుల్ లైన్స్ కోసం 3 కొటేషన్స్ వాడొచ్చు:

String html = """
    <div class="card">
        <h2>%s</h2>
        <p>వయసు: %d</p>
    </div>
    """.formatted("రవి", 25);

🔍 Line-by-Line Code Explanation

sb.append(" Programming").append(" 2026");

ఇలా డాట్ పెట్టుకుంటూ కలుపుకుంటూ వెళ్లొచ్చు (దీన్నే Method Chaining అంటారు). ఇది చాలా ఫాస్ట్.

pal.reverse();

మనం ఎలాంటి కష్టం పడకుండా జస్ట్ reverse() అని పిలవగానే మొత్తం టెక్స్ట్ ఉల్టా అయిపోతుంది.

String.format("| %-20s | ధర: $%7.2f ...")

%-20s అంటే 20 క్యారెక్టర్స్ కి సరిపడా స్పేస్ వదిలి లెఫ్ట్ సైడ్ పెడుతుంది, %.2f అంటే పాయింట్ తర్వాత 2 నంబర్స్ ఉంచుతుంది.

htmlTemplate.formatted(...)

Java 15 లో వచ్చిన ఫీచర్. మల్టీ-లైన్ టెక్స్ట్ లో ఎక్కడెక్కడ %s ఉందో అక్కడికి మనం ఇచ్చిన డేటాని పంపుతుంది.

Practical Real-World Example

☕ PracticalApplication.java — Industry Implementation 
public class PracticalApplication {
    public static void main(String[] args) {
        // రియల్ టైమ్ సినారియో: బిల్లింగ్ ఇన్వాయిస్ జనరేట్ చేయడం
        String[] products = {"క్లౌడ్ సర్వర్", "SSL సర్టిఫికెట్", "డొమైన్ రిజిస్ట్రేషన్"};
        double[] prices = {149.50, 49.00, 14.99};
        int[] quantities = {2, 1, 3};

        StringBuilder invoice = new StringBuilder();
        invoice.append("========================================================\n");
        invoice.append(String.format(" %-20s | %-6s | %-9s | %-10s\n", "ఐటెమ్ పేరు", "క్వాంటిటీ", "ఒకటి ధర", "మొత్తం"));
        invoice.append("========================================================\n");

        double grandTotal = 0;
        for (int i = 0; i < products.length; i++) {
            double total = prices[i] * quantities[i];
            grandTotal += total;
            // టేబుల్ ఫార్మాట్ లో యాడ్ చేస్తున్నాం
            invoice.append(String.format(" %-22s | %-9d | $%7.2f | $%8.2f\n",
                    products[i], quantities[i], prices[i], total));
        }

        invoice.append("--------------------------------------------------------\n");
        invoice.append(String.format(" %-43s $%8.2f\n", "గ్రాండ్ టోటల్:", grandTotal));
        invoice.append("========================================================\n");

        System.out.println(invoice.toString());
    }
}

⚠️ Common Mistakes & Professional Best Practices
  • లూప్ లోపల నార్మల్ గా + వాడి స్ట్రింగ్స్ ని కలపడం. అది యాప్ ని క్రాష్ చేసేంత మెమరీని లాగేసుకుంటుంది.
  • రెండు StringBuilder లని sb1.equals(sb2) అని వాడటం. StringBuilder క్లాస్ లో equals మెథడ్ లేదు, కాబట్టి అది డైరెక్ట్ అడ్రెస్స్ లని చెక్ చేసి ఎప్పుడూ false ఇస్తుంది. కరెక్ట్ గా చేయాలంటే sb1.toString().equals(sb2.toString()) అని వాడాలి.
  • %d ని డెసిమల్ నంబర్స్ (double) కి వాడటం. ఇంటిజర్స్ కి %d, డబుల్/ఫ్లోట్ కి %f వాడాలి, రివర్స్ వాడితే ఎర్రర్ వస్తుంది.
🎯 Hands-on Coding Challenge

Test your understanding by writing the code directly in your editor or running in our online Java compiler:

☕ Challenge.java 
// Coding Challenge:
// ఒక వాక్యాన్ని తీసుకోండి: "Java is an amazing language"
// StringBuilder వాడి ప్రతి పదాన్ని అదే ప్లేస్ లో రివర్స్ చేయండి.
// అవుట్పుట్: "avaJ si na gnizama egaugnal"

public class Challenge {
    public static void main(String[] args) {
        String sentence = "Java is an amazing language";
        String[] words = sentence.split(" ");
        StringBuilder result = new StringBuilder();

        for (int i = 0; i < words.length; i++) {
            StringBuilder wordBuilder = new StringBuilder(words[i]);
            result.append(wordBuilder.reverse());
            if (i < words.length - 1) {
                result.append(" ");
            }
        }

        System.out.println("ఒరిజినల్ : " + sentence);
        System.out.println("రివర్స్   : " + result.toString());
    }
}

💡 Frequently Asked Questions & Interview Insights

❓ StringBuilder కి StringBuffer కి తేడా ఏంటి?

రెండూ ఒకేలాగా పనిచేస్తాయి. కానీ StringBuffer లో లాక్స్ ఉంటాయి (Synchronized), ఇది పాతది, స్లో గా ఉంటుంది. సింగిల్ త్రెడ్ లో వాడేటప్పుడు ఎప్పుడూ ఫాస్ట్ గా ఉండే StringBuilder మాత్రమే వాడాలి.

❓ నార్మల్ గా a + b + c రాస్తే కంపైలర్ ఏమైనా ఆప్టిమైజ్ చేస్తుందా?

అవును, ఒకే లైన్ లో రాస్తే కంపైలర్ దాన్ని ఆటోమాటిక్ గా StringBuilder కింద మారుస్తుంది. కానీ లూప్ లోపల వాడినప్పుడు మాత్రం ఆప్టిమైజ్ చేయలేదు, అందుకే లూప్స్ కి మనమే మ్యాన్యువల్ గా రాయాలి.

🚀 Quick Chapter Recap

  • లూప్స్ లో స్ట్రింగ్స్ ని కలపడానికి ఎప్పుడూ StringBuilder ఏ వాడాలి (చాలా ఫాస్ట్).
  • StringBuilder లో append(), insert(), delete(), reverse() లాంటి మంచి ఫీచర్స్ ఉన్నాయి.
  • టేబుల్స్ లాగా నీట్ గా చూపించడానికి String.format() వాడుతారు.
