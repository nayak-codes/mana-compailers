Java User Input with Scanner & Newline Trap (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 12 of 47 📂 Phase 3: Operators and Input 📅 2026 Edition
📌 Covered in this chapter:

java.util.Scanner · Reading Data (nextInt, nextDouble, nextLine) · The Infamous Newline Buffer Trap · InputMismatchException · Resource Management & closing Scanner

జావాలో కీబోర్డ్ నుంచి వాల్యూస్ (User Input) ఎలా తీసుకోవాలి? Scanner క్లాస్ ఎలా వాడాలి? నంబర్స్ తర్వాత టెక్స్ట్ తీసుకునేటప్పుడు వచ్చే "Newline Trap" అనే పెద్ద బగ్ ని ఎలా సాల్వ్ చేయాలో ఈ చాప్టర్ లో చూద్దాం.

1. Scanner క్లాస్ అంటే ఏంటి?

మనం కీబోర్డ్ లో ఏది టైప్ చేసినా అది డైరెక్ట్ గా జావా ప్రోగ్రామ్ లోకి వెళ్ళిపోదు. మధ్యలో దాన్ని చదవడానికి Scanner అనే ఒక క్లాస్ కావాలి (ఇది java.util అనే ప్యాకేజ్ లో ఉంటుంది).

Scanner ని సెటప్ చేసే విధానం:

import java.util.Scanner; // 1. పైన దీన్ని ఇంపోర్ట్ చేసుకోవాలి

Scanner input = new Scanner(System.in); // 2. సిస్టమ్ కీబోర్డ్ (System.in) ని చదవమని చెప్తున్నాం
System.out.print("మీ పేరు ఎంటర్ చేయండి: ");
String name = input.nextLine(); // 3. యూజర్ టైప్ చేసేదాన్ని చదువుతున్నాం
input.close(); // 4. పని అయ్యాక దాన్ని క్లోజ్ చేయాలి

2. Scanner లో ఉండే మెయిన్ ఫంక్షన్స్

యూజర్ ఇచ్చే డేటా ఏ టైపో దాన్నిబట్టి ఫంక్షన్ వాడాలి:

ఫంక్షన్ఏ టైప్ వస్తుంది?ఏం చదువుతుంది?
**`nextLine()`**
String | యూజర్ టైప్ చేసిన లైన్ మొత్తాన్ని (స్పేస్ లతో సహా) చదువుతుంది. Enter నొక్కే వరకు ఆగుతుంది. | | next() | String | స్పేస్ వచ్చే వరకు మాత్రమే చదువుతుంది. (ఒకే పదాన్ని తీసుకుంటుంది). | | nextInt() | int | నంబర్ ని తీసుకుంటుంది. | | nextDouble()| double | డెసిమల్ నంబర్ (పాయింట్ వాల్యూ) ని తీసుకుంటుంది. | | nextLong() | long | పెద్ద నంబర్ ని తీసుకుంటుంది. | | nextBoolean()| boolean | కేవలం true లేదా false తీసుకుంటుంది. |

3. అందరూ చేసే పెద్ద తప్పు: "Newline Buffer Trap"

జావా నేర్చుకునే ప్రతి ఒక్కరూ ఫేస్ చేసే అతిపెద్ద ప్రాబ్లమ్ ఇది. నంబర్స్ ని తీసుకుని, వెంటనే స్ట్రింగ్ ని తీసుకున్నప్పుడు ఈ ప్రాబ్లమ్ వస్తుంది.

ఏం జరుగుతుంది?:

మీరు nextInt() వాడినప్పుడు, యూజర్ నంబర్ టైప్ చేసి Enter కీ నొక్కుతాడు కదా. ఆ Enter కీ కి సంబంధించిన న్యూలైన్ (\n) క్యారెక్టర్ ని Scanner రీడ్ చేయకుండా అలా బఫర్ (మెమరీ) లోనే వదిలేస్తుంది: 
System.out.print("వయసు ఎంటర్ చేయండి: ");
int age = scanner.nextInt(); // యూజర్ '21' టైప్ చేసి ENTER నొక్కుతాడు. ఇది 21 తీసుకుంటుంది కానీ ఆ ఎంటర్ (
) అక్కడే ఉండిపోతుంది!

System.out.print("పేరు ఎంటర్ చేయండి: ");
String name = scanner.nextLine(); // నెక్స్ట్ లైన్ లోకి రాగానే.. అక్కడున్న ఆ ఎంటర్ (
) ని చూసి యూజర్ పేరు కూడా ఎంటర్ చేసాడేమో అనుకుని ఖాళీగా సేవ్ చేసేస్తుంది!
// అసలు యూజర్ కి పేరు ఎంటర్ చేసే ఛాన్సే ఇవ్వదు.

దీన్ని ఎలా సాల్వ్ చేయాలి? (The Professional Fix):

ఎప్పుడైనా సరే nextInt(), nextDouble() వాడిన తర్వాత మీరు nextLine() వాడాల్సి వస్తే.. మధ్యలో ఒక డమ్మీ scanner.nextLine() రాయాలి. ఆ డమ్మీ లైన్ ఆ ఎంటర్ (\n) ని క్లీన్ చేసేస్తుంది: 
System.out.print("వయసు ఎంటర్ చేయండి: ");
int age = scanner.nextInt();
scanner.nextLine(); // FIX: ఇది ఆ ఎంటర్ కీ (
) ని క్లీన్ చేసి పారేస్తుంది

System.out.print("పేరు ఎంటర్ చేయండి: ");
String name = scanner.nextLine(); // ఇప్పుడు పర్ఫెక్ట్ గా యూజర్ పేరు అడుగుతుంది!

4. తప్పు డేటా ఇస్తే క్రాష్ అవ్వకుండా ఆపడం (InputMismatchException)

మీరు scanner.nextInt() వాడి నంబర్ అడిగినప్పుడు, యూజర్ కావాలని నంబర్ ఇవ్వకుండా టెక్స్ట్ ("hello") టైప్ చేస్తే ఏమవుతుంది? వెంటనే జావా InputMismatchException అని ఎర్రర్ ఇచ్చి ప్రోగ్రామ్ ని క్రాష్ చేస్తుంది.

దీన్ని సేఫ్ గా ఎలా డీల్ చేయాలి?:

hasNextInt() వాడి, యూజర్ ఇచ్చింది నంబరా కాదా అని ముందే చెక్ చేసుకోవచ్చు: 
if (scanner.hasNextInt()) {
    int age = scanner.nextInt();
    System.out.println("కరెక్ట్ గా ఇచ్చారు: " + age);
} else {
    System.out.println("తప్పు! మీరు నంబర్ మాత్రమే ఎంటర్ చేయాలి.");
}

Beginner Example & Code Anatomy

☕ Main.java — Chapter 12 Core Example 
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("==========================================");
        System.out.println("   స్టూడెంట్ రిజిస్ట్రేషన్ సిస్టమ్      ");
        System.out.println("==========================================");

        // 1. ఇంటిజర్ చదవడం
        System.out.print("స్టూడెంట్ ID ఎంటర్ చేయండి (ఉదా: 101): ");
        int studentId = scanner.nextInt();

        // 2. డెసిమల్ చదవడం
        System.out.print("GPA ఎంటర్ చేయండి (ఉదా: 3.85): ");
        double gpa = scanner.nextDouble();

        // 3. ఇంపార్టెంట్: బఫర్ లో ఉన్న 'ఎంటర్' కీ ని క్లీన్ చేయడం
        scanner.nextLine();

        // 4. టెక్స్ట్ (లైన్) మొత్తం చదవడం
        System.out.print("పూర్తి పేరు ఎంటర్ చేయండి: ");
        String fullName = scanner.nextLine();

        // 5. బూలియన్ చదవడం
        System.out.print("ఫుల్ టైమ్ స్టూడెంటా? (true/false): ");
        boolean isFullTime = scanner.nextBoolean();

        // రిజల్ట్స్ ప్రింట్ చేయడం
        System.out.println("
--- స్టూడెంట్ డీటెయిల్స్ ---");
        System.out.println("ID        : #" + studentId);
        System.out.println("పేరు      : " + fullName);
        System.out.println("GPA       : " + gpa);
        System.out.println("ఫుల్ టైమ్ : " + (isFullTime ? "YES" : "NO"));

        scanner.close(); // స్మానర్ క్లోజ్ చేయడం మర్చిపోవద్దు
    }
}

🔍 Line-by-Line Code Explanation

Scanner scanner = new Scanner(System.in);

కీబోర్డ్ నుంచి వచ్చే డేటాని (System.in) చదవడానికి ఒక స్మానర్ ని రెడీ చేసుకున్నాం.

int studentId = scanner.nextInt();

యూజర్ టైప్ చేసే ఇంటిజర్ ని తీసుకొని studentId లో స్టోర్ చేస్తున్నాం.

scanner.nextLine(); // Clean buffer

పైన నంబర్స్ తీసుకున్నాం కదా, అక్కడ మిగిలిపోయిన Enter కీ ని ఇది క్లీన్ చేసేస్తుంది. (చాలా ఇంపార్టెంట్!).

String fullName = scanner.nextLine();

యూజర్ పేరు మొత్తాన్ని స్పేస్ లతో సహా చదువుతుంది.

scanner.close();

పని అయ్యాక ఆ కనెక్షన్ ని క్లోజ్ చేయాలి, లేదంటే మెమరీ లీక్ అవుతుంది.

Practical Real-World Example

☕ PracticalApplication.java — Industry Implementation 
import java.util.Scanner;

public class SimpleBillCalculator {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("--- సూపర్ మార్కెట్ బిల్లింగ్ సిస్టమ్ ---");
        System.out.print("ఐటమ్ పేరు: ");
        String itemName = input.nextLine();

        System.out.print("ఒక దాని ధర (₹): ");
        double unitPrice = input.nextDouble();

        System.out.print("ఎన్ని తీసుకున్నారు?: ");
        int quantity = input.nextInt();

        // సబ్ టోటల్ & 18% GST క్యాలిక్యులేషన్
        double subtotal = unitPrice * quantity;
        double gstAmount = subtotal * 0.18;
        double grandTotal = subtotal + gstAmount;

        System.out.println("
========= ఫైనల్ బిల్ =========");
        System.out.println("ఐటమ్      : " + itemName);
        System.out.println("క్వాంటిటీ  : " + quantity + " x ₹" + unitPrice);
        System.out.println("సబ్ టోటల్  : ₹" + subtotal);
        System.out.println("GST (18%) : ₹" + gstAmount);
        System.out.println("మొత్తం కట్టాల్సింది: ₹" + grandTotal);
        System.out.println("===============================");

        input.close();
    }
}

⚠️ Common Mistakes & Professional Best Practices
  • బఫర్ ని క్లీన్ చేయకపోవడం: nextInt() తర్వాత డైరెక్ట్ గా nextLine() వాడితే టెక్స్ట్ అసలు చదవదు. మధ్యలో ఒక డమ్మీ nextLine() కచ్చితంగా ఉండాలి.
  • పేరు అడగడానికి next() వాడటం: scanner.next() వాడితే కేవలం మొదటి పదం మాత్రమే తీసుకుంటుంది (ఉదా: Balaji Nayak అని ఇస్తే Balaji మాత్రమే తీసుకుంటుంది). కాబట్టి పూర్తి పేర్ల కోసం scanner.nextLine() వాడాలి.
  • లూప్ లోపల scanner.close() చేయడం: scanner.close() చేస్తే అది System.in ని కూడా క్లోజ్ చేస్తుంది. మళ్ళీ ఆ ప్రోగ్రామ్ రన్ అవుతున్నంత సేపు కీబోర్డ్ నుంచి ఎలాంటి డేటా తీసుకోలేరు. కాబట్టి ప్రోగ్రామ్ చివర్లోనే క్లోజ్ చేయాలి.

❓ scanner.close() కచ్చితంగా రాయాలా? రాయకపోతే ఏమవుతుంది?

రాయకపోతే జావా ఎర్రర్ ఏమీ ఇవ్వదు, కానీ మెమరీ లీక్ (Resource leak) అయ్యే ఛాన్స్ ఉందని వార్నింగ్ ఇస్తుంది. సేఫ్ సైడ్ క్లోజ్ చేయడం మంచి అలవాటు.

❓ next() కి nextLine() కి మెయిన్ డిఫరెన్స్ ఏంటి?

"next()" స్పేస్ రాగానే చదవడం ఆపేస్తుంది. "nextLine()" మనం Enter కీ నొక్కేవరకు లైన్ మొత్తాన్ని చదువుతుంది.

🚀 Quick Chapter Recap

  • యూజర్ నుంచి కీబోర్డ్ ద్వారా డేటా తీసుకోవడానికి java.util.Scanner వాడతాం.
  • లైన్ మొత్తం చదవాలంటే nextLine(), నంబర్స్ కి nextInt(), డెసిమల్స్ కి nextDouble().
  • నంబర్స్ చదివాక టెక్స్ట్ చదవాలంటే, మధ్యలో బఫర్ ని క్లీన్ చేయడానికి ఒక డమ్మీ nextLine() వాడాలి.
  • పని అయిపోయాక scanner.close() చేయాలి.
