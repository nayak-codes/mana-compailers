Java while & do-while Loops: Number & Digit Algorithms (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 20 of 47 📂 Phase 5: Loops & Control Flow 📅 2026 Edition
📌 Covered in this chapter:

while Loop (Entry-Controlled) · do-while Loop (Exit-Controlled) · When to use for vs while vs do-while · Digit Reversal · Palindrome · Armstrong Numbers

ఎన్నిసార్లు తిరగాలో తెలియనప్పుడు వాడే `while`, కనీసం ఒక్కసారైనా రన్ అవ్వాల్సినప్పుడు వాడే `do-while` లూప్స్ ని ఈ చాప్టర్ లో చూద్దాం. అలాగే నంబర్స్ ని రివర్స్ చేయడం, పాలిండ్రోమ్ (Palindrome), ఆర్మ్ స్ట్రాంగ్ నంబర్ (Armstrong) లాంటి పాపులర్ ఇంటర్వ్యూ ప్రోగ్రామ్స్ ఎలా చేయాలో నేర్చుకుందాం.

1. `while` Loop (ముందే చెక్ చేస్తుంది - Entry-Controlled)

while లూప్ ని ఎంట్రీ-కంట్రోల్డ్ లూప్ అంటారు. అంటే లోపలికి వెళ్లే ముందే కండిషన్ చెక్ చేస్తుంది. ఫస్ట్ టైమే కండిషన్ తప్పు అయితే.. అసలు లోపలికి కూడా వెళ్ళదు:

while (కండిషన్) {
    // కండిషన్ true ఉన్నంతసేపు ఇది రన్ అవుతుంది
    // కచ్చితంగా లూప్ బ్రేక్ అయ్యేలా ఒక వాల్యూ అప్డేట్ చేయాలి!
}

ఏ లూప్ ఎప్పుడు వాడాలి? (for vs while):

- for లూప్: ఎన్నిసార్లు రన్ చేయాలో మీకు ముందే తెలిస్తే ఇది వాడాలి (ఉదాహరణకి: 10 సార్లు రన్ చేయాలి, అరే లో 50 నంబర్స్ ఉన్నాయి). - while లూప్: ఎన్నిసార్లు రన్ చేయాలో మీకు ముందే తెలియనప్పుడు ఇది వాడాలి (ఉదాహరణకి: యూజర్ 'స్టాప్' అని టైప్ చేసేదాక రన్ చేయాలి, ఫైల్ లో డేటా అయిపోయేదాక రన్ చేయాలి).

2. `do-while` Loop (చివర్లో చెక్ చేస్తుంది - Exit-Controlled)

do-while లూప్ ఎగ్జిట్-కంట్రోల్డ్ లూప్. అంటే ఫస్ట్ కండిషన్ తో సంబంధం లేకుండా ఒక్కసారైనా కోడ్ రన్ చేసేసి.. ఆ తర్వాత కండిషన్ చెక్ చేసుకుంటుంది:

do {
    // కండిషన్ ఫాల్స్ అయినా కనీసం ఒక్కసారైనా ఇది రన్ అవుతుంది!
} while (కండిషన్); // ఇక్కడ సెమికోలన్ కచ్చితంగా ఉండాలి!

మెయిన్ డిఫరెన్స్:

కండిషన్ ముందే తప్పు ఉన్నప్పుడు ఏమవుతుందో చూడండి: 
int x = 10;

// while loop: 10 < 5 తప్పు కాబట్టి ఇది అసలు రన్ అవ్వదు (0 సార్లు రన్ అవుతుంది)
while (x < 5) {
    System.out.println("While loop రన్ అయ్యింది");
}


// do-while loop: ఇది కనీసం ఒక్కసారి రన్ అయిపోయి, ఆ తర్వాత కండిషన్ చెక్ చేసుకుని ఆగుతుంది!
do {
    System.out.println("Do-while ఒక్కసారి రన్ అయ్యింది!");
} while (x < 5);

3. నంబర్స్ తో ఆడుకోవడానికి `while` లూప్స్

కంపెనీ ఇంటర్వ్యూస్ లో ఎక్కువగా అడిగేది నంబర్స్ లాజిక్స్. వీటిని మోడ్యులస్ (%), డివిజన్ (/) ఆపరేటర్స్ వాడి సాల్వ్ చేస్తాం:

1. చివరి నంబర్ తీయడానికి: int lastDigit = number % 10; (ఉదాహరణకి: 1234 ని 10 తో భాగిస్తే శేషం 4 వస్తుంది)
2. చివరి నంబర్ ని కట్ చేయడానికి: number = number / 10; (ఉదాహరణకి: 1234 / 10 అంటే 123 వస్తుంది)
3. నంబర్ ని రివర్స్ చేయడానికి: reversed = (reversed * 10) + lastDigit;

Armstrong Number (ఆర్మ్ స్ట్రాంగ్ నంబర్) అంటే ఏంటి?

ఏదైనా నంబర్ ని విడదీసి.. ఒక్కో డిజిట్ ని క్యూబ్ ($x^3$) చేసి కలిపితే.. మళ్ళీ అదే నంబర్ వస్తే దాన్ని Armstrong అంటారు (ఉదాహరణకి: 153, 370). $$153 = 1^3 + 5^3 + 3^3 = 1 + 125 + 27 = 153$$

Beginner Example & Code Anatomy

☕ Main.java — Chapter 20 Core Example 
public class Main {
    public static void main(String[] args) {
        System.out.println("=== 1. నంబర్ ని రివర్స్ చేయడం & పాలిండ్రోమ్ చెక్ ===");
        int originalNumber = 12321;
        int temp = originalNumber;
        int reversedNumber = 0;
        int digitCount = 0;

        // temp జీరో అయ్యేదాక ఒక్కో నంబర్ ని బయటికి తీస్తున్నాం
        while (temp > 0) {
            int lastDigit = temp % 10;                 // లాస్ట్ నంబర్ ని తీసుకున్నాం
            reversedNumber = (reversedNumber * 10) + lastDigit; // పాత దాన్ని లెఫ్ట్ కి జరిపి ఇది అటాచ్ చేసాం
            temp = temp / 10;                          // లాస్ట్ నంబర్ ని కట్ చేసాం
            digitCount++;
        }

        System.out.println("ఒరిజినల్ నంబర్ : " + originalNumber);
        System.out.println("మొత్తం డిజిట్స్ : " + digitCount);
        System.out.println("రివర్స్ నంబర్   : " + reversedNumber);
        System.out.println("పాలిండ్రోమా?   : " + (originalNumber == reversedNumber));

        System.out.println("
=== 2. ఆర్మ్ స్ట్రాంగ్ నంబర్ చెక్ (153) ===");
        int testArm = 153;
        int armTemp = testArm;
        int armSum = 0;

        while (armTemp > 0) {
            int digit = armTemp % 10;
            armSum += (digit * digit * digit); // క్యూబ్ చేసి కలుపుతున్నాం
            armTemp /= 10;
        }

        System.out.println("మొత్తం కలిపితే వచ్చింది : " + armSum);
        System.out.println("153 ఆర్మ్ స్ట్రాంగ్ ఏనా? : " + (testArm == armSum));
    }
}

🔍 Line-by-Line Code Explanation

int lastDigit = temp % 10;

ఏ నంబర్ ని అయినా 10 తో మోడ్యులస్ చేస్తే, దాని చివరి అంకె వస్తుంది.

reversedNumber = (reversedNumber * 10) + lastDigit;

ఉన్న రివర్స్ నంబర్ ని 10 తో మల్టిప్లై చేసి, కొత్త డిజిట్ ని కలుపుతున్నాం.

temp = temp / 10;

నంబర్ ని 10 తో డివైడ్ చేస్తే.. లాస్ట్ డిజిట్ కట్ అయిపోతుంది. చివరకి జీరో అయిపోయి లూప్ ఆగుతుంది.

originalNumber == reversedNumber

రివర్స్ చేసినా మళ్ళీ అదే వస్తే దాన్ని పాలిండ్రోమ్ (Palindrome) అంటారు.

⚠️ Common Mistakes & Professional Best Practices
  • while లూప్ లో వాల్యూ ని అప్డేట్ చేయకపోవడం: "while (x > 0)" అని రాసి, లోపల "x--" రాయకపోతే అది జీవితాంతం తిరుగుతూనే ఉంటుంది (CPU హ్యాంగ్ అవుతుంది).
  • do-while చివర్లో సెమికోలన్ మర్చిపోవడం: "while (cond)" తర్వాత కచ్చితంగా సెమికోలన్ ";" ఉండాలి, లేదంటే ఎర్రర్ వస్తుంది.
  • ఒరిజినల్ వేరియబుల్ ని కట్ చేయడం: నంబర్ ని రివర్స్ చేసేటప్పుడు ఎప్పుడూ ఒక "temp = num;" వేరియబుల్ తీసుకుని దాన్ని కట్ చేయాలి. ఒరిజినల్ వేరియబుల్ ని మార్చేస్తే లాస్ట్ లో పాలిండ్రోమ్ చెక్ చేయడానికి పాత నంబర్ దొరకదు.

💡 Frequently Asked Questions & Interview Insights

❓ while కీ do-while కీ మెయిన్ డిఫరెన్స్ ఏంటి?

"while" కండిషన్ ముందే చెక్ చేస్తుంది, కాబట్టి తప్పు అయితే ఒక్కసారి కూడా రన్ అవ్వదు. "do-while" కండిషన్ ని చివర్లో చెక్ చేస్తుంది, కాబట్టి కనీసం ఒక్కసారైనా కోడ్ రన్ అవుతుంది.

❓ మైనస్ (-) నంబర్స్ ని రివర్స్ చేయాలంటే ఎలా?

"Math.abs(num)" వాడి ముందే ఆ మైనస్ ని తీసేయండి. రివర్స్ చేశాక మళ్ళీ కావాలంటే మైనస్ కలుపుకోవచ్చు.

🚀 Quick Chapter Recap

  • while లూప్ ఎంట్రీ-కంట్రోల్డ్ లూప్ (ముందే కండిషన్ చెక్ చేస్తుంది).
  • do-while లూప్ ఎగ్జిట్-కంట్రోల్డ్ లూప్ (చివర్లో కండిషన్ చెక్ చేస్తుంది, కనీసం ఒక్కసారైనా రన్ అవుతుంది).
  • % 10 తో లాస్ట్ డిజిట్ వస్తుంది; / 10 తో లాస్ట్ డిజిట్ పోతుంది.
  • పాలిండ్రోమ్, ఆర్మ్ స్ట్రాంగ్ నంబర్ లాంటివి while లూప్ వాడి ఈజీగా కనుక్కోవచ్చు.
