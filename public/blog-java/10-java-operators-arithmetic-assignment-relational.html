Java Arithmetic, Assignment & Relational Operators (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 10 of 47 📂 Phase 3: Operators and Input 📅 2026 Edition
📌 Covered in this chapter:

Arithmetic Operators (+, -, *, /, %) · Integer Division vs Floating-Point · String Concatenation Nuances · Compound Assignment · Relational Operators

జావాలో మ్యాథ్స్ (Arithmetic) ఆపరేషన్స్ ఎలా చేయాలి? పాయింట్ (డెసిమల్) నంబర్స్ తో వచ్చే కన్ఫ్యూజన్ ఏంటి? రెండు వేరియబుల్స్ ని (Relational) ఎలా కంపేర్ చేయాలి? స్ట్రింగ్స్ ని నంబర్స్ ని కలిపితే ఏమవుతుంది? అనే విషయాలు డీటెయిల్డ్ గా నేర్చుకుందాం.

1. Arithmetic Operators (+, -, *, /, %)

మ్యాథ్స్ లో వాడే బేసిక్ సింబల్స్ ని జావాలో కూడా అలాగే వాడుతాం:

ఆపరేటర్పేరుఎలా వాడాలి?ఎగ్జాంపుల్రిజల్ట్
**`+`**
ఎడిషన్ (Addition) | a + b | 10 + 5 | 15 | | - | సబ్ట్రాక్షన్ (Subtraction) | a - b | 10 - 5 | 5 | | * | మల్టిప్లికేషన్ (Multiplication) | a * b | 10 * 5 | 50 | | / | డివిజన్ (Division) | a / b | 10 / 4 vs 10.0 / 4 | 2 vs 2.5 | | % | మాడ్యులస్ (Remainder) | a % b | 10 % 3 | 1 (శేషం వస్తుంది) |

డివిజన్ (/) చేసేటప్పుడు వచ్చే పెద్ద కన్ఫ్యూజన్ (Integer Division Trap):

జావాలో డివైడ్ చేసే రెండు నంబర్స్ ఇంటిజర్స్ (int) అయితే, జావా వాటిని డివైడ్ చేశాక పాయింట్ తర్వాత ఉన్న వాల్యూ ని కట్ చేసి పారేస్తుంది. 
int result1 = 7 / 2;     // ఆన్సర్ 3 వస్తుంది (3.5 లో .5 కట్ అయిపోయింది)
double result2 = 7 / 2;   // ఆన్సర్ 3.0 వస్తుంది (డివైడ్ అయ్యాకే డబుల్ కి మారింది కాబట్టి)
double result3 = 7.0 / 2; // ఆన్సర్ 3.5 వస్తుంది (ఒక నంబర్ డెసిమల్ కాబట్టి కరెక్ట్ ఆన్సర్ వచ్చింది)

2. స్ట్రింగ్స్ ని కలపడం (String Concatenation)

జావాలో + సింబల్ కి రెండు పనులున్నాయి:
1. రెండు నంబర్స్ మధ్యలో పెడితే.. వాటిని కలుపుతుంది (మ్యాథ్స్ ఎడిషన్).
2. ఒక టెక్స్ట్ (String) కీ, నంబర్ కీ మధ్యలో పెడితే.. ఆ నంబర్ ని కూడా టెక్స్ట్ లా మార్చేసి పక్కపక్కన జాయింట్ చేస్తుంది.

జావా లెఫ్ట్ నుంచి రైట్ కి చదువుతుంది:

System.out.println("Result: " + 10 + 20);   // అవుట్పుట్: "Result: 1020" (స్ట్రింగ్ పక్కన 10, 20 వచ్చి జాయిన్ అయ్యాయి)
System.out.println("Result: " + (10 + 20)); // అవుట్పుట్: "Result: 30" (బ్రాకెట్స్ లో ఉంది కాబట్టి ఫస్ట్ క్యాలిక్యులేట్ అయ్యింది)
System.out.println(10 + 20 + " is Total");  // అవుట్పుట్: "30 is Total" (ఫస్ట్ రెండు నంబర్స్ కాబట్టి యాడ్ అయిపోయాయి)

3. షార్ట్ కట్ ఆపరేటర్స్ (Compound Assignment)

నార్మల్ గా ఒక వేరియబుల్ వాల్యూ ని మార్చాలంటే x = x + 5 అని రాస్తాం. దాన్నే షార్ట్ కట్ లో ఇలా రాయొచ్చు:

షార్ట్ కట్అసలు అర్థంఏం చేస్తుంది?
**`x += 5`**
x = x + 5 | x కి 5 కలిపి, మళ్ళీ x లోనే సేవ్ చేస్తుంది. | | x -= 5 | x = x - 5 | 5 తగ్గిస్తుంది. | | x *= 5 | x = x * 5 | 5 తో మల్టిప్లై చేస్తుంది. | | x /= 5 | x = x / 5 | 5 తో డివైడ్ చేస్తుంది. | | x %= 5 | x = x % 5 | 5 తో డివైడ్ చేసి రిమైండర్ సేవ్ చేస్తుంది. |

దీనికొక స్పెషాలిటీ ఉంది (Auto-Cast):

byte b = 10;
// b = b + 5; // ఇది ఎర్రర్ ఇస్తుంది (int ని byte లో పెడుతున్నారు అని)
b += 5;       // ఇది పనిచేస్తుంది! ఎందుకంటే షార్ట్ కట్ వాడినప్పుడు జావా ఆటోమాటిక్ గా టైప్ కాస్ట్ చేసేసుకుంటుంది.

4. Relational (Comparison) Operators

రెండు వాల్యూస్ ని కంపేర్ చేసి.. అవునా కాదా (true / false) అని చెప్పడానికి ఇవి వాడతాం:

ఆపరేటర్మీనింగ్ఎగ్జాంపుల్ (`a = 10, b = 20`)రిజల్ట్
**`==`**
ఈక్వల్ (సమానమా) | a == b | false | | != | నాట్ ఈక్వల్ | a != b | true | | > | గ్రేటర్ దెన్ | a > b | false | | < | లెస్ దెన్ | a < b | true | | >= | గ్రేటర్ దెన్ ఆర్ ఈక్వల్ | a >= 10 | true | | <= | లెస్ దెన్ ఆర్ ఈక్వల్ | b <= 20 | true |

Beginner Example & Code Anatomy

☕ Main.java — Chapter 10 Core Example 
public class Main {
    public static void main(String[] args) {
        // 1. మ్యాథ్స్ ఆపరేషన్స్
        int a = 25;
        int b = 4;

        System.out.println("--- మ్యాథ్స్ ఆపరేటర్స్ ---");
        System.out.println("a + b = " + (a + b)); // 29
        System.out.println("a - b = " + (a - b)); // 21
        System.out.println("a * b = " + (a * b)); // 100
        System.out.println("a / b (Integer Division) = " + (a / b));       // 6
        System.out.println("a / b (Decimal Division) = " + ((double)a / b)); // 6.25 (ఫోర్స్ చేసి double లా మార్చాం)
        System.out.println("a % b (శేషం)              = " + (a % b));       // 1

        // 2. షార్ట్ కట్ ఆపరేటర్స్
        int score = 100;
        score += 50;  // 150 అవుతుంది
        score *= 2;   // 300 అవుతుంది
        score -= 75;  // 225 అవుతుంది
        System.out.println("
ఫైనల్ స్కోర్: " + score);

        // 3. కంపేర్ చేయడం (Relational)
        int passMarks = 40;
        int studentScore = 78;
        boolean hasPassed = studentScore >= passMarks;
        boolean isPerfect = studentScore == 100;

        System.out.println("
--- రిజల్ట్స్ ---");
        System.out.println("స్టూడెంట్ పాస్ అయ్యాడా? : " + hasPassed);
        System.out.println("100 కి 100 వచ్చాయా? : " + isPerfect);
    }
}

🔍 Line-by-Line Code Explanation

(double)a / b

డెసిమల్స్ (పాయింట్ వాల్యూస్) మిస్ అవ్వకుండా ఉండటానికి, డివైడ్ చేసే ముందే ఒక నంబర్ ని డబుల్ కి మార్చాం.

a % b

దీన్ని మోడ్యులస్ అంటారు. 25 ని 4 తో భాగిస్తే మిగిలే శేషం (Remainder) 1 వస్తుంది.

score += 50;

ఇది score = score + 50 కి షార్ట్ కట్.

boolean hasPassed = studentScore >= passMarks;

స్టూడెంట్ మార్క్స్ 40 కి సమానంగా లేదా అంతకంటే ఎక్కువ ఉంటే true వస్తుంది.

Practical Real-World Example

☕ PracticalApplication.java — Industry Implementation 
public class EvenOddDemo {
    public static void main(String[] args) {
        int[] numbers = { 14, 27, 40, 99, 102 };

        System.out.println("=== సరి సంఖ్య (Even) / బేసి సంఖ్య (Odd) చెకింగ్ ===");
        
        for (int num : numbers) {
            // ఒక నంబర్ ని 2 తో భాగిస్తే శేషం 0 వస్తే అది Even, లేదంటే Odd
            boolean isEven = (num % 2 == 0);
            System.out.println("నంబర్ " + num + " : " + (isEven ? "EVEN" : "ODD"));
        }
    }
}

⚠️ Common Mistakes & Professional Best Practices
  • బ్రాకెట్స్ మర్చిపోవడం: టెక్స్ట్ పక్కన "Sum: " + 10 + 20 అని ఇస్తే "Sum: 1020" అని వస్తుంది. అదే "Sum: " + (10 + 20) అని ఇస్తే "Sum: 30" వస్తుంది.
  • == కి బదులు = వాడటం: "if (x = 5)" అంటే ఎర్రర్ వస్తుంది. అసైన్ చేయడానికి ఒక్క =, కంపేర్ చేయడానికి == వాడాలి.
  • int / int క్యాలిక్యులేషన్: "double ratio = 1 / 2;" అంటే 0.5 రాదు, 0.0 వస్తుంది. కచ్చితంగా డెసిమల్స్ కావాలంటే "1.0 / 2.0" అని వాడాలి.

💡 Frequently Asked Questions & Interview Insights

❓ ఫ్లోటింగ్ పాయింట్ (డెసిమల్స్) నంబర్స్ ని సున్నాతో డివైడ్ చేస్తే ఏమవుతుంది (ఉదా: 10.0 / 0.0)?

ఇంటిజర్స్ ని 0 తో డివైడ్ చేస్తే క్రాష్ అవుతుంది (ArithmeticException). కానీ డెసిమల్స్ ని డివైడ్ చేస్తే క్రాష్ అవ్వదు, దానికి బదులు ఆన్సర్ "Infinity" అని వస్తుంది. 0.0 ని 0.0 తో డివైడ్ చేస్తే "NaN" (Not a Number) వస్తుంది.

❓ మైనస్ నంబర్స్ కి % (మోడ్యులస్) పనిచేస్తుందా?

చేస్తుంది! జావాలో ఫస్ట్ ఏ నంబర్ ఉందో, దాని సైన్ (+ లేదా -) ఫైనల్ ఆన్సర్ కి వస్తుంది. ఉదాహరణకి -7 % 3 అంటే -1 వస్తుంది. అదే 7 % -3 అంటే 1 వస్తుంది.

🚀 Quick Chapter Recap

  • రెండు ఇంటిజర్స్ ని డివైడ్ చేస్తే పాయింట్ తర్వాత వచ్చే ఆన్సర్ ని జావా కట్ చేస్తుంది.
  • + సింబల్ నంబర్స్ ని కలుపుతుంది, స్ట్రింగ్స్ ని అయితే పక్కపక్కన అతుక్కునేలా (concatenate) చేస్తుంది.
  • +=, -= లాంటివి షార్ట్ కట్ ఆపరేటర్స్. ఇవి టైప్ ని ఆటోమాటిక్ గా అడ్జస్ట్ చేస్తాయి.
  • ==, !=, >, < లాంటివన్నీ అవునా కాదా (true/false) అనే ఆన్సర్ నే ఇస్తాయి.
