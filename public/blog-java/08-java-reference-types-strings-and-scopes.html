Reference Types, Strings, Constants & Variable Scopes (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 8 of 47 📂 Phase 2: Variables & Data Types 📅 2026 Edition
📌 Covered in this chapter:

Primitive vs Reference Types · String Immutability & Pool · final Constants · Variable Scopes: Local, Instance & Static

బేసిక్ డేటా టైప్స్ (Primitive) కీ, రెఫరెన్స్ డేటా టైప్స్ (Reference) కీ తేడా ఏంటి? అసలు జావాలో String ని అంత స్పెషల్ గా ఎందుకు డిజైన్ చేశారు? ఎవరూ మార్చలేని వేరియబుల్స్ (Constants) ఎలా క్రియేట్ చేయాలి? లోకల్, ఇన్స్టాన్స్ వేరియబుల్స్ అంటే ఏంటో చూద్దాం.

1. Primitive కి Reference డేటా టైప్స్ కి తేడా ఏంటి?

జావాలో మెయిన్ గా రెండు రకాల డేటా టైప్స్ ఉంటాయి:

తేడాPrimitive Types (`int`, `double` వగైరా)Reference Types (`String`, `Arrays`, `Classes`)
**ఎక్కడ స్టోర్ అవుతాయి?**
డైరెక్ట్ గా వాల్యూ మొత్తం Stack Memory లోనే ఉంటుంది. | అసలు డేటా Heap Memory లో ఉంటే, దానికి సంబంధించిన అడ్రెస్ (లింక్) మాత్రం Stack లో ఉంటుంది. | | సైజు ఎంత? | ఇది ముందే ఫిక్స్ (1, 2, 4, 8 bytes). | అది తీసుకునే డేటాని బట్టి సైజు మారుతుంది. | | డీఫాల్ట్ వాల్యూ? | 0, false లాంటివి ఉంటాయి. | null ఉంటుంది (అంటే ఏం లేదని). | | ఫంక్షన్స్ వాడొచ్చా? | వాడలేం (దాని పక్కన డాట్ (.) పెడితే ఏమీ రావు). | దానికి సంబంధించిన ఫంక్షన్స్ వాడుకోవచ్చు (ఉదా: name.toUpperCase()). |

2. `String` మరియు String Pool స్టోరీ

జావాలో String అనేది ఒక టెక్స్ట్ ని సేవ్ చేసుకునే ఒక ఆబ్జెక్ట్.

జావాలో స్ట్రింగ్స్ కి ఒక స్పెషాలిటీ ఉంది.. అవేంటంటే Immutable (మార్చలేనివి). ఒకసారి క్రియేట్ చేశాక అందులో అక్షరాల్ని మనం మార్చలేం. ఒకవేళ మీరు ఆ టెక్స్ట్ కి ఇంకొంచెం టెక్స్ట్ ని యాడ్ చేసినా (లేదా మార్చినా), జావా ఏం చేస్తుందంటే.. పాతదాన్ని అలాగే వదిలేసి కొత్త పేరుతో ఇంకో ఆబ్జెక్ట్ ని క్రియేట్ చేస్తుంది.

String Pool అంటే ఏంటి?:

మెమరీ వేస్ట్ అవ్వకుండా ఉండటానికి Heap Memory లోపల ఒక చిన్న ఏరియాని కేటాయించారు. దాన్నే String Pool అంటారు. - మీరు String s1 = "Java"; అన్నారనుకోండి. పూల్ లో "Java" సేవ్ అవుతుంది. - మళ్లీ ఇంకోసారి String s2 = "Java"; అన్నారనుకోండి. ఇప్పుడు కొత్తగా సేవ్ చేయకుండా, ఆల్రెడీ పూల్ లో ఉన్న దాన్నే s2 కి కూడా ఇస్తుంది! అంటే s1, s2 రెండూ ఒకే వాల్యూ ని పాయింట్ చేస్తుంటాయి. - అదే ఒకవేళ మీరు కావాలని new String("Java") అంటే మాత్రం.. పూల్ కి సంబంధం లేకుండా విడిగా ఇంకో ఆబ్జెక్ట్ క్రియేట్ అవుతుంది.

3. `final` కీవర్డ్ తో Constants క్రియేట్ చేయడం

ప్రోగ్రామ్ రన్ అవుతున్నంత సేపు ఒక వేరియబుల్ వాల్యూ ఎవరూ మార్చకూడదు అనుకుంటే, దాని ముందు final అనే కీవర్డ్ పెట్టాలి. వాటినే Constants అంటారు.

ఒకసారి final వేరియబుల్ కి వాల్యూ ఇచ్చాక దాన్ని మళ్ళీ అసైన్ చేయలేం:

public static final double PI = 3.14159;
public static final int MAX_USERS = 5;

బెస్ట్ ప్రాక్టీసెస్:

1. కాన్స్టంట్స్ కి ఎప్పుడూ static final రెండు కలిపి రాయడం మంచిది. ఎందుకంటే ఆ వాల్యూ అందరికీ ఒకటే కాబట్టి మెమరీ సేవ్ అవుతుంది. 2. కాన్స్టంట్స్ పేర్లు ఎప్పుడూ క్యాపిటల్స్ లోనే UPPER_SNAKE_CASE ఉండాలి.

4. మూడు రకాల Variable Scopes

ఒక వేరియబుల్ ని ఎక్కడ డిక్లేర్ చేసాం అనేదాన్ని బట్టి, అది ఎంతసేపు బ్రతికుటుందో ఆధారపడి ఉంటుంది. దీన్నే Scope అంటారు.

+-----------------------------------------------------------------------------------+
|                           JAVA VARIABLE SCOPES                                    |
+-----------------------------------------------------------------------------------+

class Bank {
// 1. STATIC VARIABLE (క్లాస్ లోపల, সবারకి ఒకటే)
public static String bankName = "SBI";
// 2. INSTANCE VARIABLE (క్లాస్ లోపల, కానీ ఒక్కో ఆబ్జెక్ట్ కి ఒక్కో కాపీ)
private double balance = 1000.00;
public void deposit(double amount) {
// 3. LOCAL VARIABLE (ఫంక్షన్ లోపల మాత్రమే బ్రతికుటుంది)
double fee = 10.0;
balance = balance + (amount - fee);
}
}

+-----------------------------------------------------------------------------------+

1. Local Variables: ఒక బ్లాక్ {} లేదా ఫంక్షన్ లోపల రాసేవి. ఆ ఫంక్షన్ అవ్వగానే ఇవి మెమరీ నుంచి పోతాయి. వీటికి ముందే వాల్యూ ఇవ్వాలి.
2. Instance Variables: ఫంక్షన్స్ కి పైన క్లాస్ లో రాసేవి. మనం ఎన్ని ఆబ్జెక్ట్స్ క్రియేట్ చేస్తే అన్ని కాపీలు తయారవుతాయి.
3. Static Variables: క్లాస్ లో రాసి ముందు static అని పెట్టేవి. ఇవి ఎన్ని ఆబ్జెక్ట్స్ క్రియేట్ చేసినా సరే, క్లాస్ కి ఒకటే కాపీ ఉంటుంది. అందరూ దాన్నే వాడుకోవాలి.

Beginner Example & Code Anatomy

☕ Main.java — Chapter 8 Core Example 
public class Main {
    
    // 1. Static Variable (క్లాస్ లెవెల్, అందరికీ ఒకటే)
    public static final String COLLEGE = "XYZ College";
    public static int totalStudents    = 0;

    // 2. Instance Variables (ఆబ్జెక్ట్ లెవెల్, ఎవరికీ వారికి విడిగా ఉంటుంది)
    private String name;
    private double gpa;

    // ఇది కన్స్ట్రక్టర్ (వాల్యూస్ సెట్ చేయడానికి)
    public Main(String n, double g) {
        this.name = n;
        this.gpa = g;
        totalStudents++; // ఆబ్జెక్ట్ క్రియేట్ అయిన ప్రతిసారీ స్టూడెంట్స్ కౌంట్ పెంచుతున్నాం
    }

    public void showData() {
        // 3. Local Variable (ఈ ఫంక్షన్ లోపల మాత్రమే పనిచేస్తుంది)
        String grade = (this.gpa >= 3.5) ? "A Grade" : "B Grade";

        System.out.println("కాలేజ్  : " + COLLEGE);
        System.out.println("పేరు   : " + this.name);
        System.out.println("గ్రేడ్  : " + grade);
        System.out.println("-------------------------");
    }

    public static void main(String[] args) {
        // ఇద్దరు స్టూడెంట్స్ కి ఆబ్జెక్ట్స్ క్రియేట్ చేసాం
        Main s1 = new Main("Balaji", 3.9);
        Main s2 = new Main("Ravi", 3.2);

        s1.showData();
        s2.showData();

        // స్టాటిక్ వేరియబుల్ కావడంతో టోటల్ కౌంట్ 2 అయింది
        System.out.println("మొత్తం స్టూడెంట్స్: " + Main.totalStudents);
    }
}

Practical Real-World Example

☕ PracticalApplication.java — Industry Implementation 
public class StringPoolTest {
    public static void main(String[] args) {
        // నార్మల్ గా స్ట్రింగ్స్ క్రియేట్ చేస్తే పూల్ లోకి వెళ్తాయి
        String s1 = "Java";
        String s2 = "Java";

        // న్యూ కీవర్డ్ తో క్రియేట్ చేస్తే సపరేట్ గా వెళ్తాయి
        String s3 = new String("Java");

        System.out.println("=== String Pool టెస్ట్ ===");
        
        // "==" అనేది కేవలం అడ్రెస్ (లింక్) ని మాత్రమే చెక్ చేస్తుంది
        System.out.println("s1 == s2 : " + (s1 == s2)); // పూల్ లో ఒకటే లింక్ కాబట్టి true
        System.out.println("s1 == s3 : " + (s1 == s3)); // s3 సపరేట్ కాబట్టి false

        // ".equals()" వాల్యూ ని చెక్ చేస్తుంది కాబట్టి రెండూ true వస్తాయి
        System.out.println("s1.equals(s3) : " + s1.equals(s3)); 
    }
}

=== String Pool టెస్ట్ === s1 == s2 : true s1 == s3 : false s1.equals(s3) : true
⚠️ Common Mistakes & Professional Best Practices
  • స్ట్రింగ్స్ వాల్యూ సమానంగా ఉందో లేదో "==" తో చెక్ చేయడం: ఇది అస్సలు చేయకూడదు. జావాలో ఎప్పుడూ "str1.equals(str2)" అని మాత్రమే వాడాలి.
  • final వేరియబుల్ ని మార్చాలని చూడటం: "final int x = 10; x = 20;" అంటే జావా ఒప్పుకోదు.
  • స్టాటిక్ ఫంక్షన్ లోపల ఇన్స్టాన్స్ వేరియబుల్ వాడటం: main అనేది స్టాటిక్ ఫంక్షన్. అందులో డైరెక్ట్ గా స్టాటిక్ కాని వేరియబుల్స్ వాడితే ఎర్రర్ వస్తుంది.

💡 Frequently Asked Questions & Interview Insights

❓ స్ట్రింగ్స్ ని ఎందుకు Immutable (మార్చలేనివిగా) చేసారు?

సెక్యూరిటీ కోసం! పాస్వర్డ్స్, డేటాబేస్ లింక్స్ అన్నీ స్ట్రింగ్స్ లోనే ఇస్తాం. ఎవరైనా హ్యాకర్ వాటిని మార్చాలని చూసినా మార్చలేరు. అలాగే పూల్ లో స్టోర్ చేసి మెమరీ సేవ్ చేయడానికి కూడా ఇది ఉపయోగపడుతుంది.

❓ static కీ, final కీ తేడా ఏంటి?

"static" అంటే అందరికీ కలిపి ఒకటే కాపీ ఉందని అర్థం. "final" అంటే ఆ కాపీ వాల్యూ ఇంక మారదు అని అర్థం.
