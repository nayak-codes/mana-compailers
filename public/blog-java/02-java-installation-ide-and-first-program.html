02. ఎన్విరాన్‌మెంట్ సెటప్, JDK 21+ & మొదటి ప్రోగ్రామ్ (Environment Setup, JDK 21+ & First Program)

☕ Java (Java 21+ LTS) 🟢 Lesson 02 of 25 📂 Part 01: Basics & JVM (Page 2 of 5) ⏱️ 22 min read
📌 Covered in this lesson: Architect's Toolkit Analogy · OpenJDK 21 LTS Installation · JAVA_HOME & System PATH Configuration · VS Code vs IntelliJ IDEA Setup · First Hello World Program · javac & java CLI Anatomy · Classpath Mechanics · 5 Production Pitfalls

ఏదైనా ప్రోగ్రామింగ్ భాషలో గొప్ప సాఫ్ట్‌వేర్ ఇంజనీర్‌గా ఎదగడానికి మొదటి మరియు అత్యంత దృఢమైన పునాది — మీ స్థానిక కంప్యూటర్‌లో డెవలప్‌మెంట్ ఎన్విరాన్‌మెంట్‌ను సరైన పరిశ్రమ ప్రమాణాలతో నిర్మించుకోవడం. జావా ప్రపంచంలో కేవలం ఒక కంపైలర్ ఉంటే సరిపోదు; సిస్టమ్ పాత్ కాన్ఫిగరేషన్, ఆధునిక ఇంటెలిజెంట్ IDE, మరియు బిల్డ్ టూల్స్ అనుసంధానం అత్యంత కీలకం.

ఆర్కిటెక్ట్ వర్క్‌షాప్ & టూల్‌కిట్ అనాలజీ (The Architect's Workshop & Toolkit Analogy):
1. JDK 21 (The Heavy Machinery Workshop): ఒక అంతర్జాతీయ స్థాయి భవన నిర్మాణ శిల్పికి అవసరమైన క్రేన్లు, మెటల్ కట్టర్లు, లేజర్ స్కేలర్లు మరియు రోలింగ్ మెషీన్లు ఎలాగో — ఒక ప్రొఫెషనల్ జావా డెవలపర్‌కు కంపైలర్ (javac), రన్‌టైమ్ వర్చువల్ మెషీన్ (java), డాక్యుమెంటర్ (javadoc), మరియు ప్యాకేజింగ్ ఆర్కైవర్ (jar) ఉండే పూర్తి వర్క్‌షాప్ JDK (Java Development Kit).
2. JAVA_HOME & PATH (The Global GPS Navigation Address): మీ వర్క్‌షాప్ నగరం నడిబొడ్డున ఉన్నా, దానికి సరైన రోడ్డు లేదా జీపీఎస్ అడ్రస్ లేకపోతే ఎవరు చేరుకోలేరు. అలాగే విండోస్ లేదా లైనక్స్ ఆపరేటింగ్ సిస్టమ్‌కు జావా టూల్స్ ఎక్కడ ఉన్నాయో చూపే సిస్టమ్ GPS అడ్రస్సే JAVA_HOME మరియు PATH ఎన్విరాన్‌మెంట్ వేరియబుల్స్.
3. IDE - IntelliJ IDEA / VS Code (The Modern Digital Drafting Studio): కాగితంపై పెన్సిల్‌తో డ్రాయింగ్ వేసే బదులు, తప్పులు జరిగితే వెంటనే హెచ్చరించే ఆటో-కరెక్షన్, బ్లూప్రింట్ 3D ప్రివ్యూ, మరియు ఎర్రర్ వార్నింగ్స్ ఇచ్చే అత్యాధునిక డిజిటల్ ఆర్కిటెక్చర్ కంప్యూటర్ స్టూడియో లాంటిదే ఆధునిక IDE.

ఈ రెండవ పాఠంలో మనం పరిశ్రమ ప్రమాణమైన OpenJDK 21 (LTS) ను సున్నా నుండి ఇన్‌స్టాల్ చేయడం, విండోస్ ఎన్విరాన్‌మెంట్ వేరియబుల్స్ సెట్ చేయడం, టెర్మినల్ ద్వారా మన మొదటి జావా ప్రోగ్రామ్‌ను కంపైల్ చేసి రన్ చేయడం, మరియు డెవలపర్లు ఎదుర్కొనే ప్రధాన లోపాలను లోతుగా నేర్చుకుందాం!

1 సరైన JDK ఎంపిక: Oracle JDK vs OpenJDK సమగ్ర పోలిక

జావా ప్రపంచంలోకి అడుగుపెట్టే ప్రతి కొత్త డెవలపర్‌కు వచ్చే మొదటి మరియు అత్యంత ప్రధానమైన సందేహం — "మార్కెట్లో ఇన్ని రకాల JDKలు ఉన్నాయి కదా, నేను దేనిని డౌన్‌లోడ్ చేసుకోవాలి?". గతంలో కేవలం Sun Microsystems మాత్రమే జావాను విడుదల చేసేది. అయితే 2006లో జావాను ఓపెన్ సోర్స్ చేసిన తర్వాత, ప్రపంచవ్యాప్తంగా అనేక టెక్ దిగ్గజాలు తమ స్వంత పంపిణీలను (Distributions) రూపొందిస్తున్నాయి. ప్రస్తుతం అందుబాటులో ఉన్న ప్రధాన JDK ఎంపికలను కింది పట్టికలో పరిశీలిద్దాం:

ఫీచర్ Oracle JDK Eclipse Temurin (Adoptium OpenJDK) Amazon Corretto / MS OpenJDK
లైసెన్సింగ్ మోడల్ (License) OTN License (కమర్షియల్ ప్రొడక్షన్ కోసం కంపెనీలు భారీగా లైసెన్స్ ఫీజు చెల్లించాలి). GPL v2 with Classpath Exception (100% ఉచితం, పూర్తి ఓపెన్ సోర్స్). GPL v2 (పూర్తి ఉచితం, క్లౌడ్ ఆప్టిమైజ్డ్).
ఉపయోగ పరిధి (Usage Scope) పర్సనల్ లెర్నింగ్ మరియు లోకల్ టెస్టింగ్‌కు మాత్రమే ఉచితం. ఎంటర్‌ప్రైజ్ ప్రొడక్షన్, స్టార్టప్‌లు & బిజినెస్ ప్రాజెక్టులకు పూర్తి ఉచితం. AWS, Azure క్లౌడ్ మరియు మైక్రోసర్వీసులకు అనుకూలం.
LTS మద్దతు (Support) Oracle స్వంత పెయిడ్ సపోర్ట్ ప్లాన్. Adoptium వర్కింగ్ గ్రూప్ (Google, Microsoft, Red Hat, IBM) సంయుక్త సపోర్ట్. Amazon & Microsoft స్వంత క్లౌడ్ సపోర్ట్.
పరిశ్రమ సిఫార్సు కేవలం లెగసీ లైసెన్స్ ఉన్న కార్పొరేట్ కంపెనీలు. డెవలపర్లు, విద్యార్థులు & ప్రొఫెషనల్ ఇంజనీర్లకు నంబర్ 1 సిఫార్సు! క్లౌడ్ ఆధారిత అప్లికేషన్లకు సిఫార్సు.

💡 Industry Standard Recommendation (పరిశ్రమ ప్రమాణం):

మాస్టర్‌క్లాస్ విద్యార్థులందరికీ మేము Eclipse Temurin (Adoptium) OpenJDK 21 (LTS) ను బలంగా సిఫార్సు చేస్తున్నాము. ఇది అధికారిక Java SE TCK (Technology Compatibility Kit) ను 100% విజయవంతంగా పాస్ అయిన అత్యంత స్థిరమైన, పరిశ్రమలో విస్తృతంగా ఉపయోగించబడుతున్న డిస్ట్రిబ్యూషన్. దీనిని ప్రొడక్షన్‌లో వాడినా కంపెనీలకు ఎలాంటి లీగల్ లేదా లైసెన్సింగ్ సమస్యలు తలెత్తవు.

2 OpenJDK 21 LTS ఇన్‌స్టాలేషన్ స్టెప్-బై-స్టెప్

మీ కంప్యూటర్‌లో OpenJDK 21 ని సురక్షితంగా మరియు పక్కాగా ఇన్‌స్టాల్ చేయడానికి కింది 4 దశలను అనుసరించండి:

  1. అధికారిక వెబ్‌సైట్ సందర్శన: మీ బ్రౌజర్‌లో https://adoptium.net వెబ్‌సైట్‌కు వెళ్లండి.
  2. వెర్షన్ ఎంపిక: హోమ్‌పేజీలో కనిపించే Temurin 21 (LTS) బటన్‌పై క్లిక్ చేయండి. మీ ఆపరేటింగ్ సిస్టమ్ విండోస్ అయితే Windows x64 ఆర్కిటెక్చర్‌ను ఎంచుకుని .msi (Windows Installer) ఫైల్‌ను డౌన్‌లోడ్ చేసుకోండి.
  3. ఇన్‌స్టాలర్ విజార్డ్ ప్రారంభం: డౌన్‌లోడ్ అయిన .msi ఫైల్‌పై డబుల్ క్లిక్ చేయండి. "Welcome to Eclipse Temurin Setup Wizard" స్క్రీన్ కనిపిస్తుంది. Next క్లిక్ చేయండి.
  4. కస్టమ్ సెటప్ ఫీచర్స్ (కీలకమైన దశ!): ఫీచర్ల జాబితాలో కింది రెండు ఆప్షన్లను తప్పనిసరిగా ఎనేబుల్ చేయండి:
      • "Add to PATH" — దీనిని "Entire feature will be installed on local hard drive" గా మార్చండి.
      • "Set JAVA_HOME variable" — దీని పక్కన ఉన్న డ్రాప్‌డౌన్ క్లిక్ చేసి "Entire feature will be installed on local hard drive" ను సెలెక్ట్ చేసుకోండి.
  5. ఇన్‌స్టాలేషన్ పూర్తి: Install క్లిక్ చేయండి. యూజర్ అకౌంట్ కంట్రోల్ (UAC) పాప్-అప్ వచ్చినప్పుడు Yes క్లిక్ చేస్తే కొన్ని సెకన్లలో ఇన్‌స్టాలేషన్ విజయవంతంగా పూర్తవుతుంది.

3 JAVA_HOME & System PATH కాన్ఫిగరేషన్ (మ్యాన్యువల్ వెరిఫికేషన్)

కొన్నిసార్లు ఇన్‌స్టాలర్ ద్వారా ఆటోమేటిక్‌గా వేరియబుల్స్ సెట్ కాకపోవచ్చు, లేదా మీరు .zip ఆర్కైవ్ ద్వారా పోర్టబుల్ JDK ని డౌన్‌లోడ్ చేసుకుని ఉండవచ్చు. అటువంటి పరిస్థితుల్లో విండోస్ ఎన్విరాన్‌మెంట్ వేరియబుల్స్‌ను మ్యాన్యువల్‌గా ఎలా కాన్ఫిగర్ చేయాలో ప్రతి సాఫ్ట్‌వేర్ ఇంజనీర్ తప్పనిసరిగా తెలుసుకోవాలి:

⚙️ Step-by-Step Manual Environment Configuration:

1. విండోస్ సెర్చ్ బార్‌లో Win + S ప్రెస్ చేసి "environment variables" అని టైప్ చేసి "Edit the system environment variables" ను ఓపెన్ చేయండి.
2. క్రింద కనిపించే "Environment Variables..." బటన్‌ను క్లిక్ చేయండి.
3. "System variables" (క్రింది బాక్స్) లో New... బటన్ నొక్కండి:
  • Variable name: JAVA_HOME
  • Variable value: C:\Program Files\Eclipse Adoptium\jdk-21.0.2-hotspot\ (గమనిక: చివర bin ఫోల్డర్ ఉండకూడదు, కేవలం JDK రూట్ ఫోల్డర్ మాత్రమే ఇవ్వాలి).
4. ఇప్పుడు System variables జాబితాలో Path అనే వేరియబుల్ ఉంటుంది. దానిని సెలెక్ట్ చేసి Edit... క్లిక్ చేయండి.
5. విండో కుడివైపున ఉన్న New బటన్ నొక్కి %JAVA_HOME%\bin అని టైప్ చేయండి.
6. పైకి తరలించడానికి Move Up బటన్ నొక్కి దానిని మొదటి స్థానాల్లో ఉంచండి, తర్వాత అన్ని డైలాగ్ బాక్సులలో OK నొక్కండి.

JAVA_HOME ఎందుకు అంత ముఖ్యం? పరిశ్రమలో మీరు భవిష్యత్తులో ఉపయోగించే స్ప్రింగ్ బూట్ (Spring Boot), మేవెన్ (Apache Maven), గ్రేడిల్ (Gradle), డాకర్ (Docker), మరియు టామ్‌క్యాట్ (Apache Tomcat) సర్వర్లు మీ సిస్టమ్‌లోని జావా రన్‌టైమ్‌ను కనుగొనడానికి JAVA_HOME ఎన్విరాన్‌మెంట్ వేరియబుల్‌నే ప్రామాణికంగా ఉపయోగిస్తాయి.

5 IDE ఎంపిక: IntelliJ IDEA vs Visual Studio Code

ఆధునిక సాఫ్ట్‌వేర్ ఇంజనీరింగ్‌లో వేగవంతమైన కోడింగ్, ఆటోమేటిక్ రీఫ్యాక్టరింగ్, మరియు విజువల్ డీబగ్గింగ్ కోసం ఒక సమర్థవంతమైన IDE (Integrated Development Environment) ని ఎంచుకోవడం అత్యంత ముఖ్యం:

ఫీచర్ IntelliJ IDEA (Community Edition) Visual Studio Code (VS Code)
ఉద్దేశం (Focus) 100% జావా మరియు JVM ఆధారిత లాంగ్వేజెస్ కోసం ప్రత్యేకంగా నిర్మించబడింది. జనరల్ పర్పస్ మల్టీ-లాంగ్వేజ్ టెక్స్ట్ ఎడిటర్.
కోడ్ ఇంటెలిజెన్స్ ప్రపంచంలో అత్యుత్తమ సింటాక్స్ అనాలిసిస్, స్మార్ట్ ఆటో-ఇంపోర్ట్స్, మరియు ఇన్-డెప్త్ స్టాటిక్ అనాలిసిస్. "Extension Pack for Java" ప్లగిన్ ద్వారా మంచి ఫీచర్లు లభిస్తాయి.
మెమరీ వినియోగం కాస్త ఎక్కువ RAM అవసరం (కనీసం 8GB సిఫార్సు చేయబడింది). లైట్‌వెయిట్, తక్కువ RAM లో కూడా వేగంగా నడుస్తుంది.
ఎంటర్‌ప్రైజ్ స్వీకరణ ప్రపంచంలోని 80% కంటే ఎక్కువ ఫార్చ్యూన్ 500 కంపెనీల డెవలపర్లు వాడతారు. ఫ్రంట్‌ఎండ్ (React, Vue) మరియు బ్యాకెండ్ రెండింటినీ కలిపి వాడేవారికి ఫేవరెట్.

🚀 Recommended Setup for Beginners:

మీరు ప్రారంభ దశలో ఉన్నట్లయితే మరియు మీ సిస్టమ్‌లో 8GB లేదా అంతకంటే ఎక్కువ RAM ఉంటే, నేరుగా IntelliJ IDEA Community Edition ను డౌన్‌లోడ్ చేసుకోండి (ఇది ఉచితం). ఒకవేళ మీ సిస్టమ్ కాన్ఫిగరేషన్ 4GB RAM లేదా లైట్‌వెయిట్ ల్యాప్‌టాప్ అయితే VS Code లో "Extension Pack for Java" ని ఇన్‌స్టాల్ చేసుకుని కొనసాగవచ్చు.

6 మొదటి "Hello World" ప్రోగ్రామ్ అనాటమీ

మీ డెస్క్‌టాప్ లేదా ఏదైనా వర్కింగ్ ఫోల్డర్‌లో HelloWorld.java అనే పేరుతో ఒక కొత్త ఫైల్‌ను సృష్టించండి. జావాలో ఒక ప్రధాన నియమం గుర్తుంచుకోండి: ఫైల్ పేరు మరియు కోడ్‌లోని public class పేరు ఖచ్చితంగా ఒక్కటే కావాలి!

కింది కోడ్‌ను HelloWorld.java లో రాయండి:

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("నమస్కారం, జావా ప్రపంచం! (Hello World from Java 21!)");
    }
}

ఈ కోడ్‌లోని ప్రతి పదం యొక్క ఉద్దేశం ఏమిటి?

  • public class HelloWorld: జావాలో ప్రతి కోడ్ లైన్ ఏదో ఒక క్లాస్ లోపలే ఉండాలి. public అంటే ఈ క్లాస్‌ను ఎవరైనా యాక్సెస్ చేయవచ్చు.
  • public static void main(String[] args): ఇది జావా ప్రోగ్రామ్ యొక్క ఎగ్జిక్యూషన్ స్టార్టింగ్ పాయింట్ (ఎంట్రీ గేట్). JVM ఈ నిర్దిష్ట సిగ్నేచర్ కోసమే ఫైల్‌లో వెతుకుతుంది.
  • System.out.println(): స్క్రీన్ లేదా టెర్మినల్ కన్సోల్‌పై సమాచారాన్ని ప్రింట్ చేసి కొత్త లైన్‌కు కర్సర్‌ను తరలించే జావా బిల్ట్-ఇన్ మెథడ్.

7 కంపైలేషన్ & ఎగ్జిక్యూషన్ అంతర్గత ప్రాసెస్

మనం టెర్మినల్‌లో javac HelloWorld.java అని రన్ చేసినప్పుడు మరియు java HelloWorld అని ఎగ్జిక్యూట్ చేసినప్పుడు కంప్యూటర్ లోపల జరిగే అంతర్గత ప్రక్రియను పరిశీలిద్దాం:

🔬 The Two-Step Journey (javac to java):

1. javac HelloWorld.java (Compilation Phase):
జావా కంపైలర్ మీ సోర్స్ కోడ్‌లోని సింటాక్స్ మరియు వ్యాకరణ నియమాలను క్షుణ్ణంగా తనిఖీ చేస్తుంది. ఎలాంటి తప్పులు లేకపోతే, కంప్యూటర్ హార్డ్‌వేర్ ఆర్కిటెక్చర్‌తో నిమిత్తం లేని HelloWorld.class అనే Bytecode ఫైల్‌ను ఉత్పత్తి చేస్తుంది.

2. java HelloWorld (Runtime Execution Phase):
జావా రన్‌టైమ్ (JVM) స్టార్ట్ అవుతుంది. ClassLoader ద్వారా HelloWorld.class లోడ్ అవుతుంది. బైట్‌కోడ్ వెరిఫైయర్ ద్వారా భద్రత ధృవీకరించబడుతుంది. అనంతరం ఎగ్జిక్యూషన్ ఇంజిన్ (JIT Compiler) ఆ బైట్‌కోడ్‌ను మీ ప్రాసెసర్ అర్థం చేసుకునే నేటివ్ మెషీన్ కోడ్ (0s & 1s) లోకి మార్చి రన్ చేస్తుంది!

8 కోడ్ డెమో 1: సిస్టమ్ ఎన్విరాన్‌మెంట్ ఇన్స్పెక్టర్

మీ సిస్టమ్‌లోని జావా రన్‌టైమ్ వెర్షన్, ఆపరేటింగ్ సిస్టమ్ ఆర్కిటెక్చర్, మరియు యూజర్ డైరెక్టరీ వివరాలను వెలికితీసే సమగ్ర డయాగ్నోస్టిక్ ప్రోగ్రామ్:

EnvironmentInspector.java 
public class EnvironmentInspector {
    public static void main(String[] args) {
        System.out.println("==================================================");
        System.out.println("       JAVA RUNTIME & ENVIRONMENT INSPECTOR       ");
        System.out.println("==================================================");

        // Fetching system environment and JVM properties
        String javaVersion = System.getProperty("java.version");
        String javaVendor  = System.getProperty("java.vendor");
        String javaHome    = System.getProperty("java.home");
        String osName      = System.getProperty("os.name");
        String osArch      = System.getProperty("os.arch");
        String userDir     = System.getProperty("user.dir");

        System.out.println("Working Directory: " + userDir);
        System.out.println("File Encoding    : " + fileEncoding);
        System.out.println("--------------------------------------------------");
        System.out.println("Environment Status: [VERIFIED] All Systems Ready!");
        System.out.println("==================================================");
    }
}

9 కోడ్ డెమో 2: మల్టీ-లైన్ కన్సోల్ అవుట్‌పుట్ & ఫార్మాటింగ్ ఇంజిన్

10 కోడ్ డెమో 3: డెవలపర్ వర్క్‌స్పేస్ వెరిఫైయర్ (Capstone Mini Project)

ఒక పూర్తిస్థాయి డెవలపర్ టూల్‌కిట్: సిస్టమ్‌లో లభ్యమయ్యే CPU కోర్లు, JVM కి కేటాయించిన గరిష్ట మరియు ఉచిత మెమరీ, మరియు గార్బేజ్ కలెక్టర్ కెపాసిటీని విశ్లేషించే Java Workspace Telemetry & Health Engine:

WorkspaceTelemetryEngine.java 
public class WorkspaceTelemetryEngine {
    public static void main(String[] args) {
        Runtime runtime = Runtime.getRuntime();

        int availableCores = runtime.availableProcessors();
        long maxMemoryMB   = runtime.maxMemory() / (1024 * 1024);
        long totalMemoryMB = runtime.totalMemory() / (1024 * 1024);
        long freeMemoryMB  = runtime.freeMemory() / (1024 * 1024);
        long usedMemoryMB  = totalMemoryMB - freeMemoryMB;

        System.out.println("==================================================");
        System.out.println("      WORKSPACE TELEMETRY & HARDWARE PROFILER     ");
        System.out.println("==================================================");
        System.out.println("CPU Available Cores : " + availableCores);
        System.out.println("JVM Max Memory Alloc: " + maxMemoryMB + " MB");
        System.out.println("JVM Total Heap Size : " + totalMemoryMB + " MB");
        System.out.println("JVM Active Memory   : " + usedMemoryMB + " MB");
        System.out.println("JVM Free Headroom   : " + freeMemoryMB + " MB");
        System.out.println("System Architecture : " + System.getProperty("os.arch"));
        System.out.println("--------------------------------------------------");

        if (maxMemoryMB >= 1024) {
            System.out.println("Hardware Telemetry: [EXCELLENT] Ready for High-Throughput Java Apps!");
        } else {
            System.out.println("Hardware Telemetry: [MODERATE] Suitable for Standard Console Apps.");
        }
        System.out.println("==================================================");
    }
}

11 డెవలపర్లు ఎదుర్కొనే 5 కామన్ ఎర్రర్లు & పరిష్కారాలు

కొత్తగా జావా నేర్చుకునే సమయంలో 90% మంది డెవలపర్లు ఎదుర్కొనే ప్రధాన సమస్యలు, వాటి మూల కారణాలు మరియు పరిష్కారాలు:

ఎర్రర్ మెసేజ్ మూల కారణం (Root Cause) ఖచ్చితమైన పరిష్కారం (Exact Solution)
'javac' is not recognized as an internal or external command విండోస్ PATH వేరియబుల్‌లో JDK యొక్క bin డైరెక్టరీ యాడ్ కాలేదు. System Environment Variables లో %JAVA_HOME%\bin ని యాడ్ చేసి, ఇప్పటికే తెరిచి ఉన్న కమాండ్ ప్రాంప్ట్‌ను క్లోజ్ చేసి కొత్తది తెరవండి.
Class names are only accepted if annotation processing is explicitly requested కంపైల్ చేసేటప్పుడు ఫైల్ పేరు చివర .java ఎక్స్‌టెన్షన్ ఇవ్వడం మర్చిపోయారు. javac HelloWorld కాకుండా ఖచ్చితంగా javac HelloWorld.java అని ఎక్స్‌టెన్షన్‌తో రన్ చేయండి.
Could not find or load main class HelloWorld రన్ చేసే సమయంలో పొరపాటున java HelloWorld.class అని .class ఎక్స్‌టెన్షన్ ఇవ్వడం. ఎగ్జిక్యూట్ చేసేటప్పుడు .class తీసేసి కేవలం java HelloWorld అని మాత్రమే క్లాస్ పేరు ఇవ్వాలి.
class HelloWorld is public, should be declared in a file named HelloWorld.java ఫైల్ పేరు మరియు కోడ్‌లోని public class పేరు స్పెల్లింగ్ లేదా కేస్‌లో సరిపోలలేదు. జావా కేస్-సెన్సిటివ్ కాబట్టి రెండు పేర్లలోని అక్షరాలు (క్యాపిటల్/స్మాల్) అక్షరాలా సరిపోలేలా మార్చండి.
Main method not found in class main మెథడ్ సిగ్నేచర్‌లో static లేదా String[] args తప్పుగా రాయడం. public static void main(String[] args) అనే అధికారిక సింటాక్స్‌ను ఖచ్చితంగా పాటించండి.

12 బెస్ట్ ప్రాక్టీసెస్ & 5 ఇంటరాక్టివ్ క్విజ్‌లు

మీ డెవలప్‌మెంట్ ఎన్విరాన్‌మెంట్‌ను ఎల్లప్పుడూ క్లీన్‌గా మరియు ప్రొడక్షన్-రెడీగా ఉంచడానికి ఈ సూత్రాలు పాటించండి:

  • ఎల్లప్పుడూ LTS (Long-Term Support) వెర్షన్లను మాత్రమే ఎంచుకోండి (ప్రస్తుతం Java 17 లేదా Java 21 LTS).
  • ప్రాజెక్టులను సిస్టమ్ OS (C:) డ్రైవ్‌లో కాకుండా ప్రత్యేకమైన డెవలప్‌మెంట్ డ్రైవ్ (ఉదా: D:\workspace\java) లో నిర్వహించండి.
  • VS Code లేదా IntelliJ లో జావా ఫైల్స్ సేవ్ చేసేటప్పుడు ఎన్‌కోడింగ్ ఎల్లప్పుడూ UTF-8 లో ఉండేలా చూసుకోండి.
  • javac కమాండ్‌తో కంపైల్ చేసేటప్పుడు -d bin ఫ్లాగ్ వాడి బైట్‌కోడ్ ఫైల్స్‌ను ప్రత్యేక ఫోల్డర్‌లో ఆర్గనైజ్ చేయండి.

🧠 మీ అవగాహనను పరీక్షించుకోండి (5 Interactive Quizzes):

ప్రశ్న 1: జావా కంపైల్ చేయడానికి మరియు రన్ చేయడానికి కమాండ్ లైన్‌లో ఏ కమాండ్స్ వాడాలి?

సమాధానం: కంపైల్ చేయడానికి javac FileName.java, రన్ చేయడానికి java ClassName వాడాలి.

ప్రశ్న 2: 'java HelloWorld.class' అని రన్ చేస్తే ఏమి జరుగుతుంది?

సమాధానం: ఎర్రర్ వస్తుంది! JVM HelloWorld.class అనే పేరుతో ఒక క్లాస్ లోపల ప్యాకేజ్ కోసం వెతుకుతుంది. సరైన కమాండ్ కేవలం java HelloWorld మాత్రమే.

ప్రశ్న 3: JAVA_HOME పాత్ ఎందుకు సెట్ చేయాలి?

సమాధానం: Maven, Gradle, Tomcat, మరియు IDE ల వంటి టూల్స్ మీ సిస్టమ్‌లోని JDK లొకేషన్‌ను స్వయంచాలకంగా గుర్తించడానికి JAVA_HOME ఎన్విరాన్‌మెంట్ వేరియబుల్ పై ఆధారపడతాయి.

ప్రశ్న 4: ఒక .java ఫైల్ లో public class పేరు "MyBankApp" అయితే ఫైల్ పేరు ఏమై ఉండాలి?

సమాధానం: ఖచ్చితంగా MyBankApp.java మాత్రమే అయి ఉండాలి (Case-Sensitive).

ప్రశ్న 5: Eclipse Temurin OpenJDK ఎందుకు ఇండస్ట్రీలో ప్రాచుర్యం పొందింది?

సమాధానం: ఇది పూర్తిగా ఉచితం, ఓపెన్ సోర్స్, TCK కంప్లయంట్, మరియు ఎలాంటి కమర్షియల్ లైసెన్స్ ఫీజు లేకుండా ప్రొడక్షన్‌లో వాడుకోవచ్చు.
