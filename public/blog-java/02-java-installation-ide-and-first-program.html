Java Installation, IDEs & First Hello World Program (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 2 of 47 📂 Phase 1: Java Basics 📅 2026 Edition
📌 Covered in this chapter:

JDK 21 LTS Installation · Setting JAVA_HOME & PATH · IDEs vs Online Compiler · First Program Breakdown · main() Signature Anatomy · System.out.println

మీ కంప్యూటర్ లో Java 21 LTS ని ఎలా ఇన్స్టాల్ చేయాలి? ప్రొఫెషనల్స్ వాడే IDEs (IntelliJ IDEA, VS Code) ఏంటి? మీ మొదటి Hello World ప్రోగ్రామ్ ఎలా రాయాలి? అందులో ఉన్న పబ్లిక్, స్టాటిక్ లాంటి ప్రతి పదం వెనక ఉన్న అర్థం ఏంటో డీటెయిల్డ్ గా చూద్దాం.

1. Java 21 LTS ఇన్స్టాలేషన్ & ఎన్విరాన్మెంట్ వేరియబుల్స్ సెటప్

మనం ఎప్పుడైనా జావా డౌన్లోడ్ చేసేటప్పుడు Long-Term Support (LTS) వెర్షన్ నే (ఉదా: Java 21 LTS లేదా 17 LTS) డౌన్లోడ్ చేసుకోవాలి.
- Oracle JDK: [oracle.com/java](https://www.oracle.com/java/)
- Eclipse Temurin: [adoptium.net](https://adoptium.net/) (ఇది చాలా కంపెనీల్లో వాడే ఫ్రీ అండ్ ఓపెన్ సోర్స్ వెర్షన్)

Windows లో Environment Variables సెట్ చేయడం:

జావా ఇన్స్టాల్ చేసిన తర్వాత, మన సిస్టమ్ కి జావా ఎక్కడుందో చెప్పాలి: 1. JAVA_HOME: ఒక కొత్త వేరియబుల్ క్రియేట్ చేసి, అందులో జావా ఇన్స్టాల్ అయిన ఫోల్డర్ పాత్ (ఉదా: C:\Program Files\Eclipse Adoptium\jdk-21.0.2) ఇవ్వాలి. 2. PATH: సిస్టమ్ లో ఉన్న Path వేరియబుల్ కి %JAVA_HOME%\bin ని యాడ్ చేయాలి. అప్పుడే మనం టెర్మినల్ లో javac, java కమాండ్స్ వాడగలం.

2. కోడ్ రాయడానికి బెస్ట్ ఎడిటర్స్ (IDEs) ఏవి?

కంపెనీల్లో కోడ్ రాయడానికి నార్మల్ నోట్ ప్యాడ్ వాడరు. తప్పులు ముందే చూపించే స్మార్ట్ ఎడిటర్స్ (IDEs) వాడతారు:

- IntelliJ IDEA (JetBrains): జావా అనగానే గుర్తొచ్చే నెంబర్ వన్ సాఫ్ట్ వేర్ ఇదే. చాలా ఫాస్ట్ గా ఉంటుంది, తప్పులు ముందే చెప్తుంది.
- Visual Studio Code (VS Code): మైక్రోసాఫ్ట్ వాళ్ళది. ఇది కూడా ఫాస్ట్ అండ్ సింపుల్. "Extension Pack for Java" ఇన్స్టాల్ చేసుకుంటే సరిపోతుంది.
- Eclipse IDE: ఇది చాలా పాతది కానీ ఇంకా కొన్ని పెద్ద కంపెనీల్లో పాత ప్రాజెక్ట్స్ కోసం వాడుతున్నారు.
- Our Compiler (Online): సాఫ్ట్ వేర్స్ ఏమీ లేకుండా డైరెక్ట్ గా బ్రౌజర్ లోనే ప్రాక్టీస్ చేయాలంటే మన ఆన్లైన్ కంపైలర్ వాడుకోవచ్చు.

3. First Java Program: అందులో ఉన్న ప్రతి పదం అర్థం ఏంటి?

ఇది జావాలో రాసే ఫస్ట్ బేసిక్ ప్రోగ్రామ్:

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

చూడటానికి చాలా పదాలు ఉన్నట్టు అనిపిస్తాయి, కానీ ఒక్కొక్క పదం వెనక ఒక రీజన్ ఉంది:

1. public class Main

- public (Access Modifier): దీన్ని పబ్లిక్ అని ఇస్తేనే బయట ఎక్కడినుంచైనా ఈ కోడ్ ని యాక్సెస్ చేయగలం. - class (Keyword): జావాలో మనం రాసే కోడ్ అంతా ఒక క్లాస్ లోపలే ఉండాలి. - Main (పేరు): మన ఫైల్ కి పెట్టుకున్న పేరు. ఇంపార్టెంట్ రూల్: క్లాస్ కి పబ్లిక్ అని ఇస్తే.. ఆ ఫైల్ పేరు, క్లాస్ పేరు ఎగ్జాక్ట్ గా ఒకేలా ఉండాలి (Main.java).

2. public static void main(String[] args)

ప్రోగ్రామ్ ఎక్కడినుంచి స్టార్ట్ అవ్వాలో JVM కి చెప్పే మెయిన్ ఎంట్రీ పాయింట్ ఇదే. - public: JVM ఎక్కడో బయట రన్ అవుతుంటుంది, అది మన ప్రోగ్రామ్ లోకి రావాలంటే దీన్ని పబ్లిక్ గా ఓపెన్ ఉంచాలి. - static: నార్మల్ గా జావాలో ఏ ఫంక్షన్ ని కాల్ చేయాలన్నా దానికి ఆబ్జెక్ట్ క్రియేట్ చేయాలి. కానీ JVM డైరెక్ట్ గా ఈ ఫంక్షన్ ని కాల్ చేయాలి కాబట్టి ఆబ్జెక్ట్ అవసరం లేకుండా static వాడతాం. - void: ఈ ఫంక్షన్ పని అయిపోయాక ఎలాంటి రిజల్ట్ ని వెనక్కి (return) ఇవ్వట్లేదు అని చెప్పడానికి. - main: JVM వెతికే కీవర్డ్ ఇదే, ఈ పేరు చూసే అది ఎంట్రీ పాయింట్ అని గుర్తుపడుతుంది. - String[] args: టెర్మినల్ నుంచి ఎవరైనా మనం రాసిన ప్రోగ్రామ్ కి అదనంగా ఇన్పుట్స్ పంపితే, వాటిని స్టోర్ చేసుకోవడానికి.

3. System.out.println("Hello, World!");

- System: ఇది జావాలో ముందే రాసిపెట్టిన ఒక క్లాస్ పేరు. - out: ఆ క్లాస్ లోపల ఉండే ఒక పబ్లిక్ ప్రాపర్టీ (దీని పని అవుట్పుట్ ని స్క్రీన్ మీద చూపించడం). - println(): టెక్స్ట్ ని ప్రింట్ చేసి, నెక్స్ట్ లైన్ కి వెళ్ళమని చెప్తున్నాం. - ; (Semicolon): జావాలో ప్రతి లైన్ కచ్చితంగా సెమికోలన్ తో ఎండ్ అవ్వాలి (అంటే అక్కడ స్టేట్మెంట్ కంప్లీట్ అయిందని అర్థం).

4. `print()` vs `println()` vs `printf()` మధ్య తేడా?

జావాలో స్క్రీన్ మీద ప్రింట్ చేయడానికి 3 రకాల ఫంక్షన్స్ ఉంటాయి:

Methodఏం చేస్తుంది?ఎగ్జాంపుల్
**`print()`**
టెక్స్ట్ ప్రింట్ అవుతుంది కానీ కర్సర్ అక్కడే ఆగిపోతుంది. నెక్స్ట్ ఏం ప్రింట్ చేసినా పక్కనే వచ్చేస్తుంది. | System.out.print("Hi "); System.out.print("There"); -> Hi There | | println() | టెక్స్ట్ ప్రింట్ అయ్యాక, ఆటోమాటిక్ గా నెక్స్ట్ లైన్ కి వెళ్ళిపోతుంది. | System.out.println("Line 1"); System.out.println("Line 2"); | | printf() | వేరియబుల్స్ లో ఉన్న వాల్యూస్ ని టెక్స్ట్ మధ్యలో నీట్ గా పెట్టి ప్రింట్ చేయడానికి. | System.out.printf("పేరు: %s, వయసు: %d", "Ravi", 25); |

Beginner Example & Code Anatomy

☕ Main.java — Chapter 2 Core Example 
public class Main {
    public static void main(String[] args) {
        // 1. println() వాడితే టెక్స్ట్ ప్రింట్ అయ్యాక కింద లైన్ కి వెళ్తుంది
        System.out.println("1. జావా స్టార్ట్ అయ్యింది.");
        System.out.println("2. ఇది ఇంకో లైన్ లో వస్తుంది:");

        // 2. print() వాడితే పక్కపక్కనే వస్తుంది
        System.out.print("   [డౌన్లోడ్: ");
        System.out.print("25% -> ");
        System.out.print("50% -> ");
        System.out.print("100% పూర్తయింది");
        System.out.println("]"); // ఇక్కడ న్యూ లైన్ కి వెళ్తుంది

        // 3. డైరెక్ట్ గా మ్యాథ్స్ చేయొచ్చు
        System.out.println("3. 10 + 20 ఎంత? = " + (10 + 20));
        System.out.println("4. Welcome to Java!");
    }
}

🔍 Line-by-Line Code Explanation

public class Main

Main.java అనే ఫైల్ పేరుతో ఒక పబ్లిక్ క్లాస్ ని స్టార్ట్ చేస్తున్నాం.

public static void main(String[] args)

ప్రోగ్రామ్ స్టార్ట్ అయ్యే చోటు ఇది. JVM డైరెక్ట్ గా ఈ మెయిన్ ఫంక్షన్ లోకి వస్తుంది.

System.out.print(...)

టెక్స్ట్ ప్రింట్ చేశాక నెక్స్ట్ లైన్ కి వెళ్ళకుండా అక్కడే ఆగిపోవడానికి వాడుతున్నాం.

"..." + (10 + 20)

టెక్స్ట్ ని క్యాలిక్యులేట్ చేసిన నెంబర్ తో కలపడానికి ప్లస్ (+) వాడాం.

Practical Real-World Example

☕ PracticalApplication.java — Industry Implementation 
public class CommandLineArgs {
    public static void main(String[] args) {
        // టెర్మినల్ నుంచి ఎవరైనా ఎక్స్ట్రా డేటా పంపితే args లో స్టోర్ అవుతుంది.
        if (args.length > 0) {
            System.out.println("టెర్మినల్ నుంచి పంపిన ఇన్పుట్స్ ఇవిగో:");
            for (int i = 0; i < args.length; i++) {
                System.out.println("  ఇన్పుట్ [" + i + "]: " + args[i]);
            }
        } else {
            System.out.println("మీరు బయట నుంచి ఎలాంటి ఎక్స్ట్రా ఇన్పుట్ పంపలేదు.");
            System.out.println("ఇలా రన్ చేసి చూడండి: java CommandLineArgs Server 8080");
        }
    }
}

⚠️ Common Mistakes & Professional Best Practices
  • ఫైల్ పేరు, క్లాస్ పేరు వేరువేరుగా ఉండటం: మీరు కోడ్ లో "public class Main" అని రాసి, ఫైల్ ని మాత్రం test.java అని సేవ్ చేస్తే.. ఎర్రర్ వస్తుంది.
  • స్పెల్లింగ్ లేదా క్యాపిటల్ లెటర్స్ తప్పు రాయడం: జావా case-sensitive. అంటే "System" అని రాయాలి కానీ "system" అని రాస్తే ఒప్పుకోదు.
  • సెమికోలన్ మర్చిపోవడం: ప్రతి లైన్ చివర కచ్చితంగా సెమికోలన్ (;) ఉండాలి.
  • మెయిన్ ఫంక్షన్ మార్చడం: "public void main()" అని static తీసేస్తే.. కోడ్ కంపైల్ అవుతుంది కానీ, రన్ చేసేటప్పుడు ఎర్రర్ వస్తుంది.

💡 Frequently Asked Questions & Interview Insights

❓ "String[] args" అని కాకుండా వేరేలా రాయొచ్చా?

రాయొచ్చు! "String args[]" అని కానీ, "String... args" అని కానీ రాసినా జావా యాక్సెప్ట్ చేస్తుంది.

❓ ఒకే ఫైల్ లో రెండు, మూడు క్లాసులు రాయొచ్చా?

రాయొచ్చు. కానీ ఆ ఫైల్ మొత్తంలో ఒక్క క్లాస్ కి మాత్రమే "public" అని ఉండాలి. ఆ పబ్లిక్ క్లాస్ పేరే ఫైల్ కి ఉండాలి.

❓ main() ఫంక్షన్ లో నుంచి static అనే పదం తీసేస్తే ఏమవుతుంది?

కోడ్ ఎర్రర్ లేకుండా కంపైల్ అవుతుంది. కానీ రన్ చేద్దామని చూసినప్పుడు.. JVM కి పబ్లిక్ గా యాక్సెస్ అయ్యే స్టాటిక్ ఫంక్షన్ దొరకక "NoSuchMethodError" అని ఆగిపోతుంది.

🚀 Quick Chapter Recap

  • జావా 21 LTS అనేది లేటెస్ట్ వెర్షన్, దాన్నే అందరూ ప్రాజెక్ట్స్ కి వాడుతున్నారు.
  • జావా ప్రోగ్రామ్ రన్ అవ్వాలంటే కచ్చితంగా "public static void main(String[] args)" ఉండాలి.
  • పబ్లిక్ క్లాస్ పేరు, ఫైల్ పేరు కచ్చితంగా ఒకేలా ఉండాలి.
  • System.out.println() అంటే ప్రింట్ చేసి నెక్స్ట్ లైన్ కి వెళ్లడం. System.out.print() అంటే అక్కడే ఉండిపోవడం.
