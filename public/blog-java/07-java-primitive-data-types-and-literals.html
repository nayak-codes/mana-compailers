Java 8 Primitive Data Types & Literals (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 7 of 47 📂 Phase 2: Variables & Data Types 📅 2026 Edition
📌 Covered in this chapter:

byte, short, int, long · float, double · char (Unicode UTF-16) · boolean · Memory Sizes & Bit Ranges · Numeric Underscores & Literals

జావాలో బేసిక్ గా ఉండే 8 రకాల డేటా టైప్స్ ఏంటి? వాటికి మెమరీ లో ఎన్ని బైట్స్ తీసుకుంటాయి? పెద్ద నంబర్స్ వస్తే ఏది వాడాలి? పాయింట్ తర్వాత వచ్చే నంబర్స్ కి ఏది వాడాలి? అనే విషయాలు డీటెయిల్డ్ గా నేర్చుకుందాం.

1. జావాలో ఉండే 8 Primitive Data Types లిస్ట్

జావాలో ముందే డిజైన్ చేసిపెట్టిన 8 బేసిక్ (Primitive) డేటా టైప్స్ ఇవే:

డేటా టైప్ఏ రకం?సైజు (Bytes)ఎక్కడ నుంచి ఎక్కడ వరకు?డీఫాల్ట్ వాల్యూఎగ్జాంపుల్
**`byte`**

2. నంబర్స్ (Integers): `int` ఎందుకు డీఫాల్ట్? `long` కి L ఎందుకు వాడాలి?

మనం జావాలో ఏ నంబర్ రాసినా సరే, జావా దాన్ని బై డీఫాల్ట్ int (4 బైట్స్) లాగే చూస్తుంది.

ఒకవేళ మీరు int సైజు కంటే పెద్ద నంబర్ (214 కోట్లు దాటినవి) రాస్తుంటే, దాని చివర కచ్చితంగా L (అంటే Long) అని పెట్టాలి. లేదంటే ఎర్రర్ వస్తుంది.

int standardNumber = 2000000;
long worldPopulation = 8000000000L; // పెద్ద నంబర్ కాబట్టి L పెట్టాలి

3. డెసిమల్ నంబర్స్: `float` (f) vs `double` (డీఫాల్ట్)

జావాలో పాయింట్ ఉన్న ఏ నంబర్ రాసినా, అది బై డీఫాల్ట్ double (8 బైట్స్) అనుకుంటుంది.

ఒకవేళ మీరు దాన్ని float లోనే స్టోర్ చేసి మెమరీ సేవ్ చేద్దామనుకుంటే, కచ్చితంగా దాని పక్కన f అని పెట్టాలి. లేదంటే జావా ఒప్పుకోదు.

double exactGpa = 3.95;    // పక్కన ఏమీ ఇవ్వకపోతే అది double అనుకుంటుంది
float screenCoord = 120.5f; // float కి మాత్రం చివర 'f' ఇవ్వాల్సిందే

4. `char` మరియు ప్రపంచ భాషలు (Unicode)

పాత లాంగ్వేజెస్ (C, C++) లో ఒక అక్షరాన్ని స్టోర్ చేయడానికి (ASCII) 1 బైట్ వాడేవాళ్లు. కానీ అందులో ఇంగ్లీష్ అక్షరాలు మాత్రమే స్టోర్ అవుతాయి.

కానీ జావా ప్రపంచం మొత్తానికి పనికిరావాలని, char కి 2 బైట్స్ (Unicode) ఇచ్చింది. దీనివల్ల ఇంగ్లీషే కాకుండా తెలుగు, హిందీ, చైనీస్ లాంటి ఏ భాష అక్షరాలనైనా స్టోర్ చేసుకోవచ్చు!

char englishChar = 'A';
char teluguChar = '\u0C05'; // తెలుగు అక్షరం 'అ'
char asciiCode   = 65;       // నంబర్ 65 ఇస్తే అది 'A' ని ప్రింట్ చేస్తుంది

5. నంబర్స్ ని ఈజీగా చదవడానికి Underscores (_)

లక్షలు, కోట్లు రాసేటప్పుడు ఎన్ని సున్నాలు ఉన్నాయో చదవడం కష్టం కదా. అందుకే జావా 7 నుంచి నంబర్స్ మధ్యలో అండర్ స్కోర్స్ పెట్టుకునే ఫెసిలిటీ ఇచ్చారు:

long creditCardNumber = 4123_5678_9012_3456L;
int oneMillion = 1_000_000;
double price = 4_500.75;
ఈ అండర్ స్కోర్స్ ని కంపైలర్ వదిలేస్తుంది, జస్ట్ మనం చదువుకోవడానికే.

Beginner Example & Code Anatomy

☕ Main.java — Chapter 7 Core Example 
public class Main {
    public static void main(String[] args) {
        // 1. Integer Types
        byte  smallNum = 80;
        short mediumNum  = 1250;
        int   cityPopulation  = 2_500_000; // అండర్ స్కోర్ వాడాం
        long  globalData = 9_876_543_210_000L; // చివర 'L' వాడాం

        // 2. Floating-Point Types
        float  percentage = 87.5f; // చివర 'f' వాడాం
        double exactValue = 3.141592653589793;

        // 3. Character
        char letter = 'J';
        char teluguLetter = '\u0C05'; // తెలుగు 'అ'
        char symbol = '₹';

        // 4. Boolean
        boolean isOnline = true;

        // అవుట్పుట్ ప్రింట్ చేయడం
        System.out.println("--- జావా బేసిక్ డేటా టైప్స్ ---");
        System.out.println("byte    (8-bit)  : " + smallNum);
        System.out.println("short   (16-bit) : " + mediumNum);
        System.out.println("int     (32-bit) : " + cityPopulation);
        System.out.println("long    (64-bit) : " + globalData);
        System.out.println("float   (32-bit) : " + percentage + "%");
        System.out.println("double  (64-bit) : " + exactValue);
        System.out.println("char    (Unicode): " + letter + " | " + teluguLetter + " | " + symbol);
        System.out.println("boolean (Truth)  : " + isOnline);
    }
}

🔍 Line-by-Line Code Explanation

int cityPopulation = 2_500_000;

నంబర్స్ ని ఈజీగా చదవడానికి మధ్యలో అండర్ స్కోర్ పెట్టొచ్చు, దానివల్ల అవుట్పుట్ మారదు.

long globalData = 9_876_543_210_000L;

నంబర్ పెద్దది కాబట్టి జావా కన్ఫ్యూజ్ అవ్వకుండా ఉండటానికి లాస్ట్ లో L పెట్టాం.

float percentage = 87.5f;

డెసిమల్స్ ని double అనుకోకుండా float అనుకోవడానికి చివర f పెట్టాం.

char teluguLetter = '\u0C05';

యూనికోడ్ వాడి తెలుగు అక్షరం కూడా ఇచ్చాం (ప్రతి అక్షరానికి ఒక కోడ్ ఉంటుంది).

⚠️ Common Mistakes & Professional Best Practices
  • పెద్ద నంబర్స్ కి L మర్చిపోవడం: "long x = 5000000000;" అని ఇస్తే ఎర్రర్ వస్తుంది. "5000000000L" అని ఇవ్వాలి.
  • ఫ్లోట్ కి f మర్చిపోవడం: "float pi = 3.14;" అంటే ఎర్రర్ వస్తుంది, ఎందుకంటే 3.14 అనగానే దాన్ని double అనుకుంటుంది. "3.14f" అని ఇవ్వాలి.
  • boolean ని 0, 1 లాగా రాయడం: వేరే లాంగ్వేజెస్ లో 1 అంటే true. కానీ జావాలో boolean కచ్చితంగా true లేదా false అని అక్షరాల్లోనే రాయాలి.

💡 Frequently Asked Questions & Interview Insights

❓ C లాంగ్వేజ్ లాగా కాకుండా జావాలో char కి 2 బైట్స్ ఎందుకిచ్చారు?

ఇంగ్లీష్ కి 1 బైట్ చాలు. కానీ ప్రపంచంలో ఉన్న తెలుగు, హిందీ లాంటి అన్ని భాషల అక్షరాలని సపోర్ట్ చేయాలంటే 2 బైట్స్ (Unicode) ఉండాల్సిందే.

❓ బ్యాంక్ బ్యాలెన్స్ లాంటి డబ్బులకి float వాడాలా double వాడాలా?

రెండూ వాడకూడదు! ఇవి రెండూ కొన్నిసార్లు డెసిమల్స్ ని రౌండ్ ఆఫ్ చేస్తాయి. డబ్బుల లెక్కల కోసం జావాలో కచ్చితంగా "BigDecimal" అనే క్లాస్ ని వాడాలి.

❓ నంబర్ ముందు అండర్ స్కోర్ (_100) పెట్టొచ్చా?

పెట్టకూడదు. ఎప్పుడూ నంబర్స్ మధ్యలోనే పెట్టాలి. ఫస్ట్ కానీ లాస్ట్ కానీ అండర్ స్కోర్ పెడితే ఎర్రర్ వస్తుంది.

🚀 Quick Chapter Recap

  • జావాలో బేసిక్ డేటా టైప్స్ 8 ఉంటాయి. (byte, short, int, long, float, double, char, boolean).
  • నార్మల్ నంబర్ ఇస్తే int అనుకుంటుంది, డెసిమల్ ఇస్తే double అనుకుంటుంది.
  • long వాడాలంటే చివర L, float వాడాలంటే చివర f కచ్చితంగా పెట్టాలి.
  • char కి 2 బైట్స్ ఉంటాయి, కాబట్టి ఏ భాష అక్షరాన్నైనా స్టోర్ చేసుకోవచ్చు.
