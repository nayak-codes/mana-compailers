1. Javadoc డాక్యుమెంటేషన్ అంటే ఏంటి?

కంపెనీల్లో మీరు రాసిన మెథడ్ వేరే డెవలపర్స్ కూడా వాడుకుంటారు. వాళ్ళకి అది ఏం చేస్తుందో చెప్పడానికి కోడ్ పైన Javadoc comments (/** ... */) రాస్తారు. ఇది రాస్తే జావా ఆటోమాటిక్ గా ఒక వెబ్సైట్ (HTML) లాంటి డాక్యుమెంటేషన్ ని జనరేట్ చేస్తుంది.

/**
 * ఇచ్చిన డబ్బులకి కాంపౌండ్ ఇంట్రెస్ట్ క్యాలిక్యులేట్ చేస్తుంది.
 *
 * @param principal అసలు అమౌంట్ (0 కన్నా ఎక్కువ ఉండాలి).
 * @param annualRate సంవత్సరానికి ఎంత వడ్డీ శాతం.
 * @param years ఎన్ని సంవత్సరాలకి కట్టాలి.
 * @return వడ్డీతో కలిపి మొత్తం ఎంతైందో రిటర్న్ చేస్తుంది.
 * @throws IllegalArgumentException అమౌంట్ తప్పుగా ఇస్తే ఈ ఎర్రర్ ఇస్తుంది.
 */
public static double calculateCompoundInterest(double principal, double annualRate, int years) {
    if (principal <= 0 || years < 1) {
        throw new IllegalArgumentException("తప్పు అమౌంట్ లేదా ఇయర్స్ ఇచ్చారు");
    }
    return principal * Math.pow(1 + (annualRate / 100.0), years);
}

2. జావాలో క్లీన్ కోడ్ ప్రిన్సిపుల్స్ (Clean Code)

1. Single Responsibility Principle (SRP): ఒక మెథడ్ కి ఒక్క పనే ఉండాలి. అదే టాక్స్ క్యాలిక్యులేట్ చేసి, అదే డేటాబేస్ లో సేవ్ చేసి, అదే ఈమెయిల్ పంపించకూడదు. ఈ మూడింటికీ 3 వేరు వేరు మెథడ్స్ రాయాలి!
2. చిన్న సైజు: ఒక ప్రొఫెషనల్ మెథడ్ మహా అయితే 5 నుంచి 20 లైన్లు మాత్రమే ఉండాలి.
3. క్లియర్ పేర్లు (Verb-Noun): మెథడ్ పేర్లు పనిని బట్టి ఉండాలి. ఉదా: sendNotification(), validatePassword(), calculateNetPay().
4. తక్కువ పారామీటర్స్: ఒక మెథడ్ కి 0 నుంచి 3 పారామీటర్స్ ఉంటే బెస్ట్. 7, 8 ఇవ్వాల్సి వస్తే.. అవన్నీ కలిపి ఒక ఆబ్జెక్ట్ లో పంపించడం బెటర్.

Beginner Example & Code Anatomy

☕ Main.java — Chapter 37 Core Example 
import java.util.Arrays;

public class Main {
    // -------------------------------------------------------------
    // ప్రాజెక్ట్ 1: సైంటిఫిక్ క్యాలిక్యులేటర్
    // -------------------------------------------------------------
    public static class Calculator {
        public static double add(double a, double b) { return a + b; }
        public static double subtract(double a, double b) { return a - b; }
        public static double multiply(double a, double b) { return a * b; }
        public static double divide(double a, double b) {
            if (b == 0) {
                System.out.println("  [ఎర్రర్] జీరో తో డివైడ్ చేయలేం!");
                return Double.NaN; // Not a Number
            }
            return a / b;
        }
        public static double power(double base, double exp) { return Math.pow(base, exp); }
        public static double modulus(double a, double b) { return a % b; }
    }

    // -------------------------------------------------------------
    // ప్రాజెక్ట్ 2: స్టూడెంట్ గ్రేడింగ్ & GPA సిస్టమ్
    // -------------------------------------------------------------
    public static class StudentGrader {
        // అన్నీ సింగిల్ రెస్పాన్సిబిలిటీ తో విడగొట్టాం
        public static int calculateTotal(int[] marks) {
            int total = 0;
            for (int m : marks) total += m;
            return total;
        }

        public static double calculatePercentage(int[] marks, int maxPerSubject) {
            int total = calculateTotal(marks);
            int maxTotal = marks.length * maxPerSubject;
            return ((double) total / maxTotal) * 100.0;
        }

        public static char determineLetterGrade(double percentage) {
            if (percentage >= 90) return 'A';
            if (percentage >= 80) return 'B';
            if (percentage >= 70) return 'C';
            if (percentage >= 60) return 'D';
            return 'F';
        }

        public static double calculateGPA(double percentage) {
            return Math.min(4.0, (percentage / 100.0) * 4.0);
        }
    }

    // -------------------------------------------------------------
    // ప్రాజెక్ట్ 3: బ్యాంకింగ్ ఆపరేషన్స్ (ట్రాన్సాక్షన్స్)
    // -------------------------------------------------------------
    public static class BankService {
        public static double deposit(double currentBalance, double amount) {
            if (amount <= 0) {
                System.out.println("  [BANK ఎర్రర్] అమౌంట్ తప్పుగా ఉంది: $" + amount);
                return currentBalance;
            }
            return currentBalance + amount;
        }

        public static double withdraw(double currentBalance, double amount) {
            if (amount <= 0 || amount > currentBalance) {
                System.out.println("  [BANK ఎర్రర్] విత్-డ్రా ఆగిపోయింది! అమౌంట్ తప్పు లేదా బ్యాలెన్స్ లేదు.");
                return currentBalance;
            }
            return currentBalance - amount;
        }

        public static boolean transferFunds(double[] senderBalance, double[] receiverBalance, double amount) {
            if (amount <= 0 || senderBalance[0] < amount) {
                return false; // బ్యాలెన్స్ లేకపోతే ఆగిపోతుంది
            }
            senderBalance[0] -= amount; // పంపేవాడికి కట్ అవుతుంది
            receiverBalance[0] += amount; // తీసుకునేవాడికి యాడ్ అవుతుంది
            return true;
        }
    }

    // -------------------------------------------------------------
    // ప్రాజెక్ట్ 4: ఎంటర్ప్రైజ్ కామన్ యూటిలిటీస్ (CommonUtils)
    // -------------------------------------------------------------
    public static class CommonUtils {
        public static boolean isValidEmail(String email) {
            if (email == null || email.isBlank()) return false;
            // ఈమెయిల్ లో @, . లాంటివి ఉన్నాయా లేదా అని రెగ్యులర్ ఎక్స్ప్రెషన్ తో చెక్ చేస్తుంది
            return email.matches("^[A-Za-z0-9+_.-]+@[A-Za-z0-9.-]+$");
        }

        public static String maskCreditCard(String cardNum) {
            if (cardNum == null || cardNum.length() < 4) return "****";
            String clean = cardNum.replaceAll("[^0-9]", "");
            // సెక్యూరిటీ కోసం ముందు నంబర్స్ హైడ్ చేసి లాస్ట్ 4 మాత్రమే ఇస్తుంది
            return "****-****-****-" + clean.substring(clean.length() - 4);
        }

        public static String formatCurrency(double amount) {
            return String.format("$%,.2f", amount); // కామాలతో పాటు నీట్ గా కరెన్సీ వస్తుంది
        }
    }

    public static void main(String[] args) {
        System.out.println("=== ప్రాజెక్ట్ 1: క్యాలిక్యులేటర్ ===");
        System.out.println("  10.5 + 4.5  = " + Calculator.add(10.5, 4.5));
        System.out.println("  15.0 / 3.0  = " + Calculator.divide(15.0, 3.0));
        System.out.println("  2.0 ^ 10.0  = " + Calculator.power(2.0, 10.0));
        Calculator.divide(10.0, 0); // ఎర్రర్ కండిషన్ చెక్ చేస్తున్నాం

        System.out.println("
=== ప్రాజెక్ట్ 2: స్టూడెంట్ గ్రేడింగ్ సిస్టమ్ ===");
        int[] studentMarks = {88, 92, 79, 95, 84};
        int totalMarks = StudentGrader.calculateTotal(studentMarks);
        double percentage = StudentGrader.calculatePercentage(studentMarks, 100);
        char grade = StudentGrader.determineLetterGrade(percentage);
        double gpa = StudentGrader.calculateGPA(percentage);

        System.out.println("  మొత్తం మార్కులు : " + totalMarks + "/500");
        System.out.printf("  పర్సంటేజ్     : %.2f%%%n", percentage);
        System.out.println("  గ్రేడ్         : " + grade);
        System.out.printf("  GPA (4.0)    : %.2f%n", gpa);

        System.out.println("
=== ప్రాజెక్ట్ 3: బ్యాంకింగ్ ఆపరేషన్స్ ===");
        double myAccount = 1000.0;
        myAccount = BankService.deposit(myAccount, 500.0);
        myAccount = BankService.withdraw(myAccount, 200.0);
        System.out.println("  నా ఫైనల్ బ్యాలెన్స్: " + CommonUtils.formatCurrency(myAccount));

        double[] alice = {1200.0};
        double[] bob = {300.0};
        boolean txStatus = BankService.transferFunds(alice, bob, 400.0);
        System.out.println("  ఆలిస్ నుంచి బాబ్ కి $400 ట్రాన్స్ఫర్ : సక్సెస్ = " + txStatus);
        System.out.println("  ఆలిస్ కొత్త బ్యాలెన్స్              : " + CommonUtils.formatCurrency(alice[0]));
        System.out.println("  బాబ్ కొత్త బ్యాలెన్స్               : " + CommonUtils.formatCurrency(bob[0]));

        System.out.println("
=== ప్రాజెక్ట్ 4: ఎంటర్ప్రైజ్ యూటిలిటీస్ ===");
        System.out.println("  ఈమెయిల్ 'dev@google.com' కరెక్టేనా? : " + CommonUtils.isValidEmail("dev@google.com"));
        System.out.println("  ఈమెయిల్ 'invalid-email' కరెక్టేనా?  : " + CommonUtils.isValidEmail("invalid-email"));
        System.out.println("  మాస్క్ చేసిన క్రెడిట్ కార్డ్              : " + CommonUtils.maskCreditCard("4111-2222-3333-8945"));
        System.out.println("  కరెన్సీ ఫార్మాట్ చేసిన పెద్ద అమౌంట్      : " + CommonUtils.formatCurrency(1250450.75));
    }
}

☕ PracticalApplication.java — Industry Implementation 
public class PracticalApplication {
    public static void main(String[] args) {
        // రియల్ టైమ్ సినారియో: ఆఫీస్ లో ఎంప్లాయీస్ కి జీతాలు (Payroll) వేసే సిస్టమ్
        String[] employees = {"Ravi Teja", "Priya Sharma", "Kiran Kumar"};
        double[] baseSalaries = {4500.0, 6200.0, 3800.0};
        double bonusRate = 0.15; // 15% బోనస్

        System.out.println("=== ఆఫీస్ పెరోల్ (జీతాల) ప్రాసెసింగ్ ===");
        for (int i = 0; i < employees.length; i++) {
            double bonus = baseSalaries[i] * bonusRate;
            double gross = baseSalaries[i] + bonus;
            double tax = gross * 0.10; // 10% టాక్స్ కట్
            double net = gross - tax;

            // CommonUtils లో ఉన్న మెథడ్ ని ఇక్కడ మళ్ళీ వాడుకుంటున్నాం (దీన్నే Reusability అంటారు!)
            System.out.printf("ఎంప్లాయీ: %-14s | గ్రాస్: %s | టేక్-హోమ్: %s%n",
                    employees[i],
                    Main.CommonUtils.formatCurrency(gross),
                    Main.CommonUtils.formatCurrency(net));
        }
    }
}

⚠️ Common Mistakes & Professional Best Practices
  • ఒకే మెథడ్ లో 200 లైన్లు రాసేసి మొత్తం పనంతా అక్కడే చేయడం. దీన్ని 'స్పెగెట్టి కోడ్' అంటారు. అలా కాకుండా చిన్న చిన్న మెథడ్స్ గా విడగొట్టాలి.
  • మ్యాథ్స్ మెథడ్స్ రాసినప్పుడు సున్నా (0) తో డివైడ్ చేస్తే క్రాష్ అయ్యే ఎడ్జ్ కేస్ ని మర్చిపోవడం.
  • మెథడ్ కి వచ్చే ఇన్పుట్ null ఉందా లేదా అని చెక్ చేయకపోవడం (దీనివల్ల NullPointerException వస్తుంది).
  • మెథడ్ కి doWork(), process() లాంటి పిచ్చి పేర్లు పెట్టడం. calculateNetPay() లాగా అర్థమయ్యేలా ఉండాలి.

// Coding Challenge:
// CommonUtils లోకి calculateMedian(double[] values) అనే మెథడ్ ని యాడ్ చేయండి:
// 1. అరే కి జిరాక్స్ తీసి సార్ట్ చేయాలి.
// 2. సైజు బేసి సంఖ్య (odd) అయితే ఎగ్జాక్ట్ గా మధ్యలో ఉన్న వాల్యూ ఇవ్వాలి.
// 3. సరి సంఖ్య (even) అయితే మధ్యలో ఉన్న రెండింటి ఆవరేజ్ ఇవ్వాలి.

public class Challenge {
    public static double calculateMedian(double[] values) {
        if (values == null || values.length == 0) return 0.0;
        double[] sorted = values.clone(); // ఒరిజినల్ అరే పాడవకుండా కాపీ చేసాం
        java.util.Arrays.sort(sorted);
        
        int n = sorted.length;
        if (n % 2 != 0) {
            return sorted[n / 2]; // Odd సైజు అయితే
        }
        return (sorted[(n / 2) - 1] + sorted[n / 2]) / 2.0; // Even సైజు అయితే రెండింటి ఆవరేజ్
    }

    public static void main(String[] args) {
        System.out.println("మీడియన్ (Odd) : " + calculateMedian(new double[]{5, 1, 9, 3, 7})); // 5.0
        System.out.println("మీడియన్ (Even): " + calculateMedian(new double[]{1, 2, 3, 4}));    // 2.5
    }
}

💡 Frequently Asked Questions & Interview Insights

❓ Pure Function అంటే ఏంటి?

ఏ ఫంక్షన్ కి అయితే మీరు సేమ్ ఇన్పుట్ ఇస్తే ఎప్పుడూ సేమ్ అవుట్పుట్ ఇస్తుందో, పైగా అది వేరే డేటాబేస్ లను గానీ బయట వేరియబుల్స్ ని గానీ మార్చకుండా సైలెంట్ గా తన పని చేసుకుంటుందో దాన్ని Pure Function అంటారు (ఉదా: `Math.max()`).

❓ Javadoc ఎలా HTML వెబ్సైట్ లాగా మారుతుంది?

జావాలోనే `javadoc` అనే ఒక టూల్ ఉంటుంది. కమాండ్ ప్రాంప్ట్ లో `javadoc src/*.java` అని కొడితే అది ఈ `/** ... */` కామెంట్స్ అన్నింటినీ చదివి ఒక అందమైన వెబ్సైట్ లాగా మార్చేస్తుంది.

❓ యూటిలిటీ క్లాస్ లకి (CommonUtils) ప్రైవేట్ కన్స్ట్రక్టర్ ఎందుకు పెడతారు?

ఎందుకంటే యూటిలిటీ క్లాస్ లో అన్నీ స్టాటిక్ మెథడ్స్ ఏ ఉంటాయి. వాటిని పిలవడానికి ఆబ్జెక్ట్ అక్కర్లేదు కదా! పొరపాటున ఎవరైనా `new CommonUtils()` అని ఆబ్జెక్ట్ క్రియేట్ చేయకుండా ఉండటానికి ప్రైవేట్ కన్స్ట్రక్టర్ రాసి బ్లాక్ చేస్తారు.

  • మెథడ్స్ ని మోడ్యులర్ గా రాస్తేనే ఒకదాంట్లో రాసిన కోడ్ ని ప్రాజెక్ట్ అంతటా వాడుకోవచ్చు (Reusability).
