Logical, Bitwise, Unary & Ternary Operators (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 11 of 47 📂 Phase 3: Operators and Input 📅 2026 Edition
📌 Covered in this chapter:

Logical Operators (&&, ||, !) · Short-Circuit Evaluation · Prefix vs Postfix (++x / x++) · Ternary Operator (? :) · Bitwise Operators · Operator Precedence Table

రెండు మూడు కండిషన్స్ ని ఒకేసారి ఎలా చెక్ చేయాలి (&&, ||)? ++x కీ x++ కీ తేడా ఏంటి? ఇఫ్-ఎల్స్ (if-else) ని ఒకే లైన్ లో షార్ట్ కట్ (Ternary) లో ఎలా రాయాలి? మరియు ఇవన్నీ ఒకే లైన్ లో వస్తే జావా దేన్ని ఫస్ట్ క్యాలిక్యులేట్ చేస్తుంది? డీటెయిల్డ్ గా చూద్దాం.

1. లాజికల్ ఆపరేటర్స్ & Short-Circuit పవర్

రెండు మూడు కండిషన్స్ ని కలుపుతూ చెక్ చేయడానికి లాజికల్ ఆపరేటర్స్ వాడతాం:

ఆపరేటర్పేరుమీనింగ్
**`&&`**
AND | రెండు కండిషన్స్ true అయితేనే ఫైనల్ రిజల్ట్ true వస్తుంది. | | || | OR | రెండిట్లో ఏ ఒక్కటి true అయినా సరే ఫైనల్ రిజల్ట్ true వస్తుంది. | | ! | NOT | ఉన్నదాన్ని రివర్స్ చేస్తుంది (!true అంటే false). |

Short-Circuit Evaluation అంటే ఏంటి?:

ఇది జావాలో ఉన్న ఒక సూపర్ ఫీచర్. మన కండిషన్స్ ని ఇది సగం వరకే చెక్ చేసి ఆన్సర్ డిసైడ్ చేసేస్తుంది. - && (AND): ఫస్ట్ కండిషనే false అయితే.. ఇక రెండో కండిషన్ ని జావా అసలు చెక్ చేయదు! ఎందుకంటే AND లో ఒక్కటి false అయినా మొత్తం false అయిపోతుంది కాబట్టి. - || (OR): ఫస్ట్ కండిషనే true అయితే.. అప్పుడు కూడా రెండో కండిషన్ ని అసలు చెక్ చేయదు! ఎందుకంటే OR లో ఒక్కటి true అయినా మొత్తం true నే కాబట్టి.

దీనివల్ల మన యాప్ స్పీడ్ పెరగడమే కాకుండా క్రాష్ అవ్వకుండా కాపాడుకోవచ్చు:

String user = null;
// ఇక్కడ user != null అనేది false. కాబట్టి జావా ఇక పక్కనున్న user.length() ని అసలు చెక్ చేయదు.
// ఒకవేళ దాన్ని చెక్ చేస్తే యాప్ క్రాష్ అయ్యేది! సేవ్ అయ్యాం!
if (user != null && user.length() > 0) { ... }

2. Increment/Decrement: Prefix (++x) vs Postfix (x++)

ఒక వేరియబుల్ వాల్యూ ని 1 పెంచడానికి (++) లేదా తగ్గించడానికి (--) ఇవి వాడతాం. కానీ దీన్ని ముందు రాస్తే ఒకలా, వెనక రాస్తే ఒకలా పనిచేస్తుంది:

+-----------------------------------------------------------------------------------+
|                        PREFIX vs POSTFIX INCREMENT                                |
+-----------------------------------------------------------------------------------+
|  1. PREFIX (++x): "ముందు పెంచు.. ఆ తర్వాత వాడుకో"                                        |
|     int x = 5;                                                                    |
|     int y = ++x; // ఫస్ట్ x వాల్యూ 6 అవుతుంది. ఆ తర్వాత y లో 6 స్టోర్ అవుతుంది.               |
|     (ఫైనల్ గా: x = 6, y = 6)                                                         |
+-----------------------------------------------------------------------------------+
|  2. POSTFIX (x++): "ముందు వాడుకో.. ఆ తర్వాత పెంచు"                                       |
|     int a = 5;                                                                    |
|     int b = a++; // ఫస్ట్ b లో పాత వాల్యూ 5 స్టోర్ అవుతుంది. ఆ తర్వాత a వాల్యూ 6 అవుతుంది.     |
|     (ఫైనల్ గా: a = 6, b = 5)                                                         |
+-----------------------------------------------------------------------------------+

3. Ternary Operator (? :)

ఇది if-else రాయడానికి ఒక సింపుల్ షార్ట్ కట్. 4, 5 లైన్లు రాసే బదులు ఒకే లైన్ లో రాసేయొచ్చు:

వాల్యూ = (కండిషన్) ? ట్రూ అయితే ఇది : ఫాల్స్ అయితే ఇది;
int score = 85;
String status = (score >= 50) ? "PASS" : "FAIL";

int a = 10, b = 25;
int max = (a > b) ? a : b; // ఇక్కడ a కన్నా b పెద్దది కాబట్టి ఫాల్స్ కండిషన్ (b) సెలెక్ట్ అయ్యి 25 సేవ్ అవుతుంది.

4. Bitwise ఆపరేటర్స్

కంప్యూటర్ ఇంటర్నల్ గా అర్థం చేసుకునే బైనరీ బిట్స్ (0, 1) ని డైరెక్ట్ గా ఆపరేట్ చేయడానికి ఇవి వాడతారు. (ఇవి నార్మల్ యాప్స్ లో వాడం, లో-లెవెల్ ప్రోగ్రామింగ్ లో వాడతారు).

ఆపరేటర్పేరుఏం చేస్తుంది?
**`&`**
Bitwise AND | రెండు బిట్స్ 1 ఉంటేనే రిజల్ట్ 1 అవుతుంది. | | | | Bitwise OR | ఏ ఒక్క బిట్ 1 ఉన్నా రిజల్ట్ 1 అవుతుంది. | | ^ | Bitwise XOR | రెండు బిట్స్ వేరువేరుగా (0,1 లేదా 1,0) ఉంటేనే రిజల్ట్ 1 అవుతుంది. | | ~ | Bitwise NOT | 0 ని 1 గా, 1 ని 0 గా మారుస్తుంది. | | << | Left Shift | బిట్స్ ని లెఫ్ట్ కి జరుపుతుంది (నంబర్ డబుల్ అవుతుంది $x \times 2$). | | >> | Right Shift | బిట్స్ ని రైట్ కి జరుపుతుంది (నంబర్ సగం అవుతుంది $x / 2$). |

5. ఆపరేటర్స్ లో ఎవరికి ఫస్ట్ ర్యాంక్? (Precedence)

ఒకే లైన్ లో ప్లస్, మైనస్, మల్టిప్లికేషన్ అన్నీ వస్తే, జావా దేన్ని ఫస్ట్ క్యాలిక్యులేట్ చేయాలో ఒక ఆర్డర్ (బోడ్ మాస్ రూల్ లాగా) ఉంటుంది:

ర్యాంక్ఆపరేటర్స్ఏ డైరెక్షన్ లో చదువుతుంది?
**1 (హైయెస్ట్)**
బ్రాకెట్స్ (), x++, x-- | లెఫ్ట్ నుంచి రైట్ కి | | 2 | ముందు వచ్చేవి ++x, --x, !, (type) | రైట్ నుంచి లెఫ్ట్ కి | | 3 | మల్టిప్లికేషన్ *, /, % | లెఫ్ట్ నుంచి రైట్ కి | | 4 | ఎడిషన్ +, - | లెఫ్ట్ నుంచి రైట్ కి | | 5 | రిలేషనల్ <, <=, >, >= | లెఫ్ట్ నుంచి రైట్ కి | | 6 | ఈక్వాలిటీ ==, != | లెఫ్ట్ నుంచి రైట్ కి | | 7 | లాజికల్ AND && | లెఫ్ట్ నుంచి రైట్ కి | | 8 | లాజికల్ OR || | లెఫ్ట్ నుంచి రైట్ కి | | 9 | టెర్నరీ ? : | రైట్ నుంచి లెఫ్ట్ కి | | 10 (లోయెస్ట్) | అసైన్ చేయడం =, +=, -= వగైరా | రైట్ నుంచి లెఫ్ట్ కి |

Beginner Example & Code Anatomy

☕ Main.java — Chapter 11 Core Example 
public class Main {
    public static void main(String[] args) {
        // 1. లాజికల్ ఆపరేటర్స్ (&&, ||)
        int age = 22;
        boolean hasVoterCard = true;
        // వయసు 18 దాటాలి, మరియు ఓటర్ కార్డ్ ఉండాలి.. అప్పుడే ఓట్ వేయొచ్చు
        boolean canVote = (age >= 18) && hasVoterCard;
        System.out.println("ఓట్ వేయొచ్చా?: " + canVote);

        // 2. Prefix vs Postfix
        int p = 10;
        int q = ++p; // ఫస్ట్ p 11 అవుతుంది, ఆ తర్వాత 11 వాల్యూ q కి వెళ్తుంది.
        System.out.println("Prefix (p, q)  : p=" + p + ", q=" + q);

        int m = 10;
        int n = m++; // ఫస్ట్ n కి పాత వాల్యూ 10 వెళ్తుంది. ఆ తర్వాత m వాల్యూ 11 అవుతుంది.
        System.out.println("Postfix (m, n) : m=" + m + ", n=" + n);

        // 3. Ternary Operator షార్ట్ కట్
        double cartTotal = 1500.00;
        // బిల్ 1000 దాటితే డెలివరీ ఫ్రీ (0.0), లేదంటే 50 రూపాయలు.
        double shippingFee = (cartTotal >= 1000.00) ? 0.00 : 50.00;
        System.out.println("బిల్: ₹" + cartTotal + " | డెలివరీ ఛార్జ్: ₹" + shippingFee);

        // 4. Bitwise ఆపరేషన్స్ (బైనరీ లెవెల్ లో)
        int bitA = 0b0101; // బైనరీలో 5
        int bitB = 0b0011; // బైనరీలో 3
        System.out.println("
--- Bitwise Operations (5 & 3) ---");
        System.out.println("5 & 3 (AND) : " + (bitA & bitB)); // 0001 = 1
        System.out.println("5 | 3 (OR)  : " + (bitA | bitB)); // 0111 = 7
        System.out.println("5 << 1 (లెఫ్ట్ కి జరిపితే డబుల్ అవుతుంది): " + (bitA << 1)); // 10
    }
}

🔍 Line-by-Line Code Explanation

(age >= 18) && hasVoterCard

AND ఆపరేటర్: రెండు కండిషన్స్ ట్రూ అయితేనే ఫైనల్ ఆన్సర్ ట్రూ వస్తుంది.

int q = ++p;

Prefix: ముందు వాల్యూ పెరిగి, ఆ తర్వాత అసైన్ అవుతుంది.

int n = m++;

Postfix: ముందు అసైన్ అయ్యిపోయి, ఆ తర్వాత వాల్యూ పెరుగుతుంది.

(cartTotal >= 1000.00) ? 0.00 : 50.00

Ternary: 1000 కంటే ఎక్కువ ఉందా? అవును (true) అయితే 0.00 వస్తుంది, లేదంటే 50.00 వస్తుంది.

Practical Real-World Example

☕ PracticalApplication.java — Industry Implementation 
public class AccessControlDemo {
    public static void main(String[] args) {
        boolean isAuthenticated = true;
        boolean isAdmin = false;
        boolean hasSpecialPermission = true;

        // రూల్: యూజర్ లాగిన్ అయ్యుండాలి.. దాంతో పాటు అతను అడ్మిన్ అన్నా అయ్యుండాలి లేదా స్పెషల్ పర్మిషన్ అన్నా ఉండాలి
        boolean hasAccess = isAuthenticated && (isAdmin || hasSpecialPermission);

        String accessBadge = hasAccess ? "[ACCESS GRANTED] వెళ్ళండి" : "[ACCESS DENIED] ఆగిపోండి";
        System.out.println("సెక్యూరిటీ చెక్: " + accessBadge);
    }
}

⚠️ Common Mistakes & Professional Best Practices
  • రెండు సార్లు (&&) బదులు ఒక్కసారి (&) వాడటం: సింగిల్ & వాడితే, ఫస్ట్ ది ఫాల్స్ అయినా కూడా.. అనవసరంగా రెండోది కూడా చెక్ చేస్తుంది. దీనివల్ల క్రాష్ అయ్యే ఛాన్స్ ఉంది.
  • కాంప్లెక్స్ గా కోడ్ రాయడం: "int z = x++ + ++x;" లాంటివి రాస్తే కోడ్ చదవడానికి చాలా కన్ఫ్యూజింగ్ గా ఉంటుంది. ఇలాంటి ట్రిక్స్ రాయకూడదు.
  • ఒకదానిలో ఒకటి టెర్నరీ వాడటం: టెర్నరీలోపల ఇంకో టెర్నరీ (a ? (b ? c : d) : e) రాస్తే అర్థం కాదు. అలాంటప్పుడు నార్మల్ if-else రాయడమే బెటర్.

❓ Bitwise shift (x << 1) వాడితే స్పీడ్ గా ఉంటుందా లేదా మల్టిప్లై (x * 2) చేస్తే స్పీడ్ గా ఉంటుందా?

ఇంటర్నల్ గా జావా (x * 2) ని కూడా ఆటోమాటిక్ గా బిట్ షిఫ్ట్ లాగే మార్చుకుని క్యాలిక్యులేట్ చేస్తుంది. కాబట్టి మనం నార్మల్ మ్యాథ్స్ లాగే రాసుకోవచ్చు, స్పీడ్ లో తేడా ఉండదు.

❓ ++x రైట్ నుంచి లెఫ్ట్ కి ఎందుకు క్యాలిక్యులేట్ అవుతుంది?

అది ముందు వేరియబుల్ (x) ని తీసుకుని, ఆ తర్వాత వాల్యూ పెంచుతుంది కాబట్టి రైట్ నుంచి లెఫ్ట్ కి పనిచేస్తుంది.

🚀 Quick Chapter Recap

  • && మరియు || లు సగం వరకే చెక్ చేసి (short-circuit) ఆన్సర్ డిసైడ్ చేసేస్తాయి.
  • Prefix (++x) ముందే వాల్యూ పెంచుతుంది, Postfix (x++) తర్వాత పెంచుతుంది.
  • Ternary operator అంటే if-else ని ఒకే లైన్ లో రాయడం.
  • బ్రాకెట్స్ కి హైయెస్ట్ ర్యాంక్ ఉంటుంది, కాబట్టి ఏది ముందు క్యాలిక్యులేట్ అవ్వాలో దాన్ని బ్రాకెట్స్ లో పెట్టడం బెస్ట్.
