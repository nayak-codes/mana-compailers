Java Type Casting (Widening/Narrowing) & var Keyword (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 9 of 47 📂 Phase 2: Variables & Data Types 📅 2026 Edition
📌 Covered in this chapter:

Widening Casting (Implicit) · Narrowing Casting (Explicit) · Data Loss & Overflow · ASCII char/int Conversions · var Keyword (Local Variable Type Inference)

ఒక డేటా టైప్ లో ఉన్న వాల్యూ ని వేరే డేటా టైప్ లోకి ఎలా మార్చాలి (Type Casting)? చిన్నదాన్ని పెద్ద దానిలోకి వేస్తే ఏమవుతుంది? పెద్ద దాన్ని చిన్నదాంట్లోకి వేస్తే డేటా ఎలా మిస్ అవుతుంది? మరియు జావా 10 లో కొత్తగా వచ్చిన `var` కీవర్డ్ తో ఈజీగా కోడ్ ఎలా రాయాలో చూద్దాం.

1. Type Casting అంటే ఏంటి?

Type Casting అంటే ఒక డేటా టైప్ లో ఉన్న వాల్యూ ని వేరే డేటా టైప్ కి మార్చడం.

దీంట్లో మెయిన్ గా రెండు రకాలు ఉంటాయి:

+-----------------------------------------------------------------------------------+
|                        JAVA TYPE CASTING HIERARCHY                                |
+-----------------------------------------------------------------------------------+
|  1. WIDENING CASTING (చిన్నదాని నుంచి పెద్దదానికి - ఆటోమేటిక్ గా జరుగుతుంది)              |
|     byte -> short -> char -> int -> long -> float -> double                       |
|     (చిన్న సైజు ఉన్న డేటాని పెద్ద బాక్స్ లో పెడుతున్నాం కాబట్టి ఏ ప్రాబ్లమ్ రాదు)                 |
+-----------------------------------------------------------------------------------+
|  2. NARROWING CASTING (పెద్దదాని నుంచి చిన్నదానికి - మనమే మాన్యువల్ గా చేయాలి)            |
|     double -> float -> long -> int -> char -> short -> byte                       |
|     (పెద్ద సైజు డేటాని చిన్న బాక్స్ లోకి కుక్కుతున్నాం కాబట్టి డేటా మిస్ అవ్వొచ్చు!)             |
+-----------------------------------------------------------------------------------+

2. Widening Casting (ఆటోమేటిక్ గా జరిగేది)

ఒక చిన్న డేటా టైప్ (ఉదా: int) లో ఉన్న వాల్యూని పెద్ద డేటా టైప్ (ఉదా: double) కి ఇస్తే జావా ఎవరికీ చెప్పకుండా సైలెంట్ గా మార్చేసుకుంటుంది. దీనివల్ల డేటా ఏమీ పోదు.

int smallNumber = 100;
double largeNumber = smallNumber; // int(4 bytes) కాస్త double(8 bytes) అయిపోయింది

System.out.println(smallNumber); // 100
System.out.println(largeNumber); // 100.0 (చివర ఆటోమాటిక్ గా పాయింట్ జీరో వచ్చింది)

3. Narrowing Casting (మనం ఫోర్స్ చేసి చేయాలి)

ఒక పెద్ద డేటా టైప్ (ఉదా: double) వాల్యూ ని చిన్న డేటా టైప్ (ఉదా: int) లోకి మార్చాలి అంటే ఆటోమేటిక్ గా జరగదు. మనం ఫోర్స్ చేయాలి. ఎలా అంటే, మనం మార్చాలనుకున్న టైప్ ని బ్రాకెట్స్ లో (int) అని ముందు పెట్టాలి.

ఇలా పెద్దదాన్ని చిన్నదాంట్లోకి కుక్కడం వల్ల డేటా మిస్ అయ్యే ఛాన్స్ ఉంది (ఉదాహరణకి డెసిమల్స్ పోతాయి):

// డెసిమల్స్ పోవడం:
double itemPrice = 99.95;
int truncatedPrice = (int) itemPrice; // పాయింట్ తర్వాత ఉన్న .95 ని జావా కట్ చేసి పారేస్తుంది! కేవలం 99 మాత్రమే మిగులుతుంది.

// బైట్ లిమిట్ దాటిపోవడం:
int largeInt = 130;
byte overflowByte = (byte) largeInt; // బైట్ కి మాక్సిమం 127 వరకే పడుతుంది. ఇక్కడ 130 ఇస్తే అది కన్ఫ్యూజ్ అయిపోయి మైనస్ 126 (-126) కి మారిపోతుంది!

4. అక్షరాలని నంబర్స్ లాగా మార్చొచ్చా (Char to Int)?

జావాలో char కి 2 బైట్స్ ఉంటాయి, అంతేకాకుండా వెనకాల ప్రతి అక్షరానికి ఒక నంబర్ (Unicode) లింక్ అయి ఉంటుంది. కాబట్టి మనం ఈజీగా నంబర్స్ ని అక్షరాల్లా, అక్షరాల్ని నంబర్స్ లా మార్చుకోవచ్చు.

char letter = 'A';
int code = (int) letter; // 65 వస్తుంది

int myCode = 66;
char myLetter = (char) myCode; // 'B' వస్తుంది

5. కొత్తగా వచ్చిన `var` కీవర్డ్ (జావా 10 నుంచి)

జావా 10 నుంచి మనం ప్రతిసారి int, String అని చెప్పాల్సిన పనిలేకుండా, సింపుల్ గా var వాడుకోవచ్చు. మనం ఇచ్చిన వాల్యూ ని బట్టి అది ఏ టైపో కంపైలర్ ఆటోమాటిక్ గా గుర్తుపడుతుంది.

var age = 25;                       // వాల్యూ 25 కాబట్టి ఇది int అని అదే అర్థం చేసుకుంటుంది
var price = 99.99;                  // ఇది double
var greeting = "Hello!";            // ఇది String
var isOk = true;                    // ఇది boolean

var వాడుతున్నప్పుడు గుర్తుపెట్టుకోవాల్సిన రూల్స్:

1. మధ్యలో మార్చలేం: మీరు ఒకసారి నంబర్ ఇస్తే, అది int అయిపోతుంది. తర్వాత వెళ్లి అందులో టెక్స్ట్ పెడతా అంటే ఒప్పుకోదు. (ఇది పైథాన్ లాగా డైనమిక్ కాదు). 
var count = 10;
   // count = "ten"; // ఎర్రర్ వస్తుంది!
2. లోకల్ గా మాత్రమే: ఫంక్షన్స్ లోపల మాత్రమే var వాడాలి. క్లాస్ లో పైన రాయడానికి లేదు. 3. కచ్చితంగా వాల్యూ ఇవ్వాలి: var x; అని వదిలేయడానికి కుదరదు. వాల్యూ ఇవ్వకపోతే అది ఏ టైపో కంపైలర్ కి ఎలా తెలుస్తుంది?

Beginner Example & Code Anatomy

☕ Main.java — Chapter 9 Core Example 
public class Main {
    public static void main(String[] args) {
        // 1. Widening Casting (చిన్న నుంచి పెద్దకి)
        int salary = 50000;
        double salaryDouble = salary;
        System.out.println("Widening Casting (int -> double): " + salaryDouble);

        // 2. Narrowing Casting (పెద్ద నుంచి చిన్నకి)
        double rate = 1845.75;
        int rateInt = (int) rate; // పాయింట్ తర్వాత ఉన్నది పోతుంది
        System.out.println("Narrowing Casting (double -> int): " + rateInt + " (డెసిమల్స్ కట్ అయ్యాయి)");

        // 3. Char to Int
        char symbol = 'Z';
        int ascii = (int) symbol;
        System.out.println("అక్షరం '" + symbol + "' కి ఉన్న నంబర్: " + ascii);

        // 4. var కీవర్డ్
        var id = 987654321L;     // long అని అదే తెలుసుకుంటుంది
        var name = "Anitha";     // String
        var ok = true;           // boolean

        System.out.println("
--- var వాడి క్రియేట్ చేసినవి ---");
        System.out.println("ID  : " + id + " (టైప్: Long)");
        System.out.println("పేరు: " + name + " (టైప్: String)");
        System.out.println("Okనా: " + ok);
    }
}

🔍 Line-by-Line Code Explanation

double salaryDouble = salary;

int లో ఉన్నది double లోకి ఆటోమాటిక్ గా మారిపోయింది.

int rateInt = (int) rate;

double ని ఫోర్స్ చేసి మరీ int లోకి మార్చాం, కాబట్టి .75 కట్ అయిపోయింది.

int ascii = (int) symbol;

అక్షరాన్ని (Z) నంబర్ లాగా మారిస్తే 90 వచ్చింది.

var id = 987654321L;

మనం టైప్ చెప్పకుండా var వాడితే, జావానే దాన్ని లాంగ్ (Long) అని డిసైడ్ చేసింది.

        int orig = 130;

        // బైట్ 127 వరకు వెళ్ళి, ఆ తర్వాత 128 అవ్వకుండా.. వెనక్కి తిరిగి మైనస్ 128, మైనస్ 127.. అలా మైనస్ 126 కి వచ్చి ఆగుతుంది.

⚠️ Common Mistakes & Professional Best Practices
  • var కి వాల్యూ ఇవ్వకుండా వాడటం: "var x;" అని రాస్తే ఎర్రర్ వస్తుంది. కచ్చితంగా వాల్యూ ఇస్తేనే అది పనిచేస్తుంది.
  • క్లాస్ లోపల var వాడటం: ఫంక్షన్స్ లోపల మాత్రమే var పనిచేస్తుంది, పైన గ్లోబల్ గా వేరియబుల్స్ కి వాడలేం.
  • Casting చేస్తే రౌండ్ ఆఫ్ అవుతుంది అనుకోవడం: "int x = (int) 9.99;" అంటే 10 రాదు, 9 మాత్రమే వస్తుంది. రౌండ్ ఆఫ్ చేయాలంటే Math.round() వాడాలి.

💡 Frequently Asked Questions & Interview Insights

❓ var వాడితే ప్రోగ్రామ్ స్లో అవుతుందా?

అస్సలు అవ్వదు. మనం కోడ్ కంపైల్ చేసేటప్పుడే కంపైలర్ దాన్ని ఒరిజినల్ టైప్ (int, String) లాగా మార్చేసుకుంటుంది. కాబట్టి స్పీడ్ ఎక్కడా తగ్గదు.

❓ ఒక ఆబ్జెక్ట్ ని ఇంకో ఆబ్జెక్ట్ లోకి టైప్ కాస్ట్ చేయొచ్చా?

చేయొచ్చు, దాన్ని Downcasting / Upcasting అంటారు. కానీ ఎర్రర్ రాకుండా ఉండటానికి "instanceof" వాడి చెక్ చేసుకొని చేయాలి.

🚀 Quick Chapter Recap

  • చిన్న డేటాని పెద్ద దానిలోకి మారిస్తే (Widening) ఎలాంటి ప్రాబ్లమ్ రాదు, ఆటోమేటిక్ గా జరిగిపోతుంది.
  • పెద్ద డేటాని చిన్నదానిలోకి కుక్కితే (Narrowing) డెసిమల్స్ పోవడం, మైనస్ లోకి వెళ్ళిపోవడం లాంటివి జరుగుతాయి.
  • అక్షరాలని ఈజీగా నంబర్స్ లాగా మార్చుకోవచ్చు.
  • జావా 10 నుంచి ప్రతిదానికీ డేటా టైప్ చెప్పకుండా var వాడుకుని సింపుల్ గా కోడ్ రాయొచ్చు.
