Java Constructors, this Keyword & Constructor Overloading (తెలుగులో)

☕ Java 21+ LTS 🟢 Chapter 39 of 47 📂 Phase 9: Classes & Objects 📅 2026 Edition
📌 Covered in this chapter:

What is a Constructor? · Default Constructor · Parameterized Constructor · Constructor vs Method Differences · this Keyword: 3 Roles · this() Constructor Chaining · Constructor Overloading · Copy Constructor Pattern

ఆబ్జెక్ట్ పుట్టగానే దానికి ఒక పేరు, వయసు లాంటివి డిఫాల్ట్ గా సెట్ అవ్వాలంటే ఎలా? అందుకోసమే జావాలో **Constructors (కన్స్ట్రక్టర్స్)** ఉంటాయి. అసలు ఇవి మామూలు మెథడ్స్ కి ఎలా వేరు? దీంట్లో `this` కీవర్డ్ ఎందుకు అంత ఇంపార్టెంట్? కన్స్ట్రక్టర్స్ ని ఓవర్ లోడ్ చేసి రకరకాలుగా ఆబ్జెక్ట్స్ ని ఎలా క్రియేట్ చేయాలో ఈ చాప్టర్ లో డీప్ గా చూద్దాం.

1. Constructor అంటే ఏంటి? (ఆబ్జెక్ట్ కి ప్రాణం పోసేది)

Constructor అంటే ఒక స్పెషల్ మెథడ్. మనం new అని ఆబ్జెక్ట్ క్రియేట్ చేయగానే.. జావా ఆటోమాటిక్ గా దీన్ని రన్ చేస్తుంది. ఆబ్జెక్ట్ లోపల ఉన్న వేరియబుల్స్ కి ఫస్ట్ టైమ్ వాల్యూస్ ఇవ్వడానికి (Initial setup) దీన్ని వాడతాం.

కన్స్ట్రక్టర్ కి, మామూలు మెథడ్ కి ఉన్న 5 తేడాలు:

రూల్Constructorమామూలు Method
**పేరు**
క్లాస్ పేరు ఏదైతే ఉందో, అచ్చం అదే పేరు ఉండాలి | మన ఇష్టం వచ్చిన పేరు పెట్టుకోవచ్చు | | రిటర్న్ టైప్ | ఏమీ ఉండకూడదు (కనీసం void అని కూడా రాయకూడదు!) | కచ్చితంగా void లేదా ఏదో ఒక టైప్ రాయాలి | | ఎప్పుడు రన్ అవుతుంది? | new తో ఆబ్జెక్ట్ క్రియేట్ అవ్వగానే ఆటోమాటిక్ గా | మనం ఎప్పుడు పిలిస్తే అప్పుడు | | వారసత్వంగా వస్తుందా? | రాదు (Inherit అవ్వదు) | వస్తుంది (Inherit అవుతుంది) | | ఎందుకు వాడతారు? | ఆబ్జెక్ట్ పుట్టగానే డేటా సెటప్ చేయడానికి | మనకి కావాల్సిన లాజిక్స్ రన్ చేసుకోవడానికి |

2. Default Constructor (మనం రాయకపోయినా ఉండేది)

ఒకవేళ మీరు క్లాస్ లోపల కన్స్ట్రక్టర్ ఏమీ రాయకపోతే, కంపైల్ చేసేటప్పుడు జావా ఆటోమాటిక్ గా ఒక డమ్మీ కన్స్ట్రక్టర్ ని సృష్టించి పెడుతుంది. దాన్నే Default Constructor అంటారు.

class Product {
    String name;
}
// జావా లోపల ఇలా రాసుకుంటుంది:
// Product() { }

Product p = new Product(); // ఇది వర్క్ అవుతుంది ఎందుకంటే జావా డమ్మీది పెట్టింది కాబట్టి

డేంజర్ అలర్ట్: ఒకవేళ మీరు సొంతంగా కనీసం ఒక్క కన్స్ట్రక్టర్ రాసినా సరే.. జావా ఇక ఆ డమ్మీ దాన్ని ఇవ్వదు! అప్పుడు మీరు new Product() అని ఖాళీగా ఇస్తే ఎర్రర్ వస్తుంది.

3. Parameterized Constructor (మనం డేటా పంపించడం)

ఆబ్జెక్ట్ క్రియేట్ చేసేటప్పుడే మనం దానికి కావాల్సిన వాల్యూస్ ని (పేరు, వయసు లాంటివి) పంపించడాన్నే Parameterized Constructor అంటారు:

class Student {
    String name;
    int age;

// Parameterized Constructor
    Student(String name, int age) {
        this.name = name; // "this.name" అంటే క్లాస్ లో ఉన్న వేరియబుల్. "name" అంటే మనం పంపించిన పారామీటర్
        this.age  = age;
    }
}


// ఒకే లైన్ లో ఆబ్జెక్ట్ కి డేటా ఇచ్చేస్తున్నాం
Student s = new Student("Ravi", 20);

4. The this Keyword — దీనికి ఉన్న 3 రోల్స్

this అనే కీవర్డ్ కరెంట్ ఆబ్జెక్ట్ ని పాయింట్ చేస్తుంటుంది. అంటే "నాది" అని అర్థం.

రోల్ 1: పేర్ల కన్ఫ్యూజన్ తీర్చడం (Field Disambiguation)
క్లాస్ లో ఉన్న వేరియబుల్ పేరు, మనం మెథడ్ కి పంపిన పారామీటర్ పేరు ఒక్కటే ఉంటే.. కంపైలర్ కి అర్థం కాదు. అప్పుడు this వాడి "ఇది నా క్లాస్ వేరియబుల్ రా బాబు" అని చెప్తాం:

Student(String name, int age) {
    this.name = name; // ఈ 'name' నా క్లాస్ ది, ఇవతల ఉన్న 'name' నువ్వు పంపించింది
    this.age  = age;
}

రోల్ 2: కరెంట్ ఆబ్జెక్ట్ ని వేరే వాళ్ళకి పంపడం

void register() {
    Database.save(this); // నన్ను నేను (నా ఆబ్జెక్ట్ ని) డేటాబేస్ కి పంపించుకుంటున్నా
}

రోల్ 3: ఇంకో కన్స్ట్రక్టర్ ని పిలవడానికి (this())

Student(String name) {
    this(name, 18); // ఇదే క్లాస్ లో ఉన్న రెండు పారామీటర్స్ తీసుకునే కన్స్ట్రక్టర్ కి పంపుతుంది
}

5. Constructor Overloading (ఒకటి కంటే ఎక్కువ కన్స్ట్రక్టర్స్)

మెథడ్స్ లాగానే, కన్స్ట్రక్టర్స్ కి కూడా ఒకే పేరుతో (అంటే క్లాస్ పేరుతో) మల్టిపుల్ వెర్షన్స్ రాయొచ్చు. దీన్ని బట్టి ఆబ్జెక్ట్ ని మన ఇష్టం వచ్చినట్టు వేరు వేరు స్టైల్స్ లో క్రియేట్ చేసుకోవచ్చు:

class Student {
    String name;
    int age;

// ఏమీ ఇవ్వకపోతే డిఫాల్ట్ గా ఇది తీసుకుంటుంది
    Student() {
        this("Unknown", 18);
    }


// పేరు మాత్రమే ఇస్తే ఇది రన్ అవుతుంది
    Student(String name) {
        this(name, 18);
    }


// మొత్తం పంపిస్తే ఇది రన్ అవుతుంది (అసలు పని జరిగేది ఇక్కడే)
    Student(String name, int age) {
        this.name = name;
        this.age  = age;
    }
}

Beginner Example & Code Anatomy

☕ Main.java — Chapter 39 Core Example 
class Student {
    String name;
    int age;
    double gpa;
    String department;

    // కన్స్ట్రక్టర్ 1: ఏమీ ఇవ్వకపోతే డమ్మీ డేటాతో కిందకి పంపుతుంది
    Student() {
        this("Unknown Student", 18, 0.0, "Undeclared");
    }

    // కన్స్ట్రక్టర్ 2: పేరు, వయసు ఇస్తే మిగిలినవి డమ్మీ పెట్టి పంపుతుంది
    Student(String name, int age) {
        this(name, age, 0.0, "General");
    }

    // కన్స్ట్రక్టర్ 3: అసలైన ఫుల్ కన్స్ట్రక్టర్ (అన్నీ తీసుకుంటుంది)
    Student(String name, int age, double gpa, String department) {
        this.name       = name;
        this.age        = age;
        this.gpa        = gpa;
        this.department = department;
    }

    // Copy Constructor: ఒక ఆబ్జెక్ట్ లో ఉన్న డేటా మొత్తం కాపీ కొట్టి కొత్తది క్రియేట్ చేయడం
    Student(Student other) {
        this(other.name, other.age, other.gpa, other.department);
    }

    // ఇది మామూలు మెథడ్
    void displayDetails() {
        System.out.println(this.name + " - " + this.age);
    }

    void displayFullProfile() {
        System.out.printf("  పేరు: %-18s | వయసు: %2d | GPA: %.2f | బ్రాంచ్: %s%n",
                name, age, gpa, department);
    }
}

public class Main {
    public static void main(String[] args) {
        System.out.println("=== 1. పారామీటర్స్ తో క్రియేట్ చేయడం ===");
        Student student = new Student("Ravi", 20);
        student.displayDetails();

        System.out.println("
=== 2. Constructor Overloading డెమో ===");
        Student noArg   = new Student(); // ఏమీ ఇవ్వలేదు
        Student nameAge = new Student("Priya", 22); // రెండు ఇచ్చాం
        Student full    = new Student("Kiran", 21, 3.85, "Computer Science"); // అన్నీ ఇచ్చాం

        noArg.displayFullProfile();
        nameAge.displayFullProfile();
        full.displayFullProfile();

        System.out.println("
=== 3. Copy Constructor (కాపీ కొట్టడం) ===");
        Student original = new Student("Ananya Reddy", 23, 3.95, "Data Science");
        Student copy = new Student(original);  // ఒరిజినల్ ఆబ్జెక్ట్ ని పంపించి కొత్తది క్రియేట్ చేసాం
        copy.name = "Ananya Reddy (కాపీ)";    // కాపీ ని మార్చినా ఒరిజినల్ మారదు!

        System.out.println("ఒరిజినల్: " + original.name + " | GPA: " + original.gpa);
        System.out.println("కాపీ     : " + copy.name     + " | GPA: " + copy.gpa);

        System.out.println("
=== 4. this Keyword వాడుక ===");
        Student s = new Student("Venkat", 25, 3.7, "Electronics");
        s.displayFullProfile();
    }
}

🔍 Line-by-Line Code Explanation

Student student = new Student("Ravi", 20);

రెండు పారామీటర్స్ ఉన్న కన్స్ట్రక్టర్ రన్ అవుతుంది, అది `this()` వాడి ఫుల్ కన్స్ట్రక్టర్ కి పంపుతుంది.

this("Unknown Student", 18, 0.0, "Undeclared");

ఇలా `this()` వాడి ఒక కన్స్ట్రక్టర్ ఇంకో కన్స్ట్రక్టర్ కి పనిని అప్పజెప్పొచ్చు. ఇది కచ్చితంగా ఆ బ్లాక్ లో మొదటి లైన్ గానే ఉండాలి.

this.name = name;

ఎడమవైపు ఉన్న `this.name` క్లాస్ కి చెందింది. కుడివైపు ఉన్న `name` మనం బయటనుంచి పంపింది.

Student copy = new Student(original);

ఇలా ఆబ్జెక్ట్ కి ఆబ్జెక్ట్ ని మొత్తం పంపించి దానికి జిరాక్స్ తీసినట్టు ఇంకో ఆబ్జెక్ట్ క్రియేట్ చేయడాన్ని Copy Constructor అంటారు.

Practical Real-World Example

☕ PracticalApplication.java — Industry Implementation 
class Product {
    String productId;
    String name;
    double price;
    int stockQuantity;

    Product(String productId, String name, double price, int stockQuantity) {
        this.productId     = productId;
        this.name          = name;
        this.price         = price;
        this.stockQuantity = stockQuantity;
    }

    void displayProduct() {
        System.out.printf("  [%s] %-20s | ప్రైస్: $%6.2f | స్టాక్: %3d యూనిట్లు%n",
                productId, name, price, stockQuantity);
    }
}

public class PracticalApplication {
    public static void main(String[] args) {
        // అన్నీ ఒకే లైన్ లో ఆబ్జెక్ట్ తో పాటు సెటప్ అయిపోతున్నాయి
        Product p1 = new Product("SKU-001", "Mechanical Keyboard", 79.99, 150);
        Product p2 = new Product("SKU-002", "Wireless Mouse",      29.99, 320);
        Product p3 = new Product("SKU-003", "4K Monitor",         349.00,  48);

        System.out.println("=== అమెజాన్ ఇన్వెంటరీ క్యాటలాగ్ ===");
        p1.displayProduct();
        p2.displayProduct();
        p3.displayProduct();
    }
}

  • కన్స్ట్రక్టర్ ముందు void లేదా ఏదో ఒక రిటర్న్ టైప్ పెట్టడం. అలా పెడితే అది కన్స్ట్రక్టర్ కాదు, జస్ట్ ఒక మామూలు మెథడ్ అయిపోతుంది.
  • this() ని కన్స్ట్రక్టర్ లోపల ఎక్కడపడితే అక్కడ రాయడం. అది కచ్చితంగా ఆ బ్లాక్ లో మొట్టమొదటి లైన్ లోనే ఉండాలి.
  • ఒక పారామీటర్ కన్స్ట్రక్టర్ రాసేసి, మళ్ళీ ఆ తర్వాత new Student() అని ఖాళీగా ఆబ్జెక్ట్ క్రియేట్ చేద్దాం అనుకోవడం. (ఎర్రర్ వస్తుంది, డిఫాల్ట్ ది పోయింది కదా!)
  • this.name = this.name; అని రాయడం. ఇలా రాస్తే దానికి అదే అసైన్ అయ్యి వాల్యూ సెట్ అవ్వదు. this.name = name; అనే ఉండాలి.

// Coding Challenge:
// Circle అనే క్లాస్ ని క్రియేట్ చేయండి:
// 1. ఫీల్డ్: double radius ఉండాలి.
// 2. ఒక కన్స్ట్రక్టర్ Circle(double radius) కి this కీవర్డ్ వాడి సెట్ చేయాలి.
// 3. ఏమీ పంపకపోతే radius 1.0 ఉండేలా No-arg కన్స్ట్రక్టర్ రాయాలి (this(1.0) వాడాలి).
// 4. ఏరియా, చుట్టుకొలత కనుక్కునే మెథడ్స్ తో పాటు displayInfo() అని ప్రింట్ చేయాలి.

class Circle {
    double radius;

    Circle() {
        this(1.0); // డిఫాల్ట్ గా 1 వెళ్తుంది
    }

    Circle(double radius) {
        this.radius = radius;
    }

    double getArea() {
        return Math.PI * radius * radius;
    }

    double getCircumference() {
        return 2 * Math.PI * radius;
    }

    void displayInfo() {
        System.out.printf("  సర్కిల్ | రేడియస్: %.2f | ఏరియా: %.4f | చుట్టుకొలత: %.4f%n",
                radius, getArea(), getCircumference());
    }
}

public class Challenge {
    public static void main(String[] args) {
        new Circle().displayInfo();       // డిఫాల్ట్ రేడియస్ 1.0
        new Circle(5.0).displayInfo();    // రేడియస్ 5.0
        new Circle(12.5).displayInfo();   // రేడియస్ 12.5
    }
}

💡 Frequently Asked Questions & Interview Insights

❓ క్లాస్ లో కన్స్ట్రక్టర్ ఏమీ రాయకపోతే ఏమవుతుంది?

జావా ఒక డిఫాల్ట్ కన్స్ట్రక్టర్ ని అదే రాసుకుంటుంది (ఏ పారామీటర్స్ లేనిది). కానీ మీరు ఏదైనా ఒకటి రాస్తే మాత్రం, జావా ఆ డిఫాల్ట్ దాన్ని ఇవ్వదు.

❓ ఒక కన్స్ట్రక్టర్ లోపల నుంచి ఇంకో కన్స్ట్రక్టర్ ని పిలవొచ్చా?

పిలవొచ్చు! దాన్నే Constructor Chaining అంటారు. `this(పారామీటర్స్)` అని రాసి పిలుస్తారు, కానీ ఇది కచ్చితంగా మొదటి లైన్ లోనే ఉండాలి.

❓ కన్స్ట్రక్టర్స్ కి private అని పెట్టొచ్చా?

పెట్టొచ్చు! అలా పెడితే బయట ఎవరూ మీ క్లాస్ కి ఆబ్జెక్ట్ క్రియేట్ చేయలేరు. దీన్ని Singleton డిజైన్ ప్యాటర్న్ లో ఎక్కువగా వాడతారు.

🚀 Quick Chapter Recap

  • ఆబ్జెక్ట్ క్రియేట్ అయిన వెంటనే డేటాని సెటప్ చేయడానికి Constructor వాడతారు.
  • దీనికి రిటర్న్ టైప్ ఉండదు, క్లాస్ పేరే ఉంటుంది.
  • పేర్లు కన్ఫ్యూజ్ అవ్వకుండా ఉండటానికి క్లాస్ వేరియబుల్ ముందు this వాడుతాం.
  • this() వాడి ఒక కన్స్ట్రక్టర్ ఇంకో కన్స్ట్రక్టర్ ని పిలవొచ్చు (Constructor Chaining).
  • ఒకే పేరుతో రకరకాల కన్స్ట్రక్టర్స్ రాయడాన్నే Constructor Overloading అంటారు.
