1. Overview & Acceptance

Welcome to Our Compiler ("we," "us," or "our"), an online developer platform operated by Balanju Solutions. We respect your privacy and are committed to protecting any information collected during your visit to ourcompiler.com.

By accessing or using Our Compiler, you consent to the data collection and usage practices described in this policy. If you do not agree with any portion of this Privacy Policy, please discontinue using the website.

2. Account-Free & Registration-Free Access

We do not require account creation or registration. You can access all online compilers, interactive editors, and programming tutorials without providing your name, phone number, physical address, or email address.

3. Log Files & Technical Data Collection

Like standard web server infrastructure, Our Compiler uses log files to ensure security, detect malicious activity, and optimize site performance. Information collected in log files includes:

  • Internet Protocol (IP) address
  • Browser type, language, and version
  • Operating system and device platform
  • Date and time stamp of requests
  • Referring / exit pages and URL paths

Log file data is processed automatically for diagnostic purposes and is not linked to any personally identifiable information.

4. Code Execution & Source Code Privacy

When you click "Run Code," your source code and input text are transmitted securely via HTTPS to our cloud backend runner for compilation and execution:

  • Code execution is stateless and processed in memory only. Your code is discarded immediately after execution completes.
  • We do not store your source code, use it to train AI models, or sell it to third parties.
  • Please refrain from embedding sensitive secrets, credentials, API keys, or personal data inside your public code submissions.

5. Browser Local Storage & Cookies

Our Compiler uses standard browser technologies to improve user experience:

  • Browser LocalStorage: We save your recent code drafts and selected color theme (Dark / Light mode) in your browser's local storage so your work is preserved when you refresh or reopen the page. This data remains on your local device.
  • Essential Cookies: Cookies may be used for session management, security checks, and site navigation.

8. GDPR & CCPA/CPRA Privacy Rights

Under international privacy regulations (including the EU General Data Protection Regulation and California Consumer Privacy Act), you have rights regarding your data:

  • Right to Know / Access: Request details on data collected.
  • Right to Deletion: Request deletion of any collected technical logs.
  • Right to Opt-Out: Opt-out of personalized ad targeting at any time.
  • Non-Discrimination: Equal service regardless of privacy choice.

9. Children's Online Privacy Protection Act (COPPA)

Our Compiler is designed for general audiences, students, and software developers. We do not knowingly collect personal identifiable information from children under 13 years of age. If a parent or guardian believes a child has submitted personal information, please contact us for immediate removal.

10. Data Security Controls

We implement robust technical and organizational security controls to protect information: end-to-end HTTPS TLS encryption, isolated container sandboxes with memory execution limits, automatic process timeouts, and rate limiting to prevent denial-of-service attacks.
