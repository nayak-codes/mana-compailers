📊 3. Log Files & Technical Data Collection

Like standard web server infrastructure, Our Compiler uses log files to ensure platform stability, detect malicious activity, and optimize site performance. Information collected in technical log files includes:

  • ✓ Internet Protocol (IP) address
  • ✓ Browser type, language, and version
  • ✓ Operating system and device platform
  • ✓ Date and time stamps of request URLs
  • ✓ Referring / exit page headers

Log file data is processed automatically for diagnostic purposes and is not linked to any personally identifiable information.

SECTION 04

🔒 4. Code Execution & Source Code Privacy

When you click ▶ Run Code, your source code and optional stdin input text are transmitted securely via HTTPS TLS 1.3 to our cloud execution backend:

  • ✓ Code execution is stateless and processed in memory only. Your code is destroyed immediately after output is returned.
  • ✓ We do not permanently store your source code, use it to train AI models, or sell it to third parties.
  • ✓ Please avoid embedding sensitive secrets, database passwords, or private API keys inside public code submissions.
