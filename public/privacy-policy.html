1. Overview & Acceptance

Welcome to Our Compiler ("we," "us," or "our"), an online multi-language code execution platform operated by Balanju Solutions. We respect your privacy and are committed to protecting any technical or personal information collected when you visit ourcompiler.com.

By accessing or using Our Compiler, you consent to the data collection and usage practices described in this Privacy Policy. If you do not agree with any portion of this policy, please discontinue using the website.

2. Account-Free & Registration-Free Access

We do not require account creation or user registration. You can access all 11 programming compilers, code sharing tools, and 775+ programming lessons without submitting your name, phone number, address, or password.

3. Log Files & Technical Data Collection

Like standard web server infrastructure, Our Compiler uses log files to ensure security, detect malicious activity, and optimize site performance. Information collected in log files includes:

  • ✓ Internet Protocol (IP) address
  • ✓ Browser type, version, and language preference
  • ✓ Operating system and device platform
  • ✓ Date and time stamps of request URLs
  • ✓ Referring / exit page headers

Log file data is processed automatically for diagnostic purposes and is not linked to any personally identifiable information.

4. Code Execution & Source Code Privacy

When you click ▶ Run Code, your source code and optional input text are transmitted securely via HTTPS TLS 1.3 to our isolated cloud runners:

  • ✓ Code execution is stateless and processed strictly in memory. Your code is destroyed immediately after output is returned.
  • ✓ We do not permanently store your source code, use it to train AI models, or sell it to third parties.
  • ✓ Please avoid embedding sensitive secrets, database passwords, or private API keys in your public code submissions.

5. Browser Local Storage & Cookies

Our Compiler uses standard browser local storage technologies to enhance developer user experience:

  • ✓ Browser LocalStorage (Code Saver): We save your active code drafts and selected IDE color theme (Dark / Light mode) in your browser's local storage so your work is preserved across refreshes and restarts. This data remains on your local device until you click "Clear Code".
  • ✓ Essential Session Cookies: Cookies may be used for security checks, session management, and site preferences.
