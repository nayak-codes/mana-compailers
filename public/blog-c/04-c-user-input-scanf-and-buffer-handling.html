C User Input: scanf(), Address Operator (&), Buffer Pitfalls & fgets() (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 4 📂 Phase 03: Input & Operators 📅 2026 Edition
📌 Covered in this in-depth guide: scanf() Mechanics · Address Operator (&) · Reading Primitives & Strings · Stdin Buffer Pitfall (\n) · fgets() Safe Text Input · Input Validation

Phase 3 (Part 1): C User Input, scanf(), Buffer Mechanics & fgets() Masterclass కు స్వాగతం! యూజర్ కీబోర్డ్ ద్వారా ఇచ్చే డేటాని (Standard Input: stdin) మన ప్రోగ్రామ్ లోకి తీసుకోవాలంటే C లో scanf() (Scan Formatted) అనే ఫంక్షన్ వాడతాం. అయితే, C లాంగ్వేజ్ డైరెక్ట్ గా RAM మెమరీ తో పనిచేస్తుంది కాబట్టి, scanf() వాడేటప్పుడు అడ్రస్ ఆపరేటర్ (&) ఎందుకు పెట్టాలి అనేది తెలుసుకోవడం చాలా ముఖ్యం. అంతేకాకుండా, C లో ఇన్పుట్ తీసుకునేటప్పుడు వచ్చే అతి పెద్ద సమస్య "Input Buffer Trap (మిగిలిపోయిన Newline)". ఈ గైడ్ లో, అన్ని డేటా టైప్స్ కి ఇన్పుట్ ఎలా తీసుకోవాలి, ఆ బఫర్ ప్రాబ్లం ని ఎలా సాల్వ్ చేయాలి, స్పేస్ లతో సహా పేర్లని చదవడానికి fgets() ఎలా వాడాలి అనేది పూర్తిగా తెలుగులో నేర్చుకుందాం.

1scanf() ఎలా పనిచేస్తుంది? & ఆపరేటర్ ఎందుకు వాడాలి?

సాధారణంగా ఫంక్షన్స్ లోపలికి వాల్యూస్ కాపీ అవుతాయి. కానీ scanf() అనేది కీబోర్డ్ నుండి తీసుకున్న వాల్యూ ని మనం క్రియేట్ చేసిన వేరియబుల్ యొక్క RAM మెమరీ అడ్రస్ లో డైరెక్ట్ గా సేవ్ చేయాలి. అందుకే వేరియబుల్ పేరు ముందు కచ్చితంగా Address-of Operator (&) పెడతాము:

RAM లోకి scanf() డేటాని ఎలా రాస్తుందో చూద్దాం:
int age; // RAM లో 0x2000 అనే అడ్రస్ లో ప్లేస్ వచ్చింది (ఇప్పుడు Garbage value ఉంది)
scanf("%d", &age); // యూజర్ "21" అని ఎంటర్ చేసాడు

1. scanf() యూజర్ ఇచ్చిన "21" ని బైనరీ లోకి మారుస్తుంది
2. తర్వాత scanf() ఆ 0x2000 అడ్రస్ కి వెళ్లి డైరెక్ట్ గా 21 ని అక్కడ సేవ్ చేస్తుంది!

RAM Address 0x2000: [ 21 ] <--- age అప్డేట్ అయిపొయింది!

⚠️ scanf() లో & ఎప్పుడు పెట్టకూడదు?

Strings (పదాలు లేదా పేర్లు, ఉదాహరణకి char name[50];) ని రీడ్ చేసేటప్పుడు & అవసరం లేదు: scanf("%s", name); అని ఇస్తే చాలు.
ఎందుకు? ఎందుకంటే C లో ఒక అర్రే (Array) పేరు రాస్తే, ఆటోమాటిక్ గా అది దాని ఫస్ట్ మెమరీ అడ్రస్ (&name[0]) ని ఇచ్చేస్తుంది!

C — User Curriculum Example ▶ Run in C Compiler 
#include <stdio.h>

int main(void) {
    int age;

    printf("Enter your age: ");
    scanf("%d", &age);

    printf("Your age is %d\n", age);
    return 0;
}
2వేర్వేరు Data Types ని scanf() తో చదవడం

ఏ డేటా కి ఏ ఫార్మాట్ వాడాలో scanf() కి కచ్చితంగా చెప్పాలి:

Data Typescanf ఫార్మాట్సింటాక్స్ముఖ్యమైన విషయం
int%dscanf("%d", &num);ముందున్న స్పేసెస్ ని ఆటోమాటిక్ గా ఇగ్నోర్ చేస్తుంది.
float%fscanf("%f", &gpa);32-bit float నంబర్ ని రీడ్ చేస్తుంది.
double%lf (Long Float)scanf("%lf", &price);⚠️ scanf లో కచ్చితంగా %lf వాడాలి (తప్పుగా %f వాడితే మెమరీ కరప్ట్ అవుతుంది!).
char%cscanf(" %c", &grade);⚠️ స్పేసెస్ ని ఇగ్నోర్ చేయదు! అందుకే " %c" లాగా ముందు ఒక ఖాళీ స్పేస్ ఇవ్వాలి.
char[] (Word)%sscanf("%s", name);ఒక్క పదాన్ని మాత్రమే చదువుతుంది; స్పేస్ వస్తే ఆగిపోతుంది.
3అందరినీ కన్ఫ్యూజ్ చేసే Input Buffer ( ) ట్రాప్ ⚠️

⚠️ scanf("%d") తర్వాత scanf("%c") ఎందుకు స్కిప్ అయిపోతుంది?

యూజర్ కీబోర్డ్ మీద 25 టైప్ చేసి ENTER కొట్టినప్పుడు, C కంపైలర్ బఫర్ లో '2', '5', '\n' సేవ్ అవుతాయి.
1. ఫస్ట్ ఉన్న scanf("%d", &age) కేవలం 25 ని మాత్రమే రీడ్ చేసి '\n' (ఎంటర్ కీ) ని అక్కడే బఫర్ లో వదిలేస్తుంది.
2. నెక్స్ట్ లైన్ లో scanf("%c", &grade) కాల్ అయినప్పుడు, అది యూజర్ ఎంటర్ చేసేదాకా ఆగకుండా ఆ మిగిలిపోయిన '\n' ని తీసేసుకొని స్కిప్ అయిపోతుంది!

✅ సొల్యూషన్ 1: scanf(" %c", &grade); (ఇలా పర్సంటేజ్ కి ముందు ఖాళీ స్పేస్ ఇస్తే, మిగిలిపోయిన ఆ ఎంటర్ కీ ని ఇగ్నోర్ చేస్తుంది).
✅ సొల్యూషన్ 2: బఫర్ ని పూర్తిగా క్లీన్ చేయడానికి ఈ లూప్ వాడొచ్చు: while((c = getchar()) != '\n' && c != EOF);

4fgets() తో స్పేస్ లతో సహా స్ట్రింగ్స్ ని సేఫ్ గా చదవడం

scanf("%s") వాడితే మధ్యలో స్పేస్ రాగానే ఆగిపోతుంది. ఒకవేళ యూజర్ సైజు కి మించి పెద్ద పేరు ఇస్తే Buffer Overflow వచ్చి ప్రోగ్రామ్ క్రాష్ అవుతుంది. అందుకే ప్రొఫెషనల్ C డెవలపర్స్ ఎప్పుడూ టెక్స్ట్ కోసం fgets() వాడతారు:

C — Safe String Input with fgets() & Input Validation ▶ Run Code 
#include <stdio.h>
#include <string.h>

int main(void) {
    char fullName[50];
    int rollNumber;

    // 1. Reading multi-word line safely with fgets
    printf("Enter your Full Name (with spaces): ");
    fgets(fullName, sizeof(fullName), stdin);

    // Remove trailing newline captured by fgets
    fullName[strcspn(fullName, "\n")] = 0;

    // 2. Robust Input Validation with scanf return value
    printf("Enter your Roll Number: ");
    if (scanf("%d", &rollNumber) != 1) {
        printf("❌ Invalid Input! You must enter a numeric integer.\n");
        return 1; // Exit with error code
    }

    printf("\n--- Student Card ---\n");
    printf("Name: %s\n", fullName);
    printf("Roll No: %d\n", rollNumber);

    return 0;
}

int main(void) {

    scanf("%d", &luckyNumber);

    printf("Namaste, %s! Your lucky number squared is %d.\n", name, luckyNumber * luckyNumber);
    return 0;
}
