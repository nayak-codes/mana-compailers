Call by Value vs Call by Reference (పాయింటర్స్ ద్వారా)

⚡ Modern C (C99 / C11) 🟢 Chapter 10 of 20 📂 Phase 03: ఫంక్షన్స్, స్కోప్ & రికర్షన్ 📅 2026 Edition
📌 Covered in this chapter: మెమరీ కాపీ vs ఒరిజినల్ అడ్రస్ పాసింగ్ · swap(&a, &b) స్వాపింగ్ పోస్ట్‌మార్టం · మల్టిపుల్ రిటర్న్ వాల్యూస్
ఫంక్షన్‌కు ఆర్గ్యుమెంట్లను పంపేటప్పుడు విలువ కాపీ అవుతుందా (Call by Value), లేక అసలైన మెమరీ అడ్రస్ వెళ్తుందా (Call by Reference) అనేది C ప్రోగ్రామింగ్‌లో అత్యంత కీలకమైన అంశం. పాయింటర్ల ద్వారా విలువలను స్వాప్ చేసే విధానాన్ని నేర్చుకుందాం.
1Call by Value లో స్వాపింగ్ ఎందుకు ఫెయిల్ అవుతుంది?

సాధారణంగా ఫంక్షన్‌కు పంపినప్పుడు వేరియబుల్స్ కాపీ మాత్రమే వెళ్తాయి. ఫంక్షన్ లోపల మార్పులు చేస్తే కేవలం లోకల్ కాపీలు మాత్రమే మారుతాయి, main() లోని అసలు వేరియబుల్స్ అలాగే ఉంటాయి.

C — Swapping using Pointers (Call by Reference) ▶ Run in Compiler 
#include <stdio.h>

// పాయింటర్లు (*x, *y) మెమరీ అడ్రస్‌ను సూచిస్తాయి
void swap(int* x, int* y) {
    int temp = *x;
    *x = *y;
    *y = temp;
}

int main() {
    int a = 10, b = 20;
    printf("Before: a = %d, b = %d\n", a, b);

    // &a, &b అంటే మెమరీ అడ్రస్‌లను పంపడం
    swap(&a, &b);

    printf("After:  a = %d, b = %d (Swapped! ✅)\n", a, b);
    return 0;
}
