Trees Basics & Binary Search Tree (BST) (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 56 📂 Phase 19: Data Structures - 2 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Tree Terminology · Root & Leaves · Binary Tree · Binary Search Tree (BST) Logic

ఇంతవరకు మనం నేర్చుకున్న Array, Linked List అన్నీ ఒక సరళ రేఖలో (Linear) ఉంటాయి. అంటే డేటా వెతకాలంటే ఒకదాని తర్వాత ఒకటి వెతుక్కుంటూ వెళ్లాలి. ఒకవేళ 1 కోటి రికార్డ్స్ ఉంటే, లాస్ట్ రికార్డ్ వెతకడానికి ఒక కోటి సెకన్లు పడుతుంది! కానీ గూగుల్ లాంటి వాళ్ళు మీరు టైప్ చేయగానే ఆన్సర్ ఎలా ఇస్తున్నారు? దానికి వాడే బ్రహ్మాస్త్రమే Trees (చెట్లు). ఇవి Non-linear డేటా స్ట్రక్చర్స్. మన ఫ్యామిలీ ట్రీ లాగా, లేదా కంప్యూటర్ ఫోల్డర్ల లాగా డేటాని ఒక చెట్టు కొమ్మల్లాగా విడగొట్టి కనెక్ట్ చేస్తాయి. ఇందులో Binary Search Tree (BST) అయితే డేటాని వెతకడంలో స్పీడ్ కి రారాజు! అదెలాగో ఈరోజు అద్భుతంగా నేర్చుకుందాం.

1 ట్రీ (Tree) లో ఉండే పదాలు (Terminology)

ప్రోగ్రామింగ్ లో చెట్టు తలకిందులుగా ఉంటుంది! అంటే వేర్లు పైన ఉంటాయి, ఆకులు కింద ఉంటాయి.

  • Root (రూట్): చెట్టు పైభాగంలో ఉండే మొట్టమొదటి బాక్స్. (హెడ్ లాగా అన్నమాట).
  • Parent & Child (తల్లి - పిల్లలు): ఒక బాక్స్ కింద ఇంకో బాక్స్ కి లింక్ ఉంటే, పైనున్న దాన్ని పేరెంట్ అని, కింద దాన్ని చైల్డ్ అని అంటారు.
  • Leaf (ఆకు): కింద ఇంకా ఎవరికీ కనెక్ట్ అవ్వని బాక్స్ ని (చివరి వాటిని) లీఫ్ నోడ్స్ అంటారు.

Binary Tree (బైనరీ ట్రీ) అంటే ఏంటి? ఏ చెట్టులో అయితే ప్రతి పేరెంట్ కి కేవలం మాక్సిమం ఇద్దరు పిల్లలే (Left Child, Right Child) ఉంటారో, దాన్నే బైనరీ ట్రీ అంటారు. (అంటే 0, 1, లేదా 2 పిల్లలు మాత్రమే ఉండాలి).

2 Binary Search Tree (BST) లాజిక్

బైనరీ ట్రీ కి ఒక పవర్ఫుల్ కండిషన్ (రూల్) పెడితే, అది బైనరీ సెర్చ్ ట్రీ (BST) అవుతుంది! ఆ రూల్ ఏంటంటే:

🔍 రియల్ లైఫ్ స్టోరీ: స్కూల్ అసెంబ్లీ లైన్ (The Left-Right Rule)

ఒక బాస్ (Root = 50) నిలబడ్డాడు. కొత్తగా ఒక పిల్లాడు (30) వచ్చాడు. బాస్ కన్నా తక్కువ ఉన్నాడు కాబట్టి, కచ్చితంగా ఎడమ వైపు (Left) నిలబడాలి. ఇంకో పిల్లాడు (70) వచ్చాడు. బాస్ కన్నా ఎక్కువ ఉన్నాడు కాబట్టి కుడి వైపు (Right) నిలబడాలి.

ఇప్పుడు మీరు 25 కోసం వెతకాలి. బాస్ ని అడుగుతారు. బాస్ ఏమంటాడు? "నేను 50, నువ్వు వెతుకుతున్నది నాకన్నా చిన్నది కదా, కాబట్టి నా కుడి వైపు అసలు వెళ్ళకు, అందులో లక్ష మంది ఉన్నా వాళ్ళంతా నాకన్నా పెద్దోళ్ళే. డైరెక్ట్ గా నా ఎడమ వైపు వెళ్లి వెతుక్కో" అంటాడు.
దీనివల్ల సగం డేటా వెతకాల్సిన అవసరమే లేకుండా డిలీట్ అయిపోతుంది! ఇదే BST స్పీడ్ మ్యాజిక్ (O(log N)).

3 ఒకే ఒక సింపుల్ కోడ్ (Creating a BST Node)

కింద కోడ్ లో డబుల్ లింక్డ్ లిస్ట్ లాగానే రెండు పాయింటర్స్ తీసుకుని, కానీ ఈసారి వాటిని left మరియు right గా పెట్టి ఒక సింపుల్ BST ని ఎలా డిజైన్ చేసామో చూడండి.

C — Binary Search Tree (BST) ▶ Run Code 
#include <stdio.h>
#include <stdlib.h>

// ట్రీ నోడ్ బ్లూప్రింట్ (ఒక డేటా, రెండు చేతులు)
struct Node {
    int data;
    struct Node* left;  // ఎడమ చేయి
    struct Node* right; // కుడి చేయి
};

// కొత్త నోడ్ ని తయారుచేసే ఫంక్షన్
struct Node* createNode(int value) {
    struct Node* newNode = (struct Node*)malloc(sizeof(struct Node));
    newNode->data = value;
    newNode->left = NULL;
    newNode->right = NULL;
    return newNode;
}

// BST లోకి కొత్త వాల్యూ ని దూర్చడం (Insert)
struct Node* insertNode(struct Node* root, int value) {
    // చెట్టు ఖాళీగా ఉంటే, వీడే రూట్ (బాస్) అవుతాడు
    if (root == NULL) {
        return createNode(value);
    }
    
    // వాల్యూ బాస్ కన్నా చిన్నది అయితే ఎడమ వైపు వెళ్ళు
    if (value < root->data) {
        root->left = insertNode(root->left, value);
    }
    // వాల్యూ బాస్ కన్నా పెద్దది అయితే కుడి వైపు వెళ్ళు
    else if (value > root->data) {
        root->right = insertNode(root->right, value);
    }
    
    // బాస్ కి పర్మిషన్ ఇచ్చి రిటర్న్ చేయి
    return root;
}

int main() {
    printf("--- Binary Search Tree (BST) ---\n\n");
    
    struct Node* root = NULL; // మొదట్లో చెట్టు లేదు
    
    // 50 ని యాడ్ చేద్దాం (ఇది రూట్ అవుతుంది)
    root = insertNode(root, 50);
    printf("Inserted 50 (Root)\n");
    
    // చిన్నవి యాడ్ చేద్దాం (ఇవి ఎడమ వైపుకి వెళ్తాయి)
    insertNode(root, 30);
    insertNode(root, 20);
    printf("Inserted 30, 20 (Went Left)\n");
    
    // పెద్దవి యాడ్ చేద్దాం (ఇవి కుడి వైపుకి వెళ్తాయి)
    insertNode(root, 70);
    insertNode(root, 90);
    printf("Inserted 70, 90 (Went Right)\n");
    
    printf("\n[+] Tree successfully created in RAM!\n");
    
    // (నెక్స్ట్ లెసన్ లో వీటిని ఎలా ప్రింట్ చేయాలో చూద్దాం)
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • struct Node* left, *right;: డబుల్ లింక్డ్ లిస్ట్ లో లాగా ఇక్కడ వెనక్కి వెళ్లే దారి ఉండదు! పేరెంట్ నుండి చైల్డ్ కి, ఎడమ కొమ్మ లేదా కుడి కొమ్మ గా రెండు దారులు చీలుతాయి.
  • insertNode(...): ఇది ఒక రికర్సివ్ (Recursive) ఫంక్షన్. అంటే తనని తనే కాల్ చేసుకుంటుంది. బాస్ కన్నా చిన్నది వస్తే, insertNode(root->left, value) అని పిలిచి, ఎడమ పక్కన ఉన్నవాడిని అడగమని కిందికి పంపుతుంది. ఖాళీ దొరికేదాకా ఆ వాల్యూ కిందికి దిగుతూనే ఉంటుంది!
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: ఒకవేళ వాల్యూ బాస్ తో సమానం అయితే (Duplicate) ఎటు వెళ్ళాలి?

చాలా ఇంపార్టెంట్ క్వశ్చన్! స్టాండర్డ్ బైనరీ సెర్చ్ ట్రీ లో డూప్లికేట్స్ ని అసలు ఒప్పుకోరు. కానీ కొన్ని సిస్టమ్స్ లో కావాలనుకుంటే, వాటిని ఎప్పుడూ కుడి వైపు (Right side) కి వెళ్లేలా రూల్ రాసుకుంటారు. (>= అని వాడతారు).

Q2: BST లో డేటా వెతకడానికి ఎంత టైమ్ పడుతుంది?

ఆవరేజ్ గా O(log N) పడుతుంది. అంటే మీరు ప్రతిసారి సగం చెట్టుని ఇగ్నోర్ చేస్తారు. 1024 రికార్డ్స్ ఉంటే కేవలం 10 సార్లు జంప్ చేస్తే చాలు డేటా దొరుకుతుంది. అర్రే లో అయితే 1024 సార్లు వెతకాలి. అదీ పవర్ ఆఫ్ ట్రీ!

Q3: వరస్ట్ కేస్ (Worst case) లో BST ఎలా బిహేవ్ చేస్తుంది?

మీరు డేటాని ఒక ఆర్డర్ లో (10, 20, 30, 40) ఇస్తే, అన్నీ బాస్ కి కుడివైపే వెళ్తాయి. అప్పుడు ఆ చెట్టు కాస్తా ఒక సరళ రేఖ (Linked List లాగా) అయిపోతుంది! దాన్ని Skewed Tree అంటారు. అప్పుడు దాని స్పీడ్ కాస్తా స్లో (O(N)) అయిపోతుంది. దీన్ని సాల్వ్ చేయడానికే AVL Trees, Red-Black Trees అని డిజైన్ చేశారు (వాటంతట అవే బ్యాలెన్స్ చేసుకుంటాయి).
