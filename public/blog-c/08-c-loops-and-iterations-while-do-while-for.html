Loops & Iterations: while, do-while, for (తెలుగులో డీప్ ఎక్స్‌ప్లనేషన్)

⚡ C (C17 / C23 Standard) 🟢 Lesson 8 📂 Phase 05: Loops & Iterations 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: లూప్స్ అవసరం ఏంటి? · Entry Control vs Exit Control · for లూప్ నిర్మాణం

కంప్యూటర్లకు ఉన్న అతి పెద్ద బలం ఏమిటంటే... ఒకే పనిని విసుగు లేకుండా వేలసార్లు, లక్షలసార్లు చేయగలగడం. మనుషులమైన మనం ఒకే మాటను వందసార్లు రాయాలంటే బోర్ గా ఫీల్ అవుతాం. కానీ సిస్టమ్ కి ఆ ప్రాబ్లెమ్ లేదు. ఒకే పనిని మళ్ళీ మళ్ళీ చేయడాన్ని ప్రోగ్రామింగ్ లో Looping (లూపింగ్) అంటారు. ఈ పాఠంలో లూప్స్ ఎన్ని రకాలు ఉన్నాయో, వాటిని ఎప్పుడు వాడాలో విశ్లేషిద్దాం.

1 అసలు లూప్స్ ఎందుకు?

ఒక చిన్న ఉదాహరణ తీసుకుందాం. మీరు స్క్రీన్ పైన మీ పేరును 5 సార్లు ప్రింట్ చేయాలి. అప్పుడు మీరు printf ని 5 సార్లు రాస్తారు. ఒకవేళ 1000 సార్లు ప్రింట్ చేయాలంటే? 1000 లైన్ల కోడ్ రాయడం అసాధ్యం. దానికి టైమ్ వేస్ట్, ఎనర్జీ వేస్ట్. లూప్ వాడితే కేవలం 2 లైన్లతో ఆ పని అయిపోతుంది.

🔄 రియల్ లైఫ్ స్టోరీ: రన్నింగ్ ట్రాక్ లో అథ్లెట్

ఒక కోచ్ తన స్టూడెంట్ ని "ఈ గ్రౌండ్ చుట్టూ 10 రౌండ్లు కొట్టు" అని చెప్పాడు. స్టూడెంట్ ఏం చేస్తాడు? ప్రతి రౌండ్ పూర్తి అవ్వగానే "ఇది నా ఒకటో రౌండ్, ఇది రెండో రౌండ్..." అని మనసులో లెక్క పెట్టుకుంటాడు. 10 రౌండ్లు పూర్తవ్వగానే ఆగిపోతాడు.

ఇక్కడ రౌండ్ కొట్టడం = పని (Execution).
లెక్క పెట్టుకోవడం = కండిషన్ చెక్ (Condition checking). లూప్స్ సరిగ్గా ఇదే కాన్సెప్ట్ తో పనిచేస్తాయి!

2 సింపుల్ ఫర్ లూప్ (For Loop)

కింద ఉన్న సింపుల్ కోడ్ ని చూడండి. ఇది కేవలం 1 నుండి 3 వరకు నంబర్స్ ని ప్రింట్ చేస్తుంది. ఇది చదివితే మీకు లూప్స్ ఎంత ఈజీనో అర్థమైపోతుంది.

C — Simple Loop ▶ Run Code 
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 3; i++) {
        printf("Count: %d\n", i);
    }
    return 0;
}

ఇంతే! int i = 1 అంటే 1 తో మొదలుపెట్టాం. i <= 3 అంటే 3 వచ్చే వరకు మాత్రమే ఆగు అన్నాం. i++ అంటే ఒక్కొక్కటి పెంచుకుంటూ వెళ్ళు అని అర్థం. ఈ ఒక్క చిన్న కోడ్ బ్లాక్ తో మొత్తం లూపింగ్ కాన్సెప్ట్ కవర్ అయిపోతుంది.

3 ఫ్రీక్వెంట్ గా అడిగే ప్రశ్నలు (FAQ)

Q: while లూప్ ఎప్పుడు వాడాలి?

మీకు ఒక పని ఎన్నిసార్లు చేయాలో ముందే తెలిస్తే 'for' లూప్ వాడాలి. ఎన్నిసార్లు చేయాలో తెలియదు, కానీ ఒక కండిషన్ ఫెయిల్ అయ్యేదాకా చేస్తూనే ఉండాలి అనుకుంటే 'while' లూప్ వాడాలి.

Q: ఇన్ఫినిట్ లూప్ అంటే ఏమిటి?

కండిషన్ ఎప్పటికీ ఫెయిల్ అవ్వకుండా, లూప్ ఆగకుండా రన్ అవుతూనే ఉంటే దాన్ని ఇన్ఫినిట్ లూప్ అంటారు. కోడ్ లో కండిషన్ తప్పుగా రాస్తే మనకి తెలీకుండానే ఇవి క్రియేట్ అయిపోయి ప్రోగ్రామ్ ని హ్యాంగ్ చేస్తాయి.
