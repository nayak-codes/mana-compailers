Variables Scope & Lifecycle in C (తెలుగులో డీప్ ఎక్స్‌ప్లనేషన్)

⚡ C (C17 / C23 Standard) 🟢 Lesson 11 📂 Phase 06: Functions & Modular Programming 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Local Scope · Global Scope · Block Scope · Variable Lifecycle

ఒక వేరియబుల్ ని క్రియేట్ చేసిన తర్వాత అది ఎంతసేపు బ్రతికి ఉంటుంది? దాన్ని సిస్టమ్ లో ఎవరెవరు చూడగలరు? ఈ కాన్సెప్ట్ నే ప్రోగ్రామింగ్ లో Scope (స్కోప్) అంటారు. బగ్స్ లేకుండా కోడ్ రాయాలంటే ఈ కాన్సెప్ట్ చాలా ముఖ్యం.

1 లోకల్ స్కోప్ vs గ్లోబల్ స్కోప్

ఒక {} బ్రాకెట్స్ (Block) లోపల క్రియేట్ చేసిన వేరియబుల్ ని Local Variable అంటారు. బయట వాళ్ళకు అసలు అలాంటి ఒక వేరియబుల్ ఉందన్న విషయం కూడా తెలియదు. ఫంక్షన్స్ అన్నీటికీ పైన క్రియేట్ చేసే వేరియబుల్స్ ని Global Variables అంటారు. వీటిని ఎవరైనా వాడుకోవచ్చు.

🏠 రియల్ లైఫ్ స్టోరీ: ఇంట్లో టీవీ vs పబ్లిక్ పార్క్

మీ ఇంట్లో ఉన్న టీవీ కేవలం మీ ఇంట్లో (లోకల్ గా) ఉన్నవాళ్లు మాత్రమే చూడగలరు. ఇది Local Variable.

అదే మీ వీధిలో ఉన్న పబ్లిక్ పార్క్ కి ఎవరైనా వెళ్లొచ్చు. ఇది Global Variable. గ్లోబల్ వేరియబుల్స్ ని ఏ ఫంక్షన్ అయినా మార్చేయొచ్చు కాబట్టి వీటిని తక్కువగా వాడాలి.

2 ఒకే ఒక సింపుల్ కోడ్

కింద కోడ్ లో చూడండి, x అనే వేరియబుల్ గ్లోబల్ గా ఉంది కాబట్టి ఎవరైనా వాడొచ్చు. కానీ y అనేది కేవలం మెయిన్ ఫంక్షన్ లో మాత్రమే ఉంది కాబట్టి అది లోకల్.

C — Simple Scope ▶ Run Code 
#include <stdio.h>

// ఇది గ్లోబల్ వేరియబుల్ (అందరికీ కనిపిస్తుంది)
int x = 100; 

int main(void) {
    // ఇది లోకల్ వేరియబుల్ (కేవలం ఇక్కడ మాత్రమే)
    int y = 50; 
    
    printf("Global: %d, Local: %d\n", x, y);
    return 0;
}
3 ఫ్రీక్వెంట్ గా అడిగే ప్రశ్నలు (FAQ)

Q: ఒకే పేరుతో Local మరియు Global వేరియబుల్స్ ఉండొచ్చా?

ఉండొచ్చు! అప్పుడు సిస్టమ్ ఎప్పుడూ లోకల్ వేరియబుల్ కే మొదటి ప్రాధాన్యత ఇస్తుంది. దీన్నే Variable Shadowing అంటారు.

Q: Static Variables అంటే ఏమిటి?

ఇవి లోకల్ గా ఒక ఫంక్షన్ లోనే ఉంటాయి, కానీ ఫంక్షన్ అవ్వగానే చనిపోవు! నెక్స్ట్ టైం ఫంక్షన్ ని మళ్ళీ పిలిచినప్పుడు పాత వాల్యూ ని అలాగే గుర్తుపెట్టుకుంటాయి.
