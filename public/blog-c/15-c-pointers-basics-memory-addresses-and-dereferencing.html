Pointers Basics: The Core of C Language (తెలుగులో డీప్ ఎక్స్‌ప్లనేషన్)

⚡ C (C17 / C23 Standard) 🟢 Lesson 15 📂 Phase 08: Strings & Pointers Intro 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Memory Addresses · Pointer Declaration · Dereferencing (*) · అడ్రస్ ఆపరేటర్ (&)

చాలామంది స్టూడెంట్స్ C లాంగ్వేజ్ నేర్చుకునేటప్పుడు కంగారుపడే టాపిక్ ఏదైనా ఉందంటే అది Pointers (పాయింటర్స్) మాత్రమే. కానీ నిజానికి పాయింటర్స్ అంత కష్టం కాదు, అవి కేవలం కొన్ని రియల్ లైఫ్ లాజిక్స్ మీద ఆధారపడి ఉంటాయి. C లాంగ్వేజ్ కి అంత స్పీడ్, అంత పవర్ ఎక్కడి నుండి వస్తుంది అంటే అది కేవలం ఈ పాయింటర్స్ వల్లే! ఆపరేటింగ్ సిస్టమ్స్ ని, గేమ్ ఇంజిన్స్ ని, కంపైలర్స్ ని రాయడానికి పాయింటర్స్ వాడకం కచ్చితంగా ఉండాలి. ఈ పాఠంలో ఆ భయాన్ని పూర్తిగా పోగొట్టి, పాయింటర్స్ అంటే ఏంటో డీప్ గా తెలుసుకుందాం.

1 అసలు పాయింటర్ అంటే ఏమిటి?

సాధారణంగా ఒక వేరియబుల్ (ఉదాహరణకు int age = 20;) అంటే, ఆ డబ్బా లోపల 20 అనే నంబర్ దాగి ఉంటుంది. అంటే ఒక మామూలు వేరియబుల్ కేవలం "డేటా" ని మాత్రమే స్టోర్ చేసుకుంటుంది.

కానీ పాయింటర్ కూడా ఒక వేరియబుల్ లాంటిదే కాకపోతే అది డేటాని స్టోర్ చేయదు. దానికి బదులుగా ఇంకొక వేరియబుల్ యొక్క అడ్రస్ (Address) ని స్టోర్ చేసుకుంటుంది. అంటే ఒక డబ్బా ఎక్కడ ఉందో చెప్పే అడ్రస్ మాత్రమే అందులో ఉంటుంది.

🗺️ రియల్ లైఫ్ స్టోరీ: మీ స్నేహితుడి ఇల్లు

మీరు మీ స్నేహితుడి (Friend) ని కలవాలి అనుకున్నారు. వాడి ఇల్లు మీకు తెలీదు. కానీ మీ చేతిలో ఒక కాగితం ఉంది. ఆ కాగితం మీద వాడి ఇంటి అడ్రస్ (Address) రాసి ఉంది. (ఉదా: ప్లాట్ నంబర్ 45, బంజారా హిల్స్).

ఇప్పుడు ఆ కాగితం మీ ఫ్రెండ్ కాదు! కానీ ఆ కాగితం మీ ఫ్రెండ్ దగ్గరికి మిమ్మల్ని తీసుకువెళ్లగలదు (Point చేస్తుంది).
మీ ఫ్రెండ్ = Data (వేరియబుల్).
మీ చేతిలో ఉన్న కాగితం = Pointer (పాయింటర్).

అందుకే దాని పేరు పాయింటర్. అది ఇంకొక దాని వైపు వేలు చూపిస్తూ (పాయింట్ చేస్తూ) ఉంటుంది.

2 అడ్రస్ ఎలా తెలుసుకోవాలి? (& మరియు *)

ఒక వేరియబుల్ యొక్క అడ్రస్ తెలుసుకోవాలంటే దాని ముందు & (ఆంపర్సాండ్) పెట్టాలి. దీన్నే "Address of" ఆపరేటర్ అంటారు.
ఒక పాయింటర్ దగ్గర అడ్రస్ ఉంది కదా, ఆ అడ్రస్ లోపలికి వెళ్లి అక్కడ ఉన్న డేటాని చూడాలంటే * (స్టార్) వాడాలి. దీన్నే "Dereference" ఆపరేటర్ అంటారు. అంటే కాగితంలో ఉన్న అడ్రస్ దగ్గరికి వెళ్లి తలుపు తట్టడం లాంటిది.

3 ఒకే ఒక సింపుల్ కోడ్

కింద కోడ్ లో చూడండి, age అనే డబ్బా ఉంది. ptr అనే కాగితం (పాయింటర్) మీద ఆ డబ్బా అడ్రస్ రాసుకున్నాం. చివర్లో ఆ కాగితం వాడి ఆ డబ్బా లోపల ఉన్న వాల్యూ ని ప్రింట్ చేస్తున్నాం.

C — Simple Pointer ▶ Run Code 
#include <stdio.h>

int main(void) {
    int age = 20;
    
    // పాయింటర్ ని క్రియేట్ చేసి దాంట్లో అడ్రస్ దాస్తున్నాం
    int *ptr = &age; 
    
    // పాయింటర్ సాయంతో ఆ అడ్రస్ లోపల ఏముందో చూస్తున్నాం (*)
    printf("Value is: %d\n", *ptr); // 20 వస్తుంది
    
    return 0;
}
4 ఫ్రీక్వెంట్ గా అడిగే ప్రశ్నలు (FAQ)

Q: అసలు డైరెక్ట్ గా డేటాని వాడొచ్చు కదా, అడ్రస్ లతో పని ఏముంది?

డైరెక్ట్ గా వాడితే ఒక ఫంక్షన్ నుండి ఇంకో ఫంక్షన్ కి డేటా పంపినపుడు మొత్తం డేటా జిరాక్స్ (Copy) అవుతుంది. దానికి చాలా మెమరీ వేస్ట్ అవుతుంది. అడ్రస్ ఇస్తే జిరాక్స్ తీయక్కర్లేదు, డైరెక్ట్ గా ఒరిజినల్ కాగితాన్ని (Memory) ఎడిట్ చేయొచ్చు. స్పీడ్ విపరీతంగా పెరుగుతుంది.

Q: నల్ పాయింటర్ (Null Pointer) అంటే ఏమిటి?

పాయింటర్ క్రియేట్ చేసి అందులో ఏ అడ్రస్ వేయకపోతే అది గాలిలో ఏదో ఒక అడ్రస్ కి పాయింట్ చేస్తుంది. దానివల్ల సిస్టమ్ క్రాష్ అవుతుంది. అందుకే అందులో NULL అని రాస్తారు. అంటే ఆ కాగితం ఖాళీగా ఉంది, ఎవరి అడ్రస్ లేదు అని అర్థం.
