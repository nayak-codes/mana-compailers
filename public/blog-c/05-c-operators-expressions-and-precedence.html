C Operators, Precedence & 6 Real-World Practice Programs

⚡ C (C17 / C23 Standard) 🟢 Lesson 5 📂 Phase 03: Input & Operators 📅 2026 Edition
📌 Covered in this in-depth guide: Arithmetic & Modulus · Relational & Logical · Prefix vs Postfix (++x/x++) · Bitwise · Ternary · Precedence Table · 6 Practice Programs

Phase 3 (Part 2): C Operators & 6 Practice Programs Masterclass కు స్వాగతం! మన ప్రోగ్రామ్ లో మ్యాథ్స్ కాలిక్యులేషన్స్ చేయాలన్నా, కండిషన్స్ చెక్ చేయాలన్నా, లేదా డైరెక్ట్ గా బైనరీ బిట్స్ ని మార్చాలన్నా మనకు Operators (ఆపరేటర్లు) కావాలి. ఈ గైడ్ లో, మనం C లో ఉన్న అన్నీ రకాల ఆపరేటర్లను (Arithmetic, Relational, Logical, Bitwise, Ternary), Prefix vs Postfix ల మధ్య ఉన్న తేడాలని, Operator Precedence (ఏ ఆపరేటర్ ఫస్ట్ రన్ అవ్వాలి) టేబుల్ ని, మరియు రియల్ టైం లో వాడే 6 ప్రాక్టికల్ ప్రోగ్రామ్స్ ని తెలుగులో నేర్చుకుందాం.

1C లో ఉండే ఆపరేటర్ల రకాలు

C లాంగ్వేజ్ లో ఆపరేటర్లను ముఖ్యంగా 6 రకాలుగా విభజించవచ్చు:

1. Arithmetic (లెక్కల కోసం)
  • + (Addition), - (Subtraction)
  • * (Multiplication), / (Division)
  • % (Modulus - శేషం కనుక్కోవడానికి) ⚠️ ఇది పాయింట్ నంబర్స్ కి పనిచేయదు!
2. Relational (పోల్చి చూడటానికి)
  • == (Equal to), != (Not equal)
  • >, <, >=, <=
  • కండిషన్ నిజమైతే 1 (True), అబద్ధం అయితే 0 (False) ఇస్తుంది.
3. Logical (లాజిక్ చెక్ చేయడానికి)
  • && (Logical AND — Short-circuit!)
  • || (Logical OR — Short-circuit!)
  • ! (Logical NOT - ఉన్న వాల్యూ ని రివర్స్ చేస్తుంది)
4. Bitwise (బైనరీ బిట్స్ మార్చడానికి)
  • & (Bitwise AND), | (Bitwise OR)
  • ^ (XOR), ~ (NOT / Invert bits)
  • << (Left Shift), >> (Right Shift)
2Prefix (++x) vs Postfix (x++) & Ternary ఆపరేటర్

⚡ Prefix (++x) కి Postfix (x++) కి తేడా ఏంటి?

• Prefix (++x): వాల్యూ ని ముందే ప్లస్ వన్ (+1) చేసి, ఆ తర్వాత ఆ లైన్ లో ఉన్న మిగతా ఫార్ములాలో వాడుతుంది ("ముందు పెంచు, తర్వాత వాడు").
• Postfix (x++): ఫార్ములాలో పాత వాల్యూ నే వాడేసి, ఆ లైన్ అయిపోయాక అప్పుడు వాల్యూ ని పెంచుతుంది ("ముందు వాడు, తర్వాత పెంచు").

Ternary Operator (సింగిల్ లైన్ If-Else): condition ? (నిజమైతే) : (అబద్ధమైతే)

పెద్ద if-else కండిషన్స్ రాయకుండా ఒకే లైన్ లో ఆన్సర్ తెప్పించుకోవడానికి ఇది బెస్ట్:
int max = (a > b) ? a : b;

3Operator Precedence టేబుల్ (ఏది ఫస్ట్ రన్ అవ్వాలి?) ⭐

ఒక పెద్ద ఫార్ములాలో ప్లస్, మైనస్, ఇంటూ అన్నీ కలిసి ఉంటే ఏ ఆపరేటర్ ఫస్ట్ రన్ అవ్వాలి అనేది Precedence (ప్రాధాన్యత) డిసైడ్ చేస్తుంది:

ర్యాంక్ (ప్రాధాన్యత)ఆపరేటర్లువివరణఎటు వైపు నుండి రన్ అవుతుంది?
1 (Highest - ఫస్ట్ రన్ అవుతాయి)(), [], ->, .బ్రాకెట్స్ మరియు అర్రేLeft to Right (ఎడమ నుండి కుడికి)
2++, --, !, ~, +, -, (type), *, &, sizeofఒకే వేరియబుల్ మీద పనిచేసేవిRight to Left
3*, /, %ఇంటూ, బై, మోడ్యులస్ (శేషం)Left to Right
4+, -ప్లస్, మైనస్Left to Right
5<<, >>Bitwise Left and Right ShiftsLeft to Right
6<, <=, >, >=పోల్చి చూసేవి (లెస్ దాన్, గ్రేటర్ దాన్)Left to Right
7==, !=సమానమా కాదా?Left to Right
8&Bitwise ANDLeft to Right
9^Bitwise XORLeft to Right
10|Bitwise ORLeft to Right
11&&లాజికల్ ANDLeft to Right
12||లాజికల్ ORLeft to Right
13?:టెర్నరీ కండిషన్Right to Left
14 (Lowest)=, +=, -=, *=, /=, %=అసైన్ చేయడం (లాస్ట్ లో రన్ అవుతాయి)Right to Left
46 ప్రాక్టికల్ ప్రోగ్రామ్స్ (ఫార్ములాస్ తో పాటు)

ఇప్పటివరకు నేర్చుకున్న ఆపరేటర్లని వాడి రియల్ టైం లో పనిచేసే 6 ప్రోగ్రామ్స్ చూద్దాం:

📌 ఈ ప్రోగ్రామ్స్ లో వాడిన ఫార్ములాస్:

1. రెండు నంబర్స్ కలపడం: $Sum = a + b$
2. వడ్డీ (Simple Interest): $SI = rac{P imes T imes R}{100}$
3. దీర్ఘచతురస్రం ఏరియా: $Area = L imes W$, చుట్టుకొలత = 2(L + W)
4. టెంపరేచర్ మార్చడం: $F = (C imes rac{9.0}{5.0}) + 32.0$
5. స్టూడెంట్ ఆవరేజ్ మార్క్స్: $Avg = rac{M_1 + M_2 + M_3}{3.0}$
6. GST తో సూపర్ మార్కెట్ బిల్లు: $Final = Subtotal + (Subtotal imes rac{GST%}{100})$

C — All 6 Practice Programs in One Comprehensive Suite ▶ Run Programs 
#include <stdio.h>

int main(void) {
    // 1. Add Two Numbers
    int num1 = 45, num2 = 30;
    printf("1. Sum of %d + %d = %d\n", num1, num2, num1 + num2);

    // 2. Simple Interest: P = 10000, T = 2 years, R = 7.5%
    double P = 10000.0, T = 2.0, R = 7.5;
    double SI = (P * T * R) / 100.0;
    printf("2. Simple Interest on Rs.%.0f: Rs.%.2f\n", P, SI);

    // 3. Rectangle Area & Perimeter (L = 12.5, W = 6.0)
    double length = 12.5, width = 6.0;
    double area = length * width;
    double perimeter = 2.0 * (length + width);
    printf("3. Rectangle Area = %.2f sq.units | Perimeter = %.2f units\n", area, perimeter);

    // 4. Celsius to Fahrenheit (37°C normal body temp)
    double celsius = 37.0;
    double fahrenheit = (celsius * 9.0 / 5.0) + 32.0;
    printf("4. 37°C in Fahrenheit = %.1f°F\n", fahrenheit);

    // 5. Student Average Marks (85, 92, 78)
    int m1 = 85, m2 = 92, m3 = 78;
    double average = (m1 + m2 + m3) / 3.0; // Using 3.0 avoids integer division!
    printf("5. Student Average: %.2f%%\n", average);

    // 6. Supermarket Bill Calculator with 18% GST
    double itemPrice = 1250.0;
    int quantity = 3;
    double subtotal = itemPrice * quantity;
    double finalBill = subtotal + (subtotal * 0.18);
    printf("6. Bill: Subtotal = Rs.%.2f | With 18%% GST = Rs.%.2f\n", subtotal, finalBill);

    return 0;
}
