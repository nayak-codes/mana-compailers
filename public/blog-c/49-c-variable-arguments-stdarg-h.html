Variable Arguments (stdarg.h) (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 49 📂 Phase 17: Advanced Concepts 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Variadic Functions · stdarg.h · va_list · va_start & va_arg · printf internals

మామూలుగా మనం ఒక C ఫంక్షన్ రాస్తే int add(int a, int b) అని దానికి రెండే ఆర్గ్యుమెంట్స్ ఇస్తాం. మీరు మూడోది ఇస్తే కంపైలర్ ఒప్పుకోదు. కానీ ఎప్పుడైనా ఆలోచించారా? printf("%d %d %d", a, b, c) లో మీరు ఎన్ని వేరియబుల్స్ ఇచ్చినా అది తీసుకుంటుంది. అది ఎలా సాధ్యం? దానికి కారణం Variadic Functions (వేరియబుల్ ఆర్గ్యుమెంట్స్). మనకు ముందుగానే యూజర్ ఎన్ని నంబర్స్ పంపుతాడో తెలియనప్పుడు (అన్-లిమిటెడ్), మన స్వంత ఫంక్షన్ కి కూడా ఈ సూపర్ పవర్ ని ఎలా ఇవ్వాలో ఈరోజు stdarg.h హెడ్డర్ ఫైల్ ద్వారా నేర్చుకుందాం.

1 3 డాట్స్ (Ellipsis ...) మ్యాజిక్

మీరు ఫంక్షన్ రాసేటప్పుడు లాస్ట్ లో మూడు డాట్స్ (...) పెడితే, కంపైలర్ కి "బాబు, ఇక్కడ నుండి ఎన్ని వాల్యూస్ వచ్చినా సరే ఒక సంచి (Bag) లో వేసుకో" అని చెప్పినట్లు లెక్క!

🛍️ రియల్ లైఫ్ స్టోరీ: కౌంటర్ దగ్గర సంచి (The Magic Bag)

మీరు ఒక బట్టల షాప్ కి వెళ్లారు. మీరు ఎన్ని షర్ట్స్ కొంటారో క్యాషియర్ కి ముందే తెలీదు. కానీ అతను ఒక ఖాళీ సంచి (దీన్నే va_list అంటారు) పట్టుకుని ఉంటాడు.

ముందుగా మీరు "నేను 4 షర్ట్స్ కొంటున్నా" అని చెప్తారు (ఇదే మొదటి ఫిక్సెడ్ ఆర్గ్యుమెంట్). దాన్ని బట్టి అతను సంచి ఓపెన్ చేస్తాడు (va_start). ఆ తర్వాత ఒక్కో షర్ట్ ని సంచిలో నుండి తీసుకుని బిల్ వేస్తాడు (va_arg). మొత్తం 4 అయిపోగానే సంచిని క్లోజ్ చేస్తాడు (va_end). ప్రోగ్రామింగ్ లో కూడా వేరియబుల్ ఆర్గ్యుమెంట్స్ అచ్చం ఇలాగే పనిచేస్తాయి!

2 తప్పనిసరిగా వాడాల్సిన ఫంక్షన్స్

ఈ మ్యాజిక్ చేయాలంటే మనకి నాలుగు స్పెషల్ మాక్రోస్ కావాలి:

  • va_list: సంచి తయారు చేయడం (ఆర్గ్యుమెంట్స్ దాచుకోవడానికి ఒక పాయింటర్).
  • va_start: సంచి ఓపెన్ చేయడం (దీనికి ఆర్గ్యుమెంట్స్ ఎక్కడ నుండి స్టార్ట్ అవుతున్నాయో చెప్పాలి).
  • va_arg: సంచిలో నుండి ఒక్కో ఐటమ్ ని బయటికి తీయడం (దాని టైప్ int ఆ, float ఆ చెప్పాలి).
  • va_end: పని అయ్యాక సంచిని క్లీన్ చేసి మూసేయడం (మెమరీ సేఫ్టీ).
3 ఒకే ఒక సింపుల్ కోడ్ (Unlimited Add Function)

కింద కోడ్ లో మనం ఒక sum అనే ఫంక్షన్ రాసి, దానికి ఒకసారి 3 నంబర్స్, ఇంకోసారి 5 నంబర్స్ పంపి రిజల్ట్ ఎలా తెప్పించామో చూడండి.

C — Variadic Functions (stdarg.h) ▶ Run Code 
#include <stdio.h>
#include <stdarg.h> // వేరియబుల్ ఆర్గ్యుమెంట్స్ కి ఇది అవసరం

// ఫస్ట్ ఆర్గ్యుమెంట్ ఎప్పుడూ ఫిక్స్డ్ ఉండాలి (ఎన్ని వస్తున్నాయో చెప్పడానికి)
// ఆ తర్వాత ఎన్ని కావాలంటే అన్ని ఇవ్వొచ్చు (...)
int calculateSum(int count, ...) {
    int total = 0;
    
    // 1. సంచి (లిస్ట్) ని క్రియేట్ చేస్తున్నాం
    va_list args;
    
    // 2. సంచి ఓపెన్ చేద్దాం. 'count' తర్వాత నుండే ఐటమ్స్ ఉన్నాయి అని చెప్తున్నాం
    va_start(args, count);
    
    // 3. ఒక్కొక్కటిగా బయటికి తీద్దాం
    for (int i = 0; i < count; i++) {
        // va_arg వాడి నెక్స్ట్ ఐటమ్ ని int లాగా బయటికి లాగుతున్నాం
        int currentNum = va_arg(args, int);
        total += currentNum;
    }
    
    // 4. సంచిని క్లోజ్ చేద్దాం
    va_end(args);
    
    return total;
}

int main() {
    printf("--- Variadic Functions Demo ---\n\n");
    
    // ఫస్ట్ నంబర్ 3 (అంటే తర్వాత 3 నంబర్స్ వస్తున్నాయి అని అర్థం)
    int result1 = calculateSum(3, 10, 20, 30);
    printf("Sum of 3 numbers (10,20,30) : %d\n", result1);
    
    // ఫస్ట్ నంబర్ 5 (అంటే తర్వాత 5 నంబర్స్ వస్తున్నాయి)
    int result2 = calculateSum(5, 1, 2, 3, 4, 5);
    printf("Sum of 5 numbers (1..5)     : %d\n", result2);
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • int calculateSum(int count, ...): మీరు కనీసం ఒక ఫిక్సెడ్ ఆర్గ్యుమెంట్ (count) ఇవ్వకపోతే, లోపల ఉన్న డాట్స్ (...) ఎక్కడ స్టార్ట్ అవుతున్నాయో కంపైలర్ కి అసలు తెలీదు. కనీసం ఒక్కటి అయినా ఉండాల్సిందే.
  • va_arg(args, int): ఇక్కడ మ్యాజిక్ ఏంటంటే, సంచిలో చేయి పెట్టి బయటికి తీసిన ప్రతీసారి, పాయింటర్ ఆటోమేటిక్ గా నెక్స్ట్ నంబర్ కి వెళ్ళిపోతుంది. మీరు ptr++ చేయక్కర్లేదు. దానికి ఏ టైప్ కావాలో పక్కన int, double అని చెప్తే చాలు.
  • va_end(args): ఇది రాయకపోయినా కొన్నిసార్లు ప్రోగ్రామ్ పనిచేస్తుంది, కానీ కొన్ని ప్లాట్ఫామ్స్ (ARM ప్రాసెసర్స్) లో రాకపోతే మెమరీ కరప్ట్ అయి యాప్ క్రాష్ అవుతుంది. ఇది బెస్ట్ ప్రాక్టీస్!
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: మనం పంపే కౌంట్ కన్నా (ఉదా: 3 అని చెప్పి) ఎక్కువ నంబర్స్ (5) పంపితే ఏమవుతుంది?

కంపైలర్ ఎర్రర్ ఇవ్వదు! కానీ ఫంక్షన్ లోపల లూప్ 3 సార్లు మాత్రమే తిరిగి, మొదటి 3 నంబర్స్ ని మాత్రమే యాడ్ చేసుకుని ఆగిపోతుంది. మిగతా రెండు నంబర్స్ ని పూర్తిగా ఇగ్నోర్ చేస్తుంది.

Q2: కౌంట్ ఎక్కువ చెప్పి (ఉదా: 5 అని చెప్పి) తక్కువ నంబర్స్ (3) పంపితే?

ఇది చాలా డేంజర్! లూప్ 5 సార్లు తిరుగుతుంది, సంచిలో 3 ఐటమ్స్ ఏ ఉంటాయి. నాలుగో సారి ఖాళీ సంచిలో చేయి పెట్టినప్పుడు, మెమరీ లో పక్కన ఉన్న ఎవరిదో గార్బేజ్ వాల్యూ (Garbage Value) ని తీసుకుని యాడ్ చేస్తుంది. దీనివల్ల రాంగ్ రిజల్ట్స్ వస్తాయి.

Q3: printf కి మనం కౌంట్ పంపం కదా, మరి దానికి ఎలా తెలుస్తుంది?

సూపర్ లాజిక్! మనం పంపే టెక్స్ట్ లో ఎన్ని పర్సంటేజ్ సింబల్స్ (%d, %s) ఉన్నాయో printf లోపల ముందు కౌంట్ చేసుకుంటుంది. దాన్ని బట్టి అది అన్-లిమిటెడ్ గా ఆర్గ్యుమెంట్స్ ని తీస్తుంది. అందుకే మీరు %d లు ఎక్కువ పెట్టి, పక్కన వేరియబుల్స్ తక్కువ ఇస్తే గార్బేజ్ వాల్యూస్ వస్తాయి!
