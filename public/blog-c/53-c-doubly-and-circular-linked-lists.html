Doubly & Circular Linked Lists (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 53 📂 Phase 18: Data Structures - 1 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Doubly Linked List (prev & next) · Circular Linked List · Reverse Traversal · Real-world usage

మామూలు లింక్డ్ లిస్ట్ (Singly) లో ఒక ప్రాబ్లమ్ ఉంది. అది వన్-వే ట్రాఫిక్ లాంటిది. మీరు ముందుకి వెళ్ళగలరే తప్ప వెనక్కి రాలేరు. మీరు క్రోమ్ బ్రౌజర్ లో హిస్టరీ చూస్తుంటే Back మరియు Forward రెండు బటన్స్ నొక్కుతారు కదా! ఆ ఫీచర్ కావాలంటే ఒక నోడ్ కి ముందు నోడ్ ఎవరో, వెనక నోడ్ ఎవరో రెండు అడ్రస్ లు తెలియాలి. దాన్నే Doubly Linked List (డబుల్ లింక్డ్ లిస్ట్) అంటారు. అలాగే లాస్ట్ నోడ్ కి నల్ (NULL) ఇవ్వకుండా దాన్ని తీసుకొచ్చి మళ్ళీ ఫస్ట్ నోడ్ (Head) కి తగిలిస్తే అదొక చక్రం లాగా తిరుగుతుంది, దాన్నే Circular List (సర్క్యులర్ లిస్ట్) అంటారు. ఇవెలా పనిచేస్తాయో డీప్ గా పోస్ట్‌మార్టం చేద్దాం.

1 Doubly Linked List అంటే ఏంటి?

సింగిల్ లిస్ట్ లో ప్రతి డబ్బా కి ఒకటే చైన్ (next) ఉంటుంది. డబుల్ లిస్ట్ లో ప్రతి డబ్బా కి రెండు చైన్స్ (prev మరియు next) ఉంటాయి.

[ NULL | Data: 10 | Next ] <====> [ Prev | Data: 20 | Next ] <====> [ Prev | Data: 30 | NULL ]

దీనివల్ల మనం హెడ్ (Head) నుండి చివరి దాకా వెళ్ళచ్చు, మళ్ళీ లాస్ట్ (Tail) పట్టుకుని మొదటి వరకు వెనక్కి (Reverse) రావచ్చు. మ్యూజిక్ ప్లేయర్ లో "Next Song", "Previous Song" బటన్స్ అన్నీ బ్యాక్ గ్రౌండ్ లో ఈ డబుల్ లిస్ట్ మీదే పనిచేస్తాయి.

2 Circular Linked List (చక్రం)

సర్క్యులర్ లిస్ట్ లో NULL అనే కాన్సెప్టే ఉండదు! లాస్ట్ డబ్బా యొక్క next పాయింటర్ ని తీసుకొచ్చి మొదటి డబ్బాకి (Head) కనెక్ట్ చేస్తారు.

🔁 రియల్ లైఫ్ స్టోరీ: విండోస్ లో ఆల్ట్+ట్యాబ్ (Alt+Tab)

మీరు కంప్యూటర్ లో 5 యాప్స్ ఓపెన్ చేసారు. ఆల్ట్ పట్టుకుని ట్యాబ్ నొక్కుతూ ఉంటే ఒకదాని తర్వాత ఒకటి హైలైట్ అవుతూ, లాస్ట్ యాప్ దాటాక మళ్ళీ ఫస్ట్ యాప్ కి వస్తుంది కదా! అదొక సర్క్యులర్ లిస్ట్!

ఆపరేటింగ్ సిస్టమ్ (OS) లో ఒక ప్రాసెసర్ వంద యాప్స్ కి టైమ్ ఇస్తున్నప్పుడు (Round Robin Scheduling), లాస్ట్ యాప్ కి టైమ్ ఇచ్చాక మళ్ళీ లూప్ తిరిగి ఫస్ట్ యాప్ కి రావాలి. ఆ ప్రాసెస్ మొత్తాన్ని హ్యాండిల్ చేసేది ఈ సర్క్యులర్ లింక్డ్ లిస్టే.

3 ఒకే ఒక సింపుల్ కోడ్ (Doubly Linked List)

కింద కోడ్ లో డబుల్ పాయింటర్స్ (prev, next) వాడి ఒక లిస్ట్ ని ఎలా తయారు చేసామో, దాన్ని ముందుకి మరియు వెనక్కి ఎలా ప్రింట్ (Forward & Reverse) చేసామో క్రియేటివ్ గా చూడండి.

C — Doubly Linked List ▶ Run Code 
#include <stdio.h>
#include <stdlib.h>

// 1. డబుల్ లిస్ట్ కోసం నోడ్ బ్లూప్రింట్ (రెండు పాయింటర్స్ ఉంటాయి)
struct Node {
    int data;
    struct Node* prev; // వెనక డబ్బా అడ్రస్
    struct Node* next; // ముందు డబ్బా అడ్రస్
};

// కొత్త బాక్స్ క్రియేట్ చేసి చివర్లో యాడ్ చేయడానికి ఫంక్షన్
void append(struct Node** head_ref, int new_data) {
    // కొత్త బాక్స్ కి మెమరీ ఇద్దాం
    struct Node* new_node = (struct Node*)malloc(sizeof(struct Node));
    new_node->data = new_data;
    new_node->next = NULL; // ఇది లాస్ట్ కాబట్టి next నల్ అవుతుంది
    
    struct Node* last = *head_ref;
    
    // ఒకవేళ లిస్ట్ ఖాళీగా ఉంటే, ఇదే ఫస్ట్ (Head) అవుతుంది
    if (*head_ref == NULL) {
        new_node->prev = NULL; // ఫస్ట్ కాబట్టి prev కూడా నల్
        *head_ref = new_node;
        return;
    }
    
    // ఖాళీ లేకపోతే, లాస్ట్ డబ్బా దాకా వెతుక్కుంటూ వెళ్దాం
    while (last->next != NULL) {
        last = last->next;
    }
    
    // లాస్ట్ డబ్బా దొరికింది! దానికి ఈ కొత్త బాక్స్ ని కనెక్ట్ చేద్దాం
    last->next = new_node;
    new_node->prev = last; // కొత్త బాక్స్ కి వెనకాల ఈ పాత డబ్బా ఉంటుందని చెప్పాలి!
}

// లిస్ట్ ని ముందుకి, వెనక్కి ప్రింట్ చేసే ఫంక్షన్
void printList(struct Node* node) {
    struct Node* last;
    
    printf("Forward Traversal (Head to Tail):\n");
    while (node != NULL) {
        printf("%d -> ", node->data);
        last = node; // వెనక్కి రావడానికి లాస్ట్ డబ్బా ని పట్టుకుంటున్నాం
        node = node->next;
    }
    printf("NULL\n\n");
    
    printf("Reverse Traversal (Tail to Head):\n");
    while (last != NULL) {
        printf("%d -> ", last->data);
        last = last->prev; // చైన్ పట్టుకుని వెనక్కి (prev) నడుస్తున్నాం!
    }
    printf("NULL\n");
}

int main() {
    struct Node* head = NULL;
    
    printf("--- Doubly Linked List Demo ---\n\n");
    
    // కొన్ని నోడ్స్ ని యాడ్ చేద్దాం
    append(&head, 10);
    append(&head, 20);
    append(&head, 30);
    append(&head, 40);
    
    // ముందుకి వెనక్కి ప్రింట్ చేద్దాం
    printList(head);
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • struct Node* prev;: ఇదే మనకి వెనక్కి వెళ్లడానికి ఉపయోగపడే టైమ్ మెషిన్. మనం కొత్త డబ్బా క్రియేట్ చేసిన ప్రతిసారీ, new_node->prev = last; అని కనెక్ట్ చేస్తేనే ఆ లింక్ అతుక్కుంటుంది.
  • last = node;: ఫార్వర్డ్ లూప్ లో మనం లాస్ట్ కి వెళ్ళిపోతే node నల్ (NULL) అయిపోతుంది. కానీ రివర్స్ రావాలంటే లాస్ట్ డబ్బా అడ్రస్ కావాలి కదా! అందుకే లూప్ లోపలే last అనే పాయింటర్ లో దాన్ని సేవ్ చేసుకుంటూ వెళ్ళాం.
  • last = last->prev;: రివర్స్ లూప్ లో next కాకుండా prev వాడాం. అంటే 40 నుండి 30, 30 నుండి 20 కి రివర్స్ గేర్ లో వస్తుంది!
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: Doubly Linked List లో మెమరీ వేస్ట్ అవుతుందా?

అవును! సింగిల్ లిస్ట్ తో పోలిస్తే ఇందులో ప్రతి డబ్బాలో ఎక్స్ట్రా ఒక పాయింటర్ (prev) ఉంటుంది. ఒక పాయింటర్ కి 8 బైట్స్ (64-bit సిస్టమ్ లో) పడుతుంది. లక్ష డబ్బాలు ఉంటే లక్ష ఎక్స్ట్రా పాయింటర్స్ కి మెమరీ పోతుంది. అందుకే వెనక్కి రావలసిన అవసరం ఉంటేనే దీన్ని వాడాలి.

Q2: డబుల్ లిస్ట్ లో ఇన్సర్ట్ (Insert) చేయడం కష్టమా?

లాజిక్ కొంచెం కష్టం! మీరు మధ్యలో కొత్త నోడ్ దూర్చాలంటే సింగిల్ లిస్ట్ లో 2 చైన్స్ అతుకుతారు. కానీ ఇందులో 4 చైన్స్ మార్చాలి! (కొత్త దాని prev, next కి కనెక్ట్ చేయాలి, అలాగే అటు ఇటు ఉన్న డబ్బాల prev, next లని కూడా కొత్త దానికి మార్చాలి). ఏ ఒక్కటి మర్చిపోయినా లిస్ట్ విరిగిపోతుంది.

Q3: బ్రౌజర్ హిస్టరీ లో Doubly List ఎందుకు బెస్ట్? Array వాడొచ్చు కదా?

బ్రౌజర్ హిస్టరీ లో మీరు 10 పేజీలు ముందుకెళ్లి, 5 పేజీలు వెనక్కి (Back) వచ్చి, అక్కడ నుండి కొత్త లింక్ క్లిక్ చేస్తే... పాత ఫార్వర్డ్ హిస్టరీ మొత్తం డిలీట్ అయిపోవాలి! లింక్డ్ లిస్ట్ లో అయితే చైన్ కట్ చేస్తే ఆటోమేటిక్ గా కట్ అయిపోతుంది (O(1)). అదే అర్రే లో అయితే అన్నిటినీ వెతుక్కుంటూ డిలీట్ చేయాలి (స్లో). అందుకే డబుల్ లిస్ట్ బెస్ట్!
