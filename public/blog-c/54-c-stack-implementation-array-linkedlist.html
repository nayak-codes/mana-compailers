Stack Implementation (Array & LinkedList) (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 54 📂 Phase 18: Data Structures - 1 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: LIFO Concept · Push and Pop · Stack Overflow/Underflow · Undo Feature

డేటా స్ట్రక్చర్స్ లో అత్యంత సింపుల్ మరియు ఫేమస్ కాన్సెప్ట్ Stack (స్టాక్). దీన్ని LIFO (Last In, First Out) అంటారు. అంటే చివరగా పెట్టిందే ముందుగా బయటికి వస్తుంది. మీరు ఎప్పుడైనా ఎంఎస్ వర్డ్ (MS Word) లో ఏదైనా తప్పు టైప్ చేసి Undo (Ctrl+Z) నొక్కితే కరెక్ట్ గా లాస్ట్ చేసిన యాక్షనే వెనక్కి వెళ్తుంది కదా! అలాగే బ్రౌజర్ లో బ్యాక్ బటన్ నొక్కినా, ఫంక్షన్స్ కాల్ అయ్యి వెనక్కి రావాలన్నా ఈ స్టాక్ పద్ధతే వాడుతారు. దీన్ని C లాంగ్వేజ్ లో ఎలా డిజైన్ చేయాలో ఈరోజు ఒక ఆటలాగా నేర్చుకుందాం.

1 స్టాక్ (Stack) అంటే ఏంటి?

మీరు ఒక బుఫే (Buffet) భోజనానికి వెళ్లారు అనుకోండి. అక్కడ ఖాళీ ప్లేట్లు అన్నీ ఒకదాని మీద ఒకటి పేర్చి ఉంటాయి. ఎవరైనా ప్లేట్ కావాలంటే ఎక్కడి నుండి తీసుకుంటారు? కచ్చితంగా పైనుండే తీసుకుంటారు! అలాగే సర్వర్ కొత్త ప్లేట్ కడిగి తెస్తే ఎక్కడ పెడతాడు? పైన మాత్రమే పెడతాడు. దీన్నే LIFO అంటారు. కింద ఉన్న ప్లేట్ తీయాలంటే పైన ఉన్నవన్నీ తీశాకే కుదురుతుంది.

📚 రియల్ లైఫ్ స్టోరీ: పుస్తకాల దొంతర (Push & Pop)

స్టాక్ లో మెయిన్ గా రెండు ఆపరేషన్స్ ఉంటాయి:

1. Push (పుష్ - లోపలికి తోయడం): మీరు చదివిన బుక్ ని ఒక బాక్స్ లోపల పైనుండి పడేయడాన్ని పుష్ అంటారు. మీరు ఎన్ని వేసినా, ఎప్పుడూ 'Top' లోనే పడుతుంది.

2. Pop (పాప్ - బయటికి తీయడం): బాక్స్ లోపల పైన ఉన్న బుక్ ని బయటికి తీయడాన్ని పాప్ అంటారు. మీరు 3వ బుక్ తీయాలంటే, ముందు 1, 2 బుక్స్ ని పాప్ చేయాల్సిందే!

ఒకవేళ బాక్స్ మొత్తం ఫుల్ అయ్యి బయటికి పడిపోతే దాన్ని Stack Overflow అంటారు. అసలు బాక్స్ లో ఏమీ లేకపోయినా చేయి పెట్టి వెతికితే దాన్ని Stack Underflow అంటారు.

2 స్టాక్ ని ఎలా తయారు చేయొచ్చు?

స్టాక్ అనేది కేవలం ఒక "రూల్" మాత్రమే (LIFO రూల్). ఆ రూల్ ని మీరు Array వాడి అయినా రాయొచ్చు, లేదా Linked List వాడి అయినా రాయొచ్చు.

  • Array తో: సైజు ముందుగానే ఫిక్స్ అయిపోతుంది. కానీ చాలా ఫాస్ట్ గా పనిచేస్తుంది.
  • Linked List తో: సైజు లిమిట్ ఉండదు (డైనమిక్). ఎప్పుడు కావాలంటే అప్పుడు కొత్త బాక్స్ తయారు చేసి (Head కి) తగిలిస్తారు.
3 ఒకే ఒక సింపుల్ కోడ్ (Array Stack Demo)

కింద కోడ్ లో సింపుల్ గా ఒక 5 సైజు ఉన్న Array వాడి, Top అనే ఒక పాయింటర్ తో Push మరియు Pop ఆపరేషన్స్ ఎలా రాశామో క్లియర్ గా చూడండి.

C — Stack (Array Implementation) ▶ Run Code 
#include <stdio.h>

#define MAX 5 // బాక్స్ సైజు 5 పుస్తకాలు మాత్రమే పడుతుంది

int stack[MAX];
int top = -1; // బాక్స్ ఖాళీగా ఉందని చెప్పడానికి (Ground floor)

// 1. పుష్ ఆపరేషన్ (పైన పెట్టడం)
void push(int data) {
    if (top == MAX - 1) { // 4వ ఇండెక్స్ కి వస్తే ఫుల్ అయినట్టు!
        printf("[Error] Stack Overflow! బాక్స్ ఫుల్ అయిపోయింది.\n");
        return;
    }
    top++; // ముందు టేబుల్ హైట్ (Top) పెంచుతాం
    stack[top] = data; // ఆ హైట్ లో బుక్ పెడతాం
    printf("Pushed -> %d\n", data);
}

// 2. పాప్ ఆపరేషన్ (పైనుండి తీయడం)
void pop() {
    if (top == -1) { // అసలు బాక్స్ ఖాళీగా ఉంటే...
        printf("[Error] Stack Underflow! బాక్స్ లో ఏమీ లేవు.\n");
        return;
    }
    printf("Popped <- %d\n", stack[top]); // పైన ఉన్నది బయటికి ఇచ్చేస్తాం
    top--; // టేబుల్ హైట్ తగ్గిస్తాం
}

// 3. లాస్ట్ బుక్ ఏంటో చూడటం (తీయకుండా జస్ట్ తొంగి చూడటం)
void peek() {
    if (top == -1) {
        printf("Stack is Empty!\n");
    } else {
        printf("Top element is : %d\n", stack[top]);
    }
}

int main() {
    printf("--- Stack Operations (LIFO) ---\n\n");
    
    // బాక్స్ లో 3 బుక్స్ వేద్దాం
    push(10);
    push(20);
    push(30);
    
    printf("\n");
    peek(); // పైన ఏముందో చూద్దాం (30 ఉండాలి)
    printf("\n");
    
    // ఇప్పుడు రెండు బుక్స్ బయటికి తీద్దాం (పాప్)
    pop(); // ముందు 30 వస్తుంది
    pop(); // ఆ తర్వాత 20 వస్తుంది
    
    printf("\n");
    peek(); // ఇప్పుడు 10 మిగలాలి
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • int top = -1;: అర్రే ఇండెక్స్ 0 తో స్టార్ట్ అవుతుంది. అందుకే 0 కంటే కింద (అంటే నేల మీద) ఉన్నాం అని చెప్పడానికి -1 తీసుకున్నాం. ఖాళీ స్టాక్ కి ఇదే గుర్తు.
  • push(): పుష్ చేసిన ప్రతిసారీ ఫస్ట్ top ఇంక్రిమెంట్ అవుతుంది (0 కి వస్తుంది), ఆ 0 ఇండెక్స్ లోకి డేటా కూర్చుంటుంది. మళ్ళీ పుష్ చేస్తే 1 కి వెళ్తుంది.
  • pop(): పాప్ చేసినప్పుడు డేటా ని నిజంగా డిలీట్ చేయక్కర్లేదు! జస్ట్ top-- అని కిందకు వచ్చేస్తే చాలు. మళ్ళీ రేపు పుష్ చేసినప్పుడు ఆ పాత డేటా మీదనే కొత్త డేటా ఓవర్-రైట్ అవుతుంది. చాలా ఫాస్ట్ ట్రిక్ ఇది!
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: ప్రోగ్రామ్ రన్ అయ్యే మెమరీ "Stack" కి, ఈ డేటా స్ట్రక్చర్ "Stack" కి తేడా ఏంటి?

చాలా పెద్ద కన్ఫ్యూజన్ ఇది! మీ CPU లో ఉండే స్టాక్ మెమరీ (లోకల్ వేరియబుల్స్ కి వాడేది) కూడా సేమ్ ఈ LIFO కాన్సెప్ట్ తోనే (ఆటోమేటిక్ గా) రన్ అవుతుంది కాబట్టి దానికి ఆ పేరు వచ్చింది. కానీ మనం పైన కోడ్ తో రాసిన స్టాక్ అనేది ఒక కస్టమ్ డేటా స్ట్రక్చర్. ఇది (మనం అర్రే కి malloc వాడితే) హీప్ లో కూడా రన్ అవ్వగలదు!

Q2: Linked List తో స్టాక్ రాస్తే పుష్/పాప్ ఎక్కడ చేయాలి?

లింక్డ్ లిస్ట్ వాడినప్పుడు మీరు పుష్ ని ఎప్పుడూ మొదటి డబ్బాకి (Insert at Head) మాత్రమే చేయాలి. పాప్ కూడా అక్కడే (Delete at Head) చేయాలి. ఎందుకంటే లాస్ట్ లో చేస్తే (O(N) టైమ్ పడుతుంది). హెడ్ దగ్గర అయితే 1 సెకనులో (O(1)) అయిపోతుంది.

Q3: బ్రాకెట్స్ మ్యాచింగ్ (Balanced Parenthesis) క్వశ్చన్ ఏంటి?

ఇది ప్రాబ్లమ్ సాల్వింగ్ లో టాప్ క్వశ్చన్. ఒక కోడ్ లో { [ ( ) ] } ఇలా బ్రాకెట్స్ అన్నీ కరెక్ట్ గా క్లోజ్ అయ్యాయా లేదా అని కంపైలర్ ఎలా చెక్ చేస్తుంది? ఓపెన్ బ్రాకెట్ వస్తే స్టాక్ లోకి పుష్ చేస్తుంది, క్లోజ్ బ్రాకెట్ వస్తే పాప్ చేసి రెండూ మ్యాచ్ అయ్యాయా అని చూస్తుంది. లాస్ట్ కి స్టాక్ ఖాళీ అయితే కోడ్ కరెక్ట్ అని అర్థం!
