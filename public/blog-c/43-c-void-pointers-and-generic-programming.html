Void Pointers & Generic Programming (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 43 📂 Phase 15: Advanced Pointers 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Void Pointers · Generic Programming · Typecasting · Generic Swap Function

C లాంగ్వేజ్ లో ప్రతీ వేరియబుల్ కి ఒక క్యాస్ట్ (Type) ఉంటుంది (అది int, float, లేదా char అని). ఒకవేళ మీరు ఒక ఫంక్షన్ రాసి, అది ఏ టైప్ డేటా ఇచ్చినా సరే తీసుకోవాలి అనుకుంటే? ఉదాహరణకు printf ఫంక్షన్ కి మీరు నంబర్ ఇచ్చినా, స్ట్రింగ్ ఇచ్చినా ఎలా ప్రింట్ చేయగలుగుతోంది? దీని వెనక ఉన్న సీక్రెట్ ఆయుధమే Void Pointers (void *). అంటే ఇవి "కులమతాలు లేని పాయింటర్స్" లాంటివి! దేన్నైనా పాయింట్ చేయగలవు కానీ, వాడేటప్పుడు మాత్రం ఒరిజినల్ క్యాస్ట్ లోకి మారాలి. ఇదెలా పనిచేస్తుందో డీప్ గా చూద్దాం.

1 Void Pointer అంటే ఏంటి? (The Chameleon)

నార్మల్ గా int *ptr; అంటే అది కేవలం ఇంటీజర్ ఉన్న అడ్రస్ ని మాత్రమే పాయింట్ చేయగలదు. ఒకవేళ float అడ్రస్ ఇస్తే కంపైలర్ ఎర్రర్ ఇస్తుంది.

కానీ void *ptr; రాస్తే, అది ఏ అడ్రస్ ని అయినా తనలో స్టోర్ చేసుకోగలదు. ఇది ఒక ఊసరవెల్లి (Chameleon) లాంటిది! malloc() ఫంక్షన్ కి మీరు అందులో నంబర్స్ పెడతారో, స్ట్రింగ్స్ పెడతారో తెలీదు కాబట్టే అది ఎప్పుడూ ఒక void * ని రిటర్న్ చేస్తుంది.

🛡️ రియల్ లైఫ్ స్టోరీ: హోటల్ లో బ్లాంక్ కీ (Blank Key)

మీరు ఒక హోటల్ లో ఒక గది బుక్ చేసుకున్నారు. రిసెప్షనిస్ట్ మీకు ఒక "బ్లాంక్ కీ" (Blank Key) ఇచ్చాడు. ఆ కీ మీద ఏ రూమ్ నంబర్ అని రాసి లేదు (ఇదే void *). ఆ కీ మీ జేబులో పెట్టుకోవడం ఈజీనే, కానీ దాన్ని పట్టుకుని డైరెక్ట్ గా ఏ రూమ్ ని ఓపెన్ చేయలేరు కదా! (దాన్నే డీ-రిఫరెన్సింగ్ *ptr అంటారు).

మరి ఆ కీ వాడాలంటే ఏం చేయాలి? ఆ కీ ని తీసుకుని మేనేజర్ దగ్గరికి వెళ్లి "బాబు, దీన్ని నా 302 రూమ్ కీ లాగా మార్చు" అని అడగాలి. దాన్నే Typecasting (int *)ptr అంటారు. ఒకసారి ఆ స్టిక్కర్ వేశాక అప్పుడు మీరు రూమ్ ని ఓపెన్ చేసి వాడుకోవచ్చు.

2 జెనెరిక్ ప్రోగ్రామింగ్ (Generic Programming)

మీరు రెండు ఇంటీజర్స్ ని మార్చడానికి (Swap) ఒక ఫంక్షన్ రాసారు. రేపు పొద్దున రెండు ఫ్లోట్స్ ని మార్చాలంటే? మళ్ళీ ఇంకో ఫంక్షన్ రాయాలి. అలా 10 టైప్స్ కి 10 ఫంక్షన్స్ రాయకుండా, ఒకే ఒక ఫంక్షన్ రాసి దానికి void * పాస్ చేస్తే, అది ఏ టైప్ డేటానైనా మార్చేస్తుంది. C++ లో లాగా Templates లేకపోయినా, C లో void * వాడి అదే మ్యాజిక్ చేయొచ్చు!

3 ఒకే ఒక సింపుల్ కోడ్ (Generic Print Function)

కింద కోడ్ లో ఒకే ఫంక్షన్ కి ఒకసారి int, ఒకసారి float అడ్రస్ ని పంపి ఎలా హ్యాండిల్ చేశామో చూడండి.

C — Void Pointers ▶ Run Code 
#include <stdio.h>

// ఒకే ఫంక్షన్, కానీ ఏ టైప్ డేటా అయినా తీసుకుంటుంది (void * ద్వారా)
// టైప్ ఏంటో చెప్పడానికి typeChar అనే క్యారెక్టర్ కూడా పంపుతున్నాం
void printAnything(void *ptr, char typeChar) {
    if (typeChar == 'i') {
        // ముందు (int*) గా మార్చి, ఆ తర్వాత లాక్ ఓపెన్ (*) చేస్తున్నాం
        printf("Integer Value: %d\n", *(int*)ptr);
    } 
    else if (typeChar == 'f') {
        // (float*) గా మార్చి లాక్ ఓపెన్ (*) చేస్తున్నాం
        printf("Float Value: %.2f\n", *(float*)ptr);
    } 
    else if (typeChar == 'c') {
        // (char*) గా మార్చి లాక్ ఓపెన్ (*) చేస్తున్నాం
        printf("Character Value: %c\n", *(char*)ptr);
    }
}

int main() {
    int age = 25;
    float salary = 50000.50;
    char grade = 'A';
    
    // ఒకే void పాయింటర్ తో వేర్వేరు అడ్రస్ లని పట్టుకుందాం
    void *genericPtr;
    
    printf("--- Generic Programming in C ---\n");
    
    // 1. Integer పాయింట్ చేయడం
    genericPtr = &age;
    printAnything(genericPtr, 'i');
    
    // 2. Float పాయింట్ చేయడం
    genericPtr = &salary;
    printAnything(genericPtr, 'f');
    
    // 3. Char పాయింట్ చేయడం
    genericPtr = &grade;
    printAnything(genericPtr, 'c');
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • void *genericPtr = &age;: కంపైలర్ ఇక్కడ ఎటువంటి ఎర్రర్ ఇవ్వదు. ఎందుకంటే void పాయింటర్ కి ఏ అడ్రస్ నైనా అతుక్కునే పవర్ ఉంది.
  • *(int*)ptr: ఇది రెండు పనులు చేస్తుంది. ఫస్ట్, ఆ బ్లాంక్ కీ ని ఇంటీజర్ కీ (int*) లాగా మారుస్తుంది (Typecast). సెకండ్, ఆ కీ కి ముందు స్టార్ * పెట్టి ఆ మెమరీ లోపల ఉన్న వాల్యూ (25) ని బయటికి లాగుతుంది.
  • typeChar == 'i': మనం జెనెరిక్ గా పంపినప్పుడు, ఆ ఫంక్షన్ కి అది int అని ఎలా తెలుస్తుంది? తెలియదు! అందుకే మనం మ్యాన్యువల్ గా ఒక ఫ్లాగ్ (i, f, c) ని పంపి దానికి దారి చూపిస్తున్నాం.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: డైరెక్ట్ గా *ptr అని డీ-రిఫరెన్స్ ఎందుకు చేయకూడదు?

మీరు ఒక బాక్స్ ని ఓపెన్ చేయాలంటే అది ఎంత సైజు ఉందో కంపైలర్ కి తెలియాలి. int అయితే 4 బైట్స్ చదవాలి, char అయితే 1 బైట్ చదవాలి. కానీ void కి అసలు సైజు (Size) ఉండదు! అందుకే *ptr అని డైరెక్ట్ గా రాస్తే "incomplete type" అని కంపైలర్ క్రాష్ అవుతుంది.

Q2: Void పాయింటర్ కి ptr++ (Pointer Arithmetic) చేయొచ్చా?

స్టాండర్డ్ C (ISO C) ప్రకారం చేయకూడదు! ఎందుకంటే దానికి బైట్ సైజు తెలీదు కాబట్టి నెక్స్ట్ ఐటమ్ కి ఎంత దూరం జంప్ చేయాలో కంపైలర్ కి అర్థం కాదు. కానీ GCC కంపైలర్ (Linux లో వాడేది) దాన్ని 1-బైట్ జంప్ లాగా ట్రీట్ చేసి అలోవ్ చేస్తుంది. అయినా ఇది వాడకపోవడమే బెస్ట్ ప్రాక్టీస్.

Q3: NULL పాయింటర్ కి, void పాయింటర్ కి తేడా ఏంటి?

NULL అంటే ఆ పాయింటర్ లో ఏ అడ్రస్ లేదు (అంటే అది గాలిలో ఉంది, ఒక వేల్యూ లాంటిది). కానీ void * అనేది ఒక పాయింటర్ కి కులం (Type) లేదు అని చెప్తుంది. ఒక void *ptr = NULL; అని రాస్తే, కులం లేని పాయింటర్ లో అడ్రస్ కూడా లేదు అని అర్థం.
