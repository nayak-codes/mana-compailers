Bitwise AND, OR, XOR, NOT (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 44 📂 Phase 16: Bitwise & Low-Level 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Binary Number System · Bitwise AND (&) · OR (|) · XOR (^) · NOT (~) · Hardware Control

ఇంతవరకు మనం రాసిన మ్యాథ్స్ (+, -) అంతా డెసిమల్ (మనుషులు వాడే 10, 20) నంబర్స్ మీదే జరిగింది. కానీ కంప్యూటర్ లోపల సిపియు కి తెలిసింది కేవలం కరెంట్ ఆన్ (1) లేదా కరెంట్ ఆఫ్ (0) మాత్రమే! మీరు హార్డ్వేర్ చిప్స్ ప్రోగ్రామింగ్ చేయాలన్నా (Embedded C), లేదా మైక్రోకంట్రోలర్ లో ఒక సెన్సార్ ని ఆన్ చేయాలన్నా Bitwise Operators వాడాల్సిందే! ఇవి డైరెక్ట్ గా RAM లో ఉన్న బిట్స్ (0s & 1s) లోపలికి చొచ్చుకుని వెళ్లి ఆపరేషన్స్ చేస్తాయి. ఇవి ఎలా పనిచేస్తాయో ఈరోజు క్రిస్టల్ క్లియర్ గా తెలుసుకుందాం.

1 బిట్స్ (Bits) అంటే ఏంటి? (The Matrix)

ఒక నంబర్ 5 ని మీరు కంప్యూటర్ కి ఇస్తే, అది బైనరీ లోకి 0101 గా మారుతుంది. 3 ని ఇస్తే 0011 గా మారుతుంది. బిట్ వైజ్ ఆపరేటర్స్ డైరెక్ట్ గా ఆ బైనరీ డిజిట్స్ ని (వరుసగా నిలబెట్టి) క్యాలిక్యులేట్ చేస్తాయి.

🔌 రియల్ లైఫ్ స్టోరీ: స్విచ్ బోర్డ్ & బల్బ్స్ (The Logic Gates)

ఒక రూమ్ లో రెండు స్విచ్ లు ఉన్నాయి. ఆ రెండూ ఒకే బల్బ్ కి కనెక్ట్ అయ్యి ఉన్నాయి అనుకోండి.

AND (&) - స్ట్రిక్ట్ మేనేజర్: రెండు స్విచ్ లు (1 మరియు 1) ఆన్ లో ఉంటేనే బల్బ్ వెలుగుతుంది. ఏ ఒక్కటి ఆఫ్ (0) అయినా బల్బ్ వెలగదు. (ఉదాహరణ: యూజర్ నేమ్ అండ్ పాస్వర్డ్ రెండు కరెక్ట్ అయితేనే లాగిన్).

OR (|) - ఫ్రెండ్లీ మేనేజర్: ఏ ఒక్క స్విచ్ ఆన్ (1) అయినా చాలు బల్బ్ వెలుగుతుంది. రెండూ ఆఫ్ అయితేనే వెలగదు.

XOR (^) - ఆడ్ మ్యాన్ అవుట్: రెండు స్విచ్ లు వేర్వేరుగా (ఒకటి ఆన్, ఇంకోటి ఆఫ్) ఉంటేనే బల్బ్ వెలుగుతుంది. రెండు ఆన్ ఉన్నా ఆఫ్ అయిపోతుంది! ఇది ఎన్క్రిప్షన్ (పాస్వర్డ్స్ హైడ్ చేయడం) లో ఎక్కువగా వాడతారు.

2 మ్యాథ్స్ వర్సెస్ బిట్ వైజ్ (The Magic)
ఉదాహరణకు 5 & 3 (AND) చేద్దాం: 5 బైనరీ లో -> 0 1 0 1 3 బైనరీ లో -> 0 0 1 1 ----------------------- AND (&) రిజల్ట్-> 0 0 0 1 (రెండూ 1 ఉంటేనే 1 వస్తుంది) అంటే 5 & 3 రిజల్ట్ = 1 అన్నమాట!

NOT (~) ఆపరేటర్: ఇది సింగిల్ స్విచ్ ని ఫ్లిప్ చేస్తుంది. అంటే 1 ఉంటే 0 చేస్తుంది, 0 ఉంటే 1 చేస్తుంది (Invert).

3 ఒకే ఒక సింపుల్ కోడ్ (Bitwise in Action)

కింద కోడ్ లో 5 మరియు 3 కి AND, OR, XOR లు అప్లై చేసినప్పుడు ఫైనల్ అవుట్పుట్ ఏమొస్తుందో కంపైలర్ ద్వారా లైవ్ గా చూద్దాం.

C — Bitwise Operators ▶ Run Code 
#include <stdio.h>

int main() {
    int a = 5;  // బైనరీ: 0000 0101
    int b = 3;  // బైనరీ: 0000 0011
    
    printf("--- Bitwise Operations ---\n");
    printf("a = %d (0101), b = %d (0011)\n\n", a, b);
    
    // 1. Bitwise AND (&)
    int and_result = a & b; 
    printf("a & b (AND) = %d  -> [0001]\n", and_result); // 1
    
    // 2. Bitwise OR (|)
    int or_result = a | b;
    printf("a | b (OR)  = %d  -> [0111]\n", or_result);  // 7
    
    // 3. Bitwise XOR (^)
    int xor_result = a ^ b;
    printf("a ^ b (XOR) = %d  -> [0110]\n", xor_result); // 6
    
    // 4. Bitwise NOT (~)
    // నెగటివ్ నంబర్స్ ని 2's Complement లో రిప్రజెంట్ చేస్తారు కాబట్టి -6 వస్తుంది
    int not_result = ~a;
    printf("~a    (NOT) = %d -> [1111 1010]\n", not_result); // -6
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • a | b: 0101 మరియు 0011 కి మధ్య OR. ఏ ఒక్కటి 1 ఉన్నా ఆన్సర్ 1 కాబట్టి, 0111 వస్తుంది. బైనరీ లో 0111 అంటే డెసిమల్ లో 7.
  • a ^ b: XOR ఆపరేటర్. 0101 మరియు 0011 లో సేమ్ ఉన్నవి 0 అయిపోతాయి, డిఫరెంట్ ఉన్నవి 1 అవుతాయి. కాబట్టి 0110 వస్తుంది. దాన్ని ప్రింట్ చేస్తే 6 వచ్చింది.
  • ~a: NOT ఆపరేటర్. 5 అంటే 0000 0101 (32-bit లో). దాన్ని అంతా ఫ్లిప్ చేస్తే 1111...1010 అవుతుంది. C కంపైలర్ ఫస్ట్ బిట్ 1 ఉంటే దాన్ని మైనస్ (Negative) వాల్యూ గా తీసుకుంటుంది (2's complement ప్రకారం). కాబట్టి అది -6 అవుతుంది.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: లాజికల్ && కి, బిట్ వైజ్ & కి తేడా ఏంటి?

చాలా మంది కన్ఫ్యూజ్ అవుతారు! లాజికల్ && (డబుల్) అనేది ఒక కండిషన్ (if) ట్రూ నా ఫాల్స్ నా అని మాత్రమే చెక్ చేస్తుంది. కానీ సింగిల్ & అనేది లోపల ఉన్న బైనరీ 0s అండ్ 1s లోకి దూరి ఒక కొత్త నంబర్ ని జనరేట్ చేస్తుంది. if(5 && 3) అంటే ట్రూ, కానీ 5 & 3 అంటే 1 అనే నంబర్ వస్తుంది.

Q2: ఒక నంబర్ ఈవెన్ (Even) ఆ ఆడ్ (Odd) ఆ అని మోడ్యులో (%) లేకుండా ఎలా చెప్పాలి?

దీనికి బిట్ వైజ్ అండ్ (&) సూపర్ ట్రిక్! if (num & 1) అని రాస్తే చాలు. ఏ నంబర్ కి అయినా లాస్ట్ బైనరీ బిట్ 1 ఉంటే అది ఆడ్ నంబర్, 0 ఉంటే ఈవెన్ నంబర్. మోడ్యులో (%2) వాడటం కన్నా ఇది 10 రెట్లు ఫాస్ట్ గా కంపైల్ అవుతుంది!

Q3: మూడో వేరియబుల్ లేకుండా రెండు నంబర్స్ ని మార్చడం (Swap) ఎలా?

ఇది ఇంటర్వ్యూలలో ఫేమస్ క్వశ్చన్. మీరు XOR (^) ఆపరేటర్ వాడి మ్యాజిక్ చేయొచ్చు! a = a ^ b; b = a ^ b; a = a ^ b; అని రాస్తే a లోకి b వాల్యూ, b లోకి a వాల్యూ ఆటోమేటిక్ గా స్వాప్ అయిపోతాయి (ఎక్స్ట్రా మెమరీ అవసరం లేకుండా).
