Sorting 2 (Merge Sort, Quick Sort) (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 62 📂 Phase 20: Algorithms & Final 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Divide and Conquer · Merge Sort Logic · Quick Sort & Pivot · O(N log N) Magic

లాస్ట్ లెసన్ లో నేర్చుకున్న బబుల్ సార్ట్ (Bubble Sort) వాడి మీరు ఒక లక్ష నంబర్స్ ని సార్ట్ చేయాలంటే 1000 కోట్ల రౌండ్స్ వేయాలి, సిస్టమ్ క్రాష్ అవుతుంది! రియల్ వరల్డ్ ప్రాజెక్ట్స్ (జావా లో Arrays.sort() లాంటివి) ఆ స్లో టెక్నిక్ వాడవు. వాళ్ళు వాడే సూపర్‌మెన్ టెక్నిక్ పేరే Divide and Conquer (విడగొట్టి జయించు). ఒక పెద్ద కొండని ఒకేసారి మోయకుండా, దాన్ని సగం చేసి, ఆ సగాన్ని ఇంకో సగం చేసి విడగొట్టి మళ్ళీ అతుకుతారు. ఇలా చేసే ఫేమస్ అల్గారిథమ్స్ అయిన Merge Sort (మెర్జ్ సార్ట్) మరియు Quick Sort (క్విక్ సార్ట్) ఎలా పనిచేస్తాయో, రికర్షన్ తో ఎలా మ్యాజిక్ చేస్తాయో చూద్దాం.

1 మెర్జ్ సార్ట్ (Merge Sort) - విడగొట్టి అతకడం

లాజిక్: మీ చేతిలో 8 కార్డులు ఉన్నాయి. ముందు దాన్ని కత్తితో సగానికి కట్ చేసి 4, 4 చేయండి. ఆ 4 ని మళ్ళీ 2, 2 చేయండి. లాస్ట్ కి అన్ని కార్డులు విడిపోయి 1, 1 (సింగిల్) మిగులుతాయి. సింగిల్ గా ఉన్నది ఎప్పుడూ సార్ట్ అయ్యే ఉన్నట్టు లెక్క కదా! ఇప్పుడు ఆ సింగిల్ ముక్కలని కంపేర్ చేసి (చిన్నది ముందు, పెద్దది వెనక) రెండేసి చొప్పున అతుకుతారు (Merge). లాస్ట్ కి మొత్తం సార్ట్ అయ్యి అతుక్కుంటుంది!

[38, 27, 43, 3] (Divide) [38, 27] & [43, 3] (Divide) [38] [27] [43] [3] (Base Case - సింగిల్స్ అయ్యాయి) ఇప్పుడు అతుకుదాం (Merge & Sort): [27, 38] & [3, 43] ఫైనల్ గా: [3, 27, 38, 43]
2 క్విక్ సార్ట్ (Quick Sort) - లీడర్ ని ఎన్నుకోవడం

లాజిక్: ఇందులో ముందే కట్ చేయరు! అర్రే లో లాస్ట్ లో ఉన్న ఒక నంబర్ ని బాస్ (Pivot) గా తీసుకుంటారు. వాడికి ఒక రూల్ పెడతారు: "బాస్ కన్నా చిన్నోళ్లు అంతా లెఫ్ట్ కి వెళ్ళాలి, పెద్దోళ్లు అంతా రైట్ కి వెళ్ళాలి". వాళ్ళు అటు ఇటు వెళ్ళాక, కరెక్ట్ గా ఆ మధ్యలో ఉన్న ఖాళీ ప్లేస్ లో ఈ బాస్ వెళ్లి కూర్చుంటాడు (ఈ బాస్ జీవితంలో ఇంక వాడి ప్లేస్ మారడు!). ఇప్పుడు లెఫ్ట్ గ్రూప్ కి, రైట్ గ్రూప్ కి మళ్ళీ కొత్త లీడర్స్ ని పెట్టి ఇదే ప్రాసెస్ ని రికర్షన్ చేస్తారు.

3 ఒకే ఒక సింపుల్ కోడ్ (Merge Sort in Action)

మెర్జ్ సార్ట్ అనేది ఇంటర్వ్యూస్ లో అత్యంత కచ్చితంగా అడిగే కోడ్. విడగొట్టడానికి రికర్షన్, అతకడానికి ఇంకో కొత్త అర్రే ఎలా వాడతామో చూడండి.

C — Merge Sort (Divide & Conquer) ▶ Run Code 
#include <stdio.h>

// 2. విడిపోయిన రెండు ముక్కలని (Left & Right) సార్ట్ చేస్తూ అతికే ఫంక్షన్
void merge(int arr[], int left, int mid, int right) {
    int i, j, k;
    int n1 = mid - left + 1; // లెఫ్ట్ ముక్క సైజు
    int n2 = right - mid;    // రైట్ ముక్క సైజు
    
    // టెంపరరీ అర్రేలు క్రియేట్ చేద్దాం
    int L[n1], R[n2];
    
    // ఒరిజినల్ డేటాని ఈ టెంపరరీ బాక్సుల్లోకి కాపీ చేద్దాం
    for (i = 0; i < n1; i++) L[i] = arr[left + i];
    for (j = 0; j < n2; j++) R[j] = arr[mid + 1 + j];
    
    // ఇప్పుడు ఆ రెండింటిని చూస్తూ చిన్న దాన్ని ఒరిజినల్ అర్రే లోకి వేద్దాం
    i = 0; j = 0; k = left;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) {
            arr[k] = L[i]; // ఎడమ వాడు చిన్న అయితే వాడు వెళ్తాడు
            i++;
        } else {
            arr[k] = R[j]; // కుడి వాడు చిన్న అయితే వాడు వెళ్తాడు
            j++;
        }
        k++;
    }
    
    // ఒకవేళ ఎవరైనా మిగిలిపోతే (Extra గా) వాళ్ళని కూడా లాస్ట్ లో యాడ్ చేద్దాం
    while (i < n1) { arr[k] = L[i]; i++; k++; }
    while (j < n2) { arr[k] = R[j]; j++; k++; }
}

// 1. రికర్షన్ తో సగానికి కట్ చేసే మెయిన్ ఫంక్షన్
void mergeSort(int arr[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2; // కరెక్ట్ గా సగం
        
        // సగం అయిన దాన్ని మళ్ళీ సగం చేయమని రికర్షన్ పిలుద్దాం (ఎడమ ముక్క)
        mergeSort(arr, left, mid);
        // అలాగే కుడి ముక్క
        mergeSort(arr, mid + 1, right);
        
        // లాస్ట్ కి విడిపోయిన ఆ రెండు ముక్కలని అతుకుదాం!
        merge(arr, left, mid, right);
    }
}

void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++) printf("%d ", arr[i]);
    printf("\n");
}

int main() {
    int arr[] = {38, 27, 43, 3, 9, 82, 10};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("--- Merge Sort Magic ---\n\n");
    printf("Original Array : ");
    printArray(arr, n);
    
    // సార్ట్ చేద్దాం (0 ఇండెక్స్ నుండి లాస్ట్ ఇండెక్స్ దాకా పంపుతున్నాం)
    mergeSort(arr, 0, n - 1);
    
    printf("Sorted Array   : ");
    printArray(arr, n);
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • mergeSort(arr, left, mid);: ఇది రికర్షన్! ముందు ఎడమ పక్కనే కట్ చేసుకుంటూ సింగిల్ అయ్యేదాకా కిందికి వెళ్ళిపోతుంది. ఎడమ పక్క సింగిల్ అయ్యాకే, అప్పుడు కుడి ముక్కని కట్ చేయడానికి వెళ్తుంది.
  • int L[n1], R[n2];: మెర్జ్ సార్ట్ లో ఉన్న మెయిన్ ప్రాబ్లమ్ ఇదే. అతకబెట్టేటప్పుడు మీకు కొత్త అర్రే (ఎక్స్ట్రా మెమరీ) కచ్చితంగా కావాలి. ఆ రెండు ముక్కలని ఆ ఎక్స్ట్రా బాక్సుల్లో కాపీ చేసుకునే ఆ తర్వాత వాటిని పోల్చుకుంటూ ఒరిజినల్ దాంట్లో కలుపుతాము.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: వీటికి ఎంత టైమ్ పడుతుంది? (Time Complexity)

సగానికి కట్ చేస్తుంది కాబట్టి log N, అతుకుతూ చెక్ చేస్తుంది కాబట్టి N. టోటల్ గా O(N log N) టైమ్ పడుతుంది. ఇది బబుల్ సార్ట్ (O(N²)) కన్నా 100 రెట్లు ఫాస్ట్! లక్ష డేటా ని కూడా సెకనులోపలే సార్ట్ చేసేస్తుంది.

Q2: Merge Sort కి Quick Sort కి తేడా ఏంటి? ఏది వాడాలి?

మెర్జ్ సార్ట్ లో ప్రాబ్లమ్ ఏంటంటే, సార్ట్ చేసేటప్పుడు కొత్త అర్రేలు (Extra Space: O(N)) కావాలి! కానీ క్విక్ సార్ట్ లో ఉన్న అర్రే లోనే ప్లేస్ లు మారుస్తారు కాబట్టి ఎక్స్ట్రా మెమరీ అక్కర్లేదు (Space: O(1)). అందుకే 90% లాంగ్వేజెస్ లో (C యొక్క qsort() లాగా) Quick Sort నే మెయిన్ గా వాడతారు.

Q3: Quick Sort వరస్ట్ కేస్ (Worst Case) ఎప్పుడు వస్తుంది?

క్విక్ సార్ట్ లో లాస్ట్ వాడిని బాస్ (Pivot) గా తీసుకున్నాం కదా. ఒకవేళ ఆ అర్రే ఆల్రెడీ సార్ట్ అయ్యి (1,2,3,4,5) ఉంటే, ఆ బాస్ ఎప్పుడూ లాస్ట్ లోనే ఉంటాడు, ఎవ్వరూ లెఫ్ట్ రైట్ కి వెళ్లరు. అప్పుడు అది బబుల్ సార్ట్ లాగా వరస్ట్ స్లో (O(N²)) అయిపోతుంది. దీన్ని ఆపడానికి లాస్ట్ వాడికి బదులు రాండమ్ (Random) గా ఒకడిని పట్టుకుని లీడర్ ని చేస్తారు.
