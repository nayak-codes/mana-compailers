C Loops: for, while, do-while, break, continue & Control Flow (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 8 📂 Phase 05: Loops & Iterations 📅 2026 Edition
📌 Covered in this in-depth guide: Why Loops are Needed · 3 Pillars of a Loop · for Loop Mechanics · while vs do-while · break & continue · Infinite Loops · Array & String Traversal

Phase 5 (Part 1): C Loops & Control Flow Masterclass కు స్వాగతం! ప్రోగ్రామింగ్ లో ఒకే పనిని మళ్ళీ మళ్ళీ రాయడాన్ని తప్పుగా భావిస్తారు (DRY - Don't Repeat Yourself). లూప్స్ (Loops) ని వాడితే, కంప్యూటర్ ఒకే పనిని ఏమాత్రం తప్పు లేకుండా లక్షల సార్లు చాలా ఫాస్ట్ గా చేయగలదు. ఈ గైడ్ లో, ప్రతి లూప్ కు ఉండే 3 ముఖ్యమైన పిల్లర్స్, for లూప్ ఎలా పనిచేస్తుంది, while కి do-while కి ఉన్న తేడా ఏంటి, లూప్ మధ్యలో ఆపడానికి వాడే break మరియు continue, అలాగే మన ప్రోగ్రామ్ ని హ్యాంగ్ చేసే infinite loop ప్రాబ్లం రాకుండా ఎలా చూసుకోవాలో తెలుగులో నేర్చుకుందాం.

1లూప్స్ ఎందుకు కావాలి? & ప్రతి లూప్ కి ఉండే 3 పిల్లర్స్

ఒక పనిని వెయ్యి సార్లు మ్యాన్యువల్ గా కోడ్ రాయకుండా, ఆటోమేటిక్ గా ఒకే లైన్ తో రన్ చేయడానికే లూప్స్ వాడతాము. ప్రపంచంలో ఏ ప్రోగ్రామింగ్ లాంగ్వేజ్ లో అయినా లూప్ రన్ అవ్వాలి అంటే ఈ 3 రూల్స్ (పిల్లర్స్) కచ్చితంగా ఉండాలి:

  1. 1. Initialization (స్టార్టింగ్ పాయింట్): లూప్ ఎక్కడ మొదలవ్వాలో చెప్పడం (ఉదాహరణకి int i = 1;).
  2. 2. Condition (ఎక్కడ ఆగాలో చెప్పడం): ప్రతిసారీ చెక్ చేసే కండిషన్ (ఉదాహరణకి i <= 10;). ఇది నిజం అయినంత కాలం లూప్ రన్ అవుతూనే ఉంటుంది.
  3. 3. Update (ముందుకు వెళ్లడం): స్టార్టింగ్ పాయింట్ ని కండిషన్ వైపుకి జరపడం (ఉదాహరణకి i++). ఇది రాయకపోతే లూప్ ఎప్పటికీ ఆగిపోదు (Infinite Loop వస్తుంది)!
for Loop రన్ అయ్యే 4 స్టెప్స్:
for ( [1. స్టార్టింగ్] ; [2. కండిషన్ చెక్] ; [4. అప్డేట్] ) {
[3. లోపల ఉన్న కోడ్ రన్ అవుతుంది];
}

ఎలా రన్ అవుతుంది: [1. స్టార్ట్] ──► [2. చెక్] (TRUE) ──► [3. లోపల కోడ్ రన్] ──► [4. అప్డేట్] ──► [మళ్ళీ 2. చెక్...]
2The for Loop (ఎన్ని సార్లు రన్ అవ్వాలో తెలిసినప్పుడు)

ఒక పని కచ్చితంగా ఇన్ని సార్లు జరగాలి అని మనకు ముందే తెలిసినప్పుడు for లూప్ వాడటం బెస్ట్ చాయిస్. కౌంటర్ వేరియబుల్ (i) ని డైరెక్ట్ గా ఆ లూప్ లోనే క్రియేట్ చేయొచ్చు:

C — User Curriculum Example ▶ Run in C Compiler 
#include <stdio.h>

int main(void) {
    // Prints numbers from 1 to 5
    for (int number = 1; number <= 5; number++) {
        printf("%d\n", number);
    }

    return 0;
}
3while మరియు do-while Loops మధ్య తేడా
లూప్ పేరుకండిషన్ ఎప్పుడు చెక్ చేస్తుంది?కనీసం ఎన్ని సార్లు రన్ అవుతుంది?రియల్ టైం లో ఎప్పుడు వాడతారు?
while Loop ఫస్ట్ చెకింగ్: లోపల ఉన్న కోడ్ రన్ అవ్వక ముందే కండిషన్ చెక్ చేస్తుంది. 0 సార్లు (ఫస్ట్ టైమే కండిషన్ ఫెయిల్ అయితే అస్సలు రన్ అవ్వదు). ఫైల్స్ రీడ్ చేయడానికి, ఎన్ని సార్లు రన్ అవ్వాలో తెలియనప్పుడు వాడతారు.
do-while Loop లాస్ట్ లో చెకింగ్: లోపల ఉన్న కోడ్ రన్ అయ్యాక చివర్లో కండిషన్ చెక్ చేస్తుంది. కనీసం 1 సారి (కండిషన్ ముందే అబద్ధమైనా సరే ఒకసారైతే పక్కాగా రన్ అవుతుంది!). యూజర్ కి ఒకసారైనా మెనూ చూపించాల్సిన అవసరం ఉన్నప్పుడు (ATM మెనూ లాంటివి).
C — while vs do-while Comparison ▶ Run Code 
#include <stdio.h>

int main(void) {
    int count = 10;

    // while loop: condition is false (10 < 5), so body executes 0 times!
    while (count < 5) {
        printf("This while loop will NEVER print.\n");
        count++;
    }

    // do-while loop: body executes 1 time BEFORE checking condition!
    int val = 10;
    do {
        printf("do-while executes at least once! (val = %d)\n", val);
        val++;
    } while (val < 5); // ⚠️ Note the mandatory semicolon ';' at the end!

    return 0;
}
4break vs continue (లూప్ ని కంట్రోల్ చేయడం)

⚡ break మరియు continue అంటే ఏంటి?

• break; (బ్రేక్ వేయడం): లూప్ ని అక్కడికక్కడే ఆపేసి, మొత్తానికి లూప్ లోపలి నుండి బయటికి వచ్చేస్తుంది (కావాల్సిన ఆన్సర్ దొరికాక టైం వేస్ట్ కాకుండా బయటికి రావడానికి).
• continue; (స్కిప్ చేయడం): దీని కింద ఉన్న కోడ్ ని రన్ చేయకుండా ఆపేసి, దాన్ని స్కిప్ చేసి డైరెక్ట్ గా నెక్స్ట్ రౌండ్ కి వెళ్ళిపోతుంది.

C — String & Array Traversal with Loops ▶ Run Code 
#include <stdio.h>

int main(void) {
    char message[] = "Hello C!";
    int scores[] = {85, 92, 40, 78, 95};
    int size = sizeof(scores) / sizeof(scores[0]);

    // 1. Looping through string until null-terminator '\0'
    printf("Characters in message: ");
    for (int i = 0; message[i] != '\0'; i++) {
        printf("[%c] ", message[i]);
    }
    printf("\n");

    // 2. Looping through array with continue (skip failing grades < 50)
    printf("Passing Scores: ");
    for (int i = 0; i < size; i++) {
        if (scores[i] < 50) {
            continue; // Skip failing score
        }
        printf("%d ", scores[i]);
    }
    printf("\n");

    return 0;
}
