C Basics: History, Features, Compiler Architecture & First Program

⚡ C (C17 / C23 Standard) 🟢 Lesson 1 📂 Phase 01: C Basics & Architecture 📅 2026 Edition
📌 Covered in this in-depth guide: C ante enti? · History & Uses · Features · C vs C++ · Program Structure · Compiler & 4-Stage Pipeline · First Program Breakdown · Comments, Semicolons & Braces · 3 Error Types

Phase 1: C Language Basics & Program Architecture Masterclass కు స్వాగతం! 1972 లో Bell Laboratories లో Dennis Ritchie ద్వారా డెవలప్ చేయబడిన C లాంగ్వేజ్ ని "మదర్ ఆఫ్ ఆల్ మోడ్రన్ ప్రోగ్రామింగ్ లాంగ్వేజెస్" అంటారు. ఇది C++, Java, C#, JavaScript, PHP, Python మరియు Rust వంటి లాంగ్వేజెస్ కి దారి చూపింది. C లాంగ్వేజ్ స్ట్రక్చర్డ్ లాంగ్వేజ్ యొక్క హై-లెవెల్ రీడబిలిటీ మరియు అసెంబ్లీ లాంగ్వేజ్ యొక్క హార్డ్‌వేర్ కంట్రోల్ ని కలిపి ఇస్తుంది. ఈ గైడ్ లో C అంటే ఏంటి, కోడ్ ని కంపైలర్ ఎలా ఎక్జిక్యూట్ చేస్తుంది, 4-స్టేజ్ కంపైలర్ పైప్‌లైన్ మరియు మొదటి C ప్రోగ్రామ్ యొక్క డీటెయిల్డ్ బ్రేక్ డౌన్ చూద్దాం.

1C లాంగ్వేజ్ అంటే ఏంటి? హిస్టరీ & ఉపయోగాలు

C Language అనేది ఒక పవర్ఫుల్, జనరల్ పర్పస్, procedural (structured) ప్రోగ్రామింగ్ లాంగ్వేజ్. C లాంగ్వేజ్ కంప్యూటర్ హార్డ్వేర్ (CPU registers, RAM addresses) తో డైరెక్ట్ గా ఇంటరాక్ట్ అవ్వగలిగే కేపబిలిటీస్ ని ఇస్తుంది. దీని వల్ల సాఫ్ట్‌వేర్ ప్రపంచంలో C లాంగ్వేజ్ కి ఎవరూ మ్యాచ్ చేయలేని స్పీడ్ మరియు రిసోర్స్ ఎఫిషియెన్సీ ఉంటుంది.

📜 C హిస్టరీ — Dennis Ritchie & Unix Revolution

1972 లో USA లోని Bell Laboratories లో Dennis Ritchie అనే లెజెండరీ కంప్యూటర్ సైంటిస్ట్ Unix Operating System ని డెవలప్ చేయడానికి C లాంగ్వేజ్ ని డిజైన్ చేసారు. దీనికి ముందు ఉన్న B language (Ken Thompson డిజైన్ చేసింది) మరియు BCPL నుంచి ఇన్స్పిరేషన్ తీసుకుని, కొత్తగా టైప్ సిస్టమ్ మరియు కంపైలర్ ఆప్టిమైజేషన్స్ యాడ్ చేసి దానికి "C" గా పేరు పెట్టారు.
1973 లో Unix Kernel మొత్తం C లాంగ్వేజ్ లోకి రీరైట్ చేసారు — ఇది కంప్యూటర్ హిస్టరీ లో మొట్టమొదటి పోర్టబుల్ ఆపరేటింగ్ సిస్టమ్ గా చరిత్ర సృష్టించింది!

🌐 2026 లో C లాంగ్వేజ్ ఎక్కడ వాడుతున్నారు?

• Operating System Kernels: Linux Kernel, Windows NT Kernel, macOS Kernel (XNU), మరియు Android కోర్.
• Language Runtimes & Interpreters: CPython (అఫీషియల్ Python రన్‌టైమ్), V8 Engine (Node.js/Chrome), JVM (Java Virtual Machine కోర్), మరియు Ruby VM.
• Databases: MySQL, PostgreSQL, SQLite, మరియు Redis లాంటి కోర్ డేటాబేస్ ఇంజిన్స్ C లో రాసారు.
• Embedded Systems & IoT: Smart TVs, కార్లలో వాడే ECUs, మెడికల్ డివైజెస్, Microcontrollers, మరియు విమానాల్లో వాడే ఏవియానిక్స్.
• Game Engines & Graphics Drivers: GPU డ్రైవర్స్ (NVIDIA/AMD), Unreal Engine కోర్ మ్యాథ్ లైబ్రరీలు.

2C లాంగ్వేజ్ ఫీచర్స్ & C vs C++ తేడాలు

50 ఏళ్ళు దాటినా ఇంకా టాప్ టెక్నాలజీ సిస్టమ్స్ లో C లాంగ్వేజ్ ని ఎందుకు వాడుతున్నారో కింద ఫీచర్స్ చూస్తే అర్థమవుతుంది:

ఫీచర్ (Feature)టెక్నికల్ మీనింగ్ & అడ్వాంటేజ్
1. Procedural Paradigmప్రోగ్రామ్ అంతా ఫంక్షన్స్ (procedures) గా డివైడ్ అవుతుంది. ఎక్జిక్యూషన్ పైనుంచి కిందికి సీక్వెన్షియల్ గా జరుగుతుంది.
2. బ్లేజింగ్ ఫాస్ట్ స్పీడ్ (Execution Speed)మిగతా లాంగ్వేజెస్ లాగా Garbage Collector పాజెస్ ఉండవు, డైరెక్ట్ గా CPU కి అర్థమయ్యే మెషిన్ కోడ్ కి కంపైల్ అవుతుంది.
3. లో-లెవెల్ మెమరీ యాక్సెస్ (Pointers)హార్డ్‌వేర్ మెమరీ ని డైరెక్ట్ గా పాయింటర్స్ తో కంట్రోల్ చేయొచ్చు, malloc()/free() వాడి డైనమిక్ గా హీప్ మెమరీ ని మేనేజ్ చేయొచ్చు.
4. హైలీ పోర్టబుల్ (Highly Portable)ఒకసారి రాసిన C కోడ్ ని డిఫరెంట్ కంపైలర్స్ ద్వారా ARM, x86, RISC-V లాంటి ఏ చిప్ మీదకైనా కంపైల్ చేసి రన్ చేయొచ్చు.
5. చిన్న ఫుట్ ప్రింట్ (Minimal Runtime)క్రియేట్ అయిన C బైనరీ ఫైల్స్ చాలా చిన్నవిగా ఉంటాయి (కొన్ని కిలోబైట్స్ మాత్రమే), కాబట్టి మైక్రోకంట్రోలర్స్ కి బెస్ట్ ఛాయిస్.

⚔️ C vs C++ — ముఖ్యమైన తేడాలు

• Programming Model: C పూర్తిగా Procedural / Structured (ఫంక్షన్స్ మరియు డేటా వేరుగా ఉంటాయి). C++ అనేది Object-Oriented Programming (OOP) కాబట్టి ఇందులో Classes, Objects, Inheritance వాడుకోవచ్చు.
• Memory Management: C లో మెమరీ మేనేజ్ చేయడానికి malloc() మరియు free() వాడతారు. అదే C++ లో new మరియు delete వాడతారు.
• Complexity: C చాలా సింపుల్ లాంగ్వేజ్ (మీరు రాసిందే CPU ఎక్జిక్యూట్ చేస్తుంది). కానీ C++ లో Templates, Exception Handling లాంటి ఎన్నో ఫీచర్స్ ఉండటం వల్ల చాలా కాంప్లెక్స్ గా ఉంటుంది.

3C ప్రోగ్రామ్ స్ట్రక్చర్ & 4-స్టేజ్ కంపైలేషన్ పైప్‌లైన్

ఒక స్టాండర్డ్ C సోర్స్ ఫైల్ స్ట్రక్చర్ 5 భాగాలుగా ఉంటుంది:

  1. Preprocessor Directives: #include <stdio.h>, #define MAX 100 (కంపైలర్ రన్ అవ్వక ముందే హెడర్ ఫైల్స్ యాడ్ అవుతాయి).
  2. Function Declarations (Prototypes): యూజర్ రాసే ఫంక్షన్స్ యొక్క సిగ్నేచర్స్.
  3. Global Variable Declarations: ప్రోగ్రామ్ అంతా వాడుకునే వేరియబుల్స్.
  4. The main() Function: ప్రతి C ప్రోగ్రామ్ ఇక్కడి నుండే ఎక్జిక్యూషన్ స్టార్ట్ చేస్తుంది.
  5. User-Defined Function Definitions: పైన చెప్పిన ఫంక్షన్స్ యొక్క అసలు కోడ్ ఇక్కడ రాస్తాము.

⚙️ కంపైలర్ అంటే ఏంటి? Source Code (.c) vs Executable (.exe)

కంప్యూటర్స్ కి కేవలం Binary Machine Code (0s and 1s) మాత్రమే అర్థమవుతుంది. మనం ఇంగ్లీష్ లో రాసే కోడ్ ని Source Code (.c) అంటాము. ఈ కోడ్ ని CPU రన్ చేయగలిగే బైనరీ ఫార్మాట్ లోకి Executable (.exe on Windows / binary on Linux) మార్చే సాఫ్ట్‌వేర్ నే Compiler (ఉదా: GCC, Clang, MSVC) అంటారు.

The 4-Stage GCC Compilation Pipeline Under the Hood:

[ 1. SOURCE CODE ] hello.c (మనం రాసిన ఇంగ్లీష్ లాంటి కోడ్)
│
▼ (Preprocessor: gcc -E)
[ 2. PREPROCESSED CODE ] hello.i (హెడర్స్ యాడ్ అయ్యి, కామెంట్స్ రిమూవ్ అవుతాయి)
│
▼ (Compiler: gcc -S)
[ 3. ASSEMBLY CODE ] hello.s (అసెంబ్లీ ఇన్స్ట్రక్షన్స్: mov, add, push)
│
▼ (Assembler: gcc -c)
[ 4. OBJECT CODE ] hello.o / hello.obj (కంప్యూటర్ కి అర్థమయ్యే 0s అండ్ 1s)
│
▼ (Linker: gcc -o)
[ 5. EXECUTABLE BINARY ] hello.exe / ./a.out (రెడీ టు ఎక్జిక్యూట్ బైనరీ ఫైల్!)
4మొదటి C ప్రోగ్రామ్ & డీటెయిల్డ్ బ్రేక్ డౌన్

ఇదే మీ మొదటి బేసిక్ C ప్రోగ్రామ్:

C — First Program (Curriculum Standard) ▶ Run in C Compiler 
#include <stdio.h>

int main(void) {
    printf("Hello, World!\n");
    return 0;
}

ఇప్పుడు ఒక్కొక్క లైన్ లోపల టెక్నికల్ గా ఏం జరుగుతుందో చూద్దాం:

Syntax Componentటెక్నికల్ రోల్ & ఎక్స్ప్లనేషన్
#include <stdio.h> • # (Hash): Preprocessor Directive. కంపైలింగ్ స్టార్ట్ అవ్వక ముందే రన్ అవుతుంది.
• include: ఈ ఫైల్ లోపల ఉన్న కోడ్ ని మన ప్రోగ్రామ్ లో కాపీ పేస్ట్ చేయమని చెప్తుంది.
• <stdio.h>: Standard Input Output హెడర్ ఫైల్. ఇందులోనే printf(), scanf() లాంటి ఫంక్షన్స్ ఉంటాయి.
• Angle brackets < >: సిస్టమ్ లో ఉన్న స్టాండర్డ్ డైరెక్టరీస్ లో ఈ ఫైల్ ని వెతకమని చెప్తాయి.
int main(void) • main(): ప్రతి C ప్రోగ్రామ్ ఇక్కడి నుంచే రన్ అవ్వడం స్టార్ట్ చేస్తుంది. OS కాల్ చేసే మొదటి ఫంక్షన్ ఇదే.
• int: Return type. ప్రోగ్రామ్ సక్సెస్ ఫుల్ గా కంప్లీట్ అయ్యాక OS కి ఒక నెంబర్ (స్టేటస్ కోడ్) రిటర్న్ చేస్తుంది.
• void: ఈ ఫంక్షన్ ఎటువంటి ఆర్గ్యుమెంట్స్ ని తీసుకోదు అని C స్టాండర్డ్ ప్రకారం కచ్చితంగా చెప్తుంది.
printf(...) • Print Formatted: C Standard Library (stdio.h) లో ఉండే అవుట్పుట్ ఫంక్షన్.
• మనం డబుల్ కోట్స్ లో ఇచ్చిన టెక్స్ట్ ని స్క్రీన్ పైన (stdout) చూపిస్తుంది.
\n • Newline Escape Sequence: కర్సర్ ని నెక్స్ట్ లైన్ కి తీసుకెళ్తుంది.
• ⚡ Buffer Flushing: C లో అవుట్పుట్ లైన్-బఫర్డ్ గా ఉంటుంది. \n తగలగానే లోపల ఉన్న డేటా మొత్తం స్క్రీన్ పైన వెంటనే ఫ్లష్ అవుతుంది!
return 0; • Exit Status Code: ఆపరేటింగ్ సిస్టమ్ కి ప్రోగ్రామ్ సక్సెస్ అయిందా ఫెయిల్ అయిందా అని రిపోర్ట్ ఇస్తుంది.
• 0 అంటే EXIT_SUCCESS (ఎలాంటి ఎర్రర్ లేకుండా కంప్లీట్ అయ్యింది).
• వేరే నెంబర్ (ఉదా: 1, -1) అయితే ఏదో ప్రాబ్లం వచ్చి ప్రోగ్రామ్ క్రాష్ అయినట్టు OS కి అర్థమవుతుంది.
Semicolon ; • Statement Terminator: C లాంగ్వేజ్ లో ప్రతి లైన్ (ఇన్స్ట్రక్షన్) చివర్లో కచ్చితంగా సెమికోలన్ ; ఉండాలి. లేకపోతే Syntax Error వస్తుంది!
Braces { } • Block Delimiters: ఫంక్షన్ ఎక్కడి నుండి ఎక్కడి వరకు ఉంది అనేది ఇవి డిసైడ్ చేస్తాయి (దీన్నే Scope అంటారు).

📝 Comments in C (కామెంట్స్)

కోడ్ మనకు ఈజీగా అర్థం కావడానికి కామెంట్స్ వాడుతాం. కంపైల్ చేసేటప్పుడు కంపైలర్ ఈ కామెంట్స్ ని డిలీట్ చేసేస్తుంది కాబట్టి ఎక్జిక్యూషన్ లో ఎలాంటి తేడా ఉండదు:
• సింగిల్ లైన్ కామెంట్: // దిస్ ఈజ్ ఎ సింగిల్ లైన్ కామెంట్ (C99+ standard)
• మల్టీ లైన్ కామెంట్: /* దిస్ ఈజ్ ఎ మల్టీ లైన్ కామెంట్ */

🛑 The 3 Fundamental Error Types in C

ఎర్రర్ రకం (Error Type)ఎప్పుడు వస్తుంది?ఉదాహరణ (Example)ఎలా ఫిక్స్ చేయాలి?
1. Syntax / Compile-time Error C లాంగ్వేజ్ రూల్స్ బ్రేక్ చేసినప్పుడు. కంపైలర్ పసిగట్టి కంపైలేషన్ ఆపేస్తుంది. సెమికోలన్ (;) మర్చిపోవడం, బ్రాకెట్ క్లోజ్ చేయకపోవడం, స్పెల్లింగ్ మిస్టేక్స్ (int బదులు intr). కంపైలర్ ఇచ్చే లైన్ నంబర్ చూసి కరెక్ట్ చేయాలి.
2. Runtime Error ప్రోగ్రామ్ సక్సెస్ ఫుల్ గా కంపైల్ అయ్యాక రన్ అవుతున్నప్పుడు వస్తుంది. జీరో తో డివైడ్ చేయడం (10 / 0), సంబంధం లేని మెమరీ కి యాక్సెస్ చేయడం (Segmentation Fault). ప్రోగ్రామ్ లాజిక్ చెక్ చేయాలి, పాయింటర్స్ కరెక్ట్ గా ఉన్నాయా లేదా అని సేఫ్టీ చెక్స్ పెట్టుకోవాలి.
3. Logical Error (Bug) ప్రోగ్రామ్ బాగానే కంపైల్ అయ్యి రన్ అవుతుంది, కానీ తప్పు (Incorrect) ఆన్సర్ వస్తుంది. కలపడానికి బదులు మల్టిప్లై చేయడం total = a * b. కోడ్ ఎలా రన్ అవుతుందో పేపర్ మీద డ్రై-రన్ చేసి లేదా ప్రింట్ స్టేట్మెంట్స్ వాడి ఫిక్స్ చేయాలి.
