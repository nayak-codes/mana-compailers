C Nested Loops, Star Patterns & 9 Core Practice Algorithms

⚡ C (C17 / C23 Standard) 🟢 Lesson 9 📂 Phase 05: Loops & Iterations 📅 2026 Edition
📌 Covered in this in-depth guide: Nested Loops Architecture · Star Patterns (Triangles, Pyramids) · Number Patterns · 9 Practice Programs (Prime, Armstrong, Fibonacci, Factorial, Reverse)

Phase 5 (Part 2): C Nested Loops & Pattern Printing Masterclass కు స్వాగతం! ఒక లూప్ లోపల ఇంకో లూప్ ని రాయడాన్ని Nested Loops అంటారు. 2D మ్యాట్రిక్స్, ఇమేజ్ పిక్సెల్స్, గేమ్ బోర్డ్స్, లేదా డిజైన్స్ ని క్రియేట్ చేయడానికి ఇవి చాలా ముఖ్యం. ఈ గైడ్ లో, ఒక లూప్ లోపల ఇంకో లూప్ ఎలా తిరుగుతుంది $(i, j)$, స్టార్ డిజైన్స్ (Star Patterns) ని ఎలా ప్రింట్ చేయాలి, మరియు ఇంటర్వ్యూస్ లో ఎక్కువగా అడిగే 9 ముఖ్యమైన రియల్-వరల్డ్ ప్రోగ్రామ్స్ ని సొంతంగా ఎలా రాయాలో తెలుగులో నేర్చుకుందాం.

1Nested Loops ఎలా రన్ అవుతాయి? (2D మోడల్)

Nested loop లో, బయట ఉన్న లూప్ (Outer Loop) అడ్డు వరుసలని (Rows) కంట్రోల్ చేస్తుంది, మరియు లోపల ఉన్న లూప్ (Inner Loop) నిలువు వరుసలని (Columns) కంట్రోల్ చేస్తుంది. బయటి లూప్ ఒకసారి రన్ అయితే, లోపలి లూప్ పూర్తిగా దాని సైకిల్ అంతా రన్ అవుతుంది:

2D Matrix Coordinates (Outer Loop i = Rows, Inner Loop j = Columns):
Row 0: (0,0) (0,1) (0,2) (0,3)
Row 1: (1,0) (1,1) (1,2) (1,3)
Row 2: (2,0) (2,1) (2,2) (2,3)

Time Complexity: O(Rows * Cols)
2Star మరియు Number Patterns ని ప్రింట్ చేయడం

⭐ పాటర్న్స్ ని ప్రింట్ చేయడానికి లాజిక్:

1. బయటి లూప్ i: మొత్తం ఎన్ని అడ్డు వరుసలు (Rows) ఉన్నాయో ట్రాక్ చేస్తుంది.
2. లోపలి లూప్ j: ఆ లైన్ లో ఎన్ని స్టార్స్ లేదా నంబర్స్ ప్రింట్ అవ్వాలో డిసైడ్ చేస్తుంది.
3. printf("\n"): లోపలి లూప్ ఆగిపోగానే (ఆ లైన్ అయిపోగానే) నెక్స్ట్ లైన్ కి రావడానికి ఇది వాడతాం.

C — Star Triangle, Inverted Triangle & Number Pattern ▶ Run Code 
#include <stdio.h>

void printPatterns(int n) {
    // 1. Right-Angled Star Triangle
    printf("1. Right-Angled Star Triangle:\n");
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            printf("* ");
        }
        printf("\n");
    }

    // 2. Inverted Star Triangle
    printf("\n2. Inverted Star Triangle:\n");
    for (int i = n; i >= 1; i--) {
        for (int j = 1; j <= i; j++) {
            printf("* ");
        }
        printf("\n");
    }

    // 3. Number Half-Pyramid
    printf("\n3. Number Triangle:\n");
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            printf("%d ", j);
        }
        printf("\n");
    }
}

int main(void) {
    printPatterns(4);
    return 0;
}
39 ముఖ్యమైన ప్రాక్టికల్ ప్రోగ్రామ్స్ (ఫార్ములాస్ తో పాటు)

ప్రతి ప్రోగ్రామర్ కచ్చితంగా నేర్చుకోవాల్సిన 9 ముఖ్యమైన ప్రోగ్రామ్స్ అల్గారిథమ్స్ ఇక్కడ ఇచ్చాం:

📌 ఈ ప్రోగ్రామ్స్ లో వాడే లాజిక్ ఫార్ములాస్:

• N నంబర్స్ మొత్తం: $Sum = sum i$
• ఫ్యాక్టోరియల్ (Factorial): $N! = 1 imes 2 imes dots imes N$ (సున్నా ఫ్యాక్టోరియల్ అంటే 1)
• నంబర్ రివర్స్ (Reverse Number): $rev = rev imes 10 + (n pmod{10})$; $n /= 10$
• ప్రైమ్ నంబర్ (Prime Number): కేవలం 1 తో మరియు అదే నంబర్ తో భాగించబడేది.
• ఆర్మ్‌స్ట్రాంగ్ నంబర్ (Armstrong): $153 = 1^3 + 5^3 + 3^3 = 153$
• ఫిబోనాచీ సిరీస్ (Fibonacci): పక్కపక్కన ఉన్న రెండు నంబర్స్ ని కలిపితే వచ్చేది (0, 1, 1, 2, 3, 5, 8...)

C — The 9 Classical Algorithmic Suite ▶ Run Suite 
#include <stdio.h>
#include <stdbool.h>

int main(void) {
    // 1. Print 1 to 10 Numbers
    printf("1. Numbers (1-10): ");
    for (int i = 1; i <= 10; i++) printf("%d ", i);
    printf("\n");

    // 2. Multiplication Table (7 x i)
    printf("\n2. Multiplication Table for 7:\n");
    for (int i = 1; i <= 5; i++) printf("   7 x %d = %d\n", i, 7 * i);

    // 3. Sum of First 100 Numbers
    int sum = 0;
    for (int i = 1; i <= 100; i++) sum += i;
    printf("\n3. Sum of 1 to 100 = %d\n", sum);

    // 4. Factorial of 5 (5! = 120)
    long long fact = 1;
    for (int i = 1; i <= 5; i++) fact *= i;
    printf("4. Factorial of 5 = %lld\n", fact);

    // 5. Reverse Number & 6. Count Digits (Num = 9845)
    int num = 9845, temp = num, rev = 0, digits = 0;
    while (temp > 0) {
        rev = rev * 10 + (temp % 10);
        temp /= 10;
        digits++;
    }
    printf("5. Reverse of %d = %d\n", num, rev);
    printf("6. Total digits in %d = %d\n", num, digits);

    // 7. Prime Number Check (Num = 29)
    int checkPrime = 29;
    bool isPrime = (checkPrime > 1);
    for (int i = 2; i * i <= checkPrime; i++) {
        if (checkPrime % i == 0) { isPrime = false; break; }
    }
    printf("7. Is %d Prime? %s\n", checkPrime, isPrime ? "YES (Prime)" : "NO");

    // 8. Armstrong Number Check (Num = 153 -> 1^3 + 5^3 + 3^3 = 153)
    int armNum = 153, armTemp = armNum, armSum = 0;
    while (armTemp > 0) {
        int d = armTemp % 10;
        armSum += (d * d * d);
        armTemp /= 10;
    }
    printf("8. Is %d an Armstrong Number? %s\n", armNum, (armSum == armNum) ? "YES" : "NO");

    // 9. Fibonacci Series (First 8 Terms)
    int t1 = 0, t2 = 1, nextTerm;
    printf("9. Fibonacci (8 terms): ");
    for (int i = 1; i <= 8; i++) {
        printf("%d ", t1);
        nextTerm = t1 + t2;
        t1 = t2;
        t2 = nextTerm;
    }
    printf("\n");

    return 0;
}

ఈ ప్రోగ్రామ్స్ ని మన ఆన్‌లైన్ కంపైలర్ లో రన్ చేసి ఎలా పనిచేస్తున్నాయో చూడండి:

C (GCC Standard) ▶ Open C Compiler 
#include <stdio.h>

int main(void) {
    int n = 10, t1 = 0, t2 = 1;
    printf("First %d Fibonacci numbers:\n", n);
    for (int i = 1; i <= n; ++i) {
        printf("%d, ", t1);
        int next = t1 + t2;
        t1 = t2;
        t2 = next;
    }
    printf("\n");
    return 0;
}
