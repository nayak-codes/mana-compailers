వేరియబుల్ స్కోప్ & స్టోరేజ్ క్లాసెస్ (auto, static, extern, register)

⚡ Modern C (C99 / C11) 🟢 Chapter 11 of 20 📂 Phase 03: ఫంక్షన్స్, స్కోప్ & రికర్షన్ 📅 2026 Edition
📌 Covered in this chapter: లోకల్ vs గ్లోబల్ స్కోప్ · static వేరియబుల్ లైఫ్‌టైమ్ · CPU Register వేరియబుల్స్ · మల్టీ-ఫైల్ extern లింకేజ్
C లో ఒక వేరియబుల్‌ను డిక్లేర్ చేసినప్పుడు దానికి కేవలం డేటా టైప్ మాత్రమే కాకుండా, అది మెమరీలో ఎక్కడ నిల్వ ఉంటుంది, ప్రోగ్రామ్‌లో ఎక్కడి నుండి యాక్సెస్ చేయవచ్చు (Scope), మరియు ఎంతకాలం బతికి ఉంటుంది (Lifetime) అనే అంశాలను స్టోరేజ్ క్లాసెస్ (Storage Classes) నిర్ణయిస్తాయి. ఈ అధ్యాయంలో auto, static, extern, మరియు register ల అంతర్గత ఆర్కిటెక్చర్‌ను లోతుగా నేర్చుకుందాం.
1లోకల్ vs గ్లోబల్ స్కోప్ & షాడోయింగ్ (Scope Rules)

1. బ్లాక్ స్కోప్ / లోకల్ వేరియబుల్స్:

ఫంక్షన్ లేదా { } లోపల డిక్లేర్ చేయబడతాయి. అవి ఉన్న స్టాక్ ఫ్రేమ్ ముగియగానే అవి మెమరీ నుండి తుడిచిపెట్టుకుపోతాయి. డీఫాల్ట్ స్టోరేజ్ క్లాస్ auto.

2. ఫైల్ స్కోప్ / గ్లోబల్ వేరియబుల్స్:

అన్ని ఫంక్షన్ల బయట డిక్లేర్ చేయబడతాయి. ప్రోగ్రామ్ స్టార్ట్ అయినప్పటి నుండి ముగిసేంత వరకు RAM లోని డేటా సెగ్మెంట్‌లో జీవించి ఉంటాయి.

2static వేరియబుల్స్ — మెమరీ నిలుపుదల సూత్రం

సాధారణ లోకల్ వేరియబుల్ ఫంక్షన్ పూర్తవగానే నశిస్తుంది. కానీ ఒక లోకల్ వేరియబుల్‌కు ముందు static అని రాస్తే, ఫంక్షన్ ముగిసినా దాని విలువ మెమరీలోనే భద్రంగా ఉంటుంది! తర్వాతి సారి ఆ ఫంక్షన్‌ను పిలిచినప్పుడు పాత విలువ నుండే కొనసాగుతుంది.

C — static variable persistence ⚡ Try in C Compiler 
#include <stdio.h>

void countVisits(void) {
    // ప్రోగ్రామ్ జీవితకాలంలో ఒక్కసారి మాత్రమే ఇనీషియలైజ్ అవుతుంది
    static int visitCount = 0;
    visitCount++;
    printf("విజిట్ సంఖ్య: %d\n", visitCount);
}

int main(void) {
    countVisits(); // విజిట్ సంఖ్య: 1
    countVisits(); // విజిట్ సంఖ్య: 2
    countVisits(); // విజిట్ సంఖ్య: 3
    return 0;
}
3register & extern స్టోరేజ్ క్లాసెస్
⚡ register: CPU రిజిస్టర్ అలొకేషన్ హింట్

register int i; అని రాస్తే, కంపైలర్ ఆ వేరియబుల్‌ను RAM లో కాకుండా నేరుగా CPU లోని హై-స్పీడ్ రిజిస్టర్‌లో పెట్టడానికి ప్రయత్నిస్తుంది. ముఖ్య గమనిక: రిజిస్టర్ వేరియబుల్స్ కు మెమరీ అడ్రస్ ఉండదు కాబట్టి &i వాడటం నిషిద్ధం.

🌐 extern: మల్టీ-ఫైల్ గ్లోబల్ లింకేజ్

ఒక వేరియబుల్ వేరే ఏదో .c ఫైల్‌లో డిక్లేర్ చేయబడిందని, ఇక్కడ కేవలం వాడుకోవడానికి మాత్రమే రిఫర్ చేస్తున్నామని లింకర్‌కు చెప్పడానికి extern int globalMax; వాడతాం.

4బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. register వేరియబుల్ అడ్రస్ తీసుకోవడానికి ప్రయత్నించడం:
register int count = 10; scanf("%d", &count); // Compiler Error! రిజిస్టర్లకు RAM మెమరీ అడ్రస్ ఉండదు కాబట్టి అడ్రస్-ఆఫ్ & ఆపరేటర్ వాడితే కంపైలర్ ఎర్రర్ ఇస్తుంది.
❌ 2. గ్లోబల్ వేరియబుల్స్‌ను విచ్చలవిడిగా వాడడం:
గ్లోబల్ వేరియబుల్స్‌ను ఏ ఫంక్షన్ అయినా మార్చగలదు కాబట్టి బగ్స్ ఎక్కడ వచ్చాయో కనిపెట్టడం దాదాపు అసాధ్యం అవుతుంది. వీలైనంత వరకు లోకల్ వేరియబుల్స్ మరియు పారామీటర్లనే వాడాలి.
5తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: static వేరియబుల్స్‌కు ప్రారంభ విలువ ఇవ్వకపోతే ఏమవుతుంది?

సాధారణ లోకల్ వేరియబుల్స్‌లాగా గార్బేజ్ వాల్యూ ఉండదు! static మరియు గ్లోబల్ వేరియబుల్స్ BSS సెగ్మెంట్‌లో నిల్వ ఉంటాయి కాబట్టి కంపైలర్ వాటిని స్వయంచాలకంగా 0 (సున్నా) తో ఇనీషియలైజ్ చేస్తుంది.

Q: C++ లో auto కీవర్డ్ మరియు C లో auto కీవర్డ్ మధ్య తేడా ఏమిటి?

C లాంగ్వేజ్‌లో auto అనేది డీఫాల్ట్ లోకల్ స్టోరేజ్ క్లాస్ (దాదాపు ఎవరూ రాయరు). కానీ ఆధునిక C++ (C++11+) లో auto అంటే టైప్ ఇన్ఫరెన్స్ (Type Inference) — విలువను బట్టి డేటా టైప్‌ను కంపైలర్ స్వయంగా ఊహించడం.
