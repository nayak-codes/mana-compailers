C పరిచయం, చరిత్ర & మొదటి ప్రోగ్రామ్ (Hello World)

⚡ Modern C (C99 / C11) 🟢 Chapter 1 of 20 📂 Phase 01: బేసిక్స్ & మెమరీ ఆర్కిటెక్చర్ 📅 2026 Edition
📌 Covered in this chapter: Dennis Ritchie హిస్టరీ · GCC కంపైలర్ పైప్‌లైన్ (4 Stages) · main() ఎగ్జిక్యూషన్ · printf() మెకానిక్స్ · return 0 ప్రాముఖ్యత
కంప్యూటర్ సైన్స్ చరిత్రలో ఆపరేటింగ్ సిస్టమ్స్ (UNIX, Linux, Windows), డేటాబేస్‌లు (MySQL, Oracle) మరియు ఆధునిక ప్రోగ్రామింగ్ భాషలన్నింటికీ (C++, Java, Python) మూలస్తంభమైన C లాంగ్వేజ్ యొక్క ఆవిర్భావం, GCC కంపైలేషన్ పైప్‌లైన్ మరియు మీ మొట్టమొదటి Hello, World! ప్రోగ్రామ్‌ను ఈ ప్రారంభ అధ్యాయంలో మైక్రోస్కోపిక్‌గా విశ్లేషిద్దాం.
1C లాంగ్వేజ్ అంటే ఏమిటి? (Origins & Philosophy)

C అనేది ఒక general-purpose, procedural, statically typed, compiled ప్రోగ్రామింగ్ భాష. దీనిని 1972 లో అమెరికాలోని ప్రముఖ పరిశోధనా సంస్థ బెల్ లాబొరేటరీస్ (Bell Labs) లో లెజెండరీ కంప్యూటర్ సైంటిస్ట్ Dennis Ritchie రూపొందించారు.

అప్పట్లో రూపొందుతున్న UNIX Operating System ను రాయడానికి అసెంబ్లీ భాష చాలా కష్టంగా ఉండటంతో, హార్డ్‌వేర్ మెమరీతో నేరుగా సంభాషించే శక్తి (Low-level capabilities) మరియు ఇంగ్లీష్ లాంటి సులభమైన సింటాక్స్ (High-level abstraction) రెండూ కలిసేలా C భాషను ఆవిష్కరించారు. అందుకే C ని "Middle-Level Language" అని కూడా పిలుస్తారు.

2GCC కంపైలర్ పైప్‌లైన్ (The 4-Stage Compilation Process)

C భాషలో మనం రాసే కోడ్ నేరుగా CPU కి అర్థం కాదు. మనం రాసిన కోడ్ కంప్యూటర్ ప్రాసెసర్ అర్థం చేసుకునే బైనరీ మెషిన్ కోడ్ (0s & 1s) గా మారడానికి 4 దశలు దాటాలి:

Stage 01: Preprocessing (gcc -E)
హెడర్ ఫైల్స్ & మాక్రోల విస్తరణ
#include <stdio.h> లోని వేలాది లైన్ల స్టాండర్డ్ I/O డెఫినిషన్లను తెచ్చి మన ఫైల్ నెత్తిమీద అతికిస్తుంది (main.i).
Stage 02: Compilation (gcc -S)
ప్యూర్ C కోడ్ నుండి CPU అసెంబ్లీ కోడ్ మార్పు
సింటాక్స్ చెక్ చేసి, ప్రాసెసర్ రిజిస్టర్ సూచనలుగా (mov, push, call) మారుస్తుంది (main.s).
Stage 03: Assembly (as)
అసెంబ్లీ నుండి బైనరీ ఆబ్జెక్ట్ ఫైల్ తయారీ
అసెంబ్లర్ మిషన్ కోడ్ బైట్లను ఒక తాత్కాలిక రీలోకేటబుల్ ఆబ్జెక్ట్ ఫైల్ (main.o) లో సేవ్ చేస్తుంది.
Stage 04: Linking (ld)
లైబ్రరీలను కలిపి రన్ అయ్యే ఎగ్జిక్యూటబుల్ (.exe) తయారీ
మీ ఆబ్జెక్ట్ ఫైల్‌కు C రన్‌టైమ్ లైబ్రరీ (libc.a / crt1.o) ని అనుసంధానించి a.out / program.exe తయారు చేస్తుంది.
3మొదటి C ప్రోగ్రామ్: Hello, World!
C (C99 Standard) ▶ Run in Compiler 
#include <stdio.h>

int main() {
    printf("Hello, World! 🚀 Welcome to C Programming.\n");
    return 0;
}

🔍 లైన్-బై-లైన్ మైక్రోస్కోపిక్ విశ్లేషణ:

  • #include <stdio.h>: Standard Input Output Header. స్క్రీన్ పైన printf() ప్రింట్ చేయాలన్నా, కీబోర్డ్ నుండి scanf() చదవాలన్నా ఈ హెడర్ తప్పనిసరి.
  • int main(): ఎంట్రీ పాయింట్ (Entry Point). ఆపరేటింగ్ సిస్టమ్ మీ ప్రోగ్రామ్‌ను ఎగ్జిక్యూట్ చేయడం ఇక్కడి నుండే మొదలుపెడుతుంది.
  • printf("...");: Print Formatted Function. డబుల్ కోట్స్ లోపల ఉన్న టెక్స్ట్‌ను స్క్రీన్‌పై డిస్‌ప్లే చేస్తుంది.
  • \n: న్యూలైన్ ఎస్కేప్ సీక్వెన్స్. ప్రింట్ అయిన తర్వాత కర్సర్‌ను తర్వాతి లైన్‌కి పంపుతుంది.
  • return 0;: ప్రోగ్రామ్ ఎటువంటి లోపాలు లేకుండా విజయవంతంగా పూర్తయ్యిందని (Exit Code 0) ఆపరేటింగ్ సిస్టమ్‌కు తెలియజేస్తుంది.
4బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ Trap 1: void main() వాడటం

పాత Turbo C పుస్తకాలు చదివి చాలామంది void main() రాస్తారు. కానీ ANSI / ISO C స్టాండర్డ్స్ ప్రకారం void main() పూర్తిగా చెల్లదు. ఆపరేటింగ్ సిస్టమ్ ఎగ్జిట్ స్టేటస్ పొందడానికి తప్పనిసరిగా int main() మాత్రమే వాడాలి.
