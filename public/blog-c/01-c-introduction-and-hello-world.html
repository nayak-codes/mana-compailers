C పరిచయం, చరిత్ర & మొదటి ప్రోగ్రామ్ (Hello World)

⚡ Modern C (C99 / C11) 🟢 Chapter 1 of 20 📂 Phase 01: బేసిక్స్ & మెమరీ ఆర్కిటెక్చర్ 📅 2026 Edition
📌 Covered in this chapter: Dennis Ritchie హిస్టరీ · GCC కంపైలర్ పైప్‌లైన్ (4 Stages) · main() ఎగ్జిక్యూషన్ · printf() మెకానిక్స్ · return 0 ప్రాముఖ్యత
కంప్యూటర్ సైన్స్ చరిత్రలో ఆపరేటింగ్ సిస్టమ్స్ (UNIX, Linux, Windows), ఆధునిక గేమింగ్ ఇంజిన్లు, డేటాబేస్‌లు మరియు ప్రోగ్రామింగ్ భాషలన్నింటికీ (C++, Java, Python, Go) మూలస్తంభం C ప్రోగ్రామింగ్ లాంగ్వేజ్. 1970లలో జన్మించినప్పటికీ నేటికీ సిస్టమ్స్ ప్రోగ్రామింగ్, ఎంబెడెడ్ సాఫ్ట్‌వేర్ మరియు హై-పెర్ఫార్మెన్స్ కంప్యూటింగ్‌లో C ఎందుకు తిరుగులేని రారాజుగా వెలుగుతుందో, దాని 4-దశల GCC కంపైలేషన్ పైప్‌లైన్ మరియు మీ మొదటి C ప్రోగ్రామ్ అంతర్గత పనితీరును క్షుణ్ణంగా పరిశీలిద్దాం.
1C లాంగ్వేజ్ అంటే ఏమిటి? (Origins & Dennis Ritchie Philosophy)

C అనేది ఒక general-purpose, procedural, statically typed, compiled ప్రోగ్రామింగ్ భాష. దీనిని 1972 లో అమెరికాలోని ప్రముఖ పరిశోధనా సంస్థ Bell Labs లో Dennis Ritchie (డెన్నిస్ రిట్చీ) రూపొందించారు. అప్పటి వరకు ఉన్న Ken Thompson యొక్క B language మరియు BCPL భాషల పరిమితులను అధిగమించి, సరికొత్త UNIX Operating System కర్నల్ ను రాయడానికి C ని సృష్టించారు.

💡 C లాంగ్వేజ్ యొక్క ప్రధాన లక్షణాలు (Core Pillars):

  • Direct Memory Access (Pointers): C లో పాయింటర్స్ ద్వారా కంప్యూటర్ RAM అడ్రస్‌లను నేరుగా యాక్సెస్ చేయవచ్చు, మోడిఫై చేయవచ్చు.
  • Zero Runtime Overhead: C కి ఎటువంటి Garbage Collector లేదా భారీ వర్చువల్ మెషిన్ (JVM / Python VM లాంటివి) ఉండదు. కోడ్ నేరుగా CPU మెషిన్ ఇన్‌స్ట్రక్షన్లుగా కన్వర్ట్ అవుతుంది.
  • Portability (ప్లాట్‌ఫామ్ స్వతంత్రత): చిన్న మైక్రోకంట్రోలర్ (Arduino) నుండి సూపర్ కంప్యూటర్ల వరకు దాదాపు ప్రతి ఆర్కిటెక్చర్ (x86, ARM, RISC-V, MIPS) పై C కోడ్ రన్ అవుతుంది.
  • Deterministic Performance: ప్రోగ్రామ్ మెమరీలో ఎంత స్పేస్ తీసుకుంటుంది, ఎప్పుడు విడుదల అవుతుందో డెవలపర్ చేతిలోనే స్పష్టంగా ఉంటుంది.

🌍 C లాంగ్వేజ్‌ను నేటికీ ఎక్కడ ఉపయోగిస్తున్నారు?

🐧 Operating System Kernels Linux కర్నల్, Windows NT కర్నల్ మరియు Apple macOS Darwin కర్నల్ కోర్ భాగాలన్నీ C లోనే రాయబడ్డాయి.
🚗 Embedded & IoT Systems కార్ల ఇంజిన్ కంట్రోల్ యూనిట్లు (ECU), స్పేస్‌క్రాఫ్ట్ ఏవియానిక్స్, వాషింగ్ మెషీన్లు, మెడికల్ వెంటిలేటర్లలో C ప్రముఖం.
🗄️ Databases & Compilers MySQL, PostgreSQL, SQLite డేటాబేస్ ఇంజిన్లు, CPython (Python రన్‌టైమ్), Git వర్షన్ కంట్రోల్ C లోనే ఉన్నాయి.
🎮 Game Engines & Graphics లెజెండరీ గేమ్‌లు (Doom, Quake), OpenGL డ్రైవర్లు, DirectX ఇంటర్‌ఫేస్‌లు తక్కువ లేటెన్సీ కోసం C పై ఆధారపడతాయి.
2GCC కంపైలర్ పైప్‌లైన్ (The 4-Stage Compilation Process)

చాలామంది బిగినర్స్ C కోడ్ రాయగానే ఒకే క్లిక్‌తో ప్రోగ్రామ్ రన్ అయిపోతుందని అనుకుంటారు. కానీ తెరవెనుక GCC (GNU Compiler Collection) మీ సోర్స్ కోడ్‌ను నాలుగు ప్రత్యేక దశల (Stages) ద్వారా మెషిన్ లాంగ్వేజ్‌గా మారుస్తుంది.

దశ 1: ప్రీప్రాసెసింగ్ (Preprocessing) — gcc -E hello.c -o hello.i

ఇది కంపైలేషన్‌కు ముందస్తు సన్నాహం. కోడ్‌లోని కామెంట్లు (Comments) తొలగించబడతాయి. #include <stdio.h> లాంటి హెడర్ ఫైల్స్ యొక్క వాస్తవ కోడ్ నేరుగా ఫైల్‌లో పేస్ట్ అవుతుంది. #define మ్యాక్రోలు విస్తరించబడతాయి. దీని అవుట్‌పుట్ .i ఫైల్.

దశ 2: కంపైలేషన్ (Compilation) — gcc -S hello.i -o hello.s

ప్రీప్రాసెస్ చేసిన C కోడ్‌ను గ్రామర్, సింటాక్స్ పరిశీలించి (AST parsing & semantic analysis) ప్రాసెసర్ అర్థం చేసుకోగల Assembly Language (.s) గా మారుస్తుంది. ఇక్కడే సింటాక్స్ ఎర్రర్లు బయటపడతాయి.

దశ 3: అసెంబ్లింగ్ (Assembly) — gcc -c hello.s -o hello.o

అసెంబ్లర్ ఆ అసెంబ్లీ కోడ్‌ను CPU నేరుగా చదవగల బైనరీ ఆబ్జెక్ట్ కోడ్ (Machine Code 0s and 1s) గా మారుస్తుంది. దీని ఫలితంగా .o (లేదా .obj) ఆబ్జెక్ట్ ఫైల్ ఏర్పడుతుంది.

దశ 4: లింకింగ్ (Linking) — gcc hello.o -o hello.exe

లింకర్ మీ ఆబ్జెక్ట్ ఫైల్‌ను C స్టాండర్డ్ లైబ్రరీ (libc) కోడ్‌తో కలుపుతుంది. ఉదాహరణకు మీరు వాడిన printf() ఫంక్షన్ వాస్తవ మెషిన్ కోడ్ లైబ్రరీలో ఎక్కడ ఉందో కనుగొని, మీ కోడ్‌తో అనుసంధానించి రన్ అయ్యే ఎగ్జిక్యూటబుల్ ఫైల్ (.exe లేదా a.out) ను ఉత్పత్తి చేస్తుంది.

3మొదటి C ప్రోగ్రామ్: Hello, World!

ప్రపంచంలో ఏ ప్రోగ్రామర్ అయినా మొదటిసారి నేర్చుకునే సాంప్రదాయ ప్రోగ్రామ్ "Hello, World!". దీనిని అత్యంత సరళమైన రూపంలో రాసి, ప్రతి అక్షరాన్ని అర్థం చేసుకుందాం:

C — Hello World ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    // స్క్రీన్‌పై సందేశాన్ని ముద్రించడం
    printf("Hello, World!\n");
    return 0;
}

🔍 లైన్-బై-లైన్ లోతైన విశ్లేషణ (Exhaustive Line Breakdown):

#include <stdio.h> : ఇది Preprocessor Directive. stdio.h అంటే Standard Input Output Header. ఇందులో printf(), scanf() వంటి ఇన్‌పుట్/అవుట్‌పుట్ ఫంక్షన్ల యొక్క డిక్లరేషన్లు ఉంటాయి. ఈ లైన్ లేకుండా printf ను వాడలేం.
int main(void) : ఆపరేటింగ్ సిస్టమ్ ప్రోగ్రామ్‌ను రన్ చేయడానికి వెతికే ప్రధాన ద్వారం (Entry Point). కంప్యూటర్ మీ కోడ్‌ను మొదటిసారి ఇక్కడి నుంచే ఎగ్జిక్యూట్ చేయడం ప్రారంభిస్తుంది. int అంటే ఈ ఫంక్షన్ పని ముగిశాక OS కి ఒక పూర్ణాంక సంఖ్యను (Integer status) రిటర్న్ చేస్తుందని అర్థం. void అంటే మెయిన్ ఫంక్షన్ ఎటువంటి ఆర్గ్యుమెంట్లు తీసుకోదని స్పష్టత.
{ ... } : కర్లీ బ్రేసెస్ (Curly Braces) ఫంక్షన్ యొక్క పరిధిని (Function Body Scope) సూచిస్తాయి.
printf("Hello, World!\n"); : printf అంటే Print Formatted. డబుల్ కోట్స్ మధ్య ఉన్న టెక్స్ట్‌ను కన్సోల్ పై ముద్రిస్తుంది. \n అనేది Escape Sequence — ఇది కర్సర్‌ను తర్వాతి లైన్‌కు (Newline) తీసుకెళ్తుంది. ప్రతి C స్టేట్‌మెంట్ చివర సెమికోలన్ ; తప్పనిసరి.
return 0; : ఆపరేటింగ్ సిస్టమ్‌కు ప్రోగ్రామ్ ఎటువంటి లోపాలు లేకుండా విజయవంతంగా పూర్తయిందని (Exit Code 0 = Success) తెలియజేస్తుంది. సున్నా కాకుండా వేరే సంఖ్య రిటర్న్ అయితే ఎర్రర్ వచ్చినట్లు OS గుర్తిస్తుంది.

⚠️ కాలేజీ మిత్: void main() ఎందుకు వాడకూడదు?

చాలా పాత పుస్తకాలలో లేదా పాత Turbo C++ కంపైలర్లలో void main() రాస్తుంటారు. కానీ అంతర్జాతీయ C ప్రమాణాలైన C99, C11, C17, C23 Standards ప్రకారం void main() అనేది చెల్లని సింటాక్స్ (Undefined Behavior). ఆధునిక ఆపరేటింగ్ సిస్టమ్స్ ప్రోగ్రామ్ సక్సెస్ అయిందో లేదో తెలుసుకోవడానికి ఎగ్జిట్ స్టేటస్ కోడ్ ను ఆశిస్తాయి. కాబట్టి ఎల్లప్పుడూ int main() మాత్రమే రాయాలి.

4బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. #include చివర సెమికోలన్ పెట్టడం:
#include <stdio.h>; // తప్పు! Preprocessor డైరెక్టివ్‌లకు సెమికోలన్ ఉండదు ప్రీప్రాసెసర్ డైరెక్టివ్‌లు C స్టేట్‌మెంట్లు కావు. కాబట్టి #include మరియు #define చివర ఎప్పుడూ సెమికోలన్ పెట్టకూడదు.
❌ 2. కేస్-సెన్సిటివిటీ మర్చిపోవడం:
Printf("Hello"); // తప్పు! C లో అన్ని కీవర్డ్లు స్మాల్ లెటర్సే C లాంగ్వేజ్ కచ్చితమైన Case-Sensitive. printf ని Printf అని రాస్తే లింకర్ undefined reference ఎర్రర్ ఇస్తుంది.
❌ 3. స్ట్రింగ్స్‌కి సింగిల్ కోట్స్ వాడడం:
printf('Hello'); // తప్పు! സിంగిల్ కోట్స్ కేవలం ఒక క్యారెక్టర్ ('A') కి మాత్రమే స్ట్రింగ్స్ (పదాలు, వాక్యాలు) ఎల్లప్పుడూ డబుల్ కోట్స్ "..." లోనే ఉండాలి. సింగిల్ కోట్స్ '...' కేవలం సింగిల్ క్యారెక్టర్ కోసమే.
5తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: C నేర్చుకోవడానికి ముందు మరేదైనా ప్రోగ్రామింగ్ లాంగ్వేజ్ వచ్చి ఉండాలా?

అస్సలు అవసరం లేదు! C లాంగ్వేజ్ కంప్యూటర్ ఆర్కిటెక్చర్, మెమరీ మరియు ప్రాసెసర్ పనిచేసే విధానాన్ని అర్థం చేసుకోవడానికి ప్రపంచవ్యాప్తంగా ఉత్తమ మొదటి ప్రోగ్రామింగ్ భాషగా గుర్తించబడింది. C నేర్చుకుంటే C++, Java, C#, Go, Rust చాలా సులువుగా అర్థమవుతాయి.

Q: return 0 కాకుండా return 1 ఇస్తే ఏమవుతుంది?

ప్రోగ్రామ్ అవుట్‌పుట్ స్క్రీన్ పై కనిపిస్తుంది కానీ ఆపరేటింగ్ సిస్టమ్‌కి లేదా కాల్ చేసిన పేరెంట్ ప్రాసెస్‌కు ప్రోగ్రామ్‌లో ఏదో లోపం జరిగి అసాధారణంగా ఆగిపోయిందని (Non-zero exit status indicates failure) సంకేతం అందుతుంది.

Q: Turbo C++ బదులుగా ఆధునిక GCC / Clang ఎందుకు వాడాలి?

Turbo C++ అనేది 1990ల నాటి 16-బిట్ డాస్ (DOS) ఎన్విరాన్‌మెంట్ కంపైలర్. ఇది పాతబడింది మరియు ఆధునిక 64-బిట్ ప్రాసెసర్ల ఫీచర్లను (C99/C11 స్టాండర్డ్స్) సపోర్ట్ చేయదు. GCC మరియు Clang నేటి ఇండస్ట్రీ ప్రమాణాలు.
