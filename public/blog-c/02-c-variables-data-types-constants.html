⚡ Modern C (C99 / C11) 🟢 Chapter 2 of 20 📂 Phase 01: బేసిక్స్ & మెమరీ ఆర్కిటెక్చర్ 📅 2026 Edition
📌 Covered in this chapter: RAM మెమరీ స్లాట్లు (Bytes) · char, int, float, double · sizeof ఆపరేటర్ · const కీవర్డ్ · Signed vs Unsigned ఓవర్‌ఫ్లో
కంప్యూటర్ RAM మెమరీలో డేటాను భద్రపరచడానికి కేటాయించే పేరున్న స్థలాలనే వేరియబుల్స్ (Variables) అంటారు. C లో వివిధ రకాల డేటా టైప్స్, వాటి బైట్ పరిమాణాలు (Sizes), sizeof ఆపరేటర్ మరియు అన్‌సైన్డ్ ఓవర్‌ఫ్లో ప్రమాదాలను ఈ అధ్యాయంలో నేర్చుకుందాం.
1వేరియబుల్స్ & RAM మెమరీ లేఅవుట్

ఒక వేరియబుల్ డిక్లేర్ చేసినప్పుడు RAM లో దాని డేటా టైప్‌కు సరిపడా బైట్లు కేటాయించబడతాయి:

0x2000 to 0x2003 (4 Bytes)
int rollNo = 101;
పూర్ణాంకాలు (Integer Data)
0x2004 to 0x2007 (4 Bytes)
float cgpa = 8.75f;
దశాంశ సంఖ్యలు (Single Precision)
0x2008 (1 Byte)
char section = 'A';
సింగిల్ అక్షరం (ASCII Code 65)
2C ప్రిమిటివ్ డేటా టైప్స్ టేబుల్
డేటా టైప్ పరిమాణం (Size) పరిధి (Range) Format Specifier
char 1 Byte -128 to 127 %c
int 4 Bytes -2.14 Billion to +2.14 Billion %d
float 4 Bytes ~6-7 డెసిమల్ డిజిట్స్ %f
double 8 Bytes ~15-17 డెసిమల్ డిజిట్స్ %lf
C — sizeof operator ▶ Run in Compiler 
#include <stdio.h>

int main() {
    printf("char size:   %zu byte\n", sizeof(char));
    printf("int size:    %zu bytes\n", sizeof(int));
    printf("float size:  %zu bytes\n", sizeof(float));
    printf("double size: %zu bytes\n", sizeof(double));
    return 0;
}
