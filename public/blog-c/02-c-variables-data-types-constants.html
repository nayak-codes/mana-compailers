కంప్యూటర్ ప్రోగ్రామింగ్ అంటే వాస్తవానికి మెమరీ (RAM) లోని బైట్లను చదవడం, లెక్కించడం మరియు తిరిగి నిల్వ చేయడమే. ఈ అధ్యాయంలో C లాంగ్వేజ్ RAM ను ఎలా కేటాయిస్తుంది (Memory Cells & Addresses), ఫండమెంటల్ డేటా టైప్స్, sizeof ఆపరేటర్, const vs #define మరియు సైన్డ్ ఓవర్‌ఫ్లో ప్రమాదాలను లోతుగా నేర్చుకుందాం.
1వేరియబుల్స్ & RAM మెమరీ లేఅవుట్

వేరియబుల్ (Variable) అంటే మెమరీ (RAM) లోని ఒక నిర్దిష్ట స్థానానికి మనం పెట్టే పేరు. కంప్యూటర్ అంతర్గతంగా మెమరీని హెక్సాడెసిమల్ అడ్రస్‌లతో (ఉదాహరణకు 0x7ffee4a10) గుర్తిస్తుంది. మనుషులు ప్రతిసారీ ఈ అడ్రస్‌లను గుర్తుపెట్టుకోవడం అసాధ్యం కాబట్టి C మనకు వేరియబుల్స్ అనే సౌకర్యాన్ని కల్పిస్తుంది.

1. డిక్లరేషన్ (Declaration):
int age;

కంపైలర్‌కు "నాకు మెమరీలో 4 బైట్ల పూర్ణాంక స్థలాన్ని కేటాయించు, దాని పేరు age" అని చెప్పడం.

2. ఇనీషియలైజేషన్ (Initialization):
age = 25;

ఆ కేటాయించబడిన 4 బైట్ల RAM గదిలో 25 అనే బైనరీ విలువను నిల్వ చేయడం.

⚠️ గార్బేజ్ వాల్యూస్ (Garbage Values) ప్రమాదం:

C లో ఒక వేరియబుల్‌ను కేవలం డిక్లేర్ చేసి (int score;) దానికి విలువ ఇవ్వకపోతే, C దానిని డీఫాల్ట్‌గా 0 చేయదు! గతంలో వేరే ఏదో ప్రోగ్రామ్ RAM లో వదిలేసిన పాత విలువ (Garbage Data) అలాగే ఉంటుంది. అందుకే ఎల్లప్పుడూ వేరియబుల్స్ ను ఇనీషియలైజ్ చేయాలి.

2C ఫండమెంటల్ డేటా టైప్స్ (Data Types Matrix)

ఆధునిక 64-బిట్ ఆర్కిటెక్చర్‌లలో (GCC/Clang) డేటా టైప్స్ యొక్క పరిమాణాలు మరియు వాటి పరిధుల పట్టిక:

డేటా టైప్ మెమరీ సైజ్ ఫార్మాట్ స్పెసిఫైయర్ విలువ పరిధి (Range)
char 1 Byte (8 bits) %c -128 నుండి 127 (లేదా 0 నుండి 255)
short 2 Bytes (16 bits) %hd -32,768 నుండి 32,767
int 4 Bytes (32 bits) %d లేదా %i -2,147,483,648 నుండి 2,147,483,647
unsigned int 4 Bytes (32 bits) %u 0 నుండి 4,294,967,295
long long 8 Bytes (64 bits) %lld ≈ -9.22 × 1018 నుండి +9.22 × 1018
float 4 Bytes (32 bits) %f 6-7 దశాంశ అంకెల ఖచ్చితత్వం
double 8 Bytes (64 bits) %lf 15-17 దశాంశ అంకెల అత్యున్నత ఖచ్చితత్వం
3sizeof ఆపరేటర్: లైవ్ మెమరీ తనిఖీ

ఏదైనా వేరియబుల్ లేదా డేటా టైప్ మెమరీలో ఎన్ని బైట్లు ఆక్రమించిందో తెలుసుకోవడానికి sizeof ఆపరేటర్ వాడతాం. ఇది ఫంక్షన్ కాదు, కంపైల్-టైమ్ ఆపరేటర్.

C — sizeof operator demo ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int a = 100;
    double pi = 3.14159265;

    printf("Size of char   : %zu byte\n", sizeof(char));
    printf("Size of int    : %zu bytes\n", sizeof(a));
    printf("Size of double : %zu bytes\n", sizeof(pi));
    return 0;
}
💡 గమనిక: C లో sizeof రిటర్న్ చేసే విలువ size_t టైప్ (unsigned integer). కాబట్టి ఆధునిక C ప్రమాణాల ప్రకారం దీనిని ప్రింట్ చేయడానికి %zu ఫార్మాట్ స్పెసిఫైయర్ వాడాలి.
4కాన్‌స్టాంట్స్: const vs #define

ప్రోగ్రామ్ రన్ అవుతున్నంత సేపు మారకూడని విలువలను (ఉదా: గణిత స్థిరాంకం PI, గరిష్ట పరిమితి MAX_USERS) స్థిరంగా ఉంచడానికి C లో రెండు పద్ధతులు ఉన్నాయి:

1. const కీవర్డ్ (సిఫార్సు చేయబడినది):

const float PI = 3.14159f;
// PI = 3.15; // Compiler Error!

ఇది టైప్-సేఫ్ (Type-safe). కంపైలర్ టైప్ చెకింగ్ చేస్తుంది మరియు డీబగ్గర్‌లో వేరియబుల్ పేరు కనిపిస్తుంది.

2. #define మ్యాక్రో (పాత పద్ధతి):

#define MAX_USERS 100

ఇది ప్రీప్రాసెసర్ టెక్స్ట్ రీప్లేస్‌మెంట్ మాత్రమే. దీనికి మెమరీ లేదా డేటా టైప్ ఉండదు. ఆధునిక C కోడ్‌లో const వాడటమే శ్రేయస్కరం.

5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. అరిథ్‌మెటిక్ ఓవర్‌ఫ్లో (Arithmetic Overflow):
int max = 2147483647; max = max + 1; // ఇక్కడ max విలువ -2147483648 అవుతుంది! 32-బిట్ సైన్డ్ ఇంటిజర్ గరిష్ట పరిమితికి 1 కలిపితే 2's Complement సైకిల్ ప్రకారం నెగటివ్ విలువగా మారుతుంది. దీనిని ఇంటిజర్ ఓవర్‌ఫ్లో అంటారు.
❌ 2. వేరియబుల్ పేర్లలో నిబంధనలు ఉల్లంఘించడం:
int 2rollNumber; // తప్పు! వేరియబుల్ పేరు నంబర్‌తో ప్రారంభం కారాదు వేరియబుల్ పేరు కేవలం అక్షరాలు (A-Z, a-z), అండర్‌స్కోర్ (_) తో మాత్రమే ప్రారంభం కావాలి. కీవర్డ్లను (ఉదా: int, return) పేర్లుగా వాడరాదు.
6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: float మరియు double మధ్య ప్రధాన తేడా ఏమిటి? దేనిని ఎప్పుడు వాడాలి?

float కేవలం 4 బైట్లు మాత్రమే తీసుకుంటుంది మరియు 7 అంకెల ఖచ్చితత్వం ఇస్తుంది. double 8 బైట్లు తీసుకుని 15-17 అంకెల ఖచ్చితత్వం ఇస్తుంది. బ్యాంకింగ్, సైంటిఫిక్ కాలిక్యులేషన్స్‌లో ఖచ్చితత్వం కోసం ఎల్లప్పుడూ double వాడటమే ఆధునిక ప్రమాణం.

Q: 32-bit OS లో int 4 బైట్లు ఉంటే, 64-bit OS లో 8 బైట్లు అవుతుందా?

లేదు! ఎక్కువమంది పొరబడే విషయమిది. ఆధునిక x86_64 సిస్టమ్స్‌లో (LP64 డేటా మోడల్) int ఎల్లప్పుడూ 4 బైట్లే ఉంటుంది. పాయింటర్లు మరియు long మాత్రమే 8 బైట్లు అవుతాయి.
