break, continue, నెస్టెడ్ లూప్స్ & ప్యాటర్న్స్

⚡ Modern C (C99 / C11) 🟢 Chapter 8 of 20 📂 Phase 02: కంట్రోల్ ఫ్లో & లూప్స్ 📅 2026 Edition
📌 Covered in this chapter: లీనియర్ సెర్చ్ ఎర్లీ ఎగ్జిట్ · continue స్కిప్పింగ్ · పిరమిడ్/స్టార్ ప్యాటర్న్స్ · goto వివాదం & స్ట్రక్చర్డ్ కోడ్
లూప్స్ ఎగ్జిక్యూట్ అవుతున్నప్పుడు సాధారణ ఫ్లోను నియంత్రించడానికి, అవసరమైన సమాచారం దొరకగానే లూప్ నుండి వెంటనే బయటకు రావడానికి లేదా కొన్ని అనవసరమైన ఇటరేషన్లను దాటవేయడానికి break మరియు continue కీవర్డ్లు తప్పనిసరి. 2D మ్యాట్రిక్స్ ప్రాసెసింగ్ మరియు ఇంటర్వ్యూలలో ఎక్కువగా అడిగే నెస్టెడ్ లూప్స్ (Nested Loops) మరియు ప్యాటర్న్లను ఈ అధ్యాయంలో లోతుగా తెలుసుకుందాం.
1break కీవర్డ్ — అత్యవసర లూప్ ఎగ్జిట్ (Early Exit)

లూప్ ఎన్నిసార్లు తిరగాలని నిర్ణయించబడిందో ఆ లక్ష్యం ఇంకా పూర్తికాకముందే, ఒక నిర్దిష్ట పరిస్థితి రాగానే ఆ లూప్‌ను తక్షణమే శాశ్వతంగా ముగించి బయటకు రావడానికి break ఉపయోగపడుతుంది.

C — Linear Search with break optimization ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int numbers[7] = {12, 45, 78, 23, 56, 89, 90};
    int target = 23;
    int foundAt = -1;

    for (int i = 0; i < 7; i++) {
        if (numbers[i] == target) {
            foundAt = i;
            break; // ఎలిమెంట్ దొరికింది! మిగిలిన ఇటరేషన్లు అనవసరం కాబట్టి లూప్ ఆపేస్తున్నాం
        }
    }

    if (foundAt != -1) {
        printf("లక్ష్యం %d ఇండెక్స్ %d వద్ద లభించింది!\n", target, foundAt);
    }
    return 0;
}

💡 break లేకపోతే టార్గెట్ మొదట్లోనే దొరికినా అరే చివరి వరకు అనవసరంగా లూప్ రన్ అవుతూ విలువైన CPU సమయాన్ని వృధా చేస్తుంది.

2continue కీవర్డ్ — ప్రస్తుత ఇటరేషన్ స్కిప్ చేయడం

లూప్‌ను పూర్తిగా ఆపేయకుండా, కేవలం ఆ ప్రస్తుత ఒక్క ఇటరేషన్‌లోని తర్వాతి లైన్లను మాత్రమే స్కిప్ చేసి వెంటనే తర్వాతి రౌండ్‌కు దూకడానికి continue వాడతాం.

C — continue (Skip Multiples of 3) ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    // 1 నుండి 10 వరకు ప్రింట్ చేస్తూ 3 యొక్క గుణిజాలను స్కిప్ చేయడం
    for (int i = 1; i <= 10; i++) {
        if (i % 3 == 0) {
            continue; // ఈ రౌండ్ మిగిలిన భాగం స్కిప్ అయి i++ కి వెళ్తుంది
        }
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
⚠️ while లూప్‌లో continue వాడేటప్పుడు అత్యంత జాగ్రత్త!

for లూప్‌లో continue ఆటోమేటిక్‌గా i++ ఇంక్రిమెంట్‌కు వెళ్తుంది. కానీ while లూప్‌లో ఇంక్రిమెంట్ బాడీ చివర ఉంటే, continue వల్ల ఆ ఇంక్రిమెంట్ లైన్ ఎప్పటికీ రన్ కాక ప్రోగ్రామ్ ఇన్ఫినిట్ లూప్‌లో ఇరుక్కుపోతుంది! కాబట్టి continue కి ముందే ఇంక్రిమెంట్ చేయాలి.

3నెస్టెడ్ లూప్స్ (Nested Loops) & స్టార్ ప్యాటర్న్స్

ఒక లూప్ లోపల మరొక లూప్ ఉండడాన్ని నెస్టెడ్ లూప్ (Nested Loop) అంటారు. బయటి లూప్ (Outer Loop) అడ్డు వరుసలను (Rows) నియంత్రిస్తే, లోపలి లూప్ (Inner Loop) నిలువు వరుసలను (Columns) నియంత్రిస్తుంది.

C — Right Angled Star Pyramid ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int rows = 5;

    for (int r = 1; r <= rows; r++) {
        // లోపలి లూప్: ప్రతి వరుసలో నక్షత్రాలను ముద్రించడం
        for (int c = 1; c <= r; c++) {
            printf("* ");
        }
        printf("\n"); // వరుస పూర్తయిన తర్వాత కొత్త లైన్‌కు వెళ్లడం
    }
    return 0;
}

💡 నెస్టెడ్ లూప్స్ యొక్క టైమ్ కాంప్లెక్సిటీ సాధారణంగా $O(N imes M)$ లేదా $O(N^2)$ అవుతుంది. కాబట్టి 3 లేదా 4 స్థాయిల కంటే ఎక్కువ నెస్టెడ్ లూప్స్ రాయడం పెర్ఫార్మెన్స్‌కు హానికరం.

4goto వివాదం: ప్రొఫెషనల్ కోడింగ్‌లో అనుమతించబడే సందర్భం

ప్రముఖ కంప్యూటర్ శాస్త్రవేత్త Edsger Dijkstra తన ప్రసిద్ధ పత్రం "Go To Statement Considered Harmful" లో goto ను నిషేధించాలని పేర్కొన్నారు. కారణం అది కోడ్‌ను అర్థం చేసుకోవడం అసాధ్యమైన స్పఘెట్టి కోడ్ (Spaghetti Code) గా మారుస్తుంది.

🐧 Linux Kernel ఎక్సెప్షన్:

లైనక్స్ కర్నల్ సోర్స్ కోడ్‌లో ఎర్రర్ సంభవించినప్పుడు కేటాయించిన మెమరీ మరియు ఫైల్ డిస్క్రిప్టర్లను రివర్స్ ఆర్డర్‌లో క్లీనప్ చేయడానికి (Centralized Error Unwinding) మాత్రమే goto out_error; ను అనుమతిస్తారు. మిగిలిన సాధారణ ప్రోగ్రామింగ్‌లో goto వాడరాదు.

5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. break అన్ని నెస్టెడ్ లూప్స్ నుండి బయటకు తెస్తుందని భావించడం:
break కేవలం తాను ఉన్న అత్యంత సమీపంలోని ఇన్నర్ లూప్‌ను మాత్రమే రద్దు చేస్తుంది. ఔటర్ లూప్ సాధారణంగానే కొనసాగుతుంది. అన్నింటి నుండి బయటకు రావాలంటే బూలియన్ ఫ్లాగ్ లేదా return వాడాలి.
❌ 2. నెస్టెడ్ లూప్స్ లో వేరియబుల్ షాడోయింగ్:
for (int i = 0; ... ) { for (int i = 0; ... ) } // గందరగోళం ఔటర్ మరియు ఇన్నర్ లూప్‌లకు ఒకే వేరియబుల్ పేరు వాడకూడదు. ఎల్లప్పుడూ i, j లేదా r, c (Row, Column) అని వేర్వేరు పేర్లు వాడాలి.
6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: break మరియు exit(0) ల మధ్య ముఖ్యమైన తేడా ఏమిటి?

break కేవలం ఆ లూప్ లేదా switch నుండి మాత్రమే బయటకు తీసుకువస్తుంది; ఆ తర్వాత ఉన్న మిగిలిన ప్రోగ్రామ్ నడుస్తుంది. కానీ exit(0) మొత్తం ప్రోగ్రామ్‌నే అక్కడికక్కడే ఆపేసి ఆపరేటింగ్ సిస్టమ్‌కి కంట్రోల్‌ను తిరిగి ఇస్తుంది.

Q: నెస్టెడ్ లూప్స్ నుండి ఒకేసారి పూర్తిగా బయటకు రావడానికి ఉత్తమ పద్ధతి ఏమిటి?

ఒక ఫ్లాగ్ వేరియబుల్ (ఉదా: int found = 1) వాడి ఔటర్ లూప్‌లో కూడా బ్రేక్ చేయడం, లేదా ఆ మొత్తం నెస్టెడ్ లూప్ కోడ్‌ను ఒక ప్రత్యేక ఫంక్షన్‌లో ఉంచి కండిషన్ మ్యాచ్ కాగానే నేరుగా return చేయడం ఆధునిక క్లీన్ కోడ్ పద్ధతి.
