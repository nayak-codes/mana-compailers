Phase 8 (Chapter 18): C Strings & Safe I/O Architecture Masterclass కు స్వాగతం! Python, Java, లాంటి లాంగ్వేజెస్ లో String అనే డేటా టైప్ డైరెక్ట్ గా ఉంటుంది, కానీ C భాషలో క్యారెక్టర్స్ (అక్షరాలు) తప్ప అసలు String డేటా టైప్ అనేదే ఉండదు! అందుకని C లో క్యారెక్టర్స్ ని పక్కపక్కన ఒక Array లో పెట్టి, చివర్లో దీనితో పదం అయిపోయింది అని చెప్పడానికి '\0' (Null Terminator) ని పెడతాం. ఈ గైడ్ లో, అసలు RAM లో ఇవి ఎలా సేవ్ అవుతాయి, scanf() లేదా gets() వాడటం వల్ల హ్యాకర్స్ కి ఎలా ఛాన్స్ దొరుకుతుంది, మరియు fgets() వాడి సేఫ్ గా యూజర్ నుండి డేటా ఎలా తీసుకోవాలో తెలుగులో నేర్చుకుందాం.

1C లో Strings అంటే ఏంటి? (క్యారెక్టర్ Array)

C లాంగ్వేజ్ లో string అనే కీవర్డ్ అసలే లేదు. పేర్లు లేదా వాక్యాలు సేవ్ చేయాలంటే, char ని ఒక 1D Array లాగా వాడి, ఆ పదం ఎక్కడ ఆగిపోయిందో కంప్యూటర్ కి చెప్పడానికి చివర్లో Null Terminator ('\0') ని యాడ్ చేస్తాము.

🌟 C Strings కి ఉండే 3 గోల్డెన్ రూల్స్:

1. ఒక అక్షరానికి 1 బైట్: ప్రతి క్యారెక్టర్ RAM లో కచ్చితంగా ఒక బైట్ (8 bits) స్పేస్ ని తీసుకుంటుంది.
2. Null Terminator ('\0'): C కి ఈ పదం ఎంత పొడవు ఉందో ముందే తెలియదు. కాబట్టి printf లాంటివి లైన్ గా చదువుకుంటూ వెళ్ళి, ఆ '\0' కనబడగానే అక్కడితో ప్రింటింగ్ ఆపేస్తాయి!
3. మెమరీకి $+1$ రూల్: 5 అక్షరాలున్న పదం స్టోర్ చేయాలంటే, ఆ లాస్ట్ లో ఉండే '\0' కి కూడా ఒక ప్లేస్ కావాలి కదా, కాబట్టి మొత్తం 6 బైట్స్ మెమరీ కావాలి!

2మామూలు Array కి, String Literal కి తేడా ఏంటి? ⭐

C లో ఒక పదాన్ని సేవ్ చేయడానికి 2 వేర్వేరు పద్ధతులు ఉంటాయి. ఈ రెంటి మధ్య తేడా తెలియకపోతే, మీ ప్రోగ్రామ్ అకారణంగా Segmentation Fault అని వచ్చి క్రాష్ అయిపోతుంది:

ఎలా క్రియేట్ చేస్తాం?RAM లో ఎక్కడ పడుతుంది?మనం అక్షరాలని మార్చొచ్చా?సేఫ్ ఆర్ నాట్?
char str[] = "Hello"; Stack లో (మన కంట్రోల్ లో) ✅ ఎస్ మార్చొచ్చు! str[0] = 'M'; అంటే Mello అని మారుతుంది. ఎడిటింగ్ కి 100% సేఫ్.
char* ptr = "Hello"; .rodata లో (OS కంట్రోల్ లో) ❌ క్రాష్ అయిపోతుంది! ఇక్కడ మార్చడానికి ట్రై చేస్తే సిస్టం ఒప్పుకోదు! ఇది కేవలం చదువుకోవడానికే (Read-Only).

🛑 The String Literal Segfault Trap:

Double quotes "Hello" tho direct ga pointer declare chesthe (char* ptr = "Hello";), operating system aa text ni Read-Only Memory Segment lo peduthundhi. Daanini modify cheyyadaniki try chesthe CPU memory protection fault trigger ayi program crash avthundhi!
✅ Best Practice: Always use const char* ptr = "Hello"; to let compiler catch accidental writes during compilation!

3యూజర్ నుండి డేటా తీసుకోవడం: scanf() ఎందుకు డేంజర్?

యూజర్ కీబోర్డ్ ద్వారా టైప్ చేసిన పదాన్ని చదవడానికి C లో చాలా ఆప్షన్స్ ఉన్నాయి. కానీ వాటిలో కొన్ని వాడితే సిస్టం సులభంగా హ్యాక్ అవుతుంది:

⚠️ 1. scanf("%s", buf) వాడితే వచ్చే ప్రాబ్లమ్స్:

• ఖాళీ (Space) కనబడితే ఆగిపోతుంది: మీరు "Ratan Tata" అని టైప్ చేస్తే, scanf మధ్యలో ఉన్న స్పేస్ చూడగానే అక్కడితో కట్ చేసి, కేవలం "Ratan" మాత్రమే సేవ్ చేసుకుంటుంది!
• మెమరీ ఓవర్ ఫ్లో (చాలా డేంజర్): మీ బాక్స్ లో 10 అక్షరాలకే ప్లేస్ ఉండి, యూజర్ 100 అక్షరాలు టైప్ చేస్తే, scanf ఆ 100 ని బలవంతంగా ఎక్కించి సిస్టం ని హ్యాక్ చేసేలా చేస్తుంది (Buffer Overflow)!

🛡️ దీనికి సరైన సొల్యూషన్: fgets() + strcspn()

దీనికి పర్ఫెక్ట్ సొల్యూషన్ fgets() వాడటమే. ఇది మాత్రమే ఎందుకు వాడాలంటే:
1. మెమరీకి లిమిట్ ఇస్తుంది: ఇది మనం ఇచ్చిన సైజు ఎంతైతే అంతవరకే చదువుతుంది, కాబట్టి మెమరీ ఓవర్ ఫ్లో అవ్వదు!
2. స్పేసెస్ ని కూడా చదువుతుంది: మధ్యలో ఎన్ని ఖాళీలు ఉన్నా పూర్తి వాక్యాన్ని చదువుతుంది.
3. ఒక చిన్న చిక్కు: మనం ఎంటర్ కొట్టగానే, ఆ ఎంటర్ ('\n') కూడా వచ్చి మన పదం చివర్లో సేవ్ అయిపోతుంది.
4. సొల్యూషన్: దాన్ని తీసేయడానికి మనం buffer[strcspn(buffer, "\n")] = '\0'; అని రాస్తే సరిపోతుంది!

C — User Curriculum Standard Example (Safe I/O) ▶ Run Code in C Compiler 
#include <stdio.h>
#include <string.h>

int main(void) {
    char name[50];

    printf("Enter your name: ");
    // Safe input: reads at most 50 bytes including null terminator
    fgets(name, sizeof(name), stdin);

    // Remove trailing newline character '
'
    name[strcspn(name, "\n")] = '\0';

    printf("Hello, %s! Welcome to C String Masterclass.\n", name);
    printf("Length of name: %zu characters\n", strlen(name));

    return 0;
}

5Frequently Asked Questions & Technical Interview Deep-Dive

Q1: What is the exact difference between ASCII '0' and '\0'?

Character '0' is the numeral zero digit with ASCII value 48 (0x30). The null terminator '\0' is the non-printable sentinel byte with exact numerical value 0 (0x00). They are completely distinct in memory!

Q2: Why was the legacy gets() function officially deleted in C11?

gets() accepted input without any buffer length boundary parameter. It was impossible to use gets() safely against buffer overflow attacks, leading the ISO C committee to deprecate it in C99 and completely remove it in C11.

Q3: What happens if a string array forgets its null terminator?

String functions like printf("%s") or strlen() will continue reading past the array boundary into unallocated RAM until they randomly encounter a 0 byte. This causes garbage output, corrupted state, or immediate Segmentation Faults.
