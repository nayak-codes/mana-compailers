File Handling, fopen() & fclose() (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 36 📂 Phase 14: File I/O & Preprocessor 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: File I/O Basics · fopen() & fclose() · File Modes (r, w, a) · fprintf() & fscanf() · End of File (EOF)

ఇప్పటివరకు మనం రాసిన ప్రోగ్రామ్స్ అన్నీ పవర్ కట్ అయితే లేదా యాప్ క్లోజ్ చేస్తే అందులో డేటా మొత్తం మాయం అయిపోతుంది (ఎందుకంటే అదంతా RAM లో ఉంటుంది). కానీ యూజర్ సేవ్ చేసిన ఒక గేమ్ స్కోర్ గాని, లేదా పాస్వర్డ్ గాని లైఫ్ టైమ్ ఉండాలంటే దాన్ని పర్మనెంట్ గా హార్డ్ డిస్క్ (HDD / SSD) లో ఉన్న ఒక ఫైల్ లో దాచాలి. దాన్నే File Handling (ఫైల్ హ్యాండ్లింగ్) అంటారు. C లాంగ్వేజ్ లో ఫైల్స్ తో మాట్లాడటానికి ఆపరేటింగ్ సిస్టమ్ మనకు FILE అనే ఒక స్పెషల్ పాయింటర్ ని ఇస్తుంది. fopen() తో ఫైల్స్ ఓపెన్ చేసి, fprintf() తో ఫైల్ లోపలికి డేటా ఎలా ప్రింట్ చేయాలో ఈరోజు ఒక రియల్ వరల్డ్ ప్రాజెక్ట్ లాగా చూద్దాం.

1 ఫైల్స్ ఎలా పనిచేస్తాయి? (The File Pointer)

మన ప్రోగ్రామ్ కి హార్డ్ డిస్క్ లో ఉన్న ఫైల్ కి డైరెక్ట్ కనెక్షన్ ఉండదు. మధ్యలో ఆపరేటింగ్ సిస్టమ్ (OS) ఒక దళారి (Broker) లాగా పనిచేస్తుంది. మీరు ఒక ఫైల్ అడిగితే, OS దాన్ని ఓపెన్ చేసి, దాని అడ్రస్ ని ఒక FILE* (ఫైల్ పాయింటర్) రూపంలో మీకు ఇస్తుంది. ఆ పాయింటర్ నే పట్టుకుని మీరు డేటా రాయడం, చదవడం చేస్తారు.

📝 రియల్ లైఫ్ స్టోరీ: లైబ్రరీలో బుక్ చదవడం (File Modes)

మీరు ఒక లైబ్రరీ కి వెళ్లి ఒక బుక్ అడిగినప్పుడు, లైబ్రేరియన్ (Operating System) మిమ్మల్ని ఒక ప్రశ్న అడుగుతుంది: "బాబు, నువ్వు ఈ బుక్ ఎందుకు తీసుకుంటున్నావ్?"

Read Mode ("r"): "నేను కేవలం చదువుతాను, పెన్ తో ఏమీ రాయను" (రీడ్ మోడ్). ఒకవేళ ఆ బుక్ లేకపోతే ఎర్రర్ ఇస్తుంది.
Write Mode ("w"): "నేను ఒక కొత్త బుక్ రాస్తాను." (ఒకవేళ పాత బుక్ ఉంటే, దాన్ని చింపేసి / డిలీట్ చేసి కొత్త పేజీలు ఇస్తుంది! ఇది కొంచెం డేంజర్).
Append Mode ("a"): "ముందు ఉన్న బుక్ ని డిలీట్ చేయొద్దు, దానికి చివర్లో నా స్టోరీ కంటిన్యూ చేస్తాను" (యాడ్ చేయడం).

ఈ మోడ్స్ బట్టి ఫైల్ సేఫ్ గా ఉంటుందా, డిలీట్ అవుతుందా అనేది డిసైడ్ అవుతుంది.

2 ఫైల్ లోపల రాయడం మరియు చదవడం

మనం కన్సోల్ (స్క్రీన్) మీద ప్రింట్ చేయడానికి printf వాడతాం కదా. ఫైల్ లోపలికి ప్రింట్ చేయడానికి సింపుల్ గా దానికి ముందు ఒక 'f' తగిలించి fprintf(filePointer, "text") అని వాడతాం!

అలాగే చదవడానికి scanf బదులు fscanf() లేదా fgets() వాడతాం. fgets అనేది ఒకేసారి ఒక లైన్ మొత్తాన్ని సేఫ్ గా చదువుతుంది (బెస్ట్ ఆప్షన్). ఫైల్ అంతా చదివేసాక చివరకి వచ్చేసరికి EOF (End Of File) అనే సిగ్నల్ వస్తుంది, అప్పుడు మనం చదవడం ఆపేయాలి.

3 ఒకే ఒక సింపుల్ కోడ్ (Text File I/O)

కింద కోడ్ లో ఒక ఫైల్ క్రియేట్ చేసి అందులో రెండు లైన్ల డేటా ఎలా రాశామో (Write), ఆ తర్వాత మళ్ళీ అదే ఫైల్ ఓపెన్ చేసి లైన్ బై లైన్ ఎలా చదివామో (Read) ఒకే కోడ్ లో చూడండి.

C — File Handling (Text Mode) ▶ Run Code 
#include <stdio.h>
#include <stdlib.h>

int main() {
    // ------------------------------------
    // 1. ఫైల్ లో రాయడం (Write Mode 'w')
    // ------------------------------------
    // my_diary.txt ని రైట్ మోడ్ లో అడుగుతున్నాం
    FILE* filePtr = fopen("my_diary.txt", "w");
    
    // ఒకవేళ హార్డ్ డిస్క్ ఫుల్ అయితే ఫైల్ ఓపెన్ అవ్వదు!
    if (filePtr == NULL) {
        printf("Error: ఫైల్ క్రియేట్ అవ్వలేదు!\n");
        return 1;
    }
    
    // ఫైల్ లోపలికి ప్రింట్ చేస్తున్నాం (fprintf)
    fprintf(filePtr, "Hello, this is my first file!\n");
    fprintf(filePtr, "C Language file handling is awesome.\n");
    
    // పని అయ్యాక కచ్చితంగా క్లోజ్ చేయాలి (లేకపోతే డేటా సేవ్ అవ్వదు)
    fclose(filePtr);
    printf("[+] ఫైల్ లోకి డేటా సక్సెస్ గా రాసాము.\n\n");
    
    // ------------------------------------
    // 2. ఫైల్ ని చదవడం (Read Mode 'r')
    // ------------------------------------
    filePtr = fopen("my_diary.txt", "r"); // ఇప్పుడు రీడ్ మోడ్
    
    if (filePtr == NULL) {
        printf("Error: ఫైల్ దొరకలేదు!\n");
        return 1;
    }
    
    char buffer[100]; // చదివిన డేటా దాచుకోవడానికి ఒక బాక్స్
    
    printf("--- ఫైల్ లోపల ఉన్న డేటా ---\n");
    // fgets వాడి లైన్ బై లైన్ (max 100 chars) చదువుతున్నాం
    // ఫైల్ చివరకి (NULL) వచ్చేదాకా ఈ లూప్ తిరుగుతుంది
    while (fgets(buffer, sizeof(buffer), filePtr) != NULL) {
        printf("%s", buffer); // చదివింది స్క్రీన్ పై ప్రింట్ చేయడం
    }
    printf("---------------------------\n");
    
    // చదవడం అయ్యాక క్లోజ్ చేయాలి
    fclose(filePtr);
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • fopen("my_diary.txt", "w"): విండోస్ ఈ పేరుతో ఒక టెక్స్ట్ ఫైల్ క్రియేట్ చేస్తుంది (మీ C ప్రోగ్రామ్ ఏ ఫోల్డర్ లో ఉందో అక్కడే వస్తుంది). దానికి ఒక అడ్రస్ ఇస్తుంది.
  • fclose(filePtr): మీరు ఫైల్ లో రైట్ చేసిన డేటా వెంటనే హార్డ్ డిస్క్ కి వెళ్ళదు, RAM లో ఉన్న బఫర్ లో వెయిట్ చేస్తుంది. మీరు fclose() అని పిలిస్తేనే, OS ఆ బఫర్ లో ఉన్నదాన్ని తీసుకెళ్లి ఫైల్ లో ముద్రించి, లాక్ చేస్తుంది. ఇది మర్చిపోతే సగం డేటా మాయం అవుతుంది!
  • fgets(buffer, 100, filePtr): ఇది చాలా సేఫ్ ఫంక్షన్. ఫైల్ లోపలికి వెళ్లి గరిష్టంగా 100 అక్షరాలు లేదా ఒక 'ఎంటర్' (newline) వచ్చేదాకా చదివి, దాన్ని మన buffer అనే అర్రే లోకి కాపీ చేస్తుంది. ఆ అర్రే ని మనం ప్రింట్ చేస్తున్నాం.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: ఫైల్ మోడ్స్ లో "r+", "w+", "a+" అంటే ఏంటి?

ప్లస్ (+) ఉంటే రెండు పనులూ చేయొచ్చు అని అర్థం. "r+" అంటే రీడ్ అండ్ రైట్ (ఉన్న ఫైల్ డిలీట్ అవ్వదు). "w+" అంటే రైట్ అండ్ రీడ్ (కానీ పాత ఫైల్ ఉంటే దాన్ని పీకేసి కొత్తది ఇస్తుంది). "a+" అంటే చివర్లో యాడ్ చేయొచ్చు, ఎక్కడైనా చదవొచ్చు. చాలా కేర్ఫుల్ గా వీటిని వాడాలి.

Q2: fscanf() ఎందుకు వాడకూడదు అంటారు?

fscanf అనేది scanf లాగానే స్పేస్ (Space) రాగానే చదవడం ఆపేస్తుంది. అంటే ఒక ఫైల్ లో "Hello World" అని ఉంటే, అది కేవలం "Hello" మాత్రమే చదివి ఆగిపోతుంది. మనకు సాధారణంగా ఒక లైన్ మొత్తం చదవాలి కాబట్టి ఎప్పుడూ fgets() వాడటమే ప్రొఫెషనల్ పద్ధతి.

Q3: ఫైల్ పేరు "C:\data\file.txt" అని ఇస్తే ఫెయిల్ అవుతుందా?

సాధారణంగా అవుతుంది! C లాంగ్వేజ్ స్ట్రింగ్స్ లో సింగిల్ స్లాష్ \ అనేది ఎస్కేప్ క్యారెక్టర్ (ఉదా: \n, \t). కాబట్టి మీరు విండోస్ పాత్ ఇవ్వాలంటే ఖచ్చితంగా డబుల్ స్లాషెస్ వాడాలి. అంటే "C:\\data\\file.txt" లాగా ఇస్తేనే సిస్టమ్ కి పాత్ కరెక్ట్ గా అర్థమవుతుంది. లేదంటే లైనక్స్ లాగా ఫార్వర్డ్ స్లాష్ "C:/data/file.txt" వాడినా పనిచేస్తుంది.
