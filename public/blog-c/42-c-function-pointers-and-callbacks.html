Function Pointers & Callbacks (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 42 📂 Phase 15: Advanced Pointers 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Function Pointers Syntax · Callbacks · Array of Functions · Plugins Architecture

ఇప్పటిదాకా పాయింటర్స్ అంటే కేవలం డేటా (int, char, struct) ని మాత్రమే పాయింట్ చేస్తాయి అనుకున్నాం. కానీ మీ ప్రోగ్రామ్ రన్ అయ్యేటప్పుడు, మీరు రాసిన ఫంక్షన్ కోడ్ అంతా (Instructions) కూడా RAM లో ఒక చోట స్టోర్ అవుతుంది. అంటే ఒక ఫంక్షన్ కి కూడా అడ్రస్ ఉంటుంది! ఆ అడ్రస్ ని పట్టుకునే స్పెషల్ పాయింటర్ నే Function Pointer (ఫంక్షన్ పాయింటర్) అంటారు. దీనివల్ల ఒక ఫంక్షన్ ని ఇంకో ఫంక్షన్ కి వేరియబుల్ లాగా పాస్ చేయొచ్చు. దీన్నే Callbacks అంటారు. ఈ కాన్సెప్ట్ వల్లే జావాస్క్రిప్ట్, C++ పుట్టాయి! ఇదేంటో డీప్ గా పోస్ట్‌మార్టం చేద్దాం.

1 ఫంక్షన్ పాయింటర్ సింటాక్స్ (కొంచెం భయపెడుతుంది!)

సింటాక్స్ చూడటానికి కొంచెం గందరగోళంగా ఉంటుంది: రిటర్న్_టైప్ (*పాయింటర్_పేరు) (ఆర్గుమెంట్స్);

ఉదాహరణకు: int (*mathOp)(int, int);
ఇది mathOp అనే పాయింటర్. ఇది ఏ ఫంక్షన్ నైనా పాయింట్ చేయగలదు, కానీ ఆ ఫంక్షన్ కచ్చితంగా రెండు ఇంటీజర్స్ తీసుకుని, ఒక ఇంటీజర్ ని రిటర్న్ చేయాలి.

🎮 రియల్ లైఫ్ స్టోరీ: స్విగ్గీ డెలివరీ & కాల్‌బ్యాక్స్ (Callbacks)

మీరు స్విగ్గీ లో బిర్యాని ఆర్డర్ చేసారు (ఇదే మెయిన్ ఫంక్షన్). కానీ ఆర్డర్ రాగానే మీకు ఎలా తెలుస్తుంది? మీరు ఒక ఫోన్ నంబర్ ఇచ్చి "డెలివరీ అయ్యాక ఈ నంబర్ కి కాల్ చెయ్ బాసు" అని చెప్తారు (ఇదే మీ Callback Function).

అంటే స్విగ్గీ వాడికి ముందుగానే మీరేం చేస్తారో తెలీదు. ఆర్డర్ అవ్వగానే, మీరు ఇచ్చిన నంబర్ కి డైల్ చేస్తాడు (Calling the Pointer). ప్రోగ్రామింగ్ లో కూడా ఒక ఆపరేషన్ పూర్తయ్యాక, వేరే ఏదైనా లాజిక్ రన్ చేయాలంటే, ఆ సెకండ్ లాజిక్ తాలూకు అడ్రస్ ని ఫస్ట్ దానికి ఆర్గ్యుమెంట్ లాగా పంపుతారు. ఆపరేటింగ్ సిస్టమ్స్ లో బటన్ క్లిక్స్ (Events) అన్నీ ఇలానే పనిచేస్తాయి!

2 ఫంక్షన్స్ యొక్క అర్రే (Array of Functions)

మీరు ఒక క్యాలిక్యులేటర్ తయారు చేస్తున్నారు. అందులో +, -, *, / అని 4 ఆప్షన్స్ ఉన్నాయి. switch case రాసి 100 లైన్స్ రాసేబదులు, ఆ నాలుగు ఫంక్షన్స్ ని ఒక అర్రే లో పెట్టి operations[choice](10, 5) అని సింగిల్ లైన్ లో పని కానించేయొచ్చు! ఇది ఇండస్ట్రీలో వాడే సూపర్ ప్రొఫెషనల్ ట్రిక్.

3 ఒకే ఒక సింపుల్ కోడ్ (Callbacks in Action)

కింద కోడ్ లో రెండు వేరు వేరు ఫంక్షన్స్ ని, ఒకే ఫంక్షన్ పాయింటర్ వాడి ఎలా కాల్ చేసామో, దాన్ని ఇంకో ఫంక్షన్ కి ఎలా పంపామో క్లియర్ గా చూడండి.

C — Function Pointers & Callbacks ▶ Run Code 
#include <stdio.h>

// 1. రెండు సింపుల్ ఫంక్షన్స్ (రెండూ ఒకే సిగ్నేచర్ తో ఉన్నాయి)
int add(int a, int b) {
    return a + b;
}

int multiply(int a, int b) {
    return a * b;
}

// 2. ఒక ఫంక్షన్ ఇంకో ఫంక్షన్ ని ఆర్గ్యుమెంట్ గా తీసుకుంటుంది (Callback)
// లోపల ఆ పాయింటర్ ని (operation) అని పిలుస్తున్నాం
void executeTask(int x, int y, int (*operation)(int, int)) {
    printf("Processing Data...\n");
    // పాయింటర్ వాడి ఆ ఫంక్షన్ ని కాల్ చేస్తున్నాం!
    int result = operation(x, y); 
    printf("Result is: %d\n\n", result);
}

int main() {
    printf("--- Function Pointers Demo ---\n");
    
    // డైరెక్ట్ గా పాయింటర్ క్రియేట్ చేయడం
    int (*ptr)(int, int) = add; 
    
    // పాయింటర్ ద్వారా యాడ్ ని పిలవడం
    printf("Direct Pointer Call: %d\n\n", ptr(10, 20)); // అవుట్పుట్: 30
    
    // ఇప్పుడు అసలు మ్యాజిక్: పాయింటర్స్ ని పాస్ చేయడం (Callbacks)
    printf("Passing 'add' function:\n");
    executeTask(5, 5, add); // పేరే అడ్రస్! బ్రాకెట్స్ పెట్టకూడదు
    
    printf("Passing 'multiply' function:\n");
    executeTask(5, 5, multiply); 
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • int (*ptr)(int, int) = add;: C లాంగ్వేజ్ లో ఫంక్షన్ పేరు (పక్కన బ్రాకెట్లు లేకుండా రాస్తే) అది కచ్చితంగా ఆ ఫంక్షన్ ఉన్న మెమరీ అడ్రస్ నే ఇస్తుంది. (అర్రే పేరు లాగానే!). అందుకే డైరెక్ట్ గా = add అని రాసాము.
  • executeTask(5, 5, add): ఫంక్షన్ ని పాస్ చేస్తున్నాము. లోపల అది ఏ లాజిక్ రన్ చేయాలో ముందుగానే ఫిక్స్ చేయలేదు. మనం పాస్ చేసిన దాన్ని బట్టి డైనమిక్ గా మారిపోతుంది. దీన్నే Polymorphism (పాలిమార్ఫిజం) లాంటిది అని చెప్పొచ్చు.
  • operation(x, y): మన దగ్గర ఉన్నది జస్ట్ అడ్రస్. దానికి పక్కన బ్రాకెట్స్ పెడితే, అది ఆ అడ్రస్ లో ఉన్న కోడ్ ని రన్ చేసి రిజల్ట్ ఇస్తుంది.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: ఫంక్షన్ పాయింటర్ ని qsort() లాంటి ఇన్-బిల్ట్ ఫంక్షన్స్ కి ఎలా వాడతారు?

చాలా ఇంపార్టెంట్ ప్రశ్న! C లో qsort కి మీరు ఒక అర్రే ని ఇస్తే అది సార్ట్ చేస్తుంది. కానీ ఆ నంబర్స్ ని అసెండింగ్ లో చేయాలా, డిసెండింగ్ లో చేయాలా అని దానికి తెలీదు. అందుకే మీరు ఒక compare() అనే ఫంక్షన్ రాసి దాన్ని qsort కి ఆర్గ్యుమెంట్ లాగా (Callback) పాస్ చేస్తారు. అప్పుడు అది మీ లాజిక్ వాడి సార్ట్ చేస్తుంది.

Q2: ప్లగిన్స్ (Plugins) ని ఫంక్షన్ పాయింటర్స్ తో ఎలా రాస్తారు?

ఒక మీడియా ప్లేయర్ (VLC) ఉంది. దానికి రేపు ఎవరైనా కొత్త MP4 కొడెక్ (Codec) రాస్తే, ఆ ఫైల్స్ ని (DLL/SO) లోడ్ చేసి, అందులో ఉన్న ఫంక్షన్స్ అడ్రస్ లని ఫంక్షన్ పాయింటర్స్ తో పట్టుకుని రన్ చేస్తారు. అంటే అసలు యాప్ కోడ్ ని మార్చకుండానే కొత్త ఫీచర్స్ డైనమిక్ గా ఇంజెక్ట్ చేయొచ్చు. ఇదే ప్లగిన్ ఆర్కిటెక్చర్ బేసిక్ సీక్రెట్!

Q3: typedef వాడి ఫంక్షన్ పాయింటర్ సింటాక్స్ ని సింపుల్ చేయొచ్చా?

ఖచ్చితంగా! ప్రతిసారి అంత పెద్ద సింటాక్స్ రాయడం కష్టం కాబట్టి, typedef int (*MathFunc)(int, int); అని పైన రాసుకుంటే... ఇకపై కింద సింపుల్ గా MathFunc ptr = add; అని నార్మల్ వేరియబుల్ లాగా చాలా నీట్ గా వాడుకోవచ్చు.
