Break & Continue in C Loops (తెలుగులో డీప్ ఎక్స్‌ప్లనేషన్)

⚡ C (C17 / C23 Standard) 🟢 Lesson 9 📂 Phase 05: Loops & Iterations 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Break స్టేట్‌మెంట్ · Continue కీవర్డ్ · రియల్ వరల్డ్ యూజ్ కేసులు

లూప్ స్టార్ట్ అయిన తర్వాత కండిషన్ ఫాల్స్ అయ్యేదాకా అది ఆగదు అని తెలుసుకున్నాం. కానీ రియల్ లైఫ్ లో ఒక పర్టికులర్ పరిస్థితి రాగానే మొత్తం లూప్ ని క్యాన్సిల్ చేయాల్సి రావచ్చు, లేదా ఆ ఒక్క రౌండ్ ని స్కిప్ చేయాల్సి రావచ్చు. ఇందుకోసం C లో break మరియు continue ఉన్నాయి.

1 Break అంటే ఎమర్జెన్సీ స్టాప్!

break అంటే బద్దలుకొట్టుకుని బయటకు రావడం. లూప్ రన్ అవుతున్నప్పుడు ఎక్కడైనా break; కనిపిస్తే, అప్పటి వరకు లూప్ లో ఏం జరుగుతున్నా సరే, లూప్ మొత్తాన్ని చంపేసి బయటకు వచ్చేస్తుంది.

🛑 రియల్ లైఫ్ స్టోరీ: దొంగల వేట

పోలీసులు ఒక వీధిలో 100 ఇళ్లలో దొంగ కోసం వెతుకుతున్నారు. ఇది 1 నుండి 100 వరకు ఉన్న లూప్ అనుకుందాం.

3వ ఇంట్లో దొంగ దొరికాడు. అప్పుడు మిగతా 97 ఇళ్లను కూడా వెతుకుతారా? వెతకరు కదా! దొంగ దొరికాడు కాబట్టి "ఆపరేషన్ break" చేసి వెళ్లిపోతారు. సెర్చ్ అల్గారిథమ్స్ లో ఇది చాలా ముఖ్యం.

2 ఒకే ఒక సింపుల్ కోడ్

కింద ఉన్న కోడ్ లో మనం ఒకేసారి రెండు కీవర్డ్స్ ని చూద్దాం. మనకు నచ్చని నంబర్ వస్తే continue తో వదిలేస్తాం, ఫైనల్ టార్గెట్ రాగానే break తో లూప్ ని ఆపేస్తాం. ఇంతే సింపుల్!

C — Break & Continue ▶ Run Code 
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 5; i++) {
        if (i == 2) {
            continue; // 2 ని స్కిప్ చెయ్
        }
        if (i == 4) {
            break; // 4 రాగానే మొత్తం ఆపేయ్
        }
        printf("Value: %d\n", i);
    }
    return 0;
}

పై కోడ్ లో 1 ప్రింట్ అవుతుంది. 2 స్కిప్ అవుతుంది (continue వల్ల). 3 ప్రింట్ అవుతుంది. 4 రాగానే break అవుతుంది కాబట్టి 5 అసలు చెక్ అవ్వదు. అవుట్పుట్ కేవలం 1 మరియు 3 మాత్రమే వస్తుంది!

3 ఫ్రీక్వెంట్ గా అడిగే ప్రశ్నలు (FAQ)

Q: Switch case లో వాడే break కి, loop లో వాడే break కి తేడా ఉందా?

రెండూ చేసే పని ఒకటే! తమ చుట్టూ ఉన్న స్ట్రక్చర్ (switch లేదా loop) లో నుండి బయటకు తీసుకురావడమే బ్రేక్ పని.

Q: నెస్టెడ్ లూప్స్ లో break వాడితే ఏమవుతుంది?

నెస్టెడ్ లూప్ లో break వాడితే, అది ఏ లూప్ లోపల ఉందో, కేవలం ఆ ఒక్క ఇన్నర్ లూప్ ని మాత్రమే ఆపుతుంది. బయట ఉన్న మెయిన్ లూప్ మళ్ళీ మామూలుగానే నడుస్తుంది.
