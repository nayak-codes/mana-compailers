Linked Lists - Insertion & Deletion (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 52 📂 Phase 18: Data Structures - 1 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Insert at Head · Insert at Tail · Insert at Position · Deletion · Memory Management (free)

లాస్ట్ లెసన్ లో మనం లింక్డ్ లిస్ట్ (ట్రైన్ డబ్బాలు) క్రియేట్ చేయడం నేర్చుకున్నాం కదా. కానీ ఒక ప్యాసింజర్ వచ్చి "నన్ను కరెక్ట్ గా రెండో డబ్బాకి, మూడో డబ్బాకి మధ్యలో ఎక్కించండి" అంటే ఎలా? ఆ చైన్ ని ఎలా విడదీసి మధ్యలో కొత్త బాక్స్ ని ఎలా Insert చేయాలో, అలాగే వద్దు అనుకున్న బాక్స్ ని Delete (free) చేసి చైన్ ని మళ్ళీ ఎలా అతకాలో ఈరోజు నేర్చుకుందాం. ఇంటర్వ్యూస్ లో వైట్ బోర్డ్ మీద కోడింగ్ అడిగే క్వశ్చన్స్ అన్నీ దీనిమీదనే ఉంటాయి!

1 ఇన్సర్షన్ టెక్నిక్ (చైన్ మార్చడం)

Insert at Beginning (ముందు యాడ్ చేయడం): కొత్త ఇంజిన్ వచ్చింది. సింపుల్ గా కొత్త డబ్బా చైన్ ని పాత ఇంజిన్ (హెడ్) కి కనెక్ట్ చేసి, హెడ్ అనే కిరీటాన్ని కొత్త దానికి ఇచ్చేయడమే!

🔗 రియల్ లైఫ్ స్టోరీ: మధ్యలో దూర్చడం (Insert at Position)

అనుకోండి A, B, C అనే ముగ్గురు వ్యక్తులు చేతులు పట్టుకుని నిలబడ్డారు (A->B->C). ఇప్పుడు కొత్తగా X అనేవాడు వచ్చి B మరియు C మధ్యలో దూరాలి.

అత్యంత డేంజరస్ రూల్: B తన చేయి వదిలేసి ముందు X ని పట్టుకోకూడదు! అలా వదిలేస్తే C ఎక్కడికి పోయాడో అడ్రస్ దొరకదు (మెమరీ లీక్). దానికి కరెక్ట్ పద్ధతి ఏంటంటే: ముందు X అనేవాడు తన చేత్తో C ని పట్టుకుంటాడు. ఆ తర్వాతే B తన పాత చేయి (C) ని వదిలేసి X ని పట్టుకుంటాడు! అంటే చైన్ తెగకుండా లింక్ మారుతుంది.
కోడ్ లో దీన్ని: newNode->next = temp->next; ఆ తర్వాత temp->next = newNode; అంటారు.

2 డిలీషన్ టెక్నిక్ (చైన్ అతకడం)

మధ్యలో B అనే డబ్బాని తీసేయాలి. అప్పుడు A డబ్బా వాడికి, డైరెక్ట్ గా C అడ్రస్ ఇస్తే చాలు (A->next = B->next;). చైన్ అతుక్కుపోతుంది. కానీ ఆ తర్వాత కచ్చితంగా ఆ కట్ అయిన B డబ్బాని ఆపరేటింగ్ సిస్టమ్ కి తిరిగి ఇచ్చేయాలి (free(B)). లేదంటే మెమరీ లీక్ కన్ఫార్మ్!

3 ఒకే ఒక సింపుల్ కోడ్ (Insert at Front & End)

కింద కోడ్ లో హెడ్ ద్వారా ముందు, వెనక నోడ్స్ ని ఎలా డైనమిక్ గా ఇన్సర్ట్ చేసామో ఒక ప్రొఫెషనల్ పద్ధతిలో రాసిన ఫంక్షన్స్ ని చూడండి. డబుల్ పాయింటర్స్ (**) ఎందుకు వాడుతున్నామో గమనించండి!

C — Insert at Head & Tail ▶ Run Code 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node* next;
};

// 1. ముందు యాడ్ చేయడం (Insert at Head)
// హెడ్ అడ్రస్ ని మార్చాలి కాబట్టి (**) డబుల్ పాయింటర్ తీసుకుంటున్నాం
void push(struct Node** head_ref, int new_data) {
    // కొత్త బాక్స్ క్రియేట్ చేద్దాం
    struct Node* new_node = (struct Node*)malloc(sizeof(struct Node));
    new_node->data = new_data;
    
    // కొత్త దాని చైన్ ని పాత హెడ్ కి ఇద్దాం
    new_node->next = *head_ref;
    
    // ఇప్పుడు కొత్త బాక్స్ ని హెడ్ కింద మారుద్దాం!
    *head_ref = new_node;
}

// 2. చివర్లో యాడ్ చేయడం (Insert at Tail)
void append(struct Node** head_ref, int new_data) {
    struct Node* new_node = (struct Node*)malloc(sizeof(struct Node));
    struct Node* last = *head_ref;
    
    new_node->data = new_data;
    new_node->next = NULL; // ఇది లాస్ట్ కాబట్టి NULL
    
    // ఒకవేళ లిస్ట్ పూర్తిగా ఖాళీగా ఉంటే... ఇదే ఫస్ట్ (హెడ్) అవుతుంది
    if (*head_ref == NULL) {
        *head_ref = new_node;
        return;
    }
    
    // ఖాళీ లేకపోతే, నడుచుకుంటూ లాస్ట్ డబ్బా దాకా వెతుకుదాం
    while (last->next != NULL) {
        last = last->next;
    }
    
    // లాస్ట్ డబ్బా దొరికింది! దానికి ఈ కొత్త డబ్బాని చైన్ వేద్దాం
    last->next = new_node;
}

// లిస్ట్ ప్రింట్ చేసే ఫంక్షన్
void printList(struct Node* node) {
    while (node != NULL) {
        printf("%d -> ", node->data);
        node = node->next;
    }
    printf("NULL\n");
}

int main() {
    // లిస్ట్ మొదట్లో ఖాళీగా ఉంది (హెడ్ లేదు)
    struct Node* head = NULL;
    
    printf("--- Linked List Insertion ---\n\n");
    
    // చివర్లో 10 యాడ్ చేద్దాం (ఖాళీ కాబట్టి ఇదే హెడ్ అవుతుంది)
    append(&head, 10);
    
    // ముందు 5 యాడ్ చేద్దాం (5 -> 10)
    push(&head, 5);
    
    // చివర్లో 20 యాడ్ చేద్దాం (5 -> 10 -> 20)
    append(&head, 20);
    
    // ముందు 1 యాడ్ చేద్దాం (1 -> 5 -> 10 -> 20)
    push(&head, 1);
    
    printf("Final List is:\n");
    printList(head);
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • struct Node** head_ref: ఇది చాలా మందికి కన్ఫ్యూజ్ అవుతుంది! మనం ఒక ఫంక్షన్ ద్వారా మెయిన్ లో ఉన్న head పాయింటర్ వేల్యూ ని మార్చాలి (అంటే ఒక బాక్స్ ని హెడ్ కింద డిక్లేర్ చేయాలి). పాయింటర్ వాల్యూ ని ఫంక్షన్ లో మార్చాలంటే దాని అడ్రస్ ని (అంటే డబుల్ పాయింటర్) పంపాలి అని మనం పాత లెసన్స్ లో నేర్చుకున్నాం!
  • *head_ref = new_node;: పాత ఇంజిన్ పోయి, కొత్తగా వచ్చిన new_node కి హెడ్ (కిరీటం) దక్కింది.
  • while (last->next != NULL): అపెండ్ (Append) చేసేటప్పుడు, మనకు లాస్ట్ డబ్బా అడ్రస్ డైరెక్ట్ గా తెలీదు. కాబట్టి ఫస్ట్ నుండి ఒకటొకటి చెక్ చేసుకుంటూ వెళ్లి కరెక్ట్ గా లాస్ట్ డబ్బా దగ్గర ఆగి (నెక్స్ట్ చైన్ 0 అవ్వగానే) దానికి లింక్ కనెక్ట్ చేసాము (O(N) time).
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: Append చేయడానికి ఎప్పుడూ O(N) టైమ్ పడుతుందా? ఫాస్ట్ చేయలేమా?

సపోజ్ మీ దగ్గర లక్ష డబ్బాలు ఉంటే, చివర్లో ఇంకో డబ్బా యాడ్ చేయడానికి ప్రతిసారి మొదటి నుండి లక్ష సార్లు నడుచుకుంటూ వెళ్ళాలి. ఇది చాలా స్లో! దీన్ని సాల్వ్ చేయడానికి ప్రోగ్రామర్స్ head తో పాటు, లాస్ట్ డబ్బా అడ్రస్ ని పట్టుకునే tail అనే ఇంకో పాయింటర్ ని కూడా మెయింటైన్ చేస్తారు. దానివల్ల సెకనులో లాస్ట్ కి కనెక్ట్ చేయొచ్చు (O(1)).

Q2: Head ని డిలీట్ చేయాలంటే ఎలా?

సింపుల్! హెడ్ కి కిరీటం తీసేసి, దాని నెక్స్ట్ ఉన్న డబ్బాకి కిరీటం పెడతాం. (*head = (*head)->next;). కానీ ఆ పాత హెడ్ ని మర్చిపోకుండా ఒక టెంపరరీ పాయింటర్ లో పట్టుకుని free(temp) చేయాలి, లేదంటే అది గాలిలో అలాగే ఉండిపోయి మెమరీ లీక్ అవుతుంది.

Q3: Garbage Collector ఉన్న లాంగ్వేజెస్ లో ఇదంతా చేయాలా?

జావా (Java) లేదా పైథాన్ (Python) లో మీరు free() చేయక్కర్లేదు. మీరు ఒక లింక్ ని కట్ చేస్తే (అంటే అడ్రస్ ని నల్ చేస్తే), ఆ కట్ అయిపోయిన డబ్బా దగ్గరికి బ్యాక్ గ్రౌండ్ లో గార్బేజ్ కలెక్టర్ వచ్చి దానంతట అదే క్లీన్ చేసేస్తుంది. కానీ C లో మీరే దేవుడు కాబట్టి అంతా మీరే మ్యాన్యువల్ గా డిలీట్ చేయాలి.
