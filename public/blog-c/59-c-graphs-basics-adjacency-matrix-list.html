Graphs (Adjacency Matrix & List) (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 59 📂 Phase 19: Data Structures - 2 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Nodes & Edges · Directed vs Undirected · Adjacency Matrix · Adjacency List

డేటా స్ట్రక్చర్స్ లో అత్యంత కాంప్లెక్స్ మరియు రియల్ లైఫ్ లో అత్యంత ఎక్కువగా వాడే కాన్సెప్ట్ Graphs (గ్రాఫ్స్). ఫేస్బుక్ లో ఫ్రెండ్స్ నెట్వర్క్ అయినా, గూగుల్ మ్యాప్స్ లో ట్రాఫిక్ దారులు అయినా అన్నీ ఈ గ్రాఫ్స్ మీదే పనిచేస్తాయి! ట్రీ (Tree) లో కేవలం పైనుండి కిందికే (Parent-Child) లింక్స్ ఉంటాయి. కానీ గ్రాఫ్స్ లో ఎవరైనా ఎవరికైనా కనెక్ట్ అవ్వచ్చు (లూప్స్ కూడా ఉంటాయి). అసలు దీన్ని C లాంగ్వేజ్ లో ఎలా మెమరీ లో స్టోర్ చేయాలో (Adjacency Matrix వర్సెస్ Adjacency List) ఈరోజు డీప్ గా పోస్ట్‌మార్టం చేద్దాం.

1 గ్రాఫ్స్ (Graphs) అంటే ఏంటి? (Vertices & Edges)

గ్రాఫ్ లో రెండు మెయిన్ పార్ట్స్ ఉంటాయి:
1. Vertices (నోడ్స్/సిటీస్): అంటే ఒక మనిషి లేదా ఒక సిటీ (ఉదా: హైదరాబాద్, బెంగళూరు).
2. Edges (లింక్స్/రోడ్లు): అంటే ఆ రెండు సిటీస్ మధ్య ఉన్న దారి. ఈ దారి వన్-వే (Directed) ఉండొచ్చు, లేదా టూ-వే (Undirected) ఉండొచ్చు.

🌍 రియల్ లైఫ్ స్టోరీ: ఫేస్బుక్ (Facebook) వర్సెస్ ఇన్‌స్టాగ్రామ్ (Instagram)

Undirected Graph (ఫేస్బుక్): మీరు ఒకరికి ఫ్రెండ్ రిక్వెస్ట్ పంపి వాళ్ళు యాక్సెప్ట్ చేస్తే, వాడు మీకు ఫ్రెండ్, మీరు వాడికి ఫ్రెండ్! ఇద్దరి మధ్య టూ-వే (Two-way) కనెక్షన్ వస్తుంది. రోడ్డు కి రెండు వైపులా వెళ్ళొచ్చు.

Directed Graph (ఇన్‌స్టాగ్రామ్ / ట్విట్టర్): మీరు ఒక సెలబ్రిటీ ని ఫాలో (Follow) అవుతారు (అంటే మీ నుండి వాడికి వన్-వే కనెక్షన్ వెళ్ళింది). కానీ వాడు మిమ్మల్ని తిరిగి ఫాలో అవ్వాల్సిన రూల్ లేదు కదా! ఇది వన్-వే (One-way) రోడ్డు లాంటిది. గ్రాఫ్స్ లో దారిని (Arrow) బట్టి లాజిక్ మారిపోతుంది.

2 గ్రాఫ్ ని కంప్యూటర్ లో ఎలా దాచాలి? (2 Methods)

మనం డ్రాయింగ్ వేయడానికి బానే ఉంటుంది, కానీ కంపైలర్ కి ఆ రోడ్లు ఎలా చెప్పాలి?

  • 1. Adjacency Matrix (మ్యాట్రిక్స్): ఇదొక 2D Array (టేబుల్). అడ్డు వరుసలు, నిలువు వరుసలు వేసుకుని దారి ఉంటే 1 అని, లేకపోతే 0 అని నింపుతాం. చాలా ఫాస్ట్, కానీ ఖాళీ రోడ్లు లేకపోయినా మెమరీ ఎక్కువ తీసుకుంటుంది.
  • 2. Adjacency List (లిస్ట్): ప్రతి సిటీ కి ఒక లింక్డ్ లిస్ట్ (Linked List) క్రియేట్ చేసి, దానికి కనెక్ట్ అయిన ఊర్ల పేర్లు మాత్రమే ఆ చైన్ లో కనెక్ట్ చేస్తాం. ఇది రియల్ ప్రాజెక్ట్స్ లో బెస్ట్ పద్ధతి (మెమరీ సేవింగ్)!
3 ఒకే ఒక సింపుల్ కోడ్ (Adjacency Matrix Demo)

కింద కోడ్ లో ఒక 4 సిటీస్ (0, 1, 2, 3) తీసుకుని, వాటి మధ్య 2D Array వాడి రోడ్లు (1 or 0) ఎలా వేసామో చూడండి.

C — Graphs (Adjacency Matrix) ▶ Run Code 
#include <stdio.h>

#define V 4 // టోటల్ 4 సిటీస్ ఉన్నాయి (Vertices)

// గ్రాఫ్ కి మొదట్లో ఏ రోడ్లు లేవని (0) సెట్ చేసే ఫంక్షన్
void initGraph(int matrix[V][V]) {
    for (int i = 0; i < V; i++) {
        for (int j = 0; j < V; j++) {
            matrix[i][j] = 0;
        }
    }
}

// సిటీ 'src' నుండి సిటీ 'dest' కి రోడ్డు వేసే ఫంక్షన్
void addEdge(int matrix[V][V], int src, int dest) {
    // ఇది Undirected Graph (టూ-వే రోడ్డు)
    matrix[src][dest] = 1; // వెళ్ళడానికి దారి
    matrix[dest][src] = 1; // తిరిగి రావడానికి కూడా దారి (Facebook లాగా)
}

// మ్యాట్రిక్స్ టేబుల్ ని ప్రింట్ చేసే ఫంక్షన్
void printMatrix(int matrix[V][V]) {
    printf("   0 1 2 3\n");
    printf("   --------\n");
    for (int i = 0; i < V; i++) {
        printf("%d| ", i);
        for (int j = 0; j < V; j++) {
            printf("%d ", matrix[i][j]);
        }
        printf("\n");
    }
}

int main() {
    // 2D అర్రే నే మన గ్రాఫ్ (4x4 = 16 బాక్సులు)
    int graphMatrix[V][V];
    
    // మొదట అన్నీ జీరోస్ చేద్దాం
    initGraph(graphMatrix);
    
    printf("--- Facebook Friends Graph ---\n\n");
    // సిటీ 0: హైదరాబాద్
    // సిటీ 1: బెంగళూరు
    // సిటీ 2: ముంబై
    // సిటీ 3: ఢిల్లీ
    
    // రోడ్లు (Friends) వేద్దాం
    addEdge(graphMatrix, 0, 1); // 0 కి 1 ఫ్రెండ్
    addEdge(graphMatrix, 0, 2); // 0 కి 2 ఫ్రెండ్
    addEdge(graphMatrix, 1, 2); // 1 కి 2 కూడా ఫ్రెండ్ (Mutual!)
    addEdge(graphMatrix, 2, 3); // 2 కి 3 ఫ్రెండ్
    
    // ఫైనల్ రిపోర్ట్ ప్రింట్ చేద్దాం
    printf("Adjacency Matrix (1 means Connected):\n");
    printMatrix(graphMatrix);
    
    // ఒకవేళ 0 కి 3 కి కనెక్షన్ ఉందో లేదో వెతకాలంటే?
    printf("\nCheck: Are 0 and 3 friends? => %s\n", 
            (graphMatrix[0][3] == 1) ? "Yes" : "No");
            
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • matrix[src][dest] = 1;: అర్రే ఇండెక్స్ వాడటం వల్ల, ఒకరిద్దరు కనెక్ట్ అయ్యున్నారా లేదా అని చెక్ చేయడానికి కేవలం 1 సెకను (O(1)) పడుతుంది. ఇది దీని సూపర్ పవర్.
  • matrix[dest][src] = 1;: ఇది రాయకపోతే, కేవలం src నుండి dest కి వన్-వే రోడ్డు (Directed Graph) ఉన్నట్టు లెక్క. రెండు రాస్తే అది టూ-వే రోడ్డు అవుతుంది.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: ఫేస్బుక్ వాళ్లు Adjacency Matrix వాడతారా?

అస్సలు వాడరు! ఫేస్బుక్ లో 200 కోట్ల మంది యూజర్స్ (V = 2 బిలియన్) ఉన్నారు. ఒకవేళ 2D అర్రే క్రియేట్ చేయాలంటే (2 బిలియన్ x 2 బిలియన్) బాక్సులు మెమరీ కావాలి! ఆ అర్రే లో ఒక యూజర్ కి సగటున 500 మందే ఫ్రెండ్స్ ఉంటారు, మిగతా వందల కోట్ల బాక్సులు అన్నీ 0 తోనే నిండిపోయి దారుణంగా మెమరీ వేస్ట్ అవుతుంది. అందుకే వాళ్ళు Adjacency List వాడతారు.

Q2: Adjacency List అంటే ఏంటి? అది ఎలా బెటర్?

దీనిలో 200 కోట్ల మందికి కేవలం ఒకటే పెద్ద అర్రే తీసుకుంటారు. అందులో మీ బాక్స్ దగ్గర ఒక లింక్డ్ లిస్ట్ (Linked List) ని అటాచ్ చేస్తారు. మీకు ఎంతమంది ఫ్రెండ్స్ ఉంటే, ఆ చైన్ లో అన్ని డబ్బాలు మాత్రమే యాడ్ చేస్తారు. లేని వాళ్ళ కోసం 0 లు పెట్టాల్సిన పనేలేదు! మెమరీ సూపర్ సేవ్ అవుతుంది.

Q3: గ్రాఫ్ లో Weighted Edge అంటే ఏంటి?

గూగుల్ మ్యాప్స్ లో రెండు సిటీల మధ్య దారి ఉండటమే కాదు, ఆ దారి పొడవు ఎంత (కిలోమీటర్లు) లేదా ట్రాఫిక్ ఎంత అనేది కూడా ఉంటుంది కదా! ఆ వాల్యూ నే Weight అంటారు. అప్పుడు మ్యాట్రిక్స్ లో 1 బదులు డైరెక్ట్ గా ఆ వాల్యూ (ఉదా: 50 km) ని పెట్టి సార్టెస్ట్ పాత్ అల్గారిథమ్స్ (Dijkstra) రన్ చేస్తారు.
