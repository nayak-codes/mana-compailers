Multi-threading in C (pthreads basics) (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 50 📂 Phase 17: Advanced Concepts 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Concurrency vs Parallelism · pthreads Library · pthread_create() · pthread_join() · Multi-Core Usage

మామూలుగా మనం రాసే C ప్రోగ్రామ్స్ అన్నీ పైన లైన్ రన్ అయ్యాకే కింద లైన్ కి వెళ్తాయి (Single Threaded). అంటే మీరు ఒక పెద్ద ఫైల్ డౌన్లోడ్ చేస్తూ, అదే టైమ్ లో మ్యూజిక్ ప్లే చేయాలంటే కుదరదు! కానీ మన కంప్యూటర్ కి 8 కోర్స్ (Cores) ఉంటాయి కదా? వాటన్నిటినీ ఒకేసారి వాడుకుని ప్యారలల్ (Parallel) గా పనులు చేయించడాన్నే Multi-threading (మల్టీ-త్రెడ్డింగ్) అంటారు. విండోస్ మరియు లైనక్స్ లో <pthread.h> అనే లైబ్రరీ వాడి రెండు ఫంక్షన్స్ ని ఒకే సెకనులో ఎలా రన్ చేయాలో ఈరోజు డీప్ గా చూద్దాం.

1 త్రెడ్ (Thread) అంటే ఏంటి? (The Workers)

మీ ప్రోగ్రామ్ ని ఒక ఫ్యాక్టరీ (Process) అనుకోండి. ఫ్యాక్టరీలో పని చేసే వర్కర్స్ ని త్రెడ్స్ అంటారు. సింగిల్ త్రెడ్ అంటే ఒకే వర్కర్ మొత్తం పని అంతా ఒకడి తర్వాత ఒకటి చేయడం. మల్టీ-త్రెడ్డింగ్ అంటే నలుగురు వర్కర్స్ కి పనిని పంచడం, అందరూ ఒకేసారి (parallel గా) పని పూర్తి చేయడం.

⚡ రియల్ లైఫ్ స్టోరీ: హోటల్ వంటగది (Multi-threading vs Single-threading)

Single-threading: ఒక హోటల్ లో ఒకే చెఫ్ (Cook) ఉన్నాడు. వాడు ముందు బిర్యానీ చేసాడు (10 నిమిషాలు), ఆ తర్వాత ఫ్రైడ్ రైస్ చేసాడు (10 నిమిషాలు), ఆ తర్వాత సూప్ చేసాడు (5 నిమిషాలు). మొత్తం 25 నిమిషాలు పట్టింది. ఇది పాత కాలం C ప్రోగ్రామింగ్.

Multi-threading: ఇప్పుడు ముగ్గురు చెఫ్ లు ఉన్నారు. ముగ్గురు ఒకేసారి స్టార్ట్ చేసారు. బిర్యానీ అవ్వడానికి 10 నిమిషాలు పట్టింది. ఆ టైమ్ లోపే ఫ్రైడ్ రైస్, సూప్ కూడా అయిపోయాయి! అంటే టోటల్ టైమ్ కేవలం 10 నిమిషాలే! CPU కోర్స్ ని ఇలా ఎఫెక్టివ్ గా వాడటానికి pthread_create() అద్భుతంగా పనిచేస్తుంది.

2 Pthreads సింటాక్స్ (ఎలా వాడుతారు?)

1. pthread_create(): ఇది కొత్త వర్కర్ ని (Thread) నిద్రలేపుతుంది. మీరు ఏ ఫంక్షన్ ని రన్ చేయాలో ఆ ఫంక్షన్ అడ్రస్ (Callback) దీనికి ఇవ్వాలి. ఫంక్షన్ బ్యాక్ గ్రౌండ్ లో రన్ అవ్వడం స్టార్ట్ అవుతుంది.
2. pthread_join(): ఇది చాలా ఇంపార్టెంట్! మీరు ముగ్గురు వర్కర్స్ ని పనికి పంపాక, బాస్ (మెయిన్ ఫంక్షన్) వాళ్ళు తిరిగొచ్చే దాకా వెయిట్ చేయాలి. వెయిట్ చేయకుండా ఫ్యాక్టరీ (యాప్) మూసేస్తే వర్కర్స్ కూడా చనిపోతారు! ఈ వెయిట్ చేసే లైనే join.

3 ఒకే ఒక సింపుల్ కోడ్ (Parallel Functions)

కింద కోడ్ లో టాస్క్ 1 మరియు టాస్క్ 2 ఒకదాని తర్వాత ఒకటి కాకుండా, ఒకేసారి (Parallel) ఎలా రన్ అవుతాయో సిమ్యులేట్ చేసాం చూడండి. (గమనిక: ఈ కోడ్ లైనక్స్ లో -lpthread ఫ్లాగ్ తో కంపైల్ చేయాలి, లేదా ఆన్లైన్ కంపైలర్స్ లో పని చేస్తుంది).

C — Multi-Threading (pthreads) ▶ Run Code 
#include <stdio.h>
#include <pthread.h> // త్రెడ్స్ కోసం హెడ్డర్
#include <unistd.h>  // sleep వాడటానికి (Linux)

// త్రెడ్ లో రన్ అయ్యే ఫంక్షన్ కచ్చితంగా (void *) తీసుకోవాలి
void* downloadFile(void* arg) {
    char* fileName = (char*)arg; // వచ్చిన ఆర్గుమెంట్ ని మార్చుకోవడం
    
    printf("[Thread] Downloading: %s started...\n", fileName);
    sleep(2); // 2 సెకన్లు టైమ్ పడుతుంది అనుకుందాం (Simulating delay)
    printf("[Thread] %s Download Complete!\n", fileName);
    
    return NULL;
}

int main() {
    printf("--- Multi-Threading Masterclass ---\n\n");
    
    // 1. త్రెడ్స్ ని పట్టుకోవడానికి రెండు ఐడీలు (IDs) కావాలి
    pthread_t thread1, thread2;
    
    // 2. రెండు త్రెడ్స్ ని ఒకే సెకనులో స్టార్ట్ చేద్దాం (Parallel)
    // (అడ్రస్, attributes, ఫంక్షన్ పేరు, దానికి పంపే డేటా)
    printf("[Main] Starting Task 1 & Task 2 simultaneously...\n");
    pthread_create(&thread1, NULL, downloadFile, "Movie.mp4");
    pthread_create(&thread2, NULL, downloadFile, "Song.mp3");
    
    // మెయిన్ ఫంక్షన్ కూడా తన పని తాను చేసుకుంటుంది
    printf("[Main] Boss is doing some other UI work...\n");
    
    // 3. ఆ రెండు త్రెడ్స్ పని పూర్తయ్యేదాకా (join అయ్యేదాకా) వెయిట్ చేయాలి
    pthread_join(thread1, NULL);
    pthread_join(thread2, NULL);
    
    // వాళ్ళు వచ్చేసాక యాప్ ఎండ్ అవుతుంది
    printf("\n[Main] All downloads finished. App closing.\n");
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • pthread_create(): ఇది కాల్ చేసిన మరుక్షణం మీ కోడ్ రెండు పాయలుగా విడిపోతుంది. ఒక పాయ (Thread) downloadFile ని రన్ చేసుకుంటూ వెళ్తుంది, ఒరిజినల్ మెయిన్ ఫంక్షన్ దాన్ని వదిలేసి కింద లైన్ కి వెళ్ళిపోతుంది. దీనివల్లే ప్యారలలిజం వస్తుంది.
  • void* (*start_routine)(void*): పీ-త్రెడ్స్ కి మనం పంపే ఫంక్షన్ ఎప్పుడూ కులం లేని void * డేటాని మాత్రమే తీసుకుంటుంది, అలాగే void * నే రిటర్న్ చేస్తుంది. అందుకే ఫంక్షన్ లోపల మనం మళ్ళీ దాన్ని (char*) కింద కన్వర్ట్ (Typecast) చేసుకున్నాం.
  • pthread_join(): మీరు ఇది రాయకపోతే, మెయిన్ ఫంక్షన్ వెంటనే ఎండ్ అయిపోయి, గేమ్ క్లోజ్ అయిపోతుంది. అప్పుడు బ్యాక్ గ్రౌండ్ లో డౌన్లోడ్ అవుతున్న మూవీ మధ్యలోనే చనిపోతుంది (Thread Cancellation). అందుకే బాస్ ఎప్పుడూ వర్కర్స్ కోసం వెయిట్ చేయాలి!
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: విండోస్ లో <pthread.h> పనిచేస్తుందా?

డైరెక్ట్ గా పనిచేయదు! pthreads అనేది POSIX (Linux/Mac) స్టాండర్డ్. విండోస్ లో నేటివ్ గా <windows.h> లో ఉండే CreateThread() ఫంక్షన్ వాడతారు. అయితే, MinGW కంపైలర్ వాడితే విండోస్ లో కూడా pthreads పనిచేసేలా వాళ్ళు ఒక పోర్ట్ (Port) రాసి ఉంచారు.

Q2: రెండు త్రెడ్స్ ఒకేసారి ఒకే వేరియబుల్ ని మారిస్తే ఏమవుతుంది? (Race Condition)

ఇది మల్టీ-త్రెడ్డింగ్ లో వచ్చే అత్యంత డేంజరస్ బగ్! ఇద్దరు ఒకేసారి ఒకే బ్యాంక్ అకౌంట్ లోకి డబ్బులు వేస్తే, అప్డేట్ అయ్యేటప్పుడు ఓవర్-రైట్ అయ్యి ఒకరి డబ్బులు మాయం అవుతాయి (Race Condition). దీన్ని ఆపడానికే Mutex (Locks) వాడతారు. ఒకరు వాడుతున్నప్పుడు ఇంకొకరికి తాళం వేస్తారు.

Q3: త్రెడ్స్ ఎక్కువ క్రియేట్ చేస్తే ఫాస్ట్ అయిపోతుందా? (1000 త్రెడ్స్ చేస్తే?)

అస్సలు అవ్వదు! మీ CPU కి 8 కోర్స్ ఉంటే, 8 త్రెడ్స్ మాత్రమే ఒకేసారి రియల్ గా (Parallel) రన్ అవుతాయి. మీరు 1000 త్రెడ్స్ క్రియేట్ చేస్తే, CPU ఒక్కోదానికి టైమ్ ఇస్తూ స్విచ్ (Context Switching) చేసుకోవడానికే దాని టైమ్ అంతా వేస్ట్ అవుతుంది. అప్పుడు యాప్ ఫాస్ట్ అవ్వకపోగా ఇంకా స్లో (ల్యాగ్) అవుతుంది!
