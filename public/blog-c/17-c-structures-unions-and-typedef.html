స్ట్రక్చర్స్ (struct), యూనియన్స్ (union) & typedef

⚡ Modern C (C99 / C11) 🟢 Chapter 17 of 20 📂 Phase 05: స్ట్రక్చర్స్, డైనమిక్ మెమరీ & ప్రాజెక్ట్ 📅 2026 Edition
📌 Covered in this chapter: హెటిరోజీనియస్ డేటా గ్రూపింగ్ · . డాట్ vs -> యారో ఆపరేటర్ · Memory Padding & Alignment · union షేర్డ్ మెమరీ
వాస్తవ ప్రపంచంలో సమాచారం కేవలం ఒకే రకమైన పూర్ణాంకాలు లేదా అక్షరాల రూపంలో ఉండదు. ఒక విద్యార్థి సమాచారంలో రోల్ నంబర్ (int), పేరు (char[]), మరియు మార్కులు (float) ఉంటాయి. అర్రేలు కేవలం ఒకే రకమైన హోమోజీనియస్ డేటాను మాత్రమే నిల్వ చేయగలవు. వేర్వేరు డేటా రకాలను ఒకే కస్టమ్ రికార్డుగా సమూహపరచడానికి C లో స్ట్రక్చర్స్ (struct), మెమరీ ఆదా చేసే యూనియన్స్ (union), మరియు టైప్ అలియాసింగ్ కోసం typedef ప్రాథమిక సాధనాలు.
1స్ట్రక్చర్స్ (struct) — హెటిరోజీనియస్ డేటా గ్రూపింగ్

స్ట్రక్చర్ (struct) అనేది విభిన్న డేటా రకాలకు చెందిన వేరియబుల్స్‌ను ఒకే పేరు కింద కలిపి ఒక కొత్త యూజర్-డిఫైన్డ్ డేటా టైప్‌ను సృష్టించే విధానం.

C — struct definition & dot operator ⚡ Try in C Compiler 
#include <stdio.h>
#include <string.h>

// స్ట్రక్చర్ డిక్లరేషన్ (బ్లూప్రింట్)
struct Student {
    int rollNo;
    char name[30];
    float marks;
}; // గమనిక: డిక్లరేషన్ చివర సెమికోలన్ తప్పనిసరి!

int main(void) {
    // స్ట్రక్చర్ వేరియబుల్ సృష్టి & ఇనీషియలైజేషన్
    struct Student s1;
    s1.rollNo = 101;
    strcpy(s1.name, "రమేష్");
    s1.marks = 94.5f;

    // డాట్ (.) ఆపరేటర్ ద్వారా మెంబర్స్ యాక్సెస్
    printf("రోల్ నంబర్ : %d\n", s1.rollNo);
    printf("విద్యార్థి పేరు : %s\n", s1.name);
    printf("మార్కులు      : %.2f\n", s1.marks);
    return 0;
}
2పాయింటర్లు & స్ట్రక్చర్స్ — యారో ఆపరేటర్ (->)

ఒక స్ట్రక్చర్ యొక్క మెమరీ అడ్రస్‌ను పాయింటర్‌లో నిల్వ చేసినప్పుడు, దానిలోని మెంబర్లను యాక్సెస్ చేయడానికి (*ptr).member అని రాయడం అసౌకర్యంగా ఉంటుంది. అందుకే C మనకు సూటిగా చదవగల యారో ఆపరేటర్ (->) ను అందించింది:

C — Arrow operator (->) demo ⚡ Try in C Compiler 
#include <stdio.h>

struct Point {
    int x;
    int y;
};

void updateCoordinates(struct Point *p, int newX, int newY) {
    // యారో ఆపరేటర్ ద్వారా పాయింటర్ మెంబర్లను మార్చడం
    p->x = newX;
    p->y = newY;
}

int main(void) {
    struct Point pt = {10, 20};
    printf("ప్రారంభంలో: x = %d, y = %d\n", pt.x, pt.y);

    updateCoordinates(&pt, 50, 80);
    printf("మార్చిన తర్వాత: x = %d, y = %d\n", pt.x, pt.y);
    return 0;
}
3మెమరీ ప్యాడింగ్ & స్ట్రక్చర్ అలైన్‌మెంట్ (Memory Padding)

ఇంటర్వ్యూలలో విద్యార్థులను ఆశ్చర్యపరిచే ఒక క్లాసికల్ ప్రశ్న:

struct Sample { char a; int b; }; // sizeof(struct Sample) ఎంత?

చాలామంది char 1 బైట్ + int 4 బైట్లు = 5 బైట్లు అని సమాధానం చెబుతారు. కానీ ఆధునిక 64-బిట్ కంపైలర్లపై ప్రింట్ చేసి చూస్తే ఫలితం 8 బైట్లు వస్తుంది!

⚙️ CPU వర్డ్ అలైన్‌మెంట్ రహస్యం:

ఆధునిక 32-బిట్ లేదా 64-బిట్ ప్రాసెసర్లు RAM నుండి డేటాను ఒక్కో బైట్ చొప్పున చదవవు. అవి 4 లేదా 8 బైట్ల గుణిజాలలో (Word Boundaries) చదివితేనే అత్యంత వేగంగా పనిచేస్తాయి. 4-బైట్ int ని బౌండరీలో పెట్టడానికి కంపైలర్ char పక్కన నిశ్శబ్దంగా 3 ఖాళీ బైట్లను (Padding Bytes) జోడిస్తుంది. మెమరీ అత్యంత కీలకమైన ఎంబెడెడ్ డివైస్‌లలో ఈ ప్యాడింగ్‌ను నిరోధించడానికి #pragma pack(1) వాడతారు.

4యూనియన్స్ (union) vs స్ట్రక్చర్స్ — షేర్డ్ మెమరీ మెకానిక్స్

struct తనలోని ప్రతి మెంబర్‌కు ప్రత్యేకమైన మెమరీ స్పేస్‌ను కేటాయిస్తుంది. కానీ యూనియన్ (union) తనలోని అన్ని మెంబర్లకు కలిపి కేవలం అతిపెద్ద మెంబర్ పరిమాణం గల ఒకే ఒక్క షేర్డ్ మెమరీ లొకేషన్‌ను ఇస్తుంది.

లక్షణం స్ట్రక్చర్ (struct) యూనియన్ (union)
మెమరీ సైజ్ అన్ని మెంబర్ల మొత్తం సైజ్ (+ ప్యాడింగ్) అతిపెద్ద మెంబర్ సైజ్ మాత్రమే
మెంబర్ల యాక్సెస్ ఒకేసారి అన్ని మెంబర్లను స్వతంత్రంగా వాడవచ్చు ఒకే సమయంలో ఒకే ఒక్క మెంబర్‌ను మాత్రమే వాడాలి
ప్రయోజనం సంపూర్ణ రికార్డులను నిల్వ చేయడానికి హార్డ్‌వేర్ రిజిస్టర్లు, తీవ్రమైన మెమరీ ఆదాకు
C — typedef for clean abstractions ⚡ Try in C Compiler 
#include <stdio.h>

// typedef ఉపయోగించి టైప్ అలియాస్ సృష్టించడం
typedef struct {
    unsigned int id;
    char code[8];
} Product;

int main(void) {
    // ప్రతిసారీ struct అని రాయకుండా నేరుగా Product అని వాడవచ్చు
    Product laptop = {1001, "LAP-X1"};
    printf("ప్రోడక్ట్ ID: %u | కోడ్: %s\n", laptop.id, laptop.code);
    return 0;
}
5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. struct క్లోజింగ్ బ్రేస్ తర్వాత సెమికోలన్ మర్చిపోవడం:
struct Node { int data; } // తప్పు! చివర సెమికోలన్ తప్పనిసరి C లో స్ట్రక్చర్ డిక్లరేషన్ ఒక స్టేట్‌మెంట్ లాంటిది. }; సెమికోలన్ పెట్టకపోతే కంపైలర్ విచిత్రమైన సింటాక్స్ ఎర్రర్లను ఇస్తుంది.
❌ 2. యూనియన్‌లో ఒక విలువ రాసి మరొకటి చదవడం:
యూనియన్‌లో u.x = 10; రాసిన తర్వాత u.y = 3.14; రాస్తే పాత x విలువ శాశ్వతంగా నాశనమైపోతుంది. యూనియన్ కేవలం షేర్డ్ మెమరీని మాత్రమే అందిస్తుంది.
6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: C లాంగ్వేజ్‌లో struct లోపల ఫంక్షన్లను రాయవచ్చా?

C++ లో లాగా నేరుగా ఫంక్షన్ బాడీలను రాయలేం. కానీ ఒక ఫంక్షన్ యొక్క మెమరీ అడ్రస్‌ను సూచించే ఫంక్షన్ పాయింటర్‌ను (Function Pointer) స్ట్రక్చర్ మెంబర్‌గా ఉంచి C లో కూడా ఆబ్జెక్ట్ ఓరియెంటెడ్ పద్ధతిని అనుకరించవచ్చు.

Q: ఒక స్ట్రక్చర్ వేరియబుల్‌ను మరొకదానికి నేరుగా s2 = s1 అని అసైన్ చేయవచ్చా?

చేయవచ్చు! అర్రేలకు భిన్నంగా, రెండు స్ట్రక్చర్లు ఒకే రకానికి చెందినవైతే s2 = s1; అని రాసినప్పుడు కంపైలర్ అన్ని మెంబర్ల విలువలను బైట్-బై-బైట్ (Shallow Copy) గా నకలు చేస్తుంది.
