ఫైల్ హ్యాండ్లింగ్ (, fopen, fclose, fprintf, fscanf, fread, fwrite)

⚡ Modern C (C99 / C11) 🟢 Chapter 19 of 20 📂 Phase 05: స్ట్రక్చర్స్, డైనమిక్ మెమరీ & ప్రాజెక్ట్ 📅 2026 Edition
📌 Covered in this chapter: టెక్స్ట్ vs బైనరీ ఫైల్స్ · r, w, a, rb, wb మోడ్స్ · FILE* పాయింటర్ · ఎర్రర్ హ్యాండ్లింగ్
కంప్యూటర్ RAM లోని సమాచారం అస్థిరమైనది (Volatile). విద్యుత్ ఆగిపోయినా లేదా ప్రోగ్రామ్ క్లోజ్ అయినా వేరియబుల్స్ లోని డేటా శాశ్వతంగా తుడిచిపెట్టుకుపోతుంది. నిజ జీవిత సాఫ్ట్‌వేర్‌లలో యూజర్ సమాచారం, లాగ్ ఫైల్స్ మరియు డేటాబేస్‌లను హార్డ్ డిస్క్ లేదా SSD పై శాశ్వతంగా భద్రపరచడానికి ఫైల్ హ్యాండ్లింగ్ (File Handling) అత్యంత కీలకమైన భాగం. ఈ అధ్యాయంలో టెక్స్ట్ vs బైనరీ మోడ్స్, FILE* పాయింటర్, మరియు స్ట్రక్చర్‌లను బైనరీ రూపంలో రాయడం నేర్చుకుందాం.
1FILE* పాయింటర్ & ఫైల్ మోడ్స్ (File Access Modes)

C స్టాండర్డ్ లైబ్రరీ <stdio.h> లో ఒక ఫైల్ స్ట్రీమ్‌ను నిర్వహించడానికి FILE అనే ప్రత్యేక స్ట్రక్చర్ మరియు దాన్ని సూచించే FILE* పాయింటర్ ఉంటుంది.

మోడ్ పనితీరు ఫైల్ లేకపోతే? ఫైల్ ఇప్పటికే ఉంటే?
"r" (Read) ఫైల్ చదవడానికి మాత్రమే ఓపెన్ చేస్తుంది NULL రిటర్న్ చేస్తుంది డేటా చెక్కుచెదరకుండా ఉంటుంది
"w" (Write) ఫైల్‌లో రాయడానికి ఓపెన్ చేస్తుంది కొత్త ఫైల్ క్రియేట్ అవుతుంది పాత డేటా మొత్తం తుడిచిపెట్టుకుపోతుంది!
"a" (Append) ఫైల్ చివర కొత్త డేటా కలపడానికి కొత్త ఫైల్ క్రియేట్ అవుతుంది చివర డేటా జోడించబడుతుంది
"rb", "wb" బైనరీ ఫైల్స్ (ఇమేజ్, వీడియో, స్ట్రక్చర్) బైనరీ మోడ్‌లో వర్తిస్తుంది ఎటువంటి న్యూలైన్ కన్వర్షన్ జరగదు
2టెక్స్ట్ ఫైల్స్: fprintf() & fscanf() లైవ్ డెమో

మానవులు చదవగలిగే సాధారణ టెక్స్ట్ ఫైల్స్‌లో డేటాను రాయడానికి fprintf() మరియు తిరిగి చదవడానికి fscanf() వాడతాం:

C — Text File Write and Read ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    // 1. ఫైల్‌లో రాయడం
    FILE *fp = fopen("server_log.txt", "w");
    if (fp == NULL) {
        printf("ఫైల్ ఓపెన్ చేయడం సాధ్యం కాలేదు!\n");
        return 1;
    }

    fprintf(fp, "ID:%d Name:%s Score:%.1f\n", 101, "క్రిష్", 95.5);
    fclose(fp); // ఫైల్ క్లోజ్ చేయడం వల్ల బఫర్ డిస్క్‌పై సేవ్ అవుతుంది

    // 2. ఫైల్ నుండి చదవడం
    fp = fopen("server_log.txt", "r");
    if (fp != NULL) {
        int id; char name[20]; float score;
        fscanf(fp, "ID:%d Name:%s Score:%f", &id, name, &score);
        printf("ఫైల్ నుండి చదివిన సమాచారం: %d | %s | %.1f\n", id, name, score);
        fclose(fp);
    }
    return 0;
}
3బైనరీ ఫైల్స్: fwrite() & fread() తో Struct పర్సిస్టెన్స్

టెక్స్ట్ ఫైల్స్‌లో సంఖ్యలను స్ట్రింగ్స్‌గా మార్చి రాయాలి. కానీ బైనరీ మోడ్‌లో మొత్తం స్ట్రక్చర్‌ను (RAM లో ఉన్న యథాతథ బైట్లను) ఒకే ఒక్క ఇన్‌స్ట్రక్షన్‌తో నేరుగా హార్డ్ డిస్క్‌పై రాయవచ్చు. ఇది అత్యంత వేగవంతమైన ప్రొడక్షన్ పద్ధతి:

C — Binary Struct I/O (fwrite & fread) ⚡ Try in C Compiler 
#include <stdio.h>

typedef struct {
    int id;
    char grade;
} Record;

int main(void) {
    Record out = {501, 'A'};
    Record in;

    // బైనరీ ఫైల్‌లో రాయడం
    FILE *fp = fopen("records.dat", "wb");
    if (fp != NULL) {
        fwrite(&out, sizeof(Record), 1, fp);
        fclose(fp);
    }

    // బైనరీ ఫైల్ నుండి చదవడం
    fp = fopen("records.dat", "rb");
    if (fp != NULL) {
        fread(&in, sizeof(Record), 1, fp);
        printf("బైనరీ రికార్డు: ID = %d, Grade = %c\n", in.id, in.grade);
        fclose(fp);
    }
    return 0;
}
4బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. NULL చెక్ చేయకుండా ఫైల్ చదవడానికి ప్రయత్నించడం:
FILE *fp = fopen("abc.txt", "r"); fscanf(fp, ...); // ఫైల్ లేకపోతే క్రాష్! ఫైల్ హార్డ్ డిస్క్‌లో లేకపోతే fopen NULL రిటర్న్ చేస్తుంది. NULL పాయింటర్‌ను పాస్ చేస్తే ప్రోగ్రామ్ తక్షణమే క్రాష్ అవుతుంది. ఎల్లప్పుడూ if (fp == NULL) తనిఖీ చేయాలి.
❌ 2. fclose() చేయడం మర్చిపోవడం:
C లో ఫైల్ ఆపరేషన్లు బఫర్ చేయబడతాయి. fclose(fp) పిలిచినప్పుడు మాత్రమే డేటా పూర్తిగా డిస్క్‌పై వ్రాయబడుతుంది (Flush). ఫైల్ క్లోజ్ చేయకపోతే డేటా సేవ్ కాకుండా నష్టపోయే ప్రమాదం ఉంది.
5తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: fseek() మరియు ftell() ఫంక్షన్లను ఎందుకు ఉపయోగిస్తారు?

fseek(fp, offset, SEEK_SET) ఫైల్ కర్సర్‌ను మనకు కావలసిన నిర్దిష్ట బైట్ స్థానానికి జంప్ చేయిస్తుంది (Random Access). ftell(fp) కర్సర్ ప్రస్తుతం ఏ బైట్ వద్ద ఉందో చెబుతుంది. ఉదాహరణకు ఫైల్ చివరకు వెళ్లి ftell పిలిస్తే ఆ ఫైల్ యొక్క మొత్తం సైజ్ క్షణాల్లో తెలుస్తుంది.

Q: టెక్స్ట్ మోడ్ మరియు బైనరీ మోడ్ మధ్య విండోస్‌లో న్యూలైన్ తేడా ఏమిటి?

విండోస్‌లో టెక్స్ట్ మోడ్ \n ను ఆటోమేటిక్‌గా \r\n (Carriage Return + Line Feed) గా మారుస్తుంది. కానీ బైనరీ మోడ్ ("rb"/"wb") ఎటువంటి అనువాదం చేయకుండా అసలైన రా బైట్లను మాత్రమే భద్రపరుస్తుంది.
