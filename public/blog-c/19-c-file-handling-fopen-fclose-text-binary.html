ఫైల్ హ్యాండ్లింగ్ (, fopen, fclose, fprintf, fscanf, fread, fwrite)

⚡ Modern C (C99 / C11) 🟢 Chapter 19 of 20 📂 Phase 05: స్ట్రక్చర్స్, డైనమిక్ మెమరీ & ప్రాజెక్ట్ 📅 2026 Edition
📌 Covered in this chapter: టెక్స్ట్ vs బైనరీ ఫైల్స్ · r, w, a, rb, wb మోడ్స్ · FILE* పాయింటర్ · ఎర్రర్ హ్యాండ్లింగ్
ప్రోగ్రామ్ ముగిసిన తర్వాత కూడా డేటా కంప్యూటర్ హార్డ్ డిస్క్‌లో శాశ్వతంగా ఉండటానికి ఫైల్ హ్యాండ్లింగ్ (File Handling) అవసరం. fopen(), fclose(), మరియు టెక్స్ట్ vs బైనరీ ఫైల్ ఆపరేషన్లను నేర్చుకుందాం.
1ఫైల్ లోకి డేటాను రాయడం (File Writing with fprintf)
C — File Writing ▶ Run in Compiler 
#include <stdio.h>

int main() {
    FILE* fp = fopen("records.txt", "w");
    if (fp == NULL) {
        printf("Error opening file!\n");
        return 1;
    }

    fprintf(fp, "Student ID: 101 | Grade: A+\n");
    fprintf(fp, "Student ID: 102 | Grade: O\n");

    fclose(fp); // ఫైల్ క్లోజ్ చేయడం తప్పనిసరి
    printf("Records saved successfully to records.txt! 💾\n");
    return 0;
}
