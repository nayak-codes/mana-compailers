లూప్స్ (for, while, do-while)

⚡ Modern C (C99 / C11) 🟢 Chapter 7 of 20 📂 Phase 02: కంట్రోల్ ఫ్లో & లూప్స్ 📅 2026 Edition
📌 Covered in this chapter: 4 దశల ఎగ్జిక్యూషన్ చక్రం · ఎంట్రీ vs ఎగ్జిట్ కంట్రోల్ తేడాలు · ఇన్ఫినిట్ లూప్స్ · ఆఫ్-బై-వన్ బగ్స్ నివారణ
కంప్యూటర్ల అసలైన బలం పునరావృత చర్యలను (Repetitive Tasks) క్షణాల్లో కోట్లాది సార్లు అలసట లేకుండా చేయగలగడమే. ఒకే పనిని మళ్లీ మళ్లీ చేయడానికి కోడ్‌ను డూప్లికేట్ చేయకుండా లూప్స్ (Loops) వాడతాం. C లోని మూడు ప్రధాన లూప్స్ — for, while, మరియు do-while ల 4-దశల ఎగ్జిక్యూషన్ లైఫ్‌సైకిల్, ఎంట్రీ vs ఎగ్జిట్ కంట్రోల్ తేడాలు, మరియు ఇన్ఫినిట్ లూప్స్ ప్రమాదాలను లోతుగా నేర్చుకుందాం.
1for లూప్ — 4-దశల ఎగ్జిక్యూషన్ లైఫ్‌సైకిల్

ఇటరేషన్ల సంఖ్య ముందే ఖచ్చితంగా తెలిసినప్పుడు (ఉదాహరణకు 1 నుండి 100 వరకు సంఖ్యలు లేదా అరే సైజ్) for లూప్ అత్యంత సౌకర్యవంతమైన సాధనం.

🔄 for లూప్ యొక్క 4-దశల చక్రం:

  1. ఇనీషియలైజేషన్ (Initialization): లూప్ ప్రారంభంలో ఒక్కసారి మాత్రమే రన్ అవుతుంది (ఉదా: int i = 0).
  2. కండిషన్ చెక్ (Condition Test): ప్రతి ఇటరేషన్‌కు ముందు పరీక్షించబడుతుంది (i < 5). నిజమైతే లోపలికి వెళ్తుంది; అబద్ధమైతే లూప్ ముగుస్తుంది.
  3. బాడీ ఎగ్జిక్యూషన్ (Body Execution): లూప్ కర్లీ బ్రేసెస్ లోపల ఉన్న స్టేట్‌మెంట్లు రన్ అవుతాయి.
  4. అప్‌డేట్ / ఇంక్రిమెంట్ (Update Step): బాడీ పూర్తయిన వెంటనే వేరియబుల్ అప్‌డేట్ అవుతుంది (i++). వెంటనే మళ్లీ స్టెప్ 2 కి వెళ్తుంది.
C — for loop execution ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int sum = 0;
    // 1 నుండి 10 వరకు సహజ సంఖ్యల మొత్తం లెక్కించడం
    for (int i = 1; i <= 10; i++) {
        sum += i;
    }
    printf("1 నుండి 10 సంఖ్యల మొత్తం = %d\n", sum);
    return 0;
}
2while లూప్ — ఈవెంట్-డ్రివెన్ & అన్‌నోన్ ఇటరేషన్లు

ఒక పని ఎన్నిసార్లు జరగాలో ముందే తెలియనప్పుడు, ఒక నిర్దిష్ట పరిస్థితి మారేంత వరకు (Event-driven condition) రన్ చేయడానికి while లూప్ వాడతాం.

ఇది ఎంట్రీ-కంట్రోల్డ్ లూప్ (Entry-Controlled Loop). అంటే లూప్ లోపలికి ప్రవేశించే ముందే కండిషన్ చెక్ అవుతుంది. ప్రారంభంలోనే కండిషన్ అబద్ధమైతే (False), లూప్ బాడీ జీరో సార్లు (ఒక్కసారి కూడా రన్ అవ్వదు).

C — while loop (Reversing a Number) ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int num = 12345;
    int reversed = 0;

    while (num != 0) {
        int remainder = num % 10;
        reversed = reversed * 10 + remainder;
        num /= 10; // వేరియబుల్‌ను తగ్గించడం — ఇది లేకపోతే ఇన్ఫినిట్ లూప్ అవుతుంది!
    }

    printf("తిరగేసిన సంఖ్య (Reversed): %d\n", reversed);
    return 0;
}
3do-while లూప్ — ఎగ్జిట్-కంట్రోల్డ్ గ్యారెంటీ

కండిషన్ మొదట్లోనే తప్పుగా ఉన్నప్పటికీ, కోడ్ బ్లాక్ కనీసం ఒక్కసారైనా (At least once) ఖచ్చితంగా రన్ కావాల్సిన పరిస్థితులలో do-while లూప్ వాడతాం.

ఇది ఎగ్జిట్-కంట్రోల్డ్ లూప్ (Exit-Controlled Loop). కోడ్ రన్ అయిన తర్వాత మాత్రమే చివరలో కండిషన్ చెక్ చేయబడుతుంది.

C — do-while menu repetition ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int choice;
    do {
        printf("\n--- బ్యాంకింగ్ మెనూ ---\n");
        printf("1. బ్యాలెన్స్ తనిఖీ\n");
        printf("2. నిష్క్రమణ (Exit)\n");
        printf("మీ ఎంపిక: ");
        scanf("%d", &choice);

        if (choice == 1) {
            printf("మీ బ్యాలెన్స్: ₹25,000\n");
        }
    } while (choice != 2); // గమనిక: do-while చివర సెమికోలన్ తప్పనిసరి!

    printf("ధన్యవాదాలు! ప్రోగ్రామ్ ముగిసింది.\n");
    return 0;
}
4ఇన్ఫినిట్ లూప్స్ & CPU హ్యాంగ్ ట్రాప్

ఒక లూప్ యొక్క కండిషన్ ఎప్పటికీ FALSE కాకపోతే, ఆ లూప్ అనంతంగా రన్ అవుతూ CPU వినియోగాన్ని 100% కి చేర్చి ప్రోగ్రామ్‌ను స్తంభింపజేస్తుంది (Freeze/Hang).

ప్రమాదవశాత్తు ఇన్ఫినిట్ లూప్:

int i = 0;
while (i < 10) {
  printf("%d", i);
  // i++ రాయడం మర్చిపోయారు!
}

ఉద్దేశపూర్వక సర్వర్/ఎంబెడెడ్ లూప్:

while (1) {
  // ఎంబెడెడ్ మైక్రోకంట్రోలర్ మెయిన్ లూప్
  poll_hardware_events();
}
5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. for లేదా while లూప్ హెడర్ చివర సెమికోలన్ పెట్టడం:
for (int i = 0; i < 10; i++); { printf("%d", i); } సెమికోలన్ పెట్టడం వల్ల ఖాళీ లూప్ 10 సార్లు రన్ అయిపోతుంది. లూప్ ముగిసిన తర్వాత మాత్రమే ప్రింట్ స్టేట్‌మెంట్ ఒకేసారి రన్ అవుతుంది!
❌ 2. Off-By-One Error (ఒకటి ఎక్కువ లేదా తక్కువ తిరగడం):
for (int i = 0; i <= 10; i++) // 10 సార్లు అనుకుని 11 సార్లు తిరుగుతుంది ఇండెక్స్ 0 నుండి మొదలైనప్పుడు < 10 రాస్తే 10 సార్లు తిరుగుతుంది. పొరపాటున <= 10 రాస్తే 11 సార్లు తిరిగి అర్రే బౌండరీని దాటిపోయే ప్రమాదం ఉంది.
6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: for (int i = 0; ...) లో డిక్లేర్ చేసిన 'i' వేరియబుల్ లూప్ బయట ప్రింట్ అవుతుందా?

ప్రింట్ కాదు! ఆధునిక C (C99/C11) ప్రమాణాల ప్రకారం for లూప్ హెడర్‌లో డిక్లేర్ చేసిన వేరియబుల్ యొక్క లైఫ్‌టైమ్ కేవలం ఆ లూప్ బాడీ వరకే పరిమితం (Block Scope). లూప్ బయట printf("%d", i) అని రాస్తే "undeclared identifier" ఎర్రర్ వస్తుంది.

Q: for(;;) మరియు while(1) లలో ఏది వేగవంతమైనది?

రెండూ సమానమైన వేగంతో పనిచేస్తాయి. ఆధునిక GCC/Clang కంపైలర్లు రెండింటికీ ఒకే విధమైన అన్‌కండిషనల్ అసెంబ్లీ జంప్ ఇన్‌స్ట్రక్షన్ (jmp) ను ఉత్పత్తి చేస్తాయి.
