2D Arrays & Matrices (తెలుగులో డీప్ ఎక్స్‌ప్లనేషన్)

⚡ C (C17 / C23 Standard) 🟢 Lesson 13 📂 Phase 07: Arrays & Memory Organization 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: 2D Array అంటే ఏంటి? · Rows మరియు Columns · Nested Loops

డేటా అంతా సింగిల్ లైన్ లో ఉండదు కదా. టైమ్‌టేబుల్ కానీ, థియేటర్ లోని సీట్లు కానీ అడ్డు వరుసలు (Rows) మరియు నిలువు వరుసలు (Columns) గా ఉంటాయి. ఆ విధంగా ఉండే డేటాని ప్రోగ్రామింగ్ లో స్టోర్ చేయడానికి వాడేదే 2D Arrays.

1 2D Array అంటే ఏమిటి?

ఒక 2D Array ని సింపుల్ గా "అర్రేస్ తో చేసిన అర్రే (Array of Arrays)" అని చెప్పొచ్చు. దీన్ని క్రియేట్ చేయడానికి మనం రెండు సైజులు ఇవ్వాలి: int matrix[3][4];

🎬 రియల్ లైఫ్ స్టోరీ: థియేటర్ సీట్లు

మీ సినిమా టికెట్ పైన "H-12" అని రాసి ఉంది.
"H" అనేది ఏ అడ్డు వరుస (Row) అని చెప్తుంది.
"12" అనేది ఆ వరుసలో ఏ సీట్ నంబర్ (Column) అని చెప్తుంది.

అంటే ఒక సీట్ ని కనిపెట్టాలంటే మనకు కచ్చితంగా రెండు నంబర్లు కావాలి. 2D అర్రే కూడా కరెక్ట్ గా ఇదే లాజిక్ తో పనిచేస్తుంది. డేటాని స్టోర్ చేయాలంటే [Row][Column] కావాలి.

2 ఒకే ఒక సింపుల్ కోడ్

మనం ఒకే ఒక చిన్న 2D అర్రే క్రియేట్ చేసి అందులో ఒక ఎలిమెంట్ ని ఎలా యాక్సెస్ చేయాలో కింద కోడ్ లో చూద్దాం. ఇది చాలా సింపుల్!

C — Simple 2D Array ▶ Run Code 
#include <stdio.h>

int main(void) {
    // 2 Rows, 2 Columns ఉన్న చిన్న గ్రిడ్
    int grid[2][2] = {
        {10, 20}, 
        {30, 40}
    };
    
    // మొదటి రో(0) లో రెండో కాలమ్(1) లో ఉన్న నంబర్
    printf("Value: %d\n", grid[0][1]); // 20 ప్రింట్ అవుతుంది
    return 0;
}
3 ఫ్రీక్వెంట్ గా అడిగే ప్రశ్నలు (FAQ)

Q: కంప్యూటర్ RAM లో 2D Array గ్రిడ్ లాగే ఉంటుందా?

లేదు! కంప్యూటర్ RAM అదొక పెద్ద స్ట్రెయిట్ లైన్. కాబట్టి 2D అర్రేని కూడా సిస్టమ్ ఒక సింగిల్ లైన్ లోనే పక్కపక్కన సేవ్ చేస్తుంది. మన కంపైలర్ లోపల మ్యాథ్స్ వాడి దాన్ని 2D లాగా చూపిస్తుంది అంతే!

Q: 3D Arrays కూడా ఉంటాయా?

ఉంటాయి! గేమ్స్ డెవలప్‌మెంట్ లో స్పేస్ లో ఒక ఆబ్జెక్ట్ (x, y, z) అక్షాంశాలను చెప్పడానికి వీటిని వాడుతుంటారు.
