File Handling: Reading & Writing Files in C (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 20 📂 Phase 11: File Handling 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: File Pointer (FILE *) · fopen మరియు fclose · 'w', 'r', 'a' మోడ్స్ అంటే ఏంటి?

ఇప్పటివరకు మనం రాసిన ప్రోగ్రామ్స్ లో ఒక పెద్ద సమస్య ఉంది. మీరు ఒక కోడ్ రాసి అందులో డేటా ఇచ్చారు, అవుట్పుట్ వచ్చింది. కానీ ప్రోగ్రామ్ క్లోజ్ చేయగానే ఆ డేటా అంతా గాలిలో (RAM లో) ఆవిరైపోతుంది కదా! రేపు వచ్చి చూస్తే డేటా ఉండదు. ఆ డేటా శాశ్వతంగా హార్డ్ డిస్క్ లో స్టోర్ అవ్వాలంటే మనం దాన్ని ఒక File (ఫైల్) లోపల రాయాలి. దీన్నే ప్రోగ్రామింగ్ లో File Handling (ఫైల్ హ్యాండ్లింగ్) అంటారు.

1 ఫైల్ ఆపరేషన్స్ (File Operations)

ఫైల్ తో పని చేసేటప్పుడు ఎప్పుడూ మూడు స్టెప్స్ ఉంటాయి: 1) ఫైల్ ని ఓపెన్ చేయడం, 2) అందులో రాయడం లేదా చదవడం, 3) ఫైల్ ని క్లోజ్ చేయడం.

📓 రియల్ లైఫ్ స్టోరీ: ఒక డైరీ రాయడం

మీరు ఒక సీక్రెట్ డైరీ రాస్తున్నారు అనుకోండి.

ముందు డైరీ తాళం తీసి ఓపెన్ చేస్తారు (ఇదే fopen).
తర్వాత పెన్ పెట్టి కొత్త పేజీలో ఏమైనా రాస్తారు (ఇదే fprintf).
అయిపోయాక ఆ డైరీ మూసేసి తాళం వేస్తారు కదా, ఎందుకంటే వేరేవాళ్ళు చూడకూడదని. (ఇదే fclose).

కంప్యూటర్ లో ఫైల్ కూడా అంతే. దాన్ని క్లోజ్ చేయకపోతే డేటా సేవ్ అవ్వదు మరియు వేరే ప్రోగ్రామ్స్ దాన్ని వాడలేవు!

2 ఒకే ఒక సింపుల్ కోడ్ (ఫైల్ లోకి రాయడం)

కింద కోడ్ లో మనం "w" (అంటే Write) మోడ్ లో ఒక ఫైల్ ని ఓపెన్ చేసి అందులో ఒక చిన్న టెక్స్ట్ రాస్తున్నాం.

C — Simple File Write ▶ Run Code 
#include <stdio.h>

int main(void) {
    // 1. ఫైల్ ని Write మోడ్ ('w') లో ఓపెన్ చేస్తున్నాం
    FILE *fptr = fopen("hello.txt", "w");
    
    // ఫైల్ ఓపెన్ అయ్యిందో లేదో చెక్ చేస్తున్నాం
    if (fptr != NULL) {
        // 2. అందులోకి డేటా రాస్తున్నాం (printf బదులు fprintf వాడాలి)
        fprintf(fptr, "Hello, this is my first file!");
        
        // 3. కచ్చితంగా క్లోజ్ చేయాలి
        fclose(fptr);
    }
    
    return 0;
}
3 ఫ్రీక్వెంట్ గా అడిగే ప్రశ్నలు (FAQ)

Q: 'w' (Write) మోడ్ కి, 'a' (Append) మోడ్ కి తేడా ఏంటి?

మీరు 'w' (Write) మోడ్ లో ఫైల్ ఓపెన్ చేస్తే, అందులో పాత డేటా ఏమైనా ఉంటే అది మొత్తం డిలీట్ అయిపోయి కొత్త డేటా మాత్రమే ఉంటుంది. కానీ 'a' (Append) మోడ్ లో ఓపెన్ చేస్తే, పాత డేటా అలాగే ఉంటుంది, కొత్త డేటా దాని కింద యాడ్ అవుతుంది.

Q: ఫైల్ చదవడానికి (Reading) ఏ మోడ్ వాడాలి?

దానికి 'r' (Read) మోడ్ వాడాలి. అప్పుడు సిస్టమ్ ఆ ఫైల్ లో ఉన్న డేటాని తీసుకొచ్చి మన ప్రోగ్రామ్ కి ఇస్తుంది.
