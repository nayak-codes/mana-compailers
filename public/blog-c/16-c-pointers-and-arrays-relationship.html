Pointers & Arrays Relationship (తెలుగులో డీప్ ఎక్స్‌ప్లనేషన్)

⚡ C (C17 / C23 Standard) 🟢 Lesson 16 📂 Phase 08: Strings & Pointers Intro 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Array Decay · Pointer Arithmetic · Arrays as Pointers

మనం ఇంతకుముందు పాఠాల్లో అర్రేస్ (Arrays) గురించి నేర్చుకున్నాం, ఆ తర్వాత పాయింటర్స్ (Pointers) గురించి నేర్చుకున్నాం. కానీ C లాంగ్వేజ్ లో ఒక అద్భుతమైన సీక్రెట్ ఏంటంటే... ఈ రెండు దాదాపు ఒకటే! అవును, తెర వెనుక (Behind the scenes) అర్రేస్ అన్నీ కూడా పాయింటర్స్ లాగానే పనిచేస్తాయి. అందుకే ఆ రెండిటి మధ్య ఉన్న బంధం (Relationship) గురించి తెలుసుకోవడం చాలా అవసరం. దీన్ని అర్థం చేసుకుంటే C లాంగ్వేజ్ మీ గుప్పెట్లో ఉన్నట్టే!

1 అర్రే పేరు కూడా ఒక పాయింటరే! (Array Name as Pointer)

మీరు int arr[5]; అని రాసినప్పుడు 5 గదులు తయారవుతాయి అని తెలుసుకున్నాం. అయితే కంపైలర్ ఆ గదులను ట్రాక్ చేయడానికి ఆ అర్రే పేరుని (అంటే arr అనే పదాన్ని) మొదటి గది యొక్క అడ్రస్ గా మార్చేస్తుంది.

🚂 రియల్ లైఫ్ స్టోరీ: ట్రైన్ ఇంజిన్ మరియు బోగీలు

ఒక పొడవైన రైలుని ఊహించుకోండి. దానికి 10 బోగీలు (Compartments) ఉన్నాయి అనుకుందాం. మీరు స్టేషన్ లో ఉన్నప్పుడు "గోదావరి ఎక్స్ప్రెస్ ఎక్కడ ఉంది?" అని అడిగితే, వాళ్ళు "ప్లాట్‌ఫామ్ 1 మీద ఇంజిన్ ఉంది" అని చెప్తారు.

రైలు మొత్తం ఎక్కడుందో వాళ్ళు చెప్పరు. కేవలం ఇంజిన్ ఎక్కడుందో (మొదటి భాగం) మాత్రమే చెప్తారు. ఇంజిన్ దొరికితే దాని వెనకాల వరుసగా అన్నీ బోగీలు ఉన్నట్టే కదా!

C లాంగ్వేజ్ లో కూడా ఇంతే. అర్రే అనేది ఒక రైలు అయితే, అర్రే పేరు arr అనేది ఇంజిన్ యొక్క అడ్రస్ (మొదటి ఎలిమెంట్ అడ్రస్). దాన్నే బేస్ అడ్రస్ అంటారు.

2 ఒకే ఒక సింపుల్ కోడ్

ఇది చాలా ఆశ్చర్యంగా ఉంటుంది! కింద కోడ్ చూడండి. మనం arr[0] అని పిలవకుండా డైరెక్ట్ గా అర్రే పేరు ముందు స్టార్ (*arr) పెట్టినా కూడా మనకి సేమ్ ఆన్సర్ వస్తుంది. ఎందుకంటే అర్రే పేరే ఒక పాయింటర్ కాబట్టి!

C — Arrays & Pointers ▶ Run Code 
#include <stdio.h>

int main(void) {
    int arr[3] = {10, 20, 30};
    
    // మామూలుగా ఇలా వాడతాం
    printf("Normal index: %d\n", arr[0]);
    
    // అర్రే పేరుని పాయింటర్ లా వాడినా సేమ్ వస్తుంది!
    printf("Pointer way: %d\n", *arr);
    
    return 0;
}
3 ఫ్రీక్వెంట్ గా అడిగే ప్రశ్నలు (FAQ)

Q: పాయింటర్ కి +1 చేస్తే ఏమవుతుంది?

దీన్నే Pointer Arithmetic అంటారు. పాయింటర్ కి +1 చేస్తే అది నెక్స్ట్ నంబర్ కి వెళ్లదు, నెక్స్ట్ గదికి జంప్ అవుతుంది. అంటే ట్రైన్ లో ఒక బోగీ నుండి పక్క బోగీకి జంప్ చేసినట్టు అన్నమాట.

Q: ఫంక్షన్స్ కి అర్రే ని పంపినప్పుడు సైజు ఎందుకు తెలియదు? (Array Decay)

చాలా ఇంట్రెస్టింగ్ డౌట్! ఒక ఫంక్షన్ కి మనం అర్రే ని పంపితే, మొత్తం అర్రే ని కాకుండా కేవలం ఆ మొదటి గది అడ్రస్ (పాయింటర్) ని మాత్రమే సిస్టమ్ పంపిస్తుంది. అంటే సైజు ఇన్ఫర్మేషన్ గాలిలో కలిసిపోతుంది. దీన్నే Array Decay అంటారు. అందుకే అర్రే తో పాటు ఎప్పుడూ సైజు ని కూడా విడిగా పంపాలి.
