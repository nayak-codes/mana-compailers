C Conditional Branching: if, else-if Ladders, Nested if & Common Traps (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 6 📂 Phase 04: Conditions & Branching 📅 2026 Edition
📌 Covered in this in-depth guide: Boolean Truth in C · if, if-else & else-if · Nested if & Guard Clauses · Logical Operators & Short-Circuit · Ternary · Comparing Chars · Common Traps

Phase 4 (Part 1): C Conditional Branching, if-else Ladders, Nested if Masterclass కు స్వాగతం! రియల్ వరల్డ్ సాఫ్ట్‌వేర్లలో, యూజర్ ఇచ్చే డేటాని బట్టి ప్రోగ్రామ్ దానంతట అదే నిర్ణయాలు (decisions) తీసుకోవాలి. C లాంగ్వేజ్ లో డెసిషన్స్ అన్నీ నెంబర్-బేస్డ్ బూలియన్ లాజిక్ మీద ఆధారపడి ఉంటాయి. అంటే, 0 వస్తే FALSE అని, జీరో కాని ఏ నెంబర్ అయినా TRUE అని అర్థం. ఈ గైడ్ లో, if, if-else, మల్టిపుల్ కండిషన్స్ చెక్ చేసే else-if లాడర్, కండిషన్ లోపల కండిషన్ రాసే nested-if, క్యారెక్టర్లను పోల్చడం, మరియు కండిషన్స్ రాసేటప్పుడు చేసే కామన్ తప్పుల గురించి తెలుగులో నేర్చుకుందాం.

1C లో Boolean Truth (నిజం/అబద్ధం) & if / if-else ఎలా పనిచేస్తాయి?

💡 C లో Boolean లాజిక్ గోల్డెన్ రూల్:

• 0 (సున్నా): కచ్చితంగా FALSE (అబద్ధం) అని అర్థం.
• సున్నా కాని ఏ నెంబర్ అయినా (1, -5, 100, 0.5 వగైరా): కచ్చితంగా TRUE (నిజం) కిందకే వస్తుంది!

Control Flow Architecture — if-else:

[ Start Condition: (marks >= 40) ]
│
┌───────────┴───────────┐
▼ (TRUE) ▼ (FALSE)
[ Grade: PASS ] [ Grade: FAIL ]

└───────────┬───────────┘
▼
[ Continue Execution ]
2The else-if Ladder (ఒకటి కంటే ఎక్కువ కండిషన్స్)

మనకు ఒకదానికొకటి సంబంధం లేని మల్టిపుల్ కండిషన్స్ ఉన్నప్పుడు else-if ladder ని వాడతాము. ఇది పైనుండి కిందకు చెక్ చేసుకుంటూ వస్తుంది. ఏ కండిషన్ ఫస్ట్ నిజమైతే ఆ బ్లాక్ లో ఉన్న కోడ్ రన్ అయ్యి, కింద ఉన్న కండిషన్స్ అన్నింటినీ స్కిప్ చేసేస్తుంది:

C — User Curriculum Grade Calculator ▶ Run in C Compiler 
#include <stdio.h>

int main(void) {
    int marks;

    printf("Enter marks: ");
    if (scanf("%d", &marks) != 1) {
        printf("❌ Invalid input! Please enter an integer.\n");
        return 1;
    }

    if (marks >= 90) {
        printf("Grade A\n");
    } else if (marks >= 60) {
        printf("Grade B\n");
    } else if (marks >= 40) {
        printf("Grade C\n");
    } else {
        printf("Fail\n");
    }

    return 0;
}
3Nested if & Logical Operators (Short-Circuit) ⭐

⚡ C లో Short-Circuit Evaluation (సమయం ఆదా)

• Logical AND (&&): ఫస్ట్ రాసిన కండిషన్ FALSE అయితే, కంపైలర్ అసలు సెకండ్ కండిషన్ ని చెక్ కూడా చేయదు (ఎందుకంటే AND లో ఒకటి ఫెయిల్ అయినా మొత్తం ఫెయిల్ కాబట్టి).
• Logical OR (||): ఫస్ట్ రాసిన కండిషన్ TRUE అయితే, సెకండ్ కండిషన్ ని చెక్ చేయదు (ఎందుకంటే OR లో కనీసం ఒకటి నిజమైనా మొత్తం నిజమే కాబట్టి).
⚡ టిప్: త్వరగా రన్ అయ్యే చిన్న కండిషన్స్ ని ఎప్పుడూ ఎడమ వైపు (ఫస్ట్) రాయాలి!

C — Multiple Logical Conditions & Character Comparison ▶ Run Code 
#include <stdio.h>

int main(void) {
    char ch;
    printf("Enter any single character: ");
    scanf(" %c", &ch);

    // Character comparison using ASCII integer values
    if (ch >= 'A' && ch <= 'Z') {
        printf("'%c' is an UPPERCASE alphabet (ASCII: %d)\n", ch, ch);
    } else if (ch >= 'a' && ch <= 'z') {
        printf("'%c' is a LOWERCASE alphabet (ASCII: %d)\n", ch, ch);
    } else if (ch >= '0' && ch <= '9') {
        printf("'%c' is a numeric DIGIT.\n", ch);
    } else {
        printf("'%c' is a SPECIAL symbol / punctuation.\n", ch);
    }

    return 0;
}
4C ప్రోగ్రామింగ్ లో కండిషన్స్ రాసేటప్పుడు చేసే పెద్ద తప్పులు ⚠️

🛑 C లో ఎక్కువగా చేసే 3 డేంజరస్ తప్పులు:

1. డబల్ ఈక్వల్స్ కి బదులు సింగిల్ ఈక్వల్ టు రాయడం (= బదులు == వాడకపోవడం):
if (x = 5) — ఇది రెండు సమానమా అని చెక్ చేయదు! x లోకి 5 ని అసైన్ చేసి, అది సున్నా కాదు కాబట్టి కండిషన్ ఎప్పటికీ TRUE అయ్యేలా చేస్తుంది!
💡 దీనికి సొల్యూషన్: ఎప్పుడూ if (5 == x) అని రాయడం అలవాటు చేసుకోండి. పొరపాటున if (5 = x) అని రాస్తే వెంటనే కంపైల్ ఎర్రర్ వస్తుంది!

2. if చివర్లో పొరపాటున Semicolon (;) పెట్టడం:
if (x > 10); { printf("Positive"); } — చివర్లో ; పెడితే అక్కడితో ఆ కండిషన్ ముగిసిపోతుంది. దాంతో ఆ కింది బ్రాకెట్స్ లో ఉన్న కోడ్ ఆ కండిషన్ తో సంబంధం లేకుండా ఎప్పుడూ రన్ అవుతూనే ఉంటుంది!

3. పాయింట్ నంబర్స్ ని డైరెక్ట్ గా ఈక్వల్ (==) తో చెక్ చేయడం:
float f = 0.1f + 0.2f; if (f == 0.3f) అని రాస్తే కంప్యూటర్ రౌండింగ్ ప్రాబ్లమ్స్ వల్ల అది FALSE అని చెప్తుంది. అందుకని ఎప్పుడూ డిఫరెన్స్ (fabs(f - 0.3f) < 0.0001) ని బట్టి చెక్ చేయాలి!
