Tree Traversals (Inorder, Preorder, Postorder) (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 57 📂 Phase 19: Data Structures - 2 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Tree Traversal · Inorder (L N R) · Preorder (N L R) · Postorder (L R N) · Recursion Magic

లాస్ట్ లెసన్ లో మనం చెట్టుని క్రియేట్ చేసాం కదా! కానీ అందులో ఉన్న డేటా ని ప్రింట్ చేయాలంటే అర్రే లాగా for లూప్ రాస్తే కుదరదు. ఎందుకంటే ఎక్కడికి వెళ్ళాలో రెండు దారులు ఉంటాయి (Left, Right). మరి చెట్టు మొత్తాన్ని మిస్ అవ్వకుండా ఎలా కవర్ చేయాలి? దానికి ఉన్న దారే Tree Traversals (ట్రావర్సల్స్). ఇందులో Inorder, Preorder, Postorder అని మూడు ఫేమస్ పద్ధతులు ఉన్నాయి. ఈ మూడు పద్ధతులు Recursion (రికర్షన్) అనే మ్యాజిక్ వాడి 10 లైన్ల కోడ్ తోనే 10 వేల నోడ్స్ ని ఎలా ప్రింట్ చేస్తాయో ఈరోజు అద్భుతంగా చూద్దాం.

1 మూడు పద్ధతులు ఏంటి? (The Golden Rules)

ప్రతి నోడ్ దగ్గరికి వెళ్ళినప్పుడు మనం మూడు పనులు చేయాలి: 1. ఎడమవైపు (L) కి వెళ్ళడం, 2. కుడివైపు (R) కి వెళ్ళడం, 3. అసలు డేటాని ప్రింట్ (N - Node) చేయడం. ఈ మూడు పనుల ఆర్డర్ బట్టే పేర్లు మారాయి!

🚶‍♂️ రియల్ లైఫ్ స్టోరీ: అడవిలో ఫొటోగ్రాఫర్

1. Inorder (L-N-R) - "మధ్యలో దేవుడు": ఫొటోగ్రాఫర్ ముందు ఎడమ పక్కకెళ్లి అంతా ఫోటోలు తీసి, ఆ తర్వాత మెయిన్ బాస్ (N) ఫోటో తీసి, లాస్ట్ లో కుడి పక్కకి వెళ్తాడు. BST లో ఇలా ప్రింట్ చేస్తే, మొత్తం డేటా అసెండింగ్ ఆర్డర్ (చిన్న నుండి పెద్ద) లో నీట్ గా సార్ట్ అయ్యి బయటికి వస్తుంది!

2. Preorder (N-L-R) - "ముందే సెల్ఫీ": ఒక కొత్త చెట్టు దగ్గరికి వెళ్ళగానే ముందే వాడు సెల్ఫీ (N) తీసేసుకుంటాడు. ఆ తర్వాతే ఎడమకి, కుడికి వెళ్తాడు. ఒక చెట్టుని యాజ్-ఇట్-ఈజ్ గా జిరాక్స్ కాపీ (Clone) కొట్టాలంటే ఈ పద్ధతి బెస్ట్.

3. Postorder (L-R-N) - "లాస్ట్ లో బ్రేక్": ముందు ఎడమ మొత్తం, తర్వాత కుడి మొత్తం చూసేసాక, లాస్ట్ లో ఆ బాస్ (N) ఫోటో తీస్తాడు. ఒక చెట్టుని సేఫ్ గా కిందినుండి డిలీట్ (Delete tree) చేయాలంటే ఇదే వాడాలి.

2 రికర్షన్ (Recursion) మ్యాజిక్ ఎలా పనిచేస్తుంది?

మీరు Inorder(root->left) అని రాస్తే, కంపైలర్ ప్రస్తుతం ప్రింట్ చేసే పనిని స్టాక్ (Stack Memory) లో హోల్డ్ లో పెట్టి, కిందికి దూకి దాని ఎడమ కొమ్మ పని పూర్తిచేస్తుంది. అది పూర్తిగా అయ్యాకే పైకి వచ్చి అప్పుడు ప్రింట్ చేస్తుంది. ఇది అర్ధం చేసుకోవడానికి కష్టం గానీ, రన్ అయితే భలే మ్యాజిక్ లాగా ఉంటుంది.

3 ఒకే ఒక సింపుల్ కోడ్ (3 Traversals Demo)

కింద కోడ్ లో మూడు ఫంక్షన్స్ చాలా చిన్నవిగా ఉంటాయి, కానీ అవుట్పుట్ లో వాటి ఆర్డర్ ఎలా మారుతుందో లైవ్ గా చూడండి.

C — Tree Traversals ▶ Run Code 
#include <stdio.h>
#include <stdlib.h>

struct Node {
    int data;
    struct Node *left, *right;
};

// కొత్త నోడ్ క్రియేట్ చేయడానికి హెల్పర్
struct Node* create(int v) {
    struct Node* n = (struct Node*)malloc(sizeof(struct Node));
    n->data = v; n->left = NULL; n->right = NULL;
    return n;
}

// ------------------------------------
// 1. Inorder (L - N - R)
// ------------------------------------
void inorder(struct Node* root) {
    if (root == NULL) return; // చెట్టు ఎండ్ అయితే ఆగిపో
    
    inorder(root->left);           // 1. ముందు మొత్తం ఎడమకి వెళ్ళు
    printf("%d ", root->data);     // 2. డేటాని ప్రింట్ చేయి
    inorder(root->right);          // 3. ఆ తర్వాత కుడికి వెళ్ళు
}

// ------------------------------------
// 2. Preorder (N - L - R)
// ------------------------------------
void preorder(struct Node* root) {
    if (root == NULL) return;
    
    printf("%d ", root->data);     // 1. ముందే ప్రింట్ చేసేయ్
    preorder(root->left);          // 2. ఎడమకి వెళ్ళు
    preorder(root->right);         // 3. కుడికి వెళ్ళు
}

// ------------------------------------
// 3. Postorder (L - R - N)
// ------------------------------------
void postorder(struct Node* root) {
    if (root == NULL) return;
    
    postorder(root->left);         // 1. ఎడమకి వెళ్ళు
    postorder(root->right);        // 2. కుడికి వెళ్ళు
    printf("%d ", root->data);     // 3. అంతా అయ్యాక లాస్ట్ లో ప్రింట్ చేయి
}

int main() {
    printf("--- Tree Traversals Magic ---\n\n");
    
    // ఒక సింపుల్ చెట్టుని మాన్యువల్ గా క్రియేట్ చేద్దాం
    //       50
    //     /    \
    //   30      70
    //  /  \    /  \
    // 20  40  60   80
    
    struct Node* root = create(50);
    root->left = create(30);
    root->right = create(70);
    root->left->left = create(20);
    root->left->right = create(40);
    root->right->left = create(60);
    root->right->right = create(80);
    
    printf("1. Inorder (Sorted output) : ");
    inorder(root); // అవుట్పుట్: 20 30 40 50 60 70 80
    
    printf("\n2. Preorder (Top-down)     : ");
    preorder(root); // అవుట్పుట్: 50 30 20 40 70 60 80
    
    printf("\n3. Postorder (Bottom-up)   : ");
    postorder(root); // అవుట్పుట్: 20 40 30 60 80 70 50
    
    printf("\n");
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • if (root == NULL) return;: ఇది రికర్షన్ కి బ్రేక్ (Base condition). ఇది లేకపోతే మీ లూప్ గాలిలోకి వెళ్లి ఇన్ఫినిట్ అయిపోయి స్టాక్ ఓవర్ ఫ్లో (Stack Overflow) వచ్చి క్రాష్ అవుతుంది! ఆకు (Leaf) దాటాక కింద ఏమీ ఉండదు కాబట్టి, ఇది అక్కడి నుండి వెనక్కి పంపుతుంది.
  • printf లైన్ మార్చడమే మ్యాజిక్! ఆ printf లైన్ ఎక్కడ ఉందో దాన్ని బట్టే ప్రింట్ అయ్యే ఆర్డర్ మారిపోతుంది. రికర్షన్ స్టాక్ (Stack Memory) లో హోల్డ్ అవుతుంది కాబట్టి, కింది ఫంక్షన్స్ పూర్తయ్యాకే పై ఫంక్షన్స్ printf ఎగ్జిక్యూట్ అవుతాయి.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: ఇవి కాకుండా Level Order (లెవెల్ ఆర్డర్) అని ఒకటి ఉంటుందా?

అవును! పై మూడు పద్ధతులు నిలువుగా (Depth-first) వెళ్తాయి. లెవెల్ ఆర్డర్ అనేది ఒక ఫ్లోర్ తర్వాత ఇంకో ఫ్లోర్ అడ్డంగా (Breadth-first) ప్రింట్ చేస్తుంది. ఇది రాయాలంటే కేవలం రికర్షన్ సరిపోదు, అదనంగా ఒక Queue (క్యూ) అనే డేటా స్ట్రక్చర్ ని వాడి కోడ్ చేయాలి. ఇంటర్వ్యూస్ లో ఇది చాలా ఫేమస్!

Q2: ఒక చెట్టుని పూర్తిగా డిలీట్ చేయాలంటే ఏ పద్ధతి వాడాలి?

Postorder నే వాడాలి! ఎందుకంటే, ముందు పిల్లల్ని (ఎడమ, కుడి) free() చేసి డిలీట్ చేసాకే పేరెంట్ ని డిలీట్ చేయాలి. ఒకవేళ ముందే పేరెంట్ ని (Inorder లాగా) డిలీట్ చేస్తే పిల్లల దగ్గరికి వెళ్ళే దారి (Address) పోయి మెమరీ లీక్ అయిపోతుంది.

Q3: Recursion కాకుండా Loops వాడి ఇవి రాయొచ్చా?

ఖచ్చితంగా రాయొచ్చు. దాన్నే Iterative Traversal అంటారు. కానీ దానికి మీరు సొంతంగా ఒక Stack డేటా స్ట్రక్చర్ ని కోడ్ లో మెయింటైన్ చేయాలి. రికర్షన్ వాడితే ఆ స్టాక్ ని ఆపరేటింగ్ సిస్టమే ఆటోమేటిక్ గా ఇస్తుంది కాబట్టి 3 లైన్ల కోడ్ లో పని అయిపోయింది.
