C Pass-by-Value vs Address, Recursion & 5 Modular Projects (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 11 📂 Phase 06: Functions & Modular Architecture 📅 2026 Edition
📌 Covered in this in-depth guide: Pass-by-Value vs Pass-by-Reference · Stack Frame Lifecycle · Recursion & Base Cases · 5 Modular Projects (Calculator, Grading, Number Utility)

Phase 6 (Part 2): C Parameter Passing & Recursion Masterclass కు స్వాగతం! ఒక ఫంక్షన్ కి వాల్యూస్ పాస్ చేసినప్పుడు RAM మెమరీలో ఏం జరుగుతుంది అనేది తెలుసుకోవడం ద్వారా మీరు అడ్వాన్స్డ్ C ప్రోగ్రామర్ అవ్వగలరు. ఈ గైడ్ లో, Call by Value (కాపీని పంపడం) కి మరియు Call by Reference (మెమరీ అడ్రస్ నే పంపడం) కి మధ్య ఉన్న డిఫరెన్స్ ఏంటో నేర్చుకుందాం. అలాగే ఒక ఫంక్షన్ తనని తానే మళ్ళీ కాల్ చేసుకునే Recursion (రికర్శన్) ఎలా రన్ అవుతుంది, Stack Overflow ఎలా ఆపాలి, మరియు ఈ కాన్సెప్ట్స్ వాడుకొని 5 రియల్ టైం మాడ్యులర్ ప్రాజెక్ట్స్ ని ఎలా రాయాలో తెలుగులో నేర్చుకుందాం.

1Pass-by-Value కి Pass-by-Address కి తేడా ఏంటి? ⭐

1. Pass by Value (కాపీ పంపడం)

మనం ఫంక్షన్ కి ఒక వేరియబుల్ ఇస్తే, అది ఒక నకిలీ కాపీని (Xerox copy) మాత్రమే తీసుకుంటుంది. కాబట్టి ఫంక్షన్ లోపల దాన్ని ఎంత మార్చినా, మన main() లో ఉన్న అసలైన వాల్యూ మారదు!

2. Pass by Address (మెమరీ అడ్రస్ పంపడం)

మనం ఫంక్షన్ కి డైరెక్ట్ గా మన వేరియబుల్ ఉన్న **RAM మెమరీ అడ్రస్ (&var)** ఇచ్చేస్తాము. అప్పుడు ఫంక్షన్ ఒక పాయింటర్ (*ptr) వాడి డైరెక్ట్ గా ఒరిజినల్ మెమరీ లోనే వాల్యూస్ మారుస్తుంది! (దీనికే పాయింటర్స్ వాడతారు).

C — Pass-by-Value vs Pass-by-Address (Swap Demo) ▶ Run Code 
#include <stdio.h>

// 1. Pass by Value (Fails to swap in main!)
void wrongSwap(int a, int b) {
    int temp = a; a = b; b = temp;
}

// 2. Pass by Address (Successfully swaps caller's RAM memory!)
void realSwap(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main(void) {
    int x = 10, y = 20;

    wrongSwap(x, y);
    printf("After wrongSwap: x = %d, y = %d (NO change!)\n", x, y);

    realSwap(&x, &y); // Passing memory addresses &x and &y
    printf("After realSwap:  x = %d, y = %d (Swapped!)\n", x, y);

    return 0;
}
2Recursion (రికర్శన్) & CPU కాలింగ్ స్టాక్ ఎలా పనిచేస్తుంది?

Recursion అంటే ఒక ఫంక్షన్ తన లోపల నుండి మళ్ళీ తననే (తన పేరుతోనే) కాల్ చేసుకోవడం. ఇలా రాసినప్పుడు కచ్చితంగా ఈ 2 రూల్స్ ఫాలో అవ్వాలి (లేకపోతే క్రాష్ అవుతుంది):

  1. 1. Base Case (ఎక్కడ ఆగాలో చెప్పడం): తనని తాను ఎప్పటిదాకా కాల్ చేసుకోవాలో ఒక లిమిట్ (కండిషన్) పెట్టాలి (ఉదాహరణకి if (n <= 1) return 1;). ఇది రాయకపోతే ప్రోగ్రామ్ ఆగకుండా రన్ అయ్యి Stack Overflow ఎర్రర్ తో క్రాష్ అయిపోతుంది!
  2. 2. Recursive Step (ప్రాబ్లమ్ ని చిన్నది చేయడం): ప్రతిసారీ తనని తాను కాల్ చేసుకునేటప్పుడు, ముందు కంటే చిన్న నంబర్ ఇచ్చి కాల్ చేయాలి (ఉదాహరణకి return n * factorial(n - 1);).
factorial(3) కోసం CPU Call Stack ఎలా రన్ అవుతుంది?:

[ లోపలికి వెళ్తూ కాల్ చేస్తుంది ] [ రివర్స్ లో ఆన్సర్ ఇస్తూ వస్తుంది ]
│ factorial(1) -> returns 1 (Base Case) │ returns 1
│ factorial(2) -> 2 * factorial(1) │ returns 2 * 1 = 2
│ factorial(3) -> 3 * factorial(2) │ returns 3 * 2 = 6
│ main() │ main() కి ఫైనల్ గా 6 వస్తుంది!
35 రియల్-వరల్డ్ మాడ్యులర్ సాఫ్ట్‌వేర్ ప్రాజెక్ట్స్

ఇప్పటివరకు నేర్చుకున్న ఫంక్షన్స్ వాడుకొని ఒక ప్రొఫెషనల్ లాగా ఈ 5 ప్రాజెక్ట్స్ ఎలా రాయాలో చూద్దాం:

ప్రాజెక్ట్స్ 1 & 2: మల్టిపుల్ ఫంక్షన్స్ తో క్యాలిక్యులేటర్ & స్టూడెంట్ గ్రేడింగ్

C — Modular Calculator & Grading Library ▶ Run Code 
#include <stdio.h>

// --- 1. Modular Calculator Library ---
double calculate(double a, double b, char op) {
    if (op == '+') return a + b;
    if (op == '-') return a - b;
    if (op == '*') return a * b;
    if (op == '/') return (b != 0) ? (a / b) : 0.0;
    return 0.0;
}

// --- 2. Student Grading System ---
char calculateGrade(double avg) {
    if (avg >= 90.0) return 'A';
    if (avg >= 75.0) return 'B';
    if (avg >= 50.0) return 'C';
    return 'F';
}

int main(void) {
    printf("1. Calculator: 50 * 4 = %.2f\n", calculate(50, 4, '*'));
    printf("2. Student Avg 82.5%% -> Grade: %c\n", calculateGrade(82.5));
    return 0;
}

C — Number Utility & Unit Converter Suite ▶ Run Suite 
#include <stdio.h>
#include <stdbool.h>

// --- 3. Number Utility Library ---
bool isPrime(int n) {
    if (n <= 1) return false;
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) return false;
    }
    return true;
}

long long factorialRecursive(int n) {
    if (n <= 1) return 1; // Base case
    return n * factorialRecursive(n - 1); // Recursive step
}

// --- 4. Unit Converter Library ---
double celsiusToFahrenheit(double c) {
    return (c * 9.0 / 5.0) + 32.0;
}

double kilometersToMiles(double km) {
    return km * 0.621371;
}

int main(void) {
    printf("3. Number Utility: Is 31 Prime? %s\n", isPrime(31) ? "YES" : "NO");
    printf("4. Recursion: Factorial of 6 = %lld\n", factorialRecursive(6));
    printf("5. Unit Converter: 100 km = %.2f Miles | 100°C = %.1f°F\n", kilometersToMiles(100), celsiusToFahrenheit(100));
    return 0;
}

#include <stdio.h>

// Recursive power: base^exp
long long power(int base, int exp) {
    if (exp == 0) return 1;
    return base * power(base, exp - 1);
}

int main(void) {
    printf("2^8 = %lld\n", power(2, 8));
    return 0;
}
