Linked Lists (Singly) - Basics (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 51 📂 Phase 18: Data Structures - 1 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Arrays vs Linked Lists · Nodes (Data & Next) · Linked List Creation · Traversal (Printing)

ఇంతవరకు మనం చాలా కాన్సెప్ట్స్ నేర్చుకున్నాం, కానీ ఇప్పుడు Data Structures (డేటా స్ట్రక్చర్స్) అనే అసలైన ప్రోగ్రామింగ్ ప్రపంచంలోకి అడుగుపెడుతున్నాం! మామూలుగా ఒక అర్రే (Array) వాడితే దాని సైజు ముందే ఫిక్స్ చేయాలి, దాన్ని పెంచడం కష్టం. ఆ ప్రాబ్లమ్ కి సొల్యూషన్ ఏంటంటే, ఎప్పుడు డేటా వస్తే అప్పుడు ఆన్ ది స్పాట్ లో ఒక బాక్స్ తయారుచేసి, దాన్ని పాత బాక్స్ కి లింక్ చేయడం! దీన్నే Linked List (లింక్డ్ లిస్ట్) అంటారు. ఇది అచ్చం ట్రైన్ డబ్బాల్లా పనిచేస్తుంది. ఒక డబ్బా ఇంకో డబ్బాకి చైన్ తో కనెక్ట్ అయ్యి ఉంటుంది. దాన్ని C లో డైనమిక్ మెమరీ (malloc) తో ఎలా సృష్టిస్తారో ఈరోజు నేర్చుకుందాం.

1 Array వర్సెస్ Linked List (తేడా ఏంటి?)

Array: మీ దగ్గర ఒక పెద్ద బెంచ్ ఉంది. అందరూ పక్కపక్కనే (Contiguous memory) కూర్చోవాలి. మధ్యలో ఎవడైనా కొత్తవాడు రావాలంటే, మిగతా అందరూ పక్కకి జరగాలి (Shift). ఇది చాలా టైమ్ వేస్ట్!

Linked List: ఒక థియేటర్ లో ఎవరికి ఎక్కడ ఖాళీ దొరికితే అక్కడ కూర్చుంటారు (Random memory). కానీ మొదటివాడి చేతిలో రెండో వాడి అడ్రస్ స్లిప్ ఉంటుంది, రెండో వాడి చేతిలో మూడో వాడి అడ్రస్ ఉంటుంది. ఇలా ఒకరి తర్వాత ఒకరు కనెక్ట్ అవుతారు!

🚂 రియల్ లైఫ్ స్టోరీ: ట్రైన్ డబ్బాలు (Nodes)

లింక్డ్ లిస్ట్ లో ప్రతి బాక్స్ ని Node (నోడ్) అంటారు. ఒక ట్రైన్ డబ్బాలో ఏముంటాయి? ప్యాసింజర్స్ కూర్చునే సీట్స్ (Data), మరియు వెనక డబ్బాకి కనెక్ట్ చేసే ఇనుప చైన్ (Pointer).

C లో ఒక స్ట్రక్చర్ రాసి అందులో ఒక వేరియబుల్ (Data), మరియు దాని స్వంత స్ట్రక్చర్ కే పాయింట్ చేసే ఒక అడ్రస్ struct Node* next; ని పెడతాము. దీన్నే Self-referential Structure అంటారు. లాస్ట్ డబ్బాకి ఇంకేమీ కనెక్ట్ అవ్వదు కాబట్టి దాని చైన్ ని తెంపేస్తాం (అదే నల్ పాయింటర్ - NULL).

2 లింక్డ్ లిస్ట్ పార్ట్స్ (Head & NULL)

Head (హెడ్): ఇది ట్రైన్ ఇంజిన్ లాంటిది. ఇది లిస్ట్ లో మొదటి నోడ్ యొక్క అడ్రస్ ని మాత్రమే పట్టుకుని ఉంటుంది. హెడ్ దొరికితే చాలు, చైన్ పట్టుకుని లాస్ట్ వరకు వెళ్లిపోవచ్చు. హెడ్ మిస్సయితే మీ డేటా మొత్తం లాస్ట్ (Memory Leak)!

[HEAD] ---> [ Data: 10 | Next ] ---> [ Data: 20 | Next ] ---> [ Data: 30 | NULL ]
3 ఒకే ఒక సింపుల్ కోడ్ (Creating a Linked List)

కింద కోడ్ లో 3 నోడ్స్ ని malloc తో ఎలా తయారు చేసామో, వాటిని చైన్ లాగా ఒకదానికొకటి ఎలా లింక్ చేసామో, ఆ తర్వాత లూప్ లో ఎలా ప్రింట్ (Traversal) చేసామో క్రియేటివ్ గా చూడండి.

C — Singly Linked List ▶ Run Code 
#include <stdio.h>
#include <stdlib.h>

// 1. ఒక నోడ్ బ్లూప్రింట్ (ట్రైన్ డబ్బా)
struct Node {
    int data;           // డేటా దాచుకోవడానికి
    struct Node* next;  // నెక్స్ట్ డబ్బా అడ్రస్ దాచుకోవడానికి (చైన్)
};

// లిస్ట్ ని ప్రింట్ చేయడానికి ఒక స్పెషల్ ఫంక్షన్ (Traversal)
void printList(struct Node* head) {
    struct Node* temp = head; // హెడ్ ని కదపకుండా ఒక టెంప్ పాయింటర్ వాడాలి
    
    printf("Linked List: ");
    while (temp != NULL) {
        printf("[%d] -> ", temp->data); // డేటా ప్రింట్ చేయి
        temp = temp->next;              // చైన్ పట్టుకుని నెక్స్ట్ డబ్బాకి వెళ్ళు!
    }
    printf("NULL\n"); // లాస్ట్ కి వచ్చేశాం
}

int main() {
    printf("--- Building a Linked List ---\n\n");
    
    // 2. మూడు ఖాళీ డబ్బాలను Heap లో తయారు చేద్దాం
    struct Node* head = (struct Node*)malloc(sizeof(struct Node));
    struct Node* second = (struct Node*)malloc(sizeof(struct Node));
    struct Node* third = (struct Node*)malloc(sizeof(struct Node));
    
    // 3. వాటిలో డేటా పెట్టి చైన్ కనెక్ట్ చేద్దాం
    
    // మొదటి డబ్బా
    head->data = 10;       // డేటా 10
    head->next = second;   // రెండో డబ్బాకి లింక్
    
    // రెండో డబ్బా
    second->data = 20;
    second->next = third;  // మూడో డబ్బాకి లింక్
    
    // మూడో డబ్బా (లాస్ట్ డబ్బా)
    third->data = 30;
    third->next = NULL;    // ట్రైన్ ఎండ్ అయింది కాబట్టి NULL
    
    // 4. ప్రింట్ చేద్దాం
    printList(head);
    
    // (రియల్ ప్రోగ్రామ్స్ లో వాడేసాక free() చేయాలి)
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • struct Node* next;: ఒక స్ట్రక్చర్ లోపల అదే స్ట్రక్చర్ క్రియేట్ చేయలేము (అది అన్-లిమిటెడ్ సైజ్ అవుతుంది). కానీ పాయింటర్ (అడ్రస్) మాత్రం స్టోర్ చేసుకోవచ్చు! ఎందుకంటే పాయింటర్ సైజ్ ఎప్పుడూ 4 లేదా 8 బైట్స్ గా ఫిక్స్ అయి ఉంటుంది.
  • temp = temp->next;: ఇది లింక్డ్ లిస్ట్ కి గుండెకాయ లాంటిది. temp ఉన్న చోట ప్రింట్ చేసి, దాని చేతిలో ఉన్న నెక్స్ట్ అడ్రస్ (next) ని తీసుకుని temp లో పెట్టుకుంటుంది. అంటే జంప్ అవుతుంది! నల్ (NULL) వచ్చేదాకా ఈ జంపింగ్ లూప్ జరుగుతుంది.
  • struct Node* temp = head;: మనం ప్రింట్ చేసేటప్పుడు ఒరిజినల్ head ని ఎప్పుడూ మార్చకూడదు! ఒకవేళ మార్చేసి లాస్ట్ కి వెళ్ళిపోతే, లిస్ట్ ముందు డేటా అంతా పోతుంది (Memory Leak). అందుకే దానికి డూప్లికేట్ temp వాడాం.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: Array వాడటం మానేసి అందరూ లింక్డ్ లిస్ట్ వాడొచ్చు కదా?

దీనికి కొన్ని మైనస్ పాయింట్స్ ఉన్నాయి! అర్రే లో మీరు డైరెక్ట్ గా arr[5] అంటే ఐదో ఐటమ్ సెకనులో వచ్చేస్తుంది (O(1)). కానీ లింక్డ్ లిస్ట్ లో 5వ ఐటమ్ కావాలంటే హెడ్ దగ్గరి నుండి ఒకటి, రెండు అని గుడ్డిగా చైన్ పట్టుకుని వెతుక్కుంటూ వెళ్ళాలి (O(N)). సెర్చ్ చేయడానికి ఇది చాలా స్లో!

Q2: ఎక్కడ Array వాడాలి? ఎక్కడ Linked List వాడాలి?

మీకు సైజు ముందే తెలుసు, అండ్ మీరు డేటాని ఫాస్ట్ గా చదవాలి (Read Heavy) అనుకుంటే Array బెస్ట్. కానీ మీకు సైజు తెలీదు, మీరు మధ్యలో కొత్త డేటాని దూర్చడం (Insert) లేదా తీసేయడం (Delete) ఎక్కువగా చేస్తారు అంటే అప్పుడు Linked List కచ్చితంగా వాడాలి. ఎందుకంటే ఇందులో షిఫ్టింగ్ (Shifting) అవసరం లేదు, చైన్ మార్చితే చాలు!

Q3: లింక్డ్ లిస్ట్ లో లాస్ట్ నోడ్ ని కనుక్కోవాలంటే ఏంటి కండిషన్?

ట్రావర్సల్ (Traversal) చేసేటప్పుడు temp != NULL వాడతాం (అది మొత్తం ప్రింట్ చేయడానికి). కానీ మీరు ఎగ్జాక్ట్ గా లాస్ట్ డబ్బా దగ్గర ఆగిపోవాలంటే temp->next != NULL అని వాడాలి. ఇది లాస్ట్ డబ్బా కి ఉన్న చైన్ 0 అవ్వగానే ఆగిపోతుంది!
