⚡ Modern C (C99 / C11) 🟢 Chapter 20 of 20 📂 Phase 05: స్ట్రక్చర్స్, డైనమిక్ మెమరీ & ప్రాజెక్ట్ 📅 2026 Edition
📌 Covered in this chapter: Structs · Pointers · Dynamic Allocation · File Persistence తో పూర్తి స్థాయి రియల్-వరల్డ్ C ప్రాజెక్ట్!
సిద్ధాంతం (Theory) ఎంత నేర్చుకున్నప్పటికీ ఒక ప్రాక్టికల్ రియల్-వరల్డ్ ప్రాజెక్ట్‌ను మొదటి నుండి సొంతంగా నిర్మించినప్పుడే ఒక ప్రోగ్రామర్‌కు నిజమైన ఆత్మవిశ్వాసం వస్తుంది. మనం గత 19 అధ్యాయాలలో నేర్చుకున్న Structs, Dynamic Memory (malloc/realloc/free), Pointers, Binary File Persistence, మరియు CLI Control Flow లన్నింటినీ ఒకచోట చేర్చి ఒక ప్రొడక్షన్-గ్రేడ్ స్టూడెంట్ రికార్డ్ మేనేజ్‌మెంట్ సిస్టమ్ (Student Record Management System) ను ఎలా రూపొందించాలో ఆర్కిటెక్చర్ నుండి కోడ్ వరకు క్షుణ్ణంగా పరిశీలిద్దాం.
1ప్రాజెక్ట్ ఆర్కిటెక్చర్ & సిస్టమ్ డిజైన్ (System Architecture)

ఒక ప్రొఫెషనల్ సాఫ్ట్‌వేర్ ఇంజనీర్ ప్రాజెక్ట్ ప్రారంభించేటప్పుడు నేరుగా కోడింగ్ రాయడం మొదలుపెట్టరు. ముందుగా సిస్టమ్ ఆర్కిటెక్చర్‌ను నాలుగు స్వతంత్ర మాడ్యూల్స్‌గా విభజిస్తారు:

1. డేటా మోడల్ (Data Model):

ప్రతి విద్యార్థి యొక్క రోల్ నంబర్, పేరు, మరియు మార్కులను ఒక కస్టమ్ రికార్డుగా రూపొందించే struct Student బ్లూప్రింట్.

2. మెమరీ మేనేజర్ (Memory Manager):

విద్యార్థుల సంఖ్య స్థిరంగా ఉండదు కాబట్టి, విద్యార్థులు పెరిగే కొద్దీ హీప్ (Heap) మెమరీని ఆటోమేటిక్‌గా రీసైజ్ చేసే realloc() ఇంజిన్.

3. స్టోరేజ్ ఇంజిన్ (Storage Engine):

కంప్యూటర్ స్విచ్ ఆఫ్ అయినా డేటా చెక్కుచెదరకుండా హార్డ్ డిస్క్‌లో students.dat ఫైల్‌లోకి బైనరీ బైట్ల రూపంలో రాసే/చదివే fwrite() & fread() మెకానిజం.

4. యూజర్ ఇంటర్‌ఫేస్ (CLI Interface):

ఇన్‌పుట్ ఎర్రర్లను నివారించే, సురక్షితమైన స్ట్రింగ్ రీడింగ్ మరియు మెనూ-డ్రివెన్ do-while ఈవెంట్ లూప్.

2మాడ్యూల్ 1: డేటా మోడలింగ్ & Struct డిజైన్

బైనరీ ఫైల్స్‌లో డేటాను భద్రపరిచేటప్పుడు డైనమిక్ పాయింటర్లు (char *name) వాడటం అత్యంత ప్రమాదకరం. ఎందుకంటే పాయింటర్‌ను ఫైల్‌లో రాస్తే కేవలం ఆ క్షణంలో RAM లో ఉన్న మెమరీ అడ్రస్ మాత్రమే సేవ్ అవుతుంది కానీ వాస్తవ టెక్స్ట్ సేవ్ అవ్వదు. కాబట్టి బైనరీ పర్సిస్టెన్స్ కోసం ఎల్లప్పుడూ స్థిర పరిమాణపు క్యారెక్టర్ అర్రే (Fixed-size Character Array) వాడాలి:

C — Data Model Definition 
typedef struct {
    int rollNo;       // 4 బైట్లు: విద్యార్థి ప్రత్యేక సంఖ్య
    char name[40];    // 40 బైట్లు: గరిష్టంగా 39 అక్షరాలు + '\0'
    float marks;      // 4 బైట్లు: అకాడెమిక్ మార్కులు
} Student;

// గ్లోబల్ లేదా సెంట్రల్ స్టేట్ మేనేజ్‌మెంట్
Student *students = NULL; // హీప్ మెమరీని సూచించే పాయింటర్
int studentCount = 0;     // ప్రస్తుతం ఉన్న మొత్తం విద్యార్థుల సంఖ్య
3మాడ్యూల్ 2: డైనమిక్ మెమరీ స్కేలింగ్ (addStudent లాజిక్)

బిగినర్స్ చేసే ప్రధాన తప్పు: Student students[100]; అని ముందే 100 సైజ్ ఇవ్వడం. దీనివల్ల కేవలం 2 విద్యార్థులు ఉంటే 98 మంది స్థలం వృధా అవుతుంది; 101వ విద్యార్థి వస్తే ప్రోగ్రామ్ క్రాష్ అవుతుంది.

దీనికి ఆధునిక పరిష్కారం realloc() డైనమిక్ గ్రోత్ ప్యాటర్న్. ప్రతిసారి కొత్త విద్యార్థిని చేర్చేటప్పుడు, కేవలం ఆ ఒక్క రికార్డుకు సరిపడా మెమరీని మాత్రమే పెంచుతాం:

C — Safe Memory Growth Strategy 
void addStudent(void) {
    // సేఫ్టీ ప్యాటర్న్: realloc ఫలితాన్ని తాత్కాలిక పాయింటర్‌లో తీసుకోవాలి
    Student *temp = (Student*) realloc(students, (studentCount + 1) * sizeof(Student));
    if (temp == NULL) {
        printf("⚠️ ఎర్రర్: సిస్టమ్ లో తగినంత RAM లేదు!\n");
        return;
    }
    students = temp; // విజయవంతమైతేనే అసలు పాయింటర్‌కు అసైన్ చేయాలి

    printf("\nరోల్ నంబర్: ");
    scanf("%d", &students[studentCount].rollNo);

    printf("విద్యార్థి పేరు: ");
    scanf(" %39s", students[studentCount].name); // బఫర్ ఓవర్‌ఫ్లో నిరోధించడానికి %39s

    printf("మార్కులు (0 - 100): ");
    scanf("%f", &students[studentCount].marks);

    studentCount++;
    printf("✅ రికార్డు విజయవంతంగా జోడించబడింది!\n");
}
4మాడ్యూల్ 3: బైనరీ ఫైల్ పర్సిస్టెన్స్ (Save & Load)

ప్రోగ్రామ్ ప్రారంభమైనప్పుడు గతంలో నిల్వ చేసిన డేటాను ఆటోమేటిక్‌గా రీలోడ్ చేయడం, మరియు ప్రోగ్రామ్ ముగిసేముందు మొత్తం డేటాను డిస్క్‌పై శాశ్వతంగా రాయడం ఎలాగో పరిశీలిద్దాం.

💾 హెడర్ మెటాడేటా ప్యాటర్న్ (Header Pattern):

ఫైల్ మొదట్లో ముందుగా studentCount (ఎంతమంది విద్యార్థులు ఉన్నారో తెలిపే సంఖ్య) ను రాస్తాం. తర్వాత రీడ్ చేసేటప్పుడు, ఆ కౌంట్‌ను చదివి, అంత పరిమాణానికి సరిపడా హీప్ మెమరీని malloc చేసి, ఆపై మొత్తం అరేని ఒకే fread కాల్‌తో చదువుతాం.

C — Binary Save & Load Functions 
void saveToFile(void) {
    FILE *fp = fopen("students.dat", "wb");
    if (fp == NULL) {
        printf("❌ ఫైల్ తెరవడం సాధ్యం కాలేదు!\n");
        return;
    }
    // 1. మొదట కౌంట్‌ను రాయడం
    fwrite(&studentCount, sizeof(int), 1, fp);
    // 2. మొత్తం అర్రే బ్లాక్‌ను రాయడం
    fwrite(students, sizeof(Student), studentCount, fp);
    fclose(fp);
    printf("💾 మొత్తం %d రికార్డులు students.dat లో సేవ్ చేయబడ్డాయి.\n", studentCount);
}

void loadFromFile(void) {
    FILE *fp = fopen("students.dat", "rb");
    if (fp == NULL) return; // ఫైల్ ఇంకా లేకపోతే (మొదటి రన్) నిశ్శబ్దంగా రిటర్న్ అవ్వాలి

    fread(&studentCount, sizeof(int), 1, fp);
    if (studentCount > 0) {
        students = (Student*) malloc(studentCount * sizeof(Student));
        if (students != NULL) {
            fread(students, sizeof(Student), studentCount, fp);
        }
    }
    fclose(fp);
}
5పూర్తి ప్రొడక్షన్-గ్రేడ్ C సోర్స్ కోడ్ (Complete Project)

క్రింది కోడ్ అన్ని ఫీచర్లను (Add, Display, Search, Delete, Binary File Persistence, Memory Cleanup) సమగ్రంగా కలిగి ఉంది:

C — Complete Student Record System ⚡ Try in C Compiler 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define DATA_FILE "students.dat"

typedef struct {
    int rollNo;
    char name[40];
    float marks;
} Student;

Student *students = NULL;
int studentCount = 0;

void addStudent(void) {
    Student *temp = (Student*) realloc(students, (studentCount + 1) * sizeof(Student));
    if (temp == NULL) {
        printf("మెమరీ కేటాయింపు విఫలమైంది!\n");
        return;
    }
    students = temp;

    printf("\nరోల్ నంబర్: ");
    scanf("%d", &students[studentCount].rollNo);
    printf("పేరు: ");
    scanf(" %39s", students[studentCount].name);
    printf("మార్కులు: ");
    scanf("%f", &students[studentCount].marks);

    studentCount++;
    printf("✅ రికార్డు జోడించబడింది!\n");
}

void displayStudents(void) {
    if (studentCount == 0) {
        printf("\n[రికార్డులు ఏవీ లేవు]\n");
        return;
    }
    printf("\n-------------------------------------------------\n");
    printf("%-10s %-25s %-10s\n", "రోల్ నెం", "పేరు", "మార్కులు");
    printf("-------------------------------------------------\n");
    for (int i = 0; i < studentCount; i++) {
        printf("%-10d %-25s %-10.2f\n", students[i].rollNo, students[i].name, students[i].marks);
    }
    printf("-------------------------------------------------\n");
}

void searchStudent(void) {
    if (studentCount == 0) {
        printf("\nవెతకడానికి రికార్డులు లేవు!\n");
        return;
    }
    int roll;
    printf("\nవెతకాల్సిన రోల్ నంబర్: ");
    scanf("%d", &roll);

    for (int i = 0; i < studentCount; i++) {
        if (students[i].rollNo == roll) {
            printf("🎯 రికార్డు లభించింది: %s | మార్కులు: %.2f\n", students[i].name, students[i].marks);
            return;
        }
    }
    printf("❌ రోల్ నంబర్ %d తో ఎవరూ లేరు.\n", roll);
}

void saveToFile(void) {
    FILE *fp = fopen(DATA_FILE, "wb");
    if (fp == NULL) return;
    fwrite(&studentCount, sizeof(int), 1, fp);
    fwrite(students, sizeof(Student), studentCount, fp);
    fclose(fp);
    printf("💾 డేటా సేవ్ చేయబడింది.\n");
}

void loadFromFile(void) {
    FILE *fp = fopen(DATA_FILE, "rb");
    if (fp == NULL) return;
    fread(&studentCount, sizeof(int), 1, fp);
    if (studentCount > 0) {
        students = (Student*) malloc(studentCount * sizeof(Student));
        if (students != NULL) {
            fread(students, sizeof(Student), studentCount, fp);
        }
    }
    fclose(fp);
}

int main(void) {
    loadFromFile();
    int choice;

    do {
        printf("\n=== స్టూడెంట్ రికార్డ్ మేనేజ్‌మెంట్ ===\n");
        printf("1. విద్యార్థిని జోడించు (Add)\n");
        printf("2. అందరినీ ప్రదర్శించు (Display All)\n");
        printf("3. రోల్ నంబర్ తో వెతుకు (Search)\n");
        printf("4. సేవ్ చేసి నిష్క్రమించు (Save & Exit)\n");
        printf("మీ ఎంపిక: ");
        if (scanf("%d", &choice) != 1) break;

        switch (choice) {
            case 1: addStudent(); break;
            case 2: displayStudents(); break;
            case 3: searchStudent(); break;
            case 4: saveToFile(); break;
            default: printf("చెల్లని ఎంపిక!\n");
        }
    } while (choice != 4);

    // క్లీన్ ఎగ్జిట్ & మెమరీ విడుదల
    if (students != NULL) {
        free(students);
        students = NULL;
    }
    printf("ప్రోగ్రామ్ విజయవంతంగా ముగిసింది.\n");
    return 0;
}
6బిగినర్స్ చేసే ప్రాజెక్ట్ తప్పులు (Project Pitfalls)
❌ 1. realloc నేరుగా పాత పాయింటర్‌కు అసైన్ చేయడం:
students = (Student*) realloc(students, new_size); // ప్రమాదకరం! ఒకవేళ మెమరీ కేటాయింపు ఫెయిల్ అయితే realloc NULL రిటర్న్ చేస్తుంది. దానివల్ల students లో ఉన్న పాత డేటా మెమరీ అడ్రస్ కూడా శాశ్వతంగా పోతుంది (Memory Leak). అందుకే తాత్కాలిక temp వేరియబుల్ వాడాలి.
❌ 2. మెమరీ కేటాయించకుండా fread చేయడం:
fread(students, sizeof(Student), count, fp); // students is NULL! ఫైల్ నుండి డేటా చదవడానికి ముందు తప్పనిసరిగా students = malloc(count * sizeof(Student)) ద్వారా హీప్‌పై స్థలాన్ని సిద్ధం చేయాలి.
❌ 3. స్ట్రింగ్ ఇన్‌పుట్‌లో బఫర్ లిమిట్ పెట్టకపోవడం:
scanf("%s", students[i].name); // బఫర్ ఓవర్‌ఫ్లో ప్రమాదం అర్రే సైజ్ 40 ఉన్నప్పుడు యూజర్ 100 అక్షరాలు టైప్ చేస్తే పక్కనున్న మార్కుల మెమరీ కరప్ట్ అవుతుంది. ఎల్లప్పుడూ scanf(" %39s", ...) అని లిమిట్ పేర్కొనాలి.
7తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: ఈ ప్రాజెక్ట్‌లో ఒక రికార్డును డిలీట్ చేయాలంటే ఎలా చేయాలి?

డిలీట్ చేయాలనుకున్న ఇండెక్స్ నుండి చివరి వరకు ఉన్న అన్ని రికార్డులను ఒక స్థానం ఎడమవైపునకు జరపాలి (for (int j = i; j < studentCount - 1; j++) students[j] = students[j + 1];). ఆ తర్వాత studentCount-- చేసి, realloc ద్వారా మెమరీని తగ్గించవచ్చు.

Q: లీనియర్ సెర్చ్ కాకుండా బైనరీ సెర్చ్ ఎలా అమలు చేయాలి?

రోల్ నంబర్ల ఆధారంగా అర్రేను qsort() తో సార్ట్ చేసి, ఆ తర్వాత bsearch() లేదా ఓన్ బైనరీ సెర్చ్ లూప్ వాడి $O(\log N)$ సమయంలో వేగంగా విద్యార్థిని కనుగొనవచ్చు.

Q: భారీ ప్రాజెక్టులలో ఈ డేటాబేస్ పద్ధతి ఎక్కడ ఉపయోగపడుతుంది?

ఇంటర్నెట్ మరియు భారీ SQL సర్వర్లు లేని ఎంబెడెడ్ డివైస్‌లు (మెడికల్ ఎక్విప్‌మెంట్, ఆటోమోటివ్ ఈసీయూలు, ఫ్లైట్ డేటా రికార్డర్లు, రూటర్లు) లో డేటాను లోకల్‌గా అత్యంత వేగంగా భద్రపరచడానికి నేటికీ ఈ బైనరీ స్ట్రక్చర్ ఫైల్ పద్ధతినే వినియోగిస్తారు.
