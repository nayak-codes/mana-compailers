C 2D/3D Arrays, Row-Major Order & Matrix Mathematics (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 15 📂 Phase 07: Arrays & Memory Organization 📅 2026 Edition
📌 Covered in this in-depth guide: 2D/3D Array Architecture · Row-Major Memory Mapping Formula · Matrix Addition & Transpose · Array of Characters vs Strings

Phase 7 (Chapter 15): C 2D Arrays & Matrix Mathematics Masterclass కు స్వాగతం! ఎక్సెల్ షీట్స్, చెస్ బోర్డ్, ఇమేజ్ పిక్సెల్స్ లాంటివి ప్రోగ్రామింగ్ లో సేవ్ చేయాలంటే 1D Array సరిపోదు. అడ్డు వరుసలు, నిలువు వరుసలు (Rows & Columns) ఉన్న Multi-Dimensional Arrays (2D/3D) వాడాలి. ఈ గైడ్ లో, 2D Arrays ఎలా పనిచేస్తాయి, కంప్యూటర్ RAM దాన్ని ఒకే లైన్ లో (1D లాగా) ఎలా సేవ్ చేసుకుంటుంది, రెండు మ్యాట్రిక్స్ ని ఎలా కలపాలి (Addition & Transpose), మరియు C లో పేర్లు (Strings) ఎలా సేవ్ అవుతాయో తెలుగులో నేర్చుకుందాం.

12D Array గ్రిడ్ vs RAM లో Row-Major ఆర్డర్

మనం 2D Array ని అడ్డు వరుసలు, నిలువు వరుసలు ఉన్న ఒక టేబుల్ లాగా ఊహించుకుంటాం. కానీ కంప్యూటర్ RAM లో అలా టేబుల్స్ ఉండవు, కేవలం ఒకే ఒక పొడవాటి సింగిల్ లైన్ ఉంటుంది. అందుకని C కంపైలర్ 2D Array ని Row-Major Order లో సేవ్ చేస్తుంది (అంటే ఫస్ట్ 0వ అడ్డు వరుస, దాని పక్కనే 1వ అడ్డు వరుస, అలా వరసగా లైన్ లో సేవ్ చేస్తుంది):

Physical RAM Flattening: int matrix[2][3] = {{1, 2, 3}, {4, 5, 6}};

Conceptual 2D Grid: Physical 1D RAM Linear Sequence:
Row 0: [ 1 ] [ 2 ] [ 3 ] ───► [ 1 ][ 2 ][ 3 ] [ 4 ][ 5 ][ 6 ]
Row 1: [ 4 ] [ 5 ] [ 6 ] └──────┬──────┘ └──────┬──────┘
Row 0 Bytes Row 1 Bytes

Memory Address Formula:
Address(matrix[i][j]) = Base_Address + (i * Total_Cols + j) * sizeof(element)
2Matrix మ్యాథ్స్: మ్యాట్రిక్స్ కలపడం (Addition) & రివర్స్ చేయడం (Transpose)

📐 1. Matrix Addition (రెండు మ్యాట్రిక్స్ ని కలపడం)

దీనికి రెండు మ్యాట్రిక్స్ కచ్చితంగా ఒకే సైజ్ $(M imes N)$ లో ఉండాలి. లోపల ఉన్న వాల్యూస్ ని ఒకదానితో ఒకటి డైరెక్ట్ గా కలుపుతాము (Nested loops వాడి).

🔄 2. Matrix Transpose (అడ్డు వరుసలని నిలువుగా మార్చడం)

ఒక మ్యాట్రిక్స్ ని అడ్డం నుండి నిలువుకి (Rows ని Columns గా) తిప్పడాన్నే Transpose అంటారు. అప్పుడు $(M imes N)$ సైజ్ ఉన్న మ్యాట్రిక్స్ కాస్తా $(N imes M)$ అవుతుంది.

C — 2D Matrix Addition & Transpose Algorithms ▶ Run Code 
#include <stdio.h>

#define ROWS 2
#define COLS 3

int main(void) {
    int A[ROWS][COLS] = {{1, 2, 3}, {4, 5, 6}};
    int B[ROWS][COLS] = {{7, 8, 9}, {1, 2, 3}};
    int Sum[ROWS][COLS];
    int Transpose[COLS][ROWS];

    // 1. Matrix Addition
    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLS; j++) {
            Sum[i][j] = A[i][j] + B[i][j];
        }
    }

    // 2. Matrix Transposition of A (2x3 -> 3x2)
    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLS; j++) {
            Transpose[j][i] = A[i][j];
        }
    }

    printf("--- Matrix Sum (A + B) ---\n");
    for (int i = 0; i < ROWS; i++) {
        for (int j = 0; j < COLS; j++) printf("%3d ", Sum[i][j]);
        printf("\n");
    }

    printf("\n--- Transpose of Matrix A (3x2) ---\n");
    for (int i = 0; i < COLS; i++) {
        for (int j = 0; j < ROWS; j++) printf("%3d ", Transpose[i][j]);
        printf("\n");
    }

    return 0;
}
