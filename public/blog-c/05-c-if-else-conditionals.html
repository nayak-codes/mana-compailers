కండిషనల్ స్టేట్‌మెంట్స్ (if, else if, else & Nested Branches)

⚡ Modern C (C99 / C11) 🟢 Chapter 5 of 20 📂 Phase 02: కంట్రోల్ ఫ్లో & లూప్స్ 📅 2026 Edition
📌 Covered in this chapter: డెసిషన్ మేకింగ్ లాజిక్ · ATM క్యాష్ విత్‌డ్రా చెక్ · గ్రేడింగ్ సిస్టమ్ · డాంగ్లింగ్ else సమస్య · అసైన్‌మెంట్ ట్రాప్ if (x = 5)
కంప్యూటర్ ప్రోగ్రామ్‌లు కేవలం క్రమపద్ధతిలో పైనుండి క్రిందికి లైన్లను ఎగ్జిక్యూట్ చేయడమే కాకుండా, పరిస్థితులకు అనుగుణంగా నిర్ణయాలు (Decision Making) తీసుకోగలగాలి. నిజ జీవితంలో ATM క్యాష్ విత్‌డ్రా చెకింగ్, ఎగ్జామ్ గ్రేడింగ్ లేదా గేమింగ్ లాజిక్‌లో నిర్ణయాలు తీసుకోవడానికి C లో కండిషనల్ స్టేట్‌మెంట్స్ (Conditional Statements) మూలాధారం. ఈ అధ్యాయంలో if, else if, else, నెస్టెడ్ బ్రాంచ్‌లు, డాంగ్లింగ్ ఎల్స్ సమస్య మరియు టెర్నరీ ఆపరేటర్లను సమగ్రంగా పరిశీలిద్దాం.
1if, else if, else డెసిషన్ మేకింగ్ ఆర్కిటెక్చర్

C లో కండిషన్లను పరీక్షించినప్పుడు కంప్యూటర్ ఒక ప్రాథమిక సూత్రాన్ని పాటిస్తుంది: ఏదైనా నాన్-జీరో (Non-zero) విలువ సత్యం (TRUE / 1), మరియు కేవలం సున్నా మాత్రమే అసత్యం (FALSE / 0).

1. సింగిల్ if స్టేట్‌మెంట్ (Single Branch)

ఇచ్చిన షరతు నిజమైతేనే (True) ఆ బ్లాక్ రన్ అవుతుంది. అబద్ధమైతే (False) ప్రోగ్రామ్ దాన్ని దాటవేసి ముందుకు వెళ్తుంది.

2. if-else స్టేట్‌మెంట్ (Two-Way Branch)

షరతు నిజమైతే if బ్లాక్, అబద్ధమైతే ప్రత్యామ్నాయంగా else బ్లాక్ ఖచ్చితంగా ఎగ్జిక్యూట్ అవుతుంది.

3. else-if లాడర్ (Multi-Way Ladder)

బహుళ షరతులను వరుసగా తనిఖీ చేస్తుంది. మొదటి ఏ షరతు నిజమైతే ఆ బ్లాక్ రన్ అయి మిగిలిన మొత్తం లాడర్ స్కిప్ అవుతుంది.

C — ATM Cash Withdrawal Logic ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int balance = 5000;
    int withdrawAmount = 2000;

    if (withdrawAmount <= 0) {
        printf("చెల్లని మొత్తం! దయచేసి ధన సంఖ్యను నమోదు చేయండి.\n");
    } else if (withdrawAmount > balance) {
        printf("సరిపడా బ్యాలెన్స్ లేదు! మీ ఖాతాలో ఉన్నది: %d\n", balance);
    } else {
        balance -= withdrawAmount;
        printf("విత్‌డ్రా విజయవంతమైంది: %d. మిగిలిన బ్యాలెన్స్: %d\n", withdrawAmount, balance);
    }
    return 0;
}
2నెస్టెడ్ if-else & డాంగ్లింగ్ else సమస్య (The Dangling else)

ఒక if లేదా else బ్లాక్ లోపల మరొక కండిషనల్ స్టేట్‌మెంట్‌ను రాయడాన్ని నెస్టెడ్ కండిషన్స్ (Nested Conditions) అంటారు. అయితే బ్రాకెట్లు { } సరిగ్గా వాడకపోతే కంపైలర్‌లో డాంగ్లింగ్ ఎల్స్ (Dangling else) అనే క్లాసికల్ బగ్ తలెత్తుతుంది:

⚠️ డాంగ్లింగ్ else ట్రాప్: if (a > 0)
    if (b > 0)
        printf("Both positive");
else
    printf("Is this for 'a' or 'b'?"); // ఎవరి else ఇది?

చూసే ప్రోగ్రామర్‌కి ఆ else మొదటి if(a > 0) కి చెందినదిగా అనిపించవచ్చు. కానీ C నియమం ప్రకారం ఏ బ్రాకెట్ లేని else ఎల్లప్పుడూ తనకు అత్యంత సమీపంలో ఉన్న మునుపటి if కే చెందుతుంది! అంటే ఇక్కడ b > 0 కి అటాచ్ అవుతుంది. అందుకే ఎల్లప్పుడూ స్పష్టమైన కర్లీ బ్రేసెస్ { ... } వాడాలి.

3టెర్నరీ ఆపరేటర్ (Ternary Operator ?: )

సాధారణ రెండు లైన్ల if-else బ్లాక్‌ను కేవలం ఒకే ఒక్క లైన్‌లో ఎక్స్‌ప్రెషన్‌గా రాయడానికి టెర్నరీ ఆపరేటర్ (?:) ఉపయోగపడుతుంది.

C — Ternary conditional expression ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int num = 17;
    // సింటాక్స్: condition ? value_if_true : value_if_false
    printf("సంఖ్య %d అనేది: %s\n", num, (num % 2 == 0) ? "సరి సంఖ్య (Even)" : "బేసి సంఖ్య (Odd)");

    int a = 45, b = 80;
    int max = (a > b) ? a : b;
    printf("గరిష్ట సంఖ్య: %d\n", max);
    return 0;
}
4బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. if పక్కన సెమికోలన్ పెట్టడం (The Empty Statement Trap):
if (age >= 18); { printf("ఓటు హక్కు ఉంది"); } // సెమికోలన్ పెట్టరాదు! if(...); అని పెడితే కండిషన్ అక్కడితో ముగిసిపోతుంది (Empty Statement). ఫలితంగా వయస్సు ఎంత ఉన్నా కర్లీ బ్రేసెస్ లోని కోడ్ ప్రతిసారీ రన్ అయిపోతుంది!
❌ 2. Yoda Conditions వాడకపోవడం (The Assignment Trap):
if (status = 1) // తప్పు! == బదులు = అసైన్ చేస్తుంది ప్రొఫెషనల్స్ ఈ బగ్ నివారించడానికి if (1 == status) అని స్థిరాంకాన్ని (Constant) ఎడమవైపు రాస్తారు. ఒకవేళ పొరపాటున = రాసినా కంపైలర్ వెంటనే ఎర్రర్ చూపిస్తుంది.
5తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: C లో if (-10) రాస్తే కండిషన్ True అవుతుందా లేక False అవుతుందా?

ఖచ్చితంగా TRUE అవుతుంది! C లాంగ్వేజ్ మెమరీ నియమాల ప్రకారం 0 మాత్రమే అసత్యం (FALSE). ధన సంఖ్యలు (+5), రుణ సంఖ్యలు (-10) మరియు ఏదైనా నాన్-జీరో అడ్రస్ అన్నీ సత్యం (TRUE) గానే పరిగణించబడతాయి.

Q: else-if లాడర్ మరియు switch లలో దేనిని ఎప్పుడు ఎంచుకోవాలి?

రేంజ్‌లు లేదా సంక్లిష్టమైన లాజికల్ కండిషన్లు (age >= 18 && score > 80) ఉన్నప్పుడు else-if వాడాలి. కేవలం స్థిరమైన పూర్ణాంకాలు లేదా క్యారెక్టర్ల చాయిస్‌లతో (మెనూ ఆప్షన్లు 1, 2, 3...) పనిచేసేటప్పుడు వేగవంతమైన switch వాడాలి.
