కండిషనల్ స్టేట్‌మెంట్స్ (if, else if, else & Nested Branches)

⚡ Modern C (C99 / C11) 🟢 Chapter 5 of 20 📂 Phase 02: కంట్రోల్ ఫ్లో & లూప్స్ 📅 2026 Edition
📌 Covered in this chapter: డెసిషన్ మేకింగ్ లాజిక్ · ATM క్యాష్ విత్‌డ్రా చెక్ · గ్రేడింగ్ సిస్టమ్ · డాంగ్లింగ్ else సమస్య · అసైన్‌మెంట్ ట్రాప్ if (x = 5)
పరిస్థితులకు అనుగుణంగా సరైన నిర్ణయాలు తీసుకోవడానికి C లో if, if-else, మరియు else-if ladder వాడతాం. ATM క్యాష్ విత్‌డ్రా లాజిక్ మరియు కండిషన్లలో = వాడటం వల్ల వచ్చే ప్రమాదాలను విశ్లేషిద్దాం.
1ATM Cash Withdrawal Decision Making
C — if-else branching ▶ Run in Compiler 
#include <stdio.h>

int main() {
    double balance = 5000.0, withdraw = 2000.0;
    if (withdraw <= balance) {
        balance -= withdraw;
        printf("Success: Dispensed Rs. %.2f\n", withdraw);
    } else {
        printf("Declined: Insufficient Funds!\n");
    }
    printf("Balance: Rs. %.2f\n", balance);
    return 0;
}
2బిగినర్స్ చేసే ప్రమాదకరమైన తప్పు: if (x = 5)
❌ Assignment vs Equality Bug:

if (score == 100) రాయాల్సింది పోయి పొరపాటున if (score = 100) రాస్తే అది 100 విలువను అసైన్ చేసి ఎల్లప్పుడూ true గా మారిపోతుంది! దీని నివారణకు if (100 == score) అని రాయడం అలవాటు చేసుకోవాలి.
