Queue Implementation (Linear & Circular) (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 55 📂 Phase 18: Data Structures - 1 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: FIFO Concept · Enqueue and Dequeue · Front & Rear Pointers · Circular Queue Magic

లాస్ట్ లెసన్ లో మనం ప్లేట్ల దొంతర లాంటి స్టాక్ (LIFO) గురించి నేర్చుకున్నాం కదా. కానీ రియల్ లైఫ్ లో ఎవరైనా సినిమా టికెట్స్ కోసం లైన్ లో నిలబడితే, ముందు వచ్చిన వాడికే ముందు టికెట్ ఇస్తారు కానీ లాస్ట్ వచ్చిన వాడికి ఇవ్వరు కదా! ఈ లాజిక్ ని కంప్యూటర్ లో డిజైన్ చేయడాన్నే Queue (క్యూ) అంటారు. దీన్ని FIFO (First In, First Out) అంటారు. మీరు ప్రింటర్ కి 10 ఫైల్స్ ఇస్తే ఏది ముందు ప్రింట్ అవ్వాలి? కస్టమర్ కేర్ కాల్స్ లో ఎవరితో ముందు మాట్లాడాలి? ఇలాంటి సర్వీస్ లాజిక్స్ అన్నీ ఈ Queue స్ట్రక్చర్ మీదే రన్ అవుతాయి. ఇదెలాగో ఈరోజు అద్భుతంగా నేర్చుకుందాం.

1 క్యూ (Queue) లో రెండు పాయింటర్స్!

స్టాక్ లో కేవలం ఒకటే టాప్ (Top) ఉంటుంది. కానీ క్యూ లో ఇద్దరు ఉంటారు. ఒకటి ముందు (Front), రెండు వెనక (Rear).

🎟️ రియల్ లైఫ్ స్టోరీ: సినిమా థియేటర్ లైన్ (Enqueue & Dequeue)

ఒక థియేటర్ ముందు క్యూ లైన్ ఉంది.

1. Enqueue (లోపలికి వెళ్లడం): కొత్తగా ఒకడు వస్తే ఎక్కడ నిలబడతాడు? క్యూ వెనకాల (Rear) నిలబడతాడు. అంటే మనం డేటా యాడ్ చేయాలంటే ఎప్పుడూ Rear దగ్గరే యాడ్ చేయాలి. ఆ తర్వాత Rear ఒక స్టెప్ వెనక్కి జరుగుతుంది.

2. Dequeue (బయటికి రావడం): కౌంటర్ లో ఉన్నవాడు ఎవరికి టికెట్ ఇస్తాడు? లైన్ లో ముందు (Front) ఉన్నోడికే! వాడు టికెట్ తీసుకుని వెళ్ళిపోగానే, Front ఒక స్టెప్ వెనక్కి వస్తుంది.

క్యూ పూర్తిగా ఫుల్ అయితే Overflow, అసలు ఎవరూ లేకపోతే Underflow అంటారు.

2 మామూలు క్యూ లో ప్రాబ్లమ్ ఏంటి? (Linear Waste)

మీ దగ్గర 5 కుర్చీలు ఉన్న ఒక క్యూ ఉంది అనుకోండి (Array Size 5). ఐదుగురు వచ్చి కూర్చున్నారు (ఫుల్). ఇప్పుడు ముందు ఉన్న ఇద్దరు టికెట్ తీసుకుని వెళ్లిపోయారు. వాళ్ళ కుర్చీలు (Index 0, 1) ఖాళీ అయ్యాయి! కానీ కొత్త వాళ్లు రావాలంటే అటు వెనకాలే రావాలి, వెనకాల కుర్చీలు లేవు! ముందు రెండు కుర్చీలు ఖాళీ ఉన్నా వాడలేము. దీన్నే Linear Queue Waste అంటారు.

దీన్ని సాల్వ్ చేయడానికే Circular Queue (చక్రాకార క్యూ) కనిపెట్టారు. ఇందులో లాస్ట్ కుర్చీ తర్వాత మళ్ళీ డైరెక్ట్ గా ఫస్ట్ కుర్చీ కి లింక్ ఉంటుంది.

3 ఒకే ఒక సింపుల్ కోడ్ (Linear Queue Demo)

కింద కోడ్ లో అర్రే వాడి ఒక సింపుల్ క్యూ ని ఎలా తయారు చేసామో, Front మరియు Rear పాయింటర్స్ ని ఎలా మార్చామో చూడండి.

C — Linear Queue (FIFO) ▶ Run Code 
#include <stdio.h>

#define MAX 5 // క్యూ సైజు 5 

int queue[MAX];
int front = -1; // ముందు పాయింటర్
int rear = -1;  // వెనక పాయింటర్

// 1. ఎన్-క్యూ (లైన్ లోకి వెళ్లడం)
void enqueue(int data) {
    if (rear == MAX - 1) { // క్యూ మొత్తం నిండిపోయింది
        printf("[Error] Queue is FULL! (Overflow)\n");
        return;
    }
    
    // ఒకవేళ ఇదే ఫస్ట్ ఎంట్రీ అయితే ఫ్రంట్ ని కూడా జీరోకి తేవాలి
    if (front == -1) {
        front = 0;
    }
    
    rear++; // వెనక ఒక స్టెప్ జరిపి
    queue[rear] = data; // అక్కడ కూర్చోపెడదాం
    printf("Enqueued: %d\n", data);
}

// 2. డి-క్యూ (టికెట్ తీసుకుని వెళ్ళిపోవడం)
void dequeue() {
    // అసలు క్యూ లో ఎవరూ లేకపోతే...
    if (front == -1 || front > rear) {
        printf("[Error] Queue is EMPTY! (Underflow)\n");
        return;
    }
    
    printf("Dequeued: %d (He got the ticket!)\n", queue[front]);
    front++; // నెక్స్ట్ వాడికి ఫ్రంట్ ని జరుపుదాం
}

// క్యూ లో ఉన్న వాళ్ళందరినీ ప్రింట్ చేద్దాం
void display() {
    if (front == -1 || front > rear) {
        printf("Queue is Empty.\n");
        return;
    }
    
    printf("Current Queue: ");
    for (int i = front; i <= rear; i++) {
        printf("%d ", queue[i]);
    }
    printf("\n");
}

int main() {
    printf("--- Queue Operations (FIFO) ---\n\n");
    
    // ముగ్గురిని లైన్ లో పెడదాం
    enqueue(10);
    enqueue(20);
    enqueue(30);
    
    display(); // 10 20 30
    
    // ఇద్దరికి టికెట్ ఇద్దాం
    printf("\nIssueing tickets...\n");
    dequeue(); // 10 వెళ్ళిపోతాడు
    dequeue(); // 20 వెళ్ళిపోతాడు
    
    display(); // ఇప్పుడు కేవలం 30 మాత్రమే లైన్ లో ఉంటాడు
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • front = -1, rear = -1: మొదట్లో ఇద్దరూ గ్రౌండ్ లో ఉంటారు. ఫస్ట్ వాడు వచ్చినప్పుడు ఇద్దరూ ఒకేసారి 0 దగ్గరికి వస్తారు.
  • rear++: కొత్త వాడు వస్తే వెనక ఉన్నోడు (Rear) జరిగి జరిగి వాల్యూ పెరుగుతూ వెళ్తుంది.
  • front++: ముందున్నోడు వెళ్ళిపోగానే, ఫ్రంట్ పాయింటర్ వాల్యూ పెరుగుతూ వెళ్తుంది. ఒకవేళ ఫ్రంట్ వాల్యూ, రియర్ ని దాటి ముందుకు వెళ్లిపోయిందంటే లైన్ ఖాళీ అయినట్టే లెక్క (front > rear)!
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: Circular Queue లాజిక్ ని (%) వాడి ఎలా రాస్తారు?

సింపుల్! నార్మల్ క్యూ లో rear++ రాస్తాం కదా, సర్క్యులర్ క్యూ లో rear = (rear + 1) % MAX అని రాస్తాం. ఒకవేళ MAX 5 అయితే, లాస్ట్ ఇండెక్స్ (4+1)%5 చేస్తే ఆన్సర్ 0 వస్తుంది. అంటే 4వ కుర్చీ నుండి డైరెక్ట్ గా మళ్ళీ 0వ కుర్చీకి రౌండ్ తిరిగి వెళ్ళిపోతుంది. ఇదే సర్క్యులర్ క్యూ మ్యాజిక్!

Q2: Priority Queue (ప్రియారిటీ క్యూ) అంటే ఏంటి?

ఇది ఒక స్పెషల్ క్యూ! ఆసుపత్రి ఎమర్జెన్సీ వార్డ్ లాంటిది. ఒక నార్మల్ పేషెంట్ వెళ్తే లైన్ లో నిలబడతాడు. కానీ ఎవరికైనా హార్ట్ ఎటాక్ వస్తే, వాడిని లైన్ వెనకాల కాకుండా డైరెక్ట్ గా ఫ్రంట్ కి (Priority) పంపిస్తారు. ఆపరేటింగ్ సిస్టమ్ లో VIP టాస్క్ లకి ముందు ర్యామ్ ఇవ్వడానికి ఈ డేటా స్ట్రక్చరే వాడుతారు (Heaps వాడి రాస్తారు).

Q3: 2 Stacks వాడి ఒక Queue ని తయారు చేయొచ్చా?

ఎస్! ఇది ఇంటర్వ్యూలలో కచ్చితంగా అడిగే పజిల్. స్టాక్ అనేది రివర్స్ చేస్తుంది కదా. ఒక బాక్స్ లో వేసి, మళ్ళీ ఆ బాక్స్ ని రివర్స్ చేసి ఇంకో బాక్స్ లో వేస్తే... రివర్స్ కి రివర్స్ ఒరిజినల్ అవుతుంది కదా! ఈ లాజిక్ తో రెండు స్టాక్స్ వాడి ఒక పర్ఫెక్ట్ క్యూ ని సిమ్యులేట్ చేయొచ్చు.
