C Functions, Prototypes, Scope & static Local Variables (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 10 📂 Phase 06: Functions & Modular Architecture 📅 2026 Edition
📌 Covered in this in-depth guide: Function Architecture · Prototypes · Parameters vs Arguments · void Return · Local vs Global · static Local Variables · Header Files (.h)

Phase 6 (Part 1): C Functions & Modular Architecture Masterclass కు స్వాగతం! మన కోడ్ మొత్తాన్ని ఒకే main() ఫంక్షన్ లో రాస్తే, అది చూడటానికి కన్ఫ్యూజింగ్ గా ఉంటుంది మరియు ఎక్కడ తప్పు జరిగిందో కనిపెట్టడం కష్టం అవుతుంది. దీన్ని సాల్వ్ చేయడానికి Functions వాడతాం. పెద్ద ప్రోగ్రామ్ ని చిన్న చిన్న ముక్కలుగా విడదీసి ఎక్కడ కావాలంటే అక్కడ వాడుకునేలా చేయడమే ఫంక్షన్స్ స్పెషాలిటీ. ఈ గైడ్ లో, ఫంక్షన్ రాయడానికి కావాల్సిన 3 ముఖ్యమైన స్టెప్స్, ఫంక్షన్ ప్రోటోటైప్స్, పారామీటర్స్, void అంటే ఏంటి, static వేరియబుల్స్ ఎలా పనిచేస్తాయి, మరియు .h ఫైల్స్ తో ప్రొఫెషనల్ ప్రాజెక్ట్స్ ఎలా క్రియేట్ చేయాలో తెలుగులో నేర్చుకుందాం.

1Functions అంటే ఏంటి? & వాటిలో ఉండే 3 స్టెప్స్

Function అంటే ఒక పర్టికులర్ పని చేయడానికి మనం రాసుకున్న ఒక చిన్న కోడ్ బ్లాక్. C లో ఫంక్షన్ ని వాడాలంటే ఈ 3 స్టెప్స్ (Stages) కచ్చితంగా ఉండాలి:

  1. 1. Declaration (Prototype): int add(int first, int second);
    మనం ఒక ఫంక్షన్ రాస్తున్నామని, దానికి ఏ పేరు పెడుతున్నామో, అది ఏ వాల్యూ ఇస్తుందో main() కంటే ముందే కంపైలర్ కి చెప్పడం.
  2. 2. Function Call (పిలవడం): int result = add(10, 20);
    ఆ ఫంక్షన్ మనకు ఎప్పుడు కావాలంటే అప్పుడు వాల్యూస్ (Arguments) పాస్ చేసి దాన్ని రన్ అయ్యేలా పిలవడం.
  3. 3. Definition (కోడ్ రాయడం): int add(int first, int second) { return first + second; }
    ఆ ఫంక్షన్ అసలు ఏం పని చేయాలో ఆ బ్రాకెట్స్ { ... } మధ్యలో పూర్తి కోడ్ రాయడం.

💡 Parameters కి Arguments కి తేడా ఏంటి?

• Parameters (పారామీటర్లు): మనం ఫంక్షన్ రాసేటప్పుడు ఆ బ్రాకెట్స్ లో తీసుకునే ఖాళీ వేరియబుల్స్ (ఉదాహరణకి int first, int second). ఇవి బాక్స్ ల లాంటివి.
• Arguments (ఆర్గ్యుమెంట్స్): మనం ఫంక్షన్ ని కాల్ చేసినప్పుడు ఆ బాక్స్ లలో వేసే నిజమైన వాల్యూస్ (ఉదాహరణకి 10, 20).

C — User Curriculum Standard Example ▶ Run in C Compiler 
#include <stdio.h>

// 1. Function Prototype (Declaration)
int add(int first, int second);

int main(void) {
    // 2. Function Call (Passing arguments 10 and 20)
    int result = add(10, 20);
    printf("Result: %d\n", result);

    return 0;
}

// 3. Function Definition
int add(int first, int second) {
    return first + second;
}
2Return Types & "void" అంటే ఏంటి?

C లో ఫంక్షన్స్ రన్ అయ్యాక ఒక వాల్యూ ని తిరిగి ఇవ్వగలవు (int, float, char వగైరా). ఒకవేళ మన ఫంక్షన్ లోపల పని చేసుకొని బయటికి ఏమీ వాల్యూ ఇవ్వకపోతే, దాన్ని void (ఏమీ ఇవ్వదు) అని చెప్తాము:

C — void & Multi-Parameter Functions ▶ Run Code 
#include <stdio.h>

// void function: takes parameters, displays output, returns nothing
void printReceipt(const char* item, int qty, double unitPrice) {
    double total = qty * unitPrice;
    printf("Item: %-12s | Qty: %2d | Total: Rs.%.2f\n", item, qty, total);
}

int main(void) {
    printReceipt("Coffee Mug", 2, 149.50);
    printReceipt("Notebook",   5,  45.00);
    return 0;
}
3Local vs Global vs static Variables అంటే ఏంటి? ⭐

C లో ఒక వేరియబుల్ ని ఎక్కడ క్రియేట్ చేసామనే దాన్ని బట్టి అది మెమరీలో ఎక్కడ సేవ్ అవుతుంది, ఎంత సేపు ఉంటుంది అనేది మారుతుంది:

వేరియబుల్ రకంRAM లో ఎక్కడ ఉంటుంది?ఎంత సేపు బ్రతికుటుంది? (Lifetime)దాని వాల్యూ ఏమవుతుంది?
లోకల్ వేరియబుల్ (Local)Stack మెమరీలోఫంక్షన్ కాల్ అవ్వగానే పుడుతుంది; ఫంక్షన్ అవ్వగానే చనిపోతుందిప్రతిసారీ కొత్తగా స్టార్ట్ అవుతుంది (పాత వాల్యూ మర్చిపోతుంది).
static లోకల్ వేరియబుల్Data Segment లోప్రోగ్రామ్ మొత్తం రన్ అయ్యేదాకా బ్రతికే ఉంటుంది!పాత వాల్యూ ని గుర్తుపెట్టుకుంటుంది! (ఫంక్షన్ అయిపోయినా వాల్యూ డిలీట్ అవ్వదు).
గ్లోబల్ వేరియబుల్ (Global)Data Segment లోప్రోగ్రామ్ మొత్తం రన్ అయ్యేదాకాఏ ఫంక్షన్ లోనుండైనా డైరెక్ట్ గా వాడుకోవచ్చు.
C — static Local Variable Persistence Demo ▶ Run Code 
#include <stdio.h>

void generateID(void) {
    int normalCounter = 0;       // Re-created as 0 every time on Stack!
    static int persistentID = 1000; // Initialized ONCE in Data Segment!

    normalCounter++;
    persistentID++;

    printf("normalCounter = %d | persistentID = %d\n", normalCounter, persistentID);
}

int main(void) {
    printf("Call 1: "); generateID();
    printf("Call 2: "); generateID();
    printf("Call 3: "); generateID();
    return 0;
}
4Header Files (.h) తో ప్రొఫెషనల్ కోడ్ స్ట్రక్చర్

📁 రియల్-టైం లో C ప్రాజెక్ట్స్ ఎలా క్రియేట్ చేస్తారు? (.h vs .c)

• my_math.h (హెడర్ ఫైల్): ఇందులో కేవలం ఫంక్షన్ ప్రోటోటైప్స్ (పేర్లు) మాత్రమే రాస్తారు (అసలు కోడ్ రాయరు).
• my_math.c (సోర్స్ ఫైల్): ఆ ఫంక్షన్స్ లోపల అసలు ఏం జరగాలో మొత్తం రియల్ కోడ్ ఇక్కడ రాస్తారు.
• main.c (మెయిన్ ఫైల్): ఫస్ట్ లైన్ లో #include "my_math.h" అని చెప్పి, ఆ ఫంక్షన్స్ అన్నింటినీ క్లీన్ గా వాడుకుంటారు!
