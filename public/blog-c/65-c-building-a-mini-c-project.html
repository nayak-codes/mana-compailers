C Master Project & Conclusion (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 65 📂 Phase 20: Algorithms & Final 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Bank Management System · Full Project Code · What's Next? · Course Conclusion

ఇప్పటివరకు మనం 64 లెసన్స్ లో C లాంగ్వేజ్ యొక్క బేసిక్స్, పాయింటర్స్, ఫైల్స్ నుండి మొదలుకుని... కంపైలర్ ఎలా పనిచేస్తుంది, డేటా స్ట్రక్చర్స్, సిస్టమ్ కాల్స్ వరకు అన్నీ విపరీతమైన డెప్త్ లో నేర్చుకున్నాం! కానీ ఇవన్నీ వేరువేరు ముక్కలు (Lego blocks). ఈ ముక్కలన్నీ కలిపి ఒక ప్రాజెక్ట్ గట్టితే గానీ మీకు అసలైన కిక్ రాదు. అందుకే ఈ లాస్ట్ లెసన్ లో మనం Bank Management System (బ్యాంక్ మేనేజ్మెంట్ సిస్టమ్) అనే ఒక సింపుల్ కన్సోల్ (Terminal) అప్లికేషన్ ని ఎలా తయారు చేయాలో నేర్చుకుందాం. దీంట్లో Structs తో డేటాని దాచడం, File Handling తో డేటాని సేవ్ చేయడం లాంటివన్నీ వాడతాం.

1 ప్రాజెక్ట్ లో ఏమేమి ఉంటాయి? (Features)

ఈ చిన్న బ్యాంకు సాఫ్ట్వేర్ లో కింది ఫీచర్స్ ఉంటాయి:

  • క్రొత్త అకౌంట్ ఓపెన్ చేయడం: కస్టమర్ పేరు, డిపాజిట్ అమౌంట్ అడగడం.
  • బ్యాలెన్స్ చెక్ చేయడం: అకౌంట్ నంబర్ ఇస్తే, సిస్టమ్ లో వెతికి చెప్పడం.
  • డేటాని హార్డ్-డిస్క్ లో సేవ్ చేయడం: యాప్ క్లోజ్ చేసినా కూడా డేటా పోకుండా ఒక Text File (bank_data.txt) లో సేవ్ అయ్యుండాలి.
2 ప్రాజెక్ట్ ఫుల్ కోడ్ (Bank Management in C)

ఈ కోడ్ ని మీ లోకల్ VS Code లో కాపీ చేసి రన్ చేయండి. ఆన్లైన్ కంపైలర్స్ లో ఫైల్ సిస్టమ్ పని చేయకపోవచ్చు కాబట్టి లోకల్ గా రన్ చేయడం బెస్ట్.

C — Final Project (Bank System) ▶ Run Code 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// 1. కస్టమర్ డేటా స్టోర్ చేసుకోవడానికి బ్లూప్రింట్
struct Account {
    int acc_no;
    char name[50];
    float balance;
};

// క్రొత్త అకౌంట్ క్రియేట్ చేసి ఫైల్ లో రాసే ఫంక్షన్
void createAccount() {
    struct Account acc;
    FILE *file;
    
    // a+ (Append Mode) లో ఫైల్ ఓపెన్ చేద్దాం
    file = fopen("bank_data.txt", "a+");
    if (file == NULL) {
        printf("Error: Cannot open database file!\n");
        return;
    }
    
    printf("\n--- Open New Account ---\n");
    printf("Enter Account Number : ");
    scanf("%d", &acc.acc_no);
    
    // స్పేస్ లతో సహా పేరు తీసుకోవడానికి ట్రిక్
    printf("Enter Customer Name  : ");
    getchar(); // పాత enter (newline) ని క్లియర్ చేయడానికి
    fgets(acc.name, sizeof(acc.name), stdin);
    acc.name[strcspn(acc.name, "\n")] = 0; // లాస్ట్ లో పడే ఎంటర్ కీ ని తీసేయడం
    
    printf("Enter Initial Deposit: ₹");
    scanf("%f", &acc.balance);
    
    // డేటాని ఫైల్ లోకి రైట్ చేద్దాం (ఫార్మాట్ గా)
    fprintf(file, "%d,%s,%.2f\n", acc.acc_no, acc.name, acc.balance);
    fclose(file);
    
    printf("[Success] Account Created Successfully!\n");
}

// అకౌంట్ నంబర్ తో వెతికే ఫంక్షన్
void searchAccount() {
    struct Account acc;
    FILE *file;
    int search_acc, found = 0;
    
    file = fopen("bank_data.txt", "r");
    if (file == NULL) {
        printf("Database is Empty! Create an account first.\n");
        return;
    }
    
    printf("\n--- Search Account ---\n");
    printf("Enter Account Number to Search: ");
    scanf("%d", &search_acc);
    
    // ఫైల్ లో ప్రతి లైన్ ని చదివి అందులో మన అకౌంట్ ఉందా అని చూద్దాం
    // "%d,%49[^,],%f" అనే ఫార్మాట్ వాడి కామా (,) తో డేటాని విడదీసి చదువుతాం
    while (fscanf(file, "%d,%49[^,],%f", &acc.acc_no, acc.name, &acc.balance) == 3) {
        if (acc.acc_no == search_acc) {
            printf("\n--- Account Details ---\n");
            printf("A/C No  : %d\n", acc.acc_no);
            printf("Name    : %s\n", acc.name);
            printf("Balance : ₹%.2f\n", acc.balance);
            found = 1;
            break;
        }
    }
    
    if (found == 0) {
        printf("Error: Account Number not found!\n");
    }
    fclose(file);
}

// మెయిన్ మెనూ లూప్
int main() {
    int choice;
    
    printf("=========================================\n");
    printf("       WELCOME TO OUR COMPILER BANK      \n");
    printf("=========================================\n");
    
    while (1) {
        printf("\n[1]. Create New Account\n");
        printf("[2]. Check Balance\n");
        printf("[3]. Exit System\n");
        printf("Enter your choice: ");
        scanf("%d", &choice);
        
        switch (choice) {
            case 1: createAccount(); break;
            case 2: searchAccount(); break;
            case 3: 
                printf("Thank you for using our Bank. Goodbye!\n");
                return 0; // ప్రోగ్రామ్ క్లోజ్
            default:
                printf("Invalid Choice! Please enter 1, 2 or 3.\n");
        }
    }
    return 0;
}
3 కోడ్ లో ఏం జరుగుతోంది? (The Architecture)
  • while(1) (ఇన్ఫినిట్ లూప్): మెయిన్ ఫంక్షన్ లో యాప్ వెంటనే క్లోజ్ అవ్వకుండా, మనం కీబోర్డ్ లో 3 (Exit) నొక్కేదాకా మెనూ చూపిస్తూనే ఉండాలి కదా! అందుకే ఈ లూప్ వాడాం.
  • File Operations: fopen(..., "a+") అంటే అపెండ్ (Append) మోడ్. అంటే పాత కస్టమర్స్ డేటా డిలీట్ అవ్వదు, ఆ ఫైల్ కిందనే కొత్త లైన్ లో నెక్స్ట్ కస్టమర్ డేటా సేవ్ అవుతుంది. డేటాబేస్ (MySQL) లేనప్పుడు ఇలా టెక్స్ట్ ఫైల్స్ నే డేటాబేస్ లాగా వాడొచ్చు.
  • fscanf Regex: %49[^,] అంటే ఏంటి? కామా (,) వచ్చేంత వరకు అక్షరాలని చదువు (Scan) అని కంపైలర్ కి స్పెషల్ లాజిక్ చెప్తున్నాం. (అంటే కస్టమర్ పేరు ని సపరేట్ చేయడానికి వాడే ట్రిక్ ఇది).
4 వాట్ నెక్స్ట్? (ఇక మీ పయనం ఎటు?)

🚀 C నేర్చుకున్నాక నెక్స్ట్ ఏం నేర్చుకోవాలి?

C లాంగ్వేజ్ అనేది అన్ని మోడరన్ లాంగ్వేజెస్ కి అమ్మ లాంటిది. మీకు C లో పాయింటర్స్, మెమరీ మేనేజ్మెంట్ అర్థమైతే, ఇక ప్రపంచంలో ఏ లాంగ్వేజ్ అయినా 10 రోజుల్లో నేర్చేసుకోవచ్చు.

1. ఆబ్జెక్ట్ ఓరియెంటెడ్ (OOP): C++ లేదా Java నేర్చుకోండి. C లో ఉన్న Structs కి ఫంక్షన్స్ కూడా కలిపితే అదే Class (క్లాస్) అవుతుంది. పెద్ద ప్రాజెక్ట్స్ కి అది వాడుతారు.
2. ఎంబెడెడ్ సిస్టమ్స్ (Hardware): ఎలక్ట్రానిక్స్ (Arduino, Raspberry Pi, IoT) మీద ఆసక్తి ఉంటే Embedded C వైపు వెళ్లండి.
3. ఆపరేటింగ్ సిస్టమ్స్: లైనక్స్ కెర్నల్ (Linux Kernel) సోర్స్ కోడ్ ని డౌన్లోడ్ చేసి చదవడం అలవాటు చేసుకోండి. సిస్టమ్ ప్రోగ్రామింగ్ కి మీరే దేవుడు అవుతారు.
