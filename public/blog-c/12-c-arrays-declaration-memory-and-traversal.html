Arrays Basics: Declaration, Memory & Traversal (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 12 📂 Phase 07: Arrays & Memory Organization 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Array అంటే ఏంటి? · Contiguous Memory ఆల్లోకేషన్ · Indexing (0-based)

క్లాస్ లో 100 మంది స్టూడెంట్స్ ఉంటే 100 వేరియబుల్స్ క్రియేట్ చేయడం అసాధ్యం కదా! ఇలా ఒకే రకమైన డేటాని ఒకే పేరుతో స్టోర్ చేసుకోవడానికి కనుగొన్న కాన్సెప్ట్ పేరే Array (అర్రే).

1 Array ని ఎలా ఊహించుకోవాలి?

అర్రే క్రియేట్ చేసే పద్ధతి: int marks[5]; అంటే 5 ఇంటిజర్లకు సరిపడే మెమరీ. ఇండెక్స్ ఎప్పుడూ 0 తోనే మొదలవుతుంది!

🏢 రియల్ లైఫ్ స్టోరీ: అపార్ట్‌మెంట్ బిల్డింగ్

ఒక అపార్ట్‌మెంట్ బిల్డింగ్ ఊహించుకోండి. ఎవరైనా కొరియర్ బాయ్ వస్తే, వాడు బిల్డింగ్ పేరుతో పాటు "ఫ్లాట్ నంబర్ 0", "ఫ్లాట్ నంబర్ 1" అని అడుగుతాడు.

ప్రోగ్రామింగ్ లో కూడా ఇంతే! బిల్డింగ్ పేరు = Array Name. ఫ్లాట్ నంబర్స్ = Index Numbers (0, 1, 2...).

ఇంకో ముఖ్యమైన విషయం Contiguous Memory Allocation. అర్రే కి సంబంధించిన మెమరీ మొత్తం RAM లో పక్కపక్కనే ఉంటుంది. దీనివల్ల డేటాని వెతకడం చాలా ఫాస్ట్ గా జరుగుతుంది.

2 ఒకే ఒక సింపుల్ కోడ్

ఇక్కడ మనం చాలా సింపుల్ గా 3 నంబర్స్ ని ఒక అర్రే లో పెట్టి ప్రింట్ చేస్తున్నాం. అంతే!

C — Simple Array ▶ Run Code 
#include <stdio.h>

int main(void) {
    // 3 ఎలిమెంట్స్ తో అర్రే
    int arr[3] = {10, 20, 30};
    
    // మొదటి ఎలిమెంట్ ఇండెక్స్ 0 అవుతుంది
    printf("First number is: %d\n", arr[0]);
    return 0;
}
3 ఫ్రీక్వెంట్ గా అడిగే ప్రశ్నలు (FAQ)

Q: ఇండెక్స్ ఎందుకు 0 తోనే మొదలవుతుంది?

ఇండెక్స్ అనేది బేస్ అడ్రస్ నుండి "ఎంత దూరంలో" ఉన్నాం (Offset) అని చెప్తుంది. మొదటి ఎలిమెంట్ బేస్ అడ్రస్ దగ్గరే ఉంటుంది కాబట్టి దాని దూరం 0. అందుకే 0 తో మొదలవుతుంది.

Q: 5 సైజు ఉన్న అర్రే లో 6వ ఎలిమెంట్ ని స్టోర్ చేయొచ్చా?

చేయకూడదు! దీన్నే Array Out of Bounds అంటారు. ఇది మెమరీ లో వేరే డేటాని పాడు చేస్తుంది, దీనివల్ల ప్రోగ్రామ్ క్రాష్ అవుతుంది.
