పాయింటర్లు: బేసిక్స్, మెమరీ అడ్రస్లు & Dereferencing (*, &)

⚡ Modern C (C99 / C11) 🟢 Chapter 15 of 20 📂 Phase 04: అర్రేస్, స్ట్రింగ్స్ & పాయింటర్లు 📅 2026 Edition
📌 Covered in this chapter: పాయింటర్ అంటే ఏమిటి? · & (Address) vs * (Value-at) · పాయింటర్ అరిథ్‌మెటిక్ (ptr + 1) · NULL vs డాంగ్లింగ్ పాయింటర్లు
సిస్టమ్స్ ప్రోగ్రామింగ్‌లో C లాంగ్వేజ్‌ను తిరుగులేని రారాజుగా నిలబెట్టిన అత్యంత శక్తివంతమైన ఫీచర్ పాయింటర్లు (Pointers). కంప్యూటర్ సైన్స్ విద్యార్థులను ఎక్కువగా భయపెట్టే కాన్సెప్ట్ కూడా ఇదే! అయితే వాస్తవానికి పాయింటర్ అంటే మరేమీ కాదు — అది కేవలం మరొక వేరియబుల్ యొక్క RAM మెమరీ అడ్రస్‌ను నిల్వ చేసే సాధారణ వేరియబుల్ మాత్రమే. & (Address) vs * (Value-at), పాయింటర్ అరిథ్‌మెటిక్, మరియు ప్రమాదకరమైన వైల్డ్ / డ్యాంగ్లింగ్ పాయింటర్లను ఈ అధ్యాయంలో అత్యంత సరళంగా నేర్చుకుందాం.
1పాయింటర్ అంటే ఏమిటి? మెమరీ అడ్రస్ & డి-రిఫరెన్సింగ్ (*, &)

కంప్యూటర్ RAM లోని ప్రతి బైట్‌కు ఒక ప్రత్యేకమైన చిరునామా (Hexadecimal Address, e.g. 0x7ffd9a) ఉంటుంది. ఒక సాధారణ వేరియబుల్ డేటాను నిల్వ చేస్తే, ఒక పాయింటర్ వేరియబుల్ ఆ డేటా ఉన్న మెమరీ అడ్రస్‌ను నిల్వ చేస్తుంది.

& (Address-of Operator):

ఒక వేరియబుల్ మెమరీలో ఎక్కడ ఉందో దాని RAM చిరునామాను అందిస్తుంది (ఉదా: &age).

* (Dereferencing Operator):

ఒక పాయింటర్ పట్టుకున్న అడ్రస్ వద్దకు వెళ్లి, అక్కడ నిల్వ ఉన్న వాస్తవ విలువను చదవడానికి లేదా మార్చడానికి వాడతాం (ఉదా: *ptr).

C — Pointer Declaration & Dereferencing ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int target = 42;
    // target యొక్క అడ్రస్‌ను నిల్వ చేసే పాయింటర్
    int *ptr = ⌖

    printf("target విలువ          : %d\n", target);
    printf("target మెమరీ అడ్రస్   : %p\n", (void*)&target);
    printf("ptr నిల్వ చేసుకున్నది : %p\n", (void*)ptr);
    printf("*ptr (డీరిఫరెన్సింగ్) : %d\n", *ptr);

    // పాయింటర్ ద్వారా అసలు విలువను మార్చడం
    *ptr = 99;
    printf("నవీకరించబడిన target   : %d\n", target);
    return 0;
}
2పాయింటర్ సైజు & డేటా టైప్స్ యొక్క ఆవశ్యకత

ఆధునిక 64-బిట్ ఆపరేటింగ్ సిస్టమ్స్‌లో ఏదైనా పాయింటర్ (అది char* అయినా, int* అయినా లేదా double* అయినా) ఖచ్చితంగా 8 బైట్ల పరిమాణంలోనే ఉంటుంది. ఎందుకంటే 64-బిట్ ఆర్కిటెక్చర్‌లో ప్రతి మెమరీ అడ్రస్ 64 బిట్లు (8 బైట్లు) ఉంటుంది.

🤔 అన్ని పాయింటర్లు 8 బైట్లే అయితే DataType ఎందుకు చెప్పాలి?

  • డీరిఫరెన్సింగ్ బౌండరీ: *ptr అన్నప్పుడు మెమరీ నుండి కేవలం 1 బైట్ చదవాలా (char), 4 బైట్లు చదవాలా (int) లేదా 8 బైట్లు చదవాలా (double) అనేది డేటా టైప్ నిర్ణయిస్తుంది.
  • పాయింటర్ అరిథ్‌మెటిక్ స్కేల్: ptr + 1 అన్నప్పుడు ఎన్ని బైట్లు ముందుకు జంప్ చేయాలో కంపైలర్‌కు డేటా టైప్ ద్వారానే తెలుస్తుంది.
3పాయింటర్ అరిథ్‌మెటిక్ (Pointer Arithmetic Scale Factor)

పాయింటర్లకు ఒక సంఖ్యను కలిపినప్పుడు సాధారణ గణితం లాగా 1 బైట్ పెరగదు. అది ఆ డేటా టైప్ పరిమాణానికి గుణించబడి ముందుకు వెళ్తుంది:

ptr + n = ptr_address + (n × sizeof(*ptr))
C — Pointer Arithmetic Scale Demo ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int arr[3] = {10, 20, 30};
    int *p = arr; // arr[0] అడ్రస్

    printf("p   యొక్క అడ్రస్: %p (విలువ: %d)\n", (void*)p, *p);
    p++; // 4 బైట్లు ముందుకు దూకుతుంది!
    printf("p++ యొక్క అడ్రస్: %p (విలువ: %d)\n", (void*)p, *p);
    return 0;
}
4ప్రమాదకరమైన పాయింటర్లు: NULL, Wild & Dangling Pointers
1. NULL Pointer (రక్షణ కవచం):

ప్రస్తుతం ఏ మెమరీనీ పాయింట్ చేయని సురక్షిత సూచిక (int *p = NULL;). ఏదైనా పాయింటర్‌ను వాడే ముందు అది NULL కాదని if (p != NULL) అని చెక్ చేసుకోవడం ఉత్తమ భద్రతా పద్ధతి.

2. Wild Pointer (ఇనీషియలైజ్ చేయని రాక్షసుడు):

కేవలం int *p; అని డిక్లేర్ చేసి దేనికీ అసైన్ చేయకపోతే, అందులో గార్బేజ్ అడ్రస్ ఉంటుంది. దీనిలోకి డేటా రాస్తే క్రాష్ ఖాయం.

3. Dangling Pointer (గాలిలో వేలాడే పాయింటర్):

ఒక మెమరీని విడుదల చేసిన తర్వాత (లేదా ఫంక్షన్ లోకల్ వేరియబుల్ నాశనమైన తర్వాత) కూడా పాత చిరునామాను అలాగే గుర్తుంచుకునే పాయింటర్. విడుదల చేసిన వెంటనే p = NULL; చేయాలి.

5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. అన్-ఇనీషియలైజ్డ్ పాయింటర్‌ను డీరిఫరెన్స్ చేయడం:
int *ptr; *ptr = 100; // ఘోరమైన సెగ్మెంటేషన్ ఫాల్ట్! పాయింటర్ ఏ వాలిడ్ మెమరీ అడ్రస్‌నూ పాయింట్ చేయకుండా నేరుగా *ptr = 100 రాయడం వల్ల అపరిచిత మెమరీని టచ్ చేసి సిస్టమ్ వెంటనే క్రాష్ అవుతుంది.
❌ 2. డిక్లరేషన్‌లో బహుళ పాయింటర్లు రాసేటప్పుడు * మిస్ అవ్వడం:
int* a, b; // ఇక్కడ 'a' మాత్రమే పాయింటర్; 'b' సాధారణ int అవుతుంది! రెండూ పాయింటర్లు కావాలంటే int *a, *b; అని రెండింటికీ విడివిడిగా ఆస్టెరిస్క్ పెట్టాలి.
6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: void* (Generic Pointer) అంటే ఏమిటి? దాన్ని ఎప్పుడు వాడతారు?

void* అనేది ఏ డేటా టైప్ యొక్క మెమరీ అడ్రస్‌నైనా నిల్వ చేయగల సార్వత్రిక పాయింటర్. డైనమిక్ మెమరీ ఫంక్షన్లైన malloc() మరియు calloc() ఫలితంగా void* నే రిటర్న్ చేస్తాయి. దీనిని డీరిఫరెన్స్ చేయడానికి ముందు సంబంధిత డేటా టైప్‌కు టైప్ కాస్ట్ చేయాలి.

Q: రెండు పాయింటర్లను కూడడం (ptr1 + ptr2) ఎందుకు అనుమతించబడదు?

రెండు మెమరీ అడ్రస్‌లను కలపడం అనేది భౌతికంగా అర్థం లేని ప్రక్రియ (రెండు ఇంటి అడ్రస్‌లను కలిపితే సరిహద్దులు దాటి ఎక్కడికో వెళ్ళిపోతుంది). అయితే రెండు పాయింటర్లను తీసివేస్తే (ptr2 - ptr1) వాటి మధ్య ఎన్ని ఎలిమెంట్లు ఉన్నాయో తెలుస్తుంది కాబట్టి తీసివేత అనుమతించబడుతుంది.
