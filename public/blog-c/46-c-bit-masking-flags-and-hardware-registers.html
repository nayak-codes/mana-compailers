Bit Masking, Flags & Hardware (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 46 📂 Phase 16: Bitwise & Low-Level 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Bit Masking · Setting a Bit · Clearing a Bit · Toggling a Bit · Checking a Bit

ఇప్పటిదాకా మనం నంబర్స్ ని అటూ ఇటూ జరిపాం. కానీ రియల్ వరల్డ్ లో, ఎంబెడెడ్ సిస్టమ్స్ (Embedded Systems) లేదా రోబోటిక్స్ ప్రోగ్రామింగ్ చేసేటప్పుడు, మీరు ఒక 8-బిట్ రిజిస్టర్ (Hardware Box) లో 3వ పిన్ కి కనెక్ట్ అయిన LED లైట్ ని మాత్రమే ఆన్ చేయాలి, మిగతావి టచ్ చేయకూడదు అనుకుంటే ఎలా? డైరెక్ట్ గా num = 1; అంటే మొత్తం అన్నీ ఆరిపోతాయి. ఇలాంటప్పుడు పర్టిక్యులర్ గా ఒకే ఒక్క బిట్ (Bit) మీద స్నిపర్ షాట్ లాగా ఆపరేషన్ చేయడాన్నే Bit Masking (బిట్ మాస్కింగ్) అంటారు. Set, Clear, Toggle అనే మూడు బ్రహ్మాస్త్రాలు ఎలా పనిచేస్తాయో ఈరోజు నేర్చుకుందాం.

1 బిట్ మాస్క్ (Bit Mask) అంటే ఏంటి?

మాస్క్ (Mask) అంటే ఏంటి? మన ఫేస్ లో కళ్లు తప్ప మిగతా అంతా కవర్ చేస్తుంది. అలాగే కంప్యూటర్ లో మనకు కావాల్సిన బిట్ ని మాత్రమే ఓపెన్ చేసి, మిగతా వాటిని (సున్నాలతో) కవర్ చేసే ఒక స్పెషల్ నంబర్ ని Bit Mask అంటారు. దీన్ని జనరేట్ చేయడానికి మనం లాస్ట్ లెసన్ లో నేర్చుకున్న షిఫ్ట్ (1 << n) వాడతాం.

🎯 4 మ్యాజిక్ ఫార్ములాస్ (The Cheat Sheet)

మీరు ఒక లైట్ ని (nth బిట్) కంట్రోల్ చేయాలి అనుకుంటే, ముందు మాస్క్ (1 << n) తయారుచేసుకోవాలి. ఆ తర్వాత:

1. Set a Bit (ఆన్ చేయడం): REG = REG | (1 << n); (ఉన్నదాన్ని కదిలించకుండా, n వ బిట్ ని 1 చేస్తుంది).
2. Clear a Bit (ఆఫ్ చేయడం): REG = REG & ~(1 << n); (మాస్క్ ని రివర్స్ చేసి అండ్ చేస్తుంది, n వ బిట్ 0 అవుతుంది).
3. Toggle a Bit (స్విచ్ వేయడం): REG = REG ^ (1 << n); (XOR వాడితే ఆన్ ఉంటే ఆఫ్, ఆఫ్ ఉంటే ఆన్ అవుతుంది).
4. Check a Bit (చెక్ చేయడం): if (REG & (1 << n)) (ఆ బిట్ ఆన్ లో ఉందా లేదా అని చెప్తుంది).

2 ఒకే ఒక సింపుల్ కోడ్ (LED Control Simulator)

కింద కోడ్ లో మనం ఒక హార్డ్వేర్ రిజిస్టర్ లాంటి 8-bit వేరియబుల్ తీసుకుని, అందులో కరెక్ట్ గా 3వ లైట్ ని ఆన్, ఆఫ్ ఎలా చేస్తున్నామో చూడండి.

C — Bit Masking (Flags) ▶ Run Code 
#include <stdio.h>

// సులువు కోసం ఒక మాక్రో రాసుకుందాం (n వ బిట్ కోసం మాస్క్)
#define BIT_MASK(n) (1 << (n))

// బైనరీ ని మనుషుల కోసం డిస్ప్లే చేసే సింపుల్ ఫంక్షన్
void printBinary(unsigned char num) {
    for (int i = 7; i >= 0; i--) {
        printf("%d", (num & BIT_MASK(i)) ? 1 : 0);
    }
    printf("\n");
}

int main() {
    // మన హార్డ్వేర్ స్టేటస్ (అన్ని లైట్స్ ఆఫ్ లో ఉన్నాయి)
    unsigned char PORT = 0; // 00000000
    
    printf("Initial PORT status: ");
    printBinary(PORT);
    
    // ------------------------------------
    // 1. SET (ఆన్ చేద్దాం): 3వ లైట్ ని ఆన్ చేయాలి
    // ------------------------------------
    PORT = PORT | BIT_MASK(3); 
    printf("After Setting bit 3: ");
    printBinary(PORT); // అవుట్పుట్: 00001000
    
    // ఇంకో లైట్ (1వ లైట్) కూడా ఆన్ చేద్దాం (పాతది పోదు)
    PORT = PORT | BIT_MASK(1);
    printf("After Setting bit 1: ");
    printBinary(PORT); // అవుట్పుట్: 00001010
    
    // ------------------------------------
    // 2. TOGGLE (రివర్స్ చేద్దాం): 1వ లైట్ ని టోగుల్ చేద్దాం
    // ------------------------------------
    PORT = PORT ^ BIT_MASK(1);
    printf("After Toggle bit 1 : ");
    printBinary(PORT); // అవుట్పుట్: 00001000 (ఆఫ్ అయింది)
    
    // ------------------------------------
    // 3. CLEAR (ఆఫ్ చేద్దాం): 3వ లైట్ ని ఆఫ్ చేద్దాం
    // ------------------------------------
    PORT = PORT & ~(BIT_MASK(3));
    printf("After Clear bit 3  : ");
    printBinary(PORT); // అవుట్పుట్: 00000000 (మొత్తం ఆఫ్)
    
    return 0;
}
3 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • BIT_MASK(3): ఇది బ్యాక్ గ్రౌండ్ లో 1 << 3 అవుతుంది. బైనరీ లో ఇది 0000 1000 కి సమానం. దీన్నే మాస్క్ అంటారు.
  • PORT | BIT_MASK(3): OR (|) ఆపరేటర్ ప్రాపర్టీ ఏంటంటే, ఎక్కడైనా 1 ఉంటే రిజల్ట్ లో 1 పెడుతుంది, 0 ఉంటే పాత వాల్యూ (పోర్ట్ లో ముందు ఉన్న వాల్యూ) నే ఉంచుతుంది. అందుకే కేవలం 3వ బిట్ మాత్రమే ఆన్ అవుతుంది!
  • PORT & ~(BIT_MASK(3)): ముందు మాస్క్ ని NOT (~) చేసాం. అప్పుడు 0000 1000 కాస్తా 1111 0111 అయ్యింది. దాన్ని అండ్ (&) చేస్తే, ఆ ఒక్క బిట్ దగ్గర 0 ఉంది కాబట్టి అది 0 అయిపోయి ఆఫ్ అవుతుంది, మిగతావన్నీ 1 తో అండ్ అయ్యి ఎలా ఉన్నాయో అలానే ఉంటాయి!
4 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: ఈ బిట్ మాస్కింగ్ కేవలం ఎంబెడెడ్ హార్డ్వేర్ లోనే వాడతారా? సాఫ్ట్వేర్ లో వాడరా?

సాఫ్ట్వేర్ లో కూడా విపరీతంగా వాడతారు! ఒక యూజర్ కి 8 రకాల పర్మిషన్స్ (Read, Write, Delete etc) ఇవ్వాలంటే, 8 వేరియబుల్స్ (8 బైట్స్) తీసుకునే బదులు, ఒకేఒక్క char వేరియబుల్ (1 బైట్) తీసుకుని అందులో 8 బిట్స్ ని 8 ఫ్లాగ్స్ లాగా వాడతారు (దీన్నే Flags అంటారు). విండోస్ API మొత్తం ఇలానే పనిచేస్తుంది (ఉదా: MB_OK | MB_ICONERROR).

Q2: num & (num - 1) అనే ఫేమస్ ఇంటర్వ్యూ క్వశ్చన్ ఏంటి?

చాలా కంపెనీస్ లో అడిగే బెస్ట్ ట్రిక్ ఇది! ఈ ఆపరేషన్ ఒక నంబర్ లో చివరగా ఉన్న '1' (Rightmost set bit) ని సున్నా (0) చేస్తుంది. ఒక నంబర్ ని పవర్ ఆఫ్ 2 (అంటే 2, 4, 8, 16 లాగా) అవునా కాదా అని కనుక్కోవడానికి if ((num & (num - 1)) == 0) అని సింగిల్ లైన్ లో చెక్ చేయొచ్చు!

Q3: 1 << 32 చేస్తే ఏమవుతుంది?

ఒక స్టాండర్డ్ ఇంట్ (int) 32-bits మాత్రమే ఉంటుంది. దాన్ని 32 సార్లు షిఫ్ట్ చేస్తే అది ఓవర్ ఫ్లో అయ్యి కంపైలర్ వార్నింగ్ ఇస్తుంది (Undefined Behavior). ఒకవేళ మీకు 64-బిట్ నంబర్స్ కావాలంటే 1ULL << 40 (Unsigned Long Long) అని స్పెసిఫై చేయాలి.
