C 1D Arrays: Contiguous RAM Memory Architecture & Indexing (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 14 📂 Phase 07: Arrays & Memory Organization 📅 2026 Edition
📌 Covered in this in-depth guide: Array ante enti? · Contiguous Memory Layout · Zero-Based Offset Formula · sizeof Length Idiom · Bounds Checking & Buffer Overflow

Phase 7 (Chapter 14): C 1D Arrays & Memory Architecture Masterclass కు స్వాగతం! ఒకే రకమైన డేటా చాలా ఉన్నప్పుడు (ఉదాహరణకి 1,000 మంది స్టూడెంట్స్ మార్క్స్), ప్రతి దానికి score1, score2... అని వెయ్యి వేరియబుల్స్ క్రియేట్ చేయడం అసాధ్యం. దీనికి సొల్యూషనే Arrays. ఒకే రకమైన డేటాని RAM లో పక్కపక్కనే (Contiguous గా) సేవ్ చేయడానికి Array వాడతాం. ఈ గైడ్ లో, Array క్రియేట్ చేసినప్పుడు RAM లో ఏం జరుగుతుంది, C లో కౌంటింగ్ 1 నుండి కాకుండా 0 తో ఎందుకు స్టార్ట్ అవుతుంది, ఒక Array సైజు ఎలా కనుక్కోవాలి, మరియు హ్యాకర్స్ వాడే Buffer Overflow ఎటాక్ ఎలా జరుగుతుందో తెలుగులో నేర్చుకుందాం.

1Array అంటే ఏంటి? & RAM లో మెమరీ ఎలా క్రియేట్ అవుతుంది?

Array అంటే ఒకే రకమైన డేటాని (Same Data Type) RAM మెమరీలో పక్కపక్కనే (Contiguous) ఒక ఆర్డర్ లో స్టోర్ చేసే ఒక విధానం.

RAM Contiguous Memory Architecture for: int marks[4] = {85, 90, 78, 92};
(Assuming Base Memory Address = 0x2000, where each int = 4 Bytes)

RAM Address: 0x2000 0x2004 0x2008 0x200C
┌───────────────┬───────────────┬───────────────┬───────────────┐
Stored Value: │ 85 │ 90 │ 78 │ 92 │
└───────────────┴───────────────┴───────────────┴───────────────┘
Element Index: marks[0] marks[1] marks[2] marks[3]
Offset Calculation: (Base + 0*4) (Base + 1*4) (Base + 2*4) (Base + 3*4)

⚡ C లో ఇండెక్స్ 0 తోనే ఎందుకు స్టార్ట్ అవుతుంది?

సాధారణంగా మనం లెక్కపెట్టేటప్పుడు 1, 2 అని పొజిషన్స్ వాడతాం. కానీ C లాంగ్వేజ్ లో, index అనేది పొజిషన్ కాదు, అది స్టార్టింగ్ అడ్రస్ నుండి ఎంత దూరం జరగాలి (Offset) అని చెప్తుంది!
$$\text{Target Address} = \text{Base Address} + (\text{Index} \times \text{sizeof(element)})$$
• మొదటి ఎలిమెంట్ అక్కడే (స్టార్టింగ్ లోనే) ఉంటుంది కాబట్టి అస్సలు జరగాల్సిన పనిలేదు. అందుకే దానికి అడ్రస్ 0 (Base + 0 * 4 = Base)!
• రెండవ ఎలిమెంట్ కి వెళ్లాలంటే 1 అడుగు ముందుకు వేయాలి (Base + 1 * 4). దీనివల్ల CPU చాలా ఫాస్ట్ గా లెక్కపెట్టుకోగలదు కాబట్టే C లో ఎప్పుడూ 0 తో స్టార్ట్ అవుతుంది!

2Array ని క్రియేట్ చేయడం & Length కనుక్కోవడం (sizeof)

C లో మనం ఒక Array ని చాలా రకాలుగా క్రియేట్ చేయొచ్చు:

📝 C లో Array ని క్రియేట్ చేసే పద్ధతులు:

1. సైజ్ చెప్పి వాల్యూస్ ఇవ్వడం: int marks[4] = {85, 90, 78, 92};
2. ఆటోమేటిక్ సైజ్ (కంపైలరే కౌంట్ చేస్తుంది): int marks[] = {85, 90, 78, 92}; (ఇందులో బ్రాకెట్స్ ఖాళీగా వదిలేయొచ్చు).
3. అన్నింటిలో సున్నా పెట్టడం: int zeros[10] = {0}; (10 ఖాళీలు క్రియేట్ అయి అన్నింటిలో 0 సేవ్ అవుతుంది).
4. ఖాళీగా వదిలేయడం (డేంజర్!): int temp[5]; (ఇలా వదిలేస్తే RAM లో పాత చెత్త వాల్యూస్ (Garbage) అన్నీ వచ్చి ఇందులో పడతాయి!).

📐 C లో Array Length కనుక్కోవడం ఎలా?

Java లేదా Python లాగా C లో డైరెక్ట్ గా .length అనే ఆప్షన్ ఉండదు. కాబట్టి మనం ఈ చిన్న లాజిక్ వాడి లెంత్ ని కనుక్కోవాలి:
$$\text{Length} = \frac{\text{sizeof(entire array in bytes)}}{\text{sizeof(single element in bytes)}} = \frac{\text{sizeof(marks)}}{\text{sizeof(marks[0])}}$$

C — User Curriculum Standard Example ▶ Run in C Compiler 
#include <stdio.h>

int main(void) {
    int marks[] = {85, 90, 78, 92};
    int length = sizeof(marks) / sizeof(marks[0]);

    for (int index = 0; index < length; index++) {
        printf("marks[%d] = %d\n", index, marks[index]);
    }

    return 0;
}
3Array లిమిట్ దాటితే ఏమవుతుంది? (Buffer Overflow) ⚠️

🛑 C లో ఉండే అతిపెద్ద డేంజర్: Out-of-Bounds!

కోడ్ చాలా ఫాస్ట్ గా రన్ అవ్వాలని C భాష **సైజు లిమిట్స్ ని అస్సలు చెక్ చేయదు**.
ఒకవేళ మీరు int arr[4]; అని క్రియేట్ చేసి, పొరపాటున arr[10] = 500; అని రాస్తే:
• C కంపైలర్ మీకు ఎలాంటి ఎర్రర్ చూపించదు!
• రన్ అవుతున్నప్పుడు, 4వ బాక్స్ తర్వాత వేరే ప్రోగ్రామ్ వాడుకుంటున్న మెమరీలోకి వెళ్లి మరీ ఈ 500 ని సేవ్ చేస్తుంది! (దీన్నే Buffer Overflow అంటారు).
• దీనివల్ల సిస్టం హ్యాక్ అవ్వడానికి ఛాన్స్ ఉంటుంది లేదా ప్రోగ్రామ్ వెంటనే Segmentation Fault అని వచ్చి క్రాష్ అయిపోతుంది!
