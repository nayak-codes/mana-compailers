Shift Operators (<<, >>) & Fast Math (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 45 📂 Phase 16: Bitwise & Low-Level 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Left Shift (<<) · Right Shift (>>) · Fast Multiplication · Fast Division · Bit Overflow

కంప్యూటర్ సీపీయూ (CPU) కి కూడిక (Addition) చేయడం చాలా ఈజీ. కానీ గుణకారం (Multiplication) మరియు భాగహారం (Division) చేయాలంటే దానికి చాలా టైమ్ (CPU Cycles) పడుతుంది. మీరు ఒక 3D గేమ్ ఆడుతున్నప్పుడు ఫ్రేమ్-రేట్ (FPS) పడిపోకుండా ఉండాలంటే, అందులో వాడే మ్యాథ్స్ సూపర్ ఫాస్ట్ గా జరగాలి. అప్పుడు ప్రోగ్రామర్స్ నార్మల్ * లేదా / వాడకుండా, Shift Operators (<<, >>) ని ఆయుధాలుగా వాడతారు. ఇవి అసలు క్యాలిక్యులేషన్ చేయకుండానే, కేవలం బిట్స్ ని జరపడం ద్వారా మ్యాథ్స్ ఎలా చేస్తాయో ఈరోజు అద్భుతంగా తెలుసుకుందాం.

1 Left Shift (<<) అంటే ఏంటి? (Fast Multiply)

డెసిమల్ (నార్మల్ నంబర్స్) లో ఒక నంబర్ పక్కన సున్నా (0) యాడ్ చేస్తే ఏమవుతుంది? 5 కాస్తా 50 అవుతుంది (అంటే 10 తో గుణించినట్లు). అలాగే బైనరీ సిస్టమ్ లో ఒక నంబర్ పక్కన సున్నా యాడ్ చేస్తే, అది 2 తో గుణించినట్లు (Multiplied by 2)!

ఒక బైనరీ నంబర్ ని పక్కకి జరుపుదాం (Left Shift): నార్మల్ 5 -> 0000 0101 Left Shift (5 << 1) -> 0000 1010 (ఇది బైనరీ లో 10 కి సమానం) Left Shift (5 << 2) -> 0001 0100 (ఇది బైనరీ లో 20 కి సమానం)

రూల్: x << n అంటే ఆ నంబర్ ని (2 పవర్ n) తో గుణించడం. (ఉదా: x << 3 అంటే x * 8 అన్నమాట). ఇది CPU లో ఒకే ఒక క్లాక్ సైకిల్ లో అయిపోయే అత్యంత ఫాస్ట్ క్యాలిక్యులేషన్!

2 Right Shift (>>) అంటే ఏంటి? (Fast Divide)

ఇది లెఫ్ట్ షిఫ్ట్ కి రివర్స్. ఒక నంబర్ కి కుడి వైపున (Right side) ఉన్న లాస్ట్ బిట్ ని చెరిపేసి (కట్ చేసి), నంబర్ ని కిందకు జరుపుతుంది. ఇది 2 తో భాగాహారం (Divided by 2) చేసినట్లు రిజల్ట్ ఇస్తుంది.

రూల్: 20 >> 1 చేస్తే లాస్ట్ లో ఉన్న ఒక బిట్ పోయి అది 10 అవుతుంది. 20 >> 2 చేస్తే (4 తో డివైడ్ అయ్యి) 5 వస్తుంది.

3 ఒకే ఒక సింపుల్ కోడ్ (Shift Math Magic)

కింద కోడ్ లో నార్మల్ ఆపరేటర్స్ బదులు, షిఫ్ట్ ఆపరేటర్స్ వాడి ఒక నంబర్ ని పెంచడం (Multiply) మరియు తగ్గించడం (Divide) ఎలా చేసామో చూద్దాం.

C — Shift Operators ▶ Run Code 
#include <stdio.h>

int main() {
    int num = 10;
    
    printf("--- Fast Math with Shifts ---\n");
    printf("Original Number : %d\n\n", num);
    
    // ------------------------------------
    // Left Shift (<<) - Multiplication
    // ------------------------------------
    // 10 ని లెఫ్ట్ వైపుకి 1 స్టెప్ జరుపుతాం (అంటే 10 * 2^1)
    int mul2 = num << 1; 
    printf("num << 1 (x 2)  : %d\n", mul2);
    
    // 10 ని లెఫ్ట్ వైపుకి 3 స్టెప్స్ జరుపుతాం (అంటే 10 * 2^3 = 10 * 8)
    int mul8 = num << 3;
    printf("num << 3 (x 8)  : %d\n\n", mul8);
    
    // ------------------------------------
    // Right Shift (>>) - Division
    // ------------------------------------
    int highNum = 40;
    printf("High Number     : %d\n", highNum);
    
    // 40 ని రైట్ వైపుకి 1 స్టెప్ జరుపుతాం (అంటే 40 / 2^1)
    int div2 = highNum >> 1;
    printf("highNum >> 1 (/ 2): %d\n", div2);
    
    // 40 ని రైట్ వైపుకి 2 స్టెప్స్ జరుపుతాం (అంటే 40 / 2^2 = 40 / 4)
    int div4 = highNum >> 2;
    printf("highNum >> 2 (/ 4): %d\n", div4);
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • num << 1: 10 యొక్క బైనరీ 0000 1010. దాన్ని ఒక అడుగు ఎడమకు (Left) జరిపితే, కుడివైపు ఖాళీ అయిన ప్లేస్ లో 0 వస్తుంది. అప్పుడు అది 0001 0100 అవుతుంది. దీని డెసిమల్ వాల్యూ 20!
  • highNum >> 2: 40 యొక్క బైనరీ 0010 1000. దాన్ని రెండు అడుగులు కుడికి (Right) జరిపితే, లాస్ట్ ఉన్న రెండు సున్నాలు బయటకి పడిపోయి డిలీట్ అవుతాయి. అప్పుడు 0000 1010 (అంటే 10) మిగులుతుంది.
  • గమనిక: ఇవి కేవలం పవర్ ఆఫ్ 2 (2, 4, 8, 16) తో గుణించడానికి లేదా భాగించడానికి మాత్రమే పనికొస్తాయి. మీరు 3 తో గుణించాలంటే ఇది పనిచేయదు.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: పెద్ద నంబర్ (ఉదా: 250) ని << చేస్తే ఏమవుతుంది?

C లాంగ్వేజ్ లో ఒక char సైజు 8 బిట్స్ (గరిష్టంగా 255). మీరు 250 ని షిఫ్ట్ చేస్తే ఆ బిట్స్ కింద పడిపోయి (Overflow అయ్యి) మీకు గార్బేజ్ రిజల్ట్ లేదా రాంగ్ వాల్యూస్ వస్తాయి. దీన్నే Bit Overflow అంటారు. డేటా టైప్ లిమిట్ దాటకుండా జాగ్రత్త పడాలి.

Q2: నెగటివ్ నంబర్స్ (ఉదా: -10) ని రైట్ షిఫ్ట్ (>>) చేస్తే ఏమవుతుంది?

ఇది కంపైలర్ మీద ఆధారపడి ఉంటుంది. నెగటివ్ నంబర్స్ ని షిఫ్ట్ చేసినప్పుడు, ఖాళీ అయిన ప్లేస్ లో 1 యాడ్ అవుతుందా లేక 0 యాడ్ అవుతుందా (Arithmetic Shift vs Logical Shift) అనేది ఆపరేటింగ్ సిస్టమ్ ని బట్టి మారుతుంది. అందుకే ప్రొఫెషనల్స్ ఎప్పుడూ unsigned int వాడినప్పుడే షిఫ్ట్ ఆపరేటర్స్ వాడుతారు.

Q3: 1 << n అంటే ఏంటి? ఎందుకు ఎక్కువగా వాడతారు?

దీన్ని Setting a Bit అంటారు! మీరు 1 << 3 అని రాస్తే బైనరీ లో 0000 1000 వస్తుంది. హార్డ్వేర్ లో (ఉదా: LED లైట్ లేదా మోటార్) 3వ పిన్ ని మాత్రమే ఆన్ చేయడానికి సిస్టమ్ ప్రోగ్రామర్స్ ఈ ట్రిక్ ని విపరీతంగా వాడతారు. దీన్నే Bit Masking అంటారు (తర్వాతి లెసన్ లో నేర్చుకుందాం).
