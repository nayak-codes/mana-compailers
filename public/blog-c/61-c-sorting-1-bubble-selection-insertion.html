Sorting (Bubble, Selection, Insertion) (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 61 📂 Phase 20: Algorithms & Final 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Sorting Algorithms · Bubble Sort Logic · Selection Sort · Insertion Sort · O(N^2) Time Complexity

లాస్ట్ లెసన్ లో బైనరీ సెర్చ్ వాడాలంటే డేటా ఒక ఆర్డర్ లో సార్ట్ (Sort) అయ్యి ఉండాలని నేర్చుకున్నాం కదా. మరి పిచ్చిపిచ్చిగా (Random) ఉన్న డేటాని అసలు ఎలా సార్ట్ చేస్తారు? అమెజాన్ లో మీరు "Price: Low to High" నొక్కగానే ప్రొడక్ట్స్ అన్నీ ఒక క్యూ లో ఎలా నిలబడతాయి? దానికి వాడే అల్గారిథమ్స్ ని Sorting Algorithms అంటారు. ఇందులో బేసిక్స్ అయిన Bubble, Selection మరియు Insertion అనే మూడు పద్ధతులు O(N²) టైమ్ తో ఎలా పనిచేస్తాయో ఈరోజు పేకముక్కల (Cards) ఆటతో డీప్ గా చూద్దాం.

1 1. బబుల్ సార్ట్ (Bubble Sort) - పక్కోడితో పోరు

లాజిక్: అర్రే లో మొదటి నుండి వెళ్తూ, పక్కపక్కనే ఉన్న ఇద్దరినీ కంపేర్ చేస్తాం. పెద్దోడు లెఫ్ట్ లో ఉంటే, వాళ్ళిద్దరినీ స్వాప్ (Swap) చేస్తాం. ఇలా ఒక రౌండ్ అయ్యేసరికి క్లాస్ లో ఉన్న అతి పెద్దోడు (గాలి బుడగ లాగా) లాస్ట్ కి వెళ్లి సెటిల్ అయిపోతాడు! మళ్ళీ ఇంకో రౌండ్ వేస్తాం, సెకండ్ పెద్దోడు సెటిల్ అవుతాడు.

ఉదాహరణకు ( 5, 1, 4, 2 ): 1. 5 > 1 కాబట్టి స్వాప్: ( 1, 5, 4, 2 ) 2. 5 > 4 కాబట్టి స్వాప్: ( 1, 4, 5, 2 ) 3. 5 > 2 కాబట్టి స్వాప్: ( 1, 4, 2, [5] ) -> 5 లాస్ట్ కి వెళ్లి ఫిక్స్ అయిపోయింది!
2 2. సెలెక్షన్ సార్ట్ (Selection Sort) - వెతుకులాట

లాజిక్: దీని స్టైల్ వేరు! ఇందులో క్లాస్ మొత్తం వెతికి (Scan చేసి) అతి చిన్న వాడిని (Minimum) పట్టుకుని తీసుకొచ్చి ఫస్ట్ ప్లేస్ లో కూర్చోపెడతాం! ఆ తర్వాత మిగిలిన వాళ్ళలో చిన్న వాడిని పట్టుకుని సెకండ్ ప్లేస్ లో కూర్చోపెడతాం.

3 3. ఇన్సర్షన్ సార్ట్ (Insertion Sort) - పేకముక్కలు

లాజిక్: మీరు రమ్మీ (Rummy) ఆడేటప్పుడు చేతిలో పేకముక్కలు ఎలా సర్దుకుంటారు? కింద నుండి ఒక ముక్క తీసి, మీ చేతిలో ఆల్రెడీ ఉన్న ముక్కలలో కరెక్ట్ ప్లేస్ చూసుకుని మధ్యలో దూరుస్తారు కదా! ఇది అచ్చం అలాగే పనిచేస్తుంది. చేతిలో ఉన్నవి ఎప్పుడూ సార్ట్ అయ్యే ఉంటాయి.

4 ఒకే ఒక సింపుల్ కోడ్ (Bubble Sort in Action)

కింద కోడ్ లో బబుల్ సార్ట్ వాడి ఒక జంబుల్ అయిన అర్రే ని రెండు ఫర్-లూప్స్ (Nested loops) ద్వారా ఎలా సార్ట్ చేసామో చూడండి.

C — Bubble Sort Algorithm ▶ Run Code 
#include <stdio.h>

// స్వాప్ (Swap) చేయడానికి సింపుల్ ఫంక్షన్ (పాయింటర్స్ వాడి)
void swap(int* xp, int* yp) {
    int temp = *xp;
    *xp = *yp;
    *yp = temp;
}

// బబుల్ సార్ట్ ఫంక్షన్
void bubbleSort(int arr[], int n) {
    // ఔటర్ లూప్: ఎన్ని రౌండ్స్ వేయాలి? (N-1 రౌండ్స్ వేస్తే చాలు)
    for (int i = 0; i < n - 1; i++) {
        
        int swapped = 0; // ఈ రౌండ్ లో అసలు స్వాప్ జరిగిందా లేదా అని చెక్ చేయడానికి
        
        // ఇన్నర్ లూప్: పక్కపక్కనోళ్లని కంపేర్ చేస్తూ ముందుకు వెళ్లడం
        // లాస్ట్ కి వెళ్ళిన పెద్దోళ్లని (i) మళ్ళీ చెక్ చేయక్కర్లేదు కాబట్టి 'n - i - 1' 
        for (int j = 0; j < n - i - 1; j++) {
            
            // ఎడమ వాడి కన్నా కుడి వాడు చిన్న ఉంటే... ప్లేస్ మార్చు!
            if (arr[j] > arr[j + 1]) {
                swap(&arr[j], &arr[j + 1]);
                swapped = 1; // స్వాప్ జరిగింది
            }
        }
        
        // ఒకవేళ ఈ రౌండ్ లో అసలు ఒక్క స్వాప్ కూడా జరగలేదంటే...
        // దాని అర్థం డేటా అంతా సార్ట్ అయిపోయిందని! లూప్ ఆపేయొచ్చు.
        if (swapped == 0) {
            break; // (Optimized Bubble Sort)
        }
    }
}

// అర్రే ని ప్రింట్ చేసే ఫంక్షన్
void printArray(int arr[], int size) {
    for (int i = 0; i < size; i++)
        printf("%d ", arr[i]);
    printf("\n");
}

int main() {
    int arr[] = {64, 34, 25, 12, 22, 11, 90};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    printf("--- Bubble Sort Demo ---\n\n");
    
    printf("Original Array : ");
    printArray(arr, n);
    
    // సార్టింగ్ ఫంక్షన్ ని పిలుద్దాం
    bubbleSort(arr, n);
    
    printf("Sorted Array   : ");
    printArray(arr, n);
    
    return 0;
}
5 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • for(i=0... n-1): ఔటర్ లూప్ ఎప్పుడూ రౌండ్స్ కౌంట్ చేస్తుంది. 7 నంబర్స్ ఉంటే 6 రౌండ్స్ (లార్లు) వేస్తే చాలు, లాస్ట్ వాడు వాడికదే సెటిల్ అయిపోతాడు.
  • for(j=0... n-i-1): ఇన్నర్ లూప్ యాక్షన్ చేస్తుంది (కంపేర్ అండ్ స్వాప్). ఇక్కడ -i ఎందుకు రాశామంటే, ఫస్ట్ రౌండ్ (i=0) లో అతి పెద్దోడు లాస్ట్ కి వెళ్లి లాక్ అయిపోతాడు. సెకండ్ రౌండ్ (i=1) లో మళ్ళీ ఆ లాస్ట్ వాడి దగ్గరికి వెళ్లి చెక్ చేయడం టైమ్ వేస్ట్ కదా!
  • swapped = 0 ఫ్లాగ్ మ్యాజిక్ ఏంటంటే, ఒకవేళ మీకు ఇచ్చిన డేటా ఆల్రెడీ సార్ట్ అయ్యి (1,2,3,4,5) ఉంటే, ఫస్ట్ రౌండ్ లో ఒక్క స్వాప్ కూడా జరగదు. అప్పుడు పిచ్చోడిలాగా మళ్ళీ 6 రౌండ్స్ ఎందుకు వేయడం? డైరెక్ట్ గా break తో బయటికి వచ్చేసి CPU టైమ్ ని సేవ్ చేస్తుంది! (దీన్నే Optimized Bubble Sort అంటారు).
6 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: ఈ మూడు సార్ట్స్ లో ఏది వాడాలి?

రియల్ ప్రాజెక్ట్స్ లో ఎవరూ ఈ మూడూ వాడరు! ఎందుకంటే వీటికి రెండు for లూప్స్ (Nested) ఉంటాయి. 10 వేల రికార్డ్స్ ఇస్తే (10000 x 10000) అంటే పది కోట్ల సార్లు లూప్ తిరిగి మీ ప్రోగ్రామ్ ఫ్రీజ్ అయిపోతుంది (దీన్నే Time Complexity O(N²) అంటారు). ఇవి కేవలం కాలేజీలో నేర్చుకోవడానికి మాత్రమే.

Q2: Insertion Sort కి ఒక అడ్వాంటేజ్ ఉందట కదా?

అవును! ఒకవేళ మీకు ఇచ్చిన డేటా దాదాపుగా సార్ట్ అయ్యి ఉండి, ఒకటో రెండో నంబర్స్ మాత్రమే తేడా ఉంటే, Insertion Sort చాలా అంటే చాలా ఫాస్ట్ గా (దాదాపు O(N) స్పీడ్ తో) పనిచేస్తుంది. అందుకే దీన్ని చిన్నచిన్న పనులకి వాడుతారు.

Q3: స్థిరమైన (Stable) సార్ట్ అంటే ఏంటి?

సపోజ్ ఇద్దరు స్టూడెంట్స్ కి 90 మార్క్స్ వచ్చాయి (A కన్నా B ముందు ఉన్నాడు). సార్ట్ చేసిన తర్వాత కూడా ఆ ఇద్దరి మార్క్స్ పక్కపక్కనే ఉండి, B ముందే ఉంటే దాన్ని Stable (స్థిరమైనది) అంటారు. బబుల్ మరియు ఇన్సర్షన్ సార్ట్స్ Stable. కానీ సెలెక్షన్ సార్ట్ అలా కాదు, అది జంప్స్ చేస్తుంది కాబట్టి Unstable అంటారు.
