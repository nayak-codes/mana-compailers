Switch Case & Menu Logic (తెలుగులో డీప్ ఎక్స్‌ప్లనేషన్)

⚡ C (C17 / C23 Standard) 🟢 Lesson 7 📂 Phase 04: Conditional Statements 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Switch Case నిర్మాణం · break మరియు default ప్రాముఖ్యత · if-else కి దీంట్లో తేడా ఏమిటి?

మనం ఇంతకుముందు పాఠంలో if-else గురించి నేర్చుకున్నాం కదా. కానీ ఒకవేళ యూజర్ కి 10 ఆప్షన్స్ ఇవ్వాలంటే, 10 సార్లు else if రాసుకుంటూ వెళ్తే కోడ్ చదవడానికి చాలా కష్టంగా ఉంటుంది. ఇలాంటి "Multiple Choice" ఆప్షన్స్ ఉన్నప్పుడు, కోడ్ ని క్లీన్ గా రాయడానికి వచ్చిన బెస్ట్ టూల్ Switch Case (స్విచ్ కేస్).

1 Switch Case ఎప్పుడు వాడాలి?

ఒక వేరియబుల్ వాల్యూ ని కేవలం "సమానమా కాదా (Equality)" అని చెక్ చేయడానికి మాత్రమే switch వాడతాం. (ఉదా: x == 1, x == 2). కానీ x > 10 లాంటి పెద్ద చిన్న కండిషన్స్ కి switch పనికిరాదు.

🍔 రియల్ లైఫ్ స్టోరీ: రెస్టారెంట్ మెనూ

మీరు ఒక రెస్టారెంట్ కి వెళ్లారు. వెయిటర్ మీకు ఒక మెనూ కార్డు ఇచ్చాడు:
1 - బిర్యానీ
2 - ఫ్రైడ్ రైస్
3 - నూడుల్స్

మీరు "ఆప్షన్ 2" అని చెప్తే, వెయిటర్ డైరెక్ట్ గా ఆప్షన్ 2 కి సంబంధించిన ఫ్రైడ్ రైస్ మాత్రమే తెస్తాడు. అంతే కానీ వాడు బిర్యానీ ని కూడా చెక్ చేయడు కదా? switch కూడా అచ్చం ఇలాగే పనిచేస్తుంది! కంపైలర్ డైరెక్ట్ గా మీరు అడిగిన ఆప్షన్ (Case) దగ్గరికి మాత్రమే వెళ్తుంది.

2 'break' మర్చిపోతే ఏమవుతుంది?

switch లోపల ప్రతి case చివర్లో కచ్చితంగా break; అని రాయాలి. ఒకవేళ రాయకపోతే, కంపైలర్ ఆ ఆప్షన్ కింద ఉన్న మిగతా ఆప్షన్స్ అన్నీ కూడా రన్ చేసుకుంటూ వెళ్లిపోతుంది! దీన్నే ప్రోగ్రామింగ్ పరిభాషలో Fall-through అంటారు. కింద కోడ్ లో చూడండి:

C — switch case Demo ▶ Run Code 
#include <stdio.h>

int main(void) {
    int choice = 2;
    
    switch(choice) {
        case 1:
            printf("You ordered Biryani\n");
            break;
        case 2:
            printf("You ordered Fried Rice\n");
            break; // ఇది లేకపోతే కింది నూడుల్స్ కూడా ప్రింట్ అయిపోతుంది!
        case 3:
            printf("You ordered Noodles\n");
            break;
        default:
            // మెనూ లో లేని నంబర్ ఇస్తే ఇది రన్ అవుతుంది
            printf("Invalid Option, please check the menu!\n");
    }
    
    return 0;
}

ఇందులో ఉన్న default అనేది if-else లో ఉన్న else లాంటిది. యూజర్ పిచ్చి పిచ్చి నంబర్స్ ఇస్తే, వాడికి తప్పు అని చెప్పడానికి ఇది వాడతాం.
