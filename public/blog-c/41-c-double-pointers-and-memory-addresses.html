Double Pointers (**) & Memory Addresses (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 41 📂 Phase 15: Advanced Pointers 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Double Pointers (**) · Pointer to Pointer · Changing Pointers in Functions · Dynamic 2D Arrays

ఒక వేరియబుల్ ఎక్కడుందో చెప్పేది పాయింటర్ (Pointer). మరి ఆ పాయింటర్ ఎక్కడుందో చెప్పేదే Double Pointer (డబుల్ పాయింటర్ **)! వినడానికి కొంచెం బ్రెయిన్ ఫ్రీజ్ లాగా అనిపిస్తుంది కానీ, రియల్ ప్రాజెక్ట్స్ లో ఒక ఫంక్షన్ కి మీ పాయింటర్ ని పాస్ చేసి, అందులో ఉన్న అడ్రస్ ని మార్చాలంటే దీనివల్లనే సాధ్యం. డేటా స్ట్రక్చర్స్ లో (Linked Lists లో నోడ్స్ డిలీట్ చేసేటప్పుడు) ఇది చాలా కీలకం. ఈరోజు డబుల్ పాయింటర్స్ వెనక ఉన్న మ్యాజిక్ ఏంటో పోస్ట్‌మార్టం చేద్దాం.

1 పాయింటర్ టు పాయింటర్ (Inception)

సింపుల్ గా చెప్పాలంటే ఇది ఒక ట్రెజర్ హంట్ (Treasure Hunt) లాంటిది! మీరు ఒక బాక్స్ (**ptr2) ఓపెన్ చేస్తే అందులో ఇంకో బాక్స్ అడ్రస్ (*ptr1) ఉంటుంది, దాన్ని ఓపెన్ చేస్తే అసలు డేటా (data) దొరుకుతుంది.

📦 రియల్ లైఫ్ స్టోరీ: లాకర్ కి తాళం (The Double Lock)

మీరు ఒక బ్యాంకు లో డబ్బు దాచారు (ఇదే ఒరిజినల్ వేరియబుల్ a=100). ఆ డబ్బు ఒక లాకర్ లో (Locker 501) ఉంది.

ఆ లాకర్ తాళం మీ ఫ్రెండ్ చేతిలో ఉంది (ఇదే సింగిల్ పాయింటర్ int *ptr = &a;). ఇప్పుడు మీ ఫ్రెండ్ ఎక్కడున్నాడు? అతను ఇంకో రూమ్ లో (Room 902) కూర్చున్నాడు. మీరు మీ బాస్ కి "ఆ రూమ్ 902 కి వెళ్ళు, అక్కడ మా ఫ్రెండ్ ఉన్నాడు, వాడి దగ్గర లాకర్ కీ ఉంది, అందులో నా డబ్బు ఉంది" అని చెప్తారు (ఇదే డబుల్ పాయింటర్ int **boss = &ptr;).

అంటే బాస్ డైరెక్ట్ గా డబ్బు దగ్గరికి వెళ్లలేడు, ముందు కీ (పాయింటర్) ఉన్నోడి దగ్గరికి వెళ్లి, వాడి ద్వారా డబ్బు తెచ్చుకుంటాడు.

2 ఫంక్షన్స్ లో అడ్రస్ మార్చడం (Pass by Reference for Pointers)

మీరు ఒక ఫంక్షన్ కి నార్మల్ వేరియబుల్ ని పాస్ చేసి దాన్ని మార్చాలంటే అడ్రస్ (&a) ని పాస్ చేస్తారు కదా! అదే విధంగా, ఒక ఫంక్షన్ కి పాయింటర్ ని పాస్ చేసి, ఆ పాయింటర్ నే మార్చాలంటే మీరు దాని అడ్రస్ ని (అంటే డబుల్ పాయింటర్ ని) పాస్ చేయాలి.

మెమరీని ఆన్ ది స్పాట్ లో (malloc) క్రియేట్ చేసి పంపే ఫంక్షన్స్ కి ఇవి చాలా చాలా అవసరం!

3 ఒకే ఒక సింపుల్ కోడ్ (Pointer of Pointer Magic)

కింద కోడ్ లో డబుల్ పాయింటర్ వాడి, మూడు అంచెల్లో ఒక వాల్యూని ఎలా మార్చామో (Dereferencing) క్లియర్ గా చూడండి.

C — Double Pointers (**) ▶ Run Code 
#include <stdio.h>

// ఫంక్షన్ పాయింటర్ ని మారుస్తుంది (డబుల్ పాయింటర్ వాడి)
void changePointer(int **doublePtr, int *newAddress) {
    // లోపల ఉన్న సింగిల్ పాయింటర్ కి కొత్త అడ్రస్ ని ఇస్తున్నాం
    *doublePtr = newAddress;
}

int main() {
    int x = 10;
    int y = 99;
    
    // సింగిల్ పాయింటర్ (x ని పాయింట్ చేస్తుంది)
    int *ptr = &x;
    
    printf("--- Before Function Call ---\n");
    printf("ptr points to value: %d\n", *ptr); // అవుట్పుట్: 10
    
    // ఇప్పుడు ptr అనే పాయింటర్ అడ్రస్ నే మార్చేద్దాం!
    // ptr అడ్రస్ ని పంపుతున్నాం కాబట్టి ఫంక్షన్ కి (**) కావాలి
    changePointer(&ptr, &y);
    
    printf("\n--- After Function Call ---\n");
    printf("ptr now points to value: %d\n", *ptr); // అవుట్పుట్: 99
    
    // అసలు డబుల్ పాయింటర్ వాల్యూని డైరెక్ట్ గా ప్రింట్ చేస్తే...
    int **dp = &ptr;
    printf("\nUsing Double Pointer: **dp = %d\n", **dp); // అవుట్పుట్: 99
    
    return 0;
}
4 కోడ్ లో ఏం జరుగుతోంది? (Step-by-Step)
  • int *ptr = &x;: ఇది నార్మల్. x ఉన్న మెమరీ లొకేషన్ ని ptr పట్టుకుంది.
  • changePointer(&ptr, &y);: మనం ptr యొక్క సొంత మెమరీ అడ్రస్ ని పంపుతున్నాం! అంటే ఆ బాక్స్ లోపలికి వెళ్లి దాన్ని చెరిపేసి కొత్తగా y అడ్రస్ ని పేస్ట్ చేయమని పర్మిషన్ ఇచ్చాం.
  • **dp (డబుల్ డీ-రిఫరెన్స్): స్టార్ స్టార్ (**) వాడితే, కంపైలర్ ఫస్ట్ టైమ్ ఒక జంప్ చేసి పాయింటర్ దగ్గరికి వెళ్తుంది, మళ్ళీ ఇంకో స్టార్ కి ఇంకో జంప్ చేసి అసలు వాల్యూ (99) దగ్గరికి వెళ్తుంది.
5 ఇంటర్వ్యూలలో అడిగే కామన్ ప్రశ్నలు (FAQ)

Q1: ***ptr (ట్రిపుల్ పాయింటర్) వాడొచ్చా? ఇది వాలిడ్ ఏనా?

సింటాక్స్ పరంగా మీరు ఎన్ని స్టార్స్ అయినా పెట్టుకోవచ్చు (****ptr). కానీ రియల్ వరల్డ్ లో డబుల్ పాయింటర్ (**) కి మించి వెళ్తే అది "Bad Design" కింద లెక్క. ఎందుకంటే బ్రెయిన్ కన్ఫ్యూజ్ అయ్యి బగ్స్ వస్తాయి. ట్రిపుల్ పాయింటర్స్ ని చాలా అరుదుగా, మల్టీ-డైమెన్షనల్ స్ట్రింగ్ అర్రేస్ (3D arrays) కోసం మాత్రమే వాడుతారు.

Q2: Dynamic 2D Arrays లో డబుల్ పాయింటర్స్ ఎందుకు వాడతారు?

మీకు ఒక మ్యాట్రిక్స్ (రోస్ & కాలమ్స్) హీప్ లో కావాలంటే, ముందుగా రోస్ అడ్రస్ లు పెట్టుకోవడానికి ఒక malloc కావాలి (ఇదే int **). ఆ తర్వాత ప్రతి రో లో కాలమ్స్ కోసం మళ్ళీ లూప్ లోపల ఇంకో malloc వాడాలి (ఇవి సింగిల్ int *). ఇండస్ట్రీలో 2D అర్రేస్ ని ఇలాగే తయారు చేస్తారు.

Q3: జావా, పైథాన్ లాంటి లాంగ్వేజెస్ లో ఈ డబుల్ పాయింటర్స్ ఉంటాయా?

ఉండవు! జావా లో పాయింటర్స్ నే పూర్తిగా తీసేశారు, అంతా రిఫరెన్సెస్ (References) ద్వారా ఆటోమేటిక్ గా జరుగుతుంది. అందుకే జావా నేర్చుకోవడం చాలా ఈజీ అంటారు. కానీ మెమరీ మీద ఫుల్ కంట్రోల్ ఉండదు. సి లాంగ్వేజ్ లో పాయింటర్స్ వల్లే అది హార్డ్వేర్ కి కింగ్ అయింది.
