పాయింటర్లు, అర్రేస్ & Double Pointers (**ptr)

⚡ Modern C (C99 / C11) 🟢 Chapter 16 of 20 📂 Phase 04: అర్రేస్, స్ట్రింగ్స్ & పాయింటర్లు 📅 2026 Edition
📌 Covered in this chapter: అర్రే డికే (Array Decay) రహస్యం · *(arr + i) నోటేషన్ · డబుల్ పాయింటర్లు (**ptr) · ఫంక్షన్ పాయింటర్లు (Callbacks)
C లాంగ్వేజ్ అంతర్గత ఆర్కిటెక్చర్‌లో అర్రేలు మరియు పాయింటర్లు ఒకే నాణేనికి ఉన్న రెండు ముఖాలు లాంటివి. ఒక ఎక్స్‌ప్రెషన్‌లో అర్రే పేరు రాసినప్పుడు అది పాయింటర్‌గా ఎలా రూపాంతరం చెందుతుంది (Array Decay), arr[i] వెనుక ఉన్న అసలు పాయింటర్ సింటాక్స్, మెమరీ పాయింటర్‌ను పాయింట్ చేసే డబుల్ పాయింటర్లు (**ptr), మరియు హైయర్ ఆర్డర్ ప్రోగ్రామింగ్‌కు మూలమైన ఫంక్షన్ పాయింటర్లు (Callbacks) ను ఈ అధ్యాయంలో లోతుగా శోధిద్దాం.
1అర్రే డికే (Array Decay) రహస్యం & arr[i] == *(arr + i)

C లో ఒక అర్రే పేరును ఎక్స్‌ప్రెషన్‌లో వాడినప్పుడు, అది స్వయంచాలకంగా తన మొదటి ఎలిమెంట్ యొక్క మెమరీ అడ్రస్ పాయింటర్‌గా దిగజారుతుంది (Decays to a pointer to its first element).

🔑 అర్రే ఇండెక్సింగ్ అనేది కేవలం షుగర్ సింటాక్స్ (Syntactic Sugar):

కంపైలర్ దృష్టిలో arr[i] అనే ప్రత్యేకమైన ఆపరేషన్ లేదు! మీరు arr[i] అని రాసిన ప్రతిసారీ కంపైలర్ అంతర్గతంగా దానిని *(arr + i) గా మారుస్తుంది.

💡 ఇంటర్వ్యూ ఫన్ ఫ్యాక్ట్: కూడికలో స్థానాలు మారినా విలువ మారదు కాబట్టి, *(arr + i) అనేది *(i + arr) కి సమానం. దీని అర్థం C లో i[arr] అని రాసినా ప్రోగ్రామ్ ఖచ్చితంగా సరైన ఫలితాన్నే ఇస్తుంది!

C — Array Pointer Equivalence & i[arr] ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int nums[4] = {10, 20, 30, 40};

    printf("nums[2]     = %d\n", nums[2]);
    printf("*(nums + 2) = %d\n", *(nums + 2));
    printf("2[nums]     = %d (వాలిడ్ సింటాక్స్!)\n", 2[nums]);
    return 0;
}
2అర్రేలను ఫంక్షన్లకు పంపినప్పుడు పాయింటర్ డికే

ఒక ఫంక్షన్ హెడర్‌లో void print(int arr[]) అని రాసినప్పటికీ, కంపైలర్ దానిని అంతర్గతంగా void print(int *arr) గానే మారుస్తుంది. అర్రే కాపీ చేయబడదు; కేవలం మొదటి ఎలిమెంట్ అడ్రస్ మాత్రమే వెళ్తుంది.

⚠️ ఫంక్షన్ లోపల sizeof(arr) ట్రాప్:

main() లో sizeof(arr) అర్రే మొత్తం బైట్లను ఇస్తుంది. కానీ ఫంక్షన్ లోపల sizeof(arr) వాడితే అది కేవలం పాయింటర్ సైజు (8 బైట్లు) మాత్రమే ఇస్తుంది! అందుకే C లో అర్రేను ఫంక్షన్‌కు పంపినప్పుడు దాని సైజ్‌ను ప్రత్యేక పారామీటర్‌గా పంపడం తప్పనిసరి.

3డబుల్ పాయింటర్లు (Double Pointers **ptr)

ఒక పాయింటర్ కూడా మెమరీలో ఒక వేరియబుల్ కాబట్టి దానికి కూడా ఒక RAM అడ్రస్ ఉంటుంది. ఒక పాయింటర్ యొక్క మెమరీ అడ్రస్‌ను నిల్వ చేసే పాయింటర్‌ను డబుల్ పాయింటర్ (Pointer to Pointer) అంటారు.

C — Double Pointer Architecture ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int val = 500;
    int *ptr = &val;     // సింగిల్ పాయింటర్: val అడ్రస్
    int **dptr = &ptr;   // డబుల్ పాయింటర్: ptr అడ్రస్

    printf("val విలువ          : %d\n", val);
    printf("*ptr (సింగిల్)     : %d\n", *ptr);
    printf("**dptr (డబుల్)      : %d\n", **dptr);

    // డబుల్ పాయింటర్ ద్వారా మార్చడం
    **dptr = 999;
    printf("నవీకరించబడిన val    : %d\n", val);
    return 0;
}

💡 డబుల్ పాయింటర్లను డైనమిక్ 2D అర్రేస్ (Dynamic 2D Arrays) సృష్టించడానికి మరియు ఫంక్షన్ ద్వారా వేరొక పాయింటర్ అడ్రస్‌ను మార్చడానికి (Modifying a pointer in a function) వాడతారు.

4ఫంక్షన్ పాయింటర్లు (Function Pointers & Callbacks)

వేరియబుల్స్ లాగే ఫంక్షన్లు కూడా RAM లోని కోడ్ సెగ్మెంట్ (Text Segment) లో నిల్వ ఉంటాయి. ఒక ఫంక్షన్ యొక్క ఎగ్జిక్యూటబుల్ మెమరీ అడ్రస్‌ను స్టోర్ చేసే పాయింటర్‌ను ఫంక్షన్ పాయింటర్ అంటారు. దీని ద్వారా రన్‌టైమ్‌లో ఏ ఫంక్షన్ పిలవాలో డైనమిక్‌గా నిర్ణయించవచ్చు (Callbacks).

C — Function Pointer Callback Demo ⚡ Try in C Compiler 
#include <stdio.h>

int add(int a, int b) { return a + b; }
int multiply(int a, int b) { return a * b; }

// ఫంక్షన్ పాయింటర్‌ను ఆర్గ్యుమెంట్‌గా స్వీకరించే ఫంక్షన్
void computeAndPrint(int x, int y, int (*operation)(int, int)) {
    int res = operation(x, y); // కాల్‌బ్యాక్ ఎగ్జిక్యూషన్
    printf("ఆపరేషన్ ఫలితం: %d\n", res);
}

int main(void) {
    computeAndPrint(10, 5, add);      // ఫలితం: 15
    computeAndPrint(10, 5, multiply); // ఫలితం: 50
    return 0;
}
5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. int *arr[] మరియు int (*arr)[] ల మధ్య కన్‌ఫ్యూజన్:
int *arr[5]; అంటే 5 పాయింటర్ల అర్రే (Array of Pointers). కానీ int (*arr)[5]; అంటే 5 పూర్ణాంకాలు గల ఒక అర్రేని పాయింట్ చేసే ఏకైక పాయింటర్. బ్రాకెట్ ప్రాధాన్యత మొత్తం అర్థాన్నే మారుస్తుంది.
❌ 2. డబుల్ పాయింటర్‌ను సింగిల్ ఆస్టెరిస్క్ తో విలువ అనుకోవడం:
dptr వద్ద *dptr అంటే కేవలం మధ్యలోని పాయింటర్ అడ్రస్ మాత్రమే వస్తుంది. అసలు విలువ కావాలంటే ఖచ్చితంగా రెండుసార్లు డీరిఫరెన్స్ (**dptr) చేయాలి.
6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: C స్టాండర్డ్ లైబ్రరీ qsort() ఫంక్షన్ పాయింటర్లను ఎలా వాడుతుంది?

qsort() అనేది జెనరిక్ క్విక్ సార్ట్ ఫంక్షన్. ఏ రెండు ఎలిమెంట్లను పోల్చాలో దానికి తెలియదు కాబట్టి, డెవలపర్ రాసిన కంపారేటర్ ఫంక్షన్ అడ్రస్‌ను (Function Pointer int (*compar)(const void*, const void*)) ఆర్గ్యుమెంట్‌గా తీసుకుని సార్టింగ్ పూర్తి చేస్తుంది.

Q: main ఫంక్షన్‌లో char *argv[] మరియు char **argv రెండూ ఒకటేనా?

అవును! ఫంక్షన్ పారామీటర్లలో అర్రే డికే నియమం ప్రకారం char *argv[] అనేది స్వయంచాలకంగా char **argv (Pointer to char pointer) గా మారుతుంది. రెండూ కమాండ్ లైన్ ఆర్గ్యుమెంట్లను రీడ్ చేయడానికి పూర్తిగా సమానమైనవి.
