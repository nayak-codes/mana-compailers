C Variables, Memory Model, Scope & Constants (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 2 📂 Phase 02: Variables & Data Types 📅 2026 Edition
📌 Covered in this in-depth guide: Variables అంటే ఏంటి? · RAM Memory Model · Declaration, Initialization & Assignment · Naming Rules · Local vs Global Scope · Stack Lifetime · const vs #define

Phase 2 (Part 1): C Variables, Memory Model, Scope & Constants కు స్వాగతం! C లాంగ్వేజ్ లో వేరియబుల్స్ అనేవి గాల్లో ఉండే కాన్సెప్ట్స్ కావు — అవి మీ కంప్యూటర్ RAM మెమరీ లో ఒక ప్లేస్ ని (bytes) డైరెక్ట్ గా రిప్రజెంట్ చేస్తాయి. C లాంగ్వేజ్ మెమరీ ని ఎలా ఇస్తుంది, స్టాక్ ఫ్రేమ్స్ ఎలా పనిచేస్తాయి, వేరియబుల్స్ లైఫ్ టైం ఏంటి, మరియు కాన్స్టాంట్స్ ఎలా వాడాలి అనేది అర్థం చేసుకుంటే మీరు పాయింటర్స్ ని చాలా ఈజీగా నేర్చేసుకోవచ్చు. ఈ గైడ్ లో, వేరియబుల్ లైఫ్ సైకిల్, మెమరీ అడ్రస్ ఆపరేటర్ (&), లోకల్ vs గ్లోబల్ స్టోరేజ్, మరియు const కి #define కి మధ్య ఉన్న తేడాలని పూర్తిగా నేర్చుకుందాం.

1Variables అంటే ఏంటి? RAM మెమరీ ఆర్కిటెక్చర్ & అడ్రస్‌లు

Variable ante computer RAM (Random Access Memory) lo data ni store cheyyadaniki allocate chesina Named Memory Location. Prati variable ki 3 main attributes untayi:

  1. Name (Identifier): మనం కోడ్ లో పిలిచే పేరు (ఉదా: age).
  2. Type & Size: ఆ వేరియబుల్ లో స్టోర్ చేసే డేటా రకం (ఉదా: int = RAM లో 4 బైట్స్ తీసుకుంటుంది).
  3. Memory Address: RAM లో ఆ వేరియబుల్ ఎక్కడ సేవ్ అయిందో చెప్పే ఒక ఫిజికల్ హెక్సాడెసిమల్ అడ్రస్ (ఉదా: 0x7ffee4b1). దీన్ని C లాంగ్వేజ్ లో &variable ఆపరేటర్ తో డైరెక్ట్ గా చూడొచ్చు.

2Declaration, Initialization & Assignment లైఫ్‌సైకిల్

C లాంగ్వేజ్ లో వేరియబుల్స్ క్రియేషన్ అనేది 3 స్టెప్స్ లో జరుగుతుంది:

1. Declaration (డిక్లరేషన్):

కంపైలర్ కి వేరియబుల్ పేరు మరియు దాని డేటా టైప్ చెప్పడం. ఈ స్టేజ్ లో మెమరీ దొరుకుతుంది కానీ మనం ఏ వాల్యూ పెట్టము: int score;
⚠️ Garbage Value Warning: C లో జస్ట్ డిక్లేర్ చేసి వదిలేసిన లోకల్ వేరియబుల్స్ లో RAM లో ముందే ఉన్న చెత్త డేటా (Garbage Value) ఉంటుంది! కాబట్టి కచ్చితంగా వాల్యూ ఇవ్వాలి.

2. Initialization (ఇనిషియలైజేషన్):

వేరియబుల్ ని క్రియేట్ చేస్తున్నప్పుడే ఫస్ట్ టైమ్ దానికి ఒక వాల్యూ ఇవ్వడం: int score = 100; (మెమరీ అలాకేషన్ + వాల్యూ ఒకేసారి జరుగుతాయి).

3. Assignment (అసైన్‌మెంట్):

ఆల్రెడీ క్రియేట్ అయిన వేరియబుల్ లో ఉన్న వాల్యూ ని పీకేసి కొత్త వాల్యూ ని పెట్టడం: score = 250;.

3Variable Naming Rules (రూల్స్)

C లాంగ్వేజ్ లో పేర్లు (Identifiers) క్రియేట్ చేయడానికి కంపైలర్ కొన్ని స్ట్రిక్ట్ రూల్స్ పెట్టింది:

రూల్ (Rule)కరెక్ట్ (Valid)తప్పు (Invalid)
కచ్చితంగా ఆల్ఫాబెట్ (a-z, A-Z) లేదా అండర్ స్కోర్ (_) తో స్టార్ట్ అవ్వాలిint age;, int _count;int 2age; (నంబర్ తో స్టార్ట్ అవ్వకూడదు!)
అక్షరాలు, నంబర్లు, మరియు అండర్ స్కోర్లు మాత్రమే ఉండాలిint total_marks1;int total-marks;, int total$ (స్పెషల్ క్యారెక్టర్స్ వాడకూడదు!)
Case Sensitive (age వేరు Age వేరు)int age = 10; int Age = 20;అనుకోకుండా కాపిటల్ లెటర్ పెడితే undeclared identifier వస్తుంది.
C కీవర్డ్స్ ని పేర్లుగా వాడకూడదు (32 Keywords)int my_return;int return;, int while;, int int; (Keyword error!)
పేరు మధ్యలో స్పేసెస్ ఉండకూడదుint student_roll_no;int student roll no; (Syntax Error!)
4Local vs Global Variables: స్కోప్ & లైఫ్ టైం ఆర్కిటెక్చర్

C లో వేరియబుల్ ఎక్కడ డిక్లేర్ చేసాము అనే దాన్ని బట్టి దాని Scope (ఎక్కడి వరకు యాక్సెస్ చేయగలం) మరియు Lifetime (RAM లో ఎంతసేపు ఉంటుంది) డిసైడ్ అవుతుంది:

ప్రాపర్టీLocal Variable (Stack Memory)Global Variable (Data Segment)
ఎక్కడ రాస్తారు?ఫంక్షన్ లోపల లేదా బ్లాక్ { ... } లోపల.ఫంక్షన్స్ కి బయట (ఫైల్ స్టార్టింగ్ లో).
Scope (విజిబిలిటీ)ఏ బ్లాక్ లో రాసామో ఆ బ్లాక్ లోపల మాత్రమే పనిచేస్తుంది.ప్రోగ్రామ్ లో ఎక్కడి నుంచైనా యాక్సెస్ చేయొచ్చు.
Default ValueGarbage Value (చెత్త డేటా!)Zero (0) ఆటోమాటిక్ గా ఇనిషియలైజ్ అవుతుంది.
Lifetime in RAMఫంక్షన్ కాల్ అయినప్పుడు క్రియేట్ అయ్యి; ఫంక్షన్ అయిపోగానే RAM నుంచి డిలీట్ అవుతుంది!ప్రోగ్రామ్ స్టార్ట్ అయినప్పుడు క్రియేట్ అయ్యి; ప్రోగ్రామ్ క్లోజ్ అయ్యేంత వరకు ఉంటుంది!
C — Local vs Global Scope Demo ▶ Run Code 
#include <stdio.h>

// 1. Global Variable (Stored in Data Segment, lives entire program)
int globalCounter = 500;

void testFunction(void) {
    // 2. Local Variable (Created in Stack frame of testFunction)
    int localVal = 10;
    printf("Inside testFunction: localVal = %d, globalCounter = %d\n", localVal, globalCounter);
} // localVal is destroyed from Stack here!

int main(void) {
    int mainLocal = 100;

    testFunction();
    printf("Inside main: mainLocal = %d, globalCounter = %d\n", mainLocal, globalCounter);

    // printf("%d", localVal); // ❌ Compile Error: 'localVal' is undeclared in main scope!
    return 0;
}
5Constants (కాన్స్టాంట్స్): const Keyword vs #define మ్యాక్రోస్

ప్రోగ్రామ్ రన్ అవుతున్నప్పుడు ఒక వేరియబుల్ వాల్యూ అస్సలు చేంజ్ అవ్వకుండా Read-Only గా ఉంచాలంటే Constants వాడతాము. C లో దీనికి 2 పద్ధతులు ఉన్నాయి:

1. const Keyword (Type-Safe కంపైలర్ కాన్స్టాంట్)

const double PI = 3.14159;
• దీనికి కచ్చితమైన డేటా టైప్ ఉంటుంది (కంపైలర్ దాన్ని చెక్ చేస్తుంది).
• మళ్ళీ వేరే వాల్యూ ఇవ్వాలని ట్రై చేస్తే error: assignment of read-only variable వస్తుంది.

2. #define Preprocessor Macro (టెక్స్ట్ రీప్లేస్‌మెంట్)

#define MAX_USERS 100
• కంపైల్ అవ్వక ముందే (Preprocessor స్టేజ్ లో) ఆ పేరు ఎక్కడ ఉంటే అక్కడ వాల్యూ పేస్ట్ అయిపోతుంది (మెమరీ తీసుకోదు).
• దీని చివర్లో సెమికోలన్ ; పెట్టకూడదు!

C — Constants in Action ▶ Run Code 
#include <stdio.h>

#define APP_VERSION 2.5   // Preprocessor Constant
const int MAX_LIMIT = 500; // Type-Safe const Variable

int main(void) {
    printf("Application Version: %.1f\n", APP_VERSION);
    printf("Maximum Limit: %d\n", MAX_LIMIT);

    // MAX_LIMIT = 600; // ❌ Compile Error: Assignment of read-only variable!
    return 0;
}
