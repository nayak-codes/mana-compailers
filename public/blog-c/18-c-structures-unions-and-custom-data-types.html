Structures (struct) & Unions Basics in C (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 18 📂 Phase 10: User-Defined Data Types 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Struct ఎందుకు కావాలి? · Struct Declaration · Union అంటే ఏంటి?

మనం ఇంతకుముందు Arrays గురించి నేర్చుకున్నాం. అర్రేస్ లో ఒకే రకమైన డేటా ని మాత్రమే స్టోర్ చేయగలం (అన్నీ ఇంటిజర్లు లేదా అన్నీ క్యారెక్టర్లు). కానీ ఒక స్టూడెంట్ డేటా స్టోర్ చేయాలంటే... వాడికి ఒక పేరు (String) ఉంటుంది, ఒక రోల్ నంబర్ (Integer) ఉంటుంది, ఒక పర్సెంటేజ్ (Float) ఉంటుంది. ఇలా వేర్వేరు రకాల డేటాని కలిపి ఒకే ప్యాకెట్ లాగా చేయడానికే C లాంగ్వేజ్ లో Structures (స్ట్రక్చర్స్) అనే కాన్సెప్ట్ ఉంది.

1 Structure (struct) అంటే ఏమిటి?

స్ట్రక్చర్ అనేది మనకు కావలసినట్టుగా మనం క్రియేట్ చేసుకునే ఒక సొంత డేటా టైప్ (Custom Data Type). దీనిలోపల మనం ఎన్నైనా రకాల వేరియబుల్స్ ని పెట్టుకోవచ్చు.

🎒 రియల్ లైఫ్ స్టోరీ: స్కూల్ బ్యాగ్

మీరు స్కూల్ కి వెళ్లేటప్పుడు కేవలం పుస్తకాలు మాత్రమే తీసుకువెళ్లరు కదా. ఒక బాక్స్ లో పుస్తకాలు, ఇంకో దాంట్లో లంచ్ బాక్స్, ఇంకో దాంట్లో పెన్సిల్ బాక్స్... ఇవన్నీ వేర్వేరు రకాల ఐటమ్స్.

కానీ ఆ పది వస్తువులను విడివిడిగా పట్టుకుని నడిస్తే కిందపడిపోతాయి. కాబట్టి వాటన్నింటినీ కలిపి ఒకే "స్కూల్ బ్యాగ్" లో పెట్టుకుంటారు.
మన C లాంగ్వేజ్ లో ఉన్న Structure అనేది కరెక్ట్ గా ఈ స్కూల్ బ్యాగ్ లాంటిదే! వేర్వేరు డేటాని ఒకే బ్యాగ్ లో సేవ్ చేస్తుంది.

2 ఒకే ఒక సింపుల్ కోడ్

స్ట్రక్చర్ ని క్రియేట్ చేయడానికి struct అనే కీవర్డ్ వాడతాం. లోపల ఉన్న డేటాని వాడాలంటే డాట్ (.) ని వాడుతాం. కింద కోడ్ లో స్టూడెంట్ బ్యాగ్ ని ఎలా క్రియేట్ చేశానో చూడండి.

C — Simple Struct ▶ Run Code 
#include <stdio.h>

// స్టూడెంట్ అనే ఒక కొత్త బ్యాగ్ (Structure) తయారీ
struct Student {
    int id;
    float marks;
};

int main(void) {
    // 's1' అనే పేరుతో ఒక బ్యాగ్ తీసుకున్నాం
    struct Student s1;
    
    // బ్యాగ్ లోపల ఉన్న ఐటమ్స్ కి డాట్(.) వాడి వాల్యూస్ ఇస్తున్నాం
    s1.id = 101;
    s1.marks = 95.5;
    
    printf("ID: %d, Marks: %.1f\n", s1.id, s1.marks);
    
    return 0;
}
3 ఫ్రీక్వెంట్ గా అడిగే ప్రశ్నలు (FAQ)

Q: Struct కి, Union కి ఉన్న తేడా ఏంటి?

రెండూ బ్యాగ్స్ లాంటివే. కానీ Struct లోపల ఎన్ని ఐటమ్స్ ఉంటే అంత మెమరీ క్రియేట్ అవుతుంది (అందరికీ సపరేట్ గా). కానీ union లో మాత్రం అందులో ఏది పెద్ద ఐటమో, దానికి మాత్రమే మెమరీ క్రియేట్ అయ్యి... మిగతావన్నీ అదే మెమరీని షేర్ చేసుకుంటాయి. మెమరీ తక్కువ ఉన్న మైక్రోకంట్రోలర్స్ లో Unions ని వాడతారు.

Q: స్ట్రక్చర్ లోపల ఇంకో స్ట్రక్చర్ ఉండొచ్చా?

ఖచ్చితంగా ఉండొచ్చు! దీన్నే Nested Structures అంటారు. ఉదాహరణకు ఒక 'Company' స్ట్రక్చర్ లోపల 'Employee' అనే ఇంకో స్ట్రక్చర్ ని పెట్టుకోవచ్చు.
