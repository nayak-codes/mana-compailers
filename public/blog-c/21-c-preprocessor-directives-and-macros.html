Preprocessor Directives & Macros in C (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 21 📂 Phase 12: Preprocessor Directives 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Preprocessor అంటే ఏంటి? · #include · #define మ్యాక్రోస్

మనం ఎప్పుడూ C ప్రోగ్రామ్ పైన #include <stdio.h> అని రాస్తూ ఉంటాం కదా. అసలు ఆ హాష్ (#) సింబల్ ఎందుకు వాడతాం? కంపైలర్ కి ఆ లైన్ అంటే ఎందుకంత భయం? ఈ హాష్ సింబల్ తో మొదలయ్యే లైన్స్ ని Preprocessor Directives అంటారు. అసలు ఈ ప్రీ-ప్రాసెసర్ అంటే ఏంటో, అది ఎలా పనిచేస్తుందో ఈ ఫైనల్ పాఠంలో నేర్చుకుందాం.

1 Preprocessor (ప్రీ-ప్రాసెసర్) అంటే ఏమిటి?

మీ కోడ్ ని కంపైలర్ (ఆంగ్ల అక్షరాలని సున్నాలు, ఒకట్లుగా మార్చేది) చదవడానికి ముందే, ఒక చిన్న అసిస్టెంట్ వచ్చి మీ కోడ్ ని రెడీ చేస్తాడు. వాడి పేరే ప్రీ-ప్రాసెసర్. వాడు కేవలం # సింబల్ తో ఉన్న లైన్స్ ని మాత్రమే వెతికి వాటిని మార్చేస్తాడు.

🎬 రియల్ లైఫ్ స్టోరీ: సినిమా డైరెక్టర్ మరియు అసిస్టెంట్

ఒక సినిమా షూటింగ్ జరుగుతోంది. డైరెక్టర్ (కంపైలర్) సీన్ తీయడానికి వచ్చే ముందే, అసిస్టెంట్ డైరెక్టర్ (ప్రీ-ప్రాసెసర్) వచ్చి లైట్స్ అన్నీ ఆన్ చేసి, కెమెరా సెట్ చేసి, యాక్టర్స్ కి డైలాగ్స్ ఇచ్చి అంతా రెడీ చేస్తాడు. డైరెక్టర్ రాగానే డైరెక్ట్ గా ఆక్షన్ చెప్తాడు.

కోడ్ లో కూడా కంపైలర్ వచ్చే ముందే, #include లైన్స్ ని చూసి ఆ ఫైల్స్ లో ఉన్న కోడ్ మొత్తాన్ని తీసుకొచ్చి మన ఫైల్ లో అతికించేవాడే ఈ ప్రీ-ప్రాసెసర్.

2 ఒకే ఒక సింపుల్ కోడ్ (#define మ్యాక్రోస్)

#define వాడి మనం మ్యాక్రోస్ (Macros) క్రియేట్ చేయొచ్చు. అంటే కోడ్ లో ఎక్కడైనా ఒక పదం ఉంటే, కంపైల్ అయ్యేముందు ఆ పదాన్ని వేరే వాల్యూ తో ఫైండ్ & రీప్లేస్ (Find and Replace) చేసేయొచ్చు.

C — #define Demo ▶ Run Code 
#include <stdio.h>

// PI అనే పదం ఎక్కడ ఉన్నా 3.14 కి మార్చేయ్ అని చెప్తున్నాం
#define PI 3.14

int main(void) {
    // ఇక్కడ కంపైలర్ కి PI బదులు 3.14 మాత్రమే వెళ్తుంది
    printf("Value of PI is: %.2f\n", PI);
    
    return 0;
}
3 ఫ్రీక్వెంట్ గా అడిగే ప్రశ్నలు (FAQ)

Q: const float PI = 3.14; కి మరియు #define PI 3.14 కి తేడా ఏంటి?

చాలా పెద్ద తేడా ఉంది. const వాడితే దానికి మెమరీ లో ఒక ప్లేస్ (డబ్బా) దొరుకుతుంది, అది కంపైలర్ చూసుకుంటుంది. కానీ #define వాడితే దానికి మెమరీ ఉండదు, అది కేవలం టెక్స్ట్ ని కాపీ-పేస్ట్ చేయడం లాంటిది (ప్రీ-ప్రాసెసర్ చూసుకుంటుంది).

Q: ప్రీ-ప్రాసెసర్ లో ఇంకేమైనా ఉంటాయా?

అవును! #ifdef, #ifndef లాంటివి ఉంటాయి. ఇవి కోడ్ ని కండిషన్స్ బట్టి కంపైల్ చేయాలా వద్దా అని డిసైడ్ చేస్తాయి (దీన్నే Conditional Compilation అంటారు). విండోస్ కి ఒక కోడ్, మ్యాక్ కి ఇంకో కోడ్ రన్ అయ్యేలా చేయొచ్చు.
