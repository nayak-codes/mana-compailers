యూజర్ ఇన్‌పుట్ (scanf), ఫార్మాట్ స్పెసిఫైయర్లు & బఫర్ హ్యాండ్లింగ్

⚡ Modern C (C99 / C11) 🟢 Chapter 3 of 20 📂 Phase 01: బేసిక్స్ & మెమరీ ఆర్కిటెక్చర్ 📅 2026 Edition
📌 Covered in this chapter: %d, %f, %c, %s స్పెసిఫైయర్లు · & (Address-of) రహస్యం · ది డేంజరస్ scanf న్యూలైన్ బఫర్ ట్రాప్ & getchar() పరిష్కారం
కీబోర్డ్ ద్వారా ప్రోగ్రామ్‌కు డేటాను అందించడానికి C లో అత్యంత ప్రముఖమైన ఫంక్షన్ scanf(). ఫార్మాట్ స్పెసిఫైయర్లు, & (Address-of) ఆపరేటర్ ఎందుకు తప్పనిసరి, మరియు బిగినర్స్ నిద్రపట్టకుండా చేసే scanf న్యూలైన్ బఫర్ ట్రాప్ ను ఈ అధ్యాయంలో నేర్చుకుందాం.
1scanf() ఎలా పనిచేస్తుంది? (& ఆపరేటర్ రహస్యం)

scanf("%d", &age); లో & ఎందుకు పెడతామంటే, C లో ఫంక్షన్లకు పాస్ చేసే విలువలు కాపీ అవుతాయి. మనం ఇచ్చిన విలువను వేరియబుల్ యొక్క మెమరీ అడ్రస్‌లో నేరుగా రాయడానికి కంపైలర్‌కు ఆ వేరియబుల్ యొక్క RAM అడ్రస్ అవసరం.

C — Basic scanf ▶ Run in Compiler 
#include <stdio.h>

int main() {
    int studentAge;
    printf("Enter Student Age: ");
    scanf("%d", &studentAge);

    printf("Confirmed Age: %d years old.\n", studentAge);
    return 0;
}
2ది మోస్ట్ ఫేమస్ C బగ్: scanf న్యూలైన్ బఫర్ ట్రాప్!

⚠️ The Ghost Enter Key Mystery:

మీరు ఒక సంఖ్యను scanf("%d", &age); తో చదివి, వెంటనే scanf("%c", &ch); రాస్తే, క్యారెక్టర్ అడగకుండానే ప్రోగ్రామ్ ముగిసిపోతుంది! ఎందుకంటే సంఖ్య టైప్ చేసి ఎంటర్ కొట్టినప్పుడు, ఆ '\n' (Enter Key) బఫర్‌లోనే ఉండిపోతుంది. తర్వాతి %c ఆ ఎంటర్‌ను చదివి వెళ్లిపోతుంది!

రహస్య పరిష్కారం: ఫార్మాట్ స్పెసిఫైయర్‌కు ముందు ఒక స్పేస్ ఇవ్వండి: scanf(" %c", &ch);. ఆ స్పేస్ బఫర్‌లోని పాత ఎంటర్‌లను ఆటోమేటిక్‌గా తుడిచివేస్తుంది!
