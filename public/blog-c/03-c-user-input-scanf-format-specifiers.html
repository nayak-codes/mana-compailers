యూజర్ ఇన్‌పుట్ (scanf), ఫార్మాట్ స్పెసిఫైయర్లు & బఫర్ హ్యాండ్లింగ్

⚡ Modern C (C99 / C11) 🟢 Chapter 3 of 20 📂 Phase 01: బేసిక్స్ & మెమరీ ఆర్కిటెక్చర్ 📅 2026 Edition
📌 Covered in this chapter: %d, %f, %c, %s స్పెసిఫైయర్లు · & (Address-of) రహస్యం · ది డేంజరస్ scanf న్యూలైన్ బఫర్ ట్రాప్ & getchar() పరిష్కారం
కంప్యూటర్ ప్రోగ్రామ్‌లు నిజమైన ప్రయోజనాన్ని ఇవ్వాలంటే అవి యూజర్ ఇచ్చే డేటాను డైనమిక్‌గా స్వీకరించగలగాలి. C లో కీబోర్డ్ ఇన్‌పుట్ తీసుకోవడానికి ప్రాథమిక సాధనం scanf(). అయితే బిగినర్స్ చేసే అత్యంత తీవ్రమైన పొరపాట్లైన మెమరీ అడ్రస్ & మర్చిపోవడం, న్యూలైన్ బఫర్ ట్రాప్ (Ghost Newline), మరియు ప్రమాదకరమైన బఫర్ ఓవర్‌ఫ్లోలను నివారించే పద్ధతులను ఈ అధ్యాయంలో లోతుగా తెలుసుకుందాం.
1scanf() అంతర్గత పనితీరు (& ఆపరేటర్ ప్రాముఖ్యత)

printf() ఫంక్షన్ విలువను స్క్రీన్‌పై ముద్రించడానికి కేవలం ఆ వేరియబుల్ విలువ యొక్క నకలును (Copy of value) తీసుకుంటే సరిపోతుంది. కానీ scanf() వినియోగదారుడు టైప్ చేసిన డేటాను నేరుగా RAM లోని ఆ వేరియబుల్ గదిలో భద్రపరచాలి.

🔑 & (Address-of Operator) ఎందుకు తప్పనిసరి?

&age అని రాసినప్పుడు అది age వేరియబుల్ యొక్క వాస్తవ మెమరీ చిరునామాను (RAM Hex Address, e.g. 0x7ffee4) కంపైలర్‌కు అందిస్తుంది. ఒకవేళ & పెట్టడం మర్చిపోతే, scanf ఆ వేరియబుల్ లోని గార్బేజ్ నంబర్‌నే మెమరీ అడ్రస్‌గా భావించి అక్కడ డేటా రాయడానికి ప్రయత్నిస్తుంది. ఫలితంగా ఆపరేటింగ్ సిస్టమ్ ప్రోగ్రామ్‌ను వెంటనే చంపేస్తుంది (Segmentation Fault / Crash).

C — scanf user input ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    int rollNumber;
    float marks;

    printf("మీ రోల్ నంబర్ మరియు మార్కులు ఎంటర్ చేయండి: ");
    // రెండు విలువలను ఒకేసారి చదవడం
    scanf("%d %f", &rollNumber, &marks);

    printf("రోల్ నంబర్: %d | మార్కులు: %.2f\n", rollNumber, marks);
    return 0;
}
2C ఫార్మాట్ స్పెసిఫైయర్స్ కాంప్రహెన్సివ్ టేబుల్

scanf() మరియు printf() లలో డేటా టైప్‌ను సూచించడానికి ఉపయోగించే ఫార్మాట్ స్పెసిఫైయర్స్ పట్టిక:

స్పెసిఫైయర్ డేటా రకం ఉదాహరణ ఇన్‌పుట్ ప్రాముఖ్యత
%d / %i Signed int 42, -10 సాధారణ పూర్ణాంకాలు చదవడానికి
%u Unsigned int 50000 ధన పూర్ణాంకాలు మాత్రమే
%f float 3.14 దశాంశ సంఖ్యలు
%lf double 3.14159265 డబుల్ ప్రెసిషన్ ఫ్లోటింగ్ పాయింట్
%c char 'A', '#' ఏకైక క్యారెక్టర్ (స్పేస్, న్యూలైన్ సహా)
%s char array (string) "Dennis" స్పేస్ వచ్చేంత వరకు ఒక పదాన్ని చదువుతుంది
%p Pointer (address) 0x7ffe42 హెక్సాడెసిమల్ మెమరీ అడ్రస్ ప్రింట్ చేయడానికి
3ది మోస్ట్ ఫేమస్ C బగ్: scanf న్యూలైన్ బఫర్ ట్రాప్!

ప్రతి C విద్యార్థిని లేదా డెవలపర్‌ను తీవ్రంగా వేధించే ఒక మిస్టీరియస్ సమస్య: ఒక నంబర్‌ను ఇన్‌పుట్ తీసుకున్న వెంటనే క్యారెక్టర్ (%c) ను ఇన్‌పుట్ తీసుకోవడానికి ప్రయత్నిస్తే, ప్రోగ్రామ్ యూజర్ కోసం ఆగకుండా ఆటోమేటిక్‌గా స్కిప్ అయిపోతుంది!

🕵️‍♂️ అసలేం జరుగుతోంది? (The Buffer Mechanics):

  1. మీరు నంబర్ 25 అని టైప్ చేసి కీబోర్డ్ పై Enter కీ ప్రెస్ చేస్తారు.
  2. స్టాండర్డ్ ఇన్‌పుట్ బఫర్ (stdin) లోకి '2', '5', మరియు '\n' (Newline క్యారెక్టర్) వెళ్తాయి.
  3. scanf("%d", &age) కేవలం 25 ను మాత్రమే చదివి, ఆ ఎంటర్‌ను ('\n') బఫర్‌లోనే వదిలేస్తుంది!
  4. వెంటనే తర్వాతి లైన్‌లోని scanf("%c", &grade) రన్ అయినప్పుడు, అది బఫర్‌లో ఇప్పటికే పడి ఉన్న '\n' ను చదివేసి క్యారెక్టర్‌గా భావిస్తుంది. దాంతో యూజర్ కీబోర్డ్ టైప్ చేయడానికి ముందే ఖాళీగా ఎగ్జిట్ అయిపోతుంది!

✅ ది అఫీషియల్ సొల్యూషన్ (The Leading Space Trick):

%c కి ముందు ఒక సింగిల్ స్పేస్ ఇవ్వండి: scanf(" %c", &grade);

ఫార్మాట్ స్ట్రింగ్‌లో ముందు స్పేస్ ఇవ్వడం ద్వారా C కంపైలర్ బఫర్‌లో నిల్వ ఉన్న అన్ని వైట్‌స్పేస్‌లను, న్యూలైన్లను ('\n') స్వయంచాలకంగా విస్మరించి, యూజర్ ఇచ్చే తాజా అక్షరం కోసం ఎదురుచూస్తుంది!

4స్పేస్‌లతో కూడిన స్ట్రింగ్స్ చదవడం: fgets() vs scanf()

ఒక పూర్తి పేరును (ఉదాహరణకు Dennis Ritchie) scanf("%s", name) తో చదివితే అది కేవలం Dennis ను మాత్రమే తీసుకుంటుంది. ఎందుకంటే స్పేస్ రాగానే scanf ఆగిపోతుంది. దీనికి పరిష్కారం fgets().

C — Safe string input with fgets ⚡ Try in C Compiler 
#include <stdio.h>

int main(void) {
    char fullName[50];

    printf("మీ పూర్తి పేరు నమోదు చేయండి: ");
    // గరిష్టంగా 50 బైట్లు మాత్రమే చదువుతుంది — సురక్షితమైనది!
    fgets(fullName, sizeof(fullName), stdin);

    printf("స్వాగతం, %s", fullName);
    return 0;
}
🚫 gets() ఫంక్షన్‌ను ఎందుకు నిషేధించారు?

పాత C పుస్తకాలలో gets(str) కనిపిస్తుంది. కానీ gets() యూజర్ ఎన్ని అక్షరాలు టైప్ చేసినా పరిమితి లేకుండా మెమరీలోకి రాసేస్తుంది (Buffer Overflow Vulnerability). ఇది హ్యాకర్లకు కంప్యూటర్‌ను హైజాక్ చేసే వెసులుబాటు కల్పించింది. అందుకే C11 Standard నుండి gets() ఫంక్షన్‌ను శాశ్వతంగా తొలగించారు. ఎల్లప్పుడూ కేవలం fgets() మాత్రమే వాడాలి.

5బిగినర్స్ చేసే ఘోరమైన తప్పులు (Beginner Pitfalls)
❌ 1. scanf లో పెట్టడం:
scanf("%d\n", &num); // ఘోరమైన తప్పు! scanf ఫార్మాట్ స్ట్రింగ్ లోపల \n పెడితే, మీరు ఏదైనా వైట్‌స్పేస్ కాని అక్షరాన్ని టైప్ చేసేంత వరకు ప్రోగ్రామ్ ఆగకుండా హ్యాంగ్ అయినట్లు ఉండిపోతుంది!
❌ 2. స్ట్రింగ్స్ (char arrays) కి & వాడడం:
char name[20]; scanf("%s", &name); // & అనవసరం C లో అర్రే పేరు (Array decay) ఇప్పటికే దాని మొదటి ఎలిమెంట్ యొక్క మెమరీ అడ్రస్ పాయింటర్ అవుతుంది. కాబట్టి scanf("%s", name) అని రాయడమే సరైనది.
6తరచుగా అడిగే ప్రశ్నలు (FAQ)

Q: scanf ఎన్ని ఇన్‌పుట్‌లను సరిగ్గా చదివిందో ప్రోగ్రామ్‌లో ఎలా తెలుసుకోవచ్చు?

scanf() ఫంక్షన్ తాను విజయవంతంగా రీడ్ చేసిన వేరియబుల్స్ సంఖ్యను రిటర్న్ చేస్తుంది! ఉదాహరణకు if (scanf("%d", &num) != 1) అని రాస్తే యూజర్ నంబర్ బదులు అక్షరం టైప్ చేశాడని గుర్తించి ఇన్‌పుట్ వాలిడేషన్ చేయవచ్చు.

Q: fflush(stdin) వాడి బఫర్ క్లియర్ చేయవచ్చా?

చేయకూడదు! C ISO స్టాండర్డ్ ప్రకారం fflush() కేవలం అవుట్‌పుట్ స్ట్రీమ్‌ల (stdout) కోసమే. ఇన్‌పుట్ స్ట్రీమ్ (stdin) పై fflush వాడటం Undefined Behavior — ఇది విండోస్‌లో పనిచేసినా లైనక్స్ లేదా మాక్‌లో పనిచేయదు. scanf(" %c") వాడటమే సరైన ప్రమాణం.
