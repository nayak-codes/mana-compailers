Dynamic Memory Allocation: malloc, calloc, free (తెలుగులో)

⚡ C (C17 / C23 Standard) 🟢 Lesson 17 📂 Phase 09: Advanced Memory Management 📅 2026 Comprehensive Master Edition
📌 Covered in this in-depth guide: Static vs Dynamic Memory · malloc() vs calloc() · free() తో మెమరీ లీక్ (Memory Leak) నివారణ

మామూలుగా మనం int arr[10]; అని రాస్తే, కంపైలర్ ప్రోగ్రామ్ రన్ అవ్వకముందే 10 గదుల మెమరీని ఫిక్స్ చేసేస్తుంది. ఒకవేళ మీరు ఆ ప్రోగ్రామ్ రన్ చేస్తున్నప్పుడు కేవలం 2 గదులే వాడితే... మిగతా 8 గదుల మెమరీ వేస్ట్ అయిపోతుంది కదా! ఒకవేళ మీకు సడన్ గా 15 గదులు కావాలంటే, అప్పటికప్పుడు పెంచుకోలేరు. ఇలాంటి మెమరీ వేస్టేజ్ ని, షార్టేజ్ ని అరికట్టడానికి C లాంగ్వేజ్ లో తీసుకొచ్చిన ఒక బ్రహ్మాస్త్రమే Dynamic Memory Allocation (డైనమిక్ మెమరీ అలొకేషన్).

1 Static Memory vs Dynamic Memory

ముందుగానే సైజు ఫిక్స్ చేసి ఇస్తే దాన్ని "స్టాటిక్ మెమరీ" అంటారు. ఇది పెరగదు, తగ్గదు. కానీ ప్రోగ్రామ్ రన్ అవుతున్నప్పుడు (Runtime లో) మీ అవసరానికి తగ్గట్టు అప్పటికప్పుడు RAM ని అడిగి మెమరీ తీసుకుంటే దాన్ని "డైనమిక్ మెమరీ" అంటారు.

🏨 రియల్ లైఫ్ స్టోరీ: పెళ్లి భోజనాలు vs రెస్టారెంట్

ఒక పెళ్లిలో 1000 మంది వస్తారని ముందే ఫిక్స్ అయ్యి 1000 మందికి వంట చేస్తారు. ఒకవేళ 500 మందే వస్తే సగం ఫుడ్ వేస్ట్ అవుతుంది (Static Allocation).

కానీ అదే రెస్టారెంట్ లో అలా కాదు. కస్టమర్ వచ్చి ఆర్డర్ ఇచ్చిన తర్వాతే వంట చేస్తారు. ఎంతమంది వస్తే అంతమందే అప్పటికప్పుడు ఆర్డర్ ఇస్తారు, ఒక్క మెతుకు కూడా వేస్ట్ అవ్వదు. సరిగ్గా Dynamic Memory అనేది మన రెస్టారెంట్ లాంటిది!

2 ఒకే ఒక సింపుల్ కోడ్ (malloc వాడకం)

దీనికోసం మనం malloc() అనే ఫంక్షన్ వాడతాం (అంటే Memory Allocation). ఇది మనకు కావాల్సిన మెమరీ ఇచ్చి దాని అడ్రస్ ని పాయింటర్ కి ఇస్తుంది. వాడకం అయిపోయాక free() తో ఆ మెమరీ ని క్లీన్ చేసేయాలి.

C — Dynamic Memory (malloc) ▶ Run Code 
#include <stdio.h>
#include <stdlib.h> // malloc కోసం ఇది రాయాలి

int main(void) {
    // 1 ఇంటిజర్ కి సరిపడా మెమరీ అడుగుతున్నాం
    int *ptr = malloc(sizeof(int)); 
    
    // ఆ అడ్రస్ లో 50 అనే నంబర్ పెడుతున్నాం
    *ptr = 50;
    
    printf("Dynamic Value: %d\n", *ptr);
    
    // వాడకం అయిపోయాక ఆ మెమరీ ని డిలీట్ చేసేయాలి
    free(ptr);
    
    return 0;
}
3 ఫ్రీక్వెంట్ గా అడిగే ప్రశ్నలు (FAQ)

Q: malloc కి మరియు calloc కి తేడా ఏంటి?

రెండు మెమరీ ఇవ్వడానికే. కానీ malloc లోపల ఉన్న చెత్త వాల్యూస్ ని (Garbage) క్లీన్ చేయదు. calloc మాత్రం మెమరీ ఇవ్వడంతో పాటు మొత్తం గదులన్నీ '0' తో క్లీన్ చేసి ఇస్తుంది. అందుకే calloc కొంచెం స్లో గా పనిచేస్తుంది.

Q: ఒకవేళ free() రాయడం మర్చిపోతే ఏమవుతుంది?

దీన్నే ప్రోగ్రామింగ్ లో భయంకరమైన Memory Leak (మెమరీ లీక్) అంటారు. ఆ మెమరీ వాడుకోకుండా లాక్ అయిపోయి ఉంటుంది. ప్రోగ్రామ్ రన్ అవుతూ ఉంటే RAM మొత్తం ఫుల్ అయిపోయి, సిస్టమ్ క్రాష్ అయిపోతుంది (హ్యాంగ్ అవుతుంది).
