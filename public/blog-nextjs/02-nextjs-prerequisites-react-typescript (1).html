Next.js Prerequisites — React & TypeScript Fundamentals

▲ Next.js 15+ (App Router) 🟢 Chapter 2 of 43 📂 Phase 1: Next.js Introduction 📅 2026 Edition
📌 Covered in this chapter: React Components & JSX · Props & State · Hooks · Modern JavaScript (destructuring, spread, async/await) · TypeScript Basics · Git Basics
Next.js లోకి దూకే ముందు, ఈ chapter లో meeku kavalsina core React, JavaScript, and TypeScript fundamentals recap chesthunnam. Ee concepts already teliste, next chapter (Setup) కి direct ga vellochu.
1Why Prerequisites Matter Before Next.js

Next.js ఒక framework — idi React meeda built. Next.js-specific concepts (Server Components, App Router, Server Actions) ardham cheskovalante, mundu plain React ela pani chestundo, JSX ela ardham chesukovalo, modern JavaScript (ES6+) syntax ela raayalo telisi undali.

Ee chapter oka checklist laaga vaadandi — prathi section chadivi, "idi naaku already telusu" ani anipiste next section ki jump avvachu.

2Core React Concepts You Must Know

Kింద unna 5 concepts Next.js entire course ki foundation:

  • Components: UI ni reusable, independent pieces ga break cheyadam — function components most common.
  • JSX: JavaScript lopala HTML-laantidi rాయadaniki syntax extension — <h1>Hello</h1> lantidi.
  • Props: Parent component nundi child component ki data pass cheyadam (read-only).
  • State: Component internal ga maintain chese, time tho change ayye data (useState).
  • Hooks: Function components lo state, lifecycle, side-effects add cheyadaniki special functions (useState, useEffect, etc).
3Quick React Recap Example

Kింద example lo components, props, state, and a hook — anni okesari chudandi:

💻 Example 1: Props + State + useState Hook
React (JSX) ▶ Run in Compiler 
function Greeting({ name }) {
  return <h2>Hello, {name}! 👋</h2>;
}

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <Greeting name="Learner" />
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}
🔍 Breakdown:
  • { name }: Props destructure చేసి direct ga vaadutunnam.
  • useState(0): Initial value 0 tho state variable create chestundi, plus updater function setCount.
  • onClick={() => setCount(count + 1)}: Button click event ki arrow function handler attach chestundi.
4Modern JavaScript Essentials (ES6+)

Next.js codebases lo ee JavaScript features chala frequent ga kanipistayi — vాటిని comfortable ga chadavagalగడం important:

💻 Example 2: Destructuring, Spread & Async/Await
JavaScript ▶ Run in Compiler 
// Destructuring
const user = { name: "Balaji", role: "Admin" };
const { name, role } = user;

// Spread operator
const updatedUser = { ...user, role: "Editor" };

// Async / Await
async function getData() {
  const response = await fetch("https://api.example.com/data");
  const data = await response.json();
  return data;
}
🔍 Breakdown:
  • { name, role }: Object nundi values ni direct ga variables ga extract chestundi.
  • { ...user, role: "Editor" }: Spread operator, original object ni copy chesi, konni fields override chestundi.
  • async/await: Promises ni synchronous-looking code laaga raayadaniki vaadutaru — Next.js Server Components lo idi core pattern.
5TypeScript Basics for Next.js

Next.js official ga TypeScript ni recommend chestundi (default option create-next-app lo). TypeScript, JavaScript meeda type safety add chestundi — bugs ni runtime ki mundే catch chestundi:

💻 Example 3: Basic Types & Interfaces
TypeScript ▶ Run in Compiler 
interface Course {
  id: number;
  title: string;
  isFree: boolean;
}

function printCourse(course: Course): string {
  return `${course.title} (Free: ${course.isFree})`;
}

const nextjsCourse: Course = { id: 1, title: "Next.js Mastery", isFree: true };
console.log(printCourse(nextjsCourse));

interface Course, object shape ni define chestundi — id number, title string, isFree boolean undali ani TypeScript compile-time lo enforce chestundi.

⚠️ Common Beginner Mistake

React fundamentals (especially useState & useEffect) sarigga ardham cheskokunda direct ga Next.js Server/Client Components chapter ki వెళ్తే, chala confusion vasthundi. Kనీసం components, props, state, hooks meeda confident ga unte migతా course chala smooth ga untundi.

💻 Hands-on Interactive Practice Challenge

Create a TypeScript interface called Student with name (string) and marks (number), then write a function that returns a pass/fail message based on marks >= 35.

TypeScript Practice ▶ Run in Compiler 
interface Student {
  name: string;
  marks: number;
}

function checkResult(student: Student): string {
  return student.marks >= 35 ? `${student.name} Passed ✅` : `${student.name} Failed ❌`;
}

console.log(checkResult({ name: "Asha", marks: 78 }));

❓ Frequently Asked Questions (FAQ)

Q Next.js nerchukovalante React deep ga nerchukovala?

Deep ga kakapoina, components, JSX, props, state, and hooks (especially useState, useEffect) meeda confident ga undali. Advanced React patterns (Context, Reducers) migతా chapters lo cover chesthaam.

Q TypeScript compulsory ah Next.js ki?

Ledu, JavaScript tho kuda Next.js project create cheyachu. Kani official docs and most production codebases TypeScript recommend chestayi, so ee course anni examples TypeScript (.tsx) lo isthunnam.

Q Git/GitHub nerchukovalsina అవసరం ఉందా?

Basic Git commands (clone, add, commit, push, pull) telisi unte, Vercel deployment (Chapter 43) chala easy avuthundi — deployment mొత్తం GitHub integration meeda base అవుతుంది.
