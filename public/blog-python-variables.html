Python 3 — Variables & Core Data Types

🐍 Python 3 🟢 Lesson 2 📅 July 2026

Think of a variable as a storage box with a label stuck to it. You write a label on the box (the variable name), put something inside it (the value), and then look it up whenever you need it. Python handles variables dynamically, meaning you don't have to state what type of data goes in the box beforehand.

1 Creating Variables

To store a value in a variable, we use the assignment operator (=). The variable name goes on the left, and the value goes on the right:

Python 3 — Variable Assignment ▶ Run Code 
# Storing data in variables
username = "Balaji"
age = 25
height = 5.9
is_developer = True

# Printing the variables
print(username)
print(age)
print(height)
print(is_developer)
2 Core Data Types

Every piece of data stored in Python belongs to a specific category. Here are the fundamental types you must know:

You can check the type of any variable using the built-in type() function:

Python 3 — Checking Types ▶ Run Code 
score = 99
print(type(score))        # <class 'int'>

pi = 3.14159
print(type(pi))           # <class 'float'>

name = "Python"
print(type(name))         # <class 'str'>

is_online = False
print(type(is_online))    # <class 'bool'>

empty = None
print(type(empty))        # <class 'NoneType'>
3 Dynamic Typing in Python

In languages like Java or C++, once you declare a variable as an integer, you can never store a string inside it. Python is dynamically typed, meaning variables can change their type as you assign new values:

Python 3 — Dynamic Types ▶ Run Code 
data = 100
print(type(data))  # <class 'int'>

data = "Now I am text!"
print(type(data))  # <class 'str'>

data = 3.14
print(type(data))  # <class 'float'>
4 Type Conversion (Casting)

You can convert one data type to another using built-in conversion functions. This is called type casting:

FunctionConverts ToExample
int()Integerint("42") → 42
float()Floatfloat("3.14") → 3.14
str()Stringstr(100) → "100"
bool()Booleanbool(0) → False
Python 3 — Type Conversion ▶ Run Code 
# String to Integer
num_str = "100"
num_int = int(num_str)
print(num_int + 50)      # 150 (math works now!)

# Integer to String (needed for concatenation)
age = 25
message = "I am " + str(age) + " years old."
print(message)           # I am 25 years old.

# Float to Integer (truncates decimal)
price = 99.99
print(int(price))        # 99

# Truthy and Falsy values
print(bool(0))           # False
print(bool(1))           # True
print(bool(""))          # False
print(bool("hello"))     # True
5 Multiple Assignment & Swapping

Python lets you assign multiple variables in a single line, which is very convenient:

Python 3 — Multiple Assignment ▶ Run Code 
# Assign multiple variables at once
x, y, z = 10, 20, 30
print(x, y, z)       # 10 20 30

# Assign the same value to multiple variables
a = b = c = 0
print(a, b, c)       # 0 0 0

# Swap two variables in ONE line (Python magic!)
first = "Alice"
second = "Bob"
first, second = second, first
print(first, second) # Bob Alice
6 The None Type

None is Python's way of representing "nothing" or "no value". It is different from 0, False, or an empty string. Use it to initialize variables that don't have a value yet:

Python 3 — None Type ▶ Run Code 
result = None  # Not yet calculated
print(result)  # None

# Check for None with 'is' keyword (best practice)
if result is None:
    print("No result yet!")
else:
    print(f"Result is: {result}")

# None is different from zero!
print(None == 0)      # False
print(None == False)  # False
print(None is None)   # True
7 F-Strings (Formatted String Literals)

F-strings are the modern, recommended way to embed variables inside strings. Prefix the string with f and put variables inside {}:

Python 3 — F-Strings ▶ Run Code 
name = "Balaji"
age = 25
language = "Python"

# Old way (messy)
print("Hello, " + name + "! You are " + str(age) + " years old.")

# F-string way (clean and readable)
print(f"Hello, {name}! You are {age} years old.")

# Expressions inside f-strings
print(f"In 5 years, you will be {age + 5}.")
print(f"Pi rounded to 2 decimals: {3.14159:.2f}")
print(f"{language.upper()} is amazing!")
8 Constants & Naming Conventions

Python doesn't have a built-in const keyword. By convention, variables written in ALL_CAPS are treated as constants — values that shouldn't change:

Python 3 — Constants & Naming ▶ Run Code 
# Constants — by convention, ALL CAPS
MAX_USERS = 1000
PI = 3.14159
APP_NAME = "Our Compiler"

print(f"App: {APP_NAME}")
print(f"Max users: {MAX_USERS}")
print(f"PI value: {PI}")

# Good variable naming (snake_case)
user_first_name = "Balaji"
total_score = 98
is_logged_in = True

# BAD naming (avoid these)
# UserFirstName = ...  # CamelCase is for classes
# x = ...             # Too vague
# 1user = ...         # Can't start with number
⚠️ Variable Naming Rules:
  • Names can only contain letters, numbers, and underscores (e.g., user_1).
  • Must never start with a number (e.g., 1user is invalid).
  • Use snake_case (all lowercase with underscores) — Python's PEP 8 style.
  • Do not use Python reserved keywords like if, else, class, return.
  • Python is case-sensitive — name and Name are two different variables.
